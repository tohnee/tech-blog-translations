# 你可以在这些地方使用 Nano Banana Pro

> 原文：[Here’s where you can use Nano Banana Pro](https://blog.google/products-and-platforms/products/gemini/where-to-use-nano-banana-pro/) · Google

我们最近发布了 Nano Banana Pro，这是我们最新的图像生成与编辑模型。Nano Banana Pro 使用 [Gemini 3 Pro](https://blog.google/products/gemini/gemini-3/#gemini-3) 来更好地理解你想要可视化的内容，并以更高的精度、更丰富的层次和细节、令人惊叹的细腻程度将其生成出来。

## 1. Gemini 应用

Nano Banana Pro 已在全球范围内开放于桌面端和移动端的 [Gemini 应用](https://gemini.google.com/)。你只需选择「创建图像」（Create images），并选择「Thinking」模型即可使用。免费档用户有使用额度限制，达到上限后，应用会退回使用原来的 Nano Banana（Google AI Plus、Pro 和 Ultra 订阅用户可享受[更高的额度](https://support.google.com/gemini/answer/16275805?sjid=8229361629659135193-NC)）。

## 2. Search 中的 AI Mode

你也可以通过 Search 中的 AI Mode 访问 Nano Banana Pro。登录你的账号后，只需前往 [AI Mode](http://google.com/ai)，在下拉菜单中选择「Thinking with 3 Pro」，点击加号图标，然后选择「Create Images Pro」。描述你想要的图像，剩下的就交给 Nano Banana Pro 吧！AI Mode 中的图像生成功能目前以英语在部分[国家和地区](https://support.google.com/websearch/answer/16649374#zippy=%2Csupported-countries-and-territories)可用。

## 3. NotebookLM

Nano Banana Pro 已面向全球所有 [NotebookLM](https://notebooklm.google.com/) 用户开放，你可以借助幻灯片（Slide Decks）和信息图（Infographics）功能，把资料和想法转化为视觉上引人入胜的叙事。Slide Decks 让你可以立即将可信的文档，甚至只是粗略的笔记，转换成排版完整的演示文稿，既适合阅读也适合演讲。这项功能在综合新信息时尤其强大：例如，你可以运行一次 [Deep Research](https://blog.google/technology/google-labs/notebooklm-deep-research-file-types/) 查询、创建一个幻灯片，无需费力啃完冗长的报告就能将复杂主题可视化。如果你已有一份演示文稿草稿，只需让 NotebookLM 创建更具视觉吸引力的幻灯片，甚至可以指定某种配色风格。

## 4. Workspace 工具

[Workspace 客户](https://workspaceupdates.googleblog.com/2025/11/workspace-nano-banana-pro.html)现在可以在 Google Slides 和 Google Vids 中使用 Nano Banana Pro。在 Slides 中，当你打开 Gemini 侧边栏并选择「Help me visualize」选项时，它会使用升级后的模型帮你创建信息图、图像、图表等。还有一个新的「Beautify this slide」功能，它使用 Nano Banana Pro，会理解你所创建幻灯片的上下文，并在此基础上进行设计。如果你对 Nano Banana Pro 的成果满意，选择「insert as new slide」即可将其添加到你的演示文稿中。

在 [Google Vids](https://workspace.google.com/products/vids/) 中，Nano Banana Pro 升级后的 AI 能以更高的精度生成图像：现在，当你从侧边栏选择带香蕉图标的「Image」选项时，如果你是 Workspace 客户，你使用的就是 Nano Banana Pro——而且如果你从零开始生成一段视频，其中所有的视觉素材都将由最新模型制作。

## 5. Flow

现在你可以在我们的 AI 电影制作工具 [Flow](https://labs.google/fx/tools/flow) 中创建图像时使用 Nano Banana Pro。你可以期待对帧和场景拥有更高的精度和控制力，以及最先进的文字渲染。这对创意工作者尤其有帮助，他们可能想要进行一些微调，比如调整相机角度、改变焦点以营造景深，或者应用精细的调色来设定完美的情绪氛围。

Nano Banana Pro 在 Flow 中面向所有付费方案开放。

## 6. Mixboard

[Mixboard](https://labs.google.com/mixboard/welcome) 是 Google Labs 的一个实验项目，帮助你探索、扩展和完善想法。借助 Mixboard 的画布，你可以用图像或文本将各种项目的不同想法可视化——无论是 DIY 手工项目、产品设计，还是你节日派对的菜单与装饰。Nano Banana Pro 已在 Mixboard 最新的 presentations（演示）功能中可用，该功能可以将你的画板转化为设计精美的演示文稿。
