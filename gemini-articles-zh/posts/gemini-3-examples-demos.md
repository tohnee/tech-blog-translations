# Gemini 3 能做什么：15 个实例

> 原文：[15 examples of what Gemini 3 can do](https://blog.google/products-and-platforms/products/gemini/gemini-3-examples-demos/) · Google

我们最新的模型 [Gemini 3](https://blog.google/products/gemini/gemini-3/) 可以帮你学习任何东西、构建任何东西、规划任何东西。它是世界上多模态理解能力最强的模型，这意味着它能够综合文本、图像、视频、音频、代码等任何主题的信息。它也是我们迄今最强大的智能体化与 vibe coding 模型，能为开发者带来巨大的生产力提升。此外，Gemini 3 还能更好地帮你把事情办成——它可以从头到尾处理复杂的多步骤工作流，代你采取行动，同时始终在你的掌控与指导之下。

我们已发布 Gemini 3 Pro 预览版，并通过一整套 Google 产品提供——包括 [Gemini 应用](https://blog.google/products/gemini/gemini-3-gemini-app/)、Search 中的 [AI Mode](https://blog.google/products/search/gemini-3-search-ai-mode/)、[Google AI Studio](https://blog.google/technology/developers/gemini-3-developers/) 等——让你能在日常生活中使用它。为了给你一些启发，下面是 15 个例子，展示我们最智能的模型能帮你做些什么。

### 1. 用代码可视化拆解艰深的科学主题

Gemini 3 在多模态理解上处于最先进水平，并拥有 100 万 token 的上下文窗口。因此它可以接收你给它的任何输入——从文本到视频再到代码乃至更多——并以对你有意义的方式帮你学习，比如基于一篇密集的研究论文生成一份互动式导读。

### 2. 获得为你量身定制的演讲辅导

只需一段你练习演讲的录音和你的幻灯片，Gemini 3 就能充当你的演讲教练。该模型运用先进的推理能力，不仅能理解并评估你的表现，还能运用其深入的知识给出建设性且可执行的建议。

### 3. 深入钻研一个科学概念

Search 中的 [AI Mode](https://blog.google/products/search/gemini-3-search-ai-mode/) 现在利用 Gemini 3 的推理能力、多模态理解和生成式 UI 能力，为你的问题动态创建最理想的版面。当模型检测到交互式工具能帮助你更好地理解某个主题时，它会实时编写一个定制模拟或工具，并加入你的回答之中。这样，它就能*展示*RNA 的作用，而不只是告诉你；此外你还能看到链接，继续探索来自全网的相关内容。

AI Mode 中的 Gemini 3

### 4. 借助信息图深入学习

[Nano Banana Pro](https://blog.google/innovation-and-ai/products/nano-banana-pro/)（Gemini 3 Pro Image）运用 Gemini 3 最先进的推理与真实世界知识，前所未有地把信息可视化，帮助你学习新学科。你可以让它为任何主题创建信息图等内容——从某个城市的天气，到如何煮印度豆蔻奶茶（Elaichi Chai），再到你新入手的室内绿植的养护方法。

Nano Banana Pro

### 5. 在你的爱好上大步前进

借助 Gemini 3 的超长上下文窗口、最先进的推理能力以及视觉与空间理解，你可以上传一段自己运动的长达一小时的视频，并获得教练级别的建议。Gemini 3 会识别出你是画面中的运动者，过滤掉噪音，并给出详细的视觉分析，包括动作姿态评估和建议的训练项目等信息。

### 6. 生成自定义界面以探索不同概念

Gemini 3 的推理与多模态能力催生了生成式界面，比如 [Gemini 应用](https://gemini.google.com/)中的新实验功能「动态视图」（dynamic view）。动态视图利用模型的智能体化编程能力，实时设计并编写一个与你的提示词完美契合的定制用户界面。例如，让 Gemini「结合每件作品的时代背景讲解梵高画廊」，你会收到一个惊艳的交互式回答，让你可以点按、滚动，以静态文本无法企及的方式学习。

Gemini 应用中的 Gemini 3

### 7. 用艺术演绎复杂的科学主题

要理解核聚变这类概念并不容易。但 Gemini 3 能深入领会这类微妙的科学主题，然后同时通过代码和诗歌，创造性地表达它的理解。

### 8. Vibe code 出丰富、可交互的 Web UI

Gemini 3 在零样本生成上表现出色。它承担了多步骤规划和编程细节的重活，让你专注于创意构想。用自然语言描述你的想法，比如一个宣传复古舞会的网站。模型大幅提升的复杂指令遵循能力和深度工具使用能力，能通过单条提示词把你的高层想法变成一个可交互的落地页。

Google AI Studio 中的 Gemini 3

### 9. 让静态图片变得可交互

多亏了 Gemini 3，一张静态图片可以变成桌面游戏，一张餐巾纸涂鸦可以变成完整的网站，一张示意图也可以通过交互式课程焕发新生。模型深度的多模态理解能力能够判断图像内容以交互形式呈现何时最吸引人，然后把它转化为可用的形式。

Google AI Studio 中的 Gemini 3

### 10. 直观呈现巨大的尺度差异

你知道亚原子粒子极其微小，而星系无比庞大。但借助 Gemini 3，你可以构建一种方式来*看见*这些尺寸差异。模型之所以擅长编程，是因为它能够综合零散的信息并遵循复杂而富有创意的指令。它还理解你想法背后的意图，让你一步到位，从粗略的概念直达一个可运行的起点。

Google AI Studio 中的 Gemini 3

### 11. 生成在真实世界能跑的代码

借助我们全新的智能体化开发平台 [Google Antigravity](https://antigravity.google/)，你可以更快地构建，并管理跨越编辑器、终端和浏览器工作的智能体。Antigravity 运用 Gemini 3 先进的推理、工具使用和智能体化编程能力充当你的伙伴，生成的代码复杂到足以在真实世界运行——比如经典的 cartpole 摆车问题。

Google Antigravity 中的 Gemini 3

### 12. 创建定制行程单

可视化布局（Visual layout）是 Gemini 应用中另一项实验性的生成式界面体验。它超越纯文本，提供一种沉浸式的杂志风格视图，包含照片和可交互的模块，让你进一步定制回答。例如，让它「规划一次为期 3 天的罗马之旅」，你会得到一份根据你的偏好定制、可以逐项探索的行程单。

Gemini 应用中的 Gemini 3

### 13. 在重要的事情上获得帮助

Gemini 3 在 Search 中的生成式 UI 能力，还能为更实际的问题构建工具。现在，[AI Mode](https://google.com/ai) 可以为你定制一个交互式贷款计算器，用来比较两种不同方案、看哪种长期更省钱，你还可以修改和自定义输入项，获得更深入的洞察。

AI Mode 中的 Gemini 3

### 14. 实现收件箱清零

Gemini Agent 是一项实验功能，直接在 Gemini 应用内处理多步骤任务，它可以帮助你做邮件分诊之类的事情。该功能建立在 [Project Mariner](https://deepmind.google/models/project-mariner/) 的洞见之上，并运用 Gemini 3 的先进推理能力，Gemini 会借助 Deep Research、Canvas、Gmail 和 Calendar 等 Google Workspace 关联应用以及实时网页浏览等工具，把复杂的请求拆解执行。使用过程中你始终掌握主动：Gemini 被设计为在关键操作前寻求确认，你也可以随时接管。

Gemini 应用中的 Gemini 3

### 15. 把周末过得更尽兴

有了 Search 中的 Gemini 3，你可以提出更复杂的问题，并在 AI Mode 中获得更丰富、更直观、更有帮助的回答。假设你对去冲浪有一系列非常具体的条件——把这些要求输入 AI Mode。Gemini 3 会再次运用其多模态理解与智能体化编程能力，即时生成最有帮助的版面，甚至构建图片、表格和网格等视觉元素来帮助你做选择。冲浪去喽！
