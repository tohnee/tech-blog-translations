# 用更新版 Gemini 2.5 Pro 构建丰富、交互式的 Web 应用

> 原文：[Build rich, interactive web apps with an updated Gemini 2.5 Pro](https://blog.google/products-and-platforms/products/gemini/gemini-2-5-pro-updates/) · Google

今天，我们发布 [Gemini 2.5 Pro Preview](https://deepmind.google/technologies/gemini/pro/)（I/O 版）的抢先体验——这是 2.5 Pro 的更新版本，在编程、尤其是构建引人入胜的交互式 Web 应用方面，能力有了显著提升。我们原计划几周后在 [Google I/O](http://io.google/) 上发布这次更新，但鉴于大家对这款模型的热情极为高涨，我们希望更早把它交到你们手中，让大家尽快开始构建。

这建立在 Gemini 2.5 Pro 编程与多模态推理能力广受好评的基础上。除了聚焦 UI 的开发，这些改进还延伸到其他编程任务，例如代码转换、代码编辑以及开发复杂的智能体化（agentic）工作流。

[在 Gemini 应用中查看这个提示词的结果。](https://g.co/gemini/share/5be8ec4c17d9)

凭借这些增强的能力，2.5 Pro 现在在 [WebDev Arena 排行榜](https://web.lmarena.ai/leaderboard)上登顶，比上一版本高出 +147 个 Elo 点。该排行榜衡量的是人类对模型构建美观且实用 Web 应用能力的偏好。它还继续建立在原生多模态与长上下文的坚实基础上；其视频理解达到最先进水平，在 VideoMME 基准上取得 84.8% 的成绩。

[在 AI Studio 上查看 Video to Learning 应用。](https://aistudio.google.com/app/apps/bundled/video-to-learning-app?showPreview=true)

开发者可以通过 [Google AI Studio](http://aistudio.google.com/app/prompts/new_chat?model=gemini-2.5-pro-preview-05-06) 和 [Vertex AI](https://console.cloud.google.com/freetrial?redirectPath=/vertex-ai/studio)，在 Gemini API 中基于这个更新版 Gemini 2.5 Pro 开始构建。它也已在 [Gemini 应用](http://gemini.google.com/)中向用户开放，为 [Canvas](https://gemini.google.com/canvas) 等功能提供支持，让任何人都能用一个提示词 vibe code 出交互式 Web 应用。
