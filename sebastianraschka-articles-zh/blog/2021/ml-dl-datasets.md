# 机器学习与深度学习数据集

> 原文：[ML & Deep Learning Datasets](https://sebastianraschka.com/blog/2021/ml-dl-datasets.html)

上个月，我分享了一份简短的数据集仓库清单，打算推荐给学生，作为他们课程项目的灵感来源。

[![插图](https://sebastianraschka.com/images/blog/2021/ml-dl-datasets/tweet.webp)](https://twitter.com/rasbt/status/1345407451865243648)

感谢大家在上面的 Twitter 推文串中提出的众多优秀建议，这份清单已经扩充了不少！如今新学期正如火如荼，我最近把这套数据集仓库分享给了我的深度学习课的学生。不过，除了用来为有趣的课程项目寻找灵感之外，这些仓库也是为你的模型寻找更多[基准测试](https://sebastianraschka.com/glossary/#benchmark "Benchmark")数据集的好去处，所以我把它发布在这里，希望对大家有用！

很难按重要性排序，也难以选出偏爱，所以下面的清单按字母顺序排列。

## Academic Torrents —— 用于共享超大规模数据集的分布式系统

- 目前该网站上已有总计 65 TB 的数据集可供获取
- 数据共享通过 BitTorrent 技术实现

链接：<https://academictorrents.com>

## Awesome Public Datasets —— 按应用领域组织的大型 GitHub README 清单

链接：<https://github.com/awesomedata/awesome-public-datasets>

- 收录了约 650 个数据集的链接
- 按应用领域组织（如农业、生物学等）

## CVonline：图像数据库 —— Bob Fisher 汇编的计算机视觉数据集

链接：<http://homepages.inf.ed.ac.uk/rbf/CVonline/Imagedbase.htm>

- 收录了超过 1000 个计算机视觉数据集的惊人合集，按类别排序（农业、通用图像等）

## Datasetlist.com —— 按领域分类的数据集

链接：<https://www.datasetlist.com>

- 可按类别对数据集排序（图像、NLP、音频等）
- 可按许可证和年份排序
- 提供原始论文链接（如适用）

## Data is Plural —— 一份数据集新闻通讯

链接：<https://tinyletter.com/data-is-plural>

- 每周汇编一份有趣新数据集清单的周报通讯

## Google Dataset Search —— 数据集搜索引擎

链接：<https://datasetsearch.research.google.com>

- 可按名称或描述搜索数据集
- 返回摘要结果，并提供可获取该数据集的各类来源链接

## Huggingface Datasets —— 用于加载 NLP 数据集的 Python 库

链接：<https://github.com/huggingface/datasets>

- 一个让 NLP 数据集可以在 Python 中直接使用的工具

## IBM 的 Data Asset Exchange —— 面向企业应用的数据集合集

链接：<https://developer.ibm.com/exchanges/data/>

- 若干围绕企业应用的大型数据集，采用对社区友好的共享许可证
- 各个数据集都附有 Jupyter notebook 链接，展示数据加载与处理示例
- 大多为表格数据，更适合传统机器学习

## Jupyter Tutorial Data —— 数据集仓库列表

链接：<https://jupyter-tutorial.readthedocs.io/en/24.1.0/>

- 一个链接到最常见数据集仓库和搜索引擎的列表

## Kaggle Datasets

链接：<https://www.kaggle.com/datasets>

- 针对 Kaggle 上可用数据集的搜索引擎
- 可通过搜索词、类别标签和文件类型发现数据集

## OpenML —— 精选数据集与工作流的搜索引擎

链接：<https://www.openml.org/search?type=data>

- 3265 个数据集，标注了样本数、特征数和类别数
- 社区提供工作流（如 scikit-learn pipeline）
- 大多数数据集是面向传统机器学习的表格数据集

## Papers with Code —— 附带基准测试的数据集

链接：<https://www.paperswithcode.com/datasets>

- 3,095 个机器学习数据集，附原始论文链接（如适用）
- 包含使用该数据集的论文数量
- 汇总了基准测试信息，并提供基准测试来源的链接

## Penn Machine Learning Benchmarks —— 干净的表格数据集

链接：<https://github.com/EpistasisLab/pmlb/tree/master/datasets>

- 一组经过预处理的表格形式数据集
- 更适合传统机器学习而非深度学习

## Public APIs —— 公开数据集 API 列表

链接：<https://github.com/public-apis/public-apis>

- 收录了约 650 个数据集 API

## r/datasets —— 用于分享和讨论数据集的 subreddit

链接：<https://www.reddit.com/r/datasets/>

- 一个可以发现数据集，并围绕数据集展开讨论的站点

## Roboflow Public Datasets —— 计算机视觉数据集

链接：<https://public.roboflow.com>

- 公开的计算机视觉数据集列表
- 类别包括图像分类与目标检测

## UCI Machine Learning Repository —— 机器学习项目的经典之选

链接：<https://archive.ics.uci.edu/ml/index.php>

- 经典的机器学习数据集仓库，可按任务（分类、回归等）、应用领域、数据类型和规模进行搜索
- 该数据库中的大多数数据集更适合传统机器学习而非深度学习

## VisualDataDiscovery

链接：<https://www.visualdata.io/discovery>

- 收录了超过 500 个计算机视觉数据集
- 可按许可证以及代码/模型可用性进行筛选
