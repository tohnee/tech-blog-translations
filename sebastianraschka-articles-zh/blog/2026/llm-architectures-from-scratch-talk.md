# 从零实现 LLM 架构（演讲）

> 原文：[Implementing LLM Architectures From Scratch](https://sebastianraschka.com/blog/2026/llm-architectures-from-scratch-talk.html)

我分享了一个简短的演讲，谈我在用 Python 和 PyTorch 从零实现 LLM 架构过程中的心得。

其中实用的部分是工作流程：当一个新的开放权重模型发布时，我通常从一份紧凑的参考实现入手，梳理架构改动，并把这些细节与模型卡、config 文件和公开代码进行比对。这往往是最快的办法，可以区分"只是命名不同"与"真正的设计改动"。

演讲在这里：[What I Learned From Implementing LLM Architectures From Scratch](https://youtu.be/TXzQ7PGpO6w)。
