# 《Build a Reasoning Model (From Scratch)》正式出版

> 原文：[Build a Reasoning Model From Scratch Is Out](https://sebastianraschka.com/blog/2026/build-a-reasoning-model-from-scratch-is-out.html)

一年半的时间、无数次实验、数百页的篇幅之后……今天是我作为工程师和作者最难忘的日子之一。*《Build a [Reasoning Model](https://sebastianraschka.com/glossary/#reasoning-model "Reasoning Model") (From Scratch)》*（《从零构建推理模型》）终于出版了，我的第一批样书刚刚到手！

440 页全彩印刷。

衷心感谢过去 1.5 年里作为早期读者和审阅者一路陪我走来的每一个人。希望这本书配得上作为《Build a Large Language Model (From Scratch)》（《从零构建大语言模型》）的续篇。

如果你想知道这本书涵盖什么内容：它带你在一个小型 Qwen3 [基座模型](https://sebastianraschka.com/glossary/#base-model "Base Model")之上从零实现现代推理技术，重点包括：

1. 推理时扩展（inference scaling）
2. 强化学习
3. [知识蒸馏](https://sebastianraschka.com/glossary/#distillation "Distillation")

《Build a Large Language Model (From Scratch)》侧重于构建和预训练一个 LLM，而这本新书则从它停下的地方接续，讲述接下来会发生什么。

（如果你喜欢模型架构细节，别担心：完整的 Qwen3 架构也在附录中从零实现并做了讲解。）

这本书已由出版社开始发货：

[Build a Reasoning Model (From Scratch)](https://mng.bz/Nwr7)

它也可以在 Amazon 上预订，预计几周后开始发货：

[在 Amazon 预订 Build a Reasoning Model (From Scratch)](https://amzn.to/4aAKiFY)

我希望它能成为一份有用的资源，帮助所有想了解推理模型底层工作原理的读者——推理模型如今已是许多现代 AI 智能体的关键组成部分。

再次感谢每一位帮助这本书问世的人！祝大家阅读愉快！
