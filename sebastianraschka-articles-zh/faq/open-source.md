# 应该从什么时候开始为开源做贡献？

> 原文：[At what point should one start contributing to open source?](https://sebastianraschka.com/faq/docs/open-source.html) · Sebastian Raschka's FAQ

如果开源贡献不是你的兴趣所在，请不要感到有压力——我更多把它看作一种学习和「回馈」的机会，但它当然不是一种「义务」:)。

> ……像修复错别字这样的小任务 […] 这些时间本可以用来学习

我会说这要看情况。我认为为开源项目做贡献不应该完全围绕个人收益；在有用的地方扩充/修复文档，对项目同样有价值。归根结底，在「这对我个人有什么好处」与「这是否能帮助社区、帮助那些为我每天免费使用的东西付出大量心血的人」这两个端点之间，你想处在哪个位置，取决于你自己。——这当然不是非黑即白的决定，也没有对错之分 :)

顺便说一句，取决于你的经验水平，「修复错别字」本身也可以是一种有价值的学习经历。例如，做「数据科学」不只是分析数据，沟通能力和团队协作能力同样重要。如果你还不熟悉版本控制，可以把修复错别字当作学习版本控制的机会，或者借此练习使用某些框架/工作流。
