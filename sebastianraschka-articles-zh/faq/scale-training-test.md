# 为什么我们需要复用训练参数来变换测试数据？

许多机器学习算法要求特征处于同一尺度上，例如当我们计算距离时（如最近邻算法）。此外，如果特征以零为中心、标准差为一——即数据具有标准正态分布的性质——那么梯度下降等优化算法的效果最好。极少数真正具有尺度不变性的机器学习算法类别是树方法。

现在，一个常见的问题是如何正确地对数据集做缩放。为简单起见，下面例子中的伪代码使用「标准化（standardization）」流程。但请注意，同样的原则也适用于 min-max 缩放等其他缩放方法。

在实践中，我见过很多在把数据集送入学习算法之前对其进行缩放的方式。你能猜出哪一种是「正确」的吗？

## 场景 1：

```python
scaled_dataset = (dataset - dataset_mean) / dataset_std_deviation

train, test = split(scaled_dataset)
```

## 场景 2：

```python
train, test = split(dataset)

scaled_train =  (train - train_mean) / train_std_deviation

scaled_test = (test - test_mean) / test_std_deviation
```

## 场景 3：

```python
scaled_train =  (train - train_mean) / train_std_deviation

scaled_test = (test - train_mean) / train_std_deviation
```

没错，「正确」的方式是*场景 3*。我承认，使用训练参数并复用它们来缩放测试数据集看起来可能有点奇怪。（注意，在实践中，如果数据集足够大，我们不会在场景 1-3 之间观察到任何实质性差异，因为我们假设所有样本都来自同一分布。）

那么，为什么是*场景 3*？原因在于我们想要把测试数据当作「新的、未见过的数据」来对待。我们使用测试数据集来很好地估计模型在任何新数据上的表现。

而在真实应用中，新的、未见过的数据可能只是我们想要分类的 1 个数据点。（如果只有 1 个数据点，我们如何估计均值和标准差？）这个直观的例子说明了为什么我们必须保留并使用训练数据的参数来缩放测试集。

总结一下：如果我们对训练数据集做了标准化，就需要保留这些参数（每个特征的*均值*和*标准差*）。然后，我们用这些参数来变换测试数据以及之后的任何未来数据。

让我给一个实际例子来说明这一点为什么重要！

假设我们有一个简单的训练集，由 3 个样本、1 个特征列组成（把这个特征列称为「长度，单位 cm」）：

- sample1：10 cm -> 类别 2
- sample2：20 cm -> 类别 2
- sample3：30 cm -> 类别 1

根据上面的数据，我们计算出以下参数：

- 均值：20
- 标准差：8.2

如果用这些参数标准化同一数据集，会得到以下值：

- sample1：-1.21 -> 类别 2
- sample2：0 -> 类别 2
- sample3：1.21 -> 类别 1

现在，假设我们的模型学习到了如下假设：它把标准化长度值 < 0.6 的样本分类为类别 2（否则为类别 1）。到目前为止一切正常。接下来，想象我们有 3 个新的、无标签的、想要分类的数据点。

- sample4：5 cm -> 类别 ?
- sample5：6 cm -> 类别 ?
- sample6：7 cm -> 类别 ?

如果看训练集中「未标准化的『长度，单位 cm』」值，很直观地可以说这些样本很可能都属于类别 2。然而，如果我们通过从新数据重新计算*标准差*和*均值*来标准化它们，就会得到与训练集中先前相似的值（即标准正态分布的性质），于是分类器会（很可能错误地）给样本 4 和 5 打上「类别 2」的标签。

- sample5：-1.21 -> 类别 2
- sample6：0 -> 类别 2
- sample7：1.21 -> 类别 1

但是，如果我们使用「训练集标准化」得到的参数，就会得到如下的标准化值：

- sample5：-18.37
- sample6：-17.15
- sample7：-15.92

注意，这些值比原始训练集中 sample1 的值更小（更偏负），这才合理得多！
