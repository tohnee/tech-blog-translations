# 我应该专注于数据科学中的哪条学习路径/方向？

> 原文：[What learning path/discipline in data science I should focus on?](https://sebastianraschka.com/faq/docs/data-science-career.html) · Sebastian Raschka's FAQ

太长不看版："数据科学"是一个涵盖许多不同专门方向的宽泛领域；你觉得哪个具体的子角色最有吸引力？统计学、机器学习、软件工程、数据可视化……？

嗯，这话该怎么说呢……一天只有 24 小时实在可惜，作为一个人，我们能学的东西终究有限。所以我认为，在选择学习主题时，认真思考一下自己的目标和兴趣是相当重要的。虽然听起来"名声不好"，但"样样都会一点"（being a jack of all trades）这个说法对独立工作的人来说确实非常诱人也非常有用。作为一名"数据科学家"，你可以沉迷其中的话题无穷无尽：从编程到统计学、数据库、微分学……当然，什么都懂一点是有用的，但我认为在有限的时间里想精通一切是不可能的。举例来说，数据科学家很少单打独斗，他们往往是有不同职责分工的大团队中的一员。有些人特别擅长统计；有些人负责构建采集、清洗和提取数据的框架；有些人开发新算法，还有一些人是"数据科学家兼程序员"，专注于以最高效的方式实现这些算法。举个例子，我认为自己是一个相当不错的 Python 程序员，但我的 Java 水平真的很粗浅。我想更好的 Java 知识偶尔能帮上忙，但我的重心更多在机器学习部分；Python 已经足以让我实现自己所有的想法。所以，与其投入精力去学一门全新的编程语言，我更倾向于聚焦于自己的强项，比如学习新鲜的机器学习概念、紧跟该领域的最新进展。当然，我也想学一门新的编程语言，因为它可能有用，但我也清楚，要学完所有这些东西，我的时间只有这么多…… ;)

我想说的是：思考一下 xx 年后你想成为什么样的人、达到那个目标需要什么，这大概不是个坏主意。哪些东西和技能是你到达那里所必需的？我会先专注于这些！
