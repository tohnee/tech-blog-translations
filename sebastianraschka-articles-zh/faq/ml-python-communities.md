# 数据科学、机器学习与 Python 社区

我认为 [Twitter](https://twitter.com/rasbt) 很适合保持联系、看看别人在做什么，当然也适合分享新闻。[Cross-validated](http://stats.stackexchange.com) 和 [Quora](https://www.quora.com/topic/Machine-Learning) 是提问具体问题、就某个话题收集多方意见的好网站。还有一个 [Google+ 上的机器学习群组](https://plus.google.com/communities/107785538899595981479)，成员很多，但恐怕已经没那么活跃了。[MachineLearning subreddit](https://www.reddit.com/r/MachineLearning/) 是讨论某些新闻和文章的另一个好去处。
