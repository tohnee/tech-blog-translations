# 你会如何向软件工程师解释机器学习？

软件工程是开发程序或工具来让任务自动化。与其"手工做事"，我们编写程序；程序本质上只是一组计算机可读、可由计算机执行的指令。
来看一个经典例子：电子邮件垃圾邮件过滤。假设我们能拿到邮件客户端的源代码并且知道怎么改，我们完全可以凭直觉想出一套规则，来帮我们解决垃圾邮件问题。

例如：
if not "sender in contacts":
if "subject line contains BUY!:
e-mail spam folder:"
else if …

不难想到，想出这些规则是一件相当繁琐的工作。更不用说，我们还必须在真实数据上测试垃圾邮件过滤器，不断评估和改进它、修改和更新规则，等等。再强调一次，我们的目标是自动化：我们希望写出一组能自动过滤垃圾邮件的指令，这样就不用"手动"把它们从收件箱里删掉了。

而**机器学习做的就是让"自动化"本身自动化**！与其自己想出用于自动化邮件垃圾过滤这类任务的规则，我们**把数据喂给机器学习算法，让它自己把这些规则琢磨出来**。在这里，"数据"应当是我们想要解决的问题的代表性样本——例如一组垃圾邮件和非垃圾邮件，这样机器学习算法才能"从经验中学习"。

在"传统"编程中，我们编写一组规则，把它连同数据一起交给计算机，然后期望它产出想要的结果。

**传统编程：**

- 规则集合 + 数据 -> 计算机 -> 结果

在机器学习中，我们拿数据（例如邮件），提供关于期望结果的信息（这些邮件的垃圾/非垃圾标签），并把它喂给一个学习算法，再由计算机执行。计算机于是*学习*出一组规则，我们可以用这组规则来自动化（解决）我们的问题任务。

**机器学习：**

- 结果 + 数据 -> 机器学习算法 + 计算机 -> 规则集合

**换句话说，机器学习就是寻找把一个任务自动化的最优指令。机器学习算法是这样一种指令：它让计算机从数据或经验中自动学习出其他指令。因此，机器学习就是自动化的自动化。**
