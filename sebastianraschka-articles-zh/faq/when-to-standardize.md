# 什么时候应该做数据归一化/标准化？

我能想到的唯一一类尺度不变的算法是基于树的方法。以通用的 CART 决策树算法为例。不必深入讨论信息增益和不纯度度量，我们可以把决策过程理解为"特征 x\_i >= 某个值吗？"凭直觉就能看出，这个特征处于什么尺度其实无关紧要（厘米、华氏度、标准化后的尺度——真的都一样）。

特征缩放（feature scaling）会带来影响的一些算法示例如下：

- k 近邻（使用欧氏距离度量时），如果希望所有特征贡献均等
- k 均值（参见 k 近邻）
- 逻辑回归、SVM、感知机、神经网络等，如果你使用基于梯度下降/上升的优化，否则某些权重的更新会远快于其他权重
- 线性判别分析、主成分分析、核主成分分析，因为你想找到使方差最大化的方向（在这些方向/特征向量/主成分正交的约束下）；你希望各特征处于同一尺度，否则你会更强调"测量尺度更大"的变量。

类似的情形远不止我在此能列出的这些……我一直建议你思考一下算法本身及其在做什么，然后通常就能明显看出我们是否需要对特征做缩放。

此外，我们还要考虑是想对数据做"标准化"（standardize）还是"归一化"（normalize，这里指缩放到 [0, 1] 区间）。有些算法假设数据以 0 为中心。例如，如果我们将一个使用 tanh 激活单元的小型多层感知机的权重初始化为 0 或以零为中心的小随机值，我们就希望"同等"地更新模型权重。
作为一条经验法则，我想说：拿不准时，就直接把数据标准化，这不会有什么坏处。
