# RoPE 与绝对位置嵌入之比较

**RoPE** 是**旋转位置编码（rotary position embeddings）**的简称，它通过在自注意力内部旋转查询向量和键向量来编码位置。学习式绝对位置嵌入的做法则更直接：为每个位置学习一个向量，并在第一个 transformer 块之前把它加到 token 嵌入上。

RoPE 之所以在现代 LLM 中变得普遍，是因为它赋予查询-键交互一种有用的相对位置结构，同时避免了固定学习位置表。它可以为训练中未曾使用的位置索引计算旋转，不过仅凭这一点并不能保证模型在更长长度上依然表现良好。

GPT-2 采用的学习式绝对做法可以写成

\[h\_t = E\_{\text{token}}(x\_t) + P\_t.\]

其中 \(E\_{\text{token}}(x\_t)\) 是 token 嵌入，\(P\_t\) 是为位置 \(t\) 学习到的向量。这两个向量宽度相同，二者之和成为第一个 transformer 块的残差流输入。

![GPT 风格的输入为每个 token 嵌入加上一个学习到的位置向量。](https://sebastianraschka.com/images/LLMs-from-scratch-images/ch02_compressed/18.webp)

位置表的形状是 `最大上下文长度` 乘 `嵌入维度`。例如 GPT-2 small 有 1,024 个宽度为 768 的位置向量，共计增加 786,432 个参数。这种表易于理解、使用成本低，但也构成了一个硬性的架构边界：在一张到位置 1,023 为止的表里，位置 1,024 没有对应的行。

增大表能解决张量形状的问题，但新增的行是未经训练的。实现上必须对它们进行初始化、插值，或通过额外训练来学习。而且模型可能已经学到了与预训练时见过的绝对索引绑定的行为。

RoPE 把位置操作从模型输入移到了每一个注意力层内部。在每个注意力头中，相邻的查询与键特征被当作二维数对处理。旋转矩阵 \(R\_t\) 按照由位置 \(t\) 和特定通道的频率决定的角度旋转每一个数对：

\[q'\_t = R\_t q\_t, \qquad k'\_t = R\_t k\_t.\]

值向量通常保持不变。随后注意力使用位置 \(m\) 上旋转后的查询与位置 \(n\) 上旋转后的键之间的点积：

\[(R\_m q\_m)^\mathsf{T}(R\_n k\_n)
= q\_m^\mathsf{T} R\_{n-m} k\_n.\]

第二种形式由旋转矩阵的性质直接得出，它说明了 RoPE 为什么与相对位置联系在一起。注意力分数中的位置项只依赖于偏移量 \(n-m\)（包括其方向），而不需要为每个绝对槽位单独学习一个向量。不过，旋转后的查询和键仍带有各自位置特定的相位，因此把 RoPE 说成纯粹相对的会稍有误导。

| 属性 | 学习式绝对嵌入 | RoPE |
| --- | --- | --- |
| 应用对象 | 第一个块之前的 token 嵌入 | 注意力中的查询和键 |
| 位置参数 | 每个支持的位置一个学习向量 | 通常没有 |
| 查询-键分数中的相对偏移 | 必须从相加的向量中学到 | 内建于旋转恒等式中 |
| 超出配置表的位置 | 表扩展之前无定义 | 角度可以计算，但质量无保证 |
| 注意力复杂度 | 不变 | 不变 |

RoPE 在头维度上使用多个旋转频率。高频数对在相邻位置之间变化很快，低频数对则变化较慢。基准频率、头维度以及被旋转通道的比例都是架构选择。有些模型对每个查询和键通道都应用 RoPE，另一些则使用部分 RoPE（partial RoPE），让每个头的一部分保持不变。

![从 GPT 到 Llama 的演进，把学习式的输入位置表替换为注意力内部的 RoPE。](https://sebastianraschka.com/images/LLMs-from-scratch-images/bonus/gpt-to-llama/gpt2-to-llama2-llama3.webp)

长上下文的主张需要谨慎对待。RoPE 可以为位置 100,000 生成旋转，而不必分配 100,000 个学习位置向量。但只在短得多的序列上训练过的模型，未必学会了使用那些陌生的相位。即使前向传播能够顺利运行，检索准确率和语言建模损失仍可能恶化。

位置插值、频率基准修改、NTK-aware scaling 以及 YaRN 等方法会针对更长的目标上下文调整 RoPE 频率。在更长的序列上继续训练也有助于模型适应。具体的缩放方案是模型配置的一部分，因此同一个「RoPE」标签之下可能描述着长上下文行为各不相同的模型。

RoPE 并不改变全注意力的二次方开销。它只是增加了廉价的逐元素旋转，而查询-键矩阵和注意力概率仍随序列长度增长。它也不会减小 KV 缓存的大小。在自回归生成期间，实现通常先按某个键的位置 ID 对其旋转，再存入缓存。位置 ID 错误——尤其是在有填充或复用缓存的情况下——可能会悄无声息地给模型错误的相对偏移。

因此，从 GPT-2 式绝对嵌入转向 RoPE，改变的是注意力表示位置的方式。RoPE 在无需学习位置表的情况下提供相对偏移结构，也更容易适配新的上下文长度。但实际的外推能力仍取决于频率、训练长度、缩放方法和评估任务。
