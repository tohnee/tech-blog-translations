# SGLang v0.3 发布：DeepSeek MLA 最高提速 7 倍、torch.compile 最高提速 1.5 倍、LLaVA-OneVision 多图/视频支持

> 原文：[SGLang v0.3 Release: 7x Faster DeepSeek MLA, 1.5x Faster torch.compile, Multi-Image/Video LLaVA-OneVision](https://lmsys.org/blog/2024-09-04-sglang-v0-3/) · LMSYS Blog · The SGLang Team

我们很高兴地宣布 [SGLang v0.3](https://github.com/sgl-project/sglang/tree/main) 正式发布。本次版本带来了显著的性能提升，并扩展了对新型模型架构的支持。主要更新如下：

- DeepSeek 多头潜在注意力（MLA）吞吐量最高提升 7 倍
- 小批量（batch size）场景下借助 `torch.compile`，延迟最高改善 1.5 倍
- LLaVA-OneVision 支持文本与多图/视频交错输入
- Gemma-2 支持交错窗口注意力，上下文长度延长至 2 倍

在本篇博文中，我们将逐一介绍这些关键特性。欢迎大家随时报告问题，或贡献想法与代码。


### DeepSeek 多头潜在注意力（MLA）吞吐量优化

[多头潜在注意力](https://arxiv.org/pdf/2405.04434)（MLA）是 DeepSeek 团队为提升推理效率而提出的一种新型注意力变体。由于它与标准注意力机制存在差异，现有开源库尚未对这一运算进行充分优化。在 SGLang v0.3 中，我们为 MLA 实现了多种优化，包括权重吸收（weight absorption）、分组解码内核（grouped decoding kernels）、FP8 批量矩阵乘法（FP8 batched MatMul）以及 FP8 KV 缓存量化。**基准测试结果显示，经过 MLA 优化的 SGLang v0.3 相比基线系统可取得 3 至 7 倍的吞吐量提升。**该基准测试在 ShareGPT 数据集上测量这些模型在 H100 GPU 上以 BF16 和 FP8 运行时的峰值输出吞吐量（lite 模型使用张量并行度 1，大模型使用张量并行度 8）。复现步骤见附录。结果虽然令人鼓舞，但仍有很大改进空间。我们正在积极推进更多优化，以完全复现 DeepSeek 论文中的结果。相关 PR：
[#905](https://github.com/sgl-project/sglang/pull/905),

### torch.compile 延迟优化

[torch.compile](https://pytorch.org/assets/pytorch2-2.pdf) 是 PyTorch 2.0 的一项重要特性。在 NVIDIA GPU 上，它会执行激进的算子融合，并生成高效的 Triton 内核。我们将 torch.compile 集成进 SGLang，作用于线性层/归一化层/激活层，并与 FlashInfer 的注意力与采样内核相结合。我们在 batch size 为 1 到 32 时启用 torch.compile，这一区间内加速最为明显。凭借这一组合，SGLang 在 batch size 为 1 时比 [gpt-fast](https://github.com/pytorch-labs/gpt-fast) 更快，同时支持所有在线推理服务特性，包括连续批处理（continuous batching）和用于前缀缓存的 RadixAttention。我们正在与 torch.compile 及 [torchao](https://github.com/pytorch/ao) 团队积极合作，将他们的最新优化引入 SGLang。要在 SGLang 中使用 torch.compile，启动服务器时加上 `--enable-torch-compile` 即可。**在下面的基准测试中，启用 torch.compile 的 SGLang 最高可获得 1.5 倍加速。**复现步骤见附录。

### LLaVA-OneVision 支持：交错文本、多图与视频

[LLaVA-OneVision](https://llava-vl.github.io/blog/2024-08-05-llava-onevision/) 是首个在三个重要计算机视觉场景——单图、多图与视频任务——均达到最先进（state-of-the-art）性能的开放模型。我们与 LLaVA 团队合作，将这些能力集成到了 SGLang v0.3 中。你可以启动服务器，并通过 OpenAI 兼容的视觉 API 进行查询，该 API 支持交错文本、多图与视频格式。用法详情见[此处](https://github.com/sgl-project/sglang/blob/c500f96bb16c686ee8ba5d5f1fc716a0bd8e5fff/README.md?plain=1#L241-L244)。作者验证了模型精度，并在 VideoDetailDescriptions 和 LLaVA-in-the-wild 数据集上给出了基准测试结果（见 [#1123](https://github.com/sgl-project/sglang/pull/1123#issuecomment-2301691452)）。**相比作者在 HuggingFace/transformers 中的原始实现，SGLang 最高可实现 4.5 倍加速。**

### Gemma-2 支持交错窗口注意力

Google 的 [Gemma-2 模型](https://arxiv.org/abs/2408.00118)采用交错窗口注意力来降低长上下文的计算复杂度，各层交替使用局部滑窗注意力（4K 上下文长度）与全局注意力（8K 上下文长度）。我们增强了 SGLang v0.3，借助 FlashInfer 优化过的窗口注意力内核（跳过而非掩蔽窗口外计算）并改进了 KV 缓存管理器，从而完整支持 8K 上下文长度。缺少这一特性的其他库只能以 4K 上下文长度运行。你可以使用以下命令启动该模型：
```
python3 -m sglang.launch_server --model-path google/gemma-2b   
```

## 附录

### DeepSeek MLA 基准测试步骤

```  
# DeepSeekCoder-V2-Lite (BF16)
## Launch a server  
python3 -m sglang.launch_server --model deepseek-ai/DeepSeek-Coder-V2-Lite-Instruct --enable-mla --disable-radix --trust-remote-code  
python3 -m vllm.entrypoints.openai.api_server --model deepseek-ai/DeepSeek-Coder-V2-Lite-Instruct --disable-log-requests --trust-remote-code --max-model-len 4096

## Run benchmark  
python3 -m sglang.bench_serving --backend sglang --num-prompts 5000  
python3 -m sglang.bench_serving --backend vllm --num-prompts 5000

# DeepSeekCoder-V2 (BF16)  
## Launch a server  
python3 -m sglang.launch_server --model deepseek-ai/DeepSeek-Coder-V2-Instruct --disable-radix --tp 8 --trust-remote-code --enable-mla  
python3 -m vllm.entrypoints.openai.api_server --model deepseek-ai/DeepSeek-Coder-V2-Instruct --disable-log-requests --tensor-parallel-size 8 --trust-remote-code --max-model-len 4096

## Run benchmark  
python3 -m sglang.bench_serving --backend sglang --num-prompts 5000  
python3 -m sglang.bench_serving --backend vllm --num-prompts 5000

# DeepSeekCoder-V2 (FP8)  
## Launch a server  
python3 -m sglang.launch_server --model neuralmagic/DeepSeek-Coder-V2-Instruct-FP8 --enable-mla --quantization fp8 --kv-cache-dtype fp8_e5m2 --disable-radix --tp 8 --trust-remote-code  
python3 -m vllm.entrypoints.openai.api_server --model neuralmagic/DeepSeek-Coder-V2-Instruct-FP8 --quantization fp8 --disable-log-requests --tensor-parallel-size 8 --trust-remote-code --max-model-len 4096

## Run benchmark  
python3 -m sglang.bench_serving --backend sglang --num-prompts 5000  
python3 -m sglang.bench_serving --backend vllm --num-prompts 5000  
```
