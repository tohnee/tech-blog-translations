# GLM-4.5 携手 SGLang：推理、编程与智能体能力

> 原文：[GLM-4.5 Meets SGLang: Reasoning, Coding, and Agentic Abilities](https://lmsys.org/blog/2025-07-31-glm4-5/) · LMSYS Blog · GLM Team

今天，我们很高兴地介绍我们最新的旗舰模型 [GLM-4.5](https://huggingface.co/zai-org/GLM-4.5) 和 [GLM-4.5-Air](https://huggingface.co/zai-org/GLM-4.5-Air)，以及它们的 FP8 版本。所有模型现已在 SGLang 上实现 Day-0 支持（首发日即可使用）。
GLM-4.5 与 GLM-4.5-Air 都是为统一推理、编程与智能体能力而打造的强大模型，总参数量分别为 **355B**（激活参数 **32B**）和 **106B**（激活参数 **12B**）。


## 使用 SGLang 部署 GLM-4.5

我们推荐使用 SGLang 部署 **GLM-4.5 系列**模型，以获得最佳性能。通过与 SGLang 社区的紧密合作，所有 GLM-4.5 模型从发布第一天起就在 SGLang 上获得了完整支持。

### 基本用法


**安装 SGLang**
```
pip install --upgrade pip
pip install "sglang[all]>=0.4.9.post6"
```

**355B 模型**
```
python3 -m sglang.launch_server --model zai-org/GLM-4.5 --tp 8
```
**106B 模型**
```
python3 -m sglang.launch_server --model zai-org/GLM-4.5-Air --tp 8
```
**355B FP8 量化模型**
```
python3 -m sglang.launch_server --model zai-org/GLM-4.5-FP8 --tp 8
```
**106B FP8 量化模型**
```
python3 -m sglang.launch_server --model zai-org/GLM-4.5-Air-FP8 --tp 4
```

### 工具调用
在命令后追加以下参数：
```
--tool-call-parser glm45 
```
### 推理解析器
在命令后追加以下参数：
```
--reasoning-parser glm45
```

### 结合 MTP 的投机解码
在命令后追加以下参数：
```
--speculative-algorithm EAGLE \
--speculative-num-steps [number of steps] \
--speculative-eagle-topk [top k] \
--speculative-num-draft-tokens [number of draft tokens]
```

## GLM-4.5 模型架构与亮点
**GLM-4.5** 采用专家混合（MoE）架构，结合无损均衡路由（loss-free balance routing）与 sigmoid 门控，提升了计算效率。与 DeepSeek-V3、Kimi K2 等模型相比，我们优先选择"深度"而非"宽度"——专家数量更少、隐藏维度更小，但层数更多——从而带来更好的推理性能。

**关键架构设计与亮点：**
* 采用部分 RoPE 的分组查询注意力（GQA）
* 在 5120 隐藏维度下使用 96 个注意力头（约为典型配置的 2.5 倍），在训练损失相近的情况下提升了 MMLU/BBH 上的推理表现
* 使用 QK-Norm 稳定注意力 logit
* 采用 Muon 优化器，实现更快收敛与更大批大小
* 用于投机解码的多 token 预测（MTP）头
* 强化学习（RL）训练由开源框架 [slime](https://github.com/THUDM/slime) 驱动，该框架此前已由 [THUDM](https://github.com/thudm) 开源。


### 性能表现
我们在 12 项基准测试上将 **GLM-4.5** 与来自 OpenAI、Anthropic、Google DeepMind、xAI、Alibaba、Moonshot 和 DeepSeek 的多款模型进行了对比，涵盖智能体（3 项）、推理（7 项）和编程（2 项）三类任务。总体来看，**GLM-4.5** 位列第 3 名，**GLM-4.5 Air** 位列第 6 名。

![基准测试概览](/images/blog/glm_4_5/benchmark-overview.png)


**智能体能力**
GLM-4.5 支持 128k 上下文和原生函数调用（function calling）。在 $\tau$-bench 和 BFCL-v3 两项基准上，它与 Claude 4 Sonnet 持平；在 BrowseComp 网页浏览基准上，它超过了 Claude 4 Opus（26.4% vs. 18.8%），并逼近 GPT o4-mini-high（28.3%）。其高达 90.6% 的工具调用成功率，凸显了它在智能体工作流中的可靠性。

**推理**
GLM-4.5 在数学与逻辑推理方面表现出色，在 MMLU Pro（84.6）、AIME-24（91.0）和 MATH500（98.2）上取得了具有竞争力的分数，并在 GPQA、LCB、AA-Index 等基准上展现出很强的泛化能力。

**编程**
GLM-4.5 展现出全面的全栈开发能力，在 SWE-bench Verified（64.2）和 Terminal-Bench（37.5）上位居顶尖模型之列。在正面对比评测中，它对 Kimi K2 的胜率达到 53.9%，对 Qwen3-Coder 的胜率达到 80.8%。其出色的智能体可靠性、多轮编程任务表现以及可视化界面质量，证明了它作为自主编程助手的实力。

## 结语
**GLM-4.5 系列**代表了新一波大语言模型浪潮，在长上下文推理、智能体工作流和编程任务上均有出色表现。其混合 MoE 架构——通过分组查询注意力、MTP、强化学习（RL）训练等技术得到增强——兼具高效率与强大能力。

**SGLang** 提供了生产级的高性能推理栈，凭借先进的内存管理与请求批处理，实现无缝部署。

**GLM-4.5** 与 **SGLang** 相结合，为下一代 AI 构筑了坚实的底座——支撑覆盖代码、文档与智能体的智能、可扩展解决方案。
