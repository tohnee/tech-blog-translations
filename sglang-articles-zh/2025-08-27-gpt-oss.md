# SGLang 支持 gpt-oss：从 Day-0 支持到性能全面增强

> 原文：[SGLang for gpt-oss: From Day 0 Support to Enhanced Performance](https://lmsys.org/blog/2025-08-27-gpt-oss/) · LMSYS Blog · Liangsheng Yin, Ke Bao

我们很高兴地宣布 SGLang 的一次重大更新，聚焦于对近期发布的 openai/gpt-oss-120b 模型的深度性能优化与新功能。**虽然我们在模型发布当天（day zero）就已提供支持，但我们利用过去几周时间持续增强引擎，确保你能获得尽可能好的性能。**

本文重点介绍我们最新的成果：gpt-oss 的显著性能提升——预填充吞吐量最高提升 **2.1 倍**、解码吞吐量最高提升 **2.25 倍**；开箱即用地支持 NVIDIA Blackwell 与 Hopper 以及 AMD MI350 GPU；支持投机解码；以及为复杂智能体（agentic）应用提供强化的 API——同时始终保持了模型的高精度。

所有改动现均已在我们的 main 分支上可用。

### SGLang 快速上手

```bash
pip install "sglang[all]>=0.5.1.post3"
python3 -m sglang.launch_server --model-path openai/gpt-oss-120b --tp 4
```

关于环境搭建以及如何获得最佳性能的详细说明，请参阅我们在 [awesome-sglang 中的指南](https://github.com/sgl-project/awesome-sglang/tree/main/gpt-oss)。

## 性能深度解析 🚀

我们的性能提升来自内核（kernel）层面的多项关键优化：

- **面向 Blackwell 的 FlashInfer 算子**：为了在 Blackwell GPU 上释放 gpt-oss 的巅峰性能，我们集成了来自 FlashInfer 的高度优化算子，在新硬件上加速多头注意力和专家混合（MoE）层等核心组件。
- **面向 Hopper 的 FlashAttention-3**：我们修改了 FlashAttention-3 算子以支持 attention sink，为 Hopper GPU 上的推理带来显著加速。
- **算子融合与削减**：我们进行了多项底层融合以减少开销，包括将 RMS 归一化与 all-reduce 融合、把写入 KV 缓冲区的操作合并进 RoPE、把 hidden states 填充融合进量化。我们还移除了不必要的算子、为部分算子启用了 [PDL](https://docs.nvidia.com/cuda/cuda-c-programming-guide/index.html#programmatic-dependent-launch-and-synchronization)，并降低了 CPU 开销，以进一步提升效率。

## 投机解码支持 🦅

**投机解码（Speculative Decoding）**是提升 LLM 推理性能的关键技术。[**EAGLE3**](https://arxiv.org/abs/2503.01840) 是当前最先进的投机解码方法，而 SGLang 是首个支持它的框架——这要归功于与 EAGLE 团队的紧密合作。

在 SGLang 中，你可以轻松地以 EAGLE3 投机解码启动 gpt-oss 模型：

```bash
# On Hopper:
# - Tree decoding (topk > 1) and chain decoding (topk = 1) are supported on both FA3 and Triton backends.
python3 -m sglang.launch_server --model openai/gpt-oss-120b --speculative-algorithm EAGLE3 --speculative-draft-model-path lmsys/EAGLE3-gpt-oss-120b-bf16 --speculative-num-steps 3 --speculative-eagle-topk 1 --speculative-num-draft-tokens 4 --tp 4
python3 -m sglang.launch_server --model openai/gpt-oss-120b --speculative-algorithm EAGLE3 --speculative-draft-model-path lmsys/EAGLE3-gpt-oss-120b-bf16 --speculative-num-steps 5 --speculative-eagle-topk 4 --speculative-num-draft-tokens 8 --tp 4

# On Blackwell:
# - Chain decoding (topk = 1) is supported on TRTLLM-MHA backend. Tree decoding (topk > 1) is in progress, stay tuned!
# - Both tree decoding (topk > 1) and chain decoding (topk = 1) are supported on the Triton backend.
python3 -m sglang.launch_server --model openai/gpt-oss-120b --speculative-algorithm EAGLE3 --speculative-draft lmsys/EAGLE3-gpt-oss-120b-bf16 --speculative-num-steps 3 --speculative-eagle-topk 1 --speculative-num-draft-tokens 4 --tp 4
python3 -m sglang.launch_server --model openai/gpt-oss-120b --speculative-algorithm EAGLE3 --speculative-draft lmsys/EAGLE3-gpt-oss-120b-bf16 --speculative-num-steps 5 --speculative-eagle-topk 4 --speculative-num-draft-tokens 8 --attention-backend triton --tp 4
```

针对 `openai/gpt-oss-120b` 模型，我们使用 [SpecForge](https://github.com/sgl-project/SpecForge)（一个高效的投机解码草稿模型训练框架）训练了 EAGLE3 草稿模型 [`lmsys/EAGLE3-gpt-oss-120b-bf16`](https://huggingface.co/lmsys/EAGLE3-gpt-oss-120b-bf16)。与 [NVIDIA 的 gpt-oss 草稿模型](https://huggingface.co/nvidia/gpt-oss-120b-Eagle3)相比，我们训练的草稿模型取得了更高的平均接受长度（average acceptance length）。

<img src="/images/blog/gpt_oss/accept_length.svg" style="display:block; margin-top: auto; margin-left: auto; margin-right: auto; margin-bottom: auto; width: 75%"></img>

我们还在 H200 TP4 上对启用 EAGLE3 的 `openai/gpt-oss-120b` 进行了基准测试，在多个标准基准数据集上都观察到了令人振奋的结果：

## 赋能智能体应用 🤖

为了更好地支持智能体（agentic）工作流，SGLang 提供了 [OpenAI Response API 支持](https://docs.sglang.io/basic_usage/gpt_oss.html#responses-api)和[原生 chat completion 支持](https://docs.sglang.io/advanced_features/tool_parser.html)。下面的示例展示如何用 SGLang 构建一个简单的网页搜索智能体（内置工具需要 `python3.12` 和 `gpt-oss` 包，更多配置细节见[此处](https://docs.sglang.io/basic_usage/gpt_oss.html#responses-api)）。

启动服务器：

```bash
export EXA_API_KEY=YOUR_EXA_KEY
python3 -m sglang.launch_server --port 30000 --model-path openai/gpt-oss-120b --tp 4 --tool-server demo 
```

使用 Response API 构建网页搜索智能体：

```python
import openai

client = openai.OpenAI(
    base_url="http://localhost:30000/v1",
    api_key="EMPTY"
)
response = client.responses.create(
    model="openai/gpt-oss-120b",
    tools=[{"type": "web_search_preview"}],
    input="What does SGLang update today?"
)

print(response.output_text)
```
