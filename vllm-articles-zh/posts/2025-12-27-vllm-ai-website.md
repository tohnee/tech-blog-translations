# vllm.ai 官网发布与多项社区更新

> 原文：[Announcing vllm.ai Website and Some Community Updates](https://vllm.ai/blog/2025-12-27-vllm-ai-website) · vLLM 博客

vLLM 团队

[#社区](https://vllm.ai/blog/tags/community)

很长一段时间里，[vllm.ai](https://vllm.ai) 只是重定向到 [vLLM GitHub 页面](https://github.com/vllm-project/vllm)。得益于我们的社区，我们如今拥有了一个全新的 [vllm.ai](https://vllm.ai) 网站，其设计灵感来自 [PyTorch 网站](https://pytorch.org)。

![](https://vllm.ai/blog-assets/figures/2025-vllm-website/homepage.jpg)

新网站提供安装选择器，引导用户在各种环境中安装 vLLM。

![](https://vllm.ai/blog-assets/figures/2025-vllm-website/install.jpg)

网站还包含一个「活动（Events）」页面，用于追踪所有社区活动与后勤安排的更新。

![](https://vllm.ai/blog-assets/figures/2025-vllm-website/events.jpg)

## 为什么要建新网站？

这次改动的动机很明确：我们需要把社区活动与后勤安排的更新维护从 GitHub 项目中分离出来。此前，几乎所有关于 vLLM 的信息都托管在 GitHub 上，活动公告和聚会幻灯片通过 pull request 添加。这一流程给希望专注代码开发的开发者带来了不必要的负担。

接下来，我们将把大部分社区活动和后勤安排更新从 GitHub 项目迁移到 vLLM 网站，让 GitHub 项目能够更专注于代码开发。

一个潜在的缺点是，大家无法像现在这样通过提交 pull request 来请求修改。为解决这一问题，我们新建了联系邮箱 **[website-feedback@vllm.ai](mailto:website-feedback@vllm.ai)**。如果你对改进网站有任何建议，请发邮件至该地址，我们会审阅并相应更新。

## 新的社区沟通邮箱

除新网站外，我们还增设了几个用于社区沟通的邮箱：

- **[talentpool@vllm.ai](mailto:talentpool@vllm.ai)** - 提交简历以申请实习和全职职位。我们会将简历转发给合作公司，为你提供更多曝光机会。LLM 推理人才需求旺盛，我们的合作公司渴望招揽优秀的工程师。
- **[collaboration@vllm.ai](mailto:collaboration@vllm.ai)** - 供有意获取简历、组织聚会或开展技术合作的伙伴公司使用。我们乐于与任何希望在产品或服务中使用 vLLM 的公司合作。该邮箱将逐步取代 [vllm-questions@lists.berkeley.edu](mailto:vllm-questions@lists.berkeley.edu) 的现有功能。
- **[social-promotion@vllm.ai](mailto:social-promotion@vllm.ai)** - 用于社交媒体推广合作（Twitter/X、LinkedIn、小红书、微信等）。如果你有任何关于 vLLM 的有趣内容想分享，请发邮件至该地址，我们会审阅并加以推广。

## 新的社区工具

为帮助社区了解 vLLM 的最新进展，我们创建了一个名为 [vLLM Daily](https://github.com/vllm-project/vllm-daily) 的新仓库。它每天汇总 vLLM 的变更。你可以将 <https://github.com/vllm-project/vllm-daily/commits/main.atom> 添加到你喜爱的 RSS 阅读器来订阅更新。

## 结语

从一个研究项目成长为被广泛使用的生产级推理引擎，vLLM 能有今天，离不开社区的鼎力支持。我们期待与大家一起继续构建 LLM 推理的未来！
