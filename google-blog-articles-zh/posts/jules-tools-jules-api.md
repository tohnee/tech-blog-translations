# 用 Jules——我们的 AI 编程智能体——构建的新方式

> 原文：[New ways to build with Jules, our AI coding agent](https://blog.google/innovation-and-ai/models-and-research/google-labs/jules-tools-jules-api/) · Google

我们正在扩展可以使用 [Jules](https://jules.google/)——Google 的 AI 驱动编程智能体——的场景和方式，为你带来更多掌控力与灵活性。Jules 通过协助软件开发工作流中的各类任务，帮助开发者更快地从想法走向可运行的代码：生成代码、修复 bug、编写测试、提升性能等等。Jules 的设计定位像一个协作者，在你构建项目的过程中与你并肩工作。

今天，我们推出 Jules Tools——我们全新的轻量级命令行界面，并提前分享 Jules API 的早期预览，它将让你能够把 Jules 直接集成到自己的系统和工作流中。

### Jules Tools

[Jules Tools](https://developers.googleblog.com/en/meet-jules-tools-a-command-line-companion-for-googles-async-coding-agent) 是我们全新的命令行界面，让你把 Jules 直接带入终端，在你自己的命令旁边启动、停止和验证任务。这是从在聊天中与 Jules 对话，到在你实际工作流中与它并肩运行的最简单方式。

### Jules API

本周，我们将开放 Jules API 的使用，让你可以把 Jules 集成到自己的系统和工作流中。你可以在 Slack 中提交 bug 时触发任务，把 Jules 接入你的 CI/CD 流水线，并扩展到任何你希望 Jules 出现的新场景。这个 API 让 Jules 更贴近你已有的构建方式。

这些发布关乎掌控力与灵活性——这是我们反复听到你们提出的两点诉求。Jules Tools 和 API 为你提供了更多让 Jules 融入工作流的方式，而近期的工作则让它在你需要时可靠运行。

## 更多新更新

过去几周，我们一直埋头改进 Jules 的可靠性和质量。我们在降低延迟方面取得了进展，并修复了一些最常见的环境设置和文件系统问题。这些发布为接下来的工作打下了基础。我们已经推出：

- **文件选择器（File selector）：** 在聊天中点名特定文件，收紧上下文。
- **记忆（Memory）：** Jules 现在会随着时间记住你的偏好，并自动将其应用到未来的任务中。
- **环境变量管理：** 一种结构化的方式，可在任务执行期间授予 Jules 访问环境变量的权限。

### 开始使用

与智能体一起编程的未来并非抽象概念。它正在发生，而且正与你一同发生。从 [Jules 更新日志](https://jules.google/docs/changelog)了解所有这些更新及更多内容的使用指引，开始构建，并在 [Discord](https://discord.gg/googlelabs) 上与我们分享你的作品。
