# 我们如何在 Google 测试 Project Starline

> 原文：[How we're testing Project Starline at Google](https://blog.google/innovation-and-ai/technology/research/how-were-testing-project-starline-google/) · Google

在 2021 年 5 月的 Google I/O 大会上，[我们分享了 Project Starline 的愿景](https://g.co/projectstarline)——这是一个将硬件与软件领域的进步结合起来的技术项目，让朋友、家人和同事即使相隔城市（甚至国家），也能感觉彼此相聚在一起。

Project Starline 是我们在 3D 成像、实时压缩、空间音频以及突破性的光场显示系统等方面所取得进展的集大成之作——这些技术结合在一起，营造出一种如同面对面交流般的纵深感与真实感。我们最近在一篇技术论文 [Project Starline: A high-fidelity telepresence system](https://research.google/pubs/pub50903/) 中描述了其中的一些进展，该论文很荣幸地被 SIGGRAPH Asia 接收发表。

随着我们开始在美国更多的 Google 办公室推广 Project Starline，积极反馈令我们备受鼓舞。Google 员工已经花了数千小时使用 Project Starline 来入职培训、面试、认识新队友、向同事推介想法以及进行一对一协作。许多用户提到，能够进行眼神交流的能力是多么强大，以及他们因此感到多么投入、多么有联结感。一位用户把这种体验比作一次咖啡闲谈——一种让你想要倾身向前、专注于对方的真实互动。

我们测量了数百名 Google 员工使用 Project Starline 的体验所产生的影响，结果表明，与传统的视频通话相比，它带来的感觉更接近于与对方共处一室。我们观察到一些在视频通话中最容易丢失的重要信号有所增加，例如专注度、记忆回忆和整体临场感。以下是我们将 Project Starline 与传统视频通话进行对比后的发现：

- 人们表现出更多的非语言行为，例如手部动作增加约 40%、点头增加约 25%、眉毛动作增加约 50%。
- 使用 Project Starline 时，人们的记忆回忆能力明显更好，在被要求回忆对话细节或会议内容时，表现要好出近 30%。
- 在一项眼动追踪实验中，人们对会议对象多聚焦了约 15%，这表明使用 Project Starline 时视觉专注度得到了增强。

![人们平均多聚焦 15% 在会议对象身上](https://storage.googleapis.com/gweb-uniblog-publish-prod/original_images/Blog_15__Project_Starline_MeetingPartner.gif)

这些早期结果表明，Project Starline 有望促进异地之间更紧密的人际连接。随着 Google 以及更多公司探索工作的未来，我们对在现代职场中深化员工之间联结与协作的潜力持乐观态度。我们期待继续扩展 Project Starline，并分享更多进展。
