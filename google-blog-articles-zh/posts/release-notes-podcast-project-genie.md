# 在我们最新的播客中了解更多关于交互式世界模型的内容

> 原文：[Hear more about interactive world models in our latest podcast.](https://blog.google/innovation-and-ai/technology/ai/release-notes-podcast-project-genie/) · Google

Google AI: Release Notes 播客最新一期聚焦 Genie 3——一个实时、交互式的世界模型。主持人 Logan Kilpatrick 与 [Project Genie](https://blog.google/innovation-and-ai/models-and-research/google-deepmind/project-genie/) 团队的 Diego Rivas、Shlomi Fruchter 和 Jack Parker-Holder 畅谈了从被动视频生成到可玩的模拟环境的演进历程。

他们深入探讨了维持世界一致性与记忆的技术挑战、「走进」一幅 2D 图像的体验，以及将世界模型作为未来 AI 智能体关键训练场的愿景。

在下方观看本期节目，或在 [Apple Podcasts](https://podcasts.apple.com/us/podcast/google-ai-release-notes/id1783661110) 或 [Spotify](https://open.spotify.com/show/1ZEwpdbarrLDlkeAfoHjtj) 上收听播客。
