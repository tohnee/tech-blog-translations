# 用这 4 个技巧在 Project Genie 中创造新世界

> 原文：[Create new worlds in Project Genie with these 4 tips](https://blog.google/innovation-and-ai/models-and-research/google-deepmind/tips-prompt-writing-project-genie/) · Google

我们[最近推出了 Project Genie](https://blog.google/innovation-and-ai/models-and-research/google-deepmind/project-genie/)，这是一个实验性研究原型，让你可以创建、探索和混搭（remix）属于自己的交互式世界。借助 Project Genie，你可以构建有角色和环境的世界，然后实时在其中穿行，比如前往一颗想象中的新星球，或者与海洋生物一同潜入水下。Project Genie 目前面向美国 18 岁以上的 Google AI Ultra 订阅用户开放，并计划进一步扩展。

你可以仅用文本提示 Project Genie，也可以结合文本和图像。如果你已经准备好让自己的想象世界成真，这里有一些关于提示词写作（prompt writing）的技巧，以及值得尝试的功能。

## 1. 详细描述环境

先写下你想要什么样的环境——例如，你可以选择森林、城市、月球……你懂的。细节要具体：森林是葱郁的还是冬日的？城市可以是喧嚣的，也可以是空无一人的。也许月球是奶酪做的！还可以添加任何你想要的结构或物体，以及天气细节，比如风或雪。再想想你想让这个世界给人什么感觉；它当然可以照片般逼真，看起来就像你身边的世界，也可以像卡通或电子游戏。

## 2. 选择一个角色

角色是你穿梭世界的载体，它可以是任何东西，从一只小小的蓝色长颈鹿到一个巨大的像素化玩偶。你可以添加细节，比如它如何移动（也许它会飞、靠轮子滚动，或者倒着跑），以及它有什么样的效果——也许每次它向前一跳，身后就会跟出一缕烟。

## 3. 用自己的图像创造世界

除了从纯文本开始创建环境，你也可以从自己的图像出发。上传你的图像，并添加任何其他定义环境的细节（比如你想让画面显得阴沉而风雨交加，还是像由黏糊糊的物质构成）。请务必使用角色位于画面中央、且有足够背景可见以定义环境的图像。

## 4. 使用直接、面向动作的语言，并用感官细节营造氛围

提示 Project Genie 时，简短的陈述句效果最好。例如，文本提示可以是「an underwater scene with lots of coral」（一个有许多珊瑚的水下场景），你的角色可以是一条金鱼。需要帮助撰写这类提示词吗？你随时可以使用 Gemini 应用来协助改写或调整。Project Genie 还会使用 Nano Banana Pro 为你展示世界和角色的预览，让你在真正开始探索之前看到它们的样子以及导航的效果。如果你想调整，可以在开始探索前修改提示词并进行实时微调。

## 5. 尝试在第一人称和第三人称视角之间切换

创建好环境和角色之后，你就可以决定如何探索这一切。你可以通过角色的眼睛来导航（第一人称视角），也可以从上方观察角色（第三人称视角）。只需选择视角按钮，即可在游览你的世界时选择你想要的视点。
