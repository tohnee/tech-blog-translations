# Project Starline：仿佛就在彼此身边

> 原文：[Project Starline: Feel like you're there, together](https://blog.google/innovation-and-ai/technology/research/project-starline/) · Google

人们喜欢相聚在一起——分享、协作、联结。而在过去这一年，出行受限、远程办公增多，"在一起"从未显得如此重要。

多年来，我们打造了许多产品来帮助人们感到彼此更紧密相连。我们用 Gmail 简化了电子邮件，用 Google Photos 让分享重要瞬间变得更容易，用 Google Meet 提升协作效率。尽管这些及其他通信工具多年来不断进步，但它们与真正坐下来面对面交谈相比，仍相去甚远。

我们把这一直视为一个重要且尚未解决的问题。我们问自己：能否用技术创造出与某人共处的感觉，就像对方真的在你面前？

为了迎接这一挑战，我们多年来一直在开发 Project Starline——这是一个将硬件与软件领域的进步结合起来的技术项目，让朋友、家人和同事即使相隔城市（甚至国家），也能感觉彼此相聚在一起。

想象一下，透过一扇某种意义上的魔法之窗，你看到另一个人，与真人同等大小、以三维形式呈现。你可以自然地交谈、打手势、进行眼神交流。

为了让这种体验成为可能，我们应用了计算机视觉、机器学习、空间音频和实时压缩方面的研究成果。我们还开发了一套突破性的光场显示系统，它能营造出体积感与纵深感，而无需佩戴任何额外的眼镜或头戴设备。

其效果，就是感觉一个人就坐在你对面，仿佛他真的就在那里。

关键突破包括 3D 成像、实时压缩和 3D 显示。

最令我们自豪的一点是：一旦你坐下来开始交谈，技术便隐入背景，你可以专注于最重要的事情——眼前的那个人。

Project Starline 目前仅在我们的少数几个办公室可用，而且它依赖定制硬件和高度专业化的设备。我们相信，这正是人与人之间通信技术能够且应当前进的方向。我们的目标是假以时日让这项技术更便宜、更易得，包括把其中一些技术进步融入我们的通信产品套件。

Project Starline 正在我们的一间 Google 办公室中使用。

![一位男士坐着使用 Project Starline。](https://storage.googleapis.com/gweb-uniblog-publish-prod/images/Booth_Blog.width-1200.format-webp.webp)

为了开启这段旅程，我们已经在 Google 内部花了数千小时测试 Project Starline，连接湾区、纽约和西雅图之间的同事。我们也在医疗健康和媒体等领域与精选的企业合作伙伴进行演示，以获取关于这项技术及其应用的早期反馈。我们计划在今年晚些时候与企业合作伙伴开展试部署。

我们对 Project Starline 的进展以及这项技术的潜力感到非常兴奋——它有望解决"想在物理上无法相聚时依然彼此相伴"这一重要问题。我们期待在今年晚些时候分享更多信息。
