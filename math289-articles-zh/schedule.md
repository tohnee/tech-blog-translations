## 暂定大纲

1. **编程基础**（第 2 周）
   - 终端/shell/IDE/服务器
   - Python、pip/uv（虚拟环境）
   - NumPy / PyTorch
   - Git/GitHub
   - 如何用编程智能体写代码
   - 安全
   - Hugging Face Transformers 库
   - Weights & Biases（Modal）
   - 沙箱、权限、配置
2. **深度学习**
   - 神经网络
   - 优化器
3. **LLM 架构**
   - 分词器（Tokenizer）
   - 嵌入（Embedding）
   - 注意力 + MLP 层
   - MoE
   - 解码器/采样
4. **思维链推理 + o1/R1 论文精神**
   - 强化学习（RL）
5. **智能体**
   - 提示词/上下文工程
   - 智能体工程
   - 编程智能体
     - 技能
     - 智能体记忆
6. **形式化/Lean 基础**
   - Lean 速成课 + 内核
7. **实践层面**
   - GPU（显存、FLOPs）
   - 成本估算
     - API 开销
     - GPU 成本
     - 如何估算某项任务的成本
   - Roofline 模型
