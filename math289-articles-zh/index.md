# MATH 289：变化世界中的数学实践

一门面向在读数学博士研究生的课程，主题是面向数学研究的 AI（AI for Mathematical Research）。

讲课时间
:   周一、周三，上午 10:30–11:50

地点
:   Sloan Hall（380 号楼），380W 教室

学分
:   3 学分

## 最新消息

- 请确认你已加入课程 Slack 和 GitHub 组织。所有通知与讨论都将通过 Slack 进行。

## 关于本课程

这是一门面向在读数学博士研究生的研讨课。课程将带领大家了解在快速演变的研究环境中前行所需的各类工具。不要求任何编程或 AI 基础。

**选课**：需获许可。请发邮件给主讲教师申请许可。可重复修读以获得学分。

**注意**：本课程不向本科生或硕士生开放。
