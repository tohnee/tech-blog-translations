## 一、提示词工程与提示词评估

提示词工程（Prompt Engineering）是用于设计高质量提示词的一套方法与实践，其目标是让模型更加准确地理解任务要求，并按照预期的方式生成结果。常见的方法包括多示例提示、使用 XML 标签组织提示词结构、明确角色与任务要求，以及约束模型的输出格式等。

提示词评估（Prompt Evaluation）关注的则是另一个问题，即一个 Prompt 的实际效果究竟如何。它并不直接研究“如何编写 Prompt”，而是通过构建测试样例和评价标准，对 Prompt 的输出结果进行系统化测试，从而判断其可靠性、稳定性以及是否满足预期要求。

通过提示词评估，我们可以根据预期结果测试模型输出，检查输出中是否存在错误，同时还可以对同一个 Prompt 的不同版本进行比较，从而判断修改后的 Prompt 是否真正取得了效果。

在实际应用中，仅仅运行一两次 Prompt 并观察结果通常是不够的。一个 Prompt 在少量测试样例上表现正常，并不意味着它在面对真实用户产生的大量不同输入时仍然能够稳定工作。真实环境中的输入通常更加复杂，也可能包含开发阶段没有考虑到的边界情况。

因此，更可靠的方法是将 Prompt 放入一个完整的评估流水线（Evaluation Pipeline）中，通过一组具有代表性的测试数据对其进行统一测试和评分。这样可以获得 Prompt 在不同测试案例下的客观指标，并利用这些指标分析 Prompt 当前存在的问题。

这种数据驱动的评估方式能够帮助我们在进入生产环境之前发现 Prompt 的薄弱环节，同时也能够更加客观地比较不同版本 Prompt 的效果。开发者可以根据量化后的评估结果不断调整 Prompt，并再次执行测试，从而形成持续迭代的优化过程。虽然建立评估流程需要额外投入一定的时间和测试成本，但这些工作能够显著提升最终 AI 应用的可靠性（Reliability）和鲁棒性（Robustness）。

本文主要使用 OpenAI SDK 的 Chat Completions API 访问模型，并使用兼容 OpenAI 接口的模型服务作为实验环境。首先完成客户端、模型以及环境变量等基础配置：

```python
import os
import re
import ast
import json
from openai import OpenAI
from dotenv import load_dotenv

load_dotenv()
API_KEY = os.getenv("MY_ALI_API_KEY")
BASE_URL = os.getenv("MY_ALI_BASE_URL")
MODEL_ID = "qwen3.7-plus"

client = OpenAI(api_key=API_KEY, base_url=BASE_URL)

```

为了方便后续构建多轮对话消息以及统一模型调用方式，本文进一步定义了一组辅助函数。其中， `add_user_message` 、 `add_assistant_message` 和 `add_system_prompt` 分别负责向消息列表中添加不同角色的消息，而 `chat` 函数则用于封装 Chat Completions API 的具体调用过程。

```python
def add_user_message(messages, text):
    user_message = {"role": "user", "content": text}
    messages.append(user_message)

def add_assistant_message(messages, text):
    assistant_message = {"role": "assistant", "content": text}
    messages.append(assistant_message)

def add_system_prompt(messages, text):
    system_prompt = {"role": "system", "content": text}
    messages.append(system_prompt)

def chat(messages, temperature=1.0):
    params = {
        "model": MODEL_ID,
        "max_tokens": 1024,
        "messages": messages,
        "temperature": temperature,
    }

    completion = client.chat.completions.create(**params)
    return completion.choices[0].message.content
```

## 二、一个典型的提示词评估工作流

一个典型的提示词评估工作流通常包含五个关键步骤，通过客观的测量结果，帮助我们系统地改进 Prompt。虽然实际应用中可以采用很多不同方式来构建评估流程，也有各种开源或商业化工具可供选择，但理解最核心的评估过程非常重要。这样我们可以先从一个简单的流程开始，再根据实际需求逐步扩展。

一个基本的 Prompt Evaluation Workflow 可以概括为：

编写 Prompt → 构建评估数据集 → 运行 Prompt → 使用评分器评估结果 → 修改 Prompt 并重复上述过程。

### 1. 编写 Prompt

第一步是编写一个希望进一步改进的初始 Prompt。例如，可以先从一个非常简单的 Prompt 开始：

```python
prompt = f"""
Please answer the user's question:

{question}
"""
```

这个 Prompt 只是要求模型回答用户的问题，但此时我们并不知道它是否足够有效。仅仅从 Prompt 本身很难判断其真实表现，因此需要通过后续的评估流程，使用更加客观的方法进行验证。

### 2. 构建评估数据集

第二步是创建评估数据集（Eval Dataset）。评估数据集中包含一组具有代表性的输入，这些输入应尽可能模拟 Prompt 在真实生产环境中可能遇到的问题或请求。随后，这些测试输入会被填充到 Prompt 模板中，并用于测试模型的实际表现。

例如，在一个简单的测试场景中，评估数据集可以包含下面三个问题：

- “2 + 2 等于多少？”
- “燕麦粥应该怎么做？”
- “月球距离地球有多远？”

在真实的评估任务中，数据集通常不会只有几个样例，而可能包含几十、几百甚至数千条测试数据。这些数据既可以由开发者手动构建，也可以借助大语言模型自动生成，从而覆盖更多不同类型的输入和边界情况。

### 3. 将测试数据输入模型

第三步是将评估数据集中的每一条输入与 Prompt 模板结合，生成完整的模型输入，然后依次发送给模型并保存输出结果。

例如，对于第一个测试问题：

```text
Please answer the user's question:

What's 2+2?
```

模型可能回答：

```text
2 + 2 = 4
```

对于另外两个问题，模型则可能分别生成燕麦粥的制作方法，以及月球与地球之间距离的相关回答。通过这一过程，我们就可以得到当前 Prompt 在整个评估数据集上的一组输出结果。

### 4. 使用评分器进行评估

得到模型输出之后，下一步需要使用评分器（Grader）对这些结果进行评价。评分器通常会同时检查原始问题和模型生成的回答，并根据预先定义好的评价标准给出一个分数，从而将原本较为主观的输出质量转化为可以量化的指标。

例如，可以采用 1～10 分的评分方式，其中 10 分表示回答非常理想，而较低的分数则表示该回答仍然存在明显的改进空间。

在上述三个测试问题中，评分器可能给出如下结果：

- 数学问题：10 分，回答完全正确
- 燕麦粥问题：4 分，回答过于简单，需要进一步改进
- 月球距离问题：9 分，回答质量较高

这样就可以通过平均分得到当前 Prompt 的整体评估结果：

```text
(10 + 4 + 9) / 3 = 7.66
```

因此，当前 Prompt 的平均得分为 **7.66** 。相比单纯观察几个模型输出，这种量化方式可以更加直观地衡量 Prompt 的整体表现，同时也能够帮助我们快速定位表现较差的测试案例。

### 5. 修改 Prompt 并重复评估

完成评分之后，就可以根据评估结果分析当前 Prompt 存在的问题，并针对得分较低的测试案例进行修改。例如，如果发现模型经常给出过于简略的回答，就可以在 Prompt 中进一步明确回答的详细程度、格式要求或内容约束。

修改完成后，再使用同一套评估数据重新运行测试并计算新的得分。如果新版本 Prompt 的整体评分有所提高，就说明当前修改是有效的。通过不断重复“测试—评分—修改”的过程，可以逐步提升 Prompt 在不同输入情况下的稳定性和可靠性。

## 三、提示词评估实践

### 1. 提示词生成

在实际进行提示词评估之前，首先需要准备一组测试数据。评估数据集的作用是模拟 Prompt 在真实使用过程中可能遇到的不同输入，并为后续评分提供统一的测试基础。

本文使用大模型自动生成评估数据集，任务主要覆盖 Python、JSON 和正则表达式（Regex）三种输出类型。每条测试数据都包含任务描述、预期输出格式以及对应的解决方案评判标准。

```python
def generate_dataset():
    prompt = """
    为提示词评估生成一个评估数据集。该数据集将用于评估那些生成 Python、JSON 或正则表达式（Regex）的提示词。请生成一个 JSON 对象数组，其中每个对象表示一个需要通过 Python、JSON 或正则表达式完成的任务。
    示例输出：

    [
        {
            "task": "任务描述",
            "format": "json 或 python 或 regex",
            "solution_criteria": "解决方案应满足的标准描述"
        }
    ]

    要求：
    *任务应当是通用的软件开发或数据处理任务，不依赖特定云平台、框架或第三方服务。
    *每个任务应能够通过一个 Python 函数、一个 JSON 对象或一个正则表达式完成。
    *避免需要大量代码或复杂项目结构的任务。
    *任务应具有明确、可验证的正确答案。

    请生成 3 个对象。
    """
    messages = []
    add_user_message(messages, prompt)
    text = chat(messages, temperature=0.5)
    return json.loads(text)

dataset = generate_dataset()
print(dataset)
```

随后调用该函数生成数据集，并将结果保存到本地文件中，方便后续重复执行评估时使用相同的数据。

```python
with open('dataset.json', 'w') as f:
    json.dump(dataset, f, indent=2)
```

### 2. 评估方式

对于 Prompt 的输出结果，通常可以采用三种方式进行评估：人工审查、基于模型的评估以及基于代码的评估。

人工审查最直观，但难以大规模自动化；基于代码的评估具有较高确定性，但适用范围有限；基于模型的评估则具有更强的灵活性，可以对语义正确性、完整性和质量进行综合判断。因此，为了构建自动化评估流程，本文主要结合代码评估与模型评估两种方式。

首先使用代码进行基础语法检查。对于 JSON，可以直接尝试解析；对于 Python，可以使用抽象语法树进行语法分析；对于正则表达式，则可以尝试进行编译。

```python
def validate_json(text):
    try:
        json.loads(text.strip())
        return 10
    except json.JSONDecodeError:
        return 0

def validate_python(text):
    try:
        ast.parse(text.strip())
        return 10
    except SyntaxError:
        return 0

def validate_regex(text):
    try:
        re.compile(text.strip())
        return 10
    except re.error:
        return 0
```

随后根据测试样例要求的输出格式，统一调用对应的检查函数。

```python
def grade_syntax(response, text_case):
    format = text_case["format"]
    if format == "python":
        return validate_python(response)
    elif format == "json":
        return validate_json(response)
    elif format == "regex":
        return validate_regex(response)
    else:
        return 0
```

基于代码的评估速度快、结果稳定，非常适合检查语法是否合法，但它只能判断“格式是否正确”，无法充分判断模型生成的内容是否真正完成了任务。

因此，还需要使用大语言模型进一步进行语义层面的评价。本文通过构建一个专门的评估 Prompt，让模型根据原始任务、输出结果和评判标准对结果进行打分。

```python
def grade_by_model(test_case, output):
    eval_prompt = f"""
    你是一名专业的代码审查专家。你的任务是评估下面这个由 AI 生成的 Python、JSON 或正则表达式（Regex）解决方案。

    原始任务：
    <task>
    {test_case["task"]}
    </task>

    要求的输出格式：
    <format>
    {test_case["format"]}
    </format>

    待评估的解决方案：
    <solution>
    {output}
    </solution>

    解决方案评判标准：
    <criteria>
    {test_case["solution_criteria"]}
    </criteria>

    输出格式：
    请按照以下字段和固定顺序，返回一个结构化 JSON 对象：

    - "strengths"：数组，包含 1-3 个该解决方案的主要优点
    - "weaknesses"：数组，包含 1-3 个需要改进的地方
    - "reasoning"：对整体评估结果的简明说明
    - "score": 1 到 10 之间的数字

    评估时请重点检查：

    - 解决方案是否正确完成了原始任务
    - 是否满足给定的解决方案评判标准
    - 输出是否符合要求的格式，即 Python、JSON 或 Regex
    - 综合考虑正确性、完整性、简洁性和健壮性
    - 如果解决方案在功能上是正确的，不要因为代码风格或表达方式不同而扣分

    只返回合法的 JSON，不要输出其他任何内容。回答应简洁、直接。

    示例返回格式：

    {{
        "strengths": ["优点1", "优点2"],
        "weaknesses": ["不足1"],
        "reasoning": "对该解决方案整体表现的简要评价。",
        "score": 8
    }}

    注意：你的回答将被直接传入 json.loads() 进行解析，因此不要包含 Markdown 代码块、注释、解释性文字或 JSON 对象之外的任何内容。
    """
    messages = []
    add_user_message(messages, eval_prompt)
    eval_text = chat(messages)
    return json.loads(eval_text)
```

### 3. 完整评估流程

完成数据集和评分器之后，就可以将各个步骤组合成完整的评估流程。对于每个测试样例，首先调用待测试 Prompt 得到模型输出，然后分别计算模型评分和语法评分，最后将两部分得分组合得到最终结果。

```python
def run_test_case(test_case):
    out_put = run_prompt(test_case)
    model_grade = grade_by_model(test_case, out_put)
    model_score = model_grade["score"]
    reasoning = model_grade["reasoning"]

    syntax_score = grade_syntax(out_put, test_case)
    score = (model_score + syntax_score) / 2

    return {
        "output": out_put,
        "test_case": test_case,
        "score": score,
        "reasoning": reasoning
    }
```

在此基础上，可以进一步遍历整个评估数据集，并计算所有测试样例的平均得分。

```python
def run_eval(dataset):
    results = []
    for test_case in dataset:
        results.append(run_test_case(test_case))
    
    average_score = sum([result["score"] for result in results]) / len(results)
    print("Average score: ", average_score)
    return results
```

最后从本地加载之前生成的数据集并执行完整评估：

```python
with open('dataset.json', 'r') as f:
    dataset = json.load(f)

```

## 四、总结

提示词评估通过构建测试数据、运行 Prompt 并对输出进行评分，帮助我们客观判断 Prompt 的实际效果。相比简单的人工试验，自动化评估能够更稳定地发现问题，并支持不同版本之间的比较。本文结合代码评估与模型评估，从语法合法性和语义正确性两个方面对输出进行检查，并通过持续的测试、评分与优化不断改进 Prompt，从而提升其可靠性。
