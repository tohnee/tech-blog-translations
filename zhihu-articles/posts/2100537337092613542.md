vLLM Semantic Router 项目开源了 Vela 3.0，覆盖**0.3B–27B 六款模型**，将请求决策、文本片段提取和视觉定位接入统一接口。对于一条客服请求，模型既可以判断客户想退款还是取消订单，也可以找出需要打码的姓名、电话和银行卡号。<br><br>与通过提示词让大模型生成答案不同，Vela 的核心输出是选项概率、原文片段及位置，便于直接用于路由、信息提取和内容核验。其中，380M 参数的 vela3-fast 面向低延迟文本处理，d3 系列扩展多语言与更复杂的文本任务，fast-vision 则支持结合图片进行判断和定位。

**从客服工单到 RAG 核验，一次调用能做什么**

Vela 的统一接口是 system_one(state, questions) 。<br><br>state 是待处理的内容，可以是一段文本，也可以是分别命名的用户请求、参考资料和模型回答；视觉模型还可以接收图片。<br><br>questions 则指定需要回答的问题：判断意图、评估紧急程度、提取个人信息，或者定位图片中的对象。<br><br>不同问题返回不同形式的结果。决策问题返回选项概率，片段问题返回原文内容、字符位置和分数，视觉定位问题返回区域框、中心点和置信度。一个接口调用可以包含多个问题，但不同问题可能进入不同网络路径，并不意味着全部任务只进行一次前向计算。<br><br>以下案例记录使用已发布的模型包，在 AMD Instinct MI300X 上进行单次调用，展示了具体输入下的模型输出：

### 客服工单：判断意图，同时找出隐私信息

一封客服邮件中，客户说明订单被重复扣款，希望当天退款，并附上姓名、邮箱、电话、银行卡号和账单地址。<br><br>vela3-fast 将退款意图的概率判为 0.97，需要尽快响应的概率判为 0.62，同时圈出上述五类个人信息。业务系统可以根据意图选择处理流程，根据紧急程度设置优先级，并在将邮件转交后续模型之前完成隐私打码。<br><br>客服工单的判断与提取结果：

![](https://pic1.zhimg.com/v2-fa765421b6b55d02fb0f191c0b3f7eea_r.jpg)

### RAG 回答核验：找出缺少依据的内容，也找出对应证据

参考资料写明服务时间为“周一至周六”，模型回答却将其表述为“一周七天”。<br><br>vela3-fast 在回答中标出缺少依据的片段，同时从参考资料中抽取相关证据。与只给出“回答可能有幻觉”的整体判断相比，这种输出能直接指出需要检查的文字，并提供核对依据。<br><br>回答中的无依据片段与参考资料中的证据：

![](https://pic1.zhimg.com/v2-1c203867fe23becacabf18aaf049d842_r.jpg)

### 中文工单：英文问题和标签，也能处理中文输入

在中文退款工单中，vela3-lite 使用英文问题和标签，完成意图判断、紧急程度判断，以及姓名、电话和订单号提取。<br><br>示例中，退款概率为 0.97，需要尽快响应的概率为 0.94，姓名、电话号码和订单号 A2391被提取出来。这里展示的是 lite 的跨语言处理能力，不应将其归为面向英语的 fast 型号。<br><br>中文工单的模型输出：

![](https://pica.zhimg.com/v2-4b33a187629e0d6904cb89f1081a0ca2_r.jpg)

### 收据核验：结合原图检查已有 OCR 结果

视觉模型的用途不只是在图片中找对象，还可以检查已有文本是否与图片一致。<br><br>示例同时输入收据原图和 OCR 字段：OCR 将金额写成 28.04，而图片中的金额是 28.40。fast-vision 将该字段标为 OCR 错误，分数为 0.97。这一流程是对已有 OCR 结果进行核验，而不是完整的收据识别或自动修正演示。<br><br>收据原图与 OCR 错误字段：

**决策与片段提取，如何放进一个模型体系**

Vela 3.0 并不是把所有任务混入同一条推理路径，而是以统一接口组织不同能力。普通决策使用基础模型的决策路径；路由信号、实体、关系、证据和无依据片段等任务，则根据问题类型、措辞和标签集合选择相应适配器。<br><br>问题如何进入不同处理路径：

![](https://pic2.zhimg.com/v2-75cc6cc9a68bbc6f9c568267973b1ed1_r.jpg)

vela3-fast 使用 24 层、380M 参数的双向 UltraBERT 编码器。每三层中，两层采用 ±128 token 的局部注意力窗口，另一层采用全局注意力，在局部信息处理与长距离关联之间进行组合，最大输入长度为 32,768 tokens。<br><br>对于决策问题，模型分别获得状态、问题和候选项的表示，从候选项标记位置读取选项特征，将状态与问题、选项之间的匹配分数和 MLP 分数结合，再通过 softmax 返回各选项的概率。是否题则按二选一处理，返回肯定答案的概率，业务系统可以直接据此设置阈值。<br><br>fast 的决策能力来自 d3 教师模型的蒸馏。首阶段使用 131 万条软标签决策数据，训练约两遍；监督目标保留教师对所有候选项的概率分布，而不只是最高分答案。存在金标准标签时，训练目标由金标准与教师分布各占一半构成，教师高置信度反对金标准的样本会被移除。<br><br>后续训练加入公开训练数据、程序生成任务和多教师筛选的数据，并对评测内容进行精确匹配与 13-gram 近重复检查。最终发布骨干由四份学生模型等权权重平均得到，不需要在推理时同时运行多个模型。<br><br>任务扩展则依靠冻结骨干与独立适配器。fast 的普通决策路径不启用任务适配器，适配器拥有各自的 LoRA、顶部层副本和任务头，其余权重共享冻结骨干。这样，新增、重训或删除某个适配器，不会改变不经过该适配器的普通决策路径。d3 系列也采用门控机制，让同批次中的普通决策行保留基础模型输出。<br><br>冻结骨干与门控适配器：

![](https://pic4.zhimg.com/v2-884dada382f11b4f7374f1906a4b8c3b_r.jpg)

片段提取不需要逐字生成答案。fast 对输入中的词和指定标签建立判断网格，再将相邻、同标签的命中词合并为片段，返回对应字符位置。开发者可以提供标签名称或描述，定义希望提取的内容；具体效果仍取决于任务与标签的匹配程度，并不保证任意新标签都能正确识别。<br><br>d3 系列的片段任务采用非因果全注意力，使词与标签能够相互关联。相比 Vela 2.0 的处理方式，它不再在标签之后重复放置第二份正文。长文本按词边界切分为重叠窗口，模型输出经过阈值判断与相邻词合并，还原为原文片段。<br><br>视觉型号将 SigLIP2 图像编码器与 UltraBERT 文本编码器结合。对于 1,024 px 图像，模型使用四个分块和一个全局视图，共形成 320 个图像 token，再由对应任务头进行判断或区域评分。定位结果属于网格级的粗粒度区域定位，不是像素级分割。

**性能表现：小模型决策、文本抽取与推理效率**

在决策能力上，团队使用 Decision Index 测试套件的公开部分，测得 vela3-fast 得分为50.36。作为对照，公开榜单中的 Amber 为 49.74，GLiClass v4 Edge 为 47.49。<br><br>小参数模型的 Decision Index 对比：

![](https://picx.zhimg.com/v2-54acf95b1774cea0eb3b5cecd466af67_r.jpg)

关系抽取要求头实体、关系和尾实体同时正确。mini 与 turbo 的严格三元组 F1 分别为 30.1和 35.9，对照的 Qwen3.5-9B 提示式方法为 25.7，GLiFormer-large 为 21.33。<br><br>实体识别、分类与关系抽取对比：

![](https://pic3.zhimg.com/v2-d5e71eb901dd67225e37a71e900f72c8_r.jpg)

在路由信号评测中，六款模型各对应 24 个测试文件，累计 144 次模型与测试文件比较，Vela 3.0 获得 105 胜、29 平、10 负。<br><br>路由信号的版本对比：

![](https://pic3.zhimg.com/v2-34a111d710c3df2e5d96ee1522cba704_r.jpg)

效率测试使用单张 AMD Instinct MI325X，文本输入为 200 tokens。回答一个片段问题时，fast 为 18 ms，lite、mini 和 flash 分别为 29、37 和 40 ms。<br><br>不同型号与任务的延迟对比：

![](https://pic1.zhimg.com/v2-9d7bf5c135182da1d959137e8aac5268_r.jpg)

选型时，380M 参数的 fast 适合英语请求决策、路由与片段提取；0.8B 的 lite 面向轻量多语言文本任务；4B mini、9B flash 和 27B turbo 可用于对分类、关系及证据提取要求更高的场景；fast-vision 则用于结合图片进行核验和区域定位。分级打分由 d3 系列支持，区域定位由 fast-vision 支持，应根据任务选择型号，而不是默认所有型号具备完全相同的能力。

**本地部署与推理**

Vela 3.0 可通过模型随附的 Python 运行时或 Transformers 进行本地推理，并提供 /v1/systemone HTTP 接口。 vela3-fast 和 vela3-fast-vision 支持 CPU 或 GPU， vela3-lite等版本适合 GPU 部署。以下分别给出英文文本路由、多语言文本提取和图像分析的部署示例。

### 模型下载

安装魔搭 SDK，按需下载对应模型：

```text
pip install modelscope
 
# 英文文本路由与提取
modelscope download --model vllm-sr/vela3-fast \
  --local_dir vllm-sr/vela3-fast
 
# 多语言文本推理：同时下载 Vela 适配器和 Decision 基座
modelscope download --model vllm-sr/vela3-lite \
  --local_dir vllm-sr/vela3-lite
modelscope download --model vllm-sr/d3-lite \
  --local_dir vllm-sr/d3-lite
 
# 图像决策、区域定位与 OCR 校验
modelscope download --model vllm-sr/vela3-fast-vision \
  --local_dir vllm-sr/vela3-fast-vision
```

后续命令均在执行模型下载命令的目录中运行。文本版和视觉版的 Transformers 版本要求不同，分别使用独立环境。

### vela3-fast：文本路由与提取

创建环境，安装模型随附的依赖：

```text
python -m venv .venv-fast
source .venv-fast/bin/activate
pip install -r vllm-sr/vela3-fast/requirements.txt
```

通过 Vela3Encoder 加载本地模型，在一次调用中完成意图分类、是非判断和实体提取：

```text
import json
import sys
from pathlib import Path
 
model_path = str(Path("vllm-sr/vela3-fast").resolve())
sys.path.insert(0, model_path)
from vela3_encoder import Vela3Encoder
 
model = Vela3Encoder.load(model_path)
result = model.system_one(
    "Steve Jobs founded Apple in Cupertino. My card was charged twice.",
    {
        "intent": {
            "type": "choice",
            "instructions": "What does the customer want?",
            "criteria": {
                "refund": "Money back for the duplicate charge",
                "cancel": "Cancel the order",
            },
        },
        "urgent": {
            "type": "noul",
            "instructions": "The customer needs a fast response.",
        },
        "entities": {
            "type": "span",
            "criteria": {"person": None, "organization": None},
        },
    },
)
print(json.dumps(result["answers"], indent=2, ensure_ascii=False))
```

模型自动选择可用的 GPU，否则使用 CPU。强制使用 CPU 时，将加载语句改为 Vela3Encoder.load(model_path, device="cpu") 。<br><br>choice 返回选项及其概率， noul 返回肯定答案的概率， span 返回文本片段、标签、字符偏移量和分数。 vela3-fast 仅支持英文；多语言任务可使用 vela3-lite 。

### vela3-lite：Transformers 推理

创建独立环境，安装官方示例依赖：

```text
python -m venv .venv-lite
source .venv-lite/bin/activate
pip install "transformers==5.17.0" "torch>=2.8" \
  torchvision pillow opencv-python-headless safetensors accelerate
```

加载 Vela 模型时，通过 base_path 显式指定本地 Decision 基座，避免自动从远端下载：

```text
import json
from pathlib import Path
from transformers import AutoModel
 
model = AutoModel.from_pretrained(
    str(Path("vllm-sr/vela3-lite").resolve()),
    trust_remote_code=True,
    base_path=str(Path("vllm-sr/d3-lite").resolve()),
    local_files_only=True,
)
result = model.system_one(
    state="Geoffrey Hinton presented capsule networks at NeurIPS in
Montreal.",
    questions={"entities": {
        "type": "span",
        "criteria": ["researcher", "algorithm", "conference",
"location"],
    }},
)
print(json.dumps(result["answers"], indent=2, ensure_ascii=False))
```

对于 RAG 回答，可传入上下文和答案，提取未被上下文支持的片段：

```text
result = model.system_one(
    state={
        "context": "The Eiffel Tower was completed in 1889.",
        "answer": "The Eiffel Tower was completed in 1925.",
    },
    questions={
        "hallucination": {
            "type": "span",
            "criteria": {"unsupported": None},
        },
    },
)
print(json.dumps(result["answers"], indent=2, ensure_ascii=False))
```

其他 Decision 基座版本也采用相同接口，但必须配套下载 Vela 配置指定的基座版本，不能直接替换为任意最新权重。

### vela3-fast-vision：图像分析

创建视觉版环境，安装模型随附的依赖；当前视觉版要求 transformers>=5.20 ：

```text
python -m venv .venv-vision
source .venv-vision/bin/activate
pip install -r vllm-sr/vela3-fast-vision/requirements.txt
```

加载本地模型，判断扫描文档类型，并定位指定区域：

```text
import json
import sys
from pathlib import Path
 
model_path = str(Path("vllm-sr/vela3-fast-vision").resolve())
sys.path.insert(0, model_path)
from vela3v_encoder import Vela3VEncoder
 
model = Vela3VEncoder.load(model_path)
result = model.system_one(
    "",
    {
        "kind": {
            "type": "choice",
            "instructions": "What type of document is this?",
            "criteria": {
                "invoice": "an invoice or bill",
                "letter": "a letter",
                "form": "a form",
            },
        },
        "where_total": {
            "type": "box",
            "instructions": "the total amount",
        },
    },
    images=["scan.png"],
)
print(json.dumps(result["answers"], indent=2, ensure_ascii=False))
```

将 scan.png 替换为本地图片。 box 返回粗粒度边界框、定位点和置信度。视觉版目前为预览版本，仅支持英文；区域定位和图像片段检测每次支持一张图片，决策问题最多支持三张图片。

### HTTP 服务调用

在 fast 环境中，使用模型随附的服务器启动文本服务：

```text
source .venv-fast/bin/activate
python vllm-sr/vela3-fast/vela3_server.py \
  --model "$PWD/vllm-sr/vela3-fast" \
  --host 127.0.0.1 \
  --port 8000
```

在另一个终端请求 /v1/systemone ：

```text
curl http://127.0.0.1:8000/v1/systemone \
  -H "Content-Type: application/json" \
  -d '{
    "state": "My card was charged twice. I want my money back.",
    "questions": {
      "intent": {
        "type": "choice",
        "instructions": "What does the customer want?",
        "criteria": {
          "refund": "Money back for the duplicate charge",
          "cancel": "Cancel the order"
        }
      }
    }
  }'
```

视觉版可在其环境中启动同样的接口：

```text
source .venv-vision/bin/activate
python vllm-sr/vela3-fast-vision/vela3_server.py \
  --model "$PWD/vllm-sr/vela3-fast-vision" \
  --host 127.0.0.1 \
  --port 8000
```

视觉 HTTP 请求需在 images 中传入 Base64 data URL，而不是客户端本地文件路径。该接口返回结构化决策和提取结果，不是 /v1/chat/completions 文本生成接口。
