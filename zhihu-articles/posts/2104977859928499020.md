昨天晚上，DeepSeek 又放大招了，这次不是发新模型，而是宣布开放「**全家桶应用 API**」。

平时我们在 DeepSeek App 里用到的联网搜索、深度思考搜索、上传文件、读链接、语音对话。

现在开发者都能通过 API 直接用上，甚至可以利用它们 **1:1 复刻出完整的 DeepSeek App**。

DeepSeek 团队还照着 App 做了一个网页版的聊天客户端 **chat-demo**，并开源给我们学习。

![](https://pic3.zhimg.com/v2-2c33c9690c5562a3241ca2b402cdc7b4_r.jpg)

一家公司主动教大家复刻自家的 App，到底图什么，对我们这些普通人又有什么用呢？

先来看看这次都开放了哪些东西。

以前开发者想在自己的应用里做出类似 App 的体验，光接入 DeepSeek 的模型还不够。

搜索、文件解析、语音这些都得另外找服务对接，再自己写代码把它们串起来。

现在这些活都交给了 DeepSeek 的服务端，开个参数，什么时候该去搜索、搜到的内容怎么交给模型，它都会自己处理好。

搜索、网页抓取、文字识别、语音识别、语音合成也拆成了单独的接口，可以只拿其中一个来用，也能几个组合在一起用。

目前支持这些能力的是 deepseek-flash，也就是 V4.1-Flash 模型。

价格方面，除了模型本身的 Token 费，调用这些工具还会另外收费，官方公布的价格如下：

![](https://pic3.zhimg.com/v2-ae2af93ac709e4392c06b1a6d36dfa72_r.jpg)

搜索和网页抓取都是 5 元一千次，语音识别一小时 0.39 元，它和语音合成目前都还在限时五折。

**那 DeepSeek 为什么要这么做呢？**

可以从崔添翼当晚发的两条帖子里找找答案，他在 DeepSeek 产品团队，平时主要做的就是 DeepSeek Harness。

第一条说，DeepSeek 产品背后的各项核心能力都已经通过 API 开放了，希望门槛降低之后，社区里能长出更多样、更有想象力的产品。

第二条就说得更直白了：「下一个超级 App 不必是面向所有人的一个超级 App。现在，每个人都有能力创造一个超级 App。」

![](https://pic3.zhimg.com/v2-5b91c4c3bd66bd35222269fb43c08402_r.jpg)

这么看来，DeepSeek 并不打算把自家的 App 做得越来越大、越来越全，反倒是把它拆成一个个零件交了出去，让大家按自己的需要去拼。

而且就在同一天，DeepSeek Harness 的新版也加了一个实验性的「DeepSeek 会话导入」插件，App 或网页版里的历史对话，可以搬进 DSH 里接着聊。

时间上正好凑在了一起，我们在 App 里聊过的那些记录，以后也不用只留在 App 里了。

![](https://pic4.zhimg.com/v2-5bc0ca85f461dc7bc8fc4968a6b06b43_r.jpg)

**最先感受到变化的，肯定是开发者。**

以前做一个能联网搜索、能看文件、能听会说的应用，得对接好几家服务，现在用一个 DeepSeek 的 API Key 就够了。

日子不太好过的，可能是那些给 DeepSeek 套个界面的第三方客户端，官方自己开源的这个 Demo，就已经有了 App 里大部分的功能。

网上也已经有网友在讨论，这波对做 DeepSeek 客户端的人来说，到底是利好还是抢活。

至于普通人，日常聊天继续用免费的 App 其实就够了，API 更适合想要点不一样东西的朋友。

想先尝尝鲜的话，可以直接打开官方的 Demo 体验页，在设置里填上自己的 API Key 就能用，Key 和聊天记录都只存在自己的浏览器里。

![](https://pic1.zhimg.com/v2-5cef970c5b44646ff1a3c8854af5e200_r.jpg)

费用是按用量来算的，模型的 Token 费在工作日高峰时段以外都是半价，周末和节假日全天也按半价算，平时偶尔用用花不了几个钱。

### **写在最后**

再往前想一下，崔添翼说的「**每个人都有能力创造一个超级 App**」，放到不会写代码的人身上，DSH 的创造模式就是一个现成的入口。

在创造模式里把需求描述清楚，它就能做出一个插件，装好之后直接就能用。

现在搜索、语音识别、语音合成、文字识别都有了官方接口，做插件的时候可以让它把这些能力接进去，能做的事情也就多了不少。

比如开会时录一段音，插件自动转成文字，再整理出一份会议纪要，或者拍一张发票，让它把金额和日期识别出来填进表格。

又或者每天早上让它搜一遍自己关注的话题，整理成一段新闻读出来，通勤路上戴着耳机就能听完。

这些插件不用管别人用不用得惯，按自己的习惯来做，自己用着顺手就行。

另外，如果做好的应用想开放给别人用，官方要求开启安全校验，内容审核、大模型登记、AI 标识这些义务也得自己承担起来。
