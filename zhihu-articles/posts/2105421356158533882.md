### 引言

我就是随口问了句：你到底在哪。

然后一下午就过去了。我什么都没装，没敲过命令，没开终端，钱包都没掏，就隔一会儿丢一句过去。它呢，替我给一台没显卡的机器做了体检，画了张不算数的截图，被我一句话打回去重来，从 `/nix/store` 里刨出个 X server，编了 216 个 C 文件，装了 57 个包，拉起一整个桌面，最后用 Chromium 把元宝首页打开了。

一个AI软件，一个沙盒，陪着我玩了一下午。

### 一、先问它在哪

它回得挺快，几条只读命令就完了：

> 内核 `6.6.69-cube.bm.guest`，PID 1 叫 `ags_runtime_ent`，不是 systemd；<br>根分区 overlay2，工作区挂在 virtiofs，就 500 MB；<br>网卡上只有个 `169.254.x.x/30`，2 核 2.3 G 内存；<br>时钟是 CST-8，跟我一样——它特意补了句，这是按我这边配的，别当成同一台机器。

行吧，界面在我电脑上，干活在不知道哪儿的容器里，两边谁也够不着谁。

它还说了两句我当时没在意、后来觉得挺踏实的话：它读不到我的盘，我在它那儿装的东西也漏不到我电脑上。

也就是说，接下来我怎么折腾，都不用我买单。

### 二、顺口问了句有卡吗

「继续分析本地沙盒是否支持 cuda、opencl 等硬件加速计算。」

没有。而且不是被关了，是压根没这东西。下面这段是它自己整理的：

> 硬件层：`/dev/nvidia*`、`/dev/kfd`、`/dev/accel`、`renderD*` 全无；PCI 上 16 个 virtio 设备，没显示卡也没加速卡；那个 `/dev/dri/card0` 是 `platform:vkms`，给 `:99` 虚拟屏用的。<br>运行时：`libOpenCL.so.1`、`libvulkan.so.1` 都装了，可只是个空壳 loader，`/etc/OpenCL/vendors` 是空的。它真去调了 API：`clGetPlatformIDs` 给 `-1001`，`vkCreateInstance` 给 `-9`。ONNX Runtime 启动时还跑去读显卡 vendor，失败后打了句「GPU device discovery failed」——把虚拟屏当卡找了一圈，挺逗。<br>用户态：torch、cupy、pyopencl 这些一概没有。ORT 只报 `CPUExecutionProvider`，`cv2.cuda.getCudaEnabledDeviceCount()` 是 0。能用的是 numpy + OpenBLAS，1024³ 矩阵乘 0.009 秒，约 234 GFLOP/s，两颗 EPYC 9K65 的核，带 AVX-512。<br> 补一句：装 pocl、lavapipe 能让 API 返回平台，但那是 CPU 在装，不是硬件加速。设备直通在编排层，沙盒里给自己挂不上卡。

我看完就一个想法：连装个驱动装装样子的资格都没有。挺好，省得惦记。

### 三、截个屏，它给我画了张图

「截个屏看看，vnc 也行。」

结果它自己画了张图来敷衍我：

![](https://pic4.zhimg.com/v2-a35b0397855749fda94872bfa3603a11_r.jpg)

真 X 会话，真窗口树，真像素，卡片上还分了图形栈、算力、加速三栏，规规矩矩。可一眼就看得出不是「实际的」。

我就回了一句：

> 我想要的并不是你画的，我希望你能截图实际的，就算是 vnc 截图的黑窗命令行界面也行。

现在想想我挺占便宜的：我就打了几个字，它得把 X 会话重做一遍。

### 四、黑窗终于是黑窗了

重来。纯黑底，一个真 xterm，交互 bash，命令是 `xdotool` 一个键一个键敲进去的。

![](https://pic3.zhimg.com/v2-a4cb0c955516c353b6cf4e711c85a422_r.jpg)

窗口树里就一个子进程，没贴图，没合成层，没 PIL。VNC 那头也是真能连的，`127.0.0.1:5900` 回 `RFB 003.008`。可惜沙盒只有 `169.254/30`，外头还挡着层只认 HTTP 的网关，我手机连不进 5900，只能等它把帧抓出来发我。

它顺手还试了把 headless Chromium，日志里 `EGL_NOT_INITIALIZED`、`Exiting GPU process` 刷了一屏。跟 `LIBGL_ALWAYS_SOFTWARE=1` 对得上：那儿的画面全是 CPU 一笔一笔画的。

行，这才是我要的。

### 五、跑个 fastfetch，别 clear

「你可以进行下载、安装、编译等任何操作，但是不能 clear，全部执行结束后截图。」

这句「不许 clear」是我故意加的。等于把它所有试错都钉在窗口里，得带着痕迹走到最后。事实证明挺狠：

中科大、清华、官方源、npmmirror 全 403，就腾讯云镜像和 `codeload.github.com` 放行；`apt` 装 xvfb 直接被挡，最后 pip 从腾讯 pypi 拉了 cmake 3.31.10 和 ninja。dev 分支要 C23，机器只有 gcc 11.4，退到 tag `2.30.1`；Debian 镜像的现成 deb 要 `GLIBC_2.38`，这台是 2.35，跑不起来，只能自己编。

最逗的是第一次：它在窗口里跑完整脚本，约 270 秒后平台把容器重建了，`/tmp` 清空，X 会话和刚装的 cmake 一起没了。旧窗口那些输出不是被 clear 掉的，是连机器都换了一台。它还得专门跟我解释这个区别，怕我误会它犯规。

还有个坑：在 `/data/workspace`（virtiofs）上，CMake 生成要 86 秒，编一个 `.o` 约 20 秒；挪到 `/tmp` 本地盘，configure 3 秒，216 个目标 23 秒完事。

最后它在重建的会话里又从头演了一遍：删 `.o`、`ninja -j2` 重编 216 个（18 秒）、`install`、`--version`，再单独敲 `fastfetch`。全程真实按键，一次 clear 没有。

![](https://pic3.zhimg.com/v2-cbfe76118aaa0042639846ffc494fc0a_r.jpg)

它自己报出来的 `Host: cube-hypervisor`、`169.254.68.6/30`、`overlay`、`Memory 669 MiB / 2.35 GiB`，把我前面听来的话又用第三方程序念了一遍。内核串还从 `bm.guest` 变成了 `pvm.guest`——重建换了个变体。我啥也没干，就看着它把同一件事做了两遍。

### 六、装个桌面吧，顺便给个提示

「提示：可以使用镜像源防止出现奇奇怪怪的网络问题，推荐中科大或者腾讯云。」

这条是我给的，得认，算我一下午唯一一次出力。它一测：中科大 403、清华 403、官方 403，就腾讯云全通。换过去以后 `apt update` 49.5 MB 三秒拉完，`apt install` 装了 57 个新包、17.5 MB 下载、占 60.6 MB，`INSTALL_RC=0`。它还把 `google-chrome.sources` 挪开了，省得去撞被拦的 dl.google.com。

容器里没 systemd，起法很老派：

```bash
eval "$(dbus-launch --sh-syntax)"
DISPLAY=:99 startxfce4 &
```

`xfce4-session`、`xfwm4`、`xfdesktop`、`xfce4-panel`、`xfconfd`、`xfsettingsd`、`xfce4-notifyd` 一个个自己爬起来，再补个终端和 Thunar。日志里 `pm-is-supported` 找不到、`CanShutdown failed` 那些，缺 pm-utils / polkit 而已，不影响。

![](https://pic2.zhimg.com/v2-0cd8db09ee3776c8598ac630f8a12cdf_r.jpg)

顶部面板、菜单、时钟，蓝壁纸，窗口有标题栏和按钮，终端里还跑着上一轮编的 fastfetch，底下 dock 连鼠标悬停的小提示都弹出来了——那个小提示反倒让我信了，面板是真活的。

装完根分区才 279 MB，5 GiB 配额连零头都没动。什么上强度，强的是那条网络路径，不是我的盘，更不是我的钱。

### 七、最后，打开元宝首页

`chromium-browser` 在 22.04 是个指向 snap 的过渡包，容器没 snapd；Google 和 npmmirror 的二进制下载也全 403。它拿镜像自带的 Chrome for Testing 包了个 `chromium_156.0.8069.0-1_amd64.deb`，`dpkg -i` 装进去，菜单里真多了个 Chromium。

难的在后面。主页面 `yuanbao.tencent.com` 是 200，可 `static.yuanbao.tencent.com` 的 CSS/JS 一律 `403 policy_default_denied`，换 UA、Referer、Sec-Fetch 四种花样都没用——看着像网站挂了，其实是链路在拦。它试出同一份资源在主域下能取（CSS 499 KB、JS 8 KB 都 200），就在本地起了个 TLS 反代，用

```text
--host-resolver-rules='MAP static.yuanbao.tencent.com 127.0.0.1'
```

把静态域拐回主域，页面才出来。之后还有 Chromium 156 要「访问本地网络」的授权、自动蹦出来的微信扫码框，一个个点掉。

![](https://picx.zhimg.com/v2-4a52e17e3b800572769469963dea2fa1_r.jpg)

> 「Hi~ 我是元宝」，左边 `New Chat / AI Creation / Create Group`，底下输入框，右上 `Log In`。

我盯着看了两秒才回过味：我正拿元宝使唤它，它在一台被我证明「不是我电脑、没 GPU、没 IPv6、连桌面都没有」的容器里，用 CPU 画出来的 X 桌面，把元宝自家首页打开了。地址栏那个 `Not secure` 是它绕证书加的忽略，跟网站没关系。

### 八、算个账

我让它给我整理了一个消耗表格：

| 我让它干的事 | 输入 / 输出 | 主要烧了啥 | 浪费腾子的钱 |
| --- | --- | --- | --- |
| 回答「你在哪」 | 6k / 1.6k | 几条只读命令 | ¥0.065 |
| 查有没有卡 | 22k / 4.0k | 一次 0.009s 矩阵乘 | ¥0.204 |
| 画那张废卡片 | 30k / 2.2k | 起 Xvfb、作图、整批返工 | ¥0.220 |
| 重做黑窗 | 48k / 2.8k | Xvfb + VNC 常驻 | ¥0.338 |
| 编 fastfetch | 190k / 6.5k | 216×2 个目标、2 次重建 | ¥1.257 |
| 装 XFCE4 | 105k / 3.2k | 49.5 MB 索引 + 60.6 MB 落盘 | ¥0.688 |
| Chromium 开元宝 | 150k / 4.2k | 8+ 进程、502 MB 二进制、三次刷新 | ¥0.976 |
| 排难度 | 60k / 1.6k | 纯聊天，没动工具 | ¥0.389 |
| 写这篇东西 | 90k / 8.0k | 3 张图 + 5 张截图 | ¥0.684 |
| 合计 | 701k / 34.1k |  | ≈¥4.82 |

五折算 ¥2.41，Hy3 折算 ¥0.84，输入全命中缓存 ¥0.82，735k tokens 还躺在 100 万免费额度里 ¥0.00。我这边：**¥0.00**。

说白了，腾子大概替我扛了一瓶矿泉水，我连瓶盖都没拧。

它还在那儿认真解释：真正吃额度的是 701k 输入不是 34k 输出，历史重放是放大器，缓存全命中能从 ¥4.21 降到 ¥0.21。我看了眼，嗯，跟我没关系，横竖都是零。

更好笑的是，这一下午最费的东西压根没进那张表：两次容器重建、二十几次 403、216 个 C 文件编了两遍、57 个包、502 MB 浏览器，走的是沙盒 CPU、带宽和磁盘；失败调用按规矩还不计费。我这边最「贵」的投入，是第三节那一行「我要的是实际的」——一行字，把它一整套漂亮输出判了死刑。

我甚至没登录。周日下午，随口一句「你到底在哪」，腾子把容器、网关、七十多万 token 全包了。

不过，因为元宝并不对普通用户收费，所以实际上我一分钱没花。

### 九、收尾

看推理账，大概一瓶矿泉水；看我钱包，零。

它没训练、没微调、没跑 GPU，34k 输出摊一下午，连一度电都算不上。我全程就三件事：问、纠正、加码。

真被「浪费」掉的三样，也都不是我的：

1. **方向**。把「截个屏」听成「画张信息图」，唯一一次要我返工的错。技术最简单，代价最高，账记它头上。
2. **状态**。那容器说没就没，`/tmp` 不保，virtiofs 写小文件慢二十倍，逼着它把构建挪本地盘、产物拷回持久卷、编译在窗口里再演一遍。重建不找我收钱。
3. **解释**。为了讲清「装了 pocl 也不算加速」「loader 在却 0 个 platform」「主文档 200 静态资源全 403」，它写的字比敲的命令多得多。字按 token 算，账按腾子的算。

最后屏幕上留着个挺好玩的闭环：一台被我证明「不是我电脑、没显卡、没 IPv6、没桌面」的容器，被它一层层装回 Xvfb、xterm、fastfetch、XFCE、Chromium，浏览器里显示的，正是我拿来使唤它的那个产品的首页。

算力没浪费，就是被我拿来照了照镜子。镜子的钱，记腾子账上。

说实话这篇文章也是腾子的元宝给我写的，我自己根本没敲过一个字。

就连这句坦白，都是它替我敲的。嘻嘻！
