**GPT-6 Astra 可能没有输给 Claude Opus 5.5；它只是输给了更容易传播的演示。**

如果你常年混迹ai社区，你会发现每当一个新模型发布时，拿鹈鹕测试来检验新模型的能力，这种测试非常直观，因为我们一眼就能看出生成质量的好坏

> *鹈鹕测试：使用SVG绘制一只骑自行车的醍醐，根据模型绘制的“精美”程度来反映模型的能力*

![](https://picx.zhimg.com/v2-6d9b088a49b0d84d410b24451a7506cf_r.jpg)

在gpt5.6sol这种级别的模型之前，我觉得一个这种测试是有意义的，因为像豆包这种模型，根本没办法做到画出一个完整的动画，但是现在我们处于6astra/opus5.5的时代，基本上任何一个厂商的模型都能做出一个完整的鹈鹕骑自行车（whatever,还是鳄鱼骑自行车，或者是秦始皇骑自行车），于是比较的标准变成了谁能把画面安排的更精美，或者加上更多炫技的元素，一个简单的鹈鹕骑自行车可能被判定为输了，这是很荒诞的一种判断模型能力的手法，因为你不能指望一段一两句话的提示词，让大模型生成一个电影级别的鹈鹕骑自行车。<br>所以我的观点很明确：**社区对 Claude 的优势有些过度延伸了，而 Astra 在科研任务中的竞争力被低估了**。

## CritPt榜单：gpt models win

> **CritPt：**Benchmarking LLMs at the Frontier of Physics 物理学前沿问题的LLM基准测试[CritPt - Physics Benchmark](https://critpt.com/)

在这份榜单上，GPT-6 Astra 得到 **83.1%**，Claude Opus 5.5 得到 **77.7%**。GPT-6.1 Sol 为 **82.0%**，也排在 Opus 前面。

![](https://pic4.zhimg.com/v2-f979b9919991e9153e31f45232e1870b_r.jpg)

这个结果至少足以打破一种过于简单的印象：**当任务变成研究级物理问题时，Astra 并没有处在一个被 Opus 远远甩开的能力档位。**

更有意思的是，官网还列出了这一评测的 API 总成本：Astra 为 **65.49 美元**，Opus 5.5 为 **133.16 美元**。

## Artificial Analysis 独立评测

| 评测 | GPT-6 Astra | Claude Opus 5.5 | 测试重点 |
| --- | --- | --- | --- |
| CritPt v2 困难子集 | 70.5% | 68.0% | 研究级物理问题 |
| Terminal-Bench-Science 0.1 | 63.3% | 59.0% | 跨学科科研计算工作流 |
| HLE-Diamond | 63.8% | 67.9% | 无工具的综合专家级问答 |

其中，[Terminal-Bench-Science](https://artificialanalysis.ai/evaluations/terminal-bench-science) 包含 70 项任务，覆盖生命科学、物理科学、数学科学、工程科学和地球科学。模型需要在终端环境中完成工作，任务必须通过对应的测试才算成功。这已经不仅仅是在回答一道选择题。

还要注意，表里的 CritPt 是 **40 题困难子集**，前面官网的 83.1% 和 77.7% 则是 **70 题完整集**

**Opus仅在综合问答中得分更高；但在真实的研究级物理问题和科研工作流中，Astra 的成绩更高。**

## 文献支持的最有说服力的测试：独立研究级科研能力

[https://arxiv.org/abs/2610.16733](https://arxiv.org/abs/2610.16733) 汇集了 50 道理论物理研究级问题。在允许联网和本地计算的设置中，**Astra + Codex 给出了 **49/50** 道题的正确终答**，Opus 5.5 + Claude Code 为 **46/50**；在禁止联网、仍允许本地计算的设置中，两者都是 **46/50**。

这很值得重视：研究级问题的答案不是靠生成一个漂亮页面就能得到的

另一个值得注意的点，在把任务进一步扩大到文献调研、研究计划、计算和论文式输出，[[FrontierPhysics]](https://arxiv.org/abs/2611.06910)中 Opus 5.5 系统的单次成功率为 **27.4%**，Astra Max 系统为 **23.2%**，**Astra在这个测试中落败了，这也符合我们的预期， Astra似乎是模型能力力大砖飞的典范，一旦涉及到调研规划等十分依赖人类审美的问题， Astra的表现似乎没那么好**

## Astra是一个“数值怪”，Opus更倾向于许愿机

我们应该欢迎更好看的界面、更自然的交互，也应该欣赏那些令人惊艳的演示。它们展示了模型真实能力的一部分。

但对研究者来说，需要回答一个更重要的问题：面对一个没有现成答案、需要严谨推导和反复验证的问题时，这个模型能帮我们走多远？

至少从目前的科研相关评测来看，把 GPT-6 Astra 视为已经被 Claude Opus 5.5 远远甩开的模型，是一个缺乏充分依据的判断。

如果你清楚自己的问题是什么，你需要去实现它，同时这个问题是困难的，我的建议很直接：Astra better
