自接触量化的 2016 至今，五年有余，然则依然自觉量化小学生，随着接触的人与事愈多，愈发觉得值得扩展的边界越多，自身的渺小与微不足

道。本文不做技术类分享，仅对笔者短暂的量化学习的经验与心得做一些总结与分享。

2016 年于笔者而言比较特殊，这一年，笔者面对着人生的第三次重大选择，大学校园的象牙塔待不下去了，对笔者而言，有几个选择：

1. 留校任教，大学教师作为社会地位比较高且业余时间较多的职业，看起来确实不错，不过，对应地，物质上的回报也最少

2. 国际学校教师，在临近毕业的时候，笔者随意投了几个简历，有国际学校伸出了橄榄枝，相比高校，国际中学给与的物质回报会更高些，

不过工作内容相比大学教师就更加单调了

3. 博士后，在临近毕业的迷茫之际，有个朋友发了一个博士后的招聘启事，看介绍是做人工智能的，虽然与笔者当前所学专业 （

理论物理） 似乎相距甚远，但是当时确实感觉是未来的一个非常好的方向，且对这个方向真的很感兴趣

在三个选择之间，犹豫很久，扪心自问好多次，最终，笔者还是选择了去深圳某高校做博士后，虽然面临跨行业，跨地域等诸多挑战，但

思虑良久，笔者到底需要的未来到底是平淡的生活，还是更加具有挑战和可能性的生活? 答案还是 ”世界这么大，我想去看看"。

虽然导师挂的博后广告是做人工智能，但是发现导师要做的是金融量化，更可惜的是，导师对这一块看起来完全没有研究，于是，很尴尬地，

笔者接触到了一门以前压根没听说过的技术，而且完全没有前辈指导。更尴尬的是，相比机器学习这类热门方向书籍视频众多，

金融量化却显得神秘而不得门路。

说起来笔者的博士后生涯是挺失败的，因为最终选择做了逃兵，退站结束了这短暂的两年，从另一方面来看，笔者的博士后生涯其实也是幸

运的，因为正是在这里，机缘巧合地遇到了形形色色的人与事，最终磕磕绊绊还算是摸到了量化的门槛。

可能会有读者觉得奇怪，笔者博士后生涯并没有前辈指导，量化也是神神秘秘，怎么去做量化的？ 现在回头看来，短暂的两年博后生涯，

笔者遇到的几件标志性事件可以说是笔者真正步入量化这个行当的促进剂了。这里简单介绍笔者的学习与进步历程，也给其他有志于

量化的读者们一点经验与介绍。

第一个标志性事件是导师开了一门量化交易课，以 TradeBlazer (期货交易软件) 为工具进行量化交易，并且指定由笔者去讲这门课。

如何合理安排课程，课程内容，需要达到什么样的程度，都需要从零开始设计与实现。幸运地是，在收集资料过程中，正好 TradeBlazer

开了一个如何使用 TradeBlazer 进行量化交易的系列。 作为一个合格的白嫖怪，自然需要将 TB 他们的课程彻底吸收，然后再嚼碎

了重新设计给其他学生。当然。这样的过程也无意中符合 ”费曼学习法“, 在不断学习，整理，教授，答疑过程中，笔者也终于算是

摸到了量化交易的门槛了，如何去实现策略，如何是进行止盈止损，如何去进行仿真交易，如何去观察绩效指标等。

第二个标志性事件来自于与网上认识的网友策略交流。 闭门造车往往会陷入各种陷阱而不自知，这时候如果可以有和其他前辈交流

的机会，对于自身的提升是巨大的。这位网友现在是某国资旗下资管负责人，当时差点到他手下工作，可惜因为各种原因，最终还是

没能成行。相比笔者纸上谈兵的浅显经验，这位朋友以其丰富的实盘经验，对笔者的各种误解与错漏进行各种指正。来自他对交易的

细节的精益求精，付出也确实让笔者收益匪浅。

印象中策略交流最深刻的一次是笔者在实现某篇国外的某个策略文献时，策略简称笔者还记得，叫 RTS (趋势反转策略)。本来是

练笔之作，没想到回测的时候，收益超级好，仔细检查后，也没有发现未来数据的引入。和前辈交流后，前辈也很振奋，不过本着

审慎的态度，他还是盯着策略仿真交易看了相当长的一段时间，最后还是发现了实现的策略中某个致命漏洞，来自 TB 的信号闪烁问题，

笔者实现的策略并没有很好地处理掉。 TB 的分钟 bar 行情会随着新的快照行情到达

后实时更新，如果以分钟 bar 进行开平仓，很容易碰到在回测时没有问题，但是仿真或实盘的时候，由于分钟 bar 的最高最低价变动，

原本出现的开仓平仓信号消失的情况，这就是信号闪烁。虽然因为后来笔者去做股票策略，放下了这个策略，不过如果有读者对这个

很原始的策略感兴趣的话，可以尝试实现并与笔者交流。

后面的几个对笔者产生重要影响的事件其实都与掘金量化有关。

在博士后第二年，笔者再次陷入瓶颈中，机器学习的书看了许多，但是都浅尝辄止，编程能力一般，而量化交易相关的技术栈

完全依赖 TradeBlazer 的实现，但是 TB 作为一个交易软件，实现一些简单策略和可视化很方便，一旦需要实现复杂的逻辑时，会遇到

非常大的困难。

在某个奇妙的夜晚，笔者在翻看掘金量化在 github 上分享的股票策略实现源码时，忽然就觉得灵光一闪，对这类事件驱动框架的

策略平台有了比较直观的理解。原来一个 Python 策略可以这么写，原来写策略需要考虑的细节有这么多，快照行情原来应该这么

处理， ~on_bar~ 与 ~on_tick~ 原来是这么个用法。

相比掘金量化， TB 交易软件实际上是把账户的复杂处理方式隐藏了，带来便利性的同时也会失去灵活性，而类似掘金的量化软件，在

自己去控制仓位，设置账户的过程中，也可以对账户的更新方式和维护方式有更深入地理解。

这里介绍下笔者学习这些有意义的源码的过程，其实很简单，看一遍，抄一遍，理解一遍，然后试着去自己写一遍，写不出来，重复

抄 -> 理解 -> 复现这样的步骤，直到能够完整地将逻辑梳理完整，代码默写出来。

有时候不得不感慨命运的奇妙，就在笔者学会基于掘金量化的 api 编写策略时，掘金量化的人找到我，他们有客户有股票策略想要实现，

问我有没有兴趣去接下来。有这么个学以致用的机会，当然要尝试啊。

其实客户的策略逻辑其实很简单，本质就是涨停板策略。不同的是，他们罗列的各种逻辑涵盖了选股，择时，仓位管理等各项内容，

笔者也是第一次看到这种策略罗列逻辑，这样的逻辑其实与策略实现非常接近了，虽然还是有很多问题，幸运地是，通过努力，笔者

还是勉强实现了他们的策略，甚至写出来该策略的回测版本。

至此，从笔者本人的感受来说，算是打通从回测到仿真交易的通路，当然了，最后人家有没有实盘，笔者也不知道了。说起来，这个笔者第一

笔外快，谈的是 2W 的价格，最后却仅仅收到了 5000，哎……算有得有失了吧。其实，如果这家公司把钱给足了，按笔者现在的实力，完全

可以继续给他们优化下去的啊，毕竟当时写的策略，现在回头看，满满的都是稚嫩啊

有了上次合作的基础，这次掘金给笔者介绍了新的客户，这位客户也成为了笔者的前任老板。前老板在股票市场上起起落落好多年，

赚过钱，爆过仓，积累了丰富的经验，偶然的机会听说到量化交易，觉得他的思想可以量化实现。奈何所托非人，一直没能找到人帮他实现

策略。然后某次辗转通过光大证券，招商证券，掘金的朋友，最后找到我这里。说实话，第一次听到前老板的投资理念，个人感觉挺一般的。

不过笔者脑中构建他的策略也没感觉多难，既是一笔外快，又是一次实践的机会。

简单实现了一个策略雏形。没想到的是，在用掘金进行仿真交易时，一天抓几十支股票，有一半涨停，剩余的居然都不亏钱，甭管人家讲的

逻辑多土，有效果就是有效果。而这次的合作也成为了一个契机，让前老板顺利成立了一个小私募，笔者也有幸成为了公司的第一个员工。

随着笔者入职新公司，相应地弊端也显现出来，缺乏在顶尖投资机构的经验，仅仅是来自老板的想法，很容易陷入策略单一，风格简单的

困境中。当然，小公司也有小公司的优势，因为人少，于是你就需要身兼多职，不仅仅做策略开发的工作，还要去清洗数据，写回测框架，

搭建仿真交易框架。感谢前公司的同事，提供了利用 pandas 进行向量化回测的思路，感谢这时候发现的开源框架 quantaxis, 笔者又一

次成为了白嫖怪，通过学习 quantaxis 的源码，拆解它对于账户管理的思路与内容，总算总算，完成了全市场分钟回测与仿真框架。

当然，这个里程碑达成也是笔者心中给自己定下的离开的时候。因为，这时候，再次地，笔者感受到了瓶颈，瓶颈在于几个方面：

1. 市面上其他先进的资管机构怎么做交易的，笔者直到此事依然毫无头绪，如何去寻找策略的灵感，如何去科学地进行投资，在这里，

笔者内心知道找不到答案了。

2. 技术上的积累也到了瓶颈期，博士阶段也写过不少 C++，不过写的都是在对应框架下简单的 C++，放下几年，早已忘记。

3. 实盘缺失，虽然打通了回测到仿真，但是实盘交易阶段，笔者被隔离开了，不得不说感慨遗憾。

自从这个小公司离职后，笔者满怀信心，觉得天下之大， 大可去的。无奈地被社会无情打脸，裸辞后，笔者赋闲在家大半年，看各种

乱七八糟的技术文章与视频，学 C++，学 NLP，学这学那，但是却都没有深入。还好，非常幸运地，某券商给了笔者机会，磨了

几个月，前前后后好几次面试，最终还是磕磕绊绊地进了某券商的信息技术中心。

在券商其实前面的岁月挺尴尬，因为确实没做出什么东西，七零八碎做了一些辅助性工作。还好领导给了足够的时间与空间让自己成长，

也是在这里，笔者第一次完整接触到股票高频的内容，并在自研的量化框架上去实现一些高频策略。

终于，在入司的第二个年头，领导交付了一个算法交易的课题，需要从原始数据出发，到模型构建，到特征构建，一直到最后出模型

效果的评价并最终落实到工程上。说起来，从零开始一个项目真的相当磨人，搜索文献，整理内容，寻找有价值，有逻辑的内容，

梳理工作流程，搭建分析框架，凡此种种，来来回回差点放弃好多次。还好，来自同事们的经验与建议，来自领导的评论与规划，

最重要的是，来自一点点运气成分，总算勉强达到一个里程碑，从原始数据输入，到最后绩效评价，可视化，勉勉强强达到了端到端

的实现。

其实于笔者而言，个人感觉这次项目也是对自己的瓶颈的再次打破，因为一个更科学的投研体系搭建出来了，虽然还抱有不少遗憾，

譬如原本想用的各种高大上模型因为时间仓促没有套上，因子的构建与实现还是略显粗糙，代码耦合度还是太高等等，来自工程化

的思考与实践，来自细节的雕琢与再雕琢，凡此种种，笔者再次感觉成长，也有种想要分享这难得的体验的感觉。

在之前笔者问读者有什么想要了解的，有读者说让笔者分享下怎么去做量化，成长经历等，其实反思与总结起来，大概几点：

1. 体系构建，带有目的的去构建学习与实践路径，譬如，如果有个股票交易的想法，想要实现，那就思考如何去构建全流程的路径，

从股票池选择，进场点，出场点，止盈止损点，极端情况的处理等，然后对每个步骤进行代码实现的思考，如果要完成对应

步骤，代码要怎么实现，不同部分的代码实现如何结合

2. 实践，纸上谈兵很容易，缺乏实践很多想当然是毫无意义的，在笔者的角度看来，很多研报，其实仅仅是提供了思路而已，甚至

更夸张地是有些研报的结论与研究方式是有问题的，当然了，对我们量化从业者而言，当灵感匮乏时，来自券商研报的

思路完全可以成为灵感源泉，不过千万要当心，不要算算 IC， IR 就结束了，对量化交易而言，需要经受住市场的拷打后

还能屹立住的策略才有意义

3. 多看，感谢 quantaxis 作者，感谢 wondertrader 作者，感谢 vnpy, kungfu 等这些开源框架贡献者，来自他们的无私分享，

才可以让策略研究可以有比较方便的量化框架可用，实现一个简单策略很简单，但是一个策略从写出来到最终成交，中间经历

了什么？如果不了解这些细节，交易也容易浮于表面，这时候，这些优秀的开源框架的实现就是一个又一个的宝库，可以看到

从行情推送过来后，如何进行撮合，如何进行账户更新等细节。

4. 多交流，说起来还要感谢 babyquant 这位大 V，他把我拉到了量化交流群，也让笔者看到了这个圈子的一角，看到行业内

现在在做什么，做到什么程度

5. 努力，其实这个内卷型的社会下，将努力有点矫情，但是笔者个人的感受时，相当多的人的时间是虚耗的，无休止的扯皮，

对着电脑的发呆，拖延时间的加班，虽然有时候确实需要随大流，但是真的是浪费生命。努力不是让待在公司将原来八小时

可以完成的工作用 十二个小时去加班完成，而是八小时工作完成后，留哪怕两个小时给自己，让自己提升能力，留两小时

给家人，放松地同时去思考会有更多的灵感。就笔者所见，优秀的人不是加班的人，而是不断扩展自己能力边界的人，譬

如 quantaxis 的作者余天，我们称他为天神，因为他确实太能肝，太能干了，下面是天神给自己规划的路径，如果觉得自己

到了瓶颈，找不到提升的方向的时候，笔者建议，这个优秀的人的路径走就行，嘿嘿

看了下，上一篇笔者发的文章还是 2020 年底，当时觉得 2021 年可能股票市场表现会一般，做了回神棍。没想到这一年都过

去了 5 个月，回头看笔者之前分享的文章，多有错漏与疏忽，停了这么久，其实笔者有个打算，将未来分享的内容做成不同

的系列，譬如交易相关，研究相关等，并针对不同水平的受众写一些文章，之前有读者留言还希望笔者能带着写一个可用的策略

出来，笔者也在考虑中，最迟六月份可能笔者会出一个视频，分享一下如何去实现回测到仿真交易，嗯，实盘还轮不上，因为

直到现在为止，笔者也仅仅到了仿真交易，有点可惜，今年的一个计划是，必须实现量化实盘，真到了实盘的时候，笔者也会

分享得与失。
