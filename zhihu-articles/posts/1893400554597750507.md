## 背景与概述

在LLM推理上，张量并行（Tensor Parallelism, TP）是一种重要的模型加速手段：将模型的权重矩阵按照一定的规则（如列分割或行分割）拆分为多个部分，在每个GPU上分别完成部分计算，从而可以提高计算速度以及降低单个GPU的内存需求。在VLLM中，张量并行主要涉及到进程(worker)管理、行并行、列并行，以及Reduce通信. 下面会结合代码给出实现和分析.

## 进程管理 —— Ray

Ray 是一个高性能的分布式计算框架，它提供简单的接口将代码扩展到分布式环境中. vllm使用Ray来管理多个进程在不同的GPU上的推理，所以这里只会介绍Ray在多进程管理上的简单使用方法. 如果只关心TP的实现，可以跳过这一节.

假设现在有一个多卡训练场景，使用PyTorch的DDP(DistributedDataParallel)实现，脚本为`ddp.py`:

```python
import torch
import torch.distributed as dist
import torch.nn as nn
import torch.optim as optim
from torch.nn.parallel import DistributedDataParallel as DDP
from torch.utils.data import DataLoader, DistributedSampler, TensorDataset
import sys
import multiprocessing as mp
import ray

def init_distributed_mode(rank, world_size):
    print("init start")
    dist.init_process_group(
        backend='nccl', 
        init_method='tcp://127.0.0.1:23456', 
        world_size=world_size, 
        rank=rank
    )
    print("init end")

class SimpleModel(nn.Module):
    def __init__(self):
        super(SimpleModel, self).__init__()
        self.fc = nn.Linear(10, 1)

    def forward(self, x):
        return self.fc(x)

def setup_model(rank):
    model = SimpleModel().to(rank)
    return DDP(model, device_ids=[rank])

def setup_dataloader(rank, world_size, batch_size=32):
    dataset = TensorDataset(torch.randn(1000, 10), torch.randn(1000, 1))
    sampler = DistributedSampler(dataset, num_replicas=world_size, rank=rank)
    dataloader = DataLoader(dataset, batch_size=batch_size, sampler=sampler)
    return dataloader

def train(rank, world_size):
    init_distributed_mode(rank, world_size)
    model = setup_model(rank)
    dataloader = setup_dataloader(rank, world_size)
    
    optimizer = optim.SGD(model.parameters(), lr=0.01)
    loss_fn = nn.MSELoss()
    
    for epoch in range(5):
        for inputs, targets in dataloader:
            inputs, targets = inputs.to(rank), targets.to(rank)
            optimizer.zero_grad()
            outputs = model(inputs)
            loss = loss_fn(outputs, targets)
            loss.backward()
            optimizer.step()
        print(f"Rank {rank}, Epoch {epoch + 1}, Loss: {loss.item()}")
    
    dist.destroy_process_group()

if __name__ == "__main__":
    pass
```

完成DDP训练涉及到多个进程的管理，主要有下面几种方式

### 手动管理进程

最简单的方法是手动在terminal中一个个去起进程，如将上述代码中`if __name__ == "__main__":` 改成如下部分：

```python
if __name__ == "__main__":
    if len(sys.argv) != 3:
        print("Usage: python script.py <rank> <world_size>")
        sys.exit(1)
    
    rank = int(sys.argv[1])
    world_size = int(sys.argv[2])
    print(f"rank : {rank}, world size : {world_size}")
    train(rank, world_size)
```

然后手动在多个终端去开启进程

```text
python ddp.py 0 4
python ddp.py 1 4
python ddp.py 2 4
python ddp.py 3 4

```

当第四个进程起来之后，模型开始训练直至结束

### multiprocessing 管理进程

上面的手动管理进程方式并不方便，特别是worker较多的情况。为了避免这样的负担，我们可以使用python的`multiprocessing` 去管理多个进程.

```python
if __name__ == "__main__":
    world_size = 4
    processes = []

    for i in range(world_size):
        process = mp.Process(target=train, args=(i, world_size))
        processes.append(process)
        process.start()

    for process in processes:
        process.join()
```

这样只要启动一次脚本即可:

```text
python ddp.py 
```

### Ray 管理进程

上述方式，依然要在代码中去管理进程，有没有这样的一种工具，能够通过类似于装饰器的方式去hack给定函数，使得每次调用该函数时，它都会在独立的进程上去执行，但是从使用者角度来说，它和普通调用没有区别. `ray.remote` 可以提供类似的功能.

给定上述的`train`函数，可以使用`train_remote = ray.remote(num_gpus=1)(train)` 得到一个hack之后的`train_remote`对象，并且可以指定对象的`gpu(num_gpus=1)`数量. 之后通过`train_remote.remote(*args, **kwargs)` 接口去创建任务，每个任务在独立的进程中去调用`train` 函数，每个进程都有一个独立的gpu.这里有两点需要注意：

- `train_remote.remote(*args, **kwargs)` 是异步的，它返回的是一个类似于`Promise`的对象，所以需要通过`ray.get`去获得执行结果.
- ray会通过设置`CUDA_VISIBLE_DEVICES` 参数来保证每个进程得到的GPU是隔离的，当`num_gpus=1`时，每个ray的进程分配到的可见gpu都是device_0，所以上述代码对于`device`的设置也需要作相应的修改，完整代码为：

```python
import torch

    sampler = DistributedSampler(dataset, num_replicas=world_size, rank=rank)
    dataloader = DataLoader(dataset, batch_size=batch_size, sampler=sampler)
    return dataloader

def train(rank, world_size):

    model = setup_model(rank, device)
    dataloader = setup_dataloader(rank, world_size)

    remote_funcs = [train_remote.remote(rank, world_size) for rank in range(world_size)]
    ray.get(remote_funcs)
```

## 张量并行 / Tensor Parallelism

在LLM中，TP主要应用于核心的Attention模块，这里以常见的Multi-Head Attention (MHA)为例来介绍TP的实现.

首先给一个基础的MHA实现:

```python
import torch
import torch.nn as nn

class MultiHeadAttention(nn.Module):
    def __init__(self, embed_dim, num_heads, bias): 
        super().__init__()
        self.embed_dim = embed_dim
        self.num_heads = num_heads
        self.head_dim = self.embed_dim // self.num_heads
        self.scalling = self.head_dim ** -0.5
        
        self.q_proj = nn.Linear(embed_dim, embed_dim, bias)
        self.k_proj = nn.Linear(embed_dim, embed_dim, bias)
        self.v_proj = nn.Linear(embed_dim, embed_dim, bias)

        self.out_proj = nn.Linear(embed_dim, embed_dim, bias=bias)
        self._init_weights()

    # q, k, v: [num_seq,  self.num_heads, seq_len, self.head_dim]
    def attention(self, q, k, v):
        scores = torch.matmul(q, k.transpose(-2, -1)) * self.scalling # [num_seq,  self.num_heads, seq_len, seq_len]
        attn_weights = torch.nn.functional.softmax(scores, dim = -1) # [num_seq,  self.num_heads, seq_len, seq_len]
        attn_output = torch.matmul(attn_weights, v)
        return attn_output

    def _init_weights(self):
        # Initialize the linear layer weights uniformly in a range (-0.1/sqrt(embed_dim), 0.1/sqrt(embed_dim))
        bias_range = 0.1 / (self.embed_dim ** 0.5)
        
        # Use xavier uniform for weight initialization if needed or any other preferred method.
        nn.init.xavier_uniform_(self.q_proj.weight)
        nn.init.xavier_uniform_(self.k_proj.weight)
        nn.init.xavier_uniform_(self.v_proj.weight)
        
        
        # Initialize biases if they exist (optional and depends on your preference or needs).
        if self.q_proj.bias is not None:
            nn.init.uniform_(self.q_proj.bias, -bias_range, bias_range)
            nn.init.uniform_(self.k_proj.bias,-bias_range, bias_range)
            nn.init.uniform_(self.v_proj.bias,-bias_range, bias_range)
            nn.init.uniform_(self.out_proj.bias,-bias_range, bias_range)

    
    def forward(self, hidden_state):
        num_seq, seq_len, embed_dim = hidden_state.size() # hidden_state : [num_seq, seq_len, embed_dim]
        q = self.q_proj(hidden_state)
        k = self.k_proj(hidden_state)  
        v = self.v_proj(hidden_state)

        q = q.view(num_seq, seq_len, self.num_heads, self.head_dim).transpose(1,2) # [num_seq,  self.num_heads, seq_len, self.head_dim]
        k = k.view(num_seq, seq_len, self.num_heads, self.head_dim).transpose(1,2)
        v = v.view(num_seq, seq_len, self.num_heads, self.head_dim).transpose(1,2) 

        attn_output = self.attention(q, k, v) # [num_seq,  self.num_heads, seq_len, self.head_dim]

        attn_output = attn_output.transpose(1,2).contiguous().view(num_seq, seq_len, embed_dim)
        output = self.out_proj(attn_output)
        return output

if __name__ == "__main__":
    torch.random.manual_seed(42)
    torch.set_printoptions(precision=10)
    model = MultiHeadAttention(embed_dim=512, num_heads=8, bias=True)
    input_tensor = torch.randn((10, 16, 512))   
    output = model(input_tensor) 
    print(output.mean())
```

### 列并行——ColumnParallelLinear

`ColumnParallelLinear` 是TP的核心模块之一，它能够将矩阵按照列切分成子矩阵，并存放到不同的gpu上，每个gpu完成子矩阵对应的计算.

在MHA的计算中, `ColumnParallelLinear` 可以用于将Attention的多个Head对应的`q`,`k`,`v` 放入到不同的gpu上去作计算.

假设Attention的参数为`embed_dim = 8`, `num_heads = 4`, `head_sdim = 2` , 输入的`hidden_state` 的`num_seq = 1`, `seq_len = 1`.

在原始的Attention中，获得每个head的q操作为：

```python
 q = self.q_proj(hidden_state)
 q = q.view(num_seq, seq_len, self.num_heads, self.head_dim).transpose(1,2) #
```

该操作如下图所示，`hidden_state` 与 `q_proj`每列的计算以及结果，都是独立且对应的.

![](https://pic1.zhimg.com/v2-33f8651784f92894fc14b003c67b7b52_r.jpg)

这表明我们可以将`W_0`, `W_1`, `W_2`, `W_3`分别放到不同的gpu上，每个gpu分别完成与hidden_state的矩阵计算，这样每个gpu上都可以得到独立的head，如图所示：<br>

![](https://pic3.zhimg.com/v2-07de46c20bc9010d48f0fcdc2e6a0718_r.jpg)

对于`k` 和 `v`同理，按照同样的方法将 `k_proj`和`v_proj`切分到不同的gpu上.

现在在`gpu_0`上有`head_0`的`q`, `k`, `v`, `gpu_1`上有`head_1`的`q`, `k`, `v`. 注意到attention的计算中，head与head之间没有数据交互，即当前head的`q`,`k`,`v`的加权计算只与当前head持有的`q`,`k`,`v` 有关.

```python
    # q, k, v: [num_seq,  self.num_heads, seq_len, self.head_dim]
    def attention(self, q, k, v):
        scores = torch.matmul(q, k.transpose(-2, -1)) * self.scalling # [num_seq,  self.num_heads, seq_len, seq_len]
        attn_weights = torch.nn.functional.softmax(scores, dim = -1) # [num_seq,  self.num_heads, seq_len, seq_len]
        attn_output = torch.matmul(attn_weights, v)
        return attn_output
```

这表示我们可以继续在每个gpu上独立完成所对应head的加权计算.

这样我们可以将`ColumnParallelLinear` 实现为:

```python
class ColumnParallelLinear(nn.Module):
    def __init__(self, input_size, output_size, rank, world_size, is_gather = False):
        super(ColumnParallelLinear, self).__init__()
        self.world_size = world_size if world_size is not None else dist.get_world_size()
        self.rank = rank
        self.input_size = input_size
        self.output_size = output_size
        self.local_output_size = output_size // self.world_size
        self.weight = nn.Parameter(torch.empty(self.local_output_size, input_size))
        self.bias = nn.Parameter(torch.empty(self.local_output_size))
        self.is_gather = is_gather

    def forward(self, x):
        output_ = F.linear(x, self.weight) + self.bias
        if self.is_gather:
            ouptut = [torch.zeros_like(output_) for _ in range(self.world_size)]
            dist.all_gather(ouptut, output_)
            ouptut = torch.cat(ouptut, dim = -1)
        else:
            output = output_
        return output

```

注意，在attention的TP中，`ColumnParallelLinear`的`is_gather`是默认设置为`False`的 ，这是因为接下来还需要作每个head的attention计算.

### 行并行——RowParallelLinear

在每个head 完成 attention计算之后，我们需要将每个head的attention结果concat，之后通过`out_proj`映射到输出，即:

```python
        attn_output = self.attention(q, k, v) # [num_seq,  self.num_heads, seq_len, self.head_dim]
        attn_output = attn_output.transpose(1,2).contiguous().view(num_seq, seq_len, embed_dim)
        output = self.out_proj(attn_output)
```

这个过程如下图所示：<br>

![](https://pic2.zhimg.com/v2-bdd61aa152aa5d4ae4ffc84c4b22de0b_r.jpg)

但是在TP的实现下，不同的head的attention计算结果在不同的gpu，如何完成这个计算？最简单的方法是通过all_gather去实现，如:

```python
class OutLinear(nn.Module):
    def __init__(self, input_size, output_size, world_size):
        super(OutLinear, self).__init__()
        self.output_proj = nn.Linear(input_size * world_size, output_size)

    def forward(self, x):
        gathered_inputs = [torch.zeros_like(x) for _ in range(dist.get_world_size())]
        dist.all_gather(gathered_inputs, x)

        concatenated_inputs = torch.cat(gathered_inputs, dim=0)
        return self.output_proj(concatenated_inputs)
```

但是这种方法并不高效，它多出了`all_gather` 的通信消耗，以及`output_proj` 在每个gpu上的重复计算.

`RowParallelLinear` 是能高效完成这些计算的方法，具体来说，`output_proj` 可以等价拆分成如下的计算方式:<br>

![](https://pic3.zhimg.com/v2-dd38faba1c37dd4e9c5df9fcbb5f6eba_r.jpg)

从上图可以看到，我们可以将`out_proj`的权重根据行(row)拆分成对应的子矩阵，这样每个gpu上的attention输出都和对应的子矩阵作矩阵乘法，之后通过Sum Reduce 将结果求和，即可得到最终结果.

这样我们可以将`RowParallelLinear`实现为:

```python
class RowParallelLinear(nn.Module):
    def __init__(self, input_size, output_size, rank, world_size, is_reduce = True):
        super(RowParallelLinear, self).__init__()
        self.world_size = world_size if world_size is not None else dist.get_world_size()
        self.rank = rank
        self.input_size = input_size
        self.output_size = output_size
        self.local_input_size = input_size // self.world_size
        self.weight = nn.Parameter(torch.empty(output_size, self.local_input_size))
        self.bias = nn.Parameter(torch.empty(output_size))
        self.is_reduce = is_reduce
    

    def forward(self, x):
        output_ = F.linear(x, self.weight)
        if self.is_reduce:
            dist.all_reduce(output_, op = dist.ReduceOp.SUM)
        output = output_ + self.bias
        return output

```

注意`is_reduce`在Attention的TP实现中是要默认开启的，因为只有通过最终各个gpu上的sum reduce，才能保证`RowParallelLinear`的TP结果是和原来的Linear计算等价

### 完整代码实现以及测试

从上面的`ColumnParallelLinear` 和 `RowParallelLinear`可以看到，Attention的TP实现主要利用了Attention的`Multi-Head`特点.

通过`ColumnParallelLinear`沿着Head维度将多头切分到不同的GPU上. 由于每个head中的q,k,v的计算都是独立且互不干扰的，所以这些heads的q,k,v加权计算可以继续在其分配的GPU上独立完成.

最后，通过`RowParallelLinear`中的`sum reduction`来完成最终的`output_proj`计算.

MHA完整的TP实现代码如下：

```python
import ray
import torch
import torch.distributed as dist
import torch.nn as nn
import torch.nn.functional as F
import numpy as np

class ColumnParallelLinear(nn.Module):
    def __init__(self, input_size, output_size, rank, world_size, is_gather = False):
        super(ColumnParallelLinear, self).__init__()
        self.world_size = world_size if world_size is not None else dist.get_world_size()
        self.rank = rank
        self.input_size = input_size
        self.output_size = output_size
        self.local_output_size = output_size // self.world_size
        self.weight = nn.Parameter(torch.empty(self.local_output_size, input_size))
        self.bias = nn.Parameter(torch.empty(self.local_output_size))
        self.is_gather = is_gather

    def init_weight(self, offset):
        with torch.no_grad():
            weight_value = torch.arange(0, self.weight.numel() * self.world_size).reshape(self.output_size, self.input_size)[self.rank * self.local_output_size : (self.rank + 1) * self.local_output_size, :]
            self.weight.copy_(weight_value)
            bias_value = torch.arange(0, self.bias.numel() * world_size)[self.rank * self.local_output_size : (self.rank + 1) * self.local_output_size]
            self.bias.copy_(bias_value)
            self.weight += offset
            self.bias += offset

    def forward(self, x):
        output_ = F.linear(x, self.weight) + self.bias
        if self.is_gather:
            ouptut = [torch.zeros_like(output_) for _ in range(self.world_size)]
            dist.all_gather(ouptut, output_)
            ouptut = torch.cat(ouptut, dim = -1)
        else:
            output = output_
        return output

class RowParallelLinear(nn.Module):
    def __init__(self, input_size, output_size, rank, world_size, is_reduce = True):
        super(RowParallelLinear, self).__init__()
        self.world_size = world_size if world_size is not None else dist.get_world_size()
        self.rank = rank
        self.input_size = input_size
        self.output_size = output_size
        self.local_input_size = input_size // self.world_size
        self.weight = nn.Parameter(torch.empty(output_size, self.local_input_size))
        self.bias = nn.Parameter(torch.empty(output_size))
        self.is_reduce = is_reduce
    
    def init_weight(self, offset):
        with torch.no_grad():
            weight_values = torch.arange(0, self.weight.numel() * self.world_size).reshape(self.output_size, self.input_size)[:, self.rank * self.local_input_size : (self.rank+1) * self.local_input_size]
            self.weight.copy_(weight_values)
            bias_value = torch.arange(0, self.bias.numel()).float()
            self.bias.copy_(bias_value)
            self.weight += offset
            self.bias += offset
        
    def forward(self, x):
        output_ = F.linear(x, self.weight)
        if self.is_reduce:
            dist.all_reduce(output_, op = dist.ReduceOp.SUM)
        output = output_ + self.bias
        return output

class MultiHeadAttentionTP(nn.Module):
    def __init__(self, embed_dim, num_heads, bias, rank, world_size): 
        super().__init__()
        self.embed_dim = embed_dim
        self.total_num_heads = num_heads
        self.node_num_heads = self.total_num_heads // world_size
        self.node_embed_dim = self.embed_dim // world_size
        self.head_dim = self.embed_dim // self.total_num_heads
        self.scalling = self.head_dim ** -0.5
        self.q_proj = ColumnParallelLinear(self.embed_dim, self.embed_dim, rank, world_size, False)
        self.k_proj = ColumnParallelLinear(self.embed_dim, self.embed_dim, rank, world_size, False)
        self.v_proj = ColumnParallelLinear(self.embed_dim, self.embed_dim, rank, world_size, False)
        self.out_proj = RowParallelLinear(embed_dim, embed_dim, rank, world_size, True)
        self.init_weight()

    def init_weight(self):
        self.q_proj.init_weight(0.1)
        self.k_proj.init_weight(-0.2)
        self.v_proj.init_weight(0.3)
        self.out_proj.init_weight(-0.4)

    # q, k, v: [num_seq,  node_num_heads, seq_len, head_dim]def attention(self, q, k, v):
        scores = torch.matmul(q, k.transpose(-2, -1)) * self.scalling # [num_seq,  node_num_heads, seq_len, seq_len]
```
