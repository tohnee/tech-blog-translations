# 02 DeepSeek Harness

DeepSeek Harness 是 DeepSeek 官方开发的一款开源 AI Agent，采用 MIT 开源许可证。

简单来说，它和我们熟悉的 Codex、Claude Code 属于相近类型的 AI Agent 工具。

你可以通过自然语言向它描述需求，让它帮你读取和修改文件、编写代码、分析数据、处理文档，甚至完成一些比较复杂的任务。

当然，这些功能如今已经算不上稀奇了。

真正吸引我的，是它的设计理念。

**Everything is a Plugin.**

万物皆插件。

看到这句话，我第一时间就想到了自己一直在用的一款笔记软件——Obsidian。

## 2.1 万物皆插件，这个理念我太喜欢了

如果你是一位 Obsidian 用户，应该很容易理解这个理念。

Obsidian 有着非常丰富的插件生态。

可以说它的功能都是由核心插件和社区插件共同搞定的。

你可以按照自己的需求安装插件，增加各种功能。

有的人把 Obsidian 当作纯粹的 Markdown 笔记软件，有的人用它管理知识库、阅读文献，甚至把任务管理、AI Agent 等功能全部整合进去。

**同样一款软件，不同的人最终可能会把它打磨成完全不同的样子。**

这也是我一直喜欢 Obsidian 的重要原因之一。

软件提供基础能力，具体怎么用、能做什么，交给用户自己决定。

而 DeepSeek Harness 让我看到了非常相似的理念。

它基于 Cordis 插件框架开发，整个系统采用高度模块化的设计。

从模型调用、工具、Skills，到 Agent 的运行机制、会话管理、沙箱，甚至部分 UI 功能，都可以通过插件扩展。

也就是说，我们可以根据自己的需求，选择不同的插件来组合所需要的功能。

不需要的功能，可以不启用。

缺少的功能，可以寻找对应的插件。

如果找不到合适的插件，甚至还可以自己开发。

而随着社区不断发展，未来也有机会形成类似 Obsidian 那样的插件生态（现在已经形成了 ）。

以前使用某个软件，遇到自己不喜欢的地方，很多时候只能等待开发者更新。现在借助 AI，我们已经可以自己 Vibe Coding，开发一些符合个人需求的小工具。

DeepSeek Harness 则更进一步，直接把这种扩展能力融入到了 Agent 本身。

比如，官方展示了一个创造模式（Creator Mode）。

你可以直接告诉 Agent：帮我写一个悬浮式番茄钟插件。

随后，它会读取插件开发相关的 Skill、编写插件代码、安装插件，并检查运行效果。

当然，实际生成效果还需要自己验证，但这种使用方式确实很吸引我。

一个可以通过 AI 不断完善自己的 AI Agent。

我觉得这才是「万物皆插件」真正值得期待的地方。

## 2.2 简约的界面，熟悉的操作逻辑

除了插件理念，DeepSeek Harness 的 UI 也是让我非常喜欢的一点。

不知道大家有没有发现，现在有些国产 AI Agent，在界面和交互设计上，都有自己的一套逻辑。

各种面板、按钮、操作入口，再加上一些独特的工作流程。

看起来可能很有特色，但实际用起来，却需要重新适应。

我个人非常不喜欢这种设计。

尤其对于 AI Agent 这样的高频工具，我更在意操作是否直观、简单、顺手。

DeepSeek Harness 就很符合我的审美。

整体界面非常简约，左侧是会话、工作区等主要功能入口，右侧是熟悉的对话区域。

整个布局以及很多操作逻辑，都和 Codex 非常相似。

由于我之前已经使用 Codex 很长时间，因此切换到 DeepSeek Harness 时，几乎没有什么学习成本，打开就是很熟悉的感觉。

这一点，我真的非常喜欢。

我觉得软件设计当然可以创新，但创新应该给用户带来实际价值。

如果只是为了做出差异化，刻意改变用户已经熟悉的操作逻辑，反倒增加了使用成本。

对于一款需要每天使用的软件来说，减少不必要的操作和学习成本，本身就是一种很好的设计。

优秀的交互设计，应该让用户把注意力放在任务本身。

## 2.3 功能方面，同样不简单

前面聊了这么多关于设计理念和 UI 的东西，接下来简单看看它的实际功能。

### 自由配置 AI 模型

虽然是 DeepSeek 官方开发的 Agent，但它也支持接入其他模型。

比如 OpenAI、Anthropic、Kimi、GLM 等模型提供商。

而且它支持自定义 API，兼容常见的 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages 协议。

这意味着，我们可以使用自己已有的 API 服务，按照不同任务选择合适的模型。

对于同时使用多个 AI 模型的人来说，非常实用。

### 从编程到日常办公

DeepSeek Harness 的定位也不局限于编程。

除了常规的代码编写、项目分析、Bug 修复等任务，它还支持文档处理、数据分析等日常办公需求。

比如整理本地文件、分析 Excel 数据、制作 PPT、撰写 Word 文档。

官方还展示了对不同文件格式的预览，以及通过对话反复修改结果的能力。

这也是我很看重的一个方向。

毕竟，对普通用户来说，AI Agent 能否解决工作中的实际问题，比它有多少复杂的技术特性更重要。

### 自动化任务与执行轨迹

DeepSeek Harness 还提供了自动化任务插件。

同时，它还提供执行轨迹查看功能。

可以了解 Agent 调用了哪些工具、执行了哪些命令，以及具体的运行结果。

对于复杂任务，尤其是 AI 编程，这些信息可以帮助我们更方便地排查问题。

# 03 如何使用？

DeepSeek Harness 目前已经提供桌面客户端，支持 macOS 和 Windows。

[https://deepseek.com/harness/](https://deepseek.com/harness/)

如果你和我一样，比较喜欢 GUI，我更推荐直接使用桌面版。

下载安装后，按照界面引导完成登录或模型配置，选择工作区，就可以开始尝试各种任务了。

需要注意，DeepSeek Harness 目前仍然处于预览阶段，部分功能和插件 API 还在持续迭代。

虽然项目本身开源免费，但调用第三方模型 API 会产生费用。另外，涉及运行命令、访问本地文件和第三方插件时，也要注意权限和数据安全。

我目前只敢给在工作区内修改的权限。

# 04 写在最后

写到这里，还是想再聊聊自己的想法。

这些年我使用的软件越来越多，但对于软件的追求，反而越来越简单了。

功能可以丰富，界面和操作一定要尽可能简单。

我不希望为了使用一个工具，花大量时间研究它的操作逻辑。

也不希望一个软件为了所谓的创新，把原本很简单的事情搞得复杂。

而 DeepSeek Harness 给我的第一印象，就是简单、熟悉、可扩展。

尤其是「万物皆插件」的设计，让我看到了它未来的可能性。

就像 Obsidian 一样。

最初安装时，它可能只是一个功能相对简单的软件。

但随着不断添加插件、调整配置、打磨工作流，最终会变成一个非常适合自己的工具。

祝大家玩得愉快！
