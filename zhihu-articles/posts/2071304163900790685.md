## 1 K8S Python客户端

### 1.1 基础配置与连接集群

Kubernetes Python Client支持多种配置方式：

- **集群内配置**：在Pod内部运行时自动获取配置
- **集群外配置**：从kubeconfig文件加载配置
- **多集群管理**：轻松切换不同的Kubernetes集群

**本地集群配置：**如果你在本地运行了Kubernetes集群（如Minikube或Docker Desktop），可以直接使用默认的kubeconfig文件：

```python
from kubernetes import client, config
 
# 加载默认kubeconfig
config.load_kube_config()
 
# 创建API客户端实例
v1 = client.CoreV1Api()
print("成功连接到Kubernetes集群！")
```

**集群内配置：**如果你的应用运行在Kubernetes集群内部，可以使用集群内配置：

```python
from kubernetes import client, config
 
# 加载集群内配置
config.load_incluster_config()
 
# 创建API客户端实例
v1 = client.CoreV1Api()
```

多集群配置：

```python
def connect_multiple_clusters():
    clusters = {
        'prod': '/path/to/prod-kubeconfig',
        'dev': '/path/to/dev-kubeconfig'
    }
    
    apis = {}
    for cluster_name, config_file in clusters.items():
        try:
            config.load_kube_config(config_file=config_file)
            apis[cluster_name] = client.CoreV1Api()
            print(f"成功连接到{cluster_name}集群")
        except Exception as e:
            print(f"连接{cluster_name}集群失败：{str(e)}")
    
    return apis
```

client启用调试日志：

```python
import logging

# Set the logging level to DEBUG
logging.basicConfig(level=logging.DEBUG)

# To see the HTTP requests and responses sent to the Kubernetes API (for debugging network-related issues), 
# configure the urllib3 logger:
logging.getLogger("urllib3").setLevel(logging.DEBUG)
```

**资源操作能力**

通过client库，你可以轻松执行以下操作：

- 创建、更新、删除Deployment、Pod、Service等资源
- 执行Pod命令和端口转发
- 监控资源变化
- 管理自定义资源对象

主要模块功能：

- `client`: 提供各种API操作接口
- `config`: 处理配置文件加载
- `watch`: 用于监控资源变化
- `ApiClient`: 底层API客户端
- `ApiException`: 异常处理

项目提供了大量示例代码，涵盖各种使用场景，位于examples/，examples_asyncio/ 目录下。

### 1.2 动态客户端

Kubernetes Python Client提供了动态客户端功能，可以处理自定义资源

```text
from kubernetes import client, config
from kubernetes.client import dynamic
from kubernetes.client.rest import ApiException
 
config.load_kube_config()
dyn_client = dynamic.DynamicClient(
    client.ApiClient(configuration=config.load_kube_config())
)
 
# 获取自定义资源
try:
    api = dyn_client.resources.get(api_version="example.com/v1", kind="MyCustomResource")
    print(f"成功获取自定义资源: {api}")
except ApiException as e:
    print(f"获取自定义资源失败: {e}")
```

### 1.3 Pod

**列出所有Pod：**

```python
from kubernetes import client, config

config.load_kube_config()

v1 = client.CoreV1Api()
print("Listing pods with their IPs:")
ret = v1.list_pod_for_all_namespaces(watch=False)
for i in ret.items:
    print("%s\t%s\t%s" % (i.status.pod_ip, i.metadata.namespace, i.metadata.name))
```

使用异步方式列出所有Pod（[list_pods.py](https://github.com/kubernetes-client/python/blob/master/examples_asyncio/list_pods.py)）：

```python
import asyncio

from kubernetes.aio import client, config
from kubernetes.aio.client.api_client import ApiClient

async def main():
    await config.load_kube_config()

    async with ApiClient() as api:

        v1 = client.CoreV1Api(api)
        print("Listing pods with their IPs:")
        ret = await v1.list_pod_for_all_namespaces()

        for i in ret.items:
            print(i.status.pod_ip, i.metadata.namespace, i.metadata.name)

if __name__ == "__main__":
    loop = asyncio.get_event_loop()
    loop.run_until_complete(main())
    loop.close()
```

**查询Pod状态**

```python
def get_pod_status(name, namespace="default"):
    v1 = client.CoreV1Api()
    try:
        pod = v1.read_namespaced_pod(name=name, namespace=namespace)
        return {
            "name": pod.metadata.name,
            "status": pod.status.phase,
            "pod_ip": pod.status.pod_ip,
            "host_ip": pod.status.host_ip,
            "start_time": pod.status.start_time,
            "conditions": [
                {
                    "type": condition.type,
                    "status": condition.status
                }
                for condition in pod.status.conditions or []
            ]
        }
    except ApiException as e:
        print(f"获取Pod状态失败：{str(e)}")
        return None
 
# 使用示例
status = get_pod_status("nginx-pod")
print(status)
```

### 1.4 资源监控

以下示例监控命名空间对象上的事件（[​pod_namespace_watch.py](https://github.com/kubernetes-client/python/blob/master/examples_asyncio/watch_namespaces.py)）：

```python
from kubernetes import client, config, watch

# Configs can be set in Configuration class directly or using helper utility
config.load_kube_config()

v1 = client.CoreV1Api()
count = 10
w = watch.Watch()
for event in w.stream(v1.list_namespace, _request_timeout=60):
    print("Event: %s %s" % (event['type'], event['object'].metadata.name))
    count -= 1
    if not count:
        w.stop()

print("Ended.")
```

异步方式（[​watch_namespaces.py](https://github.com/kubernetes-client/python/blob/master/examples_asyncio/watch_namespaces.py)）：

```python
import asyncio

from kubernetes.aio import client, config, watch

async def main():
    await config.load_kube_config()
    v1 = client.CoreV1Api()
    # 监控10个事件后停止
    count = 10
    w = watch.Watch()

    async for event in w.stream(v1.list_namespace, timeout_seconds=10):
        print("Event: {} {}".format(event["type"], event["object"].metadata.name))
        count -= 1
        if not count:
            w.stop()

    print("Ended.")
    # An explicit close is necessary to stop the stream
    # or use async context manager like in example4.py
    await w.close()

if __name__ == "__main__":
    loop = asyncio.get_event_loop()
    loop.run_until_complete(main())
    loop.close()
```

以下是一个监控 Pod 资源使用情况的示例：

```python
from kubernetes import client, config
 
# 加载 kubeconfig 文件
config.load_kube_config()
 
# 创建 API 客户端实例
v1 = client.CoreV1Api()
 
# 列出所有命名空间中的 Pod
ret = v1.list_pod_for_all_namespaces(watch=False)
for pod in ret.items:
    pod_name = pod.metadata.name
    pod_namespace = pod.metadata.namespace
    try:
        # 获取 Pod 的状态信息
        pod_status = v1.read_namespaced_pod_status(name=pod_name, namespace=pod_namespace)
        print(f"Pod: {pod_name}, Namespace: {pod_namespace}, Status: {pod_status.status.phase}")
    except Exception as e:
        print(f"Error getting status for Pod {pod_name}: {e}")
```

以下示例定期获取 Kubernetes 资源的状态信息，如 Pod 的 CPU 和内存使用情况，以便及时发现和处理问题：

```python
from kubernetes import client, config
import time
 
# 加载 kubeconfig 文件
config.load_kube_config()
 
# 创建 MetricsV1beta1Api 客户端实例
metrics_api = client.MetricsV1beta1Api()
 
while True:
    try:
        pod_metrics = metrics_api.list_namespaced_pod_metrics(namespace="default")
        for metric in pod_metrics.items:
            print(f"Pod: {metric.metadata.name}, CPU: {metric.containers[0].usage['cpu']}, Memory: {metric.containers[0].usage['memory']}")
    except Exception as e:
        print(f"Error getting metrics: {e}")
    time.sleep(60)
```

### 1.5 Deployment

创建和更新 Deployment 的示例（[​deployment_create.py](https://github.com/kubernetes-client/python/blob/master/examples/deployment_create.py)）：

```python
from kubernetes import client, config
 
# 加载 kubeconfig 文件
config.load_kube_config()
 
# 创建 API 客户端实例
apps_v1 = client.AppsV1Api()
 
# 定义 Deployment 规格
deployment_manifest = {
    'apiVersion': 'apps/v1',
    'kind': 'Deployment',
    'metadata': {
        'name': 'my-deployment'
    },
    'spec': {
        'replicas': 3,
        'selector': {
            'matchLabels': {
                'app': 'nginx'
            }
        },
        'template': {
            'metadata': {
                'labels': {
                    'app': 'nginx'
                }
            },
            'spec': {
                'containers': [{
                    'image': 'nginx:1.14.2',
                    'name': 'nginx',
                    'ports': [{'containerPort': 80}]
                }]
            }
        }
    }
}
 
# 创建 Deployment
apps_v1.create_namespaced_deployment(namespace='default', body=deployment_manifest)
 
# 更新 Deployment 的镜像版本
deployment_manifest['spec']['template']['spec']['containers'][0]['image'] = 'nginx:1.16.1'
apps_v1.patch_namespaced_deployment(name='my-deployment', namespace='default', body=deployment_manifest)
```

### 1.6 Service

创建Service：

```python
def create_service(name, selector, port, target_port, namespace="default"):
    # 创建Service对象
    service = client.V1Service(
        metadata=client.V1ObjectMeta(name=name),
        spec=client.V1ServiceSpec(
            selector=selector,
            ports=[client.V1ServicePort(
                port=port,
                target_port=target_port
            )]
        )
    )
    
    v1 = client.CoreV1Api()
    
    try:
        # 创建Service
        api_response = v1.create_namespaced_service(
            namespace=namespace,
            body=service
        )
        print(f"Service {name} 创建成功")
        return api_response
    except ApiException as e:
        print(f"Service创建失败：{str(e)}")
        return None
 
# 使用示例
create_service(
    "nginx-service",
    {"app": "nginx-deployment"},
    80,
    80
)
```

更新Service：

```python
def update_deployment(name, new_image, namespace="default"):
    apps_v1 = client.AppsV1Api()
    
    try:
        # 获取现有deployment
        deployment = apps_v1.read_namespaced_deployment(name, namespace)
        
        # 更新镜像
        deployment.spec.template.spec.containers[0].image = new_image
        
        # 应用更新
        api_response = apps_v1.patch_namespaced_deployment(
            name=name,
            namespace=namespace,
            body=deployment
        )
        print(f"Deployment {name} 更新成功")
        return api_response
    except ApiException as e:
        print(f"Deployment更新失败：{str(e)}")
        return None
 
# 使用示例
update_deployment("nginx-deployment", "nginx:1.19")
```

创建Secret：

```python
import base64
 
def create_secret(name, data, namespace="default"):
    # 编码数据
    encoded_data = {
        k: base64.b64encode(v.encode()).decode()
        for k, v in data.items()
    }
    
    # 创建Secret对象
    secret = client.V1Secret(
        metadata=client.V1ObjectMeta(name=name),
        type="Opaque",
        data=encoded_data
    )
    
    v1 = client.CoreV1Api()
    
    try:
        # 创建Secret
        api_response = v1.create_namespaced_secret(
            namespace=namespace,
            body=secret
        )
        print(f"Secret {name} 创建成功")
        return api_response
    except ApiException as e:
        print(f"Secret创建失败：{str(e)}")
        return None
 
# 使用示例
secret_data = {
    "username": "admin",
    "password": "secret123"
}
create_secret("app-secrets", secret_data)
```

### 1.8 自动化部署

可以编写 Python 脚本，根据不同的环境（如开发、测试、生产）自动部署应用。例如，在开发环境中部署一个单副本的 Deployment，在生产环境中部署多个副本：

```python
from kubernetes import client, config
 
# 加载 kubeconfig 文件
config.load_kube_config()
 
# 创建 AppsV1Api 客户端实例
apps_v1 = client.AppsV1Api()
 
# 根据环境设置副本数
env = "production"
replicas = 3 if env == "production" else 1
 
# 定义 Deployment 配置
deployment = client.V1Deployment(
    api_version="apps/v1",
    kind="Deployment",
    metadata=client.V1ObjectMeta(name="my-app-deployment"),
    spec=client.V1DeploymentSpec(
        replicas=replicas,
        selector=client.V1LabelSelector(
            match_labels={"app": "my-app"}
        ),
        template=client.V1PodTemplateSpec(
            metadata=client.V1ObjectMeta(
                labels={"app": "my-app"}
            ),
            spec=client.V1PodSpec(
                containers=[
                    client.V1Container(
                        name="my-app",
                        image="my-app:latest",
                        ports=[client.V1ContainerPort(container_port=8080)]
                    )
                ]
            )
        )
    )
)
 
# 创建 Deployment
apps_v1.create_namespaced_deployment(
    namespace="default",
    body=deployment
)
```

### 1.9 资源创建和管理

大概分两类：

1. 不需要指定什么类型的资源，根据给出的资源清单创建文件。
2. 创建什么资源就用什么特定的接口。

（1）主要接口列表：

**通过yaml文件创建资源：**utils.create_from_yaml(client, ...) 。

**通过文件夹创建资源：**utils.create_from_directory(client, yaml_dir=...) 。

**通过字典创建资源：**utils.create_from_dict(k8s_client, data=data, verbose=True) 。

**通过专门接口创建资源：**

Pod创建：v1.create_namespaced_pod() 。

Pod查询：v1.read_namespaced_pod() 。

Deployment创建：v1.create_namespaced_deployment() 。

Service创建：v1.create_namespaced_service() 。

ConfigMap创建：v1.create_namespaced_config_map() 。

Secret创建：v1.create_namespaced_secret() 。

自定义资源CRD：custom_api.create_namespaced_custom_object() 。

（2）资源管理：以Deployment为例

删除： api.delete_namespaced_deployment(namespace=ns, name=deploy_name) 。

查询：api.read_namespaced_deployment(namespace=ns, name=deploy_name) 。

修改：api.patch_namespaced_deployment(...) 。
