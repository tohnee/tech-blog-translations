```text
from sklearn.linear_model import LinearRegression

X = [[1], [2], [3], [4], [5]]       # 特征/属性
# 规律我们提前知道了，就是2x + 1
# y真实值，在2x + 1的基础上加一点噪声
y = [3.1, 4.9, 7.2, 8.8, 11.1]		# 标签

model = LinearRegression() 		# 线性回归模型
model.fit(X, y) 				# fit就是让这个模型从X开始找规律去匹配y

# 模型学到规律后，最后我们用predict进行预测
print(model.predict([[8]]))
```

**简单的线性回归模型**

| 代码 | 含义 | 说明 |
| --- | --- | --- |
| model.predict([[9]]) | 用训练好的模型预测输入为 9 时的输出 | [[9]] 是一个二维数组，表示 1 个样本、1 个特征 |
| model.coef_ | 输出模型学到的回归系数 | 对应线性公式里的权重，例如 w1, w2, ... |
| model.intercept_ | 输出模型学到的截距 | 对应线性公式里的常数项 b |

coef_=1.99

intercept_=1.05

分类
1. 导入、下载数据
import numpy as np
from sklearn.datasets import fetch_openml

mnist = fetch_openml('mnist_784', version=1, as_frame=False) # 从网上下载mnist数据集
# 70000个样本/行，每个样本有784个特征/列，最后一列是标签
X, y = mnist["data"], mnist["target"]

2. 将数据的某一行打印出来看看
img = X[0].reshape(28, 28).astype(np.uint8)
for row in img:
    print(''.join(f'{num:4d}' for num in row))

3. 取前60000行作为训练集，用来训练模型
X_train, y_train = X[:60000], y[:60000]
# 训练集的特征部分，训练集的标签部分

# 我门下面要解决二分类问题，即非黑即白，这里用的是5和非5
y_train_5 = (y_train == '5')  # 这里的shape应该是60000，1，结果都是True或者False

4. 创建一个分类用的模型SGDClassifier并学习规律
from sklearn.linear_model import SGDClassifier  # Classifier分类

sgd_clf = SGDClassifier(random_state=42)
sgd_clf.fit(X_train, y_train_5)  # 找规律，哪些结果是真，哪些是假 

5. 找前20个数据进行预测，看看模型学的效果
for i in range(20):
    print(sgd_clf.predict([X[i]]), y[i])

6. 计算准确率和召回率
X_test, y_test = X[60000:], y[60000:]  # 取了数据的最后1万行，用来评估模型效果
y_test_5 = (y_test == '5')

y_pred = sgd_clf.predict(X_test)

from sklearn.metrics import accuracy_score, recall_score

print("准确率:", accuracy_score(y_test_5, y_pred))  	# 对某个样本的判断是否准确
print("召回率:", recall_score(y_test_5, y_pred))		# 是否找到所有的5

抓小偷的例子来解释准确和召回，假设有100个小偷都放到街上，街上肯定还有其他人。
准确率用来衡量：你抓一个人回来，他必须是小偷，这样准确率才高。
召回率用来衡量：你是不是把所有的小偷都抓住了。

这两个指标互相排斥。

```text
from sklearn.linear_model import LinearRegression

X = [[1], [2], [3], [4], [5]]       # 特征/属性
# 规律我们提前知道了，就是2x + 1
# y真实值，在2x + 1的基础上加一点噪声
y = [3.1, 4.9, 7.2, 8.8, 11.1]		# 标签

model = LinearRegression() 		# 线性回归模型
model.fit(X, y) 				# fit就是让这个模型从X开始找规律去匹配y

# 模型学到规律后，最后我们用predict进行预测
print(model.predict([[8]]))

print(model.coef_)
print(model.intercept_)

# 回归问题的评价指标呢？RMSE，这个数值越小越好，即预测的和真实的非常接近。
from sklearn.metrics import root_mean_squared_error
y_pred = model.predict(X)
print("RMSE:", root_mean_squared_error(y, y_pred))
```
