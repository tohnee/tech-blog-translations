## 【ICLR 2026】FLARE: Fully Integration of Vision-Language Representations for Deep Cross-Modal Understanding

**作者列表**：Zheng Liu, Mengjie Liu, Jingzhou Chen, Jingwei Xu, Bin Cui, Conghui He, Wentao Zhang（北京大学 / 上海人工智能实验室 / 南京大学）

**代码链接**：[https://github.com/starriver030515/FLARE](https://github.com/starriver030515/FLARE)

### 文章概述

该工作针对当前 VLM 普遍沿用的”视觉编码→投影→LLM 解码”分段式管线把跨模态交互推迟到解码阶段这一痛点，提出贯穿全流程的视觉-语言深度融合范式 FLARE。论文设计了三个关键模块：(1) **Text-Guided Vision Encoding（文本引导视觉编码）**，将问题文本嵌入经 `MLP_t2v` 投影后拼接到视觉 token 上并共同送入视觉编码器，前半层屏蔽视觉→文本注意力以保留基础视觉特征，后半层放开双向交互以获得查询敏感的视觉表征；(2) **Context-Aware Alignment Decoding（上下文感知对齐解码）**，在标准 LLM 解码层之间插入”语义交换层”，让潜在 token 携带当前已生成文本的上下文对视觉 token 做交叉注意力，使视觉表征在解码每一步被动态刷新；(3) **Dual-Semantic Mapping Loss（双语义映射损失）**，在 `MLP_v2t` 与 `MLP_t2v` 之间构造双向重建目标 `L_v2t + L_t2v`（λ=0.1）以抑制”嵌入错位”，保证”猫”在视觉与文本空间中语义一致。FLARE 同步提出”文本驱动 VQA 合成”数据管线，由 LLaMA-3.1-70B 扩写复杂描述、FLUX 生成图像、多阶段 CLIP+MLLM 过滤，最终产出 ~400 万高质量问答对。3B 模型在仅用 630 视觉 token 时即超越 Cambrian-1 8B 与 Florence-VL 8B，固定分辨率版也优于 LLaVA-NeXT，验证了”融合深度比 token 数量更关键”。

## 【NeurIPS 2025】MokA: Multimodal Low-Rank Adaptation for MLLMs

**作者列表**：Yake Wei, Yu Miao, Dongzhan Zhou, Di Hu（中国人民大学高瓴人工智能学院 GeWu Lab / 上海人工智能实验室）

**代码链接**：[https://github.com/GeWu-Lab/MokA](https://github.com/GeWu-Lab/MokA)

### 文章概述

该工作针对多模态大语言模型（MLLM）参数高效微调中”文本模态主导、视听模态适配不足”的结构性问题，提出多模态感知低秩适配策略 MokA。论文首先通过”部分模态推理”诊断实验量化了传统 LoRA 共享低秩参数被文本 token 主导的现象，进而重新设计 ΔW = BA 分解中 A、B 矩阵的角色：A 矩阵按模态拆分为音频专属、视觉专属、文本专属三套低秩投影，各自独立压缩本模态 token；在此基础上引入”任务中心跨模态注意力”，以文本特征为 K/V、非文本特征为 Query 进行显式跨模态语义交互（K/V 共享 A_t，无需额外 W_q/W_k/W_v）；最后通过共享 B 矩阵将增强后的多模态表示投影到统一空间完成隐式对齐。论文在音-视-文（MUSIC-AVQA、AVE）、视-文（POPE、MME 等）、语音-文（AIR-Bench、MMAU-mini）三种场景、4 种 LLM 骨干上仅以 1.33% 可训练参数（LoRA 1.27% → 1.33%）、1.069× 推理时延实现全面领先（典型如 MUSIC-AVQA 73.41→75.71，AIR-Bench 31.75→39.64），并验证了向 4 模态（音+视+点云+文）的可扩展性。

## 【ICML 2025】M3-JEPA: Multimodal Alignment via Multi-gate MoE based on the Joint-Embedding Predictive Architecture

**作者列表**：Hongyang Lei, Xiaolong Cheng, Qi Qin, Dan Wang, Huazhen Huang, Yetao Wu, Qingqing Gu, Luo Ji（Geely AI Lab / 北京大学 / 中科院深圳先进技术研究院）

**代码链接**：[https://github.com/HongyangLL/M3-JEPA](https://github.com/HongyangLL/M3-JEPA)

### 文章概述

该工作跳出当前主流的”在 token 空间做跨模态对齐”范式，指出 token 级对齐易因梯度冲突、连续-离散域差异、信息多对多歧义而陷入模态坍缩，进而将 LeCun 提出的 Joint-Embedding Predictive Architecture (JEPA) 推广到任意模态组合的”任意对任意”对齐 M3-JEPA。论文让输入与输出模态分别由冻结的预训练单模态编码器（Llama3-8B / DINOv2-Large / LanguageBind）编码为嵌入，再由 **多门控 MoE 预测器 P** 把输入嵌入投射到输出嵌入所在的潜空间，并以能量函数 F_t(x,y) 度量二者距离，在潜空间而非 token 空间完成对齐。关键设计包括：(1) **解耦门控机制**——每个模态 N=12 个专家、Top-K=4 稀疏激活，门控把”模态嵌入 e_m”与输入嵌入拼接后 softmax 解耦出”模态特异 + 共享”信息；(2) **双门控 L=2 通道**——分别服务对比损失与正则损失，进一步减少任务间干扰；(3) **交替梯度下降（AGD）**——按 uni-direction 任务循环优化，规避多方向任务的梯度冲突。整套系统仅 140M 训练参数（编码器 LoRA rank=64 + MoE 预测器）即在多个跨模态检索/分类任务上击败 1.2B 参数的 BLIP-2，并为开放世界自监督多模态学习提供可迁移到未见模态的基础。

## 【CVPR 2025】Multi-Layer Visual Feature Fusion in Multimodal LLMs: Methods, Analysis, and Best Practices

**作者列表**：Junyan Lin, Haoran Chen, Yue Fan, Yingqi Fan, Xin Jin, Hui Su, Jinlan Fu, Xiaoyu Shen（宁波数字孪生研究院 EIT / Genmo.ai / Meituan / NUS）

**代码链接**：[https://github.com/EIT-NLP/Layer_Select_Fuse_for_MLLM](https://github.com/EIT-NLP/Layer_Select_Fuse_for_MLLM)

### 文章概述

该工作没有提出新模型，而是首次系统性地对 MLLM 中”多层级视觉特征如何融合”这一长期被凭直觉决定的问题做了地毯式消融。研究者把视觉融合问题解耦为两个独立维度并分别穷举：(1) **层级选择**——以”表征相似度”为依据把视觉编码器层级划分为初/中/末三个阶段，分别取各阶段 1 个代表层、共 3 层的组合作为视觉表征；(2) **融合策略**——按”融合位置（外部输入 vs 内部注入）”和”融合模式（模块化 vs 直接融合）”两两组合成 4 大范式，并在 6 个主流 MLLM（LLaVA-1.5、LLaVA-NeXT、Qwen-VL、MiniGPT-4、mPLUG-Owl、InstructBLIP）上做了大规模对照实验。两个关键结论被严格验证：① 跨阶段取一层（初+中+末）优于同阶段多层堆叠，多层堆叠常因冗余和分布冲突而性能下滑；② 在 LLM 输入端”外部直接融合”始终优于”内部注入”和”额外融合模块”，后者要么需要修改 LLM 内部结构、要么引入额外参数和训练不稳定。该工作因而成为 MLLM 视觉融合”黄金法则”的实验依据，并推动了后续如 TGIF、SCVM 等查询条件式层级融合研究的兴起。
