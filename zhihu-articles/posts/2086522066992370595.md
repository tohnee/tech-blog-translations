上一篇把 Agent 的工作原理大致介绍了一遍。不管是想找这方面的工作，还是自己动手做开发，都得再往深里学。这几天我整理了一些教程，分享给你。

---

### 电子书

### 《深入理解 AI Agent：设计原理与工程实践》

作者李博杰，中科大少年班出身，计算机博士，华为首批“天才少年”计划入选者。这本书围绕 Agent = LLM + 上下文 + 工具 展开，能在线读，也能下载 PDF（GitHub Star 50.7K）。

地址： [深入理解 AI Agent](https://bojieli.github.io/ai-agent-book/)

### 《Hello-Agents》

Datawhale 社区开源的一本智能体教程，带你使用原生大模型 API 从零手搓一个 Agent 架构，彻底吃透 ReAct（推理+行动）、规划（Plan-and-Solve）、反思（Reflection）等核心范式在代码层的实现逻辑。

地址： [Hello-Agents](https://hello-agents.datawhale.cc/)

---

### 视频

李宏毅的 AI Agent 系列课。B 站搜“李宏毅 AI Agent”有完整搬运，中文里讲得最清楚的之一，一讲一小时左右，适合当长节目看 [出错啦! - bilibili.com](https://space.bilibili.com/3706959322679983)

 马克的技术工作坊。B 站空间： [出错啦! - bilibili.com](https://space.bilibili.com/1815948385) ，内容偏 AI 编程实战，聊怎么把 AI 用进日常工作流。 

---

### 学习顺序

刚入门的，建议先读上面两本电子书打底，再学 LangChain / LangGraph。学 LangChain / LangGraph 可以直接跟着《Deep Agents 实战》动手，Datawhale 出品的中文开源课，基于 LangChain / LangGraph 生态，从第一个 Agent 讲到子 Agent 协作和上下文管理。

地址： [https://datawhalechina.github.io/deepagents-in-action/](https://datawhalechina.github.io/deepagents-in-action/)

在极客时间也能找到几门课，按自己的熟练程度挑。
