### 管理咨询报告 是 AI 理想的颠覆场景

咨询报告市场利润丰厚，仅管理咨询一个分支，据福布斯统计，其2024年的全球市场规模就已突破1万亿美元。其中，麦肯锡、波士顿咨询（BCG）和贝恩公司分别以135亿、120亿和60亿美元的营收领跑。一份由3到5名顶尖顾问耗时数周精心打造的战略报告，通常意味着客户需要为此支付数十万乃至数百万美元的昂贵费用。

理论上，这种输入输出主要为文本，涉及海量阅读、逻辑梳理和叙事构建为核心的咨询工作，正是Manus、Coze空间、Deep Research等AI产品的理想颠覆领域。毕竟，相比于让Agent扮演HR或虚拟伴侣，一个每月仅需十几美元的AI直接取代年薪20万美元的咨询顾问，无疑是更能点燃投资人热情的AGI叙事。

然而，时至今日。

当面对“如何在12个月内提升NVIDIA的利润率？”或“Cerebras、Groq等AI专用芯片是否会冲击NVIDIA在数据中心的主导地位？”这类复杂的战略问题时，一位麦肯锡研究员的分析和洞察必须建立在极高信度的数据之上——例如，详尽的供应链成本结构（台积电CoWoS封装成本占比）、精确的客户构成（云服务商与企业客户的比例及合同条款细则）等等。

现在Manus、Coze空间主要使用网络搜索作为信息来源，在面对交付质量要求极高的管理咨询类任务而言，并不是非常可靠的数据源。所以我们可以看到现在的通用 Agent 只能交付不那么“严肃”的报告，诸如《查询 YC 的 B2B 初创公司》《橡胶垫的供应商寻源》这类图文并茂、数据堆叠但缺乏洞察和实际可行建议的结果。

这种现状形成了一个微妙的闭环：由于通用Agent产品与用户之间的关系尚不“严肃”，用户并未支付高昂的咨询费用，因此也默许了其产出质量的局限性。不可靠的数据源持续生成着“不严肃”的报告，这反过来又将Deep Research这类产品牢牢地困在了一个“廉价沙盒”之中，使其难以真正涉足严肃的管理咨询服务。

也许有人会说“尽管数据层面表现不济”，但这类产品的芯是好的。一旦我们为其接入高质量的数据来源，构建一个垂直知识的 RAG 系统，就能够使现金基于 ReAct 作为 Agent 核心 + Plan-and-Execute 作为 Agent 编排的 Deep Research 产品，产出足够具有洞察力和逻辑，能够让用户愿意长期付费的成果。但基于我的实验、观察和分析，仅仅解决数据源信度的问题，还远远不足以让 Manus 这类 Agent 产品摆脱当前的困境。

### 多智能体编排的目标

未来也许 Agent 可以像是 AlphaGo Zero 的一样，能够沿着与人类完全不同的思路获得惊人的结果。 **但至少在当下，评价一个Agent的优劣仍然取决于其是否能够完美“复刻” 优秀人类的思维活动。**

**换句话说对于研报场景来说，如何在不引入端到端 **强化学习 和 外部数据信度受限的前提下，通过多*智能体* 的编排和设计，产出能够威胁专业投研顾问职业的报告。**

> 现在越来越多证据显示 CoT 中只常见的副词转折等少数 Critical  Token 会对推理结果产生重大影响，最终的 Reward 信号对推理过程没有那么大影响。CoT 有效的原因，多是因为出现在解数学题的一些思维活动诸如反思能够有效迁移到其他任务上，产生收益。

**多 *智能体* 编排的目标是 *递归* 式改进自我提升(Recursive Self-Improvement)，允许通过运行轮次的增加，稳定提升整体 Agent 系统在特定任务下至少某一个评测维度的性能。** 提升曲线越陡峭，系统的 **Scaling 潜力** 越大，系统的上限更高；越有更多的任务能够获得递归自我提升，系统的 **任务通用性** 越高；提升的维度越广泛，系统的 **泛化能力** 越强，意味这模型学到了更加本质的模式。在这三个维度协同进化的智能体系统，将共同构建一个能够自主学习、持续进化并解决更广泛、更复杂问题的通用智能框架，最终展现出通往通用人工智能（AGI）的清晰路径。对于企业来说，一个自我进化的智能体系统不但更有可能的直接解决客户问题，在万亿美元的 **数字劳工市场(Digital Labour)** 中拔得头筹，更加能够通过康斯坦丁·布勒尔描述的“自我进化数据飞轮”获得基于真实业务场景驱动，不断自我强化的技术壁垒，创造出相比随时间推移而贬值的传统静态 IT 系统无法匹敌的竞争优势，和竞争对手不断拉开差距。

> 我曾以为AlphaGo只是基于概率计算的机器。但当我看到这一手棋时，我改变了想法。毫无疑问，AlphaGo是具有创造力的。--- 李世石

### 澄清当前技术范式

当我们畅享AGI能够为我们的生活和经济发展带来天翻地覆的变化时，现状却让我们尴尬。大模型已经在各种 Benchmark 出现媲美顶尖 PhD 学生的能力，但却无法完成简单的日常工作，这一现象被成为克拉维夫悖论。除了少数特定场景，如写文案，文生图等，大部分真实的工作场景大模型还很难直接发挥作用。做Agent的目标也很清晰直接，就是要补上这个低能的短板，让模型真的有能力去自己干活，产生经济价值。

基于此我们有必要澄清当前技术范式的基本特性，作为讨论的基础，以免陷入对 AGI 发展的过度自信(利益相关方)和不屑一顾将LLM视为“高级鹦鹉”(e.g.LeCun) 的二边论中：

1. **基于数据驱动的本质** ：现在的大模型通过海量文本的“阅读”，使用神经网络建模词与词之间复杂的依赖关系，不断预测下一个词(Next Token Prediction, NTP)。如果我们让 GPT-4 玩剪刀石头布的游戏并统计其出拳类型，我们会发现GPT-4 出 石头的频率 会远远高于布和剪刀。其原因在于GPT-4 训练主要使用的英语语料中，rock 自然频率本身就远远高于 paper 和  scissors. 模型训练的数据来自于人类也服务于人类，其学习到的模式本身就是一种来自于人类社会结构的映射。这是当今大模型强大能力的来源，也限制了其进一步发展成为纯粹理性机器的可能性。模型中存在的各种偏见——无论是性别、种族、文化还是价值观上的——都不是程序中的“bug”，而是其“基因”中不可分割的一部分，是人类社会千百年来各种偏见与不平等的真实回响。因此当前技术范式下的 AGI 发展，研究人员创造的更像是一个 “集大成的平均人”。这个“平均人” 博学强记，能模仿人类社会中绝大多数的知识与技能，但他同时也继承了人类社会的平均偏见、平均认知局限和平均的思维惯性。换句话说，大模型其底层的的确确是一种数据驱动的模式识别，但是这种技术范式的上限在哪儿？能否指引我们通往 AGI 没有人能够给出确切答案。
2. **长上下文和编码位置外推问题** ：要让大模型在真实世界任务中发挥作用，长上下文处理能力是核心前提。无论是分析长篇报告、维持长期对话，还是理解大型代码库，都要求模型具备稳定处理海量信息的能力。然而，当前技术范式在扩展上下文窗口时面临着性能衰退的根本性挑战。首先是注意力机制的有效性问题。随着序列长度 n 的增加，模型需要处理的信息量也随之增长。标准的注意力机制需要计算每个词元（Token）与所有其他词元之间的关系。当上下文变得极长时，关键信息可能被大量不相关的中间内容稀释，导致模型难以维持对远距离关键信息的精确关注，这一现象被称为“迷失在中间”（Lost in the Middle）。最后是无法回避的计算复杂度。标准自注意力机制的时间与空间复杂度均为序列长度的平方，即 O(n2)。这意味着将上下文窗口加倍，所需的计算资源和内存将增至四倍，这种二次方增长使得暴力扩展上下文窗口在经济和硬件上都变得极为困难。为了解决这个问题，研究界开发了多种线性注意力（Linear Attention）的近似算法，试图将复杂度降至 O(n)。然而，天下没有免费的午餐。从MLP（多层感知机）的角度看，这些线性化近似方案本质上是在信息进入核心处理层之前就对其进行了一种“有损压缩”。标准注意力机制之所以强大，在于其能为序列中的任意两个位置动态计算出一个精确、独特的权重，而线性化方案则牺牲了这种点对点的精细交互能力来换取效率。这导致输入给后续MLP层的信息质量大幅下降，模型进行复杂推理的能力也随之削弱。业界对模型结构的计算效率和性能上限的取舍仍在探索当中。其次是位置编码的外推（Extrapolation）难题。Transformer架构本身对顺序不敏感，依赖于位置编码来注入序列的顺序信息。许多位置编码方法在固定的窗口长度（例如8K）内进行训练，当输入序列超过这个长度时，模型会遇到其训练期间从未见过的位置索引，导致其对序列结构的理解能力下降。尽管如RoPE、YaRN、Alib 等相对位置编码方案改善了外推性，但性能衰退的趋势依然存在，只是被一定程度地延缓。
3. **永远无法用“完美”的数据穷尽所有可能的输入分布** ：那么我们有没有可能在训练时针对剪刀石头布的这样的场景主动构建数据来弥补“偏见”呢。对于单一场景的确可行，我们可以通过后训练的方式强制收束一小部分输入 Token 的输出概率分布。但是永远不可能穷尽所有场景，一个 Llama3 模型的词表大小为 12.8 万，窗口长度(W)为 8K，其所有可能的输入长度 L 组合数量大约是 $(1.28 * 10^5)^{L}, {L < W} $ , 远远大于宇宙中的所有原子  $10^{80}$ 。这还只是输入，每一个输出都对应着 $(1.28*10^5) ^ {8192 - L}$ 的可能性。而今模型训练的语料大约在 20T Token 左右，就算剔除输入输出组合中没有语义内涵的大部分乱码，并充分考虑神经网络的泛化能力，也无法从弥合训练数据的有限性与潜在输入空间无限性之间的巨大鸿沟。神经网络的泛化，更像是基于稀疏观测点对一个无比广阔的、未知的语义空间进行的“插值”计算，而非真正意义上的、对于世界，对于物自体的归纳与推理。

4. **缺乏因果推断** ：人类天生就不满足于仅仅知道“ **发生了什么(What)”** ，我们更渴望知道 **“为什么会发生(Why)”** 和 **“如果……会怎样（What if...）"** 。比如政府想知道是“降息”导致了“经济增长”，还是由第三个混淆变量(如全球市场复苏）驱动；医生想知道是“新药”导致了“病情好转”，而不是仅仅发现“吃了药”和“病好了”这两个现象经常一起发生(安慰剂效应)。错误的归因会导致灾难性的后果。这种探究因果的好奇心，是我们理解世界、做出决策和推动科学进步的核心驱力，也是人类智能与如今机器智能最核心的区别。在一个没有因果推断的世界中，“公鸡打鸣”和“太阳升起”只是两个碰巧总是一起发生的独立事件，我们会看到事件一个接一个地发生，就像看一部没有逻辑的电影，虽然知道事件的每一个细节，却永远无法理解故事的时间线和发展脉络，而这就是以最大化序列联合概率分布 LLM 所处的世界。这种局限在人类进行因果判断的核心工具，“如果……会怎样（What if...）”的 **反事实思考** 中暴露无遗。人类可以轻易地在脑中进行模拟：“ **如果** 当时我们没有批准那个新药，病人的康复率 **会** 怎样？”而LLM 不行。 这种在精神世界中对不同可能性进行干预和推演的能力，是制定计划、吸取教训、进行科学探索的基础。更加可怕的是，缺乏负向样本训练的 LLM 当在被要求解释原因是，它会自信的给出一个语义上最通顺、统计上最常见的回答，给使用者造成可能致命的误导(aka幻觉)。在你询问 AI 为什么某个股票上涨原因时，它可能会综合新闻标题和股评，给出一个关于公司财报的“标准答案”，即使真正的原因可能是一个突发的、数据中未体现的市场传闻。其次，它使得任何基于 LLM 的智能体在需要真正规划和决策时都表现得极为脆弱。 **真正的规划需要理解行动与后果之间的因果链条** 。如果一个 Agent 无法判断 “踩油门” 是 “车速加快”的原因，那么就会在突发状况(e.g.刹车失灵) 时做出正确的、基于因果链的判断，只能无助地重复它在训练数据中学到的僵化行为模式，直接限制了 Agent 的自主性和鲁棒性。最后，科学方法论依赖于提出假说（因果模型）并通过实验来验证。LLM 可以作为强大的工具，帮助科学家整理和分析现有文献，发现潜在的相关性。但它本身无法提出一个全新的、与现有数据不完全一致但可能更根本的因果假说。它更像是一个无所不知的“文献综述者”，而不具备类似牛顿图灵莱布尼茨具备批判性思考，开宗立派的可能性。换句话说，一旦 Agent 具备了能够为一个立场推理出足够长足够可靠的因果链条，一个具备广泛知识储备、理论上拥有无限工作记忆、不知疲惫专注力超强、能够接入互联网的AI 系统时，人类就拥有了一个极大极大扩展知识边界攀登理性长梯的工具。

> 坏消息：现在大模型不具备因果推断的能力。 
>  好消息：人类一开始的也不具备的，或者说人类一开始只有一种对因果关系探求的冲动，具体的方法论是在文明发展中构建探索出来的。

**5. 缺乏对时空逻辑的把握** ：OK 那么如何让模型超越简单的“模式匹配”真正认识世界学会推理呢？从认识论的角度回顾，人类所引以为傲的智能的形成是一个从具体到抽象的层级过程。我们首先通过感官与物理世界互动，形成 **感性经验** （如冷暖、软硬、远近）。在此基础上，使用心灵结构的先验范畴对这些经验素材进行整理、归类，形成概念、范畴等 **知性认识** （比如“杯子”这个概念，背后是无数次看到、触摸、使用杯子的经验集合）。最终，我们运用逻辑和符号，在这些概念之上进行 **理性推理** 。这个过程表明，人类智能这一我们唯一知道的智慧形式，依赖与物理世界的互动，文 **本更大程度上是这一认识过程的终末产物** ，是为了人类高效记录和传播而对自身已经完成归纳的、多模态的、蕴含时空因果与经验素材的后天抽象归纳和符号化编码。一句“猫在垫子上”，其背后是关于“猫”的形态与动态、“垫子”的材质与功能、以及“在…之上”这一空间关系的无数真实世界经验的压缩。认识到文本的这一特性就不难理解 LLM 如何为何能够通过单纯的 Scaling 获得惊人能力。其关键点 LLM 对文本采用的自回归预测(NTP) 和 因果建模(Causal Masking) 和 人类心灵结构具备一种“幸运”的同构性(Isomorphism)，允许使用概率建模实现对数据理解和生成的统一，因为人类的书写与阅读习惯，天然就是线性的、有时序的。我们总是在已有上文的基础上，预测和生成下一个词，它在结构上恰好模拟了人类语言思维的单向流动过程。此外，语言中的 **介词（如“在、从、向”）与连词（如“因为、所以、如果”）** ，这些看似不起眼的虚词，正是人类将物理世界的时空关系和逻辑因果关系编码进一维文本的关键组件。它们构建了一个庞大的“能指网络”，让模型在学习词与词之间的统计关系时，也间接吸收了背后由人类心智整理好的时空与逻辑结构。因此，LLM的Scaling，本质上是在一个与人类心智高度匹配的“游戏场”里进行的，数据本身已经为模型铺好了通往智能的轨道。

然而，当我们试图将这一成功范式移植到图像或视频领域时，这种“幸运同构”便不复存在了。问题在于，像素

据与人类的知性感知之间，存在着三个层面的 **根本性“割裂”** ：

- **数据性质的割裂** ：与经过人类心智高度提纯的文本不同，图像和视频是客观存在于自然界的原始物理信号。对像素（Pixel）的概率建模，是在一个与人类概念体系完全异构的空间里进行的。预测下一个像素的颜色，和理解“一只猫跳上桌子”这一事件，是两个认知上毫不相干的任务。
- **建模与感知的割裂** ：一个模型可以完美地学习到像素的统计分布，从而生成一张照片般逼真的图像，但它本身对图像内容的知性理解（e.g., 透视关系、光影原理、物体间的物理交互）可能为零。概率建模的成功，并不自然地蕴含对世界常识的掌握。
- **生成与推理的割裂** ：模型可以生成一段“汽车在行驶”的视频，但当被问及“如果轮胎掉了会怎样？”时，它无法基于对物理世界的因果推理来回答，而只能回到数据中寻找相似的文本描述或视觉场景。

这三个维度的割裂，导致了业界期望通过预训练一个超大规模的图像视频模型，来让空间感知、物理常识等智能“自然涌现”的愿望在很大程度上落空。它解释了为何即便在海量视频数据上训练，模型依然难以掌握最基本的物理因果和空间逻辑。当然，也有可能我们或许正处在多模态的“GPT-2时刻”， **远远低估了实现智能涌现所需的数据量级** 。但无论如何，上述的“割裂”清晰地指出了当前范式在从语言走向更广阔的物理世界时，所面临的深刻挑战。

> 更加康德的角度来解释。人类心智并非一块被动接收经验的“白板”（Tabula Rasa），而是自带一套“操作系统”——即 **时空直观形式** 与 **先天知性范畴** （尤其是因果性）。它们是构成一切有效经验的 **先决条件 (a priori)** 。LLM处理的文本数据，并非原始的、混沌的世界本身（物自体/Noumena），而是已经被人类通过先天因果范畴“格式化” **过的** 现象界 (Phenomena)。LLM的成功，是搭了人类心智结构的“便车”。视觉模型直接面对的是原始的、未被组织的像素数据，这近乎于康德所说的“杂多感性材料”。单纯对像素的统计建模不能产生和人类心灵结构同构的输出。所以要训练一个与人理解物理世界一致的模型，必须要显式或隐式的带入人类的理解世界的基本方式(先验范畴)

### 对 Agen 系统设计的建议

> 哎，形而上的东西不要太多，我们赶快看看这些澄清对我们实际智能体设计有什么帮助。

当前，AI Agent 的浪潮正席卷整个科技行业，它预示着人机交互的下一个范式。然而，在激动人心的前景之下，我们必须清醒地认识到，通用人工智能（AGI）的实现并非一蹴而就，至少在未来几年内，通往“完全自主通用 Agent”的道路仍充满挑战。因此，与其追逐遥远的终极目标，更务实的态度是摆正我们对 Agent 的期望。

上面澄清了这么多，说白了就是模式识别、统计建模这一套技术范式3-5 年内不可能带领人类走向 AGI。吹嘘这套论述的人要么是聪明的利益相关方，要么就是不明所以的盲目跟风的群众。我们应将注意力从对通用性和完全自主性的过度追求，转移到在具体场景中创造切实价值。这意味着，我们需要 “静态工作流” **与** “全自主 Agent” 这个光谱中，找到最适合当前业务的落点，优先解决那些高商业价值、高模块化、高重复性的任务。人类社会大多数事务的运行逻辑都是某些固有模式叠加一些变量的反复循环，99.99999% 的工作内容都是普通人在做，远远不需要达到 AGI 智能水平。即便当前大模型训练算法没有进一步的突破，只要有足够的数据和计算资源，当前的技术水平足以在未来五年内自动化白领工作。所以注意力要放在如何根据工作场景构建针对性 Agents 。

要实现这一目标，我暂时想到了如下四点需要注意的点。

**原则一：约束而非解放——打造各司其职的专家 Agent 团队**

我们必须认识到，当前的大模型本质上是一个通过海量数据回归拟合出的“集大成的平均人”。它博学强记，但“平均”也意味着它可能什么都能做一点，却无法在任何专业领域做到顶尖。若将一个复杂任务完全交给单个通用 Agent，不仅其表现会趋于平庸，有限的上下文窗口（Context Window）也会使其产生巨大的“认知负担”，导致任务失败。

因此，设计的核心思路应是 **约束而非解放** 。我们不应追求创造一个“万能 Agent”，而应根据最终目标，设计一个由多个专家 Agent 组成的协作团队。

1. **定义 Agent 职责（RGRB 框架）** ：为每个 Agent 设定清晰的角色（ **R** ole）、明确的目标（ **G** oal）、详尽的规则（ **R** ule）和严格的边界（ **B** oundary）。例如，在一个自动化研究报告生成的任务中，可以设立“数据搜集 Agent”、“数据分析 Agent”、“图表生成 Agent”和“报告撰写 Agent”。这种职责划分确保了每个 Agent 都能在限定领域内激发出最强的专业能力。
2. **设计协作模式** ：对于单 Agent 难以胜任的复杂任务（如跨模态内容生成、多元数据融合分析等），必须将整体任务切分成职责清晰的子任务，让多个 Agent 协同推进。通过在测试和生产环境中的反馈，来平衡编排或者垂直的多智能体协作方式。

**原则二：模块化认知——为 Agent 构建多维记忆系统**

为了让 Agent 高效地执行任务并降低“认知负担”，我们需要借鉴人脑的分区工作机制，为其设计模块化的记忆系统。这将冗长的任务链条分解为日志级的短链条操作，每个 Agent 只需加载和处理其职责范围内的必要信息，从而极大地提升效率和稳定性。

**原则三：演进式学习——逐步从 **SFT* * 转向强化学习**

传统的监督微调（SFT）在构建 Agent 方面正面临瓶颈。为 Agent 构建涵盖真实工具调用环境、覆盖各种长尾场景的多轮对话数据集，成本极高且极其困难。

一个更具前景的范式是 **强化学习** **(** **Reinforcement Learning** **,** **RL** **)** 。通过在模拟或真实环境中与工具、API 和其他 Agent 交互，Agent 可以在试错中学习。结合思维链（Chain-of-Thought, CoT）等技术，RL 的端到端训练范式能够更有效地激发出预训练模型中早已存在的、但未被显式引导的“智慧碎片”，让 Agent 自主学会如何规划、执行和反思，从而获得真正解决问题的能力。

**原则四：人机协作 ——** **Human-in-the-Loop 是刚需而非过渡**

鉴于 Agent 继承了人类社会的平均认知局限，它必然缺乏应对“黑天鹅”事件的真正能力。它可能会在看似简单却超出其数据模式的常识问题上犯下低级错误。因此，将 **“人在环路”（Human-in-the-Loop, HITL）** 作为监控、仲裁和最终决策的保障，不是技术不成熟时的权宜之计，而是在当前范式下确保系统鲁棒性、安全性和可靠性的根本要求。人类专家的作用，正是为了弥补那个“平均人”Agent 所缺乏的顶尖智慧、道德决断和对真实世界复杂性的最终理解。HITL 机制是 Agent 系统与现实世界之间的最后一道“防火墙”。我们应该思考的，是如何将“平均人”的广博知识和超凡速度，与人类专家的深刻洞见和创造性思维相结合。Agent 负责完成 90% 的标准化工作，而人类专家则聚焦于那决定成败的 10% 的战略规划、创新突破和伦理把关

尽管AI Agent在理论上具备颠覆管理咨询等知识密集型产业的巨大潜力，但我们观察到现在的产品在这类任务上表现不佳。由此，我们为多智能体编排设定了目标、澄清了当前的技术范式存在根本上的局限性，并以此作为后续的讨论基础给出具体四点设计 Agents 时的建议。
