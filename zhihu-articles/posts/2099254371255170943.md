用了三四年的 Claude 账号，昨天被封了。

虽然我知道这一天可能会来，但真的来了，还是非常难过，甚至愤怒。

第一次被封号，天杀的 Dario。

最近很长一段时间，Claude 已经成了我的工作主力，几乎所有事情都在里面完成。甚至 ChatGPT，我订阅了却只用来画图。

我订阅的是 Max 5x，官网每月 100 美元的档位。苹果内购账单显示的是 124.99 美元/月，11 月 11 日才到期，还有差不多半个月。

被封的时候，我正把写好的一篇文章同步到其他平台。我可以确定，这是一件正常的工作，而且已经重复做过无数次。

开始看到这个弹窗，我还不明白是咋回事，思考了三秒才意识到：号被封了。

![](https://pic2.zhimg.com/v2-a1ea964e75f818ac91c87c5a5e186e57_r.jpg)
*图：在苹果退款页面提交申请。*

血压一下就上来了，那一下真有点五雷轰顶。

我立马点了“申请复审”，还让 ChatGPT 帮我写了一封措辞诚恳（甚至有点卑微）的复审理由。我满怀希望，以为可以恢复。

结果证明，我并没有那么好运。

几个小时后，申诉失败。我以为还能不断申诉，直到通过，结果他们比我想象的还决绝。页面上直接写着：“这是我们的最终决定。”

![](https://picx.zhimg.com/v2-456f88fc04b5002d0255280a2e17e989_r.jpg)
*图：退款申请审核中，预计 10 月 31 日出结果。*

邮件只说违反了使用政策，没有指出具体是哪次操作、哪条内容。我到现在也不知道，到底触发了什么。

一怒之下，我甚至想把账号删了，从此跟 Anthropic 拜拜。还好，最后没冲动。随后又试着注册新号，发现现在也注册不了了。

罢了，随它去吧。

虽然感觉天塌了，但生活还得继续。冷静下来，检查了一圈，有几件事可能对你也有点帮助。

## **钱没退，额度还能蹬**

人生最大的悲剧是，人走了，钱还没花完。

对账号来说也是，号被废了，钱还没用完。更悲剧的是，它还不自动退款。

![](https://picx.zhimg.com/v2-5c405fed6e50fcb436bbd6a9175f589d_r.jpg)
*图：Codex 读取原来的本地会话，接上之前的上下文。*

之前听说可以打苹果客服电话退款，我嫌麻烦，一直没折腾。

后来查了官方说明：如果走的是苹果内购，可以直接去 Apple 的退款页面（[https://reportaproblem.apple.com/](https://reportaproblem.apple.com/)）提交申请，不一定要打电话。我打开了申请页面，姑且试试。

![](https://pica.zhimg.com/v2-324a8ae3e71234a9be9e1c37b8873228_r.jpg)

10 月 29 日提交，现在状态是 Pending，苹果说 10 月 31 日给结果。

![](https://pic4.zhimg.com/v2-1a77df805b3b22a1f06ce43904f6aa37_r.jpg)

退款和取消续订还得分开处理，续订我已经取消了。

但还有一笔东西能用。

Claude 给部分付费订阅送 API 额度。我这个 Max 5x，每月有 100 美元 API 额度。目前是 Max 和 Team 有，Pro 不包含。

订阅账号被封后，我之前领到的 API 额度仍然可以使用，可以到 Claude Platform 的账单页（[https://platform.claude.com/settings/billing](https://platform.claude.com/settings/billing)）查看。

![](https://pica.zhimg.com/v2-f831e77e22665f194c63167723463ffa_r.jpg)
*图：同一份源文件，生成不同工具的适配版。*

截图里还剩 99.24 美元，11 月 15 日过期。这还不得把它蹬完？！

所以我还在 DeepSeek Harness、OpenCode 里面接着用 Claude。

![](https://pic3.zhimg.com/v2-7313605e914ae024a1641dd1f9e62eca_r.jpg)
*图：三套封面，A 是 GPT，B 是 Gemini，C 是 DeepSeek*

薅完 Dario 的最后一根汗毛。

这只是我的情况。官方只说取消订阅或退款后，已领额度可用到过期，没说封号也一定能用，API 那边也可能一起被停。

## **Claude账号封了，Claude Code还能用**

这个可能很多人跟我一样，开始没分得那么清楚，以为账号被封了，一切就都 Game Over 了。

我习惯用的是 Claude Code 的命令行版。它确实好用，用久了，很多工作已经很自然地在里面完成。

但 Claude 账号被封，Claude Code 这个工具仍然可以继续用，只是不能再靠这个账号使用 Claude 模型。Claude Code 可以接别家的模型。

所以我继续在 Claude Code 里面用 DeepSeek。之前的 Skills 照样用，这次没做什么调整。原来积累的本地记忆，也都还在。

![](https://pic1.zhimg.com/v2-aaf77b9a6f61f037b341e8ab17da887c_r.jpg)

配置 DeepSeek 也很简单。如果你在用 Codex、WorkBuddy 或 DeepSeek Harness，可以直接让它帮你配。

自己配的话，先申请一个 DeepSeek API Key，再把下面这些项合并进 ~/.claude/settings.json。已有其他配置就保留，别整份覆盖。

```text
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.deepseek.com/anthropic",
    "ANTHROPIC_AUTH_TOKEN": "你的 DeepSeek API Key",
    "ANTHROPIC_MODEL": "deepseek-flash[1m]",
    "ANTHROPIC_DEFAULT_OPUS_MODEL": "deepseek-flash[1m]",
    "ANTHROPIC_DEFAULT_SONNET_MODEL": "deepseek-flash[1m]",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "deepseek-flash",
    "CLAUDE_CODE_SUBAGENT_MODEL": "deepseek-flash",
    "CLAUDE_CODE_EFFORT_LEVEL": "max",
    "CLAUDE_CODE_AUTO_COMPACT_WINDOW": "786432"
  },
  "model": "deepseek-flash[1m]"
}
```

DeepSeek 官网也有接入 Claude Code 的说明（[接入 Claude Code | DeepSeek API Docs](https://api-docs.deepseek.com/zh-cn/quick_start/agent_integrations/claude_code/)），可以对着核对。

当然，模型换了，回答、做事方式和效果都会变。我说的“还能用”，是我熟悉的工具和原有 Skills 还能继续工作，不代表换完以后每个任务都跟 Opus 一样。

API 按用量计费，用多少扣多少，跟包月订阅不是一回事。后面要说的那篇贴图，DeepSeek 居然花了我 5 块钱，第一次觉得 DeepSeek 也贵。我日常干活，还是更喜欢订阅套餐。

## **之前聊过什么，没有跟着账号一起没了**

账号封了，我最担心两个问题：之前的会话没了，以及整个工作环境丢了。

但研究后发现，我担心的这些东西，大部分还在自己电脑里。

我主要在 Claude Code 里工作，会话记录存在本地。

这次中断的那一场，文件也还在。它停在哪、我改过哪些要求、哪些东西已经做完，都能找回来。

还可以带到 Codex 里面继续工作。

Claude Code 的默认记录位置是 ~/.claude/projects/。每个项目下面，会保存对应的会话文件。这说的是命令行版的本地记录，不能直接套到所有 Claude 网页聊天上。

Codex 也有导入入口。按照 OpenAI 的导入说明（[https://learn.chatgpt.com/docs/import](https://learn.chatgpt.com/docs/import)），在本地 Codex CLI 里输入 /import，选择 Claude Code，再选要带过去的配置、项目或最近会话，就可以继续工作。

![](https://picx.zhimg.com/v2-f77fe41aeede17ae2413fba792e16bcb_r.jpg)

这张图里，我把原会话的完整文件路径交给 Codex，它读完记录，接上了之前的上下文。

如果导入入口没找到目标会话，也可以把会话文件的完整路径交给它。连文件在哪都不知道，就直接让 Codex 帮你找。

不过，本地保存也有个容易忽略的地方：Claude Code 默认会清理超过保留期限的会话，文档列出的默认期限是 30 天。重要记录还是得另外归档，不能觉得它在电脑上，就永远都在。

## **工作环境，我一直备着两套**

还好，我以前就经常在 Claude Code 和 Codex 之间切换。

能想到的工作，我尽量都整理成 Skills。每次改完，也会同步到两边。两边有各自的适配，不要求文件一字不差。

文章、图片、脚本这些产出，用的也是同一套本地目录，还会在 GitHub 上备份。

所以这次换过去，工作文件都还在，原来的方法也有。重新搭环境这件事，对我几乎没造成什么影响。

不过，插件、外部服务的登录、工具权限，还有定时任务，都得单独看。Skill 写着“发到飞书”，不等于换一个工具以后，飞书的授权就自动好了。

我的做法是维护同一份技能源文件，用 Git 留下修改历史。平时在工具里改完，就先把改动收回这份源文件，再生成两边要用的版本。

Codex 用一版；Claude Code 那版由脚本生成，补上运行方式和工具差异。装回本机之前，脚本还会检查有没有更新、却没收回来的改动。有就先停下，免得旧版本把新东西盖掉。

![](https://pica.zhimg.com/v2-fa35ed27cb9901dbee3668ccb28fc3d0_r.jpg)

这次接手时，还有个很具体的问题：别把已经执行过的事再做一遍。

如果换个工具，只告诉它“刚才失败了，你重来”，开头那篇正在同步的文章，就可能被重复发一遍。

所以，会话拿回来之后，还得看看实际文件和执行回执。聊天最后报错，不等于前面的工作全没做。

## **今天，我选了DeepSeek做的那一版**

现在我的主力换成了 Codex 里的 GPT，Claude Code 接 DeepSeek 当备用。当初订阅了只用来画图的 ChatGPT，倒成了主力。

说实话，我还是觉得没有 Opus 5.5 顺手。额度也明显消耗得更快。这是我最近这些工作里的体感，不是严格控制条件测出来的。

但有件事挺有意思。

今天做“ChatGPT 订阅送 API 额度”那篇贴图，我分别用了 GPT 6.1 Sol、DeepSeek 4.1 Flash 和 Gemini Argon。本来只是想把之前用 Claude 的流程重新跑通一遍，最后却选了 DeepSeek 的。

![](https://picx.zhimg.com/v2-c50e8f1429ad5fdbc4c508818f977639_r.jpg)

只看封面，体现不出 DeepSeek 更好。但整套图看下来，我明显更喜欢 DeepSeek 的。

GPT 6.1 Sol 调教了几次，做了几版，还是不够满意。Gemini Argon 真够慢，图里的内容又太多，看着乱糟糟的。

DeepSeek 属于人狠话不多的。不用反复调教，在简单和复杂之间取到了一个很好的平衡，我直接就用了。

这个例子当然证明不了 DeepSeek 在所有任务上都更好。三份成品有各自的制作过程，也不能当成严格横评。

但至少，今天这个活，摆在我面前的结果是这样。我没选自己现在的主力，也没用上之前最依赖的 Opus。

我一直追求的 Opus 5.5，会不会很多时候，也没那么必要？

## **最后**

让人哭笑不得的是，账号被封了，我却收到了 Claude Duet 排队结束的通知。最近到处都是 Personal Agent，我一直挺期待这个 Duet。结果它来了，我却没法体验了。

![](https://pic1.zhimg.com/v2-1df76d824778c7b608b9d93fb76ab55e_r.jpg)

钱没退，申诉失败，我到现在还是很生气。

这个号我用了三四年，之前也没多么小心翼翼，最后还是封了。这两天看到所谓 Claude 账号“积分制”的说法，有人指望靠各种小技巧让账号永生。我对这些保号办法，已经没什么信心了。

回过头想，这几年我一直在几个模型之间反复横跳。先是 ChatGPT，后来很长一段时间依赖 Gemini，也紧张过它挂了怎么办。结果 Gemini 真变一坨屎了，我又用起了 Claude。

现在轮到 Claude。

巧的是，今天 Gemini 4 Carbon 发布了，在 Artificial Analysis 的综合排名里超过 Opus 5.5，成了第一。不过写代码这块，Opus 5.5 还是第一；Carbon 现在也只开放给少数用户。

我顺手试了试，拿 Antigravity 配 Gemini Argon 当 Claude Code 的替补。结果这玩意真辣鸡。

Antigravity？我看应该叫 Antihumanity，反人类。

我有点分不清，当初那个“没了它就不行”的感觉，有多少来自工作本身，有多少来自我已经习惯了它。

账号能用多久，我说了不算。以后就按“随时会被封”来准备。

你有没有一个“离了它就不行”的 AI 工具？如果明天它的号没了，你最先丢掉的会是什么？
