自 DeepSeek Harness 发布以来，越来越多的用户开始在 DeepSeek Harness 上工作、探索，也有越来越多的开发者通过插件扩展它的能力。今天，我们想和大家分享产品与社区的进展，并介绍面向插件作者的支持计划。

## 与社区共同成长

<br>8 月 13 日，DeepSeek Harness v0.1 版本上线；9 月 29 日，我们正式发布了 DeepSeek Harness 桌面端。截至 11 月 4 日，以使用官方 API 的用户为统计范围，DeepSeek Harness 日活跃用户已达 154 万，日消耗 Token 约 92 万亿。<br>

![](https://pic3.zhimg.com/v2-640f6462f2363a9ec825a76069e74744_r.jpg)

![](https://pic1.zhimg.com/v2-69c736d85b038dcd08497111e2614586_r.jpg)

<br>DeepSeek Harness 发布至今，第三方插件数量已增至约 3.5 万个，约 60% 的活跃用户制作或安装了至少一款第三方插件。社区插件仍在持续迭代，成熟度和适用场景各有差异，我们期待与开发者和用户一起持续提升插件的实用性与稳定性。

![](https://pic3.zhimg.com/v2-1e8e418875cb86004c53e4b1f441b51e_r.jpg)

<br>在这一过程中，我们非常惊喜地看到，许多开发者将自己的需求和经验做成了插件，有相似需求的用户也因此多了新的选择。下面，我们想介绍几个这样的插件，聊聊它们背后创作者的故事。你也可以直接在 DeepSeek Harness 插件安装页中输入对应包名，下载体验。<br>

### **自媒体创作者工作台（dsh-media-desk）**

<br>作者 GitHub：woniuniuniu（小红书：蜗牛的科技笔记）<br>从记录灵感到写脚本、做封面、设计分镜，蜗牛把日常创作装进一个工作台，也延续了 DeepSeek Harness 的极简风格。蜗牛这样形容自己的使用日常：<br>现在它已经变成我的日常工作台，睡醒、打开 DSH、秒开工作台、开蹬！<br>

![](https://pic4.zhimg.com/v2-6d29c6e95dfdb10b6ca2a77aeddefd51_r.jpg)

### <br>**设计插件（dsh-guizang-design）**

<br>作者 GitHub：op7418（公众号：歸藏的AI工具箱）<br>歸藏把常用的设计与文字润色 Skill 合成插件，让一篇文章变成网页、图文卡片或封面，完成的内容也会保存在「我的作品」中，支持通过「做同款」复用。从 Skill 到插件，歸藏也发现了更多创作空间。他说：<br>DeepSeek Harness 的插件系统能给的比 Skill 多很多。通过我的设计插件，作品、专栏和语气都能积累下来，内容生成的质量会非常稳定。<br>

![](https://pic1.zhimg.com/v2-19c4695c6674b8422bd40e2a02cac4dc_r.jpg)

### <br>**上下文洞察插件（dsh-context）**

<br>作者 GitHub：bowenliang123（B 站：博文博文）<br>bowenliang123 开发了 dsh-context。从 Context 的组成和演进，到多 Agent 团队协作的关键细节，用户可以通过插件了解 Agent 工作时使用了哪些信息，以及这些信息如何随着对话变化。在他看来：<br>DeepSeek Harness 的开放、灵活、强大的插件哲学，真正让一切变得可能，dsh-context与 dsh 重新让每个 Agent 的上下文和 Harness 真正开源，并回到你的手中。<br>

![](https://picx.zhimg.com/v2-0829458192afb6a866ce6560b84c5dcb_r.jpg)

### <br>**论文阅读插件（agentero-dsh）**

<br>作者 GitHub：Phil-Fan（小红书：PhilFan）<br>论文阅读插件将 Agentero 接入 DeepSeek Harness，读论文、做高亮、翻译和记笔记都能在同一个地方完成，也可以请 Agent 帮忙梳理思路。Phil Fan 说，这个想法来自团队的科研日常：<br>很喜欢 DeepSeek Harness 灵活的插件机制，让我们能把文献管理、翻译和笔记串起来，做一款人和 Agent 用着都舒服的文献工具。<br>

![](https://pic1.zhimg.com/v2-6a328a3d3640fae748fdf9021a812576_r.jpg)

## <br>用你的创造，定义属于你的 Harness

<br>从一个想法，到一个好用的插件，再到融入更多人的日常，离不开作者持续的开发、改进和维护，我们希望为这份投入提供更持续的支持，也让更多有想法的人迈出创作的第一步。<br>为此，我们将会进一步提升插件 API 的稳定性与兼容性，完善插件安全机制，并建设官方插件市场，让插件作者更方便地上传插件、用户更方便地找到自己所需插件。同时，我们也正在筹备面向插件作者的支持计划，通过 Token 激励、技术交流与作品推荐，支持新想法的探索与已有作品的完善。具体的支持方式，将结合社区的实际需求与反馈逐步完善。我们也欢迎创业团队和企业通过 DeepSeek Harness 插件接入产品、服务与专业能力，与我们探索合作可能。<br>感兴趣的作者和团队，可以填写意向报名表（[https://trtgsjkv6r.feishu.cn/share/base/form/shrcnkRrxNyri4bOF9n48BIYWbb](https://trtgsjkv6r.feishu.cn/share/base/form/shrcnkRrxNyri4bOF9n48BIYWbb)），向我们分享你的作品、想法与需求。目前报名主要用于前期意向收集，具体参与规则和支持安排将在计划正式推出时公布。

<br>我们希望 DeepSeek Harness 可以作为 Agent 时代的操作系统，为用户提供稳定的基础能力，并内置大多数人都需要的通用功能。面向专业场景、特定行业和个性化需求，则鼓励最了解这些需求的开发者们结合自身经验，通过插件探索更贴切的解法，以 DeepSeek Harness 插件为载体，为用户提供最优的 Agent 产品体验。在“一切皆插件”的设计下，内置功能同样可以被第三方插件替换，我们希望更多的社区作品成为用户的日常选择。

<br>感谢每一位使用 DeepSeek Harness、创作和维护插件、分享反馈的朋友。你们提出的每一个反馈、付诸实践的每一次尝试，都在拓展 Harness 的边界与可能，也帮助我们看清产品前行的方向。我们会继续完善产品，为社区的创作提供支持。<br>
