最近折腾了一下 Wolfram MCP，把它接到了自己常用的 AI 工具里。

用下来最大的变化是：以前让 AI 算东西，总觉得它是在脑补；现在至少可以让它把关键计算丢给 Wolfram Language 跑一遍。相当于给 AI 装一个强大的计算器，让它不再只会“口算”。

这件事对数学工作者，或者经常需要做数学推导、公式验证、数值计算的人，还是挺实用的。

### 为什么需要 Wolfram MCP？

用 AI 做推导时，最烦的不是它不会写，而是它写得太像真的了。

Wolfram MCP 解决的就是这个问题：让 AI Agent 可以直接调用 Wolfram Language / Wolfram|Alpha，去做符号计算、数值计算、绘图和验证。

我现在实际使用下来，比较舒服的一点是：当 AI 判断当前问题需要计算时，它会自动调用 `WolframLanguageEvaluator` 去跑 Wolfram Language 代码，然后把结果整理成可以直接阅读的公式。

如果后面还要继续整理，我可以接着让它把推导过程总结成一份可以直接编译的 $\mathrm\LaTeX$ 报告；或者让它生成 Wolfram Notebook，把问题、代码、输出和解释放在同一个 `.nb` 文件里。这样一来，AI 不只是给一个最终答案，而是能把“计算 - 验证 - 整理”这几个步骤连起来。

### 适合谁？

我觉得下面几类人会很适合：

- 做数学推导的研究生；
- 写论文、读论文时需要反复验证公式的人；
- 希望 AI 不只是“会说”，而是真的“会算”的人；

### 我的方案

核心思路很简单：

> 安装 Wolfram MCP，让 Agentic AI 可以调用本地 Wolfram 内核执行代码。

也就是说，给 AI 装一个强大的计算器，让它不再只会“口算”。AI 负责理解问题、组织推理和调用工具；Wolfram 负责真正的符号计算、数值计算和可视化。

### 安装步骤

### 1. 准备一个支持 MCP 的 AI Agent

先确认你使用的工具支持 MCP。

常见选择包括：

- VS Code
- GitHub Copilot
- Codex
- Cursor
- Claude
- Claude Code

不同客户端的配置方式略有差异，但 Wolfram 的 AgentTools 已经内置了不少客户端的安装支持。

### 2. 安装并激活 Wolfram Mathematica

需要先安装 Wolfram Mathematica / Wolfram Language，并完成激活。

我这里使用的是 Mathematica 14.3。根据 Wolfram AgentTools 官方说明，版本要求是：

```text
Wolfram Language 14.3 or higher
```

Mathematica 安装可以参考这个教程：

[Mathematica 激活指南](https://tiebamma.github.io/InstallTutorial/)

### 3. 安装 Wolfram MCP

官方文档在这里：

[https://github.com/WolframResearch/AgentTools/](https://github.com/WolframResearch/AgentTools/)

AgentTools 里有不止一种 MCP server。按照官方文档的默认流程，通常会安装 `"Wolfram"` ；但如果你的主要需求是数学推导、公式验证、Wolfram Language 代码执行、Notebook 整理，我更推荐直接安装 `"WolframLanguage"` 。

简单说：

- `"Wolfram"` / `"WolframAlpha"` 更适合自然语言问答式的计算；
- `"WolframLanguage"` 更适合让 Agent 直接写和执行 Wolfram Language 代码。

打开 Wolfram，新建一个 Notebook，输入下面三行代码，然后按 `Shift + Enter` 执行：

```text
PacletInstall["Wolfram/AgentTools"]
Needs["Wolfram`AgentTools`"]
InstallMCPServer["VisualStudioCode", "WolframLanguage"]
```

第三行里的 `"VisualStudioCode"` 要换成你正在使用的客户端。官方 README 里列出的 client name 如下：

| 客户端 | InstallMCPServer 里填写的名称 |
| --- | --- |
| Claude Code | "ClaudeCode" |
| Claude Desktop | "ClaudeDesktop" |
| Cline | "Cline" |
| Copilot CLI | "CopilotCLI" |
| Cursor | "Cursor" |
| Gemini CLI | "GeminiCLI" |
| Goose | "Goose" |
| Google Antigravity | "Antigravity" |
| OpenAI Codex | "Codex" |
| OpenCode | "OpenCode" |
| Visual Studio Code | "VisualStudioCode" |
| Windsurf | "Windsurf" |
| Zed | "Zed" |

比如你用的是 Codex，可以写成：

```text
InstallMCPServer["Codex", "WolframLanguage"]
```

按照 WolframResearch/AgentTools 的 README， `"WolframLanguage"` 主要面向 Wolfram Language 的开发和学习。装好之后，Agent 可以用 `WolframLanguageEvaluator` 执行 Wolfram Language 代码，也可以用 `ReadNotebook` / `WriteNotebook` 读取或生成 `.nb` 笔记本，还可以调用 `SymbolDefinition` 、 `CodeInspector` 、 `TestReport` 等工具做符号查询、代码检查和测试。

### 4. 重启你的 AI Agent

安装完成后，重启对应的 AI Agent。

重启后，在 Agent 的 MCP 工具列表里应该能看到 Wolfram 相关工具。之后你就可以直接让 Agent 调用 Wolfram 做计算了。

### 我遇到的问题和解决方案

### 1. Agent 不一定会主动使用 Wolfram

有些 Agent 即使已经接入 Wolfram，也可能不会主动调用工具。比如你问一个计算问题，它可能还是直接用语言模型回答，而不是调用 Wolfram 验证。

我的做法是提前给 Agent 写好一段固定指令，让它在遇到数学或科学问题时优先调用 Wolfram，而不是先自己硬算。

这段指令可以放在 Persistent Instructions 里，也可以写进 `AGENTS.md` 。前者可以理解成“长期系统提示词”：聊天客户端每次对话开始时都会把它发给 AI，相当于给 Agent 设定一套固定工作习惯。下面是我正在使用的一份开箱即用版本：

```text
When I ask mathematical or scientific questions, use WolframLanguageEvaluator when available rather than relying on mental calculation. Show the essential Wolfram Language code you ran and summarize the result in LaTeX-formatted mathematical language. When producing plots or visualizations, use clear labels and legends. For variables involving Greek letters, use Wolfram Language's supported Greek-letter symbols whenever possible, such as `\[Alpha]`, instead of English spellings like `alpha`, when there is no variable name conflict.

When writing nontrivial Wolfram Language code, use WolframLanguageContext or WolframContext when useful to check relevant functions and syntax. Prefer exact or symbolic computation when appropriate; use numerical methods when exact methods are unavailable or unsuitable. State assumptions, domains, parameter ranges, and branch choices explicitly. 

If I ask to save or summarize a calculation as a Wolfram notebook (.nb), create a concise research notebook using WriteNotebook. Include the problem, assumptions, key code, outputs, plots or figure descriptions, interpretation, and open questions. Save notebooks with clear filenames.
```

### 2. `WolframLanguageEvaluator` 有时会超时

另一个常见问题是，调用 `WolframLanguageEvaluator` 时可能会遇到超时。例如：

```text
Failure[
    "EvaluationTimeExceeded",
    <|
        "MessageTemplate" -> "Evaluation exceeded the 1 second time limit.",
        "MessageParameters" -> {30}
    |>
]
```

这通常不是 Wolfram 算不出来，而是 MCP 调用时给工具设置的时间限制太短。遇到复杂一点的积分、化简、数值优化或绘图，1 秒很容易不够。

解决方式有两个。

第一种是在 Persistent Instructions 里明确告诉 Agent：如果要调用 `WolframLanguageEvaluator` ，请根据任务复杂度设置更长的 `TimeConstraint` 。

第二种是在 MCP 配置里直接给 `WolframLanguageEvaluator` 设置默认超时时间。例如通过环境变量 `MCP_TOOL_OPTIONS` 设置：

```text
{
  "WolframLanguageEvaluator": {
    "TimeConstraint": 120
  }
}
```

也可以在重新安装 MCP server 时，把 `ToolOptions` 直接传进去：

```text
InstallMCPServer[
    "ClaudeCode",
    "WolframLanguage",
    "ToolOptions" -> <|
        "WolframLanguageEvaluator" -> <|"TimeConstraint" -> 120|>
    |>
]
```

这里的 `120` 表示允许计算最多运行 120 秒。实际使用时可以按自己的需求调整，比如设成 30、60 或 120。
