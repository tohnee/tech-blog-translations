又一篇关于 LLM Agent「记忆增强」的论文，提出了一个名为 **Memento** 的学习范式。

- 尝试解决当前 LLM Agent 面临的一个两难困境：要么依赖固定的、缺乏适应性的工作流，要么通过高成本的大模型参数微调来实现学习。
- Memento 的核心贡献在于，它开创了一条 **冻结大模型，学习小记忆** 的路径。
- 通过将智能体的决策过程建模为 **记忆增强马尔可夫决策过程 (Memory-augmented MDP)** ，它利用一个外部的、不断增长的「案例库 (Case Bank)」来存储过去的成功与失败经验。
- 智能体的学习能力体现在一个 **可学习的案例检索策略** 上，该策略通过在线强化学习（具体为软 Q 学习）不断优化，学会从记忆中挑选最有价值的过往经验来指导当前决策。
- 这种方法极大地降低了持续学习的计算成本，使智能体能够低成本、实时地适应新环境和新任务，并在多个高难度基准测试（如 GAIA）上取得了顶尖性能。

> 论文： [[2508.16153] Memento: Fine-tuning LLM Agents without Fine-tuning LLMs](https://arxiv.org/abs/2508.16153)

## 一、LLM 智能体的基本范式

### 1.1 范式一：基于固定工作流的静态智能体

这是最常见的智能体构建方式。开发者通过精巧的提示工程（Prompt Engineering）设计一套固定的工作流或反思机制，例如思维链（CoT）或 ReAct 框架。这类智能体在特定任务上可以表现出色，但其核心逻辑是静态的。

- **优点** ：实现简单，成本低，行为可预测。
- **局限性** ：

### 1.2 范式二：基于参数更新的自适应智能体

为了克服静态智能体的局限性，研究界探索了通过更新 LLM 自身参数来使其具备学习能力。这通常通过监督微调（SFT）或强化学习（RL）实现。

- **优点** ：能够将新知识和技能「内化」到模型参数中，可能实现更深层次的泛化和能力提升。
- **局限性** ：

这两种范式形成了一个两难选择：要么选择低成本但僵化的方案，要么选择高成本但具备学习能力的方案。Memento 的目标正是要打破这一僵局，探索第三条道路。

## 二、Memento：基于记忆的强化学习

Memento 的核心思想可以概括为： **冻结 LLM 的参数，将学习的焦点从「模型」转移到「记忆」。** 它不试图让 LLM 本身变得更「聪明」，而是让智能体更善于利用过去的「经验」。这一思想借鉴了认知科学中的人类记忆机制和人工智能领域的经典范式—— **案例式推理（Case-Based Reasoning, CBR）** 。CBR 的核心主张是，人类通过回忆和类比过往相似情境的解决方案来解决新问题。

Memento 将这一思想形式化，并构建了一个完整的学习闭环。

### 2.1 形式化建模：记忆增强马尔可夫决策过程 (M-MDP)

为了在数学上严谨地描述一个依赖记忆进行决策的智能体，Memento 将其决策过程建模为一个 **记忆增强马尔可夫决策过程（Memory-Based Markov Decision Process, M-MDP）** 。

一个标准的 MDP 由元组 $\langle \mathcal{S}, \mathcal{A}, \mathcal{P}, \mathcal{R}, \gamma \rangle$ 定义，分别代表状态空间、动作空间、转移概率、奖励函数和折扣因子。M-MDP 在此基础上显式地增加了一个 **记忆空间（Memory Space）$\mathcal{M}$** ，其定义如下：

一个 M-MDP 是一个元组 $\langle \mathcal{S}, \mathcal{A}, \mathcal{P}, \mathcal{R}, \gamma, \mathcal{M} \rangle$，其中 $\mathcal{M} = (\mathcal{S} \times \mathcal{A} \times \mathbb{R})^*$ 是记忆空间，由一系列历史经验（状态 - 动作 - 奖励三元组）构成。与标准 MDP 的关键区别在于，当前决策不仅依赖于当前状态 $s_t$，还依赖于整个记忆历史 $M_t$。

![](https://pic3.zhimg.com/v2-bfa3222c5048dfa635eb58355193d01c_r.jpg)

在这个框架下，智能体的行为被分解为一系列循环步骤： **检索（Retrieve）、复用与修正（Reuse & Revise）、评估（Evaluation）、保留（Retain）** 。

### 2.2 核心策略：案例式推理智能体 (CBR Agent)

基于 M-MDP 模型，Memento 定义了其核心的 CBR 智能体策略。在每个时间步 $t$，智能体面对当前状态 $s_t$ 和一个不断增长的案例库（Case Bank）$M_t$。它的决策分为两步：

1. **案例检索 (Retrieve)：智能体首先根据一个案例检索策略 $\mu$** 从案例库 $M_t$ 中选择一个过往的案例 $c_t$。这个策略是学习的核心，它决定了智能体「回忆」起哪段经验。
2. **动作生成 (Reuse & Revise)** ：接着，底层的（冻结的）LLM 将当前状态 $s_t$ 和被检索出的案例 $c_t$ 作为上下文，生成最终的动作 $a_t$。这一步由固定的 LLM 策略 $p_{LLM}$ 控制。

因此，CBR 智能体的整体策略 $\pi$ 可以表示为所有可能案例的期望：

$\pi(a | s, M) = \sum_{c \in M} \mu(c | s, M) p_{LLM}(a | s, c) \\$

这个公式揭示了 Memento 的解耦思想：$p_{LLM}$ 是固定的，代表 LLM 的通用推理能力；而 $\mu$ 是可学习的，代表智能体利用经验的特定能力。 **学习的过程就是优化检索策略 $\mu$ 的过程。**

### 2.3 学习机制：面向案例检索的 Soft Q-Learning

如何学习一个最优的案例检索策略 $\mu$？Memento 采用了 **最大熵强化学习（Maximum Entropy RL）** 框架，并通过 **软 Q 学习（Soft Q-Learning）** 进行优化。

在 RL 中，「动作」是智能体与环境的交互。在 Memento 的设定中，规划器（Planner）的「动作」是 **从记忆库中选择一个案例** 。软 Q 学习的目标不仅是最大化未来的累积奖励，还要最大化策略的熵。熵的引入旨在鼓励策略的多样性，避免智能体固守于少数几个案例，从而增强探索和鲁棒性。

通过一系列推导，最优的案例检索策略 $\mu^*$ 具有一个优雅的封闭解，即对 Q 值的 Softmax 函数：

$\mu^*(c | s, M) = \frac{\exp(Q^*(s, M, c) / \alpha)}{\sum_{c' \in M} \exp(Q^*(s, M, c') / \alpha)} \\$

其中，$Q^*(s, M, c)$ 是在状态 $s$ 和记忆 $M$ 下，选择案例 $c$ 的最优 Q 值（即未来期望回报），$\alpha$ 是控制策略随机性的温度系数。

这个结果意味着，只要我们能学到准确的 Q 函数，就能得到最优的检索策略。学习 Q 函数则可以通过标准的时序差分（TD）学习来完成。

### 2.4 Q 函数的高效近似：基于状态相似度的核方法

直接学习一个以自然语言为输入的 Q 函数 $Q(s, M, c)$ 是非常困难的，因为状态空间巨大且复杂。为此，Memento 引入了一种基于 **核函数（Kernel Function）** 的近似方法，其思想源于 **神经情景控制（Neural Episodic Control, NEC）** 。

其核心思路是：一个新状态 - 案例对的 Q 值，可以通过查询情景记忆（Episodic Memory）中与当前状态 **相似** 的历史状态的 Q 值，并进行加权平均来估计。具体来说：

$Q_{EC}(s, M, c; \theta) = \frac{\sum_{(s', c', Q') \in \mathcal{D}_c} k_{\theta}(s, s') Q'}{\sum_{(\hat{s}, \hat{c}, \hat{Q}) \in \mathcal{D}_c} k_{\theta}(s, \hat{s})} \\$

- $\mathcal{D}_c$ 是情景记忆中所有选择了案例 $c$ 的历史记录。
- $k_{\theta}(s, s')$ 是一个由参数 $\theta$ 控制的核函数，用于计算当前状态 $s$ 和历史状态 $s'$ 之间的相似度。
- $Q'$ 是历史记录中存储的 Q 值。

通过这种方式，学习 Q 函数的难题被转化为了学习一个更优的 **状态相似度核函数 $k_{\theta}$** 。这个核网络可以通过 TD 学习进行端到端的训练，使其能够更好地判断哪些历史经验对于当前状态更具参考价值。

## 三、Memento 框架详解

Memento 被实现为一个 **规划器 - 执行器（Planner-Executor）** 架构，专门用于处理复杂的「深度研究」（Deep Research）类任务。

![](https://pic1.zhimg.com/v2-a3850a81118d1850376b0f4b02dc22a4_r.jpg)

上图为 Memento 的整体架构。系统在案例式规划（Stage 1）和基于工具的执行（Stage 2）之间循环。

### 3.1 核心组件与工作流

**规划器 (Planner)** ：由一个强大的 LLM 驱动，是 CBR 智能体的具体实现。它的职责是：

1. 接收用户给定的高层任务。
2. 与 **案例记忆（Case Memory）** 模块交互，根据当前任务检索相关的历史案例。
3. 将任务指令和检索到的案例整合成一个 Prompt，输入给 LLM，生成一个分解的、可执行的子任务计划。
4. 将计划存入 **子任务记忆（Subtask Memory）** 。

**执行器 (Executor)** ：由一个更轻量、高效的 LLM 驱动。它的职责是：

1. 从子任务记忆中读取待执行的子任务。
2. 根据子任务内容，决定是直接回答，还是调用外部工具。
3. 通过一个标准化的 **模型上下文协议（MCP）** 与工具交互。
4. 将执行结果和工具调用记录存入 **工具记忆（Tool Memory）** 。

**记忆模块** ：

- **案例记忆 (Case Memory)** ：核心的长期记忆模块，存储历史任务的 `(状态, 计划, 奖励)` 三元组。
- **子任务记忆 (Subtask Memory)** ：短期工作记忆，用于协调规划器和执行器之间的任务流。
- **工具记忆 (Tool Memory)** ：记录单次子任务执行过程中的所有工具交互细节。

整个系统循环工作：规划器制定计划，执行器执行计划，规划器根据执行结果评估任务是否完成，如果未完成则进行重新规划，直到最终任务解决。任务完成后，这次完整的执行轨迹将被处理并存入案例记忆，用于未来的学习。

### 3.2 案例记忆管理：两种实现方式

Memento 的案例记忆模块提供了两种实现，分别对应不同的复杂度和性能权衡。

**非参数化记忆 (Non-Parametric Memory)**

这是一种简单高效的实现方式。

- **写入** ：当一个任务完成时，直接将其 `(状态, 动作, 奖励)` 三元组追加到案例库中。状态（即任务描述）会被一个固定的文本编码器（如 SimCSE）转换成向量表示。
- **读取** ：当新任务来临时，计算新任务向量与案例库中所有状态向量的 **余弦相似度** ，并检索出相似度最高的 Top-K 个案例。

这种方式遵循了 CBR 的朴素假设：相似的问题有相似的解决方案。

**参数化记忆 (Parametric Memory)**

这是一种更智能但实现更复杂的实现方式。它在 Memento 的单步规划设定下对 Q 学习进行了简化和特化。

- **简化 Q 学习** ：由于规划器的任务分解被视为单步决策，TD 学习中的未来价值部分（bootstrapping）消失了，学习目标简化为直接预测当前案例的即时奖励。
- **损失函数优化** ：由于任务奖励是二元的（成功=1，失败=0），标准的均方误差（MSE）损失在 0/1 边界附近梯度很小。因此，论文采用了 **交叉熵** 损失，将 Q 函数学习问题转化为一个二元分类问题：预测一个被检索的案例对于当前任务是否「有用」：$\mathcal{L}(\theta) = \mathbb{E}_{(s, c, r)} [-r \log Q(s, c; \theta) - (1-r) \log(1 - Q(s, c; \theta))]$ 这里的 $Q(s, c; \theta)$ 被训练成一个神经网络，输出一个概率值，表示案例 $c$ 对状态 $s$ 有帮助的可能性。
- **写入** ：除了追加新案例，还会用这个案例的 `(s, c, r)` 数据对 Q 网络进行一次在线梯度更新。
- **读取** ：计算当前状态 $s$ 与案例库中所有案例 $c_i$ 的 Q 值 $Q(s, c_i; \theta)$，并返回 Q 值最高的 Top-K 个案例。

参数化记忆相比非参数化记忆，其优势在于它能够学习到一种超越纯文本相似度的、更深层次的「任务 - 案例」关联性，从而选择出 **价值最高** 而非仅仅是 **表面最像** 的经验。

### 3.3 丰富的工具集

为了应对复杂的深度研究任务，Memento 集成了一套全面的工具集，并通过 MCP 协议进行调用：

- **信息获取** ：集成了 `searxng` 元搜索引擎和 `Crawl4AI` 网页抓取器，用于实时获取和解析网络信息。
- **多模态信息处理** ：能够处理图像（VLM 字幕）、音频（ASR 转录）、PDF、PPT、表格等多种格式的文件。
- **推理与分析** ：提供一个沙盒化的代码执行环境（支持 Python 及常用库）和一个数学计算工具。

## 四、实验评估与分析

### 4.1 主要性能表现

![](https://pic1.zhimg.com/v2-ff2bb0c926de45a9bf132e4e91248276_r.jpg)

- **GAIA (通用 AI 助手基准)：** 在这一极具挑战性的长程规划和工具使用基准上，Memento 在验证集上取得了 **87.88%** 的 Pass@3 准确率，排名第一；在测试集上也取得了 **79.40%** 的优异成绩，超越了多数已有的开源智能体框架。
- **DeepResearcher (网页研究基准)：** Memento 取得了 **66.6%** 的平均 F1 分数和 **80.4%** 的 PM 分数，显著优于基于训练的 SOTA 方法 DeepResearcher（F1 为 51.8%）。
- **SimpleQA (事实问答基准)：** Memento 达到了 **95.0%** 的准确率，展示了其在抑制模型幻觉、保证事实准确性方面的强大能力。
- **HLE (前沿知识基准)** ：在涉及大量长尾专业知识的 HLE 基准上，Memento 的表现仅次于假设中的 GPT-5，优于 Gemini-2.5-Pro 等模型。

![](https://pic1.zhimg.com/v2-bb285e705919759dcde4027be354c818_r.jpg)

### 4.2 组件消融分析

![](https://pic2.zhimg.com/v2-61cbc1d40955512f89cbdf6dd51dd46d_r.jpg)

为了验证每个组件的贡献，论文进行了一系列消融实验。结果表明：

1. **工具是基础** ：从无工具的 `Offline Executor` 到有工具的 `Online Executor` ，性能有显著变化（在某些数据集上提升，在某些存在数据污染的数据集上反而下降，这说明单纯依赖外部工具并非万能）。
2. **规划是关键** ：引入规划器后（ `Memento w/o CBR` ），性能得到系统性、大幅度的提升。例如，在 DeepResearcher 上，F1 分数从 30.8% 跃升至 59.9%。这证明了任务分解和策略编排的巨大价值。
3. **CBR 是催化剂** ：在规划的基础上，再加入案例式推理（CBR）记忆模块后（完整的 `Memento` ），性能得到进一步的稳定提升（DeepResearcher 的 F1 从 59.9% 提升至 66.6%）。这说明从过往经验中学习的能力，为强大的规划器提供了额外的、宝贵的指导。

### 4.3 持续学习与泛化能力

![](https://pic3.zhimg.com/v2-1b46cb9c12bceee4181f8065fac60830_r.jpg)

- **学习曲线** ：实验显示，随着交互迭代次数的增加，Memento 的性能持续稳定地提升。这直观地证明了其在线学习能力的有效性。参数化 CBR 比非参数化 CBR 展现出更强的学习潜力。
- **跨任务泛化** ：在 OOD 泛化测试中，研究人员将在部分数据集上训练得到的案例库，用于测试完全不同风格的数据集。结果显示，CBR 的引入带来了 **4.7% 到 9.6%** 的绝对性能增益。这表明 Memento 学习到的经验具备良好的迁移性。

![](https://pic4.zhimg.com/v2-17040d848c1f54ddf879ae46b1670d31_r.jpg)

### 4.4 超参数与成本分析

- **检索数量 K 的影响** ：实验发现，检索的案例数量并非越多越好。在 DeepResearcher 上，当 `K=4` 时性能达到峰值，继续增大 K 值反而可能引入噪声，导致性能轻微下降。这印证了 CBR「质量优于数量」的原则。
- **计算成本** ：由于 Memento 不涉及 LLM 微调，其学习成本极低，主要开销在于 Q 网络的少量在线更新和推理时的检索与 LLM 调用。这使其成为一种在经济上和技术上都高度可行的方案。

## 五、总结

### 5.1 贡献与启发

1. **冻结 LLM，学习记忆** ：为自适应智能体的发展开辟了一条与主流微调范式并行的、非参数化的新路径。
2. **理论与实践的结合** ：它成功地将经典的 CBR 和 RL 理论与现代 LLM 工程实践相结合，为 M-MDP 这一理论模型提供了一个强有力的实现和验证。
3. **实用价值** ：提供了一个 **低成本、可扩展** 的方案。这意味着开发者和企业无需投入巨额资源进行模型微调，也有可能构建出具备学习和自适应能力的 AI 应用，极大地降低了技术门槛。
4. **可解释性** ：通过分析智能体在决策时检索了哪些历史案例，可以在一定程度上理解其「思考过程」，相比于黑箱的微调，提供了一定的可解释性。

### 5.2 局限与挑战

1. **记忆库的膨胀与管理** ：论文中的案例库只会不断增长。如何有效管理一个庞大的记忆库，避免因低质量或冗余案例过多导致的「记忆沼泽」（swamping）问题，是一个重要的挑战。未来的研究可以探索记忆的 **遗忘、压缩、泛化与精炼机制** 。
2. **冷启动问题** ：在系统初始阶段，案例库是空的，CBR 无法发挥作用。如何度过冷启动期，或者如何利用少量高质量的种子案例进行预热，值得进一步研究。
3. **状态表示的局限性** ：目前的案例检索依赖于一个固定的文本编码器对任务状态进行表征。对于结构更复杂、或需要捕捉细微语义差异的任务，可能需要更先进的、甚至是可学习的状态表示方法。
4. **奖励信号的复杂性** ：实验中的奖励信号多为二元的（成功/失败）。在现实世界中，奖励可能是稀疏的、延迟的或连续的，这将给 Q 函数的学习带来更大的挑战。
