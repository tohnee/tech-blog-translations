## 一、场景整体架构概述（生产标准）

本次业务场景：

- **终端节点**：20万台GPU算力服务器（高密度、大流量、低时延、海量ARP/路由表项）
- **网络设备**：200台华为CE系列、华三S68/S12500数据中心交换机（接入、汇聚、核心、骨干分层部署）
- **核心诉求**：无环路、快速收敛、低转发时延、大规模表项承载、故障秒级切换、路由层级清晰、算力流量调度稳定

主流落地架构：**接入层大二层 + 汇聚/核心层三层路由**，底层消除二层环路，上层通过动态路由协议实现全网互通与容灾。

**全网协议生产选型（固定方案）**

- 接入层、汇聚层IGP：OSPF（运维简单、适配算力接入）
- 核心骨干IGP：IS-IS（大表项低震荡、低CPU开销）
- 出口跨网协议：BGP（路由稳定、支持超大组网）
- RIP：全网禁用，不支持大规模集群

## 二、二层网络核心知识点（生产必懂）+ 全套可投产配置 + 全量避坑点

二层网络工作在数据链路层，核心职责：**同网段终端转发、MAC地址学习、环路抑制、VLAN隔离、链路聚合扩容**，是20万GPU服务器接入的基础，90%集群抖动、广播风暴均来自二层配置错误。

### 2.1 核心基础知识点 + 华为/华三双版本配置

### 2.1.1 VLAN 虚拟局域网

**原理**：通过逻辑划分广播域，隔离不同业务、不同算力集群、不同租户流量，默认所有端口属于VLAN1。大规模GPU集群严禁全网VLAN1，必须按算力池、业务、租户划VLAN。

**端口模式**：

- **Access**：接入模式，连接GPU服务器终端
- **Trunk**：中继模式，交换机互联透传VLAN
- **Hybrid**：混合模式，特殊业务隔离使用

**生产强制规范**：Trunk端口禁止allow all，仅放行业务VLAN；所有服务器端口配置风暴抑制。

**华为完整配置**

```text
system-view
sysname POD1-ACC01
# 批量创建业务VLAN
vlan batch 10 20 30
# GPU服务器接入端口配置（Access+风暴抑制）
interface 100GigabitEthernet 0/0/1
 port link-type access
 port default vlan 10
 # 广播/组播/未知单播风暴抑制，防止20w终端风暴扩散
 storm-suppression broadcast 10000
 storm-suppression multicast 10000
 storm-suppression unknown-unicast 10000
 undo shutdown
# 交换机互联Trunk端口（严格按需放通）
interface 100GigabitEthernet 0/0/49
 port link-type trunk
 port trunk allow-pass vlan 10 20 30
 stp edged-port disable
 undo shutdown

```

**华三完整配置**

```text
system-view
sysname POD1-ACC01
vlan batch 10 20 30
# 服务器接入端口
interface HundredGigabitEthernet 1/0/1
 port link-mode bridge
 port access vlan 10
 storm-constrain broadcast 10000
 storm-constrain multicast 10000
 storm-constrain unknown-unicast 10000
 undo shutdown
# 设备互联Trunk端口
interface HundredGigabitEthernet 1/0/49
 port link-mode bridge
 port link-type trunk
 port trunk permit vlan 10 20 30
 stp edged-port disable
 undo shutdown

```

### 2.1.2 链路聚合 LACP（生产主流动态聚合）

**原理**：多物理100G/40G链路捆绑为逻辑聚合组，实现带宽叠加、链路冗余、单链路故障自动切换，解决算力大流量拥堵与单点故障。

**生产优化**：默认MAC哈希不均，超大流量必须开启**源目IP+端口**负载分担。

**华为 LACP 聚合完整配置**

```text
# 创建聚合组，动态LACP模式
interface Eth-Trunk 1
 mode lacp-static
 port link-type trunk
 port trunk allow-pass vlan 10 20 30
 # 超大算力流量专用负载分担
 load-balance src-dst-ip-port
 undo shutdown
# 物理端口加入聚合组
interface 100GigabitEthernet 0/0/49
 eth-trunk 1
interface 100GigabitEthernet 0/0/50
 eth-trunk 1

```

**华三 LACP 聚合完整配置**

```text
interface Bridge-Aggregation 1
 link-aggregation mode dynamic
 port link-type trunk
 port trunk permit vlan 10 20 30
 # 大流量负载分担优化
 link-aggregation load-sharing mode source-destination-ip l4-port
 undo shutdown
# 端口加入聚合组
interface HundredGigabitEthernet 1/0/49
 port link-aggregation group 1
interface HundredGigabitEthernet 1/0/50
 port link-aggregation group 1

```

### 2.1.3 MSTP 二层防环（算力集群唯一推荐）

**原理**：MSTP多生成树协议，解决STP收敛慢、RSTP无法多VLAN负载分担问题，实现二层无环路、链路负载分担、故障秒级切换。

**生产禁忌**：20w规模集群禁止使用STP，极易引发全网断流。

**华为 MSTP 全局完整配置**

```text
# 全局启用MSTP
stp mode mstp
# 配置MST域，全网设备域名、版本、实例映射必须一致
stp region-configuration
 region-name GPU-MST-CLUSTER
 revision-level 1
 instance 1 vlan 10 20
 instance 2 vlan 30
 active
# 核心设备手动配置根桥，固定拓扑
stp instance 1 root primary
stp instance 2 root secondary
# 服务器接入端口开启边缘端口，秒级UP、防震荡
interface 100GigabitEthernet 0/0/1
 stp edged-port enable

```

**华三 MSTP 全局完整配置**

```text
stp mode mstp
stp region-configuration
 region-name GPU-MST-CLUSTER
 revision-level 1
 instance 1 vlan 10 20
 instance 2 vlan 30
 active
# 核心根桥配置
stp instance 1 root primary
stp instance 2 root secondary
# 接入口边缘端口
interface HundredGigabitEthernet 1/0/1
 stp edged-port enable

```

### 2.1.4 MAC/ARP 超大规模优化（20w服务器专属）

**原理**：海量GPU服务器频繁上下线，默认MAC/ARP老化参数会导致表项爆满、网关卡顿、业务随机断流，必须专项优化，同时开启防欺骗、防漂移。

**华为优化配置**

```text
# MAC地址老化优化
mac-address aging-time 300
# 开启MAC漂移检测与告警
mac-address flapping detection
mac-address flapping alarm enable
# ARP防攻击、防冲突、防欺骗
arp anti-attack check duplicate-arp enable
arp anti-attack check arp-spoof enable
# 全局开启ARP严格学习
arp strict-learning global enable

```

**华三优化配置**

```text
mac-address aging-time 300
mac-address flapping detection enable
mac-address flapping alarm enable
arp anti-attack check duplicate-arp enable
arp anti-attack arp-spoof enable
arp strict-learning global enable

```

### 2.2 二层网络生产高频踩坑点（全覆盖）

**坑1：大规模集群使用STP协议**

STP收敛时间30s+，链路切换期间全网断流，20万GPU集群绝对禁止，必须使用MSTP/RSTP。

**坑2：Trunk端口允许所有VLAN通过（allow-pass all）**

生产高危配置，会导致VLAN穿透、业务串扰、广播风暴扩散，必须手动放行业务所需VLAN。

**坑3：链路聚合两端模式不匹配**

一端静态聚合、一端LACP，导致链路UP但不通、流量丢包，华为/华三设备严格要求两端聚合模式一致。

**坑4：MAC地址漂移未配置告警**

GPU集群流量极大，MAC漂移会导致服务器随机断流，必须开启设备MAC漂移检测+告警。

**坑5：VLAN1未做隔离**

所有端口默认在VLAN1，未手动划分VLAN会导致全网广播域过大，ARP风暴淹没CPU。

**坑6：二层端口未开启风暴抑制**

20万终端场景下，单端口广播、组播、未知单播风暴会瞬间扩散全网，必须配置风暴抑制阈值。

## 三、三层网络核心知识点 + 全套可投产配置 + 全量避坑点

三层网络工作在网络层，核心职责：**跨网段路由转发、网关终结、动态路由收敛、跨集群互通**。200台网络设备的核心/汇聚层全部为三层架构，是全网互通的核心。

### 3.1 三层核心基础知识点 + 双版本配置

### 3.1.1 VLANIF 三层网关（集群核心）

**原理**：VLANIF虚拟三层接口，作为对应VLAN内所有GPU服务器的默认网关。超大集群必须开启 **always-up**，避免VLAN内无终端导致网关Down、整网段断流。

**华为 VLANIF 网关配置**

```text
interface Vlanif 10
 ip address 10.0.10.1 255.255.255.0
 # 强制网关永久UP，解决空VLAN网关宕机问题
 vlanif always-up enable
 # 接口级ARP严格学习，防欺骗
 arp strict-learning enable

```

**华三 VLANIF 网关配置**

```text
interface Vlan-interface 10
 ip address 10.0.10.1 255.255.255.0
 vlan-interface always-up enable
 arp strict-learning enable

```

### 3.1.2 VRRP 双网关冗余（生产必备）

**原理**：两台核心网关组成VRRP组，虚拟IP作为服务器统一网关，实现单网关故障秒级切换，杜绝网关单点故障。配置延迟抢占，防止设备重启震荡。

示例：虚拟网关10.0.10.254，CORE1主用，CORE2备用

**华为 VRRP 主备完整配置**

```text
# CORE1 主网关
interface Vlanif 10
 ip address 10.0.10.1 255.255.255.0
 vrrp vrid 10 virtual-ip 10.0.10.254
 vrrp vrid 10 priority 120
 # 延迟30s抢占，防止重启震荡
 vrrp vrid 10 preempt-mode timer delay 30
 # 上行链路故障自动降优先级
 vrrp vrid 10 track interface 100GigabitEthernet0/0/49 reduced 30

# CORE2 备网关
interface Vlanif 10
 ip address 10.0.10.2 255.255.255.0
 vrrp vrid 10 virtual-ip 10.0.10.254
 vrrp vrid 10 priority 100
 vrrp vrid 10 preempt-mode timer delay 30

```

**华三 VRRP 主备完整配置**

```text
# CORE1 主网关
interface Vlan-interface 10
 ip address 10.0.10.1 255.255.255.0
 vrrp vrid 10 virtual-ip 10.0.10.254
 vrrp vrid 10 priority 120
 vrrp vrid 10 preempt-mode delay 30
 vrrp vrid 10 track interface HundredGigabitEthernet1/0/49 reduced 30

# CORE2 备网关
interface Vlan-interface 10
 ip address 10.0.10.2 255.255.255.0
 vrrp vrid 10 virtual-ip 10.0.10.254
 vrrp vrid 10 priority 100
 vrrp vrid 10 preempt-mode delay 30

```

### 3.1.3 路由优先级核心对照表（生产必背）

华为/华三优先级数值越小越优先：**直连0 > 静态60 > OSPF 10 > IS-IS 15 > RIP 100 > BGP 255**

### 3.2 三层网络生产高频踩坑点

**坑1：VLANIF接口Down导致整网段断流**

未开启always-up，VLAN无终端时网关下线，整网段业务中断。

**坑2：VRRP无延迟抢占**

设备重启立即抢占主角色，全网网关震荡、算力业务掉线。

**坑3：未开启ARP严格学习**

20w终端极易出现ARP欺骗、冲突，导致网关转发错乱。

**坑4：多协议混用不规划优先级**

出现次优路径、骨干链路拥堵、流量绕行。

## 四、四大动态路由协议 全知识点+全量生产配置+终极避坑

### 4.1 RIP 协议（纯学习、生产禁用）

**核心知识点**：距离矢量协议、最大15跳、收敛慢、无大规模组网能力，200台设备+20w服务器集群**禁止部署**。仅用于学习测试。

**华为 RIP V2 配置**

```text
rip 1
 version 2
 network 10.0.0.0
 undo summary
interface Vlanif 10
 rip split-horizon

```

**华三 RIP V2 配置**

```text
rip 1
 version 2
 network 10.0.0.0
 undo summary
interface Vlan-interface 10
 rip split-horizon

```

**RIP 致命坑点**：跳数限制、收敛震荡、无法承载大表项，大规模组网直接全网断流。

### 4.2 OSPF 协议（接入/汇聚层主力IGP）

**核心知识点**：链路状态协议、无环路、分层Area架构、中大型组网最优接入协议。核心规则：Area0骨干必须连续、ABR必须路由汇总、DR/BDR固定角色防重选。

**生产规划**：Area0骨干、Area1-POD1、Area2-POD2，汇聚设备作为ABR。

**华为 OSPF 生产完整版（含优化+认证+汇总）**

```text
ospf 1 router-id 10.255.0.1
 # 超大集群SPF震荡优化
 spf-schedule-interval 1 50
 # 关闭无用LSA刷新
 lsa-arrival-interval 1000
 # 骨干区域
 area 0
  network 10.0.0.0 0.0.0.255
 # 接入区域+路由汇总（20w集群必开，压缩路由表项）
 area 1
  network 10.0.10.0 0.0.0.255
  abr-summary 10.0.10.0 255.255.240.0
# 接口参数固化
interface Vlanif 10
 ospf area 1
 ospf cost 10
 ospf dr-priority 100
 ospf authentication-mode simple plain OSPF@GPU2026

```

**华三 OSPF 生产完整版**

```text
ospf 1 router-id 10.255.0.1
 spf timer 1 50
 lsa arrival 1000
 area 0
  network 10.0.0.0 0.0.0.255
 area 1
  network 10.0.10.0 0.0.0.255
  abr-summary 10.0.10.0 255.255.240.0
interface Vlan-interface 10
 ospf area 1
 ospf cost 10
 ospf dr-priority 100
 ospf authentication-mode simple plain OSPF@GPU2026

```

**OSPF 超大规模避坑点**

1. Area0不连续=全网路由断层；2. 不做路由汇总=核心表项爆满CPU宕机；3. DR/BDR动态选举=频繁重选震荡；4. Hello时间不匹配=邻居Down。

### 4.3 IS-IS 协议（核心骨干层主力IGP）

**核心知识点**：链路状态协议、报文精简、CPU开销极低、支持百万级表项，是200台以上设备超大集群骨干唯一优选协议。分层L1/L2，L2骨干必须连续。

**生产规划**：核心L2、汇聚L1/2、接入L1，L1渗透L2路由实现全网互通。

**华为 IS-IS 核心L2完整版配置**

```text
isis 1
 network-entity 49.0001.0000.0000.0001.00
 is-level level-2
 # 大集群防震荡优化
 timer lsp-refresh 600
 timer lsp-max-age 1200
 lsp-length originate 1492
# 骨干接口启用ISIS
interface Vlanif 10
 isis enable 1
 isis circuit-type level-2
 isis cost 20

```

**华为 汇聚L1/L2路由渗透配置**

```text
isis 1
 import-route isis level-2 into level-1

```

**华三 IS-IS 核心完整版配置**

```text
isis 1
 network-entity 49.0001.0000.0000.0001.00
 is-level level-2
 timer lsp-refresh 600
 timer lsp-max-age 1200
interface Vlan-interface 10
 isis enable 1
 isis circuit-type level-2
 isis cost 20

```

**IS-IS 避坑点**

1. NET地址错误直接断邻居；2. L2骨干断裂跨区域不通；3. 无路由渗透导致L1孤岛；4. 开销不规划导致流量不均。

### 4.4 BGP 协议（出口跨网专用）

**核心知识点**：EGP路径矢量协议、无跳数限制、路由稳定，仅用于数据中心出口、跨机房互联，内网不做转发。IBGP水平分割必须用路由反射器解决。

**生产规划**：双出口RR路由反射器，AS 65001，内网IGP承载，BGP只做出口选路。

**华为 BGP 路由反射器完整生产配置**

```text
bgp 65001
 router-id 10.255.0.1
 # 环回建立IBGP邻居
 peer 10.255.0.2 as-number 65001
 peer 10.255.0.2 connect-interface LoopBack0
 # 路由反射器客户端
 peer 10.0.0.0 reflect-client
 # 引入内网OSPF路由
 import-route ospf 1
 # EBGP多跳
 peer x.x.x.x ebgp-max-hop 10
 # 路由防泄露
 peer 10.255.0.2 route-policy BGP-OUT export

```

**华三 BGP 路由反射器完整生产配置**

```text
bgp 65001
 router-id 10.255.0.1
 peer 10.255.0.2 as-number 65001
 peer 10.255.0.2 connect-interface LoopBack0
 peer 10.0.0.0 reflect-client
 import-route ospf 1
 peer x.x.x.x ebgp-max-hop 10
 peer 10.255.0.2 route-policy BGP-OUT export

```

**BGP 致命避坑点**

1. 无路由反射器导致IBGP路由孤岛；2. 无路由策略导致内外网路由泄露；3. 多跳未配置邻居无法建立；4. 选路属性混乱导致出口拥堵。
