## The Value of Thinking: Learning When to Reason in Hybrid Decision Models

论文：《The Value of Thinking: Learning When to Reason in Hybrid Decision Models》（2026）

## 一、核心方法：两种推理模式

论文将模型输出分为了两种模式：

- **快速模式（Fast Mode）**：只调用一次前向传播，不生成推理 Token。<br>
- **慢速模式（Slow Mode）**：进行完整的显式推理。<br>

### 1. 提取特征

首先，提取两个信息：

1. LLM 某一层的隐藏状态 h_i。
2. 快速模式输出概率分布的 8 个统计特征 s_i。

把它们标准化、拼接，再输入一个轻量级 MLP：

o_i=\operatorname{softmax}\left( W_2\operatorname{GELU} \left(W_1[\tilde{h}_i;\tilde{s}_i]+b_1\right)+b_2 \right)

这个网络预测四种情况的概率：

| 情况 | 快速模式 | 慢速模式 |
| --- | --- | --- |
| 1 | 正确 | 正确 |
| 2 | 正确 | 错误 |
| 3 | 错误 | 正确 |
| 4 | 错误 | 错误 |

假设对应的概率分别为 o_1,o_2,o_3,o_4。

那么：

P(\text{Fast正确})=o_1+o_2

P(\text{Slow正确})=o_1+o_3

### 2. Value of Thinking（思考价值）

作者据此定义了 Value of Thinking：

\boxed{ v_i=\log\frac{P(\text{Slow正确})}{P(\text{Fast正确})} }

这里其实就是：

v_i=\log P(\text{Slow正确})-\log P(\text{Fast正确})

也就是比较两个正确概率的比值，再取对数，而不是直接计算概率差。

这个值衡量的是：显式推理相对于直接回答，预计能带来多少正确率收益。

然后设置一个思考价格 \lambda：

\boxed{ v_i>\lambda\Rightarrow \text{使用 Slow Mode} }

否则直接使用 Fast Mode 的答案。

这里的 \lambda 是每次进入慢速模式的价格，可以在推理时调整，而不需要重新训练路由网络。

## 二、训练方法

### 方法 A：自标注监督训练

适用于有标准答案的任务。

具体步骤：

1. 准备一批具有标准答案的问题。
2. 使用冻结的 Backbone，分别运行 Fast Mode 和 Slow Mode。
3. 比较两个模式的输出与标准答案。
4. 根据两种模式是否正确，生成前面提到的四分类标签。
5. 使用隐藏状态和统计特征训练路由 MLP。

训练目标就是普通的四分类交叉熵。

### 方法 B：CDPO（Calibrated Decision Policy Optimisation）

这是论文专门为多步 Agent 任务设计的方法。

因为 Agent 执行任务时，往往只有最终任务成功与否的奖励，无法直接知道某一步到底有没有必要进行推理。

所以作者提出了基于 PPO 的 CDPO。

**第一步：把是否进入慢速模式作为二元动作**

e_t\in{0,1}

其中：

- e_t=1：进行显式推理。<br>
- e_t=0：直接使用快速模式。<br>

路由策略采用：

\pi_\theta(e_t=1\mid x_t,\lambda_t) =\sigma\left(\frac{v_t-\lambda_t}{\tau}\right)

这里的 \tau 是温度参数，用来让原本硬性的阈值决策变成可训练的概率决策。

**第二步：对奖励进行指数折扣**

作者没有简单地使用任务最终奖励 R，而是根据整条轨迹进入慢速模式的次数，对奖励进行指数折扣：

\boxed{ G=R\exp\left(-\lambda\sum_t e_t\right) }

也就是说：

- 完成任务可以获得奖励。<br>
- 但调用慢速推理的次数越多，奖励折扣越大。<br>
- 如果快速模式已经足够完成任务，路由策略就有动力减少不必要的显式推理。<br>

**第三步：使用 PPO 优化路由策略**

最后，利用带有裁剪重要性比率的 PPO 目标优化路由策略，并使用相同价格条件下的平均回报作为 Baseline。
