> 「谁在定义个人智能体」系列 · 第 0 篇

2026 年这波个人智能体热潮，起点不在大公司，而是一个开源项目。

1 月下旬，奥地利程序员 Peter Steinberger 的业余项目 Clawdbot 在 GitHub 上走红。它是一个跑在你自己电脑上的 AI 助手，你通过 WhatsApp、Telegram 给它发消息，它替你查日历、回邮件、处理文件。上线第一天拿了约九千颗星。之后因为名字太像 Claude，被 Anthropic 发函要求改名，先改成 Moltbot，三天后又改成 OpenClaw。

2 月 14 日，Steinberger 宣布加入 OpenAI。Sam Altman 发帖说，他来是为了推动”下一代个人智能体”。OpenClaw 转给一个独立的开源基金会运营。

同月 25 日，开源实验室 Nous Research 发布了 Hermes Agent，口号是”和你一起成长的 Agent”，强调跨会话记忆和自己积累技能，几个月内拿到十几万颗星。

然后大公司陆续入场。5 月，Google 发布 Gemini Spark，叫”24⁄7 个人 AI 智能体”，媒体直接称它是 Google 版的 OpenClaw。6 月，Apple 发布 Siri AI。8 月，xAI 发布 Grok Bot，叫”AI 队友”。9 月三周之内，Meta 发布 Muse，Anthropic 把 Claude 的对话和 Cowork 合成一个产品，OpenAI 发布 dots。

国内也没闲着：6 月华为在开发者大会上把小艺定为”系统级智能体”，9 月豆包手机助手发布消费者版，vivo 和 OPPO 在同一周开了开发者大会，10 月阿里预告了 Personal Agent”千问 Go!“。

一年之内，”个人智能体”从论文里的词，先变成开发者圈子里的开源玩具，再变成大公司的产品名。

我开始整理这些材料的时候，以为大家说的是同一个东西。看下来发现不是。有的叫”助手”，有的叫”伴侣”，有的叫”队友”，有的叫”系统级智能体”，有的根本不提”个人”两个字。同样叫 personal agent 的，有的把重点放在”有一台自己的电脑”，有的放在”数据归用户所有”。

这个系列想做的事情很简单：把各家公司、实验室、开源项目、标准组织对 Personal Agent 和 Personal AI 的定义一家家摆出来，看清楚他们各自在说什么、为什么这么说。最后一篇，我会试着归纳出自己的一套框架。

这一篇是导读，先把全景讲清楚。

### 这个概念不新

“个人 AI”这个说法至少可以追到 2017 年。那一年 IEEE 立项了一个标准，编号 P7006，叫”个人数据 AI 代理”。它想解决的问题是：机器和机器之间越来越多地替人做决定，个人需要一个由自己控制的代理，替自己去协商数据怎么用。这个定义的出发点是数据权利，跟大模型没有关系。

2023 年 5 月，Inflection 发布了聊天机器人 Pi，名字是 personal intelligence 的缩写。创始人 Mustafa Suleyman 当时的说法是：品牌会有自己的 AI，网红会有自己的 AI，这些 AI 都和它们的主人站在一边；普通人也需要一个和自己利益一致的 AI，这才叫个人 AI。

2024 年，两份研究报告把这个概念讲得更完整。1 月，清华大学智能产业研究院牵头发布了一份综述，把”个人 LLM 智能体”定义为深度接入个人数据和个人设备、用来协助个人的智能体，还参照自动驾驶分了五级。4 月，Google DeepMind 发布了一份两百多页的伦理报告，讨论高级 AI 助手该如何在用户、开发者和社会之间平衡利益。

所以 2026 年变的不是概念，而是这东西第一次真的能用、真的有人在用。

### 为什么是 2026 年

做电脑操作型 Agent 的公司 Simular 总结了三个原因：模型看屏幕、点按钮的能力终于够用了；给每个用户配一台云电脑的成本降下来了；大平台认定聊天框不是终点。

我想补一条：开源项目先证明了需求。

OpenClaw 和 Hermes 都不是大公司做的，也都不需要你付订阅费，你得自己找台电脑或服务器装上，自己配模型的 API。门槛不低，但它们在几周内拿到了十万以上的星标，说明有一大批人已经愿意把邮箱、日历、文件交给一个常驻的 AI。大公司的产品是在这之后出来的，而且很多设计能看到开源项目的影子：多家媒体报道 Meta Muse 参照了 OpenClaw 的模式，小米的家庭智能方案直接以 Agent 形式接入了 OpenClaw，OpenAI 则直接把 OpenClaw 的作者请了过去。

开源项目和大公司产品的定义也因此有一个明显的差别。开源项目强调”跑在你自己的机器上、数据不离开你”，大公司产品强调”我们给你一台云电脑，你什么都不用管”。这个差别后面会反复出现。

### 叫法很乱

同样一类能力，各家的叫法差别很大：

| 来源 | 用的词 |
| --- | --- |
| OpenClaw | personal AI assistant（个人 AI 助手），自托管 |
| Hermes Agent | 和你一起成长的 Agent，自托管 |
| Meta、Google | personal AI agent（个人 AI 智能体） |
| OpenAI | always-on agents（常驻 Agent） |
| xAI | AI teammates（AI 队友） |
| Apple、Amazon | personal assistant（个人助手） |
| Microsoft | AI companion（AI 伴侣） |
| Anthropic | 不用这类说法 |
| 联想、IDC | 个人 AI、个人超级智能体 |
| 华为 | 系统级智能体 |
| vivo / OPPO | 个人化智能 / 个性化主动智能 |
| 阿里 | 个人 AI 助理 |

叫法不同不只是营销偏好。叫”助手”的公司，通常不承诺 AI 会自己去执行长任务；叫”伴侣”的，重点在关系和陪伴；叫”队友”的，是把它当成一个能干活的员工，场景更偏工作；叫”系统级智能体”的，是在说自己掌握着操作系统这个入口。名字里已经藏着各家的立场。

### 大家都同意的四件事

把这些定义放在一起看，有四点几乎所有人都同意。

**第一，只为一个人服务。** 不管叫什么，这类 AI 都是为一个具体的人配置、授权和记忆的，不是为一个团队或一家公司。Simular 的说法比较清楚：”个人”指的是为谁的目标服务，不是跑在哪里。

**第二，长期记得这个人。** 记住偏好、习惯、正在推进的事，下次不用重新交代。国内厂商喜欢说”越用越懂你”，Hermes 说”和你一起成长”，意思一样。

**第三，能替他动手。** 不只是给建议，而是真的去发邮件、改日程、下单、填表。Google 发布 Spark 时的说法是，让 Gemini 从回答问题的助手变成替你干活的助手。xAI 介绍 Grok Bot 时说，它会登录你的工具、像你一样使用它们，然后把做完的活交回来。

**第四，在他的授权范围内行动。** 正经做这件事的公司，都设计了审批机制：哪些事 AI 可以直接做，哪些要先问，哪些永远不能碰。OpenAI 的 dots 分了四档，改密码这类操作永远留给用户自己。

这四点可以当作”个人智能体”的最小定义。但它太宽了，宽到很多已有的产品都能套进去。真正有意思的是各家不一致的地方。

![](https://pic3.zhimg.com/v2-3af7bfd5c966026ecd28b3b267c791f6_r.jpg)

### 五处分歧

### 1. 叫助手还是叫智能体

Apple、Amazon 坚持叫助手，Microsoft 叫伴侣，xAI 叫队友。背后是风险偏好和场景选择：叫”智能体”就等于承诺它会自己去做事，做错了就是真的做错了，不是答错一句话那么简单。这部分在第 2 篇讲。

### 2. 电脑是你的，还是平台给的

Stratechery 的 Ben Thompson 9 月写过一句被到处引用的话：Agent 不只是 AI，而是能用电脑的 AI。

在”要有电脑”这一点上大家没分歧，分歧在电脑是谁的。OpenClaw、Hermes 跑在用户自己的电脑或服务器上；Meta、Google、OpenAI、xAI 给每个用户配一台云端虚拟机；国内手机厂商的定义几乎不提电脑，因为他们自己就是那台电脑。第 1、3、8 篇分别讲这三条路。

![](https://pic2.zhimg.com/v2-27a5cd3b436a7d2495ae86b65066546d_r.jpg)

### 3. 数据归谁

联想和 IDC 去年 12 月发布的白皮书，把”数据与算法主权归属于用户本人”直接写进了个人 AI 的定义。开源项目天然站在这一边，Hermes 的官网写着数据都留在你的机器上，没有遥测。海外大厂的产品多数跑在自己的云上，定义里很少提数据所有权，只有 Apple 把隐私当成核心卖点。这一点在第 3、7、8 篇都会涉及。

### 4. 它能不能绕过 App

个人 Agent 要替你办事，就得进别人家的 App 和网站。豆包手机助手去年 12 月用模拟点击的方式跨 App 操作，几天内就被各大应用封禁；Meta Muse 上线 12 天后被 Amazon 屏蔽了购物功能。之后中美两边几乎同时转向”协议”：豆包推出 SAEP，让 App 自己声明允不允许被自动操作；Meta 和 Sierra 发起了 Personal Agent Protocol，规定个人 Agent 怎么向企业表明身份、拿到权限。第 4 篇和第 7 篇讲这件事。

![](https://pic4.zhimg.com/v2-08c0b7371ad656e5f2fdb94bd4fc1071_r.jpg)

### 5. 分级的尺子不一样长

清华的综述分 L1 到 L5，2024 年信通院和荣耀的报告也是 L1 到 L5，但每一级的含义不同；2026 年 5 月发布的国家标准分 L1 到 L4；开发者平台 Vellum 分 L0 到 L6。四套分级没法直接对上。第 5 篇做一张对照表。

### 这个系列怎么读

接下来八篇的安排：

1. **海外激进派** ：Meta、Google、OpenAI、xAI 为什么都给 Agent 配了一台云电脑
2. **海外克制派** ：Apple、Amazon、Microsoft、Anthropic 为什么不叫它 Agent
3. **国内终端派** ：手机厂商眼里的个人智能体，就是操作系统本身
4. **国内互联网派** ：豆包、千问、元宝的入口之争
5. **分级篇** ：四套分级标准的对照
6. **研究与分析篇** ：学者和分析师在担心什么
7. **协议与身份篇** ：个人 Agent 出门办事，谁来放行
8. **开源与创业篇** ：OpenClaw、Hermes 和小公司们怎么定义

第 9 篇是我自己的框架。

每篇的写法基本一样：他们怎么说，他们为什么这么说，和别家比差在哪。定义会尽量回到原始发布材料，转述的地方会标清楚。
