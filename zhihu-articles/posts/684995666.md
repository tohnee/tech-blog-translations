## 二、MLP 模块张量并行

![](https://pica.zhimg.com/v2-3e04165ce8fef996d5d7911eef33bf74_r.jpg)

MLP 模块：Linear Layer --> Gelu --> Linear Layer --> Dropout

1. 将第一层 Linear Layer 的权重按 column 切分放置在不同的 Device 上，Input X 不切分
2. 将第二层 Linear Layer 的权重按 row 拆分放置在不同的 Device 上

Forward 时， $f$ 是 identity operator， $g$ 是 all reduce

Backward 时，$f$ 是 all reduce， $g$ 是 identity operator

这里有人会问，第一层 MLP Linear Layer 的权重是否可以按 row 切分? 其实也可以，但是这不是最优切分方式。

原始不切分时， $Y=\text{GeLU}(XA) $ ，如果按 row 切分：

![](https://pic2.zhimg.com/v2-4d0120d011c5e534efb51f1d90439ae7_1440w.jpg)

那么 $Y=\text{GeLU}(X_1A_1+X_2A_2) $

由于 GeLU 是非线性函数， $\text{GeLU}(X_1A_1+X_2A_2) \ne \text{GeLU}(X_1A_1)+\text{GeLU}(X_2A_2)$ ，因此需要先经过同步拿到完整的结果后，再送入 GeLU 函数，这样会增加通信开销。

## 三、Attention 模块张量并行

![](https://pic4.zhimg.com/v2-435ad1566a6aef708bc4cce26192986b_r.jpg)

1. 将 QKV 权重按 column 切分放置在不同的 Device 上，Input X 不切分
2. 将 Output Linear Layer 权重按 row 拆分放置在不同的 Device 上

Forward 时， $f$ 是 identity operator， $g$ 是 all reduce

Backward 时，$f$ 是 all reduce， $g$ 是 identity operator

## 四、总结

张量并行会增加通信耗时，由于卡间通信带宽较高，使用张量并行一般都在卡间使用，不会跨节点。另外 TP 越大，矩阵被切割的越小，gemm 计算量就会越小，也会导致 GPU 利用率下降。
