## 怎么读这张表

一是 0 不等于不招。智元的岗位放在飞书上，飞书的列表要签名，我们不绕过，所以读不到；星动纪元的 Moka 页这周没有新岗，但它在飞书上另有一个门户。读不到的公司我们整理成了一页，每家链到它自己的招聘页，点开直接看（链接在文末）。

二是新发少不等于机会少。在架的老岗位一样在招，只是这张表只看本周新出来的，适合每周扫一眼有没有新开的方向。

## 想每周自己拿到这张表

把 OpenHire 装进 ChatGPT、Claude、豆包、DeepSeek、Cursor 或腾讯 WorkBuddy 这类助手里（ChatGPT 在 设置 → 连接器 → 高级 → 开发者模式 里新建连接器，地址填 [https://openhire-vlny.onrender.com/mcp](https://openhire-vlny.onrender.com/mcp) ，不用装任何东西；DeepSeek 经 Cherry Studio 这类支持 MCP 的客户端）。能动手的助手，把这整段贴给它，装机、检查、出表一次做完：

```text
帮我装一个 MCP 服务：名字 openhire，启动命令 uvx openhire@latest serve。如果电脑上没有 uv，先帮我装 uv。

装好后检查：你现在能不能调用 openhire 的工具（比如 search_jobs）？
- 如果能，直接接着做下面的任务。
- 如果不能（需要重启或开新对话才能加载），就停下来，告诉我该怎么重启，不要用网页搜索或别的办法代替。我重启后会把这整段再贴一次。

任务：用 OpenHire 列出具身智能公司最近 7 天新发的岗位，按公司分组，带原始发布日期和投递链接。

我的简历只留在我电脑上，不要发给任何服务器。投递由我自己点链接去做。
```

只能聊天的助手，把这一行加进它的 MCP 配置，然后只贴上面「任务」那一句：

```json
{ "mcpServers": { "openhire": { "command": "uvx", "args": ["openhire@latest", "serve"] } } }
```

怕遇到假招聘？我把找工作的七步写成了一张清单：搜岗位、查公司、反诈骗三步、投递、盯岗，每一步写明 AI 助手能替你做什么、其余去哪个官方网站查，网址都给全了。免费，不用注册，网址会搬家、骗局会翻新，这页跟着改，值得收藏： [openhire-vlny.onrender.com/checklist](https://openhire-vlny.onrender.com/checklist)
