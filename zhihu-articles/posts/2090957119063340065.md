因为目前，同一时期，Anthropic 效果就是比 OpenAI 的效果好。

大家有这感觉吧。用过 AI 编程的都知道。

我也思考过为什么。

为什么 anthropic 的 Claude ，比 OpenAI 的 chatgpt 强那么多？百思不得其解呀！

![](https://picx.zhimg.com/v2-d297c53381ce5fa744204293374efc57_r.jpg)

![](https://pic4.zhimg.com/v2-550a6f0b15199fc2402ac8263e9d959f_r.jpg)

OpenAI 是很早就成立的公司，2015 年成立的。而 anthropic 一直到 2021 年才成立。整整差了 5 年，现如今技术上，Claude 无论哪个版本，都要明显比同时代的 chatgpt 要好点。

体感上，从 2025 年 1 月开始，Claude 始终要比 ChatGPT 要先进一个多月的差距。尤其是 sonnet3.5 一炮走红，太震撼了。

为什么？为什么？为什么？

我个人感觉，第一点是 OpenAI 它就像一个杂货铺一样，不够专注。什么都想捣鼓一下。一会儿视频、一会儿连接器、一会儿 APP、AI 浏览器、硬件、一会儿用户体验、AGI 、艺术、一会儿这个一会儿那个，喜欢玩大概念。在一个充满诱惑分散你注意力的世界中保持专注真的太难了。

![](https://pic1.zhimg.com/v2-970dd750dd29dcfa4a7ca19d4d4eb1f4_r.jpg)

然后 LLM 上分配到的精力就会少一点。创业公司不要专注于创造产品，而要专注于解决问题！！！

但是 anthropic 给我的感觉，就是死磕 LLM ，死磕 AGENT 技术，哪怕 UI 破破烂烂的，反正其他都是将就糊弄，就把 LLM 给做到最好。

确实啊，不管是人还是事儿，专注就是很重要。

![](https://pic3.zhimg.com/v2-40fab7e3f572fed95a747634095c6a88_r.jpg)

举个相比 AI 来讲，要俗气的例子，在老家，坚持做买卖十年的，基本有房有车； 常常改行的，生活水平基本都一般，为什么有的人到了四十岁，五十岁还在到处找工作，没有绝活，也从来没有专注过什么，就想赚点儿小钱过日子，慢慢思维固化，不求突破，永远都在社会的最底层挣扎，社会原本就是动物世界，每天都在现场直播人吃人，被人吃掉的，永远是小人物，弱者。

我说的没错吧！

做开发工具也是，阮一峰说过：节省几次击键的工具被高估了，保持注意力专注的工具被低估了。（所以建议大家以后开发时，要留意一下，开发那种帮我们保持注意力的工具）

OK ，回到正题。有大佬说，各大厂商的目标如下：

OpenAI 觉得全模态才能通往AGI，但太贵上下文太短没人用。

DeepSeek 觉得数学才能通往AGI，但数学几乎没实用价值。（deepseek做数学题的能力强的要死）

Anthropic 的编程路线是误打误撞碰到的，只有Cursor路线走对了。

这真的很切合我的印象。

然后 Anthropic 不知道怎么，尝到了 编程 的甜头后，就低头死磕编程，让 OpenAI 到处乱搞，让 Deepseek 天天研究数学。

然后，Anthropic 就开始神了！

但不能说 Anthropic 就赢了，因为从一个长久经营来看，只押 编程 一个赛道，无异于找死。会用编程的人，全世界也就程序员，程序员也都快失业完了，还屏蔽中国人，上限不高。而且最容易蒸馏。

而且，老板是个。算了，我不说了。

长久来看，OpenAI 还是有优势。其实，要不是 Sora 耽误了，现在应该也差不多。

哦，对了，最早最早的谷歌，deep mind ，现在声音好弱。
