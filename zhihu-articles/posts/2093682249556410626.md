2026 年 10 月 8 日 · 约 9 分钟 · 工程与基础设施

原作者：Tony Chang · InstaCloud CTO、联合创始人

2013 年，Google 给部分员工配了能在高速公路上自动驾驶的汽车。规则很简单：车负责开，你随时准备接管。

他们没有做好这个准备。几年后执掌 Waymo 的 John Krafcik <u>[向路透社描述](https://www.theregister.com/2017/10/31/google_waymo_ditched_autopilot/)</u> 了团队在车内摄像头里看到的场景：人们在打盹、化妆、玩手机，而车速 <u>[最高达到每小时 56 英里](https://cleantechnica.com/2017/11/01/googlewaymo-stopped-testing-level-3-self-driving-tech-testers-literally-fell-asleep-using-switched-full-autonomy/)</u> 。“我们发现的情况相当可怕，”他说，“他们已经失去了对周围情况的感知，很难再接管车辆。”

我经常想起这个故事，因为 Agent 现在就处在同样的位置。Agent 能完成工作，我们让人盯着它，然后人就不再盯了。

Anthropic 在 8 月 <u>[把 auto mode 设为 Claude Code 的默认模式](https://claude.com/blog/auto-mode-default-in-claude-code)</u> 时，公布了相关数据。用户会批准 97% 的权限提示。在一项有 1,053 名付费测试者参与的研究中，人工审查只拦下了 13.6% 的危险命令，自动检查则拦下了 89%。每个团队都会加上一个人工审核环节来保障 Agent 的安全，这个环节却成了系统最薄弱的部分。

![](https://pic4.zhimg.com/v2-a7a4537db64a2ef1df623a4658e5bee7_r.jpg)

Anthropic 对 1,053 名付费测试者的研究中，人工审查拦下 13.6% 的危险命令，自动检查拦下 89%。来源：Anthropic，《Auto mode 现在是 Claude Code 的默认模式》，2026 年 8 月。

自动驾驶行业在这个问题上领先了十年，我们即将进行的实验，它们已经做过了。我认为 Agent 工作会走上同一条路，所以有必要了解这条路是怎么走过来的。我自己也在其中。InsForge 的每位工程师都在 <u>[自己的 VPS](https://insforge.dev/blog/running-claude-code-in-the-cloud)</u> 上运行 Claude Code，我们有意把它对基础设施的访问设为只读。这就像给车安排一名安全员，而这个限制正是我加上的。

## 太长不看

- 汽车和 Agent 可以对应到相同的五个等级。区分等级的关键问题也相同：谁负责在出问题时兜底。
- Agent 卡在了 Level 3，人必须随时准备接管。无论是开车还是监督 Agent，人都不擅长持续保持这种状态。
- 增加护栏和审批提示，就像给一辆仍然需要司机的车增加传感器。它们有帮助，但不会改变自动化等级。
- Waymo 先划定地理围栏，在范围内积累真实行驶记录，与同一道路上的人类司机比较，表现更好后才扩大范围。Agent 也可以走这条路：每个任务都有自己的环境副本，出错的代价足够低。

## 相同的五个等级，相同的问题

自动驾驶等级来自 <u>[SAE J3016](https://wiki.unece.org/download/attachments/128418539/SAE%20J3016_202104.pdf)</u> 。把 Agent 工作放在旁边看，两者几乎能一一对应。

![](https://picx.zhimg.com/v2-b33612c47327baba087e599af16887ff_r.jpg)

我最关心 SAE 表格里“谁来兜底”那一列。Level 3 要求人处于“准备好接管”的状态，并在需要兜底时“成为驾驶者”。Level 4 则由系统自行兜底，“不预期用户需要介入”。汽车的 Level 4 和 Level 5 只差适用范围：这套能力能在限定区域内成立，还是能在任何地方成立。Agent 还多一项区别。Level 4 仍然由人审查结果，但审查限定在具体领域内；Level 5 则由 Agent 在所有领域相互检查成果。

此前已经有人划分过 Agent 的等级。Dan Shapiro 的 <u>[五个等级](https://simonwillison.net/2026/Jan/28/the-five-levels/)</u> 从“增强版自动补全”一直到无人审查代码的“黑灯工厂”； <u>[Knight Institute 的一篇论文](https://knightcolumbia.org/content/levels-of-autonomy-for-ai-agents-1)</u> 则按人的角色来定义等级。这两种划分都很好，都以人为中心。汽车行业的经验则把我们的目光转向了道路。

## 人在 Level 3 会睡着

研究自动化的人对这些现象并不意外。Lisanne Bainbridge 在 1983 年写下了讨论工厂和驾驶舱的论文 <u>[《自动化的悖论》](https://ckrybus.com/static/papers/Bainbridge_1983_Automatica.pdf)</u> 。其中一句话至今仍然适用：“即使一个人有很强的动机，也不可能对一个几乎没有变化的信息源持续保持有效的视觉注意力，超过大约半小时。”

Google 看过车内录像后，放弃了让人接管的方案，直接转向完全自动驾驶。Ford 在 2017 年 <u>[作出了同样的决定](https://cleantechnica.com/2017/02/20/ford-skip-level-3-autonomous-cars-even-engineers-supervising-self-driving-vehicle-testing-lose-situational-awareness/)</u> 。即使装上蜂鸣器和振动座椅，它的工程师仍然会在测试车里睡着。

即使司机保持清醒，接管也需要时间。《Transportation Research Part F》发表的一项 <u>[2014 年模拟器研究](https://doi.org/10.1016/j.trf.2014.09.005)</u> 发现，自动驾驶交回控制权后，司机大约需要 15 秒才能恢复控制，转向操作要过最多 40 秒才会稳定下来。在高速公路上，15 秒已经能开出很远。

Agent 的数据呈现出同样的衰减，连时间尺度都很接近。Anthropic 的研究中，会话刚开始时，人们能拦下约 17% 的危险命令；经历 50 次或更多提示后，这个数字降到了约 5%。Bainbridge 所说的半小时，在 Coding Agent 上也被测到了。

![](https://pic4.zhimg.com/v2-e1cbfd383d491010a31d4f6e31261cb9_r.jpg)

**会话刚开始：约 17%** 的危险命令被人工拦下。 **经历 50 次或更多提示后：约 5%** ，约为开始时的三分之一。人批准得越久，拦下的问题越少。来源：Anthropic，《Auto mode 现在是 Claude Code 的默认模式》，2026 年 8 月。

所以，有人说 Agent 还不够安全，必须有人监督时，接下来该问的是：跟什么相比？那个在审核环节里的人，正在不断点击同意。

## 多加传感器，不会改变等级

行业的本能是增加传感器。增加审批提示和护栏，改进分类器，再加几个仪表盘供人监看。这些措施中有些确实有用。auto mode 就比疲倦的人更善于识别危险，上面的数字已经说明了这一点。

但思路仍然停留在 Level 3。Agent 与生产环境行驶在同一条路上，我们不断提高拦截能力，希望在它撞上东西前把它停下来。

出错时会是什么样？今年 4 月，汽车软件创业公司 PocketOS 的一个 Coding Agent 正在预发布环境里 <u>[处理一项常规任务](https://www.theregister.com/software/2026/04/27/cursor-opus-agent-snuffs-out-startups-production-database/5224442)</u> 。它遇到了凭据问题，开始寻找解决办法，随后在一个无关文件里发现了 API token，权限远远超出了原本的预期。一次调用就删除了生产数据库，而备份也放在同一个地方，一起被删掉了。整个过程只用了九秒。最后，托管公司的 CEO <u>[亲自介入](https://www.theregister.com/software/2026/04/27/cursor-opus-agent-snuffs-out-startups-production-database/5224442)</u> ，才帮忙找回数据。

审查再仔细，也救不了这种情况。Agent 的确在预发布环境里，但它与生产环境之间只隔着一个 token。

## Waymo 接下来做了什么：划出一片区域

SAE 给自动驾驶系统适用的限定范围起了一个名字：运行设计域（operational design domain）。其中包括“环境、地理和时段限制”。说得简单一点，就是地理围栏。

Waymo 的发展过程，是把这个想法一步步落实。2018 年，加州为它发放了覆盖五个指定城镇的 <u>[无人驾驶测试许可](https://waymo.com/blog/2018/10/a-green-light-for-waymos-driverless-testing-in-ca/)</u> ：Mountain View、Sunnyvale、Los Altos、Los Altos Hills 和 Palo Alto。2020 年，它在凤凰城郊区的一部分区域向公众开放了 <u>[完全无人驾驶的乘车服务](https://waymo.com/blog/2020/10/waymo-is-opening-its-fully-driverless-service-in-phoenix/)</u> 。2023 年，旧金山的付费无人驾驶服务上线。截至今年 9 月，服务已进入 <u>[美国的 14 座城市](https://waymo.com/blog/2026/09/ride-in-denver-san-diego-tampa/)</u> ，每座城市都有自己的地理围栏。

![](https://pica.zhimg.com/v2-c1a23b44b3479706e9302d81e60b6b84_r.jpg)

灰色代表由人负责兜底的接管阶段；绿色代表在地理围栏内无需司机，并随着证据积累扩大范围。来源链接见正文。

Waymo 先把适用范围缩小到无需司机也能运行，再一座城市、一座城市地扩大。它并没有一直等待一辆能在任何地方行驶的车。

## 信任来自行驶记录

划定地理围栏只完成了一半。另一半是 Waymo 如何积累扩大范围的依据。

2016 年，RAND 试图算出要开多少里程，才能证明自动驾驶比人更安全。在 <u>[《Driving to Safety》](https://www.rand.org/pubs/research_reports/RR1478.html)</u> 中，它给出的答案是：要证明死亡事故率比人类低 20%，需要行驶超过 110 亿英里。如果有 100 辆车全天不停地开，大约需要 500 年。这个测试根本无法完成，所以 RAND 得出结论，企业“不能仅仅靠不断行驶来实现安全”。

真正起作用的是在限定范围内持续积累证据，再与人类的表现比较。截至今年 6 月，Waymo 已累计行驶 <u>[2.713 亿英里的无人驾驶里程](https://waymo.com/safety/impact/)</u> ，与同一道路上的人类司机相比，导致严重伤害的碰撞减少了 95%。 <u>[Swiss Re 的一项研究](https://waymo.com/blog/2024/12/new-swiss-re-study-waymo/)</u> 覆盖了其中的 2,530 万英里，发现实际发生了 9 起财产损失索赔，而人类司机在同样条件下预计会产生约 78 起。真实里程背后，还有数百亿英里的 <u>[模拟行驶](https://waymo.com/waymo-driver/)</u> ，以及一座建在旧空军基地上的 <u>[113 英亩封闭测试场](https://waymo.com/blog/2020/09/the-waymo-drivers-training-regime/)</u> 。

![](https://pic4.zhimg.com/v2-0f01338c26bebb029c5227d12c4bbb39_r.jpg)

在 2,530 万英里完全无人驾驶里程中发生的责任保险索赔，与人类司机行驶同等里程的预期索赔对比。来源：Waymo 与 Swiss Re，2024 年 12 月。

这些数字也经过了同行评审。Waymo 的安全研究人员在《Traffic Injury Prevention》上 <u>[发表了研究方法](https://doi.org/10.1080/15389588.2025.2499887)</u> 。在最初 5,670 万英里的无人驾驶里程中，他们测量的每一种伤害等级，其碰撞率都显著低于人类基准；没有任何一种碰撞类型的表现显著差于人类。 <u>[预印本](https://arxiv.org/abs/2505.01515)</u> 可以免费阅读。

评价 Agent 时，我们却反过来了。我们用基准测试评分，这相当于驾照考试的笔试部分，而且这些测试会饱和，也会发生数据泄漏。今年 2 月，OpenAI 发现前沿模型能凭记忆复现参考答案后， <u>[停止报告 SWE-bench Verified 的成绩](https://x.com/OpenAIDevs/status/2026002219909427270)</u> 。通过测试，也没有像我们希望的那样转化成实际工作的提升。METR 在 <u>[2025 年的一项随机对照试验](https://metr.org/blog/2025-07-10-early-2025-ai-experienced-os-dev-study/)</u> 中，让 16 名有经验的开发者完成 246 项真实任务。用了 AI 后，他们实际上慢了 19%，却以为自己快了 20%。

Agent 的“行驶日志”才刚刚开始出现。Anthropic 的 <u>[自主性研究](https://www.anthropic.com/research/measuring-agent-autonomy)</u> 统计了用户中断 Claude Code 的频率：新用户约在 5% 的轮次中介入，有经验的用户约为 9%。研究还指出，“我们的许多发现，仅靠部署前的测试无法观察到”。这就像一份自动驾驶接管报告。我们需要更多这样的记录，记录真实工作，再与同一项工作中由人逐步批准的方式比较。

## Agent 已经在两个场景里有了边界

看看人们已经愿意放手让 Agent 独立运行的地方。

第一个是深度研究。启动研究 Agent，离开二十分钟，再回来读报告，没人会批准每一次搜索。它用的通常还是与 Coding Agent 相同的模型，所以差别不在智能水平。浏览网页是只读操作，整个互联网都可以纳入这道围栏。

第二个是 Git 分支中的代码。没人会在 Agent 自己的分支里逐个批准它的键盘操作，你审查的是 Pull Request。有人决定合并之前，所有改动都留在分支内。Anthropic 发现，今天大多数 Agent 操作“风险低且可逆”。我们恰好给这些场景划出了边界。

接下来，Agent 需要执行数据库迁移、写入存储桶，或者部署服务，就会直接退回 Level 2。数据库、存储和运行中的服务无法像代码一样分支，因此每次写入都可能触及真实环境，必须有人批准，也就没有人在这些地方积累独立运行的记录。

模型能力已经不再是这里的阻碍。METR 对 Agent 可完成任务时长的测量显示，这个时长 <u>[大约每七个月翻一倍](https://metr.org/blog/2026-1-29-time-horizon-1-1/)</u> ，2024 年以来还在加速。METR 的 <u>[2025 年论文](https://arxiv.org/abs/2503.14499)</u> 介绍了测量方法，用熟练的人完成同一任务所需的时间衡量任务长度。Anthropic 把模型能处理的工作与人们实际允许它处理的工作之间的差距称为“部署积压”（deployment overhang）。车已经会开了，还缺一条能让它开上去的路。

## 给 Agent 一次重新开始的机会

基础设施的边界可以这样划。每个 Agent 任务都有整套环境的独立副本：包含真实数据的数据库、自己的存储，以及运行在独立 URL 上的应用。生产环境的凭据不会出现在这个副本里。Agent 删除一张表，删的是自己的表；发布了有问题的版本，坏的是自己的 URL。几秒钟就能丢掉这份环境，重新开始。

这就是一次重新开始的机会。Agent 可以出错后重来，人就不用一直盯着它。出错的代价足够低，我们终于可以允许错误发生，并统计它们。每项任务都会变成一段基于真实数据、可记录的“行驶里程”。人从批准五十个步骤，转为审查一个结果。

InstaCloud 正在构建的就是这套能力。 <u>`insta branch create`</u> 会为任务创建一个写时复制的 Postgres，打开时就带有父分支的数据，同时提供一个分叉的存储桶，以及已经运行着父分支应用的计算环境。Agent 在其中拥有完整写入权限， `insta agent events` 记录它做过的事情。工作结果符合要求，就像审查 Pull Request 一样将它提升；不符合要求，就删除分支。

![](https://pic3.zhimg.com/v2-bb34ffac0004cef7d4099f127e76b5e2_r.jpg)

每项任务都有整套环境的独立副本。错误留在虚线范围内，人只需审查一个结果，无需逐步批准。

然后像 Waymo 一样，按任务类型逐步扩大范围，用实际运行记录支持每一步。这也是我们让自己的 Agent 从只读走向可写的办法。

## 接下来会走到哪里

Agent 的 Level 5 是完全没有边界的生产环境。Agent 之间交接工作、相互检查结果，全程无需人介入。我不认为我们在所有领域都接近这个阶段了，而且大部分价值在 Level 4 就已经能实现。Waymo 没有达到 Level 5，也已经载过很多乘客。

Level 3 是一个阶段，汽车也是这样走过来的。最终做到无人驾驶的公司，没有把希望寄托在让人更专注上。它们先建立一个更小的适用范围，在其中证明车辆能够安全运行，再逐渐扩大范围。

Agent 正坐在 2013 年的那辆车里。我们已经知道汽车接下来的十年发生了什么，所以 Agent 不必再花十年走一遍。
