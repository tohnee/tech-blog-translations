## 1. Microsoft Learn MCP

**Microsoft Learn MCP Server** 的作用是 **为 AI 助手和代理（AI Agents）提供一个官方、实时更新的微软技术文档与代码示例检索通道** 。

**核心作用:**

- **消除 AI 幻觉与过时信息** ：大语言模型（LLM）的训练数据可能滞后，而该服务器允许 AI 直接查询最新的官方文档（如 Azure、.NET、Power BI 等），确保回答权威准确。
- **搜索与提取完整文档** ：支持 AI 客户端通过语义搜索查找、浏览并提取完整的 Markdown 格式技术文章。
- **发现代码示例** ：支持按编程语言过滤和检索官方的 Azure 和开发代码片段。
- **无缝集成主流 AI 客户端** ：可接入 GitHub Copilot 、VS Code、OpenCode, Codex, Claude等.

## 2. Rider MCP

从 2025.2 版本开始，JetBrains Rider 内置了 **MCP 服务器 ,** 作用是 **让外部的 AI 客户端和智能体（如 Claude Code、Claude Desktop、Cursor、VS Code、Codex、Windsurf 等）能够直接访问并操作 JetBrains Rider IDE 内部的深度上下文和开发工具** ，Rider 将该服务内置并默认启用。

## MCP配置

在项目目录中创建配置文件 `opencode.json`

```json
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "servers": {
      "microsoft-learn": {
        "type": "remote",
        "url": "https://learn.microsoft.com/api/mcp"
      },
      "rider": {
        "type": "remote",
        "url": "http://127.0.0.1:64482/stream",
        "headers": {
          "IJ_MCP_SERVER_PROJECT_PATH": "D:/codes/dotnet/aspcore/minimalapi/hello"
        },
        "oauth": false
      }
    }
  }
}
```

配置完成后,重新启动 OpenCode , 使用 `/mcps` 指令插件MCP配置是否成功加载
