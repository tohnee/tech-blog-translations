过去，一个高性能算子往往依赖算法工程师手写CUDA：管理线程绑定、分配共享内存、设计流水线、对齐Tensor Core。门槛高、调试周期长，而且高度依赖硬件经验。随着线性注意力、多模态、MoE、低比特量化、稀疏计算等新结构不断出现，算子形态变化越来越快，传统手写底层代码的方式已经很难跟上大模型的迭代节奏。而大模型直接写CUDA代码，最起码到今天为止，即使加成了各种skill、agent、toolcall，还是不具备泛化能力，只能水水论文，还是不能直接端到端用于生产高性能算子。

这正是近年来DSL密集出现的根本原因。DSL把算子开发中那些线程映射、内存层级调度、向量化、流水线重叠、指令选择等脏活累活交给编译器自动完成，让算法工程师把更多精力放在计算逻辑、数据流和性能瓶颈分析上。

CUTLASS之类的模板库把矩阵乘等常用算子进行了工程化，Triton用Python风格的DSL和block/tile级抽象降低了GPU内核开发门槛，能较快写出接近手写CUDA性能的算子，NVIDIA同时顺应民意，推出 cuTile，把编程单元进一步对齐到多维张量分块、TMA、Warp 组等新硬件特性；华为昇腾则发展出PyPTO等面向NPU的Tile级编程模型，这个PyPTO把昇腾原有的SPMD可以转为MPMD形式运行，还是有点儿东西的，改天有空开个专题讲一讲。北大计院主导开发并开源了TileLang，采用类Python的声明式语法和Tile级编程模型，支持从数学公式式描述到线程级原语控制的多层开发接口。

前面已经实现了Qwen3-8B的推理，但是性能较差，借着这个机会，加速加速Qwen3推理，顺便学习TileLang。

### TileLang：把”TILE”当一等公民

[TileLang](https://github.com/tile-ai/tilelang) 是构建在TVM/TIR之上的Python DSL，核心思路是：**计算按 tile 组织，内存层级由开发者显式管理，硬件映射（线程/Tensor Core/流水线）由编译器从tile描述推导**。官方给出的 GEMM、FlashAttention 示例能用几十行 Python逼近手写CUDA的性能。

有点绕的话，一句话来讲就是TileLang相对于Triton，控制粒度更细，可以自由控制搬运等逻辑。

### 语法速览

| 原语 | 作用 |
| --- | --- |
| T.Kernel(gx, gy, t) | 定义 Block 网格与每 Block 线程数 |
| T.alloc_shared(shape) | 声明共享内存（相当于 __shared__） |
| T.alloc_fragment(shape) | 声明寄存器片段（Tile 级别变量） |
| T.alloc_reducer(shape, dtype[, op, replication]) | 声明规约 |
| T.Parallel(m, n) | 自动并行化迭代 |
| T.Pipelined(n, stages) | 多级软件流水线 |
| T.copy(src, dst) | 自动并行数据传输 |
| T.gemm(A, B, C) | 调用最优矩阵乘实现 |
| T.cast(A, type) | 精度转换 |

**逐元素算子**：

```python
@tilelang.jit(out_idx=None, target="cuda")
def silu_mul_tl(rows: int, cols: int) -> Any:
    @T.prim_func
    def main(
        A: T.Tensor((rows, cols), "bfloat16"),
        B: T.Tensor((rows, cols), "bfloat16"),
        OUT: T.Tensor((rows, cols), "bfloat16"),
    ):
        with T.Kernel(T.ceildiv(cols, 256), rows, threads=256) as (bx, by):
            for j in T.Parallel(256):
                idx = bx * 256 + j
                if idx < cols:
                    a = T.cast(A[by, idx], "float32")
                    b = T.cast(B[by, idx], "float32")
                    sig = 1.0 / (1.0 + T.exp(-a))
                    OUT[by, idx] = T.cast(a * sig * b, "bfloat16")
    return main
```

要点：

`T.Kernel(...)` 声明 program 网格与线程数；

`T.Parallel` 的循环被编译器摊到线程上；

`T.cast` 显式管理精度转换。

**GEMM**（`gemm.py` 核心，注意三个 TileLang 特性）：

```python
with T.Kernel(T.ceildiv(N, _BLOCK_N), T.ceildiv(M, block_m), threads=128) as (bx, by):
    A_shared = T.alloc_shared((block_m, _BLOCK_K), "bfloat16")
    W_shared = T.alloc_shared((_BLOCK_N, _BLOCK_K), "bfloat16")
    C_local  = T.alloc_fragment((block_m, _BLOCK_N), "float32")
    T.clear(C_local)
    for k_tile in T.Pipelined(T.ceildiv(K, _BLOCK_K), num_stages=4):
        # 手写边界掩码 + 零填充，把 A/W 的 tile 搬进 shared
        ...
        T.gemm(A_shared, W_shared, C_local, transpose_B=True)
    # C_local 一次性写回 global
```

1. **`T.gemm(..., transpose_B=True)` 直接映射 Tensor Core MMA**，且允许 B 按 `[N, K]` 参与；
2. **`T.Pipelined(num_stages=4)`**：K维循环的软件流水（global→shared 预取与 MMA 重叠），一个参数替代手写的 multi-buffer；
3. **`T.alloc_fragment`**：寄存器级的累加器，fp32 累加、bf16 单次 round 写回。

**跨线程规约**（`rmsnorm.py`）：

```python
total = T.alloc_reducer((1,), "float32", op="sum", replication="all")
T.fill(total, 0)
for j in T.serial(0, D, 256):
    for i in T.Parallel(256):
        ...
        total[0] += v * v          # block 内跨线程求和
T.finalize_reducer(total)
scale = 1.0 / T.sqrt(total[0] / T.cast(D, "float32") + eps)
```

`T.alloc_reducer` 是给”每线程累加、最后归并”的规约原语；写完 `T.finalize_reducer` 之后所有线程看到同一份结果。

可以看出来啊，TileLang的优势还是非常大的，个人学习下来主要感觉用python写，语法相对来讲就要简单很多，而且**控制粒度介于Triton和CUDA之间**，shared/fragment/reducer都是显式的， 线程映射、MMA 发射、流水线调度等确定性比较高的都交给编译器；基本上想要的计算流程都能满足，表达能力比较强。

### 适配点

**前面已经展示了GEMM、RMSNORM、SILU等部分代码，接下来重点展示flash paged attention的DSL代码**

```python
@tilelang.jit(
    out_idx=None,          # 不自动分配输出，OUT 由调用方传入
    target="cuda",
    pass_configs={tilelang.PassConfigKey.TL_DISABLE_DATA_RACE_CHECK: True},
)
def main(
    # query： (num_rows, num_heads, head_dim)
    QBUF: T.Tensor((num_rows, num_heads, head_dim), "bfloat16"),
    # KV cache
    KV: T.Tensor((num_blocks, block_size, 2, num_kv_heads, head_dim), "bfloat16"),
    # block table
    BT: T.Tensor((bt_rows, bt_width), "int32"),
    # 每个query所属序列的有效长度。
    SEQLEN: T.Tensor((num_rows,), "int32"),
    # 每个query行属于哪条序列
    SEQID: T.Tensor((num_rows,), "int32"),
    # 每个query token在序列中的绝对位置
    POS: T.Tensor((num_rows,), "int64"),
    OUT: T.Tensor((num_rows, num_heads, head_dim), "bfloat16"),
):
    # grid = (num_rows, num_heads)：每个program处理一个 (query token, head) 对。
    with T.Kernel(num_rows, num_heads, threads=threads) as grid:
        bx: T.int32 = grid[0]   # query 行下标
        by: T.int32 = grid[1]   # query head 下标
        q_head: T.int32 = by
        # GQA 映射：多个 query head 共享一个 kv head。
        # num_heads // num_kv_heads 是分组比（如 32/8 = 4 个 q head 对应 1 个 kv head）。
        kv_head: T.int32 = by // (num_heads // num_kv_heads)

        seq: T.int32 = T.alloc_var(T.int32, SEQID[bx])
        q_pos: T.int64 = T.alloc_var(T.int64, POS[bx])
        seqlen: T.int32 = T.alloc_var(T.int32, SEQLEN[bx])

        # shared memory：Q 与当前 tile 的 K/V。
        # Q放shared是因为它要对32个token反复复用。
        q_shared = T.alloc_shared((head_dim,), "bfloat16")
        k_shared = T.alloc_shared((page_tokens, head_dim), "bfloat16")
        v_shared = T.alloc_shared((page_tokens, head_dim), "bfloat16")

        # fragment：逐元素乘积、归约后的 score、输出累加器。
        prod = T.alloc_fragment((page_tokens, head_dim), "float32")
        scores = T.alloc_fragment((page_tokens,), "float32")
        scores_shared = T.alloc_shared((page_tokens,), "float32")
        out_acc = T.alloc_fragment((head_dim,), "float32")

        run_max = T.alloc_var(T.float32, -3.0e38)
        run_sum = T.alloc_var(T.float32, 0.0)

        # 载入Q到shared memory。
        for d in T.Parallel(head_dim):
            q_shared[d] = QBUF[bx, q_head, d]

        # 清零输出累加器。
        for d in T.Parallel(head_dim):
            out_acc[d] = 0.0

        # 外层串行循环：按page_tokens(=32) 为单位流式扫描整条序列的KV。
        # 这里n_pages是以 page_tokens 为单位的逻辑块数，与cache的block_size无关；
        # 一个32-token块可能横跨多个cache页。
        n_pages: T.int32 = T.ceildiv(seqlen, page_tokens)
        for kb in T.serial(n_pages):
            base: T.int32 = kb * page_tokens

            for i, d in T.Parallel(page_tokens, head_dim):
                k_abs = T.alloc_var(T.int32, base + i)          # 逻辑 token 绝对下标
                page: T.int32 = T.alloc_var(T.int32, BT[seq, k_abs // block_size])  # 查物理页号
                in_page: T.int32 = k_abs % block_size           # 页内偏移
                live: T.bool = (k_abs < seqlen) and (T.cast(k_abs, "int64") <= q_pos)
                k_shared[i, d] = T.if_then_else(live, KV[page, in_page, 0, kv_head, d], T.cast(0, "bfloat16"))
                v_shared[i, d] = T.if_then_else(live, KV[page, in_page, 1, kv_head, d], T.cast(0, "bfloat16"))

            # 先把q·k的逐元素乘积写到 (32, head_dim) 的fragment，
            # 用float32累加避免bf16精度损失。
            for i, d in T.Parallel(page_tokens, head_dim):
                prod[i, d] = T.cast(q_shared[d], "float32") * T.cast(k_shared[i, d], "float32")
            # 沿d维归约，得到每个token的score。
            T.reduce_sum(prod, scores, dim=1)

            # 掩码与缩放
            for i in T.Parallel(page_tokens):
                k_abs = T.alloc_var(T.int32, base + i)
                live: T.bool = (k_abs < seqlen) and (T.cast(k_abs, "int64") <= q_pos)
                scores[i] = T.if_then_else(live, scores[i] * scale, -3.0e38)
            # 广播到 shared
            for i in T.Parallel(page_tokens):
                scores_shared[i] = scores[i]

            # 逐token行更新running max / running sum / out_acc。
            for i in T.serial(page_tokens):
                m_new = T.alloc_var(T.float32, T.max(run_max, scores_shared[i]))
                corr = T.alloc_var(T.float32, T.exp(run_max - m_new))
                # 当前 token 的未归一化权重。
                weight = T.alloc_var(T.float32, T.exp(scores_shared[i] - m_new))
                # 分母同步更新。
                run_sum = run_sum * corr + weight
                # 分子同步更新。
                for d in T.Parallel(head_dim):
                    out_acc[d] = out_acc[d] * corr + T.cast(v_shared[i, d], "float32") * weight
                run_max = m_new

        # 归一化输出
        inv: T.float32 = 1.0 / T.max(run_sum, 1.0e-30)
        for d in T.Parallel(head_dim):
            OUT[bx, q_head, d] = T.cast(out_acc[d] * inv, "bfloat16")
```

### 接入DeepInfer的Qwen3 8B

直接替换原有计算逻辑就好，此处考虑到一些兼容性问题，如果tilelang不可用，则回退到torch实现

```python3
class Qwen3MLP(nn.Module):
    def __init__(self, config: dict[str, Any]) -> None:
        super().__init__()
        hidden_size = config["hidden_size"]
        intermediate_size = config["intermediate_size"]
        self.gate_proj = nn.Linear(hidden_size, intermediate_size, bias=False)
        self.up_proj = nn.Linear(hidden_size, intermediate_size, bias=False)
        self.down_proj = nn.Linear(intermediate_size, hidden_size, bias=False)

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        if _tilelang_available(x) and x.dim() == 2 and x.dtype == torch.bfloat16:
            from deepinfer.model_executor.layers.tilelang_ops.cuda.silu_mul import silu_mul_tl

            gate = _fast_linear(x, self.gate_proj.weight)
            up = _fast_linear(x, self.up_proj.weight)
            h = torch.empty_like(gate)
            try:
                silu_mul_tl(gate.size(0), gate.size(1))(gate, up, h)
            except Exception:
                global _TILELANG_BROKEN
                if _TILELANG_MODE == "on":
                    raise
                _TILELANG_BROKEN = True
                return self.down_proj(nn.functional.silu(gate.float()) * up.float())
            return _fast_linear(h, self.down_proj.weight)
        return self.down_proj(nn.functional.silu(self.gate_proj(x)) * self.up_proj(x))
```
