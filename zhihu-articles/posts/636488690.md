## **写在前面**

目前大多采用Lora、P-tuning、QLora等方法针对6B、7B、13B模型进行训练，一般单张A100即可。但总有些领导让你全量参数训练模型（狗头保命），这时单张显卡装不下所有参数变量，一般采用模型并行方法来对模型参数进行拆分，主要包括：张量并行和流水线并行两种方法。

笔者今天给大家带来基于DeepSpeed框架对ChatGLM-6B的流水线并行实战。

[项目地址](https://github.com/liucongg/ChatGLM-Finetuning)

## **流水线并行**

流水线并行，顾名思义，将模型不同层放到不同的GPU设备中，在训练时训练数据按照流水线方式依次走完每个GPU设备，完成一次模型Forward和Backward。

![](https://pic2.zhimg.com/v2-e912dc01a189dc96aaf60e75bbc847bd_r.jpg)

通过上图可以看出，在训练过程中，GPU的利用率较低，在模型训练过程中，仅有一张GPU在工作，其他GPU均处于空闲状态。为了提高GPU的使用效率，常用方法有GPipe方法[1]、PipeDream方法[2]等。

GPipe方法，如下图所示，主要将mini-batch数据划分为多个micro-batch数据来提高GPU的使用效率，每个GPU处理完一个micro-batch数据后，将输出结果返回给下一个GPU后，开始处理一个新的micro-batch数据，每个micro-batch数据的梯度之和就是整个mini-batch数据的梯度结果。

![](https://pic3.zhimg.com/v2-0d60a4fa0e990c4ca49409d74fef1cdc_r.jpg)

但由于每个GPU计算必须需要前一个GPU设备的计算结果，虽然GPU使用效率有所提高，但仍然存在“气泡”时间。

其他方法可以阅读相关论文或者其他论文解读，本文不做过多介绍。

### **模型拆分**

将ChatGLM模型拆分成多层，分别放到不同GPU设备中。

Embedding层：

```python3
class EmbeddingPipeLayer(torch.nn.Module):
    def __init__(self, model: ChatGLMForConditionalGeneration):
        super().__init__()
        self.word_embeddings = model.transformer.word_embeddings
        self.weight = self.word_embeddings.weight

    def forward(self, ipt):
        input_ids, labels = ipt
        hidden_states = self.word_embeddings(input_ids)
        mask_token = 150001
        seqs = input_ids.tolist()
        mask_positions = [seq.index(mask_token) for seq in seqs]
        attention_mask = get_masks(input_ids, device=input_ids.device)
        position_ids = get_position_ids(input_ids, device=input_ids.device, mask_positions=mask_positions)
        hidden_states = hidden_states.transpose(0, 1).contiguous()
        return hidden_states, position_ids, attention_mask, labels
```

GLMBlock层：

```text
class GLMBlockPipeLayer(torch.nn.Module):
    def __init__(self, model: ChatGLMForConditionalGeneration, layer_idx):
        super().__init__()
        self.layer = model.transformer.layers[layer_idx]
        self.layer_idx = torch.tensor(layer_idx)

    def forward(self, ipt):
        hidden_states, position_ids, attention_mask, labels = ipt
        hidden_states = self.layer(hidden_states, position_ids, attention_mask, torch.tensor(self.layer_idx))[0]
        return hidden_states, position_ids, attention_mask, labels
```

Final Layernorm层：

```text
class FLNPipeLayer(torch.nn.Module):
    def __init__(self, model: ChatGLMForConditionalGeneration):
        super().__init__()
        self.final_layernorm = model.transformer.final_layernorm

    def forward(self, ipt):
        hidden_states, position_ids, attention_mask, labels = ipt
        hidden_states = self.final_layernorm(hidden_states)
        return hidden_states, labels
```

LM层：

```text
class LMPipeLayer(torch.nn.Module):
    def __init__(self, model: ChatGLMForConditionalGeneration):
        super().__init__()
        self.word_embeddings = model.transformer.word_embeddings
        self.weight = self.word_embeddings.weight

    def forward(self, ipt):
        hidden_states, labels = ipt
        logits = torch.nn.functional.linear(hidden_states, self.word_embeddings.weight)
        logits = logits.permute(1, 0, 2).contiguous()
        return logits, labels
```

Loss计算层：

```text
class LossPipeLayer(torch.nn.Module):
    def __init__(self, model: ChatGLMForConditionalGeneration):
        super().__init__()

    def forward(self, ipt):
        logits, labels = ipt
        shift_logits = logits[..., :-1, :].contiguous()
        shift_labels = labels[..., 1:].contiguous()
        loss_fct = CrossEntropyLoss()
        loss = loss_fct(shift_logits.reshape(-1, shift_logits.size(-1)), shift_labels.reshape(-1))
        return loss
```

### **模型封装**

将拆分的模型层，采用deepspeed模块进行封装。

```text
def get_model(model):
    layers = [TiedLayerSpec("word_embeddings", EmbeddingPipeLayer, model=model),
              *[LayerSpec(GLMBlockPipeLayer, model=model, layer_idx=idx) for idx in
                range(model.config.num_layers)],
              LayerSpec(FLNPipeLayer, model=model),
              TiedLayerSpec("word_embeddings", LMPipeLayer, model=model),
              LayerSpec(LossPipeLayer, model=model)]
    return layers

model = ChatGLMForConditionalGeneration.from_pretrained(args.model_name_or_path)
model_pipe = PipelineModule(layers=get_model(model), num_stages=args.num_stages)
engine, _, _, _ = deepspeed.initialize(model=model_pipe, config=ds_config, model_parameters=model_pipe.parameters())
```

其中，TiedLayerSpec封装参数相同的模块，num_stages表示将模型拆分到几张GPU设备上。

### **模型训练**

deepspeed采用pipeline训练时，采用train_batch获取损失。

```text
train_dataloader = iter(deepspeed.utils.RepeatingLoader(train_dataloader))
for step in range(args.num_train_epochs * num_update_steps_per_epoch):
    loss = engine.train_batch(data_iter=train_dataloader)
```

### **模型转化**

由于pipeline训练时，模型存在的变量名称与原始模型有所区别，因此在推理阶段，如果采用原始模型结构时，需要将保存模型进行变量名称转换。

```python3
model_static_dict = {}
for path in Path(pipeline_model_dir).iterdir():
    print("已经处理文件：{}".format(path))
    if not path.name.startswith('layer'):
        continue
    small_static_dict = torch.load(path, map_location="cpu")
    layer_i = int(path.name.split('-')[0].replace('layer_', ''))
    if layer_i == 0:
        model_static_dict["transformer.word_embeddings.weight"] = small_static_dict["word_embeddings.weight"]
    elif layer_i == 30:
        model_static_dict["lm_head.weight"] = small_static_dict["word_embeddings.weight"]
    elif layer_i == 29:
        for k, v in small_static_dict.items():
            model_static_dict["transformer." + k] = v
    else:
        for k, v in small_static_dict.items():
            model_static_dict["transformer." + k.replace("layer.", "layers.{}.".format(layer_i - 1))] = v

torch.save(model_static_dict, join(save_model_dir, "pytorch_model.bin"))
```

详细代码见Github中convert_model_to_hf.py文件。

### **训练结果**

采用三元组数据进行模型训练及测试，训练脚本：

```text
CUDA_VISIBLE_DEVICES=0,1,2,3 deepspeed --master_port 5524 train_pipeline.py \
 --train_path data/spo_0.json \
 --model_name_or_path ./ChatGLM-6B/ \
 --per_device_train_batch_size 14 \
 --max_len 1024 \
 --max_src_len 512 \
 --num_train_epochs 5 \
 --gradient_accumulation_steps 1 \
 --seed 1234 \
 --show_loss_step 20 \
 --num_stages 4 \
 --save_model_step 100 \
 --output_dir ./output-glm-pp
```

模型转换脚本

```text
python3 convert_model_to_hf.py \
 --ori_model_dir ./ChatGLM-6B/ \
 --pipeline_model_dir output-glm-pp/global_step300/ \
 --save_model_dir output-glm-pp/gs300/
```

## **总结**

虽然Lora、P-tuing等技术，使得13b模型也可以在单张A100上训练，但是如果模型参数量过大，单张显卡不足以加载训练模型时，流水线并行是必不可少的。

本文主要采用DeepSpeed针对ChatGLM进行流水线并行实验，但不涉及数据并行，如果想要数据并行和流水线并行一起使用的话，需要修改代码，本文不做过多介绍。
