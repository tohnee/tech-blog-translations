最近腾讯开源了统一的视觉语言模型 **[WeVisOne-VL](https://github.com/Tencent/WeVisOne-VL)**（提供 [WeVisOne-VL-2B](https://huggingface.co/tencent/WeVisOne-VL-2B) 和 [WeVisOne-VL-4B](https://huggingface.co/tencent/WeVisOne-VL-4B) 两个规格）。它最大的亮点在于**用一个统一模型覆盖了 6 类核心视觉感知任务**：

- `detect`（目标检测）
- `point`（关键点/目标指代定位）
- `count`（目标计数）
- `ocr`（文字识别与定位）
- `segment`（实例分割）
- `matting`（高精度 Alpha 抠图）

不过在实际工程落地时，直接用 PyTorch / Transformers 部署往往会遇到依赖重、端侧或纯 C/C++ 服务难以集成、显存/内存占用高等问题。因此，我基于 `ggml` 和 C++17 独立实现并开源了推理引擎——**WeVision.cpp**，目标就像 `llama.cpp` 之于大语言模型一样，让 **WeVisOne-VL** 能够零 Python 运行时依赖地跑在本地设备与生产服务中。

项目地址：

[https://github.com/yysu-888/WeVision.cpp](https://github.com/yysu-888/WeVision.cpp)

### **一、WeVision.cpp 的核心特性**

1. **纯 C++17 + `ggml` 独立引擎，无 Python 运行时依赖**<br>视觉编码器、多模态大语言模型（Prefill / Decode）、以及 Mask/Matting 解码分支全部在 `ggml` 计算图上完成，直接编译出单个可执行文件或动态/静态库。
2. **多后端开箱即用**<br>支持 **CPU**、**Apple Silicon Metal**、**NVIDIA CUDA**，通过 `--backend cpu|metal|cuda` 一键切换。
3. **支持 GGUF 转换与端侧量化**<br>仓库内提供转换脚本与量化工具，支持将 Hugging Face 权重转换为 GGUF 并量化为 `q4_k`、`q8_0` 等格式，大幅降低内存与显存占用。
4. **三种接入方式**

- **CLI 工具（`wevision-cli`）**：支持命令行直接推理、输出坐标/文本并渲染可视化结果图与 Mask/Alpha 平面。
- **纯 C API（`include/wevision.h`）**：提供标准 C ABI，方便嵌入 C/C++、Rust、Go、Swift 等任意宿主工程。
- **HTTP 服务（`wevision-serve`）**：模型启动时常驻加载，支持 `POST /infer` 提交推理请求并返回 JSON + Base64 PNG Mask/Alpha。

**三、实测推理耗时（`WeVisOne-VL-2B`，`q4_k`）**

**1. Apple M2（Metal 后端，`--min-pixels 16384 --max-pixels 262144`）**

| 推理阶段 | 稳态耗时 |
| --- | --- |
| preprocess | ~12 ms |
| vision | ~575–750 ms |
| prefill | ~560–700 ms |
| decode (11 tokens) | ~260–430 ms (25–42 tok/s) |
| mask (s4 + s2 + s1) | ~2950–3370 ms |
| postprocess | ~3 ms |

**2. NVIDIA CUDA（单卡 B200 ）**

| 任务类型 | WeVisOne-VL-2B 端到端耗时 |
| --- | --- |
| detect（目标检测） | 1037 ms |
| point（目标指代） | 1060 ms |
| count（目标计数） | 1066 ms |
| matting（高精度抠图） | 2135 ms |
| segment（实例分割） | 2593 ms |
| ocr（文字识别） | 11678 ms（达到 256-token 上限） |

### **四、三步快速上手**

> # 1. 编译（以 Apple Metal 为例，CUDA 可开启 -DWEVISION_GGML_CUDA=ON）<br>cmake -S . -B build-metal<br>cmake --build build-metal -j<br><br># 2. 转换并量化 Hugging Face 模型为 GGUF（2B / 4B 均支持）<br>python3 convert_wevisone_to_gguf.py /path/to/WeVisOne-VL-2B -o models/WeVisOne-VL-2B.gguf<br>./build-metal/wevision-quantize models/WeVisOne-VL-2B.gguf models/WeVisOne-VL-2B_q4_k.gguf q4_k<br><br># 3. 本地运行推理<br>./build-metal/wevision-cli models/WeVisOne-VL-2B_q4_k.gguf images/seabreeze.jpg \<br> --backend metal --task matting --query "boy" \<br> --visualize asset/seabreeze-overlay.png --output-prefix asset/seabreeze
