如果你说的是 **“使用 Python 创建一套可复用的提示词工程（Prompt Engineering）系统”** ，建议不要把 Prompt 简单写成一个字符串，而是把它设计成：

> **Prompt 模板 + 参数注入 + 角色定义 + 输出约束 + 上下文管理 + Prompt 版本管理 + 校验 + LLM 调用 + 评测**

这套方式特别适合你前面提到的 **Agent、小说改编、分镜生成、提示词优化、企业应用** 。

## 三、Python Prompt Template

可以自己实现一个简单版本。

```python
class PromptTemplate:

    def __init__(self, template: str):
        self.template = template

    def format(self, **kwargs):
        return self.template.format(**kwargs)
```

使用：

```python
template = PromptTemplate("""
你是一名专业的小说分析专家。

请分析下面的小说：

{content}

提取：
1. 人物
2. 人物关系
3. 场景
4. 冲突
5. 剧情节点
""")

prompt = template.format(
    content="张三走进房间，看到了正在等待他的李四..."
)

print(prompt)
```

## 四、进一步做成 Prompt Builder

实际项目中，我更推荐 Builder 模式。

```python
class PromptBuilder:

    def __init__(self):
        self.parts = []

    def role(self, content):
        self.parts.append(
            f"角色设定：\n{content}"
        )
        return self

    def task(self, content):
        self.parts.append(
            f"任务：\n{content}"
        )
        return self

    def context(self, content):
        self.parts.append(
            f"上下文：\n{content}"
        )
        return self

    def constraints(self, content):
        self.parts.append(
            f"约束：\n{content}"
        )
        return self

    def output_format(self, content):
        self.parts.append(
            f"输出格式：\n{content}"
        )
        return self

    def build(self):
        return "\n\n".join(self.parts)
```

使用：

```python
prompt = (
    PromptBuilder()
    .role("你是一名专业的影视剧本分析专家")
    .task("""
    分析小说并提取：
    1. 人物
    2. 人物关系
    3. 场景
    4. 核心冲突
    """)
    .context(novel)
    .constraints("""
    不允许虚构小说中不存在的人物。
    不允许修改原始剧情。
    """)
    .output_format("""
    {
        "characters": [],
        "relationships": [],
        "scenes": [],
        "conflicts": []
    }
    """)
    .build()
)
```

这样比：

```python
prompt = "你是一个专家，请分析小说......"
```

可维护性高很多。

## 五、企业级 Prompt 推荐结构

一个比较成熟的 Prompt，可以拆成：

```text
Role
↓
Objective
↓
Context
↓
Input
↓
Task
↓
Rules
↓
Constraints
↓
Reasoning Strategy
↓
Output Schema
↓
Examples
↓
Quality Criteria
```

例如：

```text
# ROLE

你是一名专业的短剧编剧。

# OBJECTIVE

将小说内容改编成适合短视频平台的短剧剧本。

# CONTEXT

故事背景：
{{story_background}}

人物信息：
{{characters}}

# INPUT

原始小说：
{{novel}}

# TASK

请完成：

1. 分析故事主线
2. 提取核心冲突
3. 重构剧情
4. 拆分剧情集数
5. 生成每集剧本

# RULES

1. 不得改变人物核心性格
2. 不得随意增加主要人物
3. 必须保持故事逻辑
4. 每集必须存在明确冲突

# OUTPUT

必须输出 JSON：

{
    "episodes": [
        {
            "episode": 1,
            "title": "",
            "summary": "",
            "conflict": "",
            "scenes": []
        }
    ]
}
```

## 六、Python 中加入变量系统

实际 Agent 系统中，Prompt 通常不是固定的。

例如：

```python
prompt = template.format(
    novel=novel,
    characters=characters,
    relationships=relationships,
    scenes=scenes,
    style="短剧",
    duration=60
)
```

可以建立统一 Context：

```python
class PromptContext:

    def __init__(
        self,
        user_input=None,
        characters=None,
        scenes=None,
        relationships=None,
        previous_result=None
    ):
        self.user_input = user_input
        self.characters = characters
        self.scenes = scenes
        self.relationships = relationships
        self.previous_result = previous_result
```

然后：

```python
context = PromptContext(
    user_input=novel,
    characters=characters,
    scenes=scenes
)
```

Prompt Engine：

```python
class PromptEngine:

    def render(self, template, context):

        return template.format(
            user_input=context.user_input,
            characters=context.characters,
            scenes=context.scenes,
            relationships=context.relationships
        )
```

## 七、Prompt 不应该直接和业务代码耦合

不推荐：

```python
def generate_story():

    prompt = """
    你是一名编剧...
    """

    response = llm.invoke(prompt)

    return response
```

推荐：

```python
class StoryAgent:

    def __init__(self, llm, prompt_engine):
        self.llm = llm
        self.prompt_engine = prompt_engine

    def run(self, novel):

        prompt = self.prompt_engine.render(
            "story_analysis",
            {
                "novel": novel
            }
        )

        return self.llm.invoke(prompt)
```

架构：

```text
StoryAgent
    │
    ├── PromptEngine
    │       │
    │       └── PromptTemplate
    │
    └── LLM
            │
            ├── OpenAI
            ├── Qwen
            ├── DeepSeek
            └── Ollama
```

这样以后换模型非常容易。

## 九、Prompt 自动优化

这也是你之前提到的 **Prompt Optimizer Agent** 。

可以设计成：

```text
用户 Prompt
     ↓
Prompt Analyzer
     ↓
问题识别
     ↓
Prompt Optimizer
     ↓
优化 Prompt
     ↓
Prompt Validator
     ↓
LLM
     ↓
质量评估
     ↓
反馈
     ↓
再次优化
```

例如：

```python
class PromptOptimizer:

    def optimize(self, prompt):

        optimizer_prompt = f"""
你是一名专业的 Prompt Engineer。

请分析下面的 Prompt：

{prompt}

检查：

1. 任务是否明确
2. 上下文是否完整
3. 是否存在歧义
4. 是否存在冲突要求
5. 输出格式是否明确
6. 是否存在不必要的信息
7. 是否可以提高稳定性

输出：

{{
    "problems": [],
    "suggestions": [],
    "optimized_prompt": ""
}}
"""

        return self.llm.invoke(optimizer_prompt)
```

## 十、Prompt Validator

Prompt 不能只生成，还要检查。

```python
class PromptValidator:

    def validate(self, prompt):

        errors = []

        if not prompt:
            errors.append("Prompt不能为空")

        if len(prompt) < 20:
            errors.append("Prompt过短")

        if "任务" not in prompt:
            errors.append("缺少任务定义")

        if "输出" not in prompt:
            errors.append("缺少输出格式")

        return {
            "valid": len(errors) == 0,
            "errors": errors
        }
```

进一步可以检查：

```text
✓ Role
✓ Task
✓ Context
✓ Input
✓ Constraints
✓ Output Format
✓ JSON Schema
✓ Variables
✓ Token Length
✓ Injection Risk
```

## 十一、结构化输出

企业 Agent 强烈建议：

```text
LLM
 ↓
JSON
 ↓
Pydantic
```

例如：

```python
from pydantic import BaseModel
from typing import List

class Character(BaseModel):
    name: str
    description: str

class StoryAnalysis(BaseModel):
    characters: List[Character]
    main_story: str
    conflicts: List[str]
```

LLM 返回：

```json
{
    "characters": [
        {
            "name": "张三",
            "description": "年轻商人"
        }
    ],
    "main_story": "......",
    "conflicts": [
        "商业竞争"
    ]
}
```

然后：

```python
result = StoryAnalysis.model_validate(data)
```

这样就不会完全依赖：

```python
json.loads(response)
```
