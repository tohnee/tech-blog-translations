很多人第一次听说Claude Code，第一反应是：

**国内能用吗？**

然后就关掉页面了。

我理解这个反应。Claude的模型服务在国内访问困难，这没办法。

但这里有一个认知盲区，值得认真说清楚：

![](https://pic2.zhimg.com/v2-63b66a1630fcd54b7e67006b07b1c2fd_r.jpg)

我反复对比了各种Agent工具之后，结论始终没变：目前最好用的Agent框架，还是Claude Code。 就算搭配国产模型跑，体验也比大多数竞品强。

这篇文章，就是给从来没装过Claude Code的朋友准备的。Mac、Windows都有。有魔法、没魔法都覆盖了。 安装流程是我和小伙伴用五六台电脑反复测试出来的，选的是最稳、最不容易翻车的路径。

## **Step 0：先判断你是哪种情况**

两个问题：① 你用的是Mac还是Windows？② 你有没有魔法（科学上网）？

四种组合，对应四条路径，下面分开说。

## **Step 1：安装Claude Code框架**

**🍎 Mac · 有魔法**

打开终端，粘贴这行命令，回车：

```bash
 curl -fsSL https://claude.ai/install.sh | bash
```

装完之后，终端可能提示安装路径没加进PATH变量，按照提示把那行echo命令跑一遍就解决了。

验证：输入`claude --version`，有版本号输出，成功。

**🍎 Mac · 没有魔法**

用Homebrew来装（macOS上「一行命令安装一切软件」的工具）。

**第一步：安装Homebrew**

```bash
 /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

按提示确认，等几分钟。

**第二步：**按终端给的提示，运行几行配置命令，让系统能找到brew。

**第三步：用Homebrew装Claude Code**

```bash
brew install --cask claude-code@latest
```

装完输入`claude`，能看到界面就成功了。

**🪟 Windows 前提条件**

Windows上，Claude Code通过Git Bash执行命令，必须先装Git：

```bash
 winget install Git.Git
```

（安装Git时关掉魔法，速度更快。）

**🪟 Windows · 有魔法**

```text
 irm https://claude.ai/install.ps1 | iex
```

**🪟 Windows · 没有魔法**

```bash
 winget install Anthropic.ClaudeCode
```

两种情况装完都输入`claude`验证一下。

> 互动一下你是Mac还是Windows？有没有遇到过安装失败的情况？评论区告诉我，我来帮你排查是哪个环节的问题。

## **Step 2：给Claude Code接上模型（CC Switch）**

框架装好了，接下来要给它配一个「大脑」。

有Claude官方账号的，直接登录就行。

没有账号的，用国产模型代替——**国内目前体验最接近Claude Opus 4.6的，是GLM-5.1**。没有GLM coding plan的，MiniMax M2.7和Kimi K2.5也都不错。

推荐用**CC Switch**工具，方便随时切换不同模型，比每次手改配置省事很多。

**Mac安装CC Switch**

```bash
brew tap farion1231/ccswitch                  
brew install --cask cc-switch
```

**Windows安装CC Switch**

去`[http://github.com/farion1231/cc-switch/releases](http://github.com/farion1231/cc-switch/releases)`下载安装包，双击安装，一路Next到底。

**配置模型（Mac和Windows操作相同）**

打开CC Switch，点Claude栏右上角加号，新增模型配置，填入：

· API Key（不知道怎么获取直接问任何一个AI）

· 选择对应的模型

其他字段CC Switch会自动填好，点「添加」完成。

## **Step 3：启动Claude Code**

```bash
claude
```

第一次启动有几个初始化设置：**颜色主题**（按喜好选）→ **安全提示**（直接回车跳过）→ **终端设置**（选推荐设置）→ 确认当前目录是否信任（选「是」）。

![](https://pic4.zhimg.com/v2-c47a751d71eb4ce26c8aca577c59755d_r.jpg)

## **Step 4：写你的CLAUDE.md——很多人忽略的关键一步**

能启动之后，你可以开始用了。但在正式深度使用之前，**有一件事我强烈建议先做：写好CLAUDE.md文件。**

![](https://picx.zhimg.com/v2-f9dd464ad100641324d8c177fcc91685_r.jpg)

**CLAUDE.md分两层：**

**全局CLAUDE.md**（`~/.claude/CLAUDE.md`）——只要打开Claude Code，不管进哪个项目都自动加载。写你是谁、你的工作原则。注意：**不要超过80行，内容跨项目通用。**

**项目CLAUDE.md**（放在每个项目根目录）——只在打开该项目时生效。**这个不用自己写**，进到项目文件夹，和Claude Code聊，告诉它你的需求，让它帮你起草一份。

**全局CLAUDE.md模板（只需要填「关于我」，其他部分直接复用）：**

```bash
 ## 关于我                  
[你的名字/身份，非程序员一定要写清楚]                  
我用Claude Code做[具体用途1]和[具体用途2]。                  

## 思维原则                  
所有决策从问题本质出发，不因「惯例如此」照搬。                  
不要谄媚，不要夸我的想法好。给我真实判断，方案有问题直接说。                  

## 约束先行                  
新项目先写CLAUDE.md，新目录先定结构约定。                  
已有规范的项目，严格遵守约定。                  

## 沟通方式                  
- 默认中文，代码命令变量名用英文                  
- 结论先行，再给理由                  
- 遇到模糊需求，先给最合理方案，再问是否调整                  

## 自主边界（红线，必须先问我）                  
- 删除文件、目录或git历史                  
- 修改.env、密钥、token、CI/CD配置                  
- 数据库schema变更或数据迁移                  
- git push、git rebase、强制推送                  
- 安装新的全局依赖或修改系统配置                  
- 公开发布（部署到生产、发文章等）                  

## 通用纪律                  
- 改完主动跑验证，不要只改不验                  
- 不要为了让代码跑起来注释掉报错，找根本原因                  
- 密钥token密码不进代码不进commit                  
- 大改动前先在Plan Mode出方案，我确认后再动手
```

## **最后说一句**

不是因为它来自Anthropic，而是因为它真的好用。就算你暂时用不了Claude的原生模型，搭配国产模型跑，也能感受到Agent框架该有的样子。
