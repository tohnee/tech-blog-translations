8 月中旬，我的 Claude 被封了。刚好那段时间我在度假，手上没安排太多工作要处理。幸好我还有一个 Codex，于是就先拿它顶上。结果这一顶，就顶到了现在。

原本我计划回来工作后，再注册一个 Claude 账号，先订一个 $20 的套餐养着，然后慢慢升级到 Max。但我重度拖延，加上那段时间 Codex 其实也能处理我手上的工作，所以一直没去注册 Claude。

紧接着，OpenAI 又发布了 GPT-6-Astra。网上对这个模型的评价褒贬不一，不过我觉得还好。没过多久，我们产品有一项非常重要的功能，就是通过这个模型完成的。从做实验到把功能开发出来，再到测试，差不多花了近一周时间，也用光了我之前攒下的所有重置卡，真的很费额度。后面又花了一周左右持续不断地修 bug、迭代，才慢慢稳定下来。这次迭代对我们来说至关重要。

这个功能背后的复杂度，我最清楚。我不知道如果用 Claude Code + Fable5.1 会花多久做出来，但这已经不重要了。重要的是，我意识到：一些复杂任务已经不再只有 Claude Code 能做出来了。

Fable5.1 和 Opus5.5 我都没用过。但大家把 Opus5.5 捧得很高，搞得我也很好奇，很想试试。接下来，我会重新注册一个 Claude 账号，先开一个 $20 的套餐养着，顺便看看 Opus5.5 到底有多厉害。

我也真心建议每个人都最好有一个 Claude 和 ChatGPT 的付费账号，哪怕只是 $20 的套餐也行。如果你是行业内的人，就更应该如此。你一定要去用一用世界上最好的模型和最好的 Harness 工具，才能体会到其中的不同。贫穷会限制想象力，这句话一点不假。
