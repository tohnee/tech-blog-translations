## 1.1 理论知识讲解

### 1.1.1 生成式AI概述

**什么是生成式AI：** 生成式AI是指能够创建新内容（文本、图像、音频、视频等）的人工智能技术，与判别式AI（分类、检测等）相对。

**核心特点：**

1. **创造性** ：能够生成全新的内容
2. **多样性** ：可以生成多种不同的输出
3. **质量高** ：生成的质量接近人类水平
4. **可控性** ：可以通过提示词控制生成内容

**主要应用领域：**

- 文本生成：文章、代码、对话
- 图像生成：艺术创作、设计、编辑
- 音频生成：音乐、语音、音效
- 视频生成：短视频、动画
- 多模态：图文、音视频结合

import torch
import torch.nn as nn
from typing import List, Optional

class TextGenerator:
    """文本生成器"""
    
    def __init__(self, model, tokenizer, device="cpu"):
        """
        初始化
        参数:
            model: 语言模型
            tokenizer: 分词器
            device: 设备
        """
        self.model = model
        self.tokenizer = tokenizer
        self.device = device
        self.model.to(device)
        self.model.eval()
    
    def generate(self, prompt: str, max_length: int = 100, 
                 temperature: float = 0.7, top_k: int = 50, 
                 top_p: float = 0.95, num_return_sequences: int = 1) -> List[str]:
        """
        生成文本
        参数:
            prompt: 提示词
            max_length: 最大生成长度
            temperature: 温度参数
            top_k: Top-K采样
            top_p: Top-P采样
            num_return_sequences: 生成序列数量
        返回:
            generated_texts: 生成的文本列表
        """
        # 编码提示词
        input_ids = self.tokenizer.encode(prompt, return_tensors="pt").to(self.device)
        
        # 生成
        with torch.no_grad():
            output_ids = self.model.generate(
                input_ids,
                max_length=max_length,
                temperature=temperature,
                top_k=top_k,
                top_p=top_p,
                num_return_sequences=num_return_sequences,
                do_sample=True,
                pad_token_id=self.tokenizer.eos_token_id
            )
        
        # 解码输出
        generated_texts = []
        for output_id in output_ids:
            generated_text = self.tokenizer.decode(output_id, skip_special_tokens=True)
            generated_texts.append(generated_text)
        
        return generated_texts
    
    def beam_search(self, prompt: str, max_length: int = 100, 
                    num_beams: int = 5, num_return_sequences: int = 1) -> List[str]:
        """
        束搜索生成
        参数:
            prompt: 提示词
            max_length: 最大生成长度
            num_beams: 束大小
            num_return_sequences: 生成序列数量
        返回:
            generated_texts: 生成的文本列表
        """
        # 编码提示词
        input_ids = self.tokenizer.encode(prompt, return_tensors="pt").to(self.device)
        
        # 生成
        with torch.no_grad():
            output_ids = self.model.generate(
                input_ids,
                max_length=max_length,
                num_beams=num_beams,
                num_return_sequences=num_return_sequences,
                early_stopping=True,
                pad_token_id=self.tokenizer.eos_token_id
            )
        
        # 解码输出
        generated_texts = []
        for output_id in output_ids:
            generated_text = self.tokenizer.decode(output_id, skip_special_tokens=True)
            generated_texts.append(generated_text)
        
        return generated_texts

### 1.2.1 生成模型原理

**生成模型类型：**

**GAN（生成对抗网络）：** 

- 生成器：生成假样本
- 判别器：判断真假
- 对抗训练：两者相互竞争

**VAE（变分自编码器）：** 

- 编码器：将数据编码到潜在空间
- 解码器：从潜在空间生成数据
- 概率建模：学习数据分布

**Diffusion（扩散模型）：** 

- 前向过程：逐步添加噪声
- 反向过程：逐步去噪
- 采样：从噪声生成数据

**前沿生成范式：**

**自回归生成（Autoregressive）** 

- 特点：逐步生成，每次预测下一个token
- 代表：GPT系列、LLaMA
- 优势：生成质量高，可控性强
- 挑战：生成速度随长度增加而下降

**掩码生成（Masked Generation）** 

- 特点：并行预测 masked tokens
- 代表：MAGE、MAR
- 优势：并行生成，速度快
- 挑战：需要特殊训练策略

**扩散概率模型（Diffusion Probabilistic Models）** 

- 特点：迭代去噪过程
- 代表：DDPM、DDIM、Stable Diffusion
- 优势：生成多样性好，训练稳定
- 挑战：计算资源需求高

**流匹配（Flow Matching）** 

- 特点：学习向量场进行生成
- 代表：Flowise、Rectified Flow
- 优势：采样步数少，收敛快

**一致性模型（Consistency Models）** 

- 特点：单步/少步生成
- 代表：LCM
- 优势：生成速度极快

**模型架构演进：**

```python
import torch.nn as nn
import torch.nn.functional as F

class Generator(nn.Module):
    """GAN生成器"""
    
    def __init__(self, latent_dim: int, output_dim: int):

        参数:

class VAE(nn.Module):
    """变分自编码器"""
    
    def __init__(self, input_dim: int, latent_dim: int):
        """
        初始化
        参数:
            input_dim: 输入维度
            latent_dim: 潜在空间维度
        """
        super(VAE, self).__init__()
        
        # 编码器
        self.encoder = nn.Sequential(
            nn.Linear(input_dim, 256),
            nn.ReLU(),
            nn.Linear(256, 128),
            nn.ReLU()
        )
        
        self.fc_mu = nn.Linear(128, latent_dim)
        self.fc_logvar = nn.Linear(128, latent_dim)
        
        # 解码器
        self.decoder = nn.Sequential(
            nn.Linear(latent_dim, 128),
            nn.ReLU(),
            nn.Linear(128, 256),
            nn.ReLU(),
            nn.Linear(256, input_dim),
            nn.Sigmoid()
        )
    
    def encode(self, x):
        """
        编码
        参数:
            x: 输入数据
        返回:
            mu: 均值
            logvar: 对数方差
        """
        h = self.encoder(x)
        mu = self.fc_mu(h)
        logvar = self.fc_logvar(h)
        return mu, logvar
    
    def reparameterize(self, mu, logvar):
        """
        重参数化
        参数:
            mu: 均值
            logvar: 对数方差
        返回:
            z: 潜在向量
        """
        std = torch.exp(0.5 * logvar)
        eps = torch.randn_like(std)
        return mu + eps * std
    
    def decode(self, z):
        """
        解码
        参数:
            z: 潜在向量
        返回:
            x: 重建数据
        """
        return self.decoder(z)
    
    def forward(self, x):
        """
        前向传播
        参数:
            x: 输入数据
        返回:
            x_recon: 重建数据
            mu: 均值
            logvar: 对数方差
        """
        mu, logvar = self.encode(x)
        z = self.reparameterize(mu, logvar)
        x_recon = self.decode(z)
        return x_recon, mu, logvar

class DiffusionModel(nn.Module):
    """扩散模型"""
    
    def __init__(self, input_dim: int, time_steps: int = 1000):
        """
        初始化
        参数:
            input_dim: 输入维度
            time_steps: 时间步数
        """
        super(DiffusionModel, self).__init__()
        
        self.time_steps = time_steps
        self.beta = torch.linspace(0.0001, 0.02, time_steps)
        self.alpha = 1 - self.beta
        self.alpha_bar = torch.cumprod(self.alpha, dim=0)
        
        self.model = nn.Sequential(
            nn.Linear(input_dim + 1, 256),
            nn.ReLU(),
            nn.Linear(256, 256),
            nn.ReLU(),
            nn.Linear(256, input_dim)
        )
    
    def forward_process(self, x_0, t):
        """
        前向过程：添加噪声
        参数:
            x_0: 原始数据
            t: 时间步
        返回:
            x_t: 加噪数据
            noise: 添加的噪声
        """
        noise = torch.randn_like(x_0)
        alpha_bar_t = self.alpha_bar[t]
        x_t = torch.sqrt(alpha_bar_t) * x_0 + torch.sqrt(1 - alpha_bar_t) * noise
        return x_t, noise
    
    def reverse_process(self, x_t, t):
        """
        反向过程：预测噪声
        参数:
            x_t: 加噪数据
            t: 时间步
        返回:
            noise: 预测的噪声
        """
        t_tensor = torch.tensor([t], dtype=torch.float32).unsqueeze(-1)
        x_t_with_t = torch.cat([x_t, t_tensor], dim=-1)
        noise = self.model(x_t_with_t)
        return noise
    
    def sample(self, shape):
        """
        采样
        参数:
            shape: 采样形状
        返回:
            x_0: 生成的数据
        """
        x_t = torch.randn(shape)
        
        for t in reversed(range(self.time_steps)):
            noise_pred = self.reverse_process(x_t, t)
            
            if t > 0:
                alpha_t = self.alpha[t]
                alpha_bar_t = self.alpha_bar[t]
                alpha_bar_t_prev = self.alpha_bar[t-1]
                
                beta_t = self.beta[t]
                noise = torch.randn_like(x_t)
                
                x_t = (1 / torch.sqrt(alpha_t)) * (
                    x_t - (1 - alpha_t) / torch.sqrt(1 - alpha_bar_t) * noise_pred
                ) + torch.sqrt(beta_t) * noise
            else:
                x_t = noise_pred
        
        return x_t
```

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class TextGenerator(nn.Module):
    """文本生成器"""
    
    def __init__(self, vocab_size: int, embed_dim: int, 
                 hidden_dim: int, num_layers: int = 2):
        """
        初始化
        参数:
            vocab_size: 词汇表大小
            embed_dim: 嵌入维度
            hidden_dim: 隐藏层维度
            num_layers: 层数
        """
        super(TextGenerator, self).__init__()
        
        self.embedding = nn.Embedding(vocab_size, embed_dim)
        self.lstm = nn.LSTM(embed_dim, hidden_dim, num_layers, batch_first=True)
        self.fc = nn.Linear(hidden_dim, vocab_size)
    
    def forward(self, x, hidden=None):
        """
        前向传播
        参数:
            x: 输入序列
            hidden: 隐藏状态
        返回:
            output: 输出
            hidden: 隐藏状态
        """
        x = self.embedding(x)
        output, hidden = self.lstm(x, hidden)
        output = self.fc(output)
        return output, hidden
    
    def generate(self, start_token: int, max_length: int, 
                 temperature: float = 1.0, top_k: int = 0) -> list:
        """
        生成文本
        参数:
            start_token: 起始token
            max_length: 最大长度
            temperature: 温度
            top_k: top-k采样
        返回:
            tokens: 生成的token列表
        """
        self.eval()
        tokens = [start_token]
        hidden = None
        
        with torch.no_grad():
            for _ in range(max_length):
                x = torch.tensor([[tokens[-1]]])
                output, hidden = self(x, hidden)
                
                # 应用温度
                logits = output[0, -1] / temperature
                
                # Top-k采样
                if top_k > 0:
                    values, indices = torch.topk(logits, top_k)
                    logits = torch.full_like(logits, float('-inf'))
                    logits[indices] = values
                
                # 采样
                probs = F.softmax(logits, dim=-1)
                next_token = torch.multinomial(probs, 1).item()
                
                tokens.append(next_token)
                
                if next_token == 0:  # 假设0是结束符
                    break
        
        return tokens
```

```python
import torch.nn as nn

class ImageGenerator(nn.Module):
    """图像生成器"""
    
    def __init__(self, latent_dim: int, image_channels: int = 3):
        """
        初始化
        参数:
            latent_dim: 潜在空间维度
            image_channels: 图像通道数
        """

        self.model = nn.Sequential(
            nn.ConvTranspose2d(latent_dim, 512, 4, 1, 0),
            nn.BatchNorm2d(512),
            nn.ReLU(),
            
            nn.ConvTranspose2d(512, 256, 4, 2, 1),
            nn.BatchNorm2d(256),
            nn.ReLU(),
            
            nn.ConvTranspose2d(256, 128, 4, 2, 1),
            nn.BatchNorm2d(128),
            nn.ReLU(),
            
            nn.ConvTranspose2d(128, 64, 4, 2, 1),
            nn.BatchNorm2d(64),
            nn.ReLU(),
            
            nn.ConvTranspose2d(64, image_channels, 4, 2, 1),
            nn.Tanh()
        )
    
    def forward(self, z):

        前向传播
        参数:
            z: 潜在向量
        返回:
            x: 生成的图像
        """
        x = z.view(z.size(0), z.size(1), 1, 1)
        return self.model(x)

class ConditionalGenerator(nn.Module):
    """条件生成器"""
    
    def __init__(self, latent_dim: int, num_classes: int, image_channels: int = 3):
        """
        初始化
        参数:
            latent_dim: 潜在空间维度
            num_classes: 类别数
            image_channels: 图像通道数
        """
        super(ConditionalGenerator, self).__init__()
        
        self.label_embedding = nn.Embedding(num_classes, latent_dim)
        
        self.model = nn.Sequential(
            nn.ConvTranspose2d(latent_dim * 2, 512, 4, 1, 0),
            nn.BatchNorm2d(512),
            nn.ReLU(),
            
            nn.ConvTranspose2d(512, 256, 4, 2, 1),
            nn.BatchNorm2d(256),
            nn.ReLU(),
            
            nn.ConvTranspose2d(256, 128, 4, 2, 1),
            nn.BatchNorm2d(128),
            nn.ReLU(),
            
            nn.ConvTranspose2d(128, 64, 4, 2, 1),
            nn.BatchNorm2d(64),
            nn.ReLU(),
            
            nn.ConvTranspose2d(64, image_channels, 4, 2, 1),
            nn.Tanh()
        )
    
    def forward(self, z, labels):
        """
        前向传播
        参数:
            z: 潜在向量
            labels: 类别标签
        返回:
            x: 生成的图像
        """
        label_emb = self.label_embedding(labels)
        x = torch.cat([z, label_emb], dim=1)
        x = x.view(x.size(0), x.size(1), 1, 1)
        return self.model(x)
```

```abap
import torch.nn as nn

class MultiModalGenerator(nn.Module):
    """多模态生成器"""
    
    def __init__(self, text_vocab_size: int, text_embed_dim: int,
                 latent_dim: int, image_channels: int = 3):
        """
        初始化
        参数:
            text_vocab_size: 文本词汇表大小
            text_embed_dim: 文本嵌入维度
            latent_dim: 潜在空间维度
            image_channels: 图像通道数
        """

        # 文本编码器
        self.text_embedding = nn.Embedding(text_vocab_size, text_embed_dim)
        self.text_encoder = nn.LSTM(text_embed_dim, latent_dim, 2, batch_first=True)
        
        # 图像生成器
        self.image_generator = nn.Sequential(
            nn.Linear(latent_dim, 512),
            nn.ReLU(),
            nn.Linear(512, 1024),
            nn.ReLU(),
            nn.Linear(1024, 64 * 64 * image_channels),
            nn.Tanh()
        )
    
    def encode_text(self, text):
        """
        编码文本
        参数:
            text: 输入文本
        返回:
            latent: 潜在表示
        """
        x = self.text_embedding(text)
        output, (h_n, c_n) = self.text_encoder(x)
        latent = h_n[-1]
        return latent
    
    def generate_image(self, latent):
        """
        生成图像
        参数:
            latent: 潜在表示
        返回:
            image: 生成的图像
        """
        x = self.image_generator(latent)
        image = x.view(x.size(0), 3, 64, 64)
        return image
    
    def forward(self, text):
        """
        前向传播
        参数:
            text: 输入文本
        返回:
            image: 生成的图像
        """
        latent = self.encode_text(text)
        image = self.generate_image(latent)
        return image
```

```python
import torch
import torch.nn as nn
import numpy as np
from scipy import linalg

def calculate_bleu(reference: list, hypothesis: list, n: int = 4) -> float:
    """
    计算BLEU分数
    参数:
        reference: 参考文本
        hypothesis: 生成文本
        n: n-gram大小
    返回:
        bleu: BLEU分数
    """
    # 简化版实现
    from collections import Counter
    
    def get_ngrams(tokens, n):
        ngrams = []
        for i in range(len(tokens) - n + 1):
            ngrams.append(tuple(tokens[i:i+n]))
        return Counter(ngrams)
    
    ref_ngrams = get_ngrams(reference, n)
    hyp_ngrams = get_ngrams(hypothesis, n)
    
    overlap = sum((ref_ngrams & hyp_ngrams).values())
    total = sum(hyp_ngrams.values())
    
    if total == 0:
        return 0.0
    
    precision = overlap / total
    return precision

def calculate_fid(real_images: np.ndarray, generated_images: np.ndarray) -> float:
    """
    计算FID分数
    参数:
        real_images: 真实图像
        generated_images: 生成图像
    返回:
        fid: FID分数
    """
    # 简化版：使用Inception模型提取特征
    # 实际应用中应使用预训练的Inception模型
    
    mu_real = np.mean(real_images, axis=0)
    mu_gen = np.mean(generated_images, axis=0)
    
    sigma_real = np.cov(real_images, rowvar=False)
    sigma_gen = np.cov(generated_images, rowvar=False)
    
    diff = mu_real - mu_gen
    covmean = linalg.sqrtm(sigma_real.dot(sigma_gen))
    
    if np.iscomplexobj(covmean):
        covmean = covmean.real
    
    fid = diff.dot(diff) + np.trace(sigma_real + sigma_gen - 2 * covmean)
    return fid
```

## 1.4 模型微调技术

### 1.4.1 微调概述

**什么是模型微调：** 模型微调（Fine-tuning）是指在预训练模型的基础上，使用特定领域的数据进行进一步训练，使模型适应特定任务或领域的技术。

**为什么需要微调：**

1. **领域适配** ：将通用模型适配到特定领域（如医疗、法律）
2. **任务定制** ：针对特定任务优化（如情感分析、问答）
3. **成本效率** ：相比从头训练，微调成本更低
4. **数据效率** ：在少量数据上即可获得良好效果

**微调与传统训练对比：**

| 方面 | 从头训练 | 微调 |
| --- | --- | --- |
| 数据需求 | 数十亿tokens | 数千到数百万tokens |
| 计算资源 | 数百至数千GPU | 1-8 GPU |
| 训练时间 | 数周至数月 | 数小时至数天 |
| 效果 | 从零开始 | 继承预训练能力 |

### 1.4.2 全参数微调

**全参数微调（Full Fine-tuning）：** 微调模型的所有参数。

```python
import torch
import torch.nn as nn
from transformers import AutoModelForCausalLM, AutoTokenizer, TrainingArguments
from datasets import Dataset

class FullFineTuner:
    """全参数微调器"""

    def __init__(self, model_name: str, output_dir: str):
        """
        初始化
        参数:
            model_name: 模型名称
            output_dir: 输出目录
        """
        self.model_name = model_name
        self.output_dir = output_dir
        self.tokenizer = AutoTokenizer.from_pretrained(model_name)
        self.model = AutoModelForCausalLM.from_pretrained(
            model_name,
            torch_dtype=torch.float16,
            device_map="auto"
        )

    def prepare_dataset(self, texts: list, labels: list = None):
        """
        准备数据集
        参数:
            texts: 文本列表
            labels: 标签列表
        返回:
            dataset: 处理后的数据集
        """
        def tokenize_function(examples):
            return self.tokenizer(
                examples["text"],
                padding="max_length",
                truncation=True,
                max_length=512
            )

        dataset = Dataset.from_dict({"text": texts})
        if labels:
            dataset = dataset.add_column("labels", labels)

        dataset = dataset.map(tokenize_function, batched=True)
        return dataset

    def fine_tune(self, train_dataset, eval_dataset=None,
                  epochs: int = 3, batch_size: int = 8,
                  learning_rate: float = 5e-5):
        """
        微调模型
        参数:
            train_dataset: 训练数据集
            eval_dataset: 评估数据集
            epochs: 训练轮数
            batch_size: 批次大小
            learning_rate: 学习率
        """
        training_args = TrainingArguments(
            output_dir=self.output_dir,
            num_train_epochs=epochs,
            per_device_train_batch_size=batch_size,
            learning_rate=learning_rate,
            evaluation_strategy="epoch" if eval_dataset else "no",
            save_strategy="epoch",
            load_best_model_at_end=True,

            model=self.model,
```

**全参数微调的优缺点：**

- ✅ 能够充分适应新领域
- ✅ 效果通常最好
- ❌ 需要大量GPU显存
- ❌ 训练成本较高

### 1.4.3 参数高效微调（PEFT）

**PEFT技术概述：** 参数高效微调（Parameter-Efficient Fine-Tuning）通过只训练少量参数来达到接近全参数微调的效果。

**主流PEFT方法：**

| 方法 | 原理 | 参数量 | 效果 |
| --- | --- | --- | --- |
| LoRA | 注入低秩矩阵 | 1-5% | 接近全参数 |
| Prefix-Tuning | 添加前缀向量 | % | 较好 |
| Prompt Tuning | 学习提示向量 | <0.1% | 依赖模型规模 |
| Adapter | 插入适配器层 | 1-3% | 接近全参数 |

**LoRA微调实现：**

```python
import torch
import torch.nn as nn
from transformers import AutoModelForCausalLM, AutoTokenizer
from peft import LoraConfig, get_peft_model, TaskType

class LoRAFineTuner:
    """LoRA微调器"""

    def __init__(self, model_name: str, lora_rank: int = 8,

            device_map="auto"

            target_modules=["q_proj", "v_proj", "k_proj", "o_proj"],
            bias="none",
            inference_mode=False
        )

        self.model = get_peft_model(self.model, self.lora_config)
        self.model.print_trainable_parameters()

    def prepare_data(self, texts: list, max_length: int = 512):
        """
        准备数据
        参数:
            texts: 文本列表
            max_length: 最大长度
        返回:
            data: 处理后的数据

            texts,
            padding=True,
            truncation=True,
            max_length=max_length,
            return_tensors="pt"

              batch_size: int = 4, learning_rate: float = 3e-4):

        训练模型
        参数:
            train_data: 训练数据
            epochs: 训练轮数
            batch_size: 批次大小
            learning_rate: 学习率
        """

        optimizer = torch.optim.AdamW(
            self.model.parameters(),
            lr=learning_rate,
            weight_decay=0.01
        )

        self.model.train()
        dataloader = DataLoader(train_data["input_ids"], batch_size=batch_size)

        for epoch in range(epochs):
            total_loss = 0
            for batch in dataloader:
                batch = batch.to(self.model.device)
                outputs = self.model(batch, labels=batch)
                loss = outputs.loss

                optimizer.zero_grad()
                loss.backward()
                optimizer.step()

                total_loss += loss.item()

            avg_loss = total_loss / len(dataloader)

            path: 保存路径
```

```python
class PrefixTuning:
    """Prefix Tuning实现"""

    def __init__(self, model, prefix_length: int = 10,
                 hidden_size: int = 768):
        """
        初始化
        参数:
            model: 基础模型
            prefix_length: 前缀长度
            hidden_size: 隐藏层大小
        """
        self.model = model
        self.prefix_length = prefix_length

        self.prefix_embedding = nn.Embedding(
            prefix_length * 2,
            hidden_size
        )

    def get_prefix(self, batch_size: int):
        """
        获取前缀
        参数:
            batch_size: 批次大小
        返回:
            prefix: 前缀嵌入
        """
        prefix_indices = torch.arange(
            self.prefix_length * 2,
            device=self.prefix_embedding.weight.device
        ).unsqueeze(0).repeat(batch_size, 1)

        return self.prefix_embedding(prefix_indices)

    def forward(self, input_ids, attention_mask=None):
        """
        前向传播
        参数:
            input_ids: 输入ID
            attention_mask: 注意力掩码
        返回:
            outputs: 模型输出
        """
        batch_size = input_ids.size(0)
        prefix = self.get_prefix(batch_size)

        inputs_embeds = self.model.get_input_embeddings()(input_ids)
        inputs_embeds = torch.cat([prefix, inputs_embeds], dim=1)

        if attention_mask is not None:
            prefix_mask = torch.ones(
                batch_size,
                self.prefix_length * 2,
                device=attention_mask.device
            )
            attention_mask = torch.cat([prefix_mask, attention_mask], dim=1)

        outputs = self.model(
            inputs_embeds=inputs_embeds,
            attention_mask=attention_mask
        )

        return outputs
```

**Adapter微调实现：**

```python
class AdapterLayer(nn.Module):
    """Adapter层"""

    def __init__(self, hidden_size: int, adapter_size: int = 64):
        """
        初始化
        参数:
            hidden_size: 隐藏层大小
            adapter_size: Adapter大小
        """
        super(AdapterLayer, self).__init__()

        self.down_project = nn.Linear(hidden_size, adapter_size)
        self.up_project = nn.Linear(adapter_size, hidden_size)
        self.activation = nn.ReLU()
        self.dropout = nn.Dropout(0.1)

    def forward(self, x):
        """
        前向传播
        参数:
            x: 输入
        返回:
            输出 + Adapter输出
        """
        adapter_output = self.down_project(x)
        adapter_output = self.activation(adapter_output)
        adapter_output = self.up_project(adapter_output)
        adapter_output = self.dropout(adapter_output)

        return x + adapter_output

class AdapterFineTuner:
    """Adapter微调器"""

    def __init__(self, model, adapter_size: int = 64):
        """
        初始化
        参数:
            model: 基础模型
            adapter_size: Adapter大小
        """
        self.model = model
        self.adapter_size = adapter_size

        hidden_size = model.config.hidden_size
        self.adapter = AdapterLayer(hidden_size, adapter_size)

    def forward(self, input_ids, attention_mask=None):
        """
        前向传播
        参数:
            input_ids: 输入ID
            attention_mask: 注意力掩码
        返回:
            outputs: 模型输出
        """
        outputs = self.model(
            input_ids,
            attention_mask=attention_mask,
            output_hidden_states=True
        )

        hidden_states = outputs.hidden_states[-1]
        adapted_hidden = self.adapter(hidden_states)

        outputs.hidden_states = outputs.hidden_states[:-1] + (adapted_hidden,)

        return outputs
```

**RLHF（人类反馈强化学习）：**

```python
class RLHFTrainer:
    """RLHF训练器"""

    def __init__(self, model, reward_model, ref_model):
        """
        初始化
        参数:
            model: 待微调模型
            reward_model: 奖励模型
            ref_model: 参考模型
        """
        self.model = model
        self.reward_model = reward_model
        self.ref_model = ref_model
        self.tokenizer = None

    def compute_rewards(self, prompts, responses):
        """
        计算奖励
        参数:
            prompts: 提示词列表
            responses: 响应列表
        返回:
            rewards: 奖励值
        """
        inputs = [p + r for p, r in zip(prompts, responses)]
        with torch.no_grad():
            rewards = self.reward_model(inputs)
        return rewards

    def compute_kl_divergence(self, prompts, responses, old_log_probs):
        """
        计算KL散度
        参数:
            prompts: 提示词列表
            responses: 响应列表
            old_log_probs: 旧的log概率
        返回:
            kl: KL散度
        """
        inputs = [p + r for p, r in zip(prompts, responses)]

        with torch.no_grad():
            ref_log_probs = self.ref_model(inputs)

        kl = old_log_probs - ref_log_probs
        return kl

    def ppo_train(self, prompts, responses, old_log_probs,
                  advantages, epochs: int = 4, batch_size: int = 64):
        """
        PPO训练
        参数:
            prompts: 提示词列表
            responses: 响应列表
            old_log_probs: 旧的log概率
            advantages: 优势函数
            epochs: 训练轮数
            batch_size: 批次大小
        """
        optimizer = torch.optim.Adam(self.model.parameters(), lr=1e-5)

        for epoch in range(epochs):
            indices = torch.randperm(len(prompts))

            for i in range(0, len(prompts), batch_size):
                batch_idx = indices[i:i+batch_size]
                batch_prompts = [prompts[i] for i in batch_idx]
                batch_responses = [responses[i] for i in batch_idx]
                batch_old_log_probs = old_log_probs[batch_idx]
                batch_advantages = advantages[batch_idx]

                new_log_probs = self.model.get_log_probs(
                    batch_prompts, batch_responses
                )

                ratio = torch.exp(new_log_probs - batch_old_log_probs)

                surr1 = ratio * batch_advantages
                surr2 = torch.clamp(
                    ratio,
                    1 - 0.2,
                    1 + 0.2
                ) * batch_advantages

                policy_loss = -torch.min(surr1, surr2).mean()

                kl = self.compute_kl_divergence(
                    batch_prompts,
                    batch_responses,
                    new_log_probs
                )

                loss = policy_loss - 0.01 * kl

                optimizer.zero_grad()
                loss.backward()
                optimizer.step()

    def dpo_train(self, chosen_responses, rejected_responses,
                 prompts, beta: float = 0.1, epochs: int = 3):
        """
        DPO训练（Direct Preference Optimization）
        参数:
            chosen_responses: 被选择的响应
            rejected_responses: 被拒绝的响应
            prompts: 提示词
            beta: 温度参数
            epochs: 训练轮数
        """
        optimizer = torch.optim.Adam(self.model.parameters(), lr=1e-5)

        for epoch in range(epochs):
            chosen_log_probs = self.model.get_log_probs(prompts, chosen_responses)
            rejected_log_probs = self.model.get_log_probs(prompts, rejected_responses)

            logits = beta * (chosen_log_probs - rejected_log_probs)
            loss = -torch.log(torch.sigmoid(logits)).mean()

            optimizer.zero_grad()
            loss.backward()
            optimizer.step()

            print(f"Epoch {epoch+1}/{epochs}, Loss: {loss.item():.4f}")
```

```python
class DomainFineTuner:
    """领域微调器"""

    def __init__(self, model_name: str, domain: str):
        """
        初始化
        参数:
            model_name: 模型名称
            domain: 领域名称
        """
        self.model_name = model_name
        self.domain = domain
        self.tokenizer = None
        self.model = None

    def analyze_domain_data(self, texts: list):
        """
        分析领域数据特点
        参数:
            texts: 领域文本
        返回:
            analysis: 分析结果
        """
        from collections import Counter

        all_words = []
        for text in texts:
            all_words.extend(text.split())

        word_counts = Counter(all_words)

        return {
            "vocab_size": len(word_counts),
            "total_words": len(all_words),
            "avg_length": sum(len(t.split()) for t in texts) / len(texts),
            "top_words": word_counts.most_common(20)
        }

    def prepare_domain_data(self, texts: list, add_special_tokens: bool = True):
        """
        准备领域数据
        参数:
            texts: 文本列表
            add_special_tokens: 是否添加特殊token
        返回:
            dataset: 处理后的数据集
        """
        if add_special_tokens:
            special_tokens = {
                "additional_special_tokens": [
                    f"[{self.domain}_START]",
                    f"[{self.domain}_END]",
                    f"[{self.domain}_SEP]"
                ]
            }
            self.tokenizer.add_special_tokens(special_tokens)
            self.model.resize_token_embeddings(len(self.tokenizer))

        return texts

    def domain_adaptive_pretraining(self, texts: list, epochs: int = 1):
        """
        领域自适应预训练
        参数:
            texts: 领域文本
            epochs: 训练轮数
        """
        from torch.utils.data import Dataset as TorchDataset

        class DomainDataset(TorchDataset):
            def __init__(self, texts, tokenizer):
                self.texts = texts
                self.tokenizer = tokenizer

            def __len__(self):
                return len(self.texts)

            def __getitem__(self, idx):
                return self.tokenizer(
                    self.texts[idx],
                    return_tensors="pt",
                    padding=True,
                    truncation=True,
                    max_length=512
                )

        dataset = DomainDataset(texts, self.tokenizer)
        dataloader = torch.utils.data.DataLoader(dataset, batch_size=8)

        optimizer = torch.optim.AdamW(self.model.parameters(), lr=2e-5)

        self.model.train()
        for epoch in range(epochs):
            total_loss = 0
            for batch in dataloader:
                inputs = {k: v.squeeze(0) for k, v in batch.items()}

                outputs = self.model(**inputs, labels=inputs["input_ids"])
                loss = outputs.loss

                optimizer.zero_grad()
                loss.backward()
                optimizer.step()

                total_loss += loss.item()

            print(f"Domain Pretraining Epoch {epoch+1}, Loss: {total_loss/len(dataloader):.4f}")

    def task_fine_tune(self, train_data, eval_data=None):
        """
        任务微调
        参数:
            train_data: 训练数据
            eval_data: 评估数据
        """
        from transformers import Trainer, TrainingArguments

        training_args = TrainingArguments(
            output_dir=f"./models/{self.domain}_finetuned",
            num_train_epochs=3,
            per_device_train_batch_size=8,
            learning_rate=5e-5,
            evaluation_strategy="epoch" if eval_data else "no",
            save_strategy="epoch",
            fp16=True,
        )

        trainer = Trainer(
            model=self.model,
            args=training_args,
            train_dataset=train_data,
            eval_dataset=eval_data,
        )

        trainer.train()
```

## 1.5 部署优化

### 1.5.1 模型量化技术

**量化概述：** 模型量化是将模型参数从高精度（如FP32）转换为低精度（如INT8、INT4）的技术，可显著减少模型大小和推理延迟。

**量化类型：**

| 类型 | 精度 | 压缩比 | 精度损失 |
| --- | --- | --- | --- |
| FP32 | 32位 | 1x | 无 |
| FP16 | 16位 | 2x | 很小 |
| BF16 | 16位 | 2x | 可忽略 |
| INT8 | 8位 | 4x | 较小 |
| INT4 | 4位 | 8x | 中等 |

**动态量化：**

```python
import torch
import torch.nn as nn
from transformers import AutoModelForCausalLM, AutoTokenizer

class DynamicQuantizer:
    """动态量化器"""

    def __init__(self, model_name: str):
        """
        初始化
        参数:
            model_name: 模型名称
        """
        self.model_name = model_name
        self.tokenizer = AutoTokenizer.from_pretrained(model_name)
        self.model = AutoModelForCausalLM.from_pretrained(
            model_name,
            torch_dtype=torch.float32
        )

    def dynamic_quantize(self):
        """
        动态量化
        """
        self.quantized_model = torch.quantization.quantize_dynamic(
            self.model,
            {nn.Linear},
            dtype=torch.qint8
        )

    def static_quantize(self):
        """
        静态量化
        """
        self.model.eval()

        self.model.qconfig = torch.quantization.get_default_qconfig('fbgemm')
        torch.quantization.prepare(self.model, inplace=True)
        torch.quantization.convert(self.model, inplace=True)

    def benchmark(self, input_text: str, max_length: int = 100):
        """
        基准测试
        参数:
            input_text: 输入文本
            max_length: 最大长度
        返回:
            results: 测试结果
        """
        import time

        inputs = self.tokenizer(input_text, return_tensors="pt")

        torch.cuda.synchronize() if torch.cuda.is_available() else None
        start_time = time.time()

        with torch.no_grad():
            outputs = self.quantized_model.generate(
                **inputs,
                max_length=max_length
            )

        torch.cuda.synchronize() if torch.cuda.is_available() else None
        end_time = time.time()

        generated_text = self.tokenizer.decode(outputs[0], skip_special_tokens=True)

        return {
            "text": generated_text,
            "latency": end_time - start_time,
            "tokens_per_second": max_length / (end_time - start_time)
        }

    def compare_with_original(self, input_text: str, max_length: int = 100):
        """
        与原模型对比
        参数:
            input_text: 输入文本
            max_length: 最大长度
        返回:
            comparison: 对比结果
        """
        original_result = self._benchmark_original(input_text, max_length)
        quantized_result = self.benchmark(input_text, max_length)

        original_size = self._get_model_size(self.model)
        quantized_size = self._get_model_size(self.quantized_model)

        return {
            "original": {
                "latency": original_result["latency"],
                "size_mb": original_size
            },
            "quantized": {
                "latency": quantized_result["latency"],
                "size_mb": quantized_size
            },
            "speedup": original_result["latency"] / quantized_result["latency"],
            "compression": original_size / quantized_size
        }

    def _benchmark_original(self, text, max_length):
        """基准测试原模型"""
        import time

        inputs = self.tokenizer(text, return_tensors="pt")

        torch.cuda.synchronize() if torch.cuda.is_available() else None
        start_time = time.time()

        with torch.no_grad():
            outputs = self.model.generate(
                **inputs,
                max_length=max_length
            )

        torch.cuda.synchronize() if torch.cuda.is_available() else None
        end_time = time.time()

        return {"latency": end_time - start_time}

    def _get_model_size(self, model):
        """获取模型大小"""
        import os
        import tempfile

        with tempfile.NamedTemporaryFile(delete=True) as tmp:
            torch.save(model.state_dict(), tmp.name)
            size_mb = os.path.getsize(tmp.name) / (1024 * 1024)

        return size_mb
```

### 1.5.2 模型蒸馏

**知识蒸馏概述：** 模型蒸馏是将大模型（教师模型）的知识迁移到小模型（学生模型）的技术。

**蒸馏方法：**

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
from transformers import AutoModelForCausalLM, AutoTokenizer

class DistillationConfig:
    """蒸馏配置"""

    def __init__(self, teacher_model_name: str, student_model_name: str,
                 temperature: float = 2.0, alpha: float = 0.5):
        """
        初始化
        参数:
            teacher_model_name: 教师模型名称
            student_model_name: 学生模型名称
            temperature: 蒸馏温度
            alpha: 损失权重
        """
        self.teacher_model_name = teacher_model_name
        self.student_model_name = student_model_name
        self.temperature = temperature
        self.alpha = alpha

class KnowledgeDistiller:
    """知识蒸馏器"""

    def __init__(self, config: DistillationConfig):
        """
        初始化
        参数:
            config: 蒸馏配置
        """
        self.config = config

        print("加载教师模型...")
        self.teacher_model = AutoModelForCausalLM.from_pretrained(
            config.teacher_model_name,
            torch_dtype=torch.float16,
            device_map="auto"
        )
        self.teacher_model.eval()

        print("加载学生模型...")
        self.student_model = AutoModelForCausalLM.from_pretrained(
            config.student_model_name,
            torch_dtype=torch.float16,
            device_map="auto"
        )

        self.tokenizer = AutoTokenizer.from_pretrained(config.teacher_model_name)

    def distillation_loss(self, student_logits, teacher_logits, labels):
        """
        计算蒸馏损失
        参数:
            student_logits: 学生模型logits
            teacher_logits: 教师模型logits
            labels: 标签
        返回:
            loss: 蒸馏损失
        """
        T = self.config.temperature

        soft_teacher = F.softmax(teacher_logits / T, dim=-1)
        soft_student = F.log_softmax(student_logits / T, dim=-1)

        distillation_loss = F.kl_div(
            soft_student,
            soft_teacher,
            reduction='batchmean'
        ) * (T * T)

        hard_loss = F.cross_entropy(
            student_logits,
            labels,
            reduction='mean'
        )

        alpha = self.config.alpha
        loss = alpha * distillation_loss + (1 - alpha) * hard_loss

        return loss

    def distill(self, train_texts, epochs: int = 3,
                batch_size: int = 4, learning_rate: float = 1e-4):
        """
        蒸馏训练
        参数:
            train_texts: 训练文本
            epochs: 训练轮数
            batch_size: 批次大小
            learning_rate: 学习率
        """
        from torch.utils.data import Dataset, DataLoader

        class TextDataset(Dataset):
            def __init__(self, texts, tokenizer, max_length=512):
                self.texts = texts
                self.tokenizer = tokenizer
                self.max_length = max_length

            def __len__(self):
                return len(self.texts)

            def __getitem__(self, idx):
                return self.tokenizer(
                    self.texts[idx],
                    return_tensors="pt",
                    padding=True,
                    truncation=True,
                    max_length=self.max_length
                )

        dataset = TextDataset(train_texts, self.tokenizer)
        dataloader = DataLoader(dataset, batch_size=batch_size, shuffle=True)

        optimizer = torch.optim.AdamW(
            self.student_model.parameters(),
            lr=learning_rate
        )

        self.student_model.train()

        for epoch in range(epochs):
            total_loss = 0

            for batch in dataloader:
                input_ids = batch["input_ids"].to(self.student_model.device)
                attention_mask = batch["attention_mask"].to(self.student_model.device)

                with torch.no_grad():
                    teacher_outputs = self.teacher_model(
                        input_ids=input_ids,
                        attention_mask=attention_mask
                    )
                    teacher_logits = teacher_outputs.logits

                student_outputs = self.student_model(
                    input_ids=input_ids,
                    attention_mask=attention_mask
                )
                student_logits = student_outputs.logits

                labels = input_ids
                loss = self.distillation_loss(
                    student_logits,
                    teacher_logits,
                    labels
                )

                optimizer.zero_grad()
                loss.backward()
                optimizer.step()

                total_loss += loss.item()

            avg_loss = total_loss / len(dataloader)
            print(f"Epoch {epoch+1}/{epochs}, Loss: {avg_loss:.4f}")

    def distill_with_intermediate(self, train_texts, epochs: int = 3):
        """
        使用中间层进行蒸馏
        参数:
            train_texts: 训练文本
            epochs: 训练轮数
        """
        from torch.utils.data import Dataset, DataLoader

        class TextDataset(Dataset):
            def __init__(self, texts, tokenizer):
                self.texts = texts
                self.tokenizer = tokenizer

            def __len__(self):
                return len(self.texts)

            def __getitem__(self, idx):
                return self.tokenizer(
                    self.texts[idx],
                    return_tensors="pt",
                    padding=True,
                    truncation=True,
                    max_length=512
                )

        dataset = TextDataset(train_texts, self.tokenizer)
        dataloader = DataLoader(dataset, batch_size=2, shuffle=True)

        optimizer = torch.optim.AdamW(
            self.student_model.parameters(),
            lr=1e-4
        )

        self.student_model.train()

        for epoch in range(epochs):
            total_loss = 0

            for batch in dataloader:
                input_ids = batch["input_ids"].to(self.student_model.device)
                attention_mask = batch["attention_mask"].to(self.student_model.device)

                with torch.no_grad():
                    teacher_outputs = self.teacher_model(
                        input_ids=input_ids,
                        attention_mask=attention_mask,
                        output_hidden_states=True
                    )
                    teacher_hidden = teacher_outputs.hidden_states

                student_outputs = self.student_model(
                    input_ids=input_ids,
                    attention_mask=attention_mask,
                    output_hidden_states=True
                )
                student_hidden = student_outputs.hidden_states

                hidden_loss = 0
                for t_hidden, s_hidden in zip(teacher_hidden, student_hidden):
                    hidden_loss += F.mse_loss(s_hidden, t_hidden.detach())

                with torch.no_grad():
                    teacher_logits = teacher_outputs.logits

                student_logits = student_outputs.logits
                ce_loss = F.cross_entropy(
                    student_logits.view(-1, student_logits.size(-1)),
                    input_ids.view(-1)
                )

                loss = 0.5 * hidden_loss + 0.5 * ce_loss

                optimizer.zero_grad()
                loss.backward()
                optimizer.step()

                total_loss += loss.item()

            print(f"Epoch {epoch+1}/{epochs}, Loss: {total_loss/len(dataloader):.4f}")

    def save_student_model(self, path: str):
        """
        保存学生模型
        参数:
            path: 保存路径
        """
        self.student_model.save_pretrained(path)
        self.tokenizer.save_pretrained(path)
```

```python
            "max_position_embeddings": 32768,
        }

                              train_data, epochs: int = 3):
        """
        多教师蒸馏
        参数:
            teachers: 教师模型列表
            student_model: 学生模型
            train_data: 训练数据
            epochs: 训练轮数
        """

                    with torch.no_grad():
                        teacher_outputs = teacher(**batch)

                    teacher_logits = teacher_outputs.logits
                    student_logits = outputs.logits

                    distillation_loss += F.kl_div(
                        F.log_softmax(student_logits / 2.0, dim=-1),
                        F.softmax(teacher_logits / 2.0, dim=-1),
                        reduction='batchmean'
                    )

                loss = distillation_loss / len(teachers)

                optimizer.zero_grad()
                loss.backward()
                optimizer.step()

        return student_model
```

```python
class StreamingGenerator:
    """流式生成器"""

    def __init__(self, model, tokenizer):
        """
        初始化
        参数:
            model: 模型
            tokenizer: 分词器
        """
        self.model = model
        self.tokenizer = tokenizer

    def generate_streaming(self, prompt: str, max_length: int = 100):
        """
        流式生成
        参数:
            prompt: 提示词
            max_length: 最大长度
        生成:
            token: 生成的token
        """
        input_ids = self.tokenizer(prompt, return_tensors="pt")
        input_ids = {k: v.to(self.model.device) for k, v in input_ids.items()}

        past_key_values = None
        generated = input_ids["input_ids"]

        for _ in range(max_length):
            outputs = self.model(
                input_ids=generated[:, -1:],
                past_key_values=past_key_values,
                use_cache=True
            )

            logits = outputs.logits[:, -1, :]
            past_key_values = outputs.past_key_values

            probs = torch.softmax(logits / 0.7, dim=-1)
            next_token = torch.multinomial(probs, num_samples=1)

            generated = torch.cat([generated, next_token], dim=-1)

            yield self.tokenizer.decode(next_token[0], skip_special_tokens=True)

            if next_token[0] == self.tokenizer.eos_token_id:
                break

class ContinuousBatching:
    """连续批处理"""

    def __init__(self, model, tokenizer, max_batch_size: int = 8):
        """
        初始化
        参数:
            model: 模型
            tokenizer: 分词器
            max_batch_size: 最大批次大小
        """
        self.model = model
        self.tokenizer = tokenizer
        self.max_batch_size = max_batch_size
        self.pending_requests = []

    def add_request(self, prompt: str):
        """
        添加请求
        参数:
            prompt: 提示词
        """
        request = {
            "prompt": prompt,
            "input_ids": self.tokenizer(prompt, return_tensors="pt")["input_ids"],
            "generated": None,
            "finished": False
        }
        self.pending_requests.append(request)

    def process_batch(self):
        """
        处理批次
        """
        active_requests = [r for r in self.pending_requests if not r["finished"]]

        if not active_requests:
            return

        batch_input = torch.cat([r["input_ids"] for r in active_requests], dim=0)

        outputs = self.model.generate(
            batch_input,
            max_length=512,
            do_sample=True,
            pad_token_id=self.tokenizer.eos_token_id
        )

        for i, request in enumerate(active_requests):
            request["generated"] = outputs[i]

            if outputs[i][-1] == self.tokenizer.eos_token_id:
                request["finished"] = True
            else:
                request["input_ids"] = outputs[i:i+1]

    def get_results(self):
        """
        获取结果
        返回:
            results: 完成的结果
        """
        finished = [r for r in self.pending_requests if r["finished"]]
        self.pending_requests = [r for r in self.pending_requests if not r["finished"]]

        return [
            self.tokenizer.decode(r["generated"], skip_special_tokens=True)
            for r in finished
        ]
```
