"Agent"这个词已经被用烂了。聊天机器人说自己叫 Agent，插件市场也说自己叫 Agent。

今天不聊概念，直接看东西。我按"你到底用它干什么"分类，把 GitHub 上真正流行的 agent 盘了一遍。star 数是今天从 GitHub API 实时抓的，不掺水分。

### 先说结论：Agent 已经分成了四个物种

- 通用执行型：给你跑腿干活的
- 编程型：住在终端里写代码的
- 浏览器型：替你操作网页的
- 框架型：给开发者搭 agent 用的

### 通用执行型：从"能聊"到"能干"

**OpenClaw（39.3 万 star）** 是这个类目的当前榜首，也是整个 GitHub 增长最快的项目之一。

它的定位是"真的做事的 AI"：跑在你自己的机器上，能读文件、执行命令、控制浏览器、接管消息渠道，把"个人助理"从聊天框搬进了操作系统。39 万 star 说明一件事——大家要的不是又一个聊天窗口，是替自己干活的。

**AutoGPT（18.8 万 star）** 是这一切的起点。

2023 年它第一个喊出"给 AI 一个目标，让它自己拆解执行"，虽然当年经常跑偏烧 token，但"自主执行"这个范式是它立的。现在的 AutoGPT 早已迭代成低代码平台，算是完成了自我进化。

### 编程型：卷得最狠的赛道

**Claude Code（15.3 万 star）** ，Anthropic 官方的终端编程 agent。

住在命令行里，读懂整个代码仓库，从改 bug 到跨文件重构一条龙。它的走红标志着"代码补全"时代的结束——现在是 agent 直接接活的年代。

**OpenHands（9.1 万 star）** ，开源界的编程 agent 标杆，原名 OpenHands 从 All-Hands-AI 独立成组织。

给一个 GitHub issue，它自己建分支、写代码、跑测试、提 PR。不想把代码交给云端工具的团队，基本都会看看它。

**goose（5.5 万 star）** ，走出编程之外的"扩展型 agent"，可装各种插件连本地工具和 MCP 服务。

**Aider（5 万 star）** ，老牌终端结对编程工具，git 集成做得极好，每一步改动自动提交，重度 git 用户的心头好。

**SWE-agent（2.1 万 star）** ，普林斯顿大学的学术派，专攻" autonomously 修 GitHub issue"这个单一命题，是很多后续项目的论文源头。

### 浏览器型：让 AI 替你上网

**browser-use（11.9 万 star）** ，Python 生态里最流行的浏览器 agent 库。

给它一句话"帮我把这个表格填了"，它自己开浏览器、找按钮、填表单。让 LLM 学会了用鼠标键盘。

**OpenManus（5.9 万 star）** ，MetaGPT 团队拆出来的通用 agent，"No fortress, purely open ground"，上线三周就破了几万 star，主打开放自由执行。

### 框架型：造 agent 的人用什么

**LangChain（14.8 万 star）** ，agent 工程的事实标准，现在定位已经是"agent 工程平台"。

**MetaGPT（7.1 万 star）** ，"AI 软件公司"流派：给 agent 们分配产品经理、架构师、程序员角色，模拟一条软件生产线。

**CrewAI（6 万 star）** ，多 agent 协作框架，用"角色扮演团队"的方式编排一队 agent 分工干活。

### 我的三个观察

**第一，通用型已经跑出头部。** OpenClaw 的 39 万 star 不是运气——当 agent 能常驻你的电脑、真正接管执行，它和"网页里聊十句"的产品就不在一个维度了。

**第二，编程 agent 是商业化最顺的。** Claude Code、Aider、OpenHands 都找到了清晰的付费点，开发者愿意为省下的时间买单。

**第三，MCP 正在成为公共底座。** 翻这些项目的更新日志，MCP（模型上下文协议）的出现频率越来越高——工具、数据、agent 之间的连接正在标准化，这可能是明年最值得关注的变化。

选型建议就一句话：想让 AI 替你干活，看通用执行型；写代码，看编程型；自动化网页操作，看浏览器型；自己造 agent，再去看框架。

工具都已经备好了，缺的只是你把活儿交出去的那一下。
