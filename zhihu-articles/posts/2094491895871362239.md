## 一、TensorRT是什么？

```text
TensorRT：NVIDIA的深度学习推理优化器

核心功能：
  1. 模型转换：PyTorch/TF → TensorRT Engine
  2. 精度优化：FP32 → FP16 → INT8
  3. 图优化：层融合、消除冗余操作
  4. 内存优化：显存复用、减少分配

为什么TensorRT这么快？
  1. 层融合 (Layer Fusion)
     Conv + BN + ReLU → 融合成一个CBR核
     减少显存读写，提升吞吐量
     
  2. 精度校准 (Precision Calibration)
     FP32 → FP16/INT8，保持精度
     
  3. 核自动调优 (Kernel Auto-Tuning)
     针对当前GPU选择最优的CUDA kernel
     
  4. 动态显存管理
     复用显存，减少分配开销
     
  5. 多流并行
     同时执行多个操作

TensorRT的典型加速比：
  FP32: 1-2x (图优化)
  FP16: 2-4x (Tensor Core)
  INT8: 3-6x (DP4A指令)

```

## 二、核心知识点

### 2.1 TensorRT优化：层融合

```text
"""
层融合是TensorRT最重要的优化之一

融合前：
  Conv → Bias → ReLU
  三个独立操作，每个都需要读写显存
  
  显存读写：
    Conv: 读输入 → 写输出
    Bias: 读Conv输出 → 写Bias输出
    ReLU: 读Bias输出 → 写最终输出
    = 3次读 + 3次写

融合后 (CBR):
  Conv + Bias + ReLU → 一个融合核
  显存读写：
    读输入 → 写输出
    = 1次读 + 1次写

显存带宽节省：67%！
对于显存带宽敏感的端侧设备（如Jetson），这是巨大的提升

TensorRT支持的融合模式：
  Conv + Bias + ReLU → CBR
  Conv + Bias + Add + ReLU → CBR + 残差
  Conv + BN + ReLU → CBR (BN参数fold到Conv中)
  Conv + SiLU → CBR
  MatMul + Add + ReLU → 全连接层融合
"""

def layer_fusion_demo():
    print("TensorRT层融合:")
    print()
    print("融合前 (3个操作):")
    print("  Conv → [读输入, 写输出]")
    print("  Bias → [读中间, 写中间]")
    print("  ReLU → [读中间, 写输出]")
    print("  总计: 3次读 + 3次写")
    print()
    print("融合后 (1个操作):")
    print("  CBR → [读输入, 写输出]")
    print("  总计: 1次读 + 1次写")
    print("  节省: 67%显存带宽")
    print()
    print("端侧AI (Jetson):")
    print("  Jetson的显存带宽是瓶颈")
    print("  层融合直接提升速度 1.5-2x")

layer_fusion_demo()

```

### 2.2 PyTorch → ONNX：模型导出

```text
"""
ONNX (Open Neural Network Exchange)
  开放神经网络交换格式
  是PyTorch → TensorRT的桥梁

为什么需要ONNX？
  PyTorch是动态图 → TensorRT需要静态图
  ONNX是静态图 → 适合TensorRT
  而且ONNX是跨框架的：TF/Caffe/PyTorch都可以导出

导出ONNX的关键参数：
  input_names: 输入节点名称
  output_names: 输出节点名称
  opset_version: ONNX算子集版本 (推荐11+)
  dynamic_axes: 动态维度 (batch可变)
  export_params: 是否导出参数 (True)
"""

class SimpleModel(nn.Module):
    """用于演示导出的简单模型"""
    def __init__(self):
        super().__init__()
        self.conv1 = nn.Conv2d(3, 64, 3, padding=1)
        self.bn1 = nn.BatchNorm2d(64)
        self.relu = nn.ReLU(inplace=True)
        self.pool = nn.MaxPool2d(2, 2)
        self.conv2 = nn.Conv2d(64, 128, 3, padding=1)
        self.bn2 = nn.BatchNorm2d(128)
        self.fc = nn.Linear(128 * 16 * 16, 10)
    
    def forward(self, x):
        x = self.relu(self.bn1(self.conv1(x)))
        x = self.pool(x)
        x = self.relu(self.bn2(self.conv2(x)))
        x = self.pool(x)
        x = x.view(x.size(0), -1)
        x = self.fc(x)
        return x

def export_to_onnx_demo():
    """演示PyTorch模型导出ONNX"""
    model = SimpleModel()
    model.eval()
    
    # 创建虚拟输入
    dummy_input = torch.randn(1, 3, 32, 32)
    
    # 导出ONNX
    onnx_path = "simple_model.onnx"
    
    try:
        torch.onnx.export(
            model,
            dummy_input,
            onnx_path,
            export_params=True,        # 导出参数
            opset_version=11,          # ONNX算子集版本
            do_constant_folding=True,  # 常量折叠优化
            input_names=['input'],     # 输入节点名
            output_names=['output'],   # 输出节点名
            dynamic_axes={             # 动态维度
                'input': {0: 'batch_size'},
                'output': {0: 'batch_size'},
            },
        )
        
        print("ONNX导出成功!")
        print(f"  模型: {onnx_path}")
        print(f"  大小: {os.path.getsize(onnx_path) / 1024:.1f} KB")
        print()
        print("ONNX导出关键参数:")
        print("  opset_version=11: 推荐，支持大部分算子")
        print("  do_constant_folding=True: 预先计算常量")
        print("  dynamic_axes: batch_size可变")
        
    except Exception as e:
        print(f"ONNX导出失败: {e}")
        print("(这是正常的，需要安装onnx库)")
    
    # 清理
    if os.path.exists(onnx_path):
        os.remove(onnx_path)

export_to_onnx_demo()

```

### 2.4 TensorRT推理流程

```text
"""
TensorRT推理流程

1. 加载Engine
2. 创建ExecutionContext
3. 分配输入输出显存
4. 拷贝输入数据到GPU
5. 执行推理 (execute_v2)
6. 拷贝输出数据到CPU
7. 后处理

TensorRT推理代码模板：
"""

def tensorrt_inference_template():
    code = """
# TensorRT推理模板
import tensorrt as trt
import pycuda.driver as cuda
import pycuda.autoinit

# 1. 加载Engine
with open('model_fp16.engine', 'rb') as f:
    engine_data = f.read()

runtime = trt.Runtime(trt.Logger(trt.Logger.WARNING))
engine = runtime.deserialize_cuda_engine(engine_data)

# 2. 创建ExecutionContext
context = engine.create_execution_context()

# 3. 分配显存
input_shape = (1, 3, 224, 224)
output_shape = (1, 1000)

d_input = cuda.mem_alloc(int(np.prod(input_shape) * 4))
d_output = cuda.mem_alloc(int(np.prod(output_shape) * 4))

# 4. 拷贝输入到GPU
input_data = np.random.randn(*input_shape).astype(np.float32)
cuda.memcpy_htod(d_input, input_data)

# 5. 执行推理
bindings = [int(d_input), int(d_output)]
context.execute_v2(bindings)

# 6. 拷贝输出到CPU
output_data = np.empty(output_shape, dtype=np.float32)
cuda.memcpy_dtoh(output_data, d_output)

# 7. 后处理
pred_class = np.argmax(output_data)
print(f"预测类别: {pred_class}")
"""
    print("TensorRT推理模板:")
    print(code)

tensorrt_inference_template()

```

## 五、常见坑点

### 坑1：ONNX导出时算子不支持

```text
# 不是所有PyTorch算子都能导出ONNX
# 常见不支持的操作：
# - torch.einsum (部分支持)
# - 自定义CUDA kernel
# - 动态控制流 (if/while)
# 排查方法：
# 1. 检查opset_version是否够新
# 2. 用onnx.checker检查模型
# 3. 用netron可视化，看是否有未知节点
# 4. 对于不支持的操作，改写为支持的等价操作
# 常见替代：
# torch.einsum → torch.bmm + permute
# 自定义操作 → 注册为ONNX custom op
```

### 坑2：TensorRT版本和ONNX opset不匹配

```text
# TensorRT版本和ONNX opset版本需要匹配
# TensorRT 8.0: 支持到opset 13
# TensorRT 8.4: 支持到opset 14
# TensorRT 8.6: 支持到opset 17
# 如果opsnet版本太高，TensorRT不支持
# 解决方案：降低opset_version
# torch.onnx.export(..., opset_version=11)  # 安全选择
```

### 坑3：INT8校准数据的选择

```text
# INT8校准需要代表性数据
# 校准数据应该：
# 1. 覆盖推理时的数据分布
# 2. 数量足够 (500-1000张)
# 3. 多样化 (各种场景、光照、角度)
# ❌ 错误：只用10张图片校准
# → 量化scale不准确 → 精度大幅下降
# ✅ 正确：用500+张代表性图片
# → 量化scale准确 → 精度下降 < 1%
```

### 坑4：动态shape的问题

```text
# TensorRT默认不支持动态shape
# 如果输入尺寸不固定，需要配置
# 解决方案1：固定尺寸（最简单）
# 所有输入都resize到固定尺寸
# 解决方案2：动态shape（复杂）
# 在build时配置optimization profile
# 指定min/opt/max三种尺寸
# builder_profile.set_shape("input", min=(1,3,224,224), 
#                                       opt=(1,3,512,512), 
#                                       max=(1,3,1024,1024))
```
