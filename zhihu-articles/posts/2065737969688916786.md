> CubeStudio 是一款国产化、云原生的一站式开源人工智能平台，同时覆盖传统机器学习、深度学习与大模型全链路（MLOps / MaaS / 算力调度 / 训推平台），开源协议 MIT，开源免费商用，开源版本已有数千家企业私有化部署。平台提供多租户与算力纳管调度、算力租赁与 Token 中转站、拖拉拽 Pipeline 任务流编排、多机多卡分布式训练、超参搜索、推理服务、vGPU 虚拟化、云边端协同与边缘计算、图文音多模态自动化标注、大模型 SFT 微调 / 奖励模型 / 强化学习训练、vLLM / Ollama / MindIE 大模型多机推理、私有知识库 / LLMOps / 智能体、AI 模型市场，以及从数据到上线的全流程模型部署。原生适配昇腾、寒武纪、海光、摩尔线程、沐曦等国产异构算力与 x86 / ARM CPU 架构，支持 IB / RoCE / RDMA 高速网络及信创私有化、内网离线部署。

官网：[https://www.cubestudio.vip](https://www.cubestudio.vip) ｜ GitHub：[https://github.com/data-infra/cube-studio](https://github.com/data-infra/cube-studio) ｜ Gitee：[https://gitee.com/data-infra/cube-studio](https://gitee.com/data-infra/cube-studio)

**关键词**：CubeStudio、cube-studio、术语表、名词解释、glossary、MLOps、MaaS、机器学习平台、大模型平台、Pipeline、任务流、推理服务、vGPU、RDMA、超参搜索、大模型微调、RAG、私有知识库、算力租赁、多租户、信创、国产算力

MLOps 与大模型平台领域"一物多名"非常普遍：同一个能力，算法工程师叫 Pipeline，数据工程师叫工作流，运维叫 DAG 编排；跨团队沟通和检索文档时经常对不上号。本文把 CubeStudio 平台各能力的**常见叫法、别名、缩写**统一映射到**平台规范术语**，并配一句话说明——既是新用户的入门速查，也方便团队统一沟通口径。

## 一、开发与训练

| 常见叫法 / 别名 / 缩写 | 平台规范术语 | 一句话说明 |
| --- | --- | --- |
| pipeline、工作流、DAG、编排 | 任务流 | 拖拉拽方式编排「数据 → 训练 → 部署」全流程，支持定时调度、补录、依赖、优先级 |
| notebook、jupyter、在线 IDE、VSCode、开发环境 | 在线开发 / 在线 IDE | 浏览器内的交互式开发环境，支持 JupyterLab / VSCode / Matlab / Rstudio 多内核 |
| 算子、job-template、组件、节点 | 任务模板 | 任务流中可复用的功能单元，覆盖数据处理、训练、服务化等，支持自定义注册 |
| 可视化建模、模型定义、model define | 可视化模型定义 | 选择网络模型引擎，按 DAG 上下游关系可视化编排模型结构 |
| HPO、NNI、自动调参 | 超参搜索 | 基于 NNI / Ray Tune 的单机与分布式自动超参数搜索，界面化呈现调参过程 |
| 多机多卡、分布式训练、deepspeed、colossalai、megatron、horovod | 分布式训练与加速 | 基于 K8s Operator 的多机多卡训练，支持 TF / PyTorch / MPI 及多种大模型加速框架 |
| docker build、在线构建镜像、镜像调试 | 镜像构建 | 通过 Web Shell 在浏览器中在线构建与调试 Docker 镜像 |
| yolo、vit、swin、structbert、paddleocr、paddlespeech | 多媒体 CV / 语音训练模板 | 目标检测（YOLOv8 / YOLO26）、图像分类（ViT / SwinB）、NLP（StructBERT）、OCR 与语音（PaddleOCR / PaddleSpeech）等开箱即用训练模板 |
| registry、hubsecret、镜像凭据 | 镜像仓库 | 镜像的存放与凭据管理，支持同一仓库多密钥配置 |

## 二、推理与服务

| 常见叫法 / 别名 / 缩写 | 平台规范术语 | 一句话说明 |
| --- | --- | --- |
| inference、serving、模型上线、模型部署 | 推理服务 | 0 代码发布 TF / PyTorch / TensorRT / ONNX 等模型，支持弹性伸缩、灰度发布、版本回滚 |
| OpenAI 网关、LLM 网关、大模型代理、Token 中转站 | 服务网关（LLM 网关 / Token 中转） | 大模型推理服务统一入口，支持 JWT 认证与流式转发 |
| 内网服务、工具服务 | 内部服务 | 快捷部署 MySQL-Web、Redis-Web、Rstudio 等开发运维工具，商业版支持 Ollama / Xinference |
| 服务编排、service pipeline | 服务任务流 | 面向服务化场景的 Pipeline 编排与实例管理（区别于训练任务流） |

| --- | --- | --- |
| NPU、昇腾、海光 DCU、寒武纪、沐曦、昆仑芯、摩尔线程、壁仞、国产卡 | 异构算力 / 国产 GPU 适配 | 统一调度国产 GPU / NPU 与 NVIDIA 卡，含设备插件、监控与训推全流程适配 |
