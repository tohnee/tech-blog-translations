今日凌晨 3 点，Anthropic 突然放出一个王炸，正式发布 Claude Fable 5.2 模型。

一发布，便在 Artificial Analysis 指数榜单上，拿下 65 高分登顶第一，直接宣布新王登基。

官方的 12 项评测，智能体编码、科学研究、计算机使用等 11 项成绩超过自家 Opus 5.5 模型。

跟 GPT-6 Astra 和 Gemini 4 Carbon 相比，可以说是几乎全面超越，基本碾压所有对手。

![](https://pica.zhimg.com/v2-b15697f7b316b3e92bd973a9f1c82ada_r.jpg)

另外，这次 Fable 5.2 的输出速度比上一代快了 30%，而且 API 价格还降了 20%。

现在每百万 Token 输入只要 8 美元、输出 40 美元，而上一代是 10 美元和 50 美元。

有点意外，Anthropic 还送出了 1 到 3 次 Fable 的额度重置机会，根据订阅套餐类型和时间来定。

不过官方也建议，日常的任务先用 Opus 5.5 就够了，遇到更复杂的活再换成 Fable 5.2 来干。

![](https://pic2.zhimg.com/v2-f90c9580db1132a125e22525fa9988e1_r.jpg)

从官方放出的案例来看，这一次 Fable 5.2 在 3D 场景和硬件设计方面的能力，有了极大提升。

于是想找个项目来试试，正好前几天在 GitHub 上看到一个很有意思的开源 Skill：**teardown**。

该项目作者只给 Claude 发了一张参考图，就做出了一只可以拆开来看的机械蜜蜂。

蜜蜂身上的外壳、齿轮和管线，全都是用 three.js 代码一点点写出来的，点一下还能把整只蜜蜂的零件炸开，效果相当惊艳。

![](https://pic3.zhimg.com/v2-25842cab86b9417ef2aa9625c75926f6_r.jpg)

后来作者把自己这套做 3D 机械拆解的流程，整理成了一个 Claude Code 的 Skill，并开源了出来。

装上之后，我们只需要问它某台机器是怎么工作的，它就会做出一个可以拆解的 3D 模拟器。

做好的成品是一个 HTML 网页文件，不用联网，在浏览器里打开就能玩。

除了蜜蜂，作者还做了一只机械章鱼，我觉得也挺有趣的。

它的每条触手都是由一节一节的零件连起来的，所以能像真的章鱼那样卷起来，还可以把其中一条触手单独拆开。

[https://www.zhihu.com/video/2103560311638967792](https://www.zhihu.com/video/2103560311638967792)

当然不只是这些机械生物，我们日常在用的设备它也能拆。

有位网友给了它一张 Mac mini 的图片，它就做出了一台可以拆开的 Mac mini。

先把顶盖掀开，接着风扇、芯片、内存和电源一个个被取了出来，里面是怎么摆的看得清清楚楚。

[https://www.zhihu.com/video/2103560208433820828](https://www.zhihu.com/video/2103560208433820828)

看完别人做的，我也用 Fable 5.2 上手试了一下，顺便看下模型的能力如何。

于是打开 Claude Code 切换到 Fable 5.2 模型，并发送下面一句话安装 teardown 技能：

![](https://pica.zhimg.com/v2-f3fe375af433cce5752d17f568593de4_r.jpg)

接着我找了一张无人机的图片发给它，让它做一个可以拆开看的四旋翼无人机模拟器。

顺便让它讲清楚无人机是怎么飞起来的，四个电机又是怎么配合着实现起飞、悬停、前进和转向。

这里提醒了，最好是给它一张参考图，如果只靠一句话来描述，做出来的机器容易千篇一律。

![](https://pica.zhimg.com/v2-328bcbb0968e1fc837244fd76f29d44a_r.jpg)

指令发送后，它没有急着动手，而是先翻了一遍技能自带的几个示例，挑了最接近的飞机起落架来参考，再开始搭这台无人机。

整个过程我没有再追问，也没有让它返工，一条提示词模拟器就做出来，只有一个 700 多 KB 的 HTML 文件。

![](https://pic1.zhimg.com/v2-a102345511f9ca4ab4ad7c9874928bea_r.jpg)

双击打开后，中间的无人机和参考图很像，机臂、橙色的桨尖、机头下面的云台相机都在，机身上的品牌标识也按要求去掉了。

左边的面板显示着四个电机的转速、总升力和飞行姿态，底部还会用一段话说明现在发生了什么。

右侧的面板，试着点了几个飞行动作，相当丝滑，还可以不断切换视角以及拆解无人机内部组件，非常有意思。

最后再让 Fable 5.2 导出一段 20 秒左右、1080P、60 帧，包括起飞、前进、转向、降落和拆解的演示视频。

[https://www.zhihu.com/video/2103559756526965050](https://www.zhihu.com/video/2103559756526965050)

### **写在最后**

以上就是使用 Fable 5.2 模型，仅用一条提示词做出来的效果，整体来说这次模型能力很强。

从弄懂飞行原理、做 3D 建模，再到写交互界面和导出演示视频，一个模型就全包了。

以前想弄明白一台机器里面是怎么运转的，只能去网上找拆解视频，或者对着一张静止的结构图慢慢看。

现在有 teardown 技能加 Fable 5.2 模型，想看哪台机器，做一个出来就可以了。

我觉得想做科普视频的朋友，或者想给孩子讲讲机械原理的家长，都可以拿它来试一试。
