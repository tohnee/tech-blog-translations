### 先想清楚：你到底要学到什么程度？

很多人一张嘴就是：“我要搞懂 AI 的底层原理。”

但如果不说实话，这篇文章就没意义。 **你真正需要的程度，通常只有三档：**

**入门档：能看懂、敢用**

**工程档：能改、能调（工程级）**

**研究档：能研究、能发 paper**

**绝大多数人，只需要学到第 2 档：工程。**

这篇文章的路线，就是围绕「普通工程向 + 能做项目」来设计的。

### 阶段 1：数学复习（3 天搞定）

目标：只学够用的数学，而不是重新读一遍高数和线代。

### 数学第 1 天：线性代数核心

**学习路径：**

1. 看 3Blue1Brown《线性代数的本质》1–3 集
2. 用纸笔跟着推一遍“矩阵乘法”的几何直觉
3. 用 numpy 手写矩阵相关的小例子

你只需要理解这三件事：

### 矩阵是什么？

矩阵本质上是： **同时对一堆向量做线性变换的工具。一张图解决所有你需要了解的知识。**

![](https://pic1.zhimg.com/v2-2a573287c9dca7834158dda273a8f14e_r.jpg)

数学 **第 1 天自查练习：**

- 用 numpy 手写： 矩阵 × 向量
- 能用一句话解释：“为什么神经网络每一层可以看成矩阵乘法？”

只要你能做完这些，这一天就合格了。

### 数学第 2 天：微积分直觉

这里不要上来就啃高等数学，只要建立一件事的直觉：

梯度下降到底在干什么？

**学习路径：**

1. 找一条简单曲线，例如 y = x^2
2. 画出它的导数 dy/dx = 2x 的图像
3. 手写一个最简单的“单变量梯度下降”程序

同样一张图解决它。

![](https://pic3.zhimg.com/v2-1586be15ceb6bef95ea81d2508c4cb6e_r.jpg)

数学 **第 2 天自查练习：**

- 用 numpy 写一个简单的梯度下降：拟合 y = x^2 或线性回归
- 打印每一步的 loss，观察是否下降
- 把学习率设大一点，看看会不会发散，再解释为什么

做到这些，你就已经具备理解“模型怎么学”的直觉。

### 数学第 3 天：概率 & 噪声

深度学习里的概率，你不用搞懂一大堆公式，只要理解这三件事：

1. 噪声（Noise）
2. 采样（Sampling）
3. Softmax 概率分布

![](https://pic3.zhimg.com/v2-a80bc7b9a46288ac477b83aa6c63bf96_r.jpg)

数学 **第 3 天自查练习：**

- 用 numpy 生成 10000 个高斯随机数并画直方图
- 手写一个 softmax 函数，检验输出是否为 1
- 在同一个 logits 上，用不同 temperature 做 softmax，看输出分布变化

做到这里，你的数学准备就够支撑后面所有内容了。再往下深挖线代或高数，对大多数想做工程的人来说，性价比不高。

### 阶段 2：深度学习基础（3 天搞定）

目标：理解“神经网络本质是什么 + 训练流程 + 最小 CNN”，不再被“黑箱”吓到。

### 深度学习第 1 天：神经网络本质 = 函数逼近器

**学习路径：**

1. 略读《Dive into Deep Learning》前 3 章或类似中文资料
2. 用 PyTorch 实现一个两层 MLP 做一个玩具二分类
3. 改几次结构，看 loss 和准确率如何变化

依然是一张图解决问题

![](https://picx.zhimg.com/v2-3d15e47acc21d82f922fd370e3eb6759_r.jpg)

深度学习 **自查练习：**

- 用 PyTorch 写一个两层 MLP，对一个二维玩具数据做分类
- 尝试用 ReLU / Sigmoid / Tanh，观察训练速度和最终效果
- 画出训练过程中的 loss 曲线

如果你能做到这些，恭喜，你已经跨过了“神经网络是黑魔法”的门槛。

### 深度学习第 2 天：前向传播 → 损失函数 → 反向传播

核心目标：你要能自己从 0 写出一段「训练循环」。

**典型训练循环大概长这样：**

![](https://pic3.zhimg.com/v2-1cb776d78bf55647d9b745cb2908d398_r.jpg)

你需要搞懂：

- 前向传播：输入 → 一层层算 → 输出预测 ŷ
- 损失函数：衡量 ŷ 和真实 y 差多远
- 反向传播：PyTorch 根据计算图，自动求出每个参数的梯度
- 优化器：拿着梯度更新参数（SGD、Adam 等）

你不需要手写链式法则推导，只要会用就行。

深度学习 **自查练习：**

- 自己从空白文件写出一个最小训练循环（不能 copy paste）
- 对比 SGD 和 Adam： 换同样学习率，看哪个收敛更快
- 能解释一句话：为什么学习率过大会发散？

### 核心模型3.3 Transformer：现在所有 LLM 的骨架

这是全篇里最值得花时间的部分。

自注意力（Self-Attention）公式：

Attention(Q,K,V) = softmax(QK^T / sqrt(d_k)) V

用下图认真解释一下：

![](https://picx.zhimg.com/v2-98ac05924e45dc8ea5ddf598fa14cf5b_r.jpg)

做到这一步，你已经能读大多数开源 LLM 的代码结构了。

### LLM工程4.1 微调：让模型“偏向你”

几种常见方式：

- SFT（监督微调）：喂给模型「问题 + 标准答案」
- LoRA：在大权重矩阵旁边加一个小的可训练低秩矩阵 BA
- QLoRA：先把原始权重量化成 4bit，再挂 LoRA，提高显存利用

什么时候用微调？

- 你的任务非常垂直（例如某行业专业问答）
- RAG 无法很好解决生成风格 / 推理逻辑问题
- 你希望模型“说话方式”有固定风格（品牌语气）

### LLM工程4.2 RAG（检索增强生成）：让模型“知道你们公司的事”

RAG 大概长这样：

问题 → Embedding → 检索相关文档 → 拼成 Prompt → 喂给 LLM → 回答

要做的工程工作主要集中在：

- 文档清洗和 chunk 切分
- 选择 embedding 模型
- 选向量数据库（FAISS / Milvus / pgvector 等）
- Rerank + Query Rewrite 提升质量
- 加上缓存和日志，做成真正可用的系统

现实里，80% 公司级问答 / 知识库 / 内部助手类需求，RAG 就够了。

### 阶段5 Agent：让模型不止“会说”，而是“会去做”

Agent 本质上是：

LLM + 一堆工具（Tool） + 一点点规划能力

它通常包含几个组件：

- Planner（规划步骤）
- Tools（执行动作，比如搜索、调用 API、跑代码）
- Memory（记住之前的关键信息）
- Executor（真正去跑）
- Reflection（复盘 & 自我修正）

你可以从最简单的开始：

- 写一个「自动写日报」 Agent： 调用日历 / 任务管理 API
- 再慢慢升级到： 自动分析 Excel

做到这个阶段，你已经从“玩玩大模型”变成了“用大模型搞自动化系统”的人。
