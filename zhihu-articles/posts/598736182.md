## 一、基础

### 1、Python

在学习RL之前，肯定是要把 **python** 的基本知识和操作熟练掌握，比如说类和对象，pycharm一些快捷键，一些数据类型numpy、list、tensor，如何增删改查，等等，这里b站上课程很多，我就不做推荐了。

ps：学习python之前记得下好 **pycharm** （python高效编写软件）和 **anaconda** （包管理软件）。

### 2、pytorch

现在的强化学习都是需要用到深度学习来训练，pytorch作为深度学习的框架之一，由于其比tensorflow更加简单易上手深受学生党和科研工作者的喜爱。

所以学习RL之前，还是要把pytorch学习一下，比如说网络训练的流程、正向传播、方向传播、计算图、链式求导、梯度下降、如何自己搭建一个网络模型、模型的保存与使用等等，这些概念在以后的学习中是必不可少的，随着学习的深入大家会更有体会。

### 3、算法学习

强化学习主要分为两大块， **值学习** 和 **策略学习** ，每个分支下边还有很多算法。不建议初学者一股脑全看一遍（因为你不可能把每个算法都用到，学习时间也不够），可以先学一下比较经典的算法，比如说 **DQN** 、 **DDPG** ，对强化学习的过程有一个深刻的认识和理解，然后再需要那个去学习哪个算法。

在此阶段，大家就可以读一些论文一起学习了。

**书籍** 的话，不太推荐初学者学习sutton的《强化学习第二版》，虽然它是强化学习领域中圣经一般的存在，可是对于初学者比较难懂。相反，国内的书籍有很多不错的选择：王树森 **《深度强化学习》** 、 **《磨菇书》** 、 **《深入浅出强化学习》，** 书中也有很多插图，方便理解。

## 二、进阶

在搞定基础和一些经典算法之后，大家就可以去学习一些进阶的算法，看一些比较新的顶会、顶刊的论文。

在看论文的时候要思考：

他论文是要解决什么样的问题？

采用了什么样的方法？

与经典的算法相比有什么改进的地方？

我们有什么可以借鉴的部分？

我们如何进行一些修改？

这几个问题会贯穿我们科研生活的始终，常思常新。

## 三、实战

作为一个以编程为基础的领域，动手实现代码是我们 **必不可少** 的技能。作为新手，在开始自己的项目之前，最好先去github上找一些别人的代码，跑起来，然后看懂，最好是多看几个，集百家之长。以下也有几点经验分享：

1、刚开始跑别人代码，在将代码下载到本地后，我们遇到的第一个问题就是环境配置问题，如果有一些报错不要觉得痛苦或烦躁，大多数是因为缺少对应的库包、库版本不匹配、pip install的时候没有关掉外网等等，将报错信息复制粘贴到网上搜一下一般都可以解决。

创建自己的虚拟环境：打开Ananconda Prompt

1）、创建自己的虚拟环境：

命令代码是：conda create -n 虚拟环境名字 python = 3.8

2）、激活虚拟环境

conda activate 虚拟环境名字

3）、安装 包

pip install xxx包

4）、卸载 包

pip uninstall xxx包

2、在前辈的代码上进行print输出或者debug，看一下数据类型和代码的流程。

3、在别人的代码上做一些改进，看看代码是否还能正常运行，运行的效率是否受到了影响？

最后，在RL的学习中，代码能力真的很重要，需要大家不要有畏惧心理，多跑跑别人的代码，尽可能多读好的代码，遇到报错认真分析原因，看提示，上谷歌或github上的话题讨论，都会给你很多帮助，祝大家科研越来越顺利！
