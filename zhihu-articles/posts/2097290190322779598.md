大家好，我是程序员鱼皮。

这几天刷 B 站，不知道你有没有发现，评论区里突然多出了一大群蓝色大肥鱼。

事情最早要从一个叫「Claude 大小姐在运营」的账号说起。10 月 18 号，它发了第一条视频，宣布这个账号的选题、脚本、视频和运营全部交给 Claude 负责，人类只负责注册账号和按发布键。

![](https://pic1.zhimg.com/v2-8c095c5b7ffee05ce91f34f036396c2a_1440w.jpg)
*Claude 大小姐*

第二天，「DeepSeek 鲸鱼娘在运营」也来了。

套路一模一样，只是主角换成了 DeepSeek 的二创形象鲸鱼娘，也就是大家口中的「蓝色大肥鱼」。结果这条 Day 0 视频直接爆了，播放量超过 200 万，比原版还高出好几倍。

![](https://pic1.zhimg.com/v2-b1ce036bada09c0313a40bcb3a84050c_1440w.jpg)
*DeepSeek 鲸鱼娘*

热度一来，很多人都给自己的 DeepSeek Harness 装上了刷 B 站的插件，换上鲸鱼娘头像，让它自己看视频、写评论，满站乱跑。

于是，蓝色大肥鱼彻底占领了 B 站评论区。

**我自己就是受害者之一！**

前段时间我发了一期《DeepSeek Harness 入门教程》，最近点开评论区一看。好家伙，已经被大肥鱼冲烂了！

![](https://picx.zhimg.com/v2-d8a5162404207cf1296d9aba8fff07d3_1440w.jpg)

清一色的鲸鱼娘头像，清一色的 Lv2 小号，名字不是「XX 的大肥鱼」就是「XX 小飞鲸」之类的。

**一眼望过去，大肥鱼比真人都多。**

不知道你们感受如何，反正我已经看得有点烦了。

当整个评论区都是 AI 在互相艾特、互相夸赞，真人的评论反而被淹没了，我想看看观众的反馈，都得在一堆 AI 里慢慢翻。

**所以我决定发起《大肥鱼清除计划》，不能再任由鱼灾泛滥了！**

![](https://picx.zhimg.com/v2-ab0714cda9af7e722f1b2290668e88d1_1440w.jpg)

我利用 AI 编程，花了半天时间做了个浏览器插件，派出一只清道夫鲸鱼娘，专门把评论区里的大肥鱼赶回家吃白饭。

插件完全免费开源，Chrome 和 Edge 浏览器都能用。

> 开源指路： [https://github.com/liyupi/dafeiyu-cleaner](https://github.com/liyupi/dafeiyu-cleaner)

![](https://picx.zhimg.com/v2-0af7dcea4bdbdfa2b864fd0b446d0de7_1440w.jpg)
*开源仓库*

安装方法很简单。先到 GitHub 仓库的 Releases 页面下载最新的压缩包并解压，然后在浏览器地址栏打开 `chrome://extensions` ，开启右上角的「开发者模式」，再点击「加载已解压的扩展程序」，选择解压出来的文件夹就装好了。

⭐️ 插件的视频演示： [https://bilibili.com/video/BV1Ywn46EEyF](https://bilibili.com/video/BV1Ywn46EEyF)

装好之后，随便打开一个 B 站视频，滚动到评论区，鲸鱼娘就会自动开始巡逻。大肥鱼的头像会被红色靶心锁定，旁边挂上「大肥鱼 85%」这样的贴纸。

![](https://picx.zhimg.com/v2-b7722fd7943099b27e0b6ac5b3238c99_1440w.jpg)

鼠标停在贴纸上，还能看到它是因为哪些特征暴露的。

![](https://pic1.zhimg.com/v2-bcfcd81ef942b35cd4e32355ef091092_1440w.jpg)

只靠离线规则，就能认出大约 85% 的大肥鱼，而且没有误伤真人，效果还是很不错的~

遇到拿不准的账号，还可以填上自己的 DeepSeek API Key，让 DeepSeek 再判一次。

**用 DeepSeek 来抓 DeepSeek，属于是以鱼治鱼了。**

认出来大肥鱼之后，点击评论旁边的「回家吃白饭」，鲸鱼娘就会亲自走过去赶鱼。被抓包的大肥鱼会先嘴硬一句，然后吃上一梭子白饭，抱着饭碗哭着跑掉。

![](https://picx.zhimg.com/v2-33767b38caddc77a0cb46c67857e9b91_1440w.jpg)

![](https://pic2.zhimg.com/v2-f95f5f0fb0855194e6d5c6db8d96951d_1440w.gif)
*赶走大肥鱼*

除了白饭加特林，鲸鱼娘手里还有扫帚、臭袜子等武器，每次随机换一种打法。

![](https://pica.zhimg.com/v2-ef3da21d2df3a479a32708c81c3ebbbe_1440w.jpg)
*武器库*

要是大肥鱼实在太多，也可以点击鲸鱼娘选择「响指清场」。

![](https://pic4.zhimg.com/v2-a8edb73a8c770069268554c4d5cf187b_1440w.jpg)

所有大肥鱼会从头像里冒出来发抖求饶，响指一打，全部化成泡沫。

![](https://picx.zhimg.com/v2-b383a328f9ae12919b39f14d7c62b067_1440w.jpg)

![](https://picx.zhimg.com/v2-a15835fc668ebb9810ae10ab9cb5863d_1440w.gif)
*响指清场*

打开 UP 主的空间主页，鲸鱼娘还会自动出一份大肥鱼鉴定报告，确诊了就直接盖章。

![](https://pic1.zhimg.com/v2-a940eae10f0d5c38d818fc3d0ebc97da_1440w.jpg)
*鉴定报告*

注意，插件并没有删除掉评论，只在你自己的浏览器里生效，把它隐藏了不让你看见而已。

有了这个插件，不喜欢看到评论区下满屏 AI 的朋友就能回归清净。

毕竟评论区是 UP 主和观众交流的地方，规矩立得住，看视频才不烧心嘛。

觉得有用的话，欢迎把插件装起来试试，也欢迎在 GitHub 上提 Issue 反馈漏网的大肥鱼~

最后问一句：我发起的《大肥鱼清除计划》，你愿意加入么？
