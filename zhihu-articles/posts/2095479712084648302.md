# 三、AI智能体开发技术栈

## 1、AI智能体开发技术栈

> 本文中使用Java技术栈，本例需求是要开发多智能体，且智能体需要自主ReAct 循环（推理 → 执行计划 → 执行工具 → 观察结果 → 再推理），所以智能体框架选中AgentScope-java中的AgentScope Harness；LLM选用的是通义千问大模型qwen-plus，向量模型选用的是qwen3.7-text-embedding。

| 序号 | 组件 | 版本 | 说明 |

| 1 | JDK | 17 | AgentScope 2.0.4要求JDK17 |
| 2 | Spring Boot | 4.0.4 | 与 AgentScope 官方 BOM 声明一致 |
| 3 | Spring Framework | 7.0.x | 由 Spring Boot 4.0.4 托管 |
| 4 | agentscope-harness | 2.0.4 | io.agentscope:agentscope-harness |
| 5 | agentscope-extensions-model-dashscope | 2.0.4 | 通义千问（DashScope） |

# 四、AI智能体工程构建

> 工程基于 **AgentScope Java 2.0.4 的 `agentscope-harness`** 构建的智能体应用示例。 
>  整体框架采用 **Spring Boot（WebFlux）+ 内嵌 Vue** ：Vue 页面直接放在 Spring Boot 的 `resources/static` 下， **不需要单独的前端工程、不需要 Node 构建** 。采用WebFlux是因为智能体需要采用流式方式向前端页面流式返回数据，前端页面对流式数据进行拼接后进行解析。

1、下载源码

```text
git clone https://gitee.com/duyanjun/agent-harness-demo.git
```

1)、修改LLM(agent.dashscope.api-key)、向量模型API_KEY(agent.rag.embedding.api-key)，这个大家可以自己申请阿里千问或deepseek的apikey都可以
