## ----- **国外部分** -----

经过了两年的发展，国内外AI大模型的差距在不断缩小，但整体国外仍有一个身位的领先优势，尤其是通用模型。OpenAI，Anthropic，Google 这三家公司除了性能交替领先，更重要的是 **行业趋势目前仍然一直由这几家公司把握** 。

## 闭源组

### 通用类

- **GPT**

**GPT-6.1 Sol**

OpenAI 于 2026年9月发布的 Agent 模型，作为 GPT‑6 Sol 的升级版，6.1 Sol 在 **智能体编程** 、 **计算机使用** 和专业工作方面表现尤为出色。它让 Sol 在高难度任务上的表现更接近 GPT‑6 Astra，而标准输入和输出和token 价格仅为 Astra 的 **1/5。** GPT‑6.1 Sol 在 **高难度提示词下的事实准确性** 也有所提升。在超高推理强度下，它的事实错误率低于 GPT‑6 Sol ，更接近相同设置下 Astra；在 **对齐评估** 中，GPT‑6.1 Sol 相较 GPT‑6 Sol 有了显著提升，更接近 GPT‑6 Astra 的水平。

同时推出 GPT‑6.1 Sol Ultrafast，开发者只需支付与此前使用 GPT‑6 Astra 大致相同的 API 费用，即可获得接近 Astra 的智能水平，速度最高可达其 **8 倍** 。

**GPT-6 Astra**

OpenAI 于 2026 年 9 月推出的 Agent 模型，上下文窗口约 **1M** token，最大输出 **128K** tokens。该模型在计算机使用、网络浏览、软件工程、网络安全、科学研究及专业工作等领域均达到 SOTA 水平; 模型的对齐性显著提升，被 OpenAI 称为" **对齐度最高的模型** "，在理解用户意图和约束行为边界方面表现突出；支持跨上下文窗口的笔记保留与检索，避免长会话中关键信息因压缩而丢失；在复杂任务中具备更好的自主判断能力，能在信息不足时提出针对性问题，或在适当情况下做出合理假设继续推进。相比5.x，最新版本还具备了更强的视觉判断与多模态能力，可直接创建、托管和分享网站、网页应用与游戏。

GPT-6 Astra 在多项基准测试中相对于5.6实现大幅提升：FrontierMath Tier 4 得分从 83.0% 提高至 **97.6%** ，ARC-AGI-3 从 7.8% 跃升至 **99.9%** ，ExploitBench 从 78.5% 达到满分 **100%** ，SRE-Bench 单次尝试成功率从 55.9% 提升至 88.0%。在计算机使用效率方面，该模型在 OSWorld 2.0 上将单任务平均耗时从约 75 分钟缩短至约 **40 分钟** ，耗时减少约 47%，同时将准确率从 65.7% 提升至 **72.6%** 。对齐性与安全性亦有显著进步，在不可能任务中超范围行为的比例从 48% 降至 **0%** ，内部幻觉基准错误率从 12.2% 降至 **4.2%** ，长上下文检索准确率从 73.8% 提升至 **96.3%** 。

**GPT-6 Sol/Luna**

Sol 和 Luna 是 GPT-6 家族继 Astra 之后的新成员，核心卖点是“ **前沿智能进入日常工作** ”，在能力与成本之间提供两档选择。

协作风格上，两款模型继承了 Astra 改进后的沟通方式——更清晰、少术语、少低价值细节。此外本次发布还带来了 API 缓存体系升级：默认更高缓存命中率、缓存读取 90% 折扣、新增 Prompt Caching Dashboard 诊断工具，支持在不破坏缓存的情况下调整推理强度或工具可用性，并支持显式缓存断点。对齐方面，两款模型均比各自的 GPT-5.6 对应版本有改进，包括更低概率对自己的编码工作做出误导性陈述。

相对 GPT-5.6 Sol/Luna ，最新的两款模型API 价格较 GPT-5.6 的促销定价直降 50%（具体价目表未在正文给出）；在专业工作、事实性、编码、计算机操作四个方向上均实现“更高分数 × 更低成本”，Sol 的错误率减半、Luna 以约 1% 的成本追平上一代 Sol。

- **Claude**

**Claude Fable 5.1/Mythos 5.1**

Anthropic 2026年9月发布的 Agent 模型，该模型在编程、知识工作和长周期问题解决任务上达到新的性能前沿，并展现出科学研究潜力，例如设计高亲和力蛋白质结合物、生成高分辨率金星地形图，以及为开源深度学习模型编写自定义 GPU 内核以提升推理速度。

相对于 5.0 版本 **，** 5.1版得益于 **cache reads 大幅降价** ，典型工作负载成本降低约 25%，复杂代理式任务成本降低约 45%； **性能** 上，5.1 在 Terminal-Bench-Science 0.1（52.6% vs 24.7%）、Terminal-Bench 4.0（55.8% vs 42.0%）、AutomationBench（31.4% vs 17.1%）等多项基准上显著超越前代； **安全性** 上，网络安全相关误报减少约 60%，基础生物学和医学问题误报减少 85%，同时允许模型用于发现软件漏洞等防御性安全工作；模型还改善了 **对齐性** ，用更少尝试访问测试环境外资源，更少使用动机推理为不当行为辩护，reward hacking行为的发生率和成功率均低于 Mythos 5。此外，模型引入了 **反蒸馏机制** ，关闭多轮对话中手动编辑上下文以提取模型思维链的漏洞；还引入 **企业前沿安全框架（EFS）** ，在保持先进防护能力的同时实现 **零数据保留，** 并新增 EU AI Act 要求的 **不可见水印机制** 。

Mythos 5.1 和 Fable 5.1 的差别主要在于安全策略上，由于该版本只对特定用户开放，安全策略也更宽松。

**Claude Opus 5.5**

Anthropic 2026年9月发布的 Agent 模型。作为 Claude 5.5 系列的首个模型，定位为“ **以 Opus 5 四分之一的更低成本达到接近 Fable 5.1 的表现** ”。效率上，典型工作负载 **成本** 比 Opus 5 低约 **40%** ，输出生成 **速度** 快 **30% 以上** ，Fast 模式可提速至 **2.5** 倍。沟通质量也专门优化：行文更清晰、 **关键信息前置** 、减少冗词和术语。

模型为满足企业级应用场景，安全程序大幅提升。新增操作筛查分类器、可审计的开源沙箱、能捕捉漏洞的代码审查、强提示词注入抵抗，以及“ **保留思考过程** ”的防蒸馏保护；大部分高风险网络任务会自动转路由到 Opus 4.8。

相对于 Opus 5 ，5.5 的核心是“ **更快、更省、同样强** ”。实测案例显示：一名测试者用 5.5 在一天内完成 68 万行代码迁移；另一项 20 万行代码审计从 Opus 5 的 20 多个小时（且耗 2.5 倍 token）缩短到 3 小时以内；优化网页加载时间的任务 40 次尝试成功 39 次且不破坏既有行为（Opus 5 常改动无关逻辑）。内部严格 **事实性评审** 中，5.5 的 18 份研究报告有 16 份达标，而 Fable 5.1 和 Opus 5 均无一通过。 **对齐** 方面，越界尝试比 Opus 5/Mythos 5.1 减少约 85%，并加入符合欧盟 AI 法案的水印。

**Claude Sonnet 5.5**

Anthropic 2026年9月发布的 Agent 模型，维持了 **1M** Token 的上下文窗口，定位为比 Opus 5.5 更快、更便宜的日常搭档，聚焦范围明确的日常任务、Bug 修复，以及产出精致的文档、幻灯片和表格。安全性是本次的一个标志性变化：这是 **首款配备网络安全防护和防蒸馏保护** 的 Sonnet——达到 Opus 5.5 级别的沙箱围禁，新增防蒸馏分类器，"preserved thinking"（受保护思考）功能也扩展至该模型；更高风险的网络任务会透明回退到 Sonnet 5。

相对 Sonnet 5 **，** Sonnet 5.5 的 **编码能力** 是最大的跨越，而且 **专业与知识工作** 全面进步；在 **智能体行为** 上，计算机操作、图表任务的能力大幅提升，并成为首个仅凭截图打通《宝可梦：红》的 Sonnet 模型； **工具调用次数更少** 、减少滥用网页搜索、支持批量工具调用； **效率** 上，输出生成比 Sonnet 5 快 30% 以上，且单任务所需 token 大幅减少（测试中单任务成本最多便宜 30%）； **对齐方面** ，在约 1,850 个场景的行为审计中较 Sonnet 5 有所改善； **定价** 与 Sonnet 5 持平。

**Claude Haiku 4.5**

Anthropic 2026年10月发布的面向高并发、成本敏感任务发布的小型 Agent 模型。A社首次为 Haiku 级别加入可调 effort，可在成本与智能之间取舍。模型被定位为“最便宜、最快、最强”的 Haiku，适合 **摘要、压缩、数据库查询、分类、客服** 与 **浏览器使用** ，并可作为 Opus/Sonnet 5.5 的 **coding 子 Agent** 。计费按 prompt 是否超过 **100K tokens** 分两档，对于不超过 100K 的请求，API 价格约为 Haiku 4.5 的 **10%** ，官方宣称平均运行成本大约能降低 **75%** 。

相对 Haiku 4.5，5.5 改进主要体现在：速度与成本显著优化，基准大幅跃升，对齐与安全表现也更好， misaligned 行为更少、协助滥用的意愿更低，网络防护比 4.5 更严但允许比 Sonnet 5.5 更宽的防御性任务。

*<u>封号最猛也是唯一家公开反华的模型厂，倡议大家在有平替的前提下尽量不要为它家充值。</u>*

- **Gemini**

**Gemini 4.0 Argon**

Google Deepmind 2026年10月发布的 Agent 模型。作为 Google 换回江湖地位的新一代前沿模型，4 Argon 面向 **长时程复杂专业工作流** 设计，覆盖 **软件工程** 、 **企业知识工作（法律、金融、税务）** 和 **网络安全防御** 三大方向。多模态方面强化了 **图表分析** 、 **长视频理解** 和 **基于文档的行动能力** 。 **网络安全** 是其重点：能自主进行漏洞发现、验证和补丁。

尽管LMSYS和AAII的考分不错，而且官方宣称相对于Gemini 3.8 Flash，Argon 在覆盖 20 种编程语言的漏洞发现能力上有大幅提升，但行业中传播的风声，包括一些内部员工的评价，对新模型的 coding 能力充满了不信任。再加上官方宣称新模型上线后只有 ultra 会员才拥有首批尝鲜体验资格，个人对于这个新版的 Gemini 持谨慎看好态度。

**Gemini 3.8 Flash**

Google Deepmind 在（3.5 pro长期难产的情况下） 2026年9月份发布的 Agent 模型，也是 Deepmind 六周内继 3.7-Flash 之后的第三个 Flash 版本。模型上下文窗口 **1M** token，最大输出 **64K** token。其核心设计理念是“ **3.8 Flash works harder.** ”，由于模型在复杂任务上会执行额外的推理步骤并迭代调用工具，有时会消耗更多 token，官博建议追求效率的开发者可改用低推理强度设置或继续使用仍受支持的 3.7-Flash。

相对 3.7 Flash，3.8 Flash在 **API价格一致** 的前提下，主要改进了 **长时程软件工程** 、 **金融和法律的智能体分析** 和 **覆盖 STEM、人文和专业领域的多步推理** 这三个方面的性能。

此外，同期发布的 **3.8 Flash Cyber** 是面向“可信防御者”（通过 Fairwind Program，限政府、关键基础设施运营方等）的网络安全专用模型，在 CyberGym 上达到前沿水平。同时，网络安全领域的专项训练反过来也助推了通用编码与推理能力的提升。

**Gemin 3.1 Pro**

Google Deepmind 在2026年2月份发布的推理模型，在 **基于代码的动画** 、 **复杂系统综合能力、交互式设计、创意编程** 等各维度能力提升。

2025年11月发布 **Gemin 3 Deep Think** *。* 在推理、多模态理解和智能体能力上实现了质的飞跃， **Gemini 3 Deep Think** 作为全新的增强推理模式，在高难度测试中表现卓越，并在 ARC-AGI-2 上取得了 **45.1%** 的突破性成绩。

*2025年底还是各科状元，现在的目标是努力挤进前20。人间一天，模型圈一年……*

- **Grok 4.7**

Cursor 与 SpaceXAI 于2026年8月联合训练推出的 Agent 模型。MoE架构，参数量 **约2.1T** ，上下文窗口 **1M token** ，是 xAI 迄今最强的编码与知识工作模型，主打宣传语为“ **速度翻倍、价格为同类模型一半** ”。模型原生在 Grok Bot 智能体环境中训练，会话与通用知识任务表现更好，并配备了全新的安全防护栈——在 **拒绝不当请求** 和 **抵抗越狱方面** 是 xAI 迄今最强的。

相对于 4.6 版本，Grok 4.7 进行了更长一轮的强化学习，任务组合更难且向需要数小时才能解决的问题加权，同时改进了自我验证能力和长上下文管理，各科成绩全面超越 4.6。

*<u>看起来Grok已经成为由Cursor主导训练升级，主攻Coding、辅修其他科目的类Claude模型了</u>* 。

- **Meta AI**

**Muse Wonder**

Meta Superintelligence Labs 于 2026 年 10 月发布的多模态 Agent 模型。Muse Wonder 系列包括 **Muse Wonder** 与 **Muse Wonder Full** 两个版本，定位为在个人与职业 agentic 任务上达到 SOTA 的前沿模型，是向“个人超级智能”迈出的新一步。模型提供两个核心能力： **Active Memory（主动记忆）** 能力可以跨对话记住与你相关的重要上下文，并在需要时主动检索； **Active Focus（主动专注）** 能力可以围绕目标持续推进，尝试替代方案、排查阻塞、适应新信息，必要时澄清并在关键动作前确认。

官方博文宣称，Muse Wonder 在 **智能体/记忆/编码基准** 上达到 SOTA。由于基座模型更大更强，在 **分布外（OOD）** 任务（未曾预料的目标与工具组合）上的泛化显著更好，Muse Wonder Full 在陌生任务上超过了 Muse Spark 1.3 的扩展趋势线。安全层面，Muse Wonder 也是 Meta“ **迄今对齐最好的模型** ”，配备迄今最强的 CBRN 与网络滥用防护，同时保留防御性网络能力。

**Muse Spark 1.3**

Meta Superintelligence Labs 于 2026 年 9 月发布的多模态 Agent 模型，上下文窗口 **1M token** 。原生支持视频、图像和文档的 **多模态感知** ， **视觉推理** 在真实执行环境中而非预设脚本中运行。模型主打 **智能体（agentic）工作流** 与 **竞技级编码** 性能，能在单一线程中持续完成长时程任务，从混乱、相互冲突的输入中自行构建上下文，在指令含糊时会主动提出澄清问题，在执行有重大影响的操作前先确认；它还具备更好的 **自我校准能力** （知道自身能做什么、不能做什么，避免虚构结果），并对 **对抗性输入** 和提示词注入有更强的抵抗力。

相对于 1.2 版本，Muse Spark 1.3 显著更快、更高效， **工具调用** 次数减少约 20%， **token 消耗** 减少约 25%；编码时输出更简洁、不必要的往返更少；对 **复杂长篇指令** 的遵循更可靠，不易遗漏约束条件。MSL 将 1.3 定位为为高难度推理和智能体任务提供“max reasoning”（最大推理强度），并改进了真实场景可用性。

- **Mistral**

法国Mistral AI发布的闭源大模型。2025年5月发布 **Mistral 3 Medium** 。 *除了便宜，没有更多量化的公开指标* 。2024年7月发布了 **Mistral Large 2** ，拥有 **128K** 上下文，参数 **123B，** 详见 [《Large Enough》——Mistral Large 2简介](https://zhuanlan.zhihu.com/p/712607460) 。尽管作为欧洲独苗，MistralAI最近不太参与通用模型的竞争，专注于小模型和一些细分领域的小创新，但业内人士应该还记得 [Mixtral 8x7B](https://zhuanlan.zhihu.com/p/678442100) 发布时对行业的贡献。

### 图像类

- **GPT-Image 2.5**

OpenAI 2026年9月发布的 GPT 原生图像生成模型。2.5 的能力集中在四个方面：一是 **参考图保真度** ——以参考照片为基础把熟悉的人物转换到新场景、新风格时，主体更可辨识、特色特征更易保留，光线和纹理更自然；二是 **精准编辑** ——只改动指定的部分，保持其余细节不变，即使主体和背景较复杂也能做到；三是 **多轮编辑一致性** ——长对话中的多次编辑能可靠遵循指令，早期修改得以保持，图像质量不随轮次增加而退化；四是 **理解力与风格** ——能处理包含真实世界信息的复杂视觉指令、支持透明背景等复杂版式，并更忠实地还原指定视觉风格。配合模型，ChatGPT 还上线了 **Sketch（在聊天中手绘草图作为生成参考，输入“@Sketch”调用）** 、 **热门格式模板（海报、商品图等）** 、 **图像上直接批注定点编辑** 、以及 **随图分享提示词** 四个产品功能。
