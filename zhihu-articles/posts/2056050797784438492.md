## LLM推理优化技术路线

**欢迎在评论区贡献！**

## 线条一：Attention优化

1. [FlashAttention: Fast and Memory-Efficient Exact Attention with IO-Awareness](https://github.com/dao-ailab/flash-attention) (Dao et al., 2022)  IO-aware 的精确注意力算法，大幅降低内存访问和计算成本，是实际推理优化的基础
2. [Star Attention: Efficient LLM Inference over Long Sequences](https://github.com/NVIDIA/Star-Attention) (Acharya et al., 2024)  块稀疏注意力机制，针对长序列推理优化。
3. [Efficient Attention Mechanisms for Large Language Models: A Survey](https://arxiv.org/abs/2507.19595) (Sun et al., 2025)  线性与稀疏注意力综述。
4. [Progressive Sparse Attention: Algorithm and System Co-design for Efficient Attention in LLM Serving](https://arxiv.org/pdf/2503.00392)
5. [FlashInfer: Efficient and Customizable Attention Engine for LLM Inference Serving](https://github.com/flashinfer-ai/flashinfer)
6. [MoBA: Mixture of Block Attention for Long-Context LLMs](https://github.com/MoonshotAI/MoBA/tree/master)
7. [MoBA: Mixture of Block Attention for Long-Context LLMs B站讲解](https://www.bilibili.com/video/BV1mh9NYvED7/?spm_id_from=333.337.search-card.all.click&vd_source=0a6f78f324f84d62793b3325491b8c8c)
8. RingAttention: [图解大模型训练系列：序列并行3，Ring Attention](https://zhuanlan.zhihu.com/p/4963530231)
9. [KV Cache Optimization Strategies for Scalable and Efficient LLM Inference](https://arxiv.org/abs/2603.20397) KV Cache优化综述 [KV Cache Optimization Strategies for Scalable and Efficient LLM Inference](https://arxiv.org/abs/2603.20397) [KV Cache Optimization Strategies for Scalable and Efficient LLM Inference](https://arxiv.org/abs/2603.20397) KV Cache优化综述
10. [KVQuant: Towards 10 Million Context Length LLM Inference with KV Cache Quantization](https://arxiv.org/pdf/2401.18079) KV Cache压缩以支持10M上下文
11. [Scissorhands: Exploiting the Persistence of Importance Hypothesis for LLM KV Cache Compression](https://arxiv.org/pdf/2305.17118) (Liu et al., 2023) 基于重要性假设的 KV 压缩。
12. [Infinite-LLM: Efficient LLM Service for Long Context with DistAttention and Distributed KVCache](https://arxiv.org/html/2401.02669v2) (Lin et al., 2024) 分布式 KV Cache 管理。
13. [KV Cache Compression for Inference Efficiency in LLMs: A Review (2025)](https://arxiv.org/abs/2508.06297) 选择性 token、量化、注意力压缩等综述。

## 线条二：解码算法优化

1. [SpeculativeDecodingPapers (GitHub 资源库)](https://github.com/hemingkx/SpeculativeDecodingPapers) 投机解码领域必读论文与博客的持续更新合
2. [A Theoretical Perspective for Speculative Decoding Algorithm (2024)](https://arxiv.org/pdf/2411.00841)
3. [Fast Inference from Transformers via Speculative Decoding](https://arxiv.org/abs/2211.17192) (Leviathan et al., Google, 2022) arXiv:  经典投机解码算法，利用小模型草稿并行生成并由大模型验证，显著加速自回归生成且不改变输出分布。
4. [Accelerating Large Language Model Decoding with Speculative Sampling](https://arxiv.org/abs/2302.01318) 提供统计保证的投机采样框架，提升解码效率。
5. [EAGLE: Speculative Sampling Requires Rethinking Feature Uncertainty](https://arxiv.org/abs/2401.15077) 基于特征级预测头的投机解码，无需独立草稿模型即可提高接受率。
6. [A Theoretical Perspective for Speculative Decoding Algorithm (2024)](https://arxiv.org/abs/2411.00841) 从马尔可夫链角度理论分析投机解码的最优性与质量-速度权衡

## 线条三：模型量化压缩

1. [A Survey on Model Compression for Large Language Models](https://arxiv.org/abs/2308.07633) (2024) 全面综述量化、剪枝和知识蒸馏等 LLM 压缩技术。
2. [GPTQ: Accurate Post-Training Quantization for Generative Pre-trained Transformers](https://arxiv.org/abs/2210.17323) (ICLR 2023) 精准的后训练量化方法，广泛用于生成模型的实际部署。
3. [AWQ: Activation-aware Weight Quantization](https://arxiv.org/abs/2306.00978) (2024) 激活感知权重量化，针对生成阶段内存瓶颈进行优化。
4. [SLIM: One-shot Quantization and Sparsity with Low-rank Approximation](https://research.nvidia.com/publication/2025-06_slim-one-shot-quantization-and-sparsity-low-rank-approximation-llm-weight) (NVIDIA, 2025)  一_shot 集成量化、稀疏与低秩压缩，实现硬件友好加速。
5. [Contemporary Model Compression on Large Language Models](https://arxiv.org/abs/2409.01990) (2024)  从量化、蒸馏和剪枝三个视角讨论当代压缩技术。

## 线条四：PD分离

1. [DistServe: Disaggregating Prefill and Decoding for Goodput-optimized Large Language Model Serving](https://arxiv.org/abs/2401.09670) (Zhong et al., OSDI 2024) 将 Prefill 与 Decode 物理分离到不同 GPU 实例，独立优化与扩缩，消除阶段干扰，在满足 SLO 的前提下将 goodput 提升最高 7.4×。
2. [Splitwise: Efficient Generative LLM Inference Using Phase Splitting](https://arxiv.org/abs/2311.18677) (Patel et al., ISCA 2024) 把推理请求拆分为 Prefill 与 Decode 两个阶段并放到不同机器上执行，针对两阶段算力/带宽差异做资源分配，显著改善吞吐与延迟权衡。
3. [Mooncake: A KVCache-centric Disaggregated Architecture for LLM Serving](https://arxiv.org/abs/2407.00079) (Qin et al., FAST 2025) 以分布式多层 KVCache 池为核心的 PD 分离架构，支持前缀哈希存储与预测式早期拒绝，专为大规模生产场景设计（Best Paper）。
4. [Prefill-Decode Aggregation or Disaggregation? Unifying Both for Goodput-Optimized LLM Serving (TaiChi)](https://arxiv.org/abs/2508.01989) (Wang et al., 2025) 统一 Aggregation 与 Disaggregation：根据 TTFT/TPOT SLO 动态混合使用 Prefill-heavy 与 Decode-heavy 实例，在平衡 SLO 下将 goodput 提升最高 77%。
5. [Not All Prefills Are Equal: PPD Disaggregation for Multi-turn LLM Serving](https://arxiv.org/abs/2603.13358) (Li et al., 2026) 针对多轮对话提出 PPD（Prefill-capable Decode），把轻量 append-prefill 路由到 Decode 节点本地执行，减少 KV 传输，Turn 2+ TTFT 降低约 68%。

## 线条五：异构优化

1. [Dovetail: A CPU/GPU Heterogeneous Speculative Decoding (2025)](https://aclanthology.org/2025.emnlp-main.879.pdf) CPU-GPU 协作投机解码，利用异构设备特性降低通信开销。
2. [High-Throughput LLM Inference on Heterogeneous Clusters (2025)](https://arxiv.org/abs/2504.15303) 针对异构集群的部署配置与资源建模，实现高吞吐推理服务。
3. [Serving Models, Fast and Slow: Optimizing Heterogeneous LLM Inferencing (2026)](https://www.microsoft.com/en-us/research/publication/serving-models-fast-and-slowoptimizing-heterogeneous-llm-inferencing-workloads-at-scale/) 针对混合延迟敏感/不敏感工作负载的异构资源动态分配框架。
4. [Hybe: GPU-NPU Hybrid System for Efficient LLM Inference (2025)](https://dl.acm.org/doi/10.1145/3695053.3731051) GPU 负责预填充、NPU 负责解码的混合系统，支持百万 token 上下文。
5. [GUIDE: A Global Unified Inference Engine for Deploying LLMs in Heterogeneous Environments (2024)](https://arxiv.org/abs/2412.04788) 统一异构环境下的 LLM 部署与性能预测引擎。
6. [A Survey on Efficient Inference for Large Language Models (2024)](https://arxiv.org/abs/2404.14294) 从数据、模型、系统三级分类的 LLM 高效推理全面综述。
7. [A survey of optimization strategies for LLM inference on hardware platforms (2026)](https://www.sciencedirect.com/science/article/abs/pii/S1383762126000081) 针对 GPU、FPGA、ASIC 和 PIM 等硬件平台的解码器 LLM 加速策略综述。
8. [Taming the Titans: A Survey of Efficient LLM Inference Serving (2025)](https://aclanthology.org/2025.inlg-main.32.pdf) 从实例级到集群级的 LLM 推理服务优化分层综述。
9. [LLM-inference-optimization-paper Collection (持续更新)](https://github.com/chenhongyu2048/LLM-inference-optimization-paper) 实用 LLM 推理优化论文与仓库的分类总结资源。
10. [Mastering LLM Techniques: Inference Optimization (2023+)](https://developer.nvidia.com/blog/mastering-llm-techniques-inference-optimization/) 工程实践总结，涵盖注意力、量化、并行等集成优化技术。

## 线条六：服务化调度优化

1. [Sarathi-Serve (2024)](https://arxiv.org/abs/2403.02310) Token-budget 感知的 chunked prefill 调度，平衡预填充与解码延迟。
2. [Efficient LLM Scheduling by Learning to Rank (2024)](https://arxiv.org/abs/2408.15792) 学习排序方法近似 Shortest Job First，大幅降低聊天延迟并提升吞吐。
3. [Optimal Scheduling Algorithms for LLM Inference: Theory and Practice (2025)](https://users.ece.utexas.edu/~gustavo/papers/BHD25j.pdf) 提供路由与调度的理论框架及实践混合调度算法。
4. [Hybrid Offline-online Scheduling Method for Large Language Model Inference (2025)](https://arxiv.org/abs/2502.15763) 混合离线/在线调度优化系统吞吐和硬件利用率。
5. [DualMap: Enabling Both Cache Affinity and Load Balancing for Distributed LLM Serving](https://arxiv.org/pdf/2602.06502) (ICLR 2026) 提出双映射调度策略，通过两个独立哈希函数将请求映射到两个候选实例，再结合系统状态智能选择，同时实现 KV Cache 亲和性（最大化前缀复用）与负载均衡。配套 SLO 感知路由、热点感知重平衡与轻量双哈希环扩缩，在真实工作负载下有效请求容量最高提升 2.25×。
