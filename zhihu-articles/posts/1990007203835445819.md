## 背景

前段时间有个朋友告诉我，他把一个cuda算子的逻辑用Ascend C实现后，在昇腾芯片上运行的耗时是GPU上的上百倍！我说，你跟我讲讲是怎么回事！

塔说，这个CUDA算子的逻辑很简单：把一个byte的每个bit都转成1个byte，举个例子，比如整数20，用8位的二进制表示是00010100，他的每个bit的值依次是0、0、0、1、0、1、0、0，所以这个算子的功能就是把一个整数展开成了8个整数：20->[0, 0, 0, 1, 0, 1, 0, 0]。

我说，那你的代码是怎么写的呢？塔说，cuda和Ascend C都是按照这个逻辑写的：

```cpp
xtern "C" __global__ __aicore__ void bitToByte(GM_ADDR x, GM_ADDR y, GM_ADDR z)
{
    __gm__ uint8_t* data1 = (__gm__ uint8_t*)x;
    __gm__ uint8_t* data2 = (__gm__ uint8_t*)y;
   int count = 8*1024*1024;
   for(int i = 0; i < count; i ++)
    {        
        uint8_t temp = data1[i];
        data2[i*8 + 0] = (uint8_t)(temp & (uint8_t)0b10000000) ? 1 : 0;
        data2[i*8 + 1] = (uint8_t)(temp & (uint8_t)0b01000000) ? 1 : 0; 
        data2[i*8 + 2] = (uint8_t)(temp & (uint8_t)0b00100000) ? 1 : 0; 
        data2[i*8 + 3] = (uint8_t)(temp & (uint8_t)0b00010000) ? 1 : 0; 
        data2[i*8 + 4] = (uint8_t)(temp & (uint8_t)0b00001000) ? 1 : 0; 
        data2[i*8 + 5] = (uint8_t)(temp & (uint8_t)0b00000100) ? 1 : 0; 
        data2[i*8 + 6] = (uint8_t)(temp & (uint8_t)0b00000010) ? 1 : 0; 
        data2[i*8 + 7] = (uint8_t)(temp & (uint8_t)0b00000001) ? 1 : 0; 
      
    }   
}

```

## 原因分析

我一看就明白了，告诉他：你这样写不慢才怪呢！鹰痿达芯片的”多核、小算力“架构和SIMT（单指令多线程）编程模式天生就擅长处理这种标量计算。

![](https://pic3.zhimg.com/v2-f07d946b82580afe5b186f274374bddc_r.jpg)

上图是英伟达芯片和昇腾芯片的抽象架构图(英伟达芯片只画出了Tensor core，没有画出cuda core，Tensor core提供了绝大多数算力)。英伟达芯片就像1000辆出租车组成的车队，而昇腾芯片就像几十辆超级后八轮组成的车队。英伟达芯片更灵活，而昇腾芯片处理大矩阵运算效率更高（比如transformer模型中的矩阵乘法）。

具体来说，英伟达芯片（以A100为例）一般有几千个cuda core和几百个Tensor core，每个cuda core都可以处理一个线程，所以基于SIMT编程模式，可以同时并行地处理上千个标量运算（比如上面代码中的逻辑运算）。而昇腾芯片一般只有几十个核，每个核里面都有处理矩阵运算、向量运算和标量运算的单元。所以尽管英伟达A100和昇腾A2芯片的总算力差不多，但是英伟达芯片在处理标量运算的并行度更高，耗时也就更短。

## 解决方案

知道原因了，怎么优化呢？那就是把昇腾芯片的vector计算单元用起来，用算法上的并行度代替线程上的并行度。具体做法是使用[select算子](https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/850alpha002/API/ascendcopapi/atlasascendc_api_07_0070.html)，把输入byte作为select_mask，例如：

```text
select([1, 0], 00010100)=[0, 0, 0, 1, 0, 1, 0, 0]
```

输入byte越长，并行度就越高。在实测中，改完之后，算子执行耗时和英伟达是同一量级。
