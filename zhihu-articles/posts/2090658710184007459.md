### 第五章：Pandas，数据驯服者

- 本章涵盖 Python 中的 Pandas 库，该库对于数据操作和分析至关重要。同时讨论了如何使用 GPT-4o 等生成式 AI 工具来编写 Python Pandas 代码。本章适合各级学习者，并侧重于实际应用。您将学习 Pandas 的主要功能，包括处理数据框和序列、清理和可视化数据，以及应用高级数据操作技术。在生成式 AI 的帮助下，本章提供了清晰的解释、代码示例，并回答您的问题，以帮助您更好地理解这些概念。通过使用 Jupyter Notebook 进行动手实践，您将培养处理现实世界数据的技能，并提升数据分析能力。

- 本章涵盖使用 **卷积神经网络 (CNN)** 和 Fast.ai 创建图像分类应用的步骤。您将获得组织项目、准备图像数据和训练 CNN 的实践经验，同时获得实时协助以帮助澄清概念并回答与编码相关的问题。在本章结束时，您将了解 CNN 如何检测图像模式，将这些方法应用于现实世界的情况，并使用 AI 工具来支持您的学习。这种实践方法涉及使用 Python、Fast.ai 和 AI 辅助，使图像分类更易于理解。

### 理解生成式人工智能

GenAI，即生成式人工智能，代表生成式人工智能。GenAI 指的是一组能够根据从广泛数据集中学习到的模式和信息创建原创内容的技术。换句话说，它们能够从现有信息中创造新事物，无论是文本、图像、音乐、视频还是代码。生成式人工智能的一些关键特征是：

### 从数据中学习

生成式人工智能系统通过大量数据进行训练，使用深度学习等方法——这是一种利用分层神经网络分析不同数据形式，然后从这些模式中学习的人工智能——来识别复杂模式并理解数据中的结构。

### 内容创作

与专注于处理和分析数据的传统人工智能不同，生成式人工智能能主动创造新内容，其范围可以从作曲到撰写文章，从创建虚拟环境到设计图形内容。

### 适应性

这些模型能够适应各种风格、类型和要求，使其成为创意行业中功能极其强大的工具。

### 自动化与效率

生成式人工智能可以显著加快内容创作流程，自动化重复性的创意任务，并协助生成想法和原型。

在本章中，我们将交替使用“生成式人工智能”和“GenAI”这两个术语，两者均指代生成式人工智能。本教材中我们将使用GenAI平台ChatGPT-4。

### Python的特点

以下是Python的一些特点：

- **易于学习：** Python非常直接，其命令类似于英语，使其易于上手和理解。这让开发者可以专注于解决问题，而不是纠结于复杂的语法和代码的排列顺序。
- **解释型语言：** Python代码逐行运行，这使得查找和修复错误更容易，因为你可以准确地看到问题出在哪里。
- **动态类型：** 在Python中，你不必指定变量将保存的数据类型；语言会在程序运行时自行确定。这种灵活性很方便，但在较大的程序中可能导致意外的错误。
- **大量现成代码：** Python拥有大量预编写的代码，可以帮助完成许多常见的编程任务，如处理文件、管理系统操作或处理互联网数据。
- **开源且社区驱动：** Python是开源的，可以免费使用和共享，甚至用于商业目的。它得到了庞大用户社区的支持，他们为其开发做出贡献，并通过论坛和其他资源提供支持。
- **跨平台运行：** Python程序可以在任何拥有Python解释器的系统上运行，如Windows、Mac OS和Unix系统。这使得Python具有很强的可移植性。

### 提示工程

提示工程是设计和优化输入以从AI模型中获得最佳输出的实践。由于大型语言模型（如OpenAI的GPT系列）的兴起，这一点变得尤为重要，这些模型根据接收到的输入进行响应。当我们向ChatGPT提问时，必须记住，尽管机器学习极其智能，但它们并非人类。我们需要确保精心设计意图明确的信息，这些信息要精确并提供足够的上下文，以便AI能够理解如何最好地回答我们的问题。由于我们将在学习Python的旅程中将ChatGPT作为个人助手使用，我们必须非常擅长正确地引导我们的AI助手，以最好地为我们提供帮助。让我们讨论一下提示工程的一些关键要素。我们将涵盖：

- 提示工程的关键方面

- 提示工程的应用

### 提示工程的关键方面

以下是提示工程的关键方面：

- **精确性：** 设计清晰且请求精确的提示，以减少模型响应中的歧义。
- **情境化：** 在提示中提供适量的上下文，以引导模型生成相关且准确的响应。
- **适应性：** 根据观察到的AI性能修改提示，以改进其输出，这涉及一个测试和调整的迭代过程。
- **指令给出：** 明确指示模型所需的输出格式、细节或结构，这可以极大地影响结果。

### 在AI交互中的重要性

### 理解内容和上下文

虽然AI可以基于数据处理和回答问题，但它通常很难理解更深层次的、隐含的上下文，尤其是复杂的人类互动或抽象概念。这对AI系统来说仍然是一个挑战，因为尽管这些系统在识别数据模式方面极其出色，但它们在处理输入和基于这些模式产生输出时，只停留在表面层次。GenAI难以识别我们人类在写作、沟通和彼此互动中可能有的一些更微妙的线索，从而导致不准确或遗漏细节。

AI在理解上下文方面也存在困难，或者它需要额外的提示来为问题提供上下文，以便答案与你的主题最相关。上下文可能迅速变化，并受到时事、文化转变或新信息的影响。这使得AI系统难以适应这些快速的变化，除非进行更新或重新训练以寻找特定细节。人类语言有某种微妙之处，AI很难捕捉到，例如讽刺。像这样的元素经常被AI系统误解，因为它们缺乏将这些线索置于上下文中理解的能力。

### 数据依赖性

AI通过分析来自极其庞大的数据源的模式和信息来创建简洁答案。这些数据源是人类创建的，这意味着它们严重依赖于我们的数据，并且AI有可能告诉我们错误的信息。我们放在网上的所有信息在AI寻找和搜索我们问题的最佳答案时都可能被使用和考虑，有时，它会从不太可靠或不准确的来源中提取信息。AI会犯错，因为人类会犯错。

### 创造力和创新

尽管AI可以通过将现有信息重新组合成新的形式来模拟创造性过程，但真正的原创性和从零开始创新的能力仍然是它不具备的特质。由于它借鉴了人类创造的来源，AI所做的所有创造性工作都与人类创作的原始作品相关联。可以认为是深受启发，或者就像AI在创作一个新的、混音的作品。

### 安全与隐私

围绕安全与隐私的担忧始终至关重要，随着这些人工智能技术在我们日常生活中日益普及，这一点变得愈发明显。在审视这些风险时，我们需要考虑以下几个要素：

- **数据泄露** ：人工智能系统通常需要访问大量数据来进行学习和决策。这些数据可能包含敏感的个人信息，如果未得到妥善保护，就可能面临泄露风险。人工智能系统中的数据泄露可能导致个人详细信息、财务信息及其他机密数据被暴露。
- **监控与监视** ：人脸识别和位置追踪等人工智能技术是强大的监控工具。虽然它们可以服务于增强安全性等有益目的，但也引发了重大的隐私担忧。不受监管或过度的监控会导致隐私丧失，并被视为具有侵入性。
- **操纵与控制** ：人工智能可用于制造逼真的虚假音视频、操纵公众舆论并影响政治局势。这种操纵可能对个人隐私和安全构成深远威胁，影响个人控制自身数据以及所接收信息真实性的能力。
- **缺乏透明度** ：许多人工智能系统的决策过程并不透明。这种透明度的缺失使得用户难以理解其数据如何被使用，也难以对人工智能做出的决策提出异议，从而可能导致隐私侵犯。

### 伦理决策

在思考人工智能技术应如何运作时，一个常被提及的问题是人工智能应如何以合乎伦理的方式进行决策。尽管通常情况下，人们对于是非对错存在共识，但每种情况都需要独特的应对措施。此外，在做决策时，人工智能可能会从其在线找到的他人内容中汲取伦理上的错误行为。本书后续将更详细地探讨这一点，但目前，以下是人工智能在进行伦理决策时遇到的某些问题的简要概述：

- **偏见与歧视** ：用于训练人工智能系统的数据可能包含带有偏见的信息或反映历史不平等。这可能导致人工智能系统延续这些偏见，影响招聘、贷款和执法等领域的决策。虽然这不是直接的隐私问题，但带有偏见的数据可能通过不公平地针对某些群体而导致隐私侵犯。
- **道德困境** ：人工智能系统可能面临需要做出具有道德影响的决策的情况。例如，自动驾驶汽车可能需要在伤害不可避免的场景中做出瞬间决策，例如在两种潜在事故之间做出选择。编程人工智能以符合人类伦理标准的方式处理此类道德困境极其困难。
- **问责与责任** ：当人工智能系统做出导致负面结果的决策时，确定谁应负责——设计者、用户还是人工智能本身——是复杂的。这在医疗保健、自动驾驶和执法等领域尤为重要。确保人工智能决策的问责制是一个重大的伦理挑战。

### 使用 pip 安装 Jupyter Notebook

首先，确保您已安装 `Python` 。建议使用 `Python 3.10` 或更高版本，您可以通过打开终端并输入以下命令来检查是否已安装：

```text
Terminal> python3 --version
```

如果未安装 `Python` ，您可以从 `Python` 官方网站下载并安装。

安装 `Python` 后，请按照以下步骤安装 `Jupyter Notebook` ：

1. **打开终端：** 您可以在应用程序的实用工具中找到终端，或使用聚焦搜索进行搜索。
2. **更新 pip：** 通过运行以下命令确保您的 `pip` 版本是最新的：

```text
Terminal> python3 -m pip install --upgrade pip
```

1. **安装 Jupyter Notebook：** 现在，使用 `pip` 安装 `Jupyter` ：

```text
Terminal> python3 -m pip install notebook
```

1. **启动 Jupyter Notebook：** 安装完成后，在终端中运行以下命令以启动 `Jupyter Notebook` ：

```text
Terminal> jupyter notebook
```

这将在您的默认网络浏览器中打开 `Jupyter Notebook` 。

在本地笔记本电脑或台式机上使用 `pip` 安装 `Jupyter Notebook` 的三大主要优势如下：

- **完全控制和自定义：** 在本地笔记本电脑上安装 `Jupyter Notebook` 允许您根据需要自定义环境。您可以安装任何 `Python` 库、配置设置，甚至添加扩展以增强功能，从而完全控制您的开发环境。
- **离线可访问性：** 本地安装意味着您可以在任何时间处理项目，即使没有互联网连接。此功能在连接受限或云平台不可用或不切实际的地区特别有用。
- **数据隐私和安全性：** 通过在本地运行 `Jupyter Notebook` ，您的数据和项目保留在您的设备上，与基于云的解决方案相比，为处理敏感或机密信息提供了更安全的选项。

总而言之，使用 `pip` 在本地安装 `Jupyter Notebook` 提供了无与伦比的灵活性、离线可访问性和增强的数据安全性。对于希望完全控制开发环境、需要在不依赖互联网连接的情况下工作或优先考虑数据隐私的用户来说，这是一个绝佳选择。本地设置使您能够根据需要定制 `Jupyter Notebook` ，同时确保项目安全且易于访问。

## 访问 GPU 和 TPU 的重要性

访问 GPU 和 TPU 至关重要，原因有以下三点。

- **数据处理效率：** 在数据科学和机器学习中，您经常需要处理需要大量计算能力的海量数据集或复杂算法。GPU 可以显著减少处理这些数据或训练模型所需的时间，使您的项目更快完成，并更易于迭代和改进。

### 综合理解for循环

在*图3.6*中，当你在第4行使用 **for i in range(5)** 时， **for** 循环被设置为运行五次。在每次迭代中，变量 **i** 获取由 **range(5)** 生成的序列中的下一个值。这个序列从0开始，每次递增1，直到达到4。因此，在第一次迭代中， **i** 是0。在第二次迭代中，它变为1，第三次为2，第四次为3，最后在第五次迭代中为4。
