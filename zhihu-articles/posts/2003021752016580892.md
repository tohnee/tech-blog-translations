## 🗺️ 从命令行到 Server Ready：完整地图

在深入细节之前，我们先建立一个”地图”，了解整个旅程的大致轮廓。

### 第一站：命令行参数解析

```python
# 代码位置：python/sglang/launch_server.py

def main():
    # 解析命令行参数
    server_args = ServerArgs.from_cli_args()

    # server_args 包含了启动服务所需的所有配置
    # - model_path: "Qwen/Qwen2.5-7B"
    # - port: 30000
    # - tp_size: 1 (tensor parallelism，后续文章会讲)
    # - load_format: "auto" (自动检测 safetensors/pytorch)
    # - 更多配置...
```

**设计思考**：为什么需要 ServerArgs？

因为配置项太多了！从模型路径、端口号到各种优化开关（量化、编译、调度策略等），统一管理这些配置能让代码更清晰。

### 第二站：创建推理引擎

```python
# 代码位置：python/sglang/srt/engine.py

class Engine:
    def __init__(self, model_path, ...):
        # 1. 创建模型配置
        self.model_config = ModelConfig(
            model_path=model_path,
            trust_remote_code=True,
            dtype=torch.bfloat16,
            ...
        )

        # 2. 创建加载配置
        self.load_config = LoadConfig(
            load_format=LoadFormat.AUTO,  # 自动选择 safetensors/pt
            download_dir=None,            # 使用默认缓存目录
        )

        # 3. 创建模型运行器（真正加载模型的地方）
        self.model_runner = ModelRunner(
            model_config=self.model_config,
            load_config=self.load_config,
            ...
        )
```

**设计思考**：为什么要分 ModelConfig 和 LoadConfig？

- **ModelConfig**：描述模型本身的特性（架构、参数量、数据类型）
- **LoadConfig**：描述如何加载模型（文件格式、缓存策略、多线程）

职责分离，便于测试和扩展。

### 第三站：选择合适的 Loader

```python
# 代码位置：python/sglang/srt/model_loader/loader.py

def get_model_loader(load_config: LoadConfig) -> BaseModelLoader:
    """根据 load_format 选择合适的 Loader"""

    if load_config.load_format == LoadFormat.AUTO:
        # 自动检测：优先使用 safetensors
        return DefaultModelLoader(load_config)

    elif load_config.load_format == LoadFormat.DUMMY:
        # 用于测试：创建随机权重
        return DummyModelLoader(load_config)

    elif load_config.load_format == LoadFormat.SHARDED_STATE:
        # 预分片的 checkpoint
        return ShardedStateLoader(load_config)

    # ... 更多 Loader 类型
```

**SGLang 支持的 Loader 类型**：

| Loader | 用途 | 适用场景 |
| --- | --- | --- |
| DefaultModelLoader | 标准加载器 | HuggingFace 模型 |
| DummyModelLoader | 随机权重 | 测试、性能分析 |
| ShardedStateLoader | 预分片文件 | 分布式训练产出 |
| GGUFModelLoader | GGUF 格式 | llama.cpp 格式 |
| BitsAndBytesModelLoader | 量化加载 | 4-bit/8-bit 量化 |

今天我们重点关注 `DefaultModelLoader`，这是最常用的加载器。

### 三个核心步骤

加载模型的三个核心步骤，对应三个关键函数：

```python
class DefaultModelLoader:
    def load_model(self, model_config, device_config):
        # === 步骤 1: 定位权重文件 ===
        hf_weights_files = self._prepare_weights(
            model_config.model_path,
            revision=None,
        )
        # 返回: [
        #     "/path/to/model-00001-of-00004.safetensors",
        #     "/path/to/model-00002-of-00004.safetensors",
        #     "/path/to/model-00003-of-00004.safetensors",
        #     "/path/to/model-00004-of-00004.safetensors",
        # ]

        # === 步骤 2: 创建模型结构（参数未填充）===
        with torch.device(device_config.device):
            model = _initialize_model(model_config, self.load_config)
        # model 此时只是空壳，参数都是未初始化的

        # === 步骤 3: 加载权重并填充参数 ===
        weights_iterator = safetensors_weights_iterator(hf_weights_files)
        model.load_weights(weights_iterator)
        # 迭代每个 tensor，填充到对应参数

        return model
```

**为什么要分三步？**

1. **解耦**：文件定位、模型创建、权重加载各自独立
2. **灵活**：可以在中间插入自定义逻辑（如量化、编译）
3. **效率**：惰性加载，不需要一次性读取所有文件

## 🔬 Layer 3: 代码视角 - 深入实现

现在我们进入最核心的部分：逐行分析关键代码。

### 步骤 1: 定位权重文件

**任务**：找到模型的 safetensors 文件

```python
# 代码位置：python/sglang/srt/model_loader/loader.py:362-444

def _prepare_weights(
    self,
    model_name_or_path: str,    # "Qwen/Qwen2.5-7B"
    revision: Optional[str],     # None
    fall_back_to_pt: bool        # True
) -> Tuple[str, List[str], bool]:
    """
    返回：
    - hf_folder: 模型所在目录
    - hf_weights_files: 权重文件列表
    - use_safetensors: 是否使用 safetensors 格式
    """

    # === 1.1 检查是本地路径还是 HuggingFace 模型名 ===
    is_local = os.path.isdir(model_name_or_path)

    if not is_local:
        # === 1.2 从 HuggingFace Hub 下载 ===
        hf_folder = download_weights_from_hf(
            model_name_or_path,
            cache_dir=self.load_config.download_dir,
            allow_patterns=["*.safetensors", "*.bin"],
            revision=revision,
        )
        # 下载到：~/.cache/huggingface/hub/models--Qwen--Qwen2.5-7B/
    else:
        hf_folder = model_name_or_path

    # === 1.3 查找权重文件 ===
    hf_weights_files = []
    for pattern in ["*.safetensors", "*.bin"]:
        hf_weights_files = glob.glob(os.path.join(hf_folder, pattern))
        if hf_weights_files:
            use_safetensors = (pattern == "*.safetensors")
            break

    if not hf_weights_files:
        raise ValueError(f"No weight files found in {hf_folder}")

    # === 1.4 去重和过滤 ===
    hf_weights_files = filter_duplicate_safetensors_files(hf_weights_files)

    return hf_folder, hf_weights_files, use_safetensors
```

**关键点 1：自动下载**

```python
def download_weights_from_hf(
    model_name_or_path: str,
    cache_dir: Optional[str],
    allow_patterns: List[str],
    revision: Optional[str],
) -> str:
    """使用 huggingface_hub 库下载模型"""

    from huggingface_hub import snapshot_download

    # 支持断点续传
    local_path = snapshot_download(
        repo_id=model_name_or_path,
        revision=revision,
        cache_dir=cache_dir,
        allow_patterns=allow_patterns,
        resume_download=True,  # 支持断点续传
        max_workers=4,         # 并行下载
    )

    return local_path
```

**关键点 2：为什么优先选择 safetensors？**

| 特性 | Safetensors | PyTorch .pt/.bin |
| --- | --- | --- |
| 安全性 | ✅ 只包含张量数据 | ❌ 可能包含恶意代码 |
| 加载速度 | ✅ 零拷贝，支持 mmap | ❌ 需要反序列化 |
| 跨平台 | ✅ 二进制兼容 | ❌ Python 版本相关 |

**关键点 3：处理 sharded checkpoints**

对于大模型，权重通常分片存储：

```python
model-00001-of-00004.safetensors  (~5GB)
model-00002-of-00004.safetensors  (~5GB)
model-00003-of-00004.safetensors  (~5GB)
model-00004-of-00004.safetensors  (~2GB)

# 配套的索引文件
model.safetensors.index.json
```

索引文件内容示例：

```python
{
  "metadata": {
    "total_size": 15169208320
  },
  "weight_map": {
    "model.embed_tokens.weight": "model-00001-of-00004.safetensors",
    "model.layers.0.self_attn.q_proj.weight": "model-00001-of-00004.safetensors",
    "model.layers.0.self_attn.k_proj.weight": "model-00001-of-00004.safetensors",
    ...
    "model.layers.27.mlp.down_proj.weight": "model-00004-of-00004.safetensors",
    "lm_head.weight": "model-00004-of-00004.safetensors"
  }
}
```

**SGLang 的处理方式**：直接遍历所有 shard 文件，不依赖索引。

### 步骤 2: 创建模型结构

**任务**：实例化模型，但不填充权重

```python
# 代码位置：python/sglang/srt/model_loader/loader.py:222-268

def _initialize_model(
    model_config: ModelConfig,
    load_config: LoadConfig,
) -> nn.Module:
    """初始化模型结构（权重未填充）"""

    # === 2.1 根据 model_type 选择模型类 ===
    model_class, _ = get_model_architecture(model_config)
    # 对于 Qwen2.5: model_class = Qwen2ForCausalLM

    # === 2.2 获取量化配置（如果有）===
    quant_config = _get_quantization_config(
        model_config,
        load_config,
        packed_modules_mapping={},
    )

    # === 2.3 实例化模型 ===
    model = model_class(
        config=model_config.hf_config,
        quant_config=quant_config,
    )
    # 此时 model 的所有参数都是未初始化的tensor

    return model
```

**关键：模型在哪个设备上创建？**

```python
# 使用 context manager 指定设备
with torch.device(device_config.device):  # "cuda:0"
    model = _initialize_model(model_config, load_config)

# 等价于
model = _initialize_model(model_config, load_config).to("cuda:0")
```

**为什么先创建空模型？**

1. **节省内存**：不需要在 CPU 和 GPU 之间做大量数据传输
2. **并行友好**：多 GPU 场景下，每个 GPU 只创建自己需要的参数
3. **灵活加载**：可以选择性加载某些层（Pipeline Parallelism）

**Qwen2ForCausalLM 的结构**：

```python
# 代码位置：python/sglang/srt/models/qwen2.py

class Qwen2ForCausalLM(nn.Module):
    def __init__(self, config, quant_config=None):
        super().__init__()
        self.config = config

        # Embedding 层
        self.model = Qwen2Model(config, quant_config)

        # LM Head (词表投影)
        self.lm_head = ParallelLMHead(
            vocab_size=config.vocab_size,  # 151936
            hidden_size=config.hidden_size,  # 3584
        )

class Qwen2Model(nn.Module):
    def __init__(self, config, quant_config=None):
        super().__init__()

        # Token Embedding
        self.embed_tokens = VocabParallelEmbedding(
            vocab_size=config.vocab_size,
            hidden_size=config.hidden_size,
        )

        # Transformer 层
        self.layers = nn.ModuleList([
            Qwen2DecoderLayer(config, quant_config)
            for _ in range(config.num_hidden_layers)  # 28 layers
        ])

        # Final LayerNorm
        self.norm = RMSNorm(config.hidden_size)

class Qwen2DecoderLayer(nn.Module):
    def __init__(self, config, quant_config=None):
        super().__init__()

        # Self-Attention
        self.self_attn = Qwen2Attention(config, quant_config)

        # MLP
        self.mlp = Qwen2MLP(config, quant_config)

        # LayerNorms
        self.input_layernorm = RMSNorm(config.hidden_size)
        self.post_attention_layernorm = RMSNorm(config.hidden_size)
```

### 步骤 3: 加载权重 - 最核心的部分

这是整个流程中最复杂、最关键的部分。

### 3.1 创建权重迭代器

```python
# 代码位置：python/sglang/srt/model_loader/weight_utils.py:792-827

def safetensors_weights_iterator(
    hf_weights_files: List[str],
    disable_mmap: bool = False,
) -> Generator[Tuple[str, torch.Tensor], None, None]:
    """
    迭代 safetensors 文件中的所有 tensor

    返回: Generator yielding (name, tensor) pairs
    """

    for st_file in tqdm(hf_weights_files, desc="Loading checkpoint shards"):
        if disable_mmap:
            # 方式 1：一次性加载整个文件到内存
            with open(st_file, "rb") as f:
                result = safetensors.torch.load(f.read())
                for name, param in result.items():
                    yield name, param
        else:
            # 方式 2：使用 memory-mapped I/O（推荐）
            with safetensors.safe_open(st_file, framework="pt", device="cpu") as f:
                # safe_open 返回一个 file handle
                # 不会立即加载所有数据

                for name in f.keys():
                    # 只有在调用 get_tensor 时才真正读取
                    tensor = f.get_tensor(name)
                    yield name, tensor
```

**Memory-mapped I/O 详解**：

```python
# 传统方式
with open("model.safetensors", "rb") as f:
    data = f.read()  # 读取整个文件 (15GB) 到内存
    # 峰值内存: 15GB (文件) + 15GB (解析后的tensors) = 30GB

# Memory-mapped 方式

    # 只读取 header，建立 name -> offset 的映射
    # 内存占用: ~几MB

    tensor = f.get_tensor("model.layers.0.self_attn.q_proj.weight")
    # 此时才读取这个 tensor 的数据
    # 通过 mmap，操作系统按需加载页面
```

**mmap 的优势**：

1. **节省内存**：不需要一次性加载整个文件
2. **加载快速**：利用操作系统的页缓存
3. **支持并发**：多个进程可以共享同一个映射

### 3.2 模型的 load_weights 方法

```python
# 代码位置：python/sglang/srt/models/qwen2.py:569-637

class Qwen2ForCausalLM(nn.Module):
    def load_weights(self, weights: Iterable[Tuple[str, torch.Tensor]]):
        """
        从迭代器加载权重

        Args:
            weights: Iterator yielding (name, tensor) pairs
        """

        # === 3.2.1 定义参数融合映射 ===
        stacked_params_mapping = [
            # (融合后的名字, 原始名字, shard_id)
            ("qkv_proj", "q_proj", "q"),
            ("qkv_proj", "k_proj", "k"),
            ("qkv_proj", "v_proj", "v"),
            ("gate_up_proj", "gate_proj", 0),
            ("gate_up_proj", "up_proj", 1),
        ]

        # === 3.2.2 获取所有参数 ===
        params_dict = dict(self.named_parameters())
        # {
        #     "model.layers.0.self_attn.qkv_proj.weight": Parameter([4608, 3584]),
        #     ...
        # }

        # === 3.2.3 遍历所有权重 ===
        for name, loaded_weight in weights:
            # name: "model.layers.0.self_attn.q_proj.weight"
            # loaded_weight: Tensor([3584, 3584])

            # 跳过不需要的权重
            if "rotary_emb.inv_freq" in name:
                continue

            # === 3.2.4 处理融合参数 ===
            for param_name, weight_name, shard_id in stacked_params_mapping:
                if weight_name not in name:
                    continue

                # 匹配到 q_proj，替换为 qkv_proj
                name = name.replace(weight_name, param_name)
                # "model.layers.0.self_attn.qkv_proj.weight"

                if name not in params_dict:
                    continue

                param = params_dict[name]
                weight_loader = param.weight_loader

                # === 核心：调用参数的 weight_loader ===
                weight_loader(param, loaded_weight, shard_id)
                break
            else:
                # 处理非融合参数
                if name in params_dict:
                    param = params_dict[name]
                    weight_loader = getattr(param, "weight_loader", default_weight_loader)
                    weight_loader(param, loaded_weight)
```

**关键问题：param.weight_loader 是什么？**

这是 SGLang 的一个精巧设计：**每个参数都知道自己该怎么被加载**。

### 3.3 weight_loader：智能参数系统

**设计思路**：

不同类型的层，加载权重的方式不同：

- **QKV 融合层**：需要根据 shard_id 确定放在哪个位置
- **Gate-Up 融合层**：需要拼接两个权重
- **普通线性层**：直接复制

传统做法需要大量 `if-else`：

```python
# 不好的设计
for name, weight in weights:
    if "qkv_proj" in name:
        load_qkv_weight(param, weight, shard_id)
    elif "gate_up_proj" in name:
        load_gate_up_weight(param, weight, shard_id)
    elif "o_proj" in name:
        load_linear_weight(param, weight)
    # ... 更多类型
```

**SGLang 的解决方案**：在创建参数时，就绑定其加载函数。

```python
# 代码位置：python/sglang/srt/layers/linear.py:896-970

class QKVParallelLinear(nn.Module):
    def __init__(self, hidden_size, head_size, total_num_heads, ...):
        super().__init__()

        # 创建参数
        self.weight = Parameter(torch.empty(
            (total_num_heads + 2 * total_num_kv_heads) * head_size,
            hidden_size,
        ))

        # *** 绑定 weight_loader 到参数 ***
        set_weight_attrs(
            self.weight,
            {
                "weight_loader": self.weight_loader,  # 绑定方法
                "output_dim": 0,
                "input_dim": 1,
            },
        )

    def weight_loader(
        self,
        param: Parameter,
        loaded_weight: torch.Tensor,
        loaded_shard_id: str = "q",
    ):
        """
        加载 Q/K/V 权重到融合参数

        融合参数布局:
        [0:3584]      -> Q (28 heads * 128)
        [3584:3584+512]  -> K (4 heads * 128)
        [3584+512:3584+512+512] -> V (4 heads * 128)
        """

        if loaded_shard_id == "q":
            # Q 权重放在最前面
            offset = 0
            output_dim = self.num_heads * self.head_size  # 3584

        elif loaded_shard_id == "k":
            # K 权重放在 Q 之后
            offset = self.num_heads * self.head_size  # 3584
            output_dim = self.num_kv_heads * self.head_size  # 512

        elif loaded_shard_id == "v":
            # V 权重放在 K 之后
            offset = (self.num_heads + self.num_kv_heads) * self.head_size
            output_dim = self.num_kv_heads * self.head_size  # 512

        # 复制到参数的对应位置
        param.data[offset : offset + output_dim].copy_(loaded_weight)
```

**set_weight_attrs 函数**：

```python
# 代码位置：python/sglang/srt/utils.py

def set_weight_attrs(
    param: torch.nn.Parameter,
    attrs: Dict[str, Any],
) -> None:
    """在参数上动态添加属性"""
    for key, value in attrs.items():
        setattr(param, key, value)

# 使用后：
# param.weight_loader  -> 可以直接调用
# param.output_dim     -> 0
# param.input_dim      -> 1
```

**为什么这个设计优雅？**

1. **统一接口**：所有参数都通过 `param.weight_loader()` 加载
2. **类型安全**：每个层定义自己的加载逻辑
3. **易扩展**：新增层类型只需实现 `weight_loader` 方法
4. **无需类型判断**：`load_weights` 函数不需要知道具体的层类型

### 洞察 2：融合是性能的关键

**未融合的计算**：

```python
# Forward pass (未融合)
q = self.q_proj(hidden_states)  # Kernel Launch 1
k = self.k_proj(hidden_states)  # Kernel Launch 2
v = self.v_proj(hidden_states)  # Kernel Launch 3

# 3 次独立的 GEMM 操作
# 3 次 Kernel Launch 开销
# 3 次内存访问 hidden_states
```

**融合后的计算**：

```python
# Forward pass (融合)
qkv = self.qkv_proj(hidden_states)  # Kernel Launch 1
q, k, v = qkv.split([q_size, k_size, v_size], dim=-1)

# 1 次大的 GEMM 操作
# 1 次 Kernel Launch 开销
# 1 次内存访问 hidden_states
```

### 洞察 3：Memory-mapped I/O 是大模型加载的基石

**传统文件读取**：

**Memory-mapped 读取**：

### 洞察 4：参数系统的”自描述”设计

**传统面向对象设计**：

```python
class WeightLoader:
    def load(self, layer, weight):
        if isinstance(layer, QKVLayer):
            self.load_qkv(layer, weight)
        elif isinstance(layer, MLPLayer):
            self.load_mlp(layer, weight)
        # ... 20+ elif

# 缺点：
# - 中心化的逻辑，难以扩展
# - 需要导入所有层类型
# - 容易遗漏新增的层
```

**SGLang 的”自描述”设计**：

```python
class QKVLayer:
    def __init__(self):
        self.weight = Parameter(...)
        # 参数"知道"自己该怎么加载
        self.weight.weight_loader = self.weight_loader

    def weight_loader(self, param, loaded_weight, shard_id):
        # 层自己定义加载逻辑
        ...

# 统一的加载器
def load_all_weights(model, weights):
    for name, weight in weights:
        param = model.get_parameter(name)
        param.weight_loader(param, weight)  # 多态

# 优点：
# - 去中心化，易扩展
# - 类型安全，编译时检查
# - 新增层只需实现自己的 weight_loader
```

这是**开放-封闭原则**的完美实践：对扩展开放，对修改封闭。

## 🎓 总结

### 关键步骤

```python
1. 命令行参数 → ServerArgs
2. 定位模型文件 → List[safetensors_files]
3. 创建模型结构 → Empty nn.Module
```

- ✅ mmap 避免大文件一次性读取
