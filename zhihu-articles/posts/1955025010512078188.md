### 1.简介

用 TensorRT 部署模型时，除了预处理和后处理，还需要写引擎加载、显存分配、数据拷贝和资源释放等代码。这部分流程在不同模型之间有不少相同之处，每次重新写比较麻烦。

我把这些公共部分封装成了一个轻量的推理模板库，对外主要提供 `TRTInfer` 类。使用时，加载模型的 engine 文件，再根据模型编写预处理和后处理即可。

下面介绍一下它的基本用法，以及如何编译、运行仓库中的示例。

### <br><br>2.先看核心：简化到极致的使用流程

先看一个使用示例。预处理函数将输入数据整理成模型需要的格式，推理接口返回输出数据，再交给后处理函数解析。这个示例用 `cv::Mat` 存放输入输出，并通过模型的节点名区分不同数据。

```cpp
#include "TRTinfer.h" // TensorRT 推理接口
#include <opencv2/opencv.hpp>
#include <unordered_map>

// 1. 预处理、加载模型并执行推理
namespace model {
std::unordered_map<std::string, cv::Mat> preprocess(cv::Mat &tensor1, cv::Mat &tensor2, ...) {
    std::unordered_map<std::string, cv::Mat> input_blob;
    // 示例操作：比如Resize、归一化、通道转换（根据你的模型需求写）
    // 存入输入Blob（key对应模型输入节点名，比如"input1"）
    input_blob["input1"] = cv::dnn::blobFromImage(tensor1, 1 / 255.f, cv::Size(), cv::Scalar(), true, false);
    input_blob["input2"] = cv::dnn::blobFromImage(tensor2, 1 / 255.f, cv::Size(), cv::Scalar(), true, false);
    return input_blob;
}

// 2. 只需要写：后处理（模型输出Blob → 最终结果）
void postprocess(std::unordered_map<std::string, cv::Mat> output_blob, cv::Mat &dst) {
    // 示例操作：比如解析分类结果、目标检测框回归（根据模型需求写）
    cv::Mat output = output_blob["output1"];  // key对应模型输出节点名
    dst = output.clone();  // 这里替换成你的后处理逻辑（如阈值筛选、画框等）
}
}  // namespace model

int main(int argc, char *argv[]) {
    // 3. 加载输入数据（用OpenCV读图，符合多数开发者习惯）
    cv::Mat tensor1 = cv::imread("input1.jpg");
    cv::Mat tensor2 = cv::imread("input2.jpg");
    if (tensor1.empty() || tensor2.empty()) {
        printf("请检查输入图片路径！\n");
        return -1;
    }

    // 4. 预处理、加载模型并执行推理
    auto input_blob = model::preprocess(tensor1, tensor2);  // 预处理
    auto model = TRTInfer::create("your_model.engine");     // 加载模型（只传engine路径）
    auto output_blob = (*model)(input_blob);                // 执行推理（像调用函数一样简单）
    
    // 5. 处理结果
    cv::Mat dst;
    model::postprocess(output_blob, dst);
    cv::imwrite("result.jpg", dst);  // 保存结果

    return 0;
}

```

更换模型时，主要需要调整模型路径、输入输出节点名，以及预处理和后处理。如果新模型的输入输出能沿用这里的接口，加载和调用推理的流程就可以继续复用。

### 3.为什么这么做

封装主要是为了复用不同模型之间相同的推理流程。下面列出加载 engine、创建执行上下文、分配内存、执行推理和释放资源的基本步骤，方便和前面的接口对照。示例省略了错误检查等细节。

```cpp
// 1. 加载引擎文件（要处理文件流、反序列化）
std::ifstream engineFile("model.engine", std::ios::binary);
engineFile.seekg(0, std::ios::end);
size_t size = engineFile.tellg();
engineFile.seekg(0, std::ios::beg);
char *buf = new char[size];
engineFile.read(buf, size);
nvinfer1::IRuntime *runtime = nvinfer1::createInferRuntime(gLogger);
nvinfer1::ICudaEngine *engine = runtime->deserializeCudaEngine(buf, size);
delete[] buf;

// 2. 创建执行上下文（还要检查输入输出维度）
nvinfer1::IExecutionContext *context = engine->createExecutionContext();
int inputIdx1 = engine->getBindingIndex("input1");
int inputIdx2 = engine->getBindingIndex("input2");
int outputIdx1 = engine->getBindingIndex("output1");

// 3. 管理内存（主机→设备、设备→主机的数据拷贝，还要处理维度匹配）
void *buffers[3];
cudaMalloc(&buffers[inputIdx1], 224*224*3*sizeof(float));
cudaMalloc(&buffers[inputIdx2], 224*224*3*sizeof(float));
cudaMalloc(&buffers[outputIdx1], 1000*sizeof(float));  // 假设输出1000类

// 4. 预处理后的数据拷贝到设备
float *hostInput1 = new float[224*224*3];
// ...（预处理逻辑）...
cudaMemcpy(buffers[inputIdx1], hostInput1, 224*224*3*sizeof(float), cudaMemcpyHostToDevice);

// 5. 执行推理
context->executeV2(buffers);

// 6. 结果从设备拷贝回主机
float *hostOutput = new float[1000];
cudaMemcpy(hostOutput, buffers[outputIdx1], 1000*sizeof(float), cudaMemcpyDeviceToHost);

// 7. 释放资源（漏一个就内存泄漏）
delete[] hostInput1;
delete[] hostOutput;
cudaFree(buffers[inputIdx1]);
cudaFree(buffers[inputIdx2]);
cudaFree(buffers[outputIdx1]);
context->destroy();
engine->destroy();
runtime->destroy();

```

这些步骤封装后，接入其他模型时，就能少写一部分重复代码。

- 引擎加载、内存管理和资源释放由库内部处理；
- 模型相关的预处理和后处理仍然需要自己编写。
- 输入输出使用 `cv::Mat`，如果原来的项目已经在用 OpenCV，接起来会方便一些。

对于需要自行调整 TensorRT 执行流程的场景，也可以在这个模板的基础上继续修改。

更新，添加了多线程并发支持。详情代码见分支 main_multistream

系统采用**生产者-消费者模型**构建异步推理框架。核心引入 **Stream 资源池**，实现对 `cudaStream_t`、`IExecutionContext` 及相关 I/O 缓冲区的统一池化管理。

任务端将输入数据与推理逻辑封装为独立 **Task** 挂载至任务队列；后端工作线程通过竞争机制获取任务，并从资源池中动态检出（Acquire）空闲实例。利用 **CUDA 多流并发**技术，系统在不同硬件流上实现内存拷贝与核函数执行的重叠（Overlap），最大化 GPU 利用率并提升系统吞吐量。代码使用如下，以IGEV立体匹配模型为例

```cpp
// .. 预处理
// 创建模型
auto model =  TRT::TRTInfer::create(engine_path, 4);
// 将数据送入任务队列
std::future<datatype> results;
// 异步执行
for(auto& data : datas)
    results.emplace_back(model->PostQueue(data));
// ...
// 要用到的时候在取
datatype result = results[num].get();

// .. 后处理

```
