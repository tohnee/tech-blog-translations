## 0、整体介绍

Megatron是一个通用的NLP大模型训练框架，支持多种并行策略，Mindspeed-LLM通过在Megatron打补丁的方式，使其能够在昇腾卡上运行，支持大部分的开源模型。mindspeed-llm目录下有一个megatron_adaptor.py文件，对megatron部分原生代码打了patch。所以在昇腾卡上执行时，部分函数实际执行的是megatron_adaptor.py文件中的内容。

以下内容主要分析megatron原生代码。

## 1、代码结构

主入口脚本为**pretrain_gpt.py**，顺序调用**pretrain_gpt.py->training.py**中的**pretrain**函数

pretrain函数中，有以下几个函数比较重要

0）、initialize_megatron：全局通信域初始化

1）、setup_model_and_optimizer：设置模型和优化器

2）、build_train_vaild_test_datasets：构造数据集

3）、train：启动训练

4）、save_checkpoint：保存模型

## 4、build_train_valid_test_data_iterators

1）、train_valid_test_datasets_provider对原始数据集进行处理，主要包括一些混合和分割

2）、**MegatronPretrainingSampler**和**MegatronPretrainingRandomSampler**提供数据集的实际迭代能力

```text
# 指明了dp-group中每个rank需要取的数据范围
    def get_start_end_idx(self):
        start_idx = self.data_parallel_rank * self.micro_batch_size
        end_idx = start_idx + self.micro_batch_size
        return start_idx, end_idx
	# 通过consumed_samples控制已经训练的数据，micro_batch_times_data_parallel_size=self.micro_batch_size * data_parallel_size
    def __iter__(self):
        batch = []
        # Last batch will be dropped if drop_last is not set False
        for idx in range(self.consumed_samples, self.total_samples):
            batch.append(idx)
            if len(batch) == self.micro_batch_times_data_parallel_size:
                start_idx, end_idx = self.get_start_end_idx()
                yield batch[start_idx:end_idx]
                batch = []
```

## 6、save_checkpoint

调用模型保存接口的地方主要有两个，一个是断点续训指定的步数，一个是训练完的保存

```text
# 中间步数保存ckpt
if args.save and args.save_interval and \
        iteration % args.save_interval == 0:
    timers('interval-time').stop()
    save_checkpoint_and_time(iteration, model, optimizer,
                                opt_param_scheduler)
    saved_checkpoint = True
    
# 训练完保存模型
if args.save and iteration != 0:
    save_checkpoint(iteration, model, optimizer, opt_param_scheduler)
```

1）、多DP的时候，只有第一个DP会对模型进行保存

```text
# Only rank zero of the data parallel writes to the disk.
model = unwrap_model(model)
```

2）保存之前会根据–save参数，该参数通常设置成保存的路径，结合最终训练完成的iteration来生成具体的保存文件，模型的命名保持model_optim_rng.pt

```text
checkpoint_name = get_checkpoint_name(args.save, iteration)
```

3）保存优化器

该处需要在训练时使用分布式优化器的参数–use_distributed_optimizer，及不设置no_save_optim，保存优化器的时候，会多生成一个distrib_optim.pt文件

```text
# Save distributed optimizer's custom parameter state.
if args.use_distributed_optimizer and not args.no_save_optim and optimizer is not None:
    optim_checkpoint_name = \
        get_distributed_optimizer_checkpoint_name(checkpoint_name)
    optimizer.save_parameter_state(optim_checkpoint_name)
```

4）保存的内容

保存的内容包括：训练的超参(args)、训练的步数(iteration)、优化器(optimizer)、模型参数数据(state_dict)

*注：使用Megatron加载模型的时候，pt中也要包含这些信息，否则无法加载模型*

```text
state_dict = {}
state_dict['args'] = args
state_dict['checkpoint_version'] = 3.0
state_dict['iteration'] = iteration
if len(model) == 1:
    state_dict['model'] = model[0].state_dict_for_save_checkpoint()

# 设置了保存优化器这里才会保存
if not args.no_save_optim:
    if optimizer is not None:
        state_dict['optimizer'] = optimizer.state_dict()
    if opt_param_scheduler is not None:
        state_dict['opt_param_scheduler'] = \
            opt_param_scheduler.state_dict()
```

5）保存，调用torch.save进行保存，保存时会进行一次同步，确保所有的pt都已经保存完成

```text
torch.save(state_dict, checkpoint_name)

# Wait so everyone is done (necessary)
if torch.distributed.is_initialized():
    torch.distributed.barrier()
```

6）生成latest_checkpointed_iteration.txt文件，这个文件中记录了，保存ckpt时，是第多少个iteration，读取时也要有。

代码逻辑中，限制了这个文件只会在第0个节点保存

```text
# And update the latest iteration
if not torch.distributed.is_initialized() \
        or torch.distributed.get_rank() == 0:
    tracker_filename = get_checkpoint_tracker_filename(args.save)
    with open(tracker_filename, 'w') as f:
        f.write(str(iteration))
```
