前段时间，Claude 杀红眼了封了一大批号，很多大 V、大号主都在公共平台发社媒声讨 Claude 的做法，因此还引发了一场后续闭源模型和开源模型的激烈争论。

然而没过多久，Claude 就被爆出来有后门，可以通过油猴脚本的方式绕过传统的支付方式，用 `SEPA Debit` 的方式可以直接白嫖 Claude Max 20x，一时间网友直接炸锅了。

这件事情打了个信息差，我怀疑因为周末 Claude 不上班，所以很多人白嫖了一下午甚至一天时间，爽麻了也是。

不过爽完了，后果得自己担着了， **Claude 为了封杀用户，直接无差别开大** ，采用了 IP 标记和指纹等连坐的方式，只要你在这个 IP 机器上白嫖过漏洞的话，不管你新的邮箱登没登过，一律封杀。我有大概 6 个邮箱都直接连坐了。

所以后续我一直对 Claude 嗤之以鼻，导致我有差不多一个多月没用过 Claude 了。

先给大家总结一下这方法就是： **注销注册 Claude 账户，用注销邮箱重新注册 Claude 账户，亲测好用。**

不过 AI 用久了你就会发现，C 端用户没有模型忠诚度，哪个模型好用用哪个，如果 Claude 不好用，我相信也不会有这么多人用，也不会有这么多人被封也要用。

如果你能接受抱着只对自己有用的这个逻辑来说，你可以往下看；如果你接受不了，请罢。

所以如果你的 Claude 被封了，你还是想用怎么办？如果你的 ip 没有被标记，大可重新注册几个邮箱来用，如果像我一样被标记的话，你可以按照我的方式来搞一下。

我在 6 月 28 日收到的账户被封禁的消息，我在 8 月注销了一下，现在已经可以重新使用了。

![](https://pic3.zhimg.com/v2-eef7fc578a85e99743824283181f4a6c_r.jpg)

*6 月 28 日收到账户封禁*

![](https://pica.zhimg.com/v2-4d4df116400ab8d3f9c830489590e2c6_r.jpg)

*注销再重新注册，账户可用了*

---

跟大家说一下是怎么做的。

你可以打开一个任意的 claude 网站，不过最好去 support.claude ，右下角有个帮助支持。

![](https://picx.zhimg.com/v2-d77af14a45d4150923cadaff6048a55d_r.jpg)

点开之后会记录你的会话 id ，然后根据提示选择 **Delete your account** 。

然后根据提示是删除 Claude 账户还是删除 API，我选择的是删除 Claude 账户。

![](https://pic2.zhimg.com/v2-2b4d09b52d30d0a7d1a0335f5bf93a15_r.jpg)

输入删除原因和组织 ID，组织 ID 可以根据 Agent 给你的 url 去反查。

![](https://pic2.zhimg.com/v2-14819a80a34732fca8fd286c2c828e0d_r.jpg)

输入删除组织的原因之后，就可以把窗口关了等着回复就行了。我是 8 月 11 号申请的，隔天收到的回复，不过这个回复还是要你等着回复。

![](https://pic4.zhimg.com/v2-cbf26a8c03b38c218c2de9202840b2f5_r.jpg)

又等了大概一周左右，Claude 处理完了，我的账户已经完全删除了。

![](https://pic2.zhimg.com/v2-b528830297d5868c4940311dfc802fb9_r.jpg)

不是我看完这份回复，我怎么感觉这个哥们，还有点高兴的样子？？？这对吗？？

这样子基本上 Claude 账户已经处理完毕了。

对了，如果大家 **没有导出数据的话** ，可以先 **导出数据** 。

如果数据导出了，账户也删除了，等着重新注册一下就行。

---

估计有小伙伴疑惑，为什么这个方法可行？

很多小伙伴以为被封后邮箱就被永久锁死了。但实际上，A 社受到严格的数据隐私合规（GDPR）约束，只要你走官方 Support 流程申请 **Delete Account** ，客服彻底清理掉你的账户数据后， **这个邮箱在系统里就变回了全新状态** 。

但是需要注意的是，注销只能帮你赎回邮箱，不能洗白脏 IP ！重新注册时，请及时换一个干净的 proxy 环境和浏览器指纹，避免刚注册又被连坐。

我现在还没有换干净的 proxy 环境，我打算尝试开 Pro 用一下，看看是否会被封禁。
