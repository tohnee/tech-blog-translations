## ModelContextProtocol 层详解

面向”改 MCP 本身”：服务器架构、公开 API、协议实现、线程与生命周期模型、配置面、扩展点。

基于该插件全部非测试源码（约 6600 行）+ 关键测试的静态阅读。

路径基准：插件根 `Engine/Plugins/Experimental/ModelContextProtocol`（下文简称 `MCP/`）。

---

### 0. 定位

一个**嵌在 UE 进程内的 MCP 服务器**，只做三件事：暴露工具、暴露资源、把外部 JSON-RPC 请求安全地搬到游戏线程上执行。

**它自己不实现任何业务工具** —— 所有引擎能力由 ToolsetRegistry 提供，它通过适配器消费。

ModelContextProtocol.uplugin 的关键事实：

```json
"FriendlyName": "Unreal MCP"
"Description": "Anthropic MCP (Model Context Protocol) server implementation for Unreal Engine."
"IsExperimentalVersion": true
"EnabledByDefault": true
"NoRedist": true
"CanContainContent": false
"Plugins": [ {"Name":"EngineAssetDefinitions"}, {"Name":"ToolsetRegistry"} ]
```

`NoRedist: true` 意味着**不能把这个插件随自己的产品再分发** —— 这也是 `Extras/Proxy` 只剩 `.tps` 许可证文件的原因。

---

### 1. 模块划分（6 个）

| 模块 | Type | 职责 |
| --- | --- | --- |
| ModelContextProtocol | Runtime | 服务器、协议、会话、设置、工具/资源注册表、适配器、Tool Search |
| ModelContextProtocolEngine | Runtime | 客户端配置生成、GenerateClientConfig 命令、旧版 ToolLibrary/AsyncAction、媒体结果编码 |
| ModelContextProtocolEditor | Editor | 设置面板定制、模态泵、ToolHashMapping commandlet、资产定义 |
| ModelContextProtocolTests | UncookedOnly | 协议/服务器/会话/适配器测试（~14000 行） |
| ModelContextProtocolEngineTests | UncookedOnly | 客户端配置、异步取消测试 |
| ModelContextProtocolEditorTests | Editor | 模态泵、commandlet、注册表集成测试 |

核心模块依赖极薄（ModelContextProtocol.Build.cs）：

```text
Public:  Core, CoreUObject, Analytics, AnalyticsET, DeveloperSettings,
         HTTPServer, JsonUtilities, Json
Private: ImageWrapper, ToolsetRegistry
bAllowUETypesInNamespaces = true
```

**没有 Editor 依赖，也没有平台白名单** —— 这是打包版能托管服务器的根本原因。
