随着大语言模型和 AI Agent（智能体）的爆发式增长，如何让 AI 安全、深度地理解并操作我们的网站，成为了技术圈最关注的话题。就在近期，WordPress 官方正式发布了一款具有里程碑意义的官方标准插件 **MCP Adapter** 。

[https://wordpress.org/plugins/mcp-adapter/](https://wordpress.org/plugins/mcp-adapter/)

这款插件的出现，意味着 **WordPress 正式向全球的 AI 生态全面敞开大门** ，通过将 WordPress 底层的 Abilities API 与全新的模型上下文协议标准打通，未来 AI 帮我们写文章、改排版、查销量甚至管理服务器，都将变得像和朋友聊天一样简单。

![](https://picx.zhimg.com/v2-1dd9bdc6fb44e315cd1fe990ca12b57d_r.jpg)

## 什么是 MCP？为什么它如此重要？

要理解这个插件，首先得知道什么是 **MCP（Model Context Protocol，模型上下文协议）** 。

MCP 是由 AI 公司 Anthropic（知名大模型 Claude 的开发方）推出的一项 **开源标准协议** 。在过去，如果想让 AI 连接到你的 WordPress 网站，开发者必须为每个 AI 工具单独编写一套复杂的 API 对接代码。这就像不同国家的人说话，需要为每个人配一个专属翻译。

而 **MCP 就像是 AI 世界的“通用语言”** ，只要你的网站支持 MCP 协议，无论是 Claude 桌面端、Cursor、VS Code 还是其他任何主流 AI 智能体，都能瞬间听懂你网站的语言，直接对网站进行读取和操作。

## MCP Adapter 的六大硬核特性

**MCP Adapter 插件本身并不具备 AI 聊天功能，它扮演的是一个安全、高性能的“AI 连接网关”的角色。** 根据官方最新发布的规范，它具备以下六大核心技术特性：

- **能力无缝转换（Ability-to-MCP）** ： 
 能自动把网站、主题及第三方插件的功能（Abilities API），翻译成 AI 能读懂的 **工具（Tools）** 、 **资源（Resources）** 和 **提示词（Prompts）** 。
- **多服务器管理（Multi-Server）** ： 
 支持在同一个 WordPress 网站内创建和管理 **多个独立的 MCP 服务器** ，并为它们配置不同的运行规则，完美适配复杂业务。
- **可扩展传输层（Extensible Transport）** ： 
 除了内置的 **HTTP** （远程云端）和 **STDIO** （本地命令行）传输协议外，还支持开发者自定义专属的传输协议。
- **精细化权限控制（Permission Control）** ： 
 提供 **颗粒度极细的权限检查** ，所有暴露给 AI 的功能默认关闭，必须经过严格的安全验证，确保网站数据万无一失。
- **灵活的错误处理（Flexible Error Handling）** ： 
 兼容 WordPress 默认错误日志，同时支持为特定的 MCP 服务器配置专门的错误捕获与处理机制，保证系统稳定性。
- **零开销可观测性（Observability）** ： 
 内置高性能指标追踪系统，在 **不消耗网站额外性能（Zero-overhead）** 的前提下，让管理员清晰掌握 AI 的调用轨迹与频率。

## 官方公告里的 3 个关键技术细节

这次发布，官方的公告（ [https://make.wordpress.org/ai/2026/10/07/the-mcp-adapter-plugin-is-now-available-on-wordpress-org/](https://make.wordpress.org/ai/2026/10/07/the-mcp-adapter-plugin-is-now-available-on-wordpress-org/) ）还包含了3 个关键技术细节：

1. 为什么不直接内置到 WordPress 核心代码中？

官方在公告中给出了非常诚恳的解释： **因为 AI 领域的 MCP 协议目前进化太快了！** 比如就在不到三个月前，MCP 协议刚经历了一次重大突破性修改。 WordPress 核心版本（Core）影响着全球数亿网站，极其注重“向后兼容”和长期稳定，更新节奏较慢。 采取 **独立 Canonical 插件** 的形式，既能保证代码安全不冲突，又能让团队 **紧跟 AI 生态的步伐快速迭代** 。

2. 开箱即用：内置默认服务器与 3 个基础元工具

插件内置了一个默认的 MCP 服务器（端点为 /wp-json/mcp/mcp-adapter-default-server），并直接包含了 **3 个最基础的元工具（Fundamental Tools）** 。外部 AI（如 Claude）接入网站时，就是通过这 3 个基础工具，去自动“侦察”和调用网站上所有公开的业务能力，开发者无需从零开始造轮子。

3. 首发 0.7.0 版本率先适配“无状态规范”

在最新的 0.7.0 版本中，插件已经原生支持了 **Anthropic 最新的无状态（Stateless）MCP 规范** 。 它引入了 McpInputRequired 语法，当 AI 在执行建站任务发现信息不足时，它不会直接报错，而是会 **主动、智能地向你“索要”缺失的参数输入** ，交互极其丝滑。

## 谁现在需要安装它？

目前阶段， **普通站长不需要盲目安装** 。因为 MCP Adapter 属于纯底层的技术基础设施，它 **没有面向普通用户的可视化操作界面（UI）** 。如果你只是想要一个在后台帮写作文的 AI 助手，它无法开箱即用。

**但如果你是以下人群，建议立刻体验：**

- **独立开发者 / 极客** ： 
 正在使用 **Cursor** 、VS Code 或 Claude Code 编写 WordPress 代码、修改主题，它可以让你的 AI 编程助手直接读取网站上下文，写代码更精准。
- **站群管理者** ： 
 需要利用 AI Agent 批量管理、巡检或更新几十个甚至上百个 WordPress 站点。
- **插件/主题开发者** ： 
 提前将自己的产品适配 MCP，让你的插件原生具备“被 AI 调用”的能力，拥抱 AI 生态。

## 总结两句

WordPress 的 MCP Adapter 插件，是传统内容管理系统（CMS）向 AI 时代迈出的坚实一步。它奠定了未来“AI 驱动建站”的底层地基。随着越来越多上层业务插件基于它进行开发，用不了多久，普通站长也能真正享受到“动动嘴，AI 就能帮你管好全站”的科技红利！
