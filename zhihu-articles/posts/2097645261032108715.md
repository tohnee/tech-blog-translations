## 一、一句话结论

**Agent 的落地顺序由"确定性"决定** ：任务结果能否被自动判定对错（编译器、测试、SQL 执行、工单闭环、文档结构）。按这条主线，市场正在分化成三档：

| 档位 | 赛道 | 2026 状态 | 确定性来源 |
| --- | --- | --- | --- |
| 已跑通（基准盘） | Coding Agent | 商业化最成熟，形成双寡头+挑战者 | 单元测试、编译、CI 可自动验证 |
| 今年主战场 | 办公 Agent | C 端+B 端同时扩容，入口之争 | 文档/表格结构可校验、可 diff 回滚 |
| 逐渐清晰（本报告重点） | 浏览器/电脑操作、客服与销售、垂直专业服务、数据分析运营、Agent 基础设施 | 从 POC 转向规模化交付 | 页面状态、工单关闭率、SQL 可执行、合规复核 |
| 尚未清晰 | 通用个人 Agent、端侧/具身 Agent | 融资火热但价值验证存疑 | 无明确验收标准 |

## 二、基准盘：Coding Agent 已经给出"什么叫跑通"的标尺

- 全球 AI 编程工具市场规模：2025 年约 **295.7 亿美元** ，预计 2030 年 **646.8 亿美元** （新浪财经/多家券商口径汇总）；另一口径给"2026 年约 128 亿美元、年增速 70%+"，差异来自是否把 IDE 补全类工具计入。
- **Claude Code** 年化收入 2026 年中已超 **25 亿美元** ，在企业级编码 Agent 市场约占 **54%** 份额。
- **Cursor** 2026 年 2 月 ARR 达 **20 亿美元** ；GitHub Copilot 份额从 **67% 降至 51%** （2026-05 数据）。
- **OpenAI Codex** 周活 2026 年 6 月突破 **500 万** ，5 个月增长数倍。
- 资本层面出现标志性事件：媒体报道 Cursor 被 SpaceX 以 **600 亿美元** 估值收购（该数字仅见于媒体报道，建议以官方口径复核）。

**对后来者的启示** ：Coding 之所以先跑通，不是因为需求最大，而是因为 **验证成本最低** 。凡是能构造出"Coding 级验证闭环"的场景，都会按相同节奏起飞。

## 三、今年的主战场：办公 Agent

### 3.1 市场规模与节奏

- CIDC/36氪研究院：中国企业级 AI Agent 市场 2025 年 **212 亿元** → 2026 年 **449 亿元** → 2029 年 **3320 亿元** ，CAGR **107.6%** 。
- IDC：2025 年中国企业级 AI 智能体约 212 亿元，2026 年 449 亿元（同比约 +112%），2029 年有望破 3320 亿元。
- Gartner： **到 2026 年底 40% 的企业应用将嵌入任务型 AI 智能体** （2025 年这一比例仍很低）；Gartner 2026-09 已把"AI Agents and Assistants"从 AI 软件中单列，该口径 2026 年 292.19 亿美元、2027 年 654.72 亿美元。
- 流量侧真实验证：2026 年 6 月国内 17 款桌面端 AI 办公智能体月总访问量突破 **6000 万次** ，比 2026 年 2 月翻了近一倍。
- 月狐数据：2026 年以来 AI 办公赛道进入爆发期，Agent 推动产品能力跃迁，C 端与 B 端同时扩容。

### 3.2 竞争格局（入口之争）

- 三类玩家：① 办公套件原生（WPS 灵犀、Microsoft Copilot）；② 协同平台原生（飞书 aily、钉钉、企业微信）；③ 大厂通用桌面 Agent（WorkBuddy、千问办公、豆包工作、百度搭子）。
- 通用桌面 Agent 的共同打法是"连接器战略"：同时连飞书/钉钉/企微 + Office/金山文档，用跨应用连接稀释单一平台锁定。
- 商业化真相（第三方估算，需谨慎）：飞书 AI 付费用户约 **255 万** 、ARPU 约 **720 元** ，年化约 **18 亿元** ；钉钉 2 亿月活但 AI 渗透率仅 **1.0%** —— 存在"用户规模是飞书 7 倍、收入只高不到一半"的效率倒挂。
- 财报侧信号：金山办公 2026H1 营收 **33.13 亿元（+24.69%）** ，经调整扣非净利 10.87 亿元（+28.29%），半年研发投入 11.5 亿元 —— AI 已成为主营收增长引擎，但也在与大厂入口正面消耗。
- 卖方研究已单独成题：野村 2026-10-01《AI Office Agent：新的战场》，讨论点是企业上下文（context）资产与切换成本。

### 3.3 办公赛道的真实门槛

1. **上下文资产** ：企业文档、IM 历史、日历、审批流构成 agent 的长期记忆，谁持有上下文谁就掌握留存。
2. **权限与审计** ：办公场景天然多主体协作，做不到可追溯就等于不可用。
3. **结果可校验** ：文档/表格/PPT 是"可 diff 的产物"，这是它比客服、比个人助理更快商业化的根本原因。

## 四、逐渐清晰的第二梯队（本报告核心）

### 4.1 Computer-use / 浏览器操作 Agent —— 最快补位

- 行业共识已形成："网页操作能力是 2026 年智能体竞争焦点"，Agent 开始进入用户正在使用的界面。
- Manus 重新独立，洽谈约 **5 亿美元** 融资、投后估值约 **40 亿美元** （约为一年前 Meta 收购价的一倍）。
- Meta 个人智能体 Muse 上线 40 天在美下载破 **千万** 、日活可观；OpenClaw 类产品在 2026 年 3 月起推动 Computer Use Agent 爆发。
- 国内：齐俊元创立的 Today AI 七个月融资超 **2 亿美元** （红杉中国、腾讯、蚂蚁等）；"Agent Computer"方向出现新的融资与团队。
- **确定性评级：中高** 。页面状态、表单提交结果、订单/工单号是可验证的成功信号；难点在环境漂移与权限安全，而非任务定义。

### 4.2 客服 / 销售 / 营销 Agent —— 现金流最稳

- IDC：2026 年全球智能客服市场将突破 **680 亿美元** ，中国约 **320 亿元** ，CAGR 约 **22.5%** （另有华为云口径给全球 1500 亿元、CAGR 35%+，口径更宽）。
- 标杆 ROI 案例：Klarna 的金融客服 Agent 节省约 **6000 万美元** 。
- 形态收敛为三种：坐席辅助（低风险高采纳）、全自动一线（高 ROI 高风险）、外呼/线索培育（强合规约束）。
- **确定性评级：高** （工单关闭率、转人工率、CSAT 可度量），但价格战激烈、替代性强。

### 4.3 垂直专业服务 Agent —— 单位经济最好

- 法律：Harvey 2026-09 完成 **5.5 亿美元** 融资，估值升至 **155 亿美元** ，已服务 15 家以上全球律所；国内智合 AI 等对标推进。
- 金融投研/保险/会计：以"报告生成 + 数据核对 + 合规审查"为切口，天然要求人类复核（human-in-the-loop），卖的是"专业产能"而非"软件席位"。
- 医疗：Hippocratic AI、OpenEvidence 在问诊分诊、循证检索方向形成独立品类。
- **确定性评级：中高，但变现节奏慢于客服** 。壁垒不在模型，而在 **合规数据集 + 行业工作流深度整合** （这一点被多家报告反复确认）。

### 4.4 数据分析 / BI / 运营 Agent —— SQL 就是验证器

- Gartner 2026 年 ABI 魔力象限：现代分析平台正普遍嵌入"代理型分析"能力，Agent 可在"数据到洞察"全链路半自主/自主运行。
- 运营侧：IDC 判断 2026–2027 是中国企业活跃智能体数量增速最快的两年，运营 Agent 正从 POC 走向规模化部署。
- **确定性评级：高** 。SQL 可执行、指标可对账、异常可回放，是最接近 Coding 的验证结构。缺点是天花板受限于数据治理成熟度。

### 4.5 Agent 基础设施 / AgentOps / 平台层 —— 卖铲子

- 企业采购决策从"模型参数比拼"转向"平台能力与交付"，2026 年 Q2 国内企业 Agent 项目中 **47% 选托管式服务** （方舟 Plan 占 62%）、 **39% 选开源框架** （LangChain 占 71%）（信通院口径）。
- 融资侧：Braintrust 8000 万美元 B 轮、Cisco 收购 Galileo，AgentOps 早期资本活跃。
- 平台层代表：百炼（MaaS+工具链）、Dify（开源）、实在智能（RPA+Agent）。
- **确定性评级：结构确定（所有场景都要它），但同质化严重** ，赢家取决于可观测性与评测（eval）能力。

## 五、仍在"变清晰"过程中 / 需要警惕

| 方向 | 现状 | 判断 |
| --- | --- | --- |
| 通用个人 Agent | 融资热、估值高（Manus 40 亿美元、Today AI 2 亿美元），但被质疑"伪命题" | 缺少验收标准，C 端留存尚未闭环 |
| 端侧 / 具身 Agent | 仍处生态布局与早期验证 | 2026 年内不构成商业行情 |
| 通用 Agent 平台替代 SaaS | "Vertical agent 取代传统 SaaS" 叙事强 | 但定价正从席位制转向结果计费，过渡期收入会被侵蚀 |
| 数字人 / 陪伴类 | 在爱分析 7 大市场中单列 | 监管与留存双重不确定 |

## 六、给做 Agent 产品的行动建议

1. **先选"验证器"，再选行业** 。能自动判定成败的场景（测试、SQL、工单、页面状态、报表对账）优先级最高；不能自动判定的（战略、创意、个人生活），2026 年还不是好生意。
2. **复制 Coding 的三件套** ：可回滚的执行环境 + 结构化验证信号 + 失败的自动重试/升级到人。
3. **办公赛道要么做入口，要么做连接器** 。夹在中间的产品（既没有上下文资产、也没有跨应用连接）会被两端挤压。
4. **垂直 Agent 的护城河写在地面部队里** ：合规数据、行业模板、评审流程 —— 而不是模型能力。
5. **定价跟随验证强度** ：验证越确定 → 越能按结果/按任务计费；验证越弱 → 只能按席位卖，且必然被砍预算。
6. **不要做通用 Agent 的估值故事，要做确定性场景的交付故事** 。2026 年市场已经从"概念验证"进入"生产力验证"。
