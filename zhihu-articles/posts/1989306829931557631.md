**作者：** Cunxiao Du，Xinyu Yang，Fengzhuo Zhang，Yunlong Hou，Sicheng Yu，Min Lin，Chao Du

近年来， **基于扩散的语言模型（Diffusion-based Large Language Models, Diffusion LLMs）** 作为一种与传统自回归（Autoregressive, AR）模型 **根本不同的架构** ，引起了广泛关注。许多人认为，扩散模型凭借其若干潜在优势，可能成为自回归 LLM 的下一代替代方案。

一个自然的问题随之而来：

> **作为语言数据的概率模型，Diffusion LLM 在拟合自然语言分布时，与自回归 LLM 本质上有何不同？**

本文提出一种新的分析视角： **将 Diffusion LLM 视为一种“任意顺序语言模型（any-order language model）”** 。在这一视角下，我们得到关于 Diffusion LLM 局限性的两个核心结论：

> **1. 自然语言本身存在强烈的结构性偏置，使得某些生成顺序（尤其是从左到右 L2R、以及从右到左 R2L）在建模上显著更容易，而随机顺序则困难得多。** 
>  **2. Diffusion LLM 对所有顺序一视同仁地进行优化，无法将模型容量自然地集中到这些“有利顺序”上，从而导致其对真实数据分布的近似显著更松。**

---

## 1. 背景：Diffusion LLM 与 Any-Order LLM

### (1) Diffusion LLM

按照 Ni 等人 [1] 的定义，本文主要关注 **最常用的 masked diffusion 形式** 。

其训练过程如下：

- 对于长度为 (n) 的序列， **均匀随机地 mask 掉 1–n 个 token** ；
- 在给定可见（未 mask）token 的条件下，模型预测被 mask 的 token；
- 损失函数定义为 
 $ \mathcal{L_{diff}} = \mathbb{E}_{q{mask}} - \log p_{\theta}(x_{\text{mask}} \mid x_{\text{non-mask}}) $

一个简单示例如下：

```text
原句:     The quick brown fox jumps over the lazy dog
Mask 后:  The quick [MASK] fox jumps [MASK] the lazy dog
任务:     在已知其余词的条件下预测 “brown” 和 “over”
```

这种训练方式在形式上与 **BERT 等 masked language model** 非常相似。

---

### (2) 将 Diffusion LLM 视为 Any-Order Language Model

masked diffusion 的一个关键特性在于： **模型在每一步都要在任意可见 token 子集的条件下，预测任意被 mask 的 token 子集** 。

从形式化角度看，对任意 token 顺序的一个排列 (o)，联合概率都可以通过如下自回归分解表示：

$p(x) = \prod_{i} p\big(x_{o(i)} \mid x_{o(<i)}\big) $

而在 diffusion 视角下：

- ( $x_{o(<i)}$ ) 被视为 **可见（未 mask）token** ；
- ( $x_{o(i)}$ ) 被视为 **需要预测的 mask token** 。

由于 diffusion 训练 **并不固定某一个规范的 token 顺序** ，而是允许在任意可见子集条件下进行预测，因此一个 Diffusion LLM 在隐含意义上 **同时学习了所有可能的 token 顺序** 。从这个角度看，Diffusion LLM 实际上就是一种 **any-order language model** 。

这一等价关系在多篇重要工作中已有所讨论，本文沿用这一视角。

为了验证这一结论在 **双向 diffusion LLM** 与 **any-order causal LLM** 之间是否仍然成立，我们在 FineWeb-1B 上训练了：

- 4 个 **随机顺序 causal LLM（340M）**
- 1 个 **双向 diffusion LLM（340M）**

![](https://pic4.zhimg.com/v2-3b47f5c17e4bd6a67743107b09ec35c7_r.jpg)
*实验发现它们的最终 loss 几乎没有显著差异，因此我们认为上述等价关系在实践中仍然成立。*

---

### (3) Any-Order 建模背后的关键问题

从 any-order 的角度看，Diffusion LLM 似乎拥有比 L2R 自回归模型 **更强的表达能力** 。然而，这也引出了一个更深层的问题：

> **对于自然语言而言，所有 token 顺序真的同样“合适”吗？**

答案是： **并非如此** 。

尽管在理论上，任何顺序都可以作为联合分布的一个合法分解方式，但在真实语言数据上， **不同顺序对应的统计建模难度差异极大** 。

基于这一观察，我们将进一步展开两个核心发现：

1. **自然语言的结构性偏置使 L2R 和 R2L 顺序显著更易建模；**
2. **Diffusion LLM 对所有顺序平均优化，反而削弱了其对真实数据分布的逼近能力。**

---

## **2. Insight I —— 不同 token 顺序的 loss 方差极其巨大**

### 2.1 现象：L2R 和 R2L 是“赢家”

我们在 FineWeb-1B 上训练了 4 个随机顺序 causal LLM，同时额外训练了 **L2R** 和 **R2L** 两种顺序。结果显示：

![](https://pic1.zhimg.com/v2-6ef9df7a2b78e8a3108737de4553a12e_r.jpg)

1. **L2R 和 R2L 的性能显著优于所有随机顺序** ；
2. **L2R 与 R2L 的 loss 非常接近** ，暗示它们捕捉到了某种共同的底层结构。

这一现象在 AO-GPT 团队的工作 [2] 中也有观察，但他们忽略了 R2L 顺序的重要性。

---

### 2.2 假设：自然语言具有近似 Markov 结构

我们进一步追问： **为什么 L2R 和 R2L 在语言建模上如此有效？**

一个常见解释是“人类从左到右生成语言”。但这一解释无法说明 **为什么从右到左生成同样有效** ，因此并非根本原因。

我们的核心假设是：

> **自然语言在很大程度上近似满足低阶 Markov 假设** ： 
>  $p(x_n \mid x_{<n}) \approx p(x_n \mid x_{n-k:n-1}) $

在这一假设下：

1. **L2R 与 R2L 顺序天然保留局部 Markov 邻域** 
 条件分布只依赖于局部上下文，符合模型的归纳偏置。
2. **随机顺序会破坏 Markov 结构** 
 条件依赖变得高度非局部，等价于一个高阶、非平稳的过程。比如说当我们预测第10个token的时候，如果数据是马尔可夫的，那么最有用的应该是7,8,9token作为条件来预测，但是随机顺序可能给得是1,17,19作为条件。
3. **高“有效 Markov 阶数”显著增加学习难度** 
 需要更高样本复杂度、更大的假设空间，训练自然变得困难。

---

### 2.2.1 合成 Markov 数据实验

我们使用 KenLM 从 FineWeb-1B 中抽取所有 bigram，构造了一个 **严格 Markov 的合成语料** 。在该数据上训练模型后发现：

> **L2R 与 R2L 表现依旧显著优于随机顺序**

这一结果与真实语言数据完全一致。

![](https://pica.zhimg.com/v2-5d8ac7770bc2640acd24443dcdca4bd2_r.jpg)

---

### 2.3 另一个更宽松的 **假设** ：时间齐次视角（time-homogeneous view）

![](https://pic4.zhimg.com/v2-aa273614e1072633b07e996448e34fcb_r.jpg)
*经过下面的order map之后，模型被迫学习singapore i love和love i * singapore这两个不同的pattern。但是l2r和r2l可以保持唯一。*

Markov 假设很有用，但它可能仍然偏强，因为自然语言很少严格满足 Markov 性质。不过，我们可以换一个更宽松、也更贴近真实语料的假设：自然语言沿着 token 位置轴大致是** **近似时间齐次（time-homogeneous）/平移不变（translation-invariant）** **的。

更具体地说，考虑同一个短语I love singapore出现在完全不同的绝对位置：

- 出现在位置 0–3： `... [i love singapore] ...`
- 出现在位置 23333–23336： `... [i love singapore] ...`

忽略边界效应，这个 trigram `(i, love, singapore)` 的语义与局部统计行为在两种情况下本质上是相同的。

接下来，我们从 **时间齐次性** 与 **平移不变性** 的角度重新审视 any-order 生成中的“顺序（order）”。直观上，每一种 order 都可以理解为对原始序列施加了一个置换（permutation）。以 trigram `[a, b, c]` 为例，你会观察到一个关键事实：除了 L2R 和 R2L 这两种特殊置换之外， **任何其他置换都会把原始 trigram 映射成多个不同的“置换后 trigram”** ，这会直接破坏平移不变性所要求的稳定局部结构。

我们可以给出一个很直接的论证：只有 **L2R 置换** 与 **R2L 置换** 能够在“原始 trigram ↔ 置换后 trigram”之间诱导一个 **双射（bijective, one-to-one mapping）** 。换句话说，在这两种置换下，一个局部片段在置换之后仍然对应唯一的局部片段，因此不会出现“同一局部结构被拆分成多种局部结构”的情况。

**更进一步** ，在其余任意置换下，不仅无法保持一一映射，甚至连置换后三个 token 的 **相对顺序关系** （ `a` 、 `b` 、 `c` 在置换空间中谁先谁后）都不能保持唯一一致。也就是说，这些置换会让 `[a, b, c]` 在不同位置处对应到多种不同的相对排列，从而进一步破坏时间齐次性所依赖的“局部统计结构稳定”。

换句话说，任意一个非l2r和r2l的order map之后，都会让数据里面原来平移不变的语义单元变成不唯一的结构。

---

### 2.3.1 **在合成 CFG 数据上的实验（Synthetic CFG Data）**

为了验证上述假设，我们构造了一个概率上下文无关文法（PCFG, probabilistic context-free grammar），并在其生成的数据上训练不同生成顺序的模型进行对比。我们清晰地观察到：**从左到右（L2R） **与** 从右到左（R2L）**的生成仍然取得了最好的性能。

这一点很关键：PCFG 数据一般 **并不满足 Markov 性质** （因为它存在更强的层级/递归结构），但它仍然 **近似呈现出某种局部的平移不变性** 。因此，该实验可以被视为对“时间齐次性解释”的一种更有力支持：即便不存在严格 Markov，L2R/R2L 仍然因为更好地保留了局部结构的一致性而占优。

![](https://pic4.zhimg.com/v2-0aeb53303b4bca4b9d45fe5b6566fda1_r.jpg)

### **3. Insight II —— Any-order 对 diffusion LLM 是一种诅咒**

一个常见观点是： **any-order 是 diffusion LLM 的优势** 。既然 L2R 只是众多顺序之一，diffusion 模型不应该更差。

问题的关键在于： **diffusion 优化的并不是一个“正确”的 any-order 概率目标** 。

---

### 3.1 Loss 形式的根本差异

一个真正一致的 any-order 模型，其序列概率应定义为：

$\mathcal{L_{correct}} = -\log \sum_{o \in \mathcal{O}} p(o) p_\theta^{(o)}(x) $

这是一个 **log-sum-exp** 形式。

而 diffusion 实际优化的是：

$\mathcal{L_{diff}} = -\frac{1}{|\mathcal{O}|} \sum_{o \in \mathcal{O}} \log p_\theta^{(o)}(x) $

这是 **sum-log** 。

> **log-sum：只要“存在”一个好顺序即可** 
>  **sum-log：要求“所有”顺序都要好**

这正是 diffusion 的根本问题。

---

### 3.2 Log-sum-exp vs. Sum-log-exp 实验

在一个包含 4 种顺序（L2R、R2L、2 个随机顺序）的可控实验中：

- **sum-log 的 loss 始终显著更高**
- **log-sum 曲线几乎与 L2R/R2L 重合**

log-sum 自动忽略劣质顺序，而 sum-log 被迫为其“买单”，所以any order没有错，有错的是训练的目标。

![](https://pic4.zhimg.com/v2-bd92258d03b40854e45f008d616dafeb_r.jpg)

---

### 3.3 强制 L2R 推理的 diffusion LLM 的局限

如果像 LLada 一样，将 diffusion LLM **强制用于 L2R 推理** ，问题依旧存在：

- 训练阶段的 L2R 信号被严重稀释；
- 推理阶段无法使用 KV cache；
- 需要反复全序列更新，效率低下。

结果是： **无论质量还是速度，都显著劣于真正的自回归 L2R 模型** 。

---

## 4. 也许 diffusion 本身没错，错的是 masked diffusion LLM

很多人认为人类思维更像 diffusion，而不是 L2R。我们同意这一点，但认为：

> **当前的 diffusion LLM 并没有真正刻画人类思维方式**

关键原因在于：

> **人类不会进行“绝对位置”的长程预测**

人类思考更接近于：

- 在 **潜在变量空间中的自回归规划**
- 对结构与语义敏感，而对绝对 token 位置不敏感

而 masked diffusion 却强迫模型在每一步预测**“ **某个绝对位置上的 token** ”**，这与人类认知方式存在根本差异。以写modelling_transformer.py为例子来解释不同：

### (1) AR（L2R 自回归）如何写 `modelling_transformer.py`

AR 的生成方式是：沿着固定顺序（通常 L2R） **逐 token 追加** 。

- **写代码的类比** ：像程序员从文件开头开始写，只依赖已写出的前缀决定“下一步写什么”。
- 生成到某个位置时，目标永远是紧挨着的下一个 token，因此条件上下文是一个连续前缀，和代码/自然语言的局部依赖结构天然对齐。
- 推理阶段也能稳定利用 KV cache 做增量计算。

---

### (2) masked diffusion（token-space masked diffusion）如何写同一个文件

masked diffusion 的训练样本可以包含 **大量被 mask 的位置** ；但在训练目标里，你可以把它理解成：模型在给定“可见 token”的条件下，被要求 **预测某一个（或一批）绝对位置上的 token** 。用写代码举例：

```text
class TransformerBlock(nn.Module):
    def __init__(self, dim, n_heads, ...):
        [MASK] [MASK] [MASK] [MASK] [MASK] ...
    def forward(self, x, attn_mask=None, cache=None):
        [MASK] [MASK] **[MASK_i]** [MASK] [MASK] ...
```

此时我们强调的训练子任务是：

> 在给定其余可见 token（包括未 mask 的 token，以及当前样本里其它位置的 mask 作为“未知占位符”）的条件下，预测 **绝对位置 (i)** 上这个 **([MASK_i])** 的真实 token 值。

关键差异在于：

- 预测目标是“ **位置 (i) 上是什么** ”，它与 **绝对位置绑定** ；
- 即使同一段里有很多 mask，模型学习的依然是大量“定位到某个位置并复原”的条件分布；
- 这与 AR 的“下一步追加”不同：AR 的目标不需要在一个已经铺开的全局序列里反复回答“第 (i) 个 token 是什么”。

---

### (3) 人类（以及更接近人的 semantic diffusion）如何写同一个文件

人类写 `modelling_transformer.py` 时通常不会以“绝对 token 位置”为思考单位，而更像：

1. 先确定结构：要有哪些类/函数、它们怎么组织（例如 `Attention/MLP/Block` 的职责与接口）；
2. 再确定关键约束：shape、cache API、数值稳定性与性能边界；
3. 最后才落到具体 token：填充具体实现细节。

如果用 diffusion 的语言来比拟，更像是 **semantic diffusion** ：不确定性主要发生在“语义/结构决策”层面，逐步细化到可执行实现；而不是像 token-space masked diffusion 那样，反复围绕“绝对位置 (i) 的 token 是什么”来训练。
