好久没更新动态了，去年跳了个槽。我大概是去年下半年加入盛大新加坡的。当时面了几家公司，最后选盛大Miromind，主要是看中它本来就是一家国际化公司，新加坡、东京、美国都有office，跨地域协同办公。入职之后才知道，新加坡的全职团队是公司里入职更早、人数一直更多的一支，到现在也还在持续扩张，最近几个月一直在发 offer，每个 quarter 团队规模都肉眼可见在涨。

入职之后，我主要承担 SFT/Midtrain 和 RL 相关的框架迁移、功能支持等 infra 工作。主线是把之前在老框架上跑的 SFT/DPO 训练 pipeline 整体迁到 新框架torchtitan 这一套上，并适配公司自己的模型 / 数据/ 多节点环境。展开说一下具体做了什么：

- 一周左右，把 DPO 完整迁过去，包括 loss、reference model 分片、训练数据路径，以及补齐多种并行策略下的单测。期间也协助算法同学做对齐复现，从小模型的 reward 曲线到大模型的多节点 e2e都跑了一遍；
- 两周左右，把长上下文训练在多机多节点上打通，完成 CP + FSDP 的并行配置和效率验证；期间针对 torch 版本兼容性问题打了几个 compat shim；
- 几天时间，把训完的 checkpoint 转 HF 格式 + 起推理服务 + 跑评测这一整条 pipeline 自动化掉，训练侧每存一个 ckpt 就能自动得到 benchmark 分数，省掉手工挑 ckpt 的成本；
- 期间也做了一些 benchmark 性质的工作，比如不同 CP 调度策略在 varlen 数据上的通信开销对比、attention kernel 在不同 seqlen 下的 forward/backward 性能验证、以及推理侧不同 speculative decoding配置的吞吐对比。

这些事情绝大部分都是在 cc 的辅助甚至主导下完成的。cc 对偏后端、偏调度、corner-case 多的传统 infra 工作真的是降维打击：框架迁移、新模型接入、kernel 替换、commit 筛选打 patch、log分析这些工作，相比之前在国内大厂的体感至少是 *5 ~ *10。迭代节奏基本按周走，经常是当天讨论的需求当天 / 第二天就能跑出 e2e 结果，反而是 human review 和判断成了瓶颈——cc 已经能写得比我快、bug还少，剩下的瓶颈是想清楚要做什么。

谈一下整体的工作状态和氛围：

资源。算力上没什么瓶颈，更多更新的 H/B 卡可以跑想跑的实验，绝大部分实验不用排队，单卡和多卡的 benchmark 想跑就跑。多机多节点的训练任务也是常态，不会出现"想跑 64 卡但只有 8卡"那种排队体验。据我了解，后续公司在机器集群和资源投入上还会继续加码，老板在算力和工具这一块是真的舍得投。

工具。老板对 AGI 是真的 open，鼓励用 AI 工具最大化生产力，Claude 不限量，cc 直接默认是大家日常 coding 的主力。这件事在国内某些大厂还在内部争论"能不能用、用多少"的时候，这边已经 default-on了好几个月。内部讨论里大家也会互相分享 cc 的用法、prompt、agent 设计，整体不是"防 AI"而是"卷 AI"的氛围。

团队。新加坡 office 同事来自的背景比较多元，包括一线大厂、海外大厂、各家研究机构和高校，技术背景互补。在 model arch、RL算法、framework、kernel、硬件这些方向上都有人持续跟踪社区最前沿，每次内部讨论基本都能学到东西。同事的 bar 普遍比较高，整体感觉是大家对手上的事情都有真实的热情，节奏紧但不是被 push着跑，而是大家自己想往前推。跨组之间互相 review 设计、互相 cover 实验的事情很常见，不会有那种"组之间的墙"的感觉。

节奏。工作节奏按新加坡本地法律和惯例走，不卷加班，周末基本不打扰，年假 18 天。生活上新加坡的整体环境也比国内一线节奏舒服一些，对有家庭的同事尤其友好。

老板。跟在国内大厂做螺丝钉的体感很不一样，老板本身是非常尊重技术、尊重人才的，在公司方向、技术路线这些事情上愿意听一线反馈，决策路径短，做事的爽感比较强。AGI这条路线本身路径长、风险高，但能感觉到老板是真的想做事、想做出有影响力的东西，不是在玩概念。

新加坡 office 还在持续扩张，目前主要在招以下几个方向：

- 训练 infra：torch / torchtitan / megatron 方向的训练框架工程师，做长上下文、MoE、并行策略（FSDP / TP / CP / EP）、训练效率优化；
- RL infra：verl / slime / miles 这一类 RL 训练框架的工程师，做 fully-async、hybrid-colocate、agentic rollout、reward modeling infra 等方向；
- 推理 infra：sglang / vllm / 自研 kernel 方向，做推理优化、speculative decoding（MTP / EAGLE）、长上下文推理；
- 预训练 / 后训练数据：数据 pipeline、数据质量、数据多样性、合成数据等方向的同学。

不限学历背景，重点看技术能力和对 AGI 的热情。base 默认新加坡，部分岗位也可以聊东京或美国。欢迎感兴趣的朋友私信我，简历可以转给 hr 走流程。
