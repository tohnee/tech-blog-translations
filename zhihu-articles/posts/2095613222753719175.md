## 读完这篇你能做到三件事：搞懂 MCP 到底是什么；用不到 30 行 Python 写出一个能用的 MCP 服务；把它接进 Claude Code，让 AI 直接帮你查笔记、记笔记。全文代码我都实际跑过。

### 一、MCP 是什么，一句话讲清楚

AI 本身只会”说话”，碰不到你电脑里的文件、数据库、软件。MCP（Model Context Protocol，模型上下文协议）就是一套统一的”插头标准”：你把某个功能做成一个 MCP 服务，任何支持 MCP 的 AI 工具（Claude Code、各类编辑器等）都能直接调用它，不用每个工具单独适配。

可以类比成 USB 口：以前每个设备一种接口，现在统一了。

一个 MCP 服务主要能提供三样东西：

- 工具（tool）：AI 可以主动调用的函数，比如”搜索笔记”。这是最常用的。
- 资源（resource）：AI 可以读取的数据，比如某个文件内容。
- 提示词模板（prompt）：预先写好的提示词。

今天我们只做”工具”。

### 二、准备环境

官方 Python SDK 要求 Python 3.11 及以上。推荐用 uv（一个快速的 Python 包管理工具）：

```bash
mkdir mcp-notes && cd mcp-notes
uv init
uv add "mcp[cli]"
```

不想用 uv 的话，用 pip 也行：

```bash
pip install "mcp[cli]"
```

注意：SDK 在 2.x 版本里把服务类写成 MCPServer；如果你装的是 1.x 老版本，对应的写法是 `from mcp.server.fastmcp import FastMCP` ，其余基本一致。

### 三、写服务：三个工具

新建 server.py，粘贴下面的代码：

```python
from pathlib import Path

from mcp.server import MCPServer

mcp = MCPServer("notes")

NOTES_DIR = Path.home() / "notes"

@mcp.tool()
def list_notes() -> list[str]:
    """列出笔记目录下所有 .md 文件名。"""
    NOTES_DIR.mkdir(exist_ok=True)
    return sorted(p.name for p in NOTES_DIR.glob("*.md"))

@mcp.tool()
def search_notes(keyword: str) -> list[str]:
    """在所有笔记里搜索关键词，返回包含它的文件名。"""
    return [
        p.name
        for p in NOTES_DIR.glob("*.md")
        if keyword in p.read_text(encoding="utf-8")
    ]

@mcp.tool()
def add_note(title: str, content: str) -> str:
    """新建一条笔记。"""
    NOTES_DIR.mkdir(exist_ok=True)
    path = NOTES_DIR / f"{title}.md"
    path.write_text(content, encoding="utf-8")
    return f"已保存：{path}"

if __name__ == "__main__":
    mcp.run()
```

这里有两个关键点：

1. 函数的类型标注（比如 keyword: str）就是参数说明书。SDK 会自动生成给 AI 看的参数格式，你不用手写。
2. 函数下面那行三引号文字（docstring）就是工具说明。AI 靠它判断”什么时候该用这个工具”，所以要写清楚、写具体。

mcp.run() 默认走 stdio 方式：AI 工具把你的脚本当子进程启动，通过标准输入输出对话。本机使用最简单，不用开端口。

### 四、先本地测试，再接入 AI

官方自带一个调试界面 Inspector：

```bash
uv run mcp dev server.py
```

打开后能看到三个工具，手动填参数点一下，确认返回正常，再往下走。这一步能省掉后面 90% 的排查时间。

### 五、接入 Claude Code

用一条命令注册（把路径换成你自己的绝对路径）：

```bash
claude mcp add --transport stdio notes -- uv run --directory /你的/绝对路径/mcp-notes python server.py
```

注意中间那个 `--` ：它前面是 Claude Code 自己的参数，后面整串是启动你服务的命令。

注册后检查一下：

```bash
claude mcp list
```

看到 notes 显示已连接就成功了。进入 Claude Code 之后，也可以输入 /mcp 查看各个服务状态。

然后直接用大白话对它说：

- “帮我记一条笔记，标题叫周报，内容是……”
- “我之前哪些笔记提到过 MCP？”

它会自己判断调用 add_note 或 search_notes。第一次调用时会问你是否允许，这是安全机制，别图省事一律放行。

### 六、常见坑

1. 工具不出现：多半是路径写成相对路径，或者命令在你终端能跑、在 Claude Code 里找不到。建议统一用绝对路径。
2. 不要在 stdio 服务里用 print()：标准输出是和 AI 通信的通道，随便 print 会破坏协议。要打日志请写到文件或标准错误。
3. 工具说明写得太随意：AI 选错工具，十有八九是 docstring 太含糊。
4. 权限别给太大：这个例子只碰 ~/notes 一个目录。自己做的服务，也应该只开放必要的能力，尤其是删除、执行命令这类。

### 总结

MCP 的核心就是”把你的功能包装成 AI 能理解的工具”。有了这 20 来行代码，你已经掌握了完整套路：定义函数 → 写好说明 → 本地调试 → 注册到 AI 工具。后面把笔记换成你的数据库、日历、公司内部接口，写法几乎一样。
