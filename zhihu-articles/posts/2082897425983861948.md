最后再考个编程题吧。写一个python程序，从命令行接收图片文件名。把图片自动缩放成长边为1600像素，并保持长宽比例和方向旋转。

```text
import sys
from PIL import Image
import os

def resize_image(image_path, target_width=1600):
    """
    将图片缩放到指定宽度，保持长宽比和方向旋转
    
    参数:
        image_path (str): 图片文件路径
        target_width (int): 目标最大宽度（默认1600）
        
    返回:
        resized_image: 调整后的图像对象
    """
    try:
        with Image.open(image_path) as img:
            original_width, original_height = img.size
            
            # 计算缩放比例，确保长边不超过target_width
            max_width = target_width
            scale_factor = min(original_width / max_width, 
                              original_height / max_width)
            
            new_width = int(original_width * scale_factor)
            new_height = int(original_height * scale_factor)
            
            # 创建调整后的图像
            resized_img = img.resize((new_width, new_height), Image.ANTIALIAS)
            
            return resized_img
    except Exception as e:
        print(f"处理图片时出错: {e}")
        return None

def main():
    if len(sys.argv) < 2:
        print("使用方法: python resize_image.py <图片文件名>")
        sys.exit(1)
    
    image_file = sys.argv[1]
    
    # 检查文件是否存在
    if not os.path.exists(image_file):
        print(f"错误: 文件 '{image_file}' 不存在")
        sys.exit(1)
    
    resized_image = resize_image(image_file, target_width=1600)
    
    if resized_image:
        output_path = f"resized_{os.path.basename(image_file)}"
        
        # 保存调整后的图片
        try:
            with Image.open(image_file) as original_img:
                resized_img.save(output_path)
            print(f"图片已保存到: {output_path}")
        except Exception as e:
            print(f"保存图片时出错: {e}")
    else:
        print("无法处理图片")

if __name__ == "__main__":
    main()

```

写的这个程序，问题也不少。首先是缩放比例算反了，应该是 scale = 1600 / max(原宽, 原高)，它那样计算只会把图像放得更大。另外，main函数中接收的图像变量名为 resized_image

`    resized_image = resize_image(image_file, target_width=1600)`

保存时又用成了 resized_img，变成缩写了

`resized_img.save(output_path)`

另外

`with Image.open(image_file) as original_img`

这里 original_img 也是完全多余的。

总体测试下来，这个面壁小钢炮表现比较差，没有太大的实用价值
