### 1. 先看地图：人工智能、机器学习、深度学习

| 名词 | 一句话解释 | 打个比方 |
| --- | --- | --- |
| 人工智能（AI） | 让机器表现得”像人一样聪明”的总目标 | 目标：造出”会开车的人” |
| 机器学习（ML） | 不写死规则，让程序从数据里自己学出规则 | 不逐条背交规，多开几次自己领悟 |
| 深度学习（DL） | 机器学习中的一种：用”很多层”的神经网络来学 | 一种练车法：靠大量分层练习形成肌肉记忆 |

三者是包含关系：深度学习 ⊂ 机器学习 ⊂ 人工智能。

**最关键的认知转变** ：

- 传统编程： **人写规则** → 喂数据 → 出答案；
- 深度学习： **喂数据 + 答案** → 机器自己长出规则。

所以深度学习擅长”规则说不清、但例子足够多”的事——认图、翻译、下棋、识别垃圾邮件，都是这一种。

### 2. 一个贯穿始终的比喻：教小孩认猫

要让从没见过猫的小孩学会认猫，你不会塞给他一本《猫科解剖学》，而是：

1. 给他看成千上万张图，告诉他”这是猫 / 这不是猫”；
2. 他慢慢总结：尖耳朵、有胡子、会喵 → 大概率是猫；
3. 认错了就纠正，下次更准。

深度学习本质就是这件事。请记住学习的三拍： **猜 → 错 → 改** 。

- 上篇讲”猜”是怎么发生的（前向传播）；
- 中篇讲”错”怎么量化、”改”怎么改（损失函数、梯度下降）；
- 下篇讲这三拍如何在 PyTorch 里串成一个真实程序。

### 3. 神经元 = 一个带”旋钮”的投票器

先别被”神经元”这种生物词吓到。在深度学习里，一个神经元就是一台 **极其简单的小机器** ：

- 收到几个输入（比如判断猫：尖耳朵？有胡子？会喵？）；
- 每个输入配一个 **权重** （”重要程度旋钮”，可拧大拧小；负数=投反对票）；
- 所有”输入 × 权重”相加，得到 **总票数** （分数）；
- 再加一个 **偏置** （”门槛旋钮”，调高难激活、调低易激活）。

给有 Python 基础的朋友， **这就是一个神经元的全部** ：

```python
def one_neuron(x1, x2, w1, w2, b):
    score = w1 * x1 + w2 * x2 + b   # 加权投票，得到分数
    return score                    # 分数越高，代表"越像这一类"
```

**权重和偏置统称”参数”** ——整个深度学习，就是不停地拧这些旋钮，让分数越来越对。

### 3.1 “线性层” = 一整排投票器

真实网络不是一个神经元单打独斗，而是 **一层一排神经元** ，每个神经元各自有一组旋钮。这一排神经元合起来叫 **线性层（Linear / Dense）** 。PyTorch 里就是 `nn.Linear(...)` ，本篇和中篇的演示里你会反复见到。

一个线性层做的事，用大白话说就是：

> 把输入的一串数字， **乘上各自的权重、加上偏置** ，变成另一串数字。

至于”每个输出是怎么由所有输入加权算出来的”，写成代码就是两个嵌套的循环——但 **别自己写** ：这就是矩阵乘法，框架一行搞定（后面会看到对拍演示）。

### 4. 前向传播：数据是怎么一步步算出答案的

把好几层这样”投票器排”串起来：第一层输出 → 第二层输入 → …… → 最后一层给出答案。 **数据从输入走到输出的这个过程，就叫前向传播（Forward）** 。

### 4.1 数据在网络里的形状变化（给 Python 基础的朋友）

请把”张量”想成 **NumPy 数组的加强版** （能自动搬上 GPU 加速）。上面那段对拍代码的注释里到处是 shape，其实是这个意思：

```text
输入 x:        (2, 3)     # 2 条样本，每条 3 个数
经过 layer1:   (2, 3) -> (2, 5)     # 3 个数被加工成 5 个数
经过 layer2:   (2, 5) -> (2, 2)     # 5 个数被加工成 2 个数（2 分类的分数）
```

规律： **线性层只改变”每条样本有几个数”，不改变”有几条样本”** 。第 1 维永远是”一批有几条”，后面的维度是”每条样本被加工成了几个数”。

### 4.2 对拍实验：框架算的 = 你自己算的

下面这段代码干了一件特别适合你验证的事：

1. 用 PyTorch 搭一个两层网络，得到随机初始化的权重；
2. 把 **同一套权重** 抄出来，用 NumPy 手动写一遍前向传播；
3. 给同一份输入， **两边结果完全一致** 。

这证明了： **PyTorch 没有魔法，它只是把你手写的那堆”乘加循环”封装成了又快又稳的矩阵运算 + 自动求导。** 你理解了这个，就永远不会被框架吓到。

```python
#coding:utf8
import os
os.environ['KMP_DUPLICATE_LIB_OK'] = 'TRUE'
import torch
import torch.nn as nn
import numpy as np

"""
numpy手动实现模拟一个线性层
"""

# 搭建一个 2 层的神经网络模型（每层都是线性层）
class TorchModel(nn.Module):
    def __init__(self, input_size=3, hidden_size1=5, hidden_size2=2):
        super(TorchModel, self).__init__()
        # 第一件事：定义要使用哪些网络层
        self.layer1 = nn.Linear(input_size, hidden_size1)   # 3 * 5
        self.layer2 = nn.Linear(hidden_size1, hidden_size2) # 5 * 2

    def forward(self, x):
        # 第二件事：定义这些网络层是如何组合的
        x = self.layer1(x)      # (batch_size, input_size) -> (batch_size, hidden_size1)
        y_pred = self.layer2(x) # (batch_size, hidden_size1) -> (batch_size, hidden_size2)
        return y_pred

# 自定义模型：把"线性层"拆成你看得懂的"矩阵乘法 + 偏置"
class DiyModel:
    def __init__(self, w1, b1, w2, b2):
        self.w1 = w1; self.b1 = b1
        self.w2 = w2; self.b2 = b2

    def forward(self, x):
        # x: 2 * 3, w1.T: 3 * 5  = 2*5  b1: 1 * 5
        hidden = np.dot(x, self.w1.T) + self.b1     # 1*5
        y_pred = np.dot(hidden, self.w2.T) + self.b2 # 1*2
        return y_pred

# 随便准备一个网络输入
x = np.array([[3.1, 1.3, 1.2],
              [2.1, 1.3, 13]])
# 建立 torch 模型
torch_model = TorchModel(3, 5, 2)
# 打印初始化的随机权重
print(torch_model.state_dict())

torch_model_w1 = torch_model.state_dict()["layer1.weight"].numpy()
torch_model_b1 = torch_model.state_dict()["layer1.bias"].numpy()
torch_model_w2 = torch_model.state_dict()["layer2.weight"].numpy()
torch_model_b2 = torch_model.state_dict()["layer2.bias"].numpy()

# 用 torch 模型做预测
torch_x = torch.FloatTensor(x)
y_pred = torch_model.forward(torch_x)
print("torch模型预测结果：", y_pred)

# 把 torch 模型权重拿过来，自己实现计算过程
diy_model = DiyModel(torch_model_w1, torch_model_b1, torch_model_w2, torch_model_b2)
y_pred_diy = diy_model.forward(x)
print("diy模型预测结果：", y_pred_diy)
```

**直接运行这段代码（需要 `pip install torch numpy` ），你会看到两段”预测结果”输出完全一致** ——一份是框架算的，一份是你手写的矩阵乘法算的。框架没有任何魔法，只是帮你把”循环+求和”换成了一行高效的矩阵运算。

为了不依赖任何库，我们再用纯 Python 感受一下”一个神经元的加权求和”（心算都能验算）：

```python
# 1 条样本：[1, 2]；1 个神经元：权重 [3, 4]、偏置 5
x1, x2 = 1, 2
w1, w2, b = 3, 4, 5
score = w1 * x1 + w2 * x2 + b   # 3*1 + 4*2 + 5 = 16
print(score)                    # 16.0
```

真实网络只是把”1 个神经元”换成”一层几百个神经元”、”1 条样本”换成”一次几百条样本”，本质没变。

### 5. 激活函数：为什么要一个”非线性开关”

如果只有线性层，那不管叠多少层， **整体仍然只是一次线性变换** （白话：层层套娃后还是”一条直线”，表达不了复杂规律）。

所以每一层输出后通常要过一个 **激活函数（Activation）** ——一个”非线性开关”。课上你会遇到两个最常见的：

| 激活函数 | 白话 | 用在哪 |
| --- | --- | --- |
| Sigmoid | 把任意分数压到 0~1 之间，像”激活程度”或”概率” | 二分类输出、把分数变成概率感 |
| ReLU | 负数一律归零，正数原样保留（”要么不亮，要么亮”) | 隐藏层默认选择，简单好用 |

有了非线性开关，多层网络才能真正”扭出”复杂形状的规律——这也是”深”的意义。 **记住结论即可：激活函数 = 让网络从”只会画直线”变成”能画任意曲线”的开关。**

### 6. 深度学习为什么能”拟合任意规律”（直觉版）

单个神经元只会”一条直线”（线性）；加上非线性开关并叠很多层后，无数个小线段/小弧线拼起来，理论上能逼近任意复杂的曲线。

### 7. 小结 + 中篇预告

- AI ⊃ 机器学习 ⊃ 深度学习；深度学习 = **从数据里长出规则** ；
- 神经元 = 带旋钮的投票器；参数（权重+偏置）= 所有旋钮；
- 线性层 = 一整排投票器；前向传播 = 数据逐层加工出答案；
- 激活函数（Sigmoid/ReLU）= 非线性开关，让网络能表达复杂规律；
- **框架（PyTorch）没有魔法** ：它把你手写的乘加运算封装成矩阵运算 + 自动求导（上面那段 PyTorch vs 你自己 numpy 的对拍代码证明了这点）。
