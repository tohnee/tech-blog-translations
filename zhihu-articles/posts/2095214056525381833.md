### 当我们以为在薅羊毛，其实我们本身就是那头被薅的羊——大厂免费给用的每一句回复，背后都是真金白银的显存和电费。

- 2026-10-09 Google 的三连击：免费层与 Pro 级模型彻底切割、Plus 老用户同价被拿走一个模型、SynthID 开放；
- OpenAI 在 GPT-6.1 Sol 把”速度”做成独立付费层（Ultrafast 极速档 ≈ 12/12/60、约 300 tok/s）；
- 方向一致，免费给你尝的越来越少，Pro 门槛越划越高。

其实对于大模型厂商而言**真正吞金的不是训练，而是推理**。

**一.大模型厂商的日常运营成本不仅是训练成本（Training），更恐怖的是海量用户实时并发的推理成本（Inference），特别是高并发下的 HBM 显存带宽与 Token 消耗。**

为了更好的理解，我们先来拆一下大模型运营成本的骨架：

![](https://pic4.zhimg.com/v2-bb6564b0f9cfa4b6c040f7690a8d786b_r.jpg)

大模型的成本中心，**已经从"建模型"（训练）转移到了"养模型"（推理）**。**训练是一次性资本开支，推理是 7×24 持续燃烧、且随用户规模线性膨胀的运营开支**。

而推理为什么这么贵的**两个技术根因**，分别是**HBM 显存带宽**（硬件端的物理瓶颈）和 **Token 消耗**（业务端的计量单位）。

**HBM显存带宽，可以拆分为以下6个维度**：

**1.与训练成本性质对比（CapEx vs OpEx）**

训练 = CapEx（资本开支）：买卡、搭集群、预训练跑几个月，这是一笔可预算、可摊销的一次性投入。GPT-4 级别的训练是"千万美元级"的确定事件

推理 = OpEx（运营开支）：每有一个用户发一条消息，就在实时烧电、烧卡、烧带宽。它不眠不休，且总量 = 用户数 × 人均对话量 × 单次成本

一个大模型“一生”的总成本里，规模化运行后的推理支出会数倍于当初的训练支出。训练是“买断”，推理是“包养”——后者没有终点。

**2.并发峰值压力**

“为峰值付钱、为波谷空转”就是成本黑洞。峰值 QPS 决定容量，必须为最忙的那一刻（晚间、热点事件）预留数倍于均值的算力，否则就会出现排队，反应超时，甚至是崩

波峰波谷的浪费，主要是体现再闲时，比如深夜虽然算力闲置，但不能把它退掉。

还有流式输出拉长占用，现在的对话是逐字吐字（streaming），一个请求占住 GPU 的时间远长于它“算完”的时间，进一步压低利用率。

**3.HBM 显存带宽——推理的“带宽墙”**

推理主要分为两阶段，prefill（读入你的提问，可并行，compute-bound）和 decode（逐字生成，每步只算 1 个 token 却要读全部模型权重，memory-bound）。真正烧钱的是 decode

它受限于带宽，不是算力。每生成一个 token，都要把几百 GB 的权重从 HBM 搬到计算单元。生成速度 ≈ HBM 总带宽 ÷ 模型权重总字节数。这就是“带宽墙”。

HBM 是稀缺资源。HBM3/HBM3e 由 SK 海力士、三星、美光三家垄断，每 GB 价格是普通 DRAM 的数倍，且供给受限。它才是大模型硬件成本的命门，不是 GPU die 本身。

而且显存还被 KV Cache 吃爆。除权重外，每个上下文的 K/V 都要常驻显存，且随上下文长度线性增长。

**4.Token 消耗——成本的计量单位**

输入 token（prefill）便宜，输出 token（decode）贵。输入可并行批量算，输出是逐 token 串行、且每次都触发一遍"读全权重"，所以 API 定价里输出通常是输入的 2–5 倍。

长上下文 等于双重膨胀。上下文越长，prefill 计算量越大，KV Cache 也越大，两者叠加推高单轮成本

还有个MOE 的误区，混合专家模型虽只激活部分参数，但KV Cache 仍按总参数量算，所以“总参数小就省显存”是错的，实际省的是算力，不是显存带宽压力。

**5.量化算账——把抽象变具体**

每个成本真正落到数字才能说透。单卡吞吐上限 ≈ 带宽 ÷ 权重字节。例如H100 HBM 带宽约 3.35 TB/s，70B 模型 FP16 权重约 140 GB ，那么理论极限 ≈ 24 token/s/卡，实际因算子开销常只有一半。

单位成本，用"每百万输出 token 成本"对标各家 API 定价（如几美元级），就能反推厂商毛利是否被推理成本吞噬

日成本估算，单用户日对话量 × 每 token 成本 × 用户数，很容易算到"免费用户越多、亏得越狠"的结论。

**6.降本与商业——成本的落脚点**

技术降本路径：

6.1 打带宽墙：量化（FP8/INT4 砍权重体积与带宽需求）、投机解码（Speculative Decoding 提 decode 吞吐）、GQA/MQA（砍 KV 头数）、PagedAttention（减显存碎片）、连续批处理（提利用率）

6.2 打 Token 消耗：模型蒸馏、小模型路由（简单问题不调大模型）、上下文裁剪

**商业本质，国内大模型“价格战”看似营销，内核是推理成本的军备竞赛。谁先把维度三、四压下来，谁就有底气降价清场。推理成本线，就是 AI 产品的生死线**

**二.长上下文是 Compute 指数炸弹**

**根据 SemiAnalysis 等半导体供应链机构的拆解，随着上下文窗口拉长到 1M+ 级别，每次长文本交互消耗的 Compute 是指数级上升的。**

![](https://picx.zhimg.com/v2-b088bd75af86bf6dc1af82d9a23f6f71_r.jpg)

**单次长文本交互的 Compute，由两部分叠加**

**1.Prefill（预填充）= ∝ n²**，丢进去的每一段上下文，模型要做一次完整的注意力计算，复杂度随窗口长度 n 的平方增长。这是 1M+ 之后最大的“加速器”

**2.KV Cache（显存带宽）= ∝ n**， 每个 token 的 K/V 都要常驻 HBM，且 decode 每生成一个新 token 都要把整段 KV 读一遍。窗口越长，显存占用和"带宽墙"压力线性（但实际受 HBM 容量限制会触发卸载/重算，导致额外惩罚）

图里那条灰色虚线是"如果成本只随 token 数线性增长"的基准；红色实线是两者叠加后的真实消耗。在 128K 之前两者差距不大（曲线还贴着基准），过了 1M，n² 项开始主导，红线和灰线的喇叭口急剧张开，这就是"指数起飞"拐点

**几个量级感的落地数字参考：**

**4K→128K：**消耗大约翻几倍，可承受。

**128K→1M：**窗口涨约 8 倍，但 prefill 的 n² 让它实际涨接近 60+ 倍（8²）。

**1M→10M：**窗口再涨 10 倍，prefill 项直接 100 倍，加上 KV Cache 撑爆单卡 HBM 引发的卸载开销，单轮交互成本可能比 4K 时高 上千倍。

**这也解释了为什么“推理比训练更恐怖”，而训练是一次性把 n 跑完，而线上每一次用户长文本对话都在重复支付这个 n² 账单**。

通俗点理解就是 长文交互=无限续杯的自助餐，用户每丢给AI一篇10万字长文，都等于给它开了一张永不结账的自助餐券。

**三.端侧 vs 云端：成本到底搬到谁身上**

端侧把推理搬到用户手机 / 眼镜的 NPU 上，省了云端 HBM 与带宽，但受限于本地算力、散热、电池——”每瓦 Tokens”是硬约束；

云端模型越强（1M 上下文、Deep Think 下放），单请求成本越贵，只能往付费层挪；

这正是10-09日两家“免费给尝的越来越少、Pro 门槛越划越高”的物理根因——不是态度问题，是电费 / 显存费问题。订阅分层正从“模型多少”转向“算力多少”，模型同质化后，真正稀缺的是 GPU 时间。

![](https://pic2.zhimg.com/v2-054030255c832a856a3cf00f25708473_r.jpg)

两家切法相反的本质是成本归属不同—— 端侧把推理从“按量 OpEx”提前买成“硬件摊销 + 近零边际”（省的是云账单，代价是购机算力上限）；

云端则是赤裸裸的“按量燃烧”，用户越多、上下文越长，账单越膨胀。 而“分层逻辑”更见分野：云端有可付费解锁的阶梯——Gemini 用 Flash-Lite→Flash→Pro→Argon 换能力上限，

OpenAI 用 Standard/Fast/Ultrafast 换速度（同权重、贵 ×6）； 端侧却只有“旗舰 or 没有”的二进制门槛——本地 NPU 免费，但散热 / 电池 / 模型尺寸一锁死，非旗舰直接无入场资格。

端侧是云端价格战之外的另一条独立降本路径，但能力上限被硬件死锁（难跑长上下文、大模型），二者互补而非替代：高频小任务下沉端侧，复杂长上下文仍回云端

**四.为什么宁可被骂也要收口**

把“被骂 vs 破产”的取舍讲清，免费层现在的定位是“让用户知道有这个产品”，不再是“让用户免费用产品”；大厂卖的从来不是模型，是 GPU 时间。

2026这轮订阅收缩，方向一致。免费额度缩水、Pro 权限上移；模型本身越来越同质化，真正稀缺的是 GPU 时间，于是大厂把刀口从“功能墙”改成了“算力墙”。

**五.行业判断**

**随着硬件成本的下降，未来这种“免费额度缩水”的趋势会缓解，还是大厂会彻底走向“免费即广告 / 轻度，付费即 Agent / 深度思考”的割裂时代？**

**短期（1–2 年）:割裂只会加剧，不会暂缓**。

理由是需求跑得比硬件降价那头快。

Agent 化让单用户 Token 消耗从”问一句”变成”调十次工具 + 自己纠错”，长上下文和 Deep Think 下放又把单请求 Compute 顶上去；而供应端的天花板是 HBM 产能和 CoWoS

先进封装（台积电 CoWoS 月产能 10 万→20 万片，要到 2027 末才翻倍），硬件降价被产能卡着脖子。

需求指数涨、供给线性爬，免费层只能继续缩、Pro 权限只能继续上移。

**长期：硬件降价逆转不了这个格局，因为它根本不是价格问题，是物理属性问题。**

Agent 和深度思考天然是”算力密度型”消费：你不是买一个答案，是买一段持续运转的推理过程（多轮工具调用、长上下文驻留、自我反思）。

这跟水电一个逻辑，电再便宜，你 24 小时开着空调也照样贵。

“免费即轻度、付费即深度”不是大厂算计出来的割裂，是算力商品的物理分层，轻量请求边际成本趋近于零所以能免，深度请求持续吞 GPU 时间所以必付费，跟硬件多便宜无关。

**免费额度从来不是福利，是获客补贴；付费层也不是收割，是给真把 AI 当生产工具的人腾带宽。大厂最怕的不是你骂，是你免费薅出深度用的体感、却不肯为 GPU 时间买单。**
