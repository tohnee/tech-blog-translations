## **Qwen 推理优化方向招聘**

Qwen 的 推理优化方向 目前正在积极招募新同学（不限 校招 / 社招 / 实习）！推理优化的工作目前主要关注高并发serving（Qwen Web & APP 以及 API 服务）下的算法侧以及系统框架侧的探索与研发，主要针对 Qwen 系列模型，其中包括对话模型（如 Qwen2.5-Instruct）、视觉-语言模型（如 Qwen2-VL）以及语音模型（如 Qwen2-Audio）。

**工作职责**

**算法方向**

- 开展高效模型结构相关探索，验证推理性能以及对模型精度的影响
- 开展 Post-training 相关推理效率优化技术探索，包括不限于模型稀疏化、蒸馏、fast decoding 等，提升模型整体推理性能，推动在产品&开源侧落地
- 与 LLM 预训练 & Post-training、VL、Audio 等算法相关同学深入合作，支持团队模型相关推理效率需求，帮助团队技术落地
- 跟进业内最新模型&技术进展，例如超长序列、o1 等，尝试&探索新的推理优化方向以及机会

**系统方向**

- 配合团队模型产品上线以及开源节奏，接入公司内部推理框架以及主流的开源框架（例如 vLLM、SGLang 等）中，负责模型精度以及推理性能
- 针对 Qwen 线上服务场景，深入优化系统性能，主要包括推理调度、runtime 开销优化、kernel 性能优化等，解决系统高并发、高可靠性、高可扩展性等技术难关。
- 与算法进行深入合作，算法系统联合优化

**要求**

- 学历与计算机、机器学习等方向相关，博士及硕士优先
- 较强的代码实现能力。系统侧同学希望有较强的底层优化能力，较强的 profile 能力，发现系统&模型的性能瓶颈，并且可以提出优化策略。
- 精通 Python 以及 Pytorch 等深度学习框架
- 熟悉 Transformer 架构以及大语言模型基础知识
- 善于平衡研究目标及落地实现，且结果导向
- 良好的沟通和合作能力
- 关注技术影响力，具有开源开放精神

**加分项**

- 具有大规模 LLM 推理实战经验，具有完整的推理效率优化项目经历的优先
- 拥有知名开源项目，在开源社区具有较好的影响力
- 曾发表顶级会议论文并具有一定的学术影响力，包括但不限于 NeurIPS、ICLR、ICML、ACL、CVPR、ECCV、OSDI、SOSP 等

北京 / 杭州 / 上海
