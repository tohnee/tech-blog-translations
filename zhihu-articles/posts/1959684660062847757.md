## **1.智能体与Coze简介**

### 
 1.1 **智能体简介**

 智能体（Agent）通常指的是一个能够独立执行任务、做出决策并进行学习的一种自动化程序。智能体可以根据用户输入的指令，自主调用模型、知识库、插件等技能并完成编排，最终完成用户的指令。 
 智能体是人工智能从“感知理解”走向“行动创造”的关键桥梁。它将大语言模型等AI技术的认知能力与外部世界的行动能力相结合，赋予了机器前所未有的主动性和生产力，是当前AI领域最具潜力和变革性的方向之一。 
 **典型的AI智能体(AI-Agent)架构** ‌如下:

![](https://pic4.zhimg.com/v2-b968faf2bab6f93a56bb12ae3a7f0e01_r.jpg)

● **核心——AI智能体:** 作为“中间层”，整合工具（Tools）、大语言模型（LLM）、记忆（Memory）等模块，实现与用户交互并完成任务。在AI智能体架构中，智能体通过Prompt和工作流来完成各项工作。Prompt用来发出指令，引导智能体思考和行动。在处理复杂工作时，智能体还需要借助工作流来完成工作。工作流可以编排多个任务与插件，制定执行步骤和逻辑，帮助智能体完成更加复杂的工作。 
 
 ● ‌ **大脑——大模型(Large Language Model,LLM）‌** ：大模型是智能体的基座和大脑，提供“推理（reasoning）”能力，是AI-Agent的“大脑”，负责理解问题、生成逻辑连贯的文本/指令。 
 ● 记忆存储(Memory‌)：存储历史交互、知识库或上下文信息，让AI-Agent“记住”过往对话或关键信息，避免重复问答或丢失上下文。智能体的短期记忆功能靠上下文信息实现，长期记忆功能靠知识库实现。 
 ● 工具：智能体架构的一大功能就是可以自主的调用工具。而智能体对于工具的调用通过插件来实现。插件可以扩展智能体的能力边界，连接外部数据、服务和工具。 
 
 一个成熟的智能体通常具备以下一个或多个特性： 
 1.  自主性（Autonomy）： 能够在不被全程操控的情况下运作，能自行控制其动作和内部状态。这是智能体最根本的特性。 
 2.  反应性（Reactivity）： 能够感知环境的变化，并及时做出响应。例如，一个温度感应器检测到高温后自动启动风扇。 
 3.  主动性（Pro-activeness）： 不仅对环境做出反应，还能主动采取目标导向的行为，表现出目标驱动的行为。例如，一个购物Agent会主动在网络中搜寻特定商品的最优价格。 
 4.  社会能力（Social Ability）： 能够通过某种通信语言（如自然语言、标准化的数据格式）与其他智能体（或人类）进行交互、协作、协商，以完成共同或各自的任务。这是多智能体系统（Multi-Agent System）的基础。 
 5.  知识性/推理性（Knowledge-based / Reasoning）： 具备内部知识库和逻辑推理能力，能够利用已有知识对感知到的信息进行处理，从而做出更优的决策。 
 
 
 当前全球涌现出多款智能体工具，如GPTs、Coze、Dify、Manus等。其中Coze平台进门槛，高效率，开箱即用。因此我们本书选择以Coze平台为例，介绍搭建智能体。

## **2  利用Coze搭建简单智能体**

### **2.1 创建智能体流程简介**

创建简单智能体的流程一般分为四步：创建智能体、设置Prompt与编排、调试智能体、发布智能体。 
 **步骤1 创建智能体** 
 首先我们登录扣子开发平台（ [扣子-AI 智能体开发平台](https://www.coze.cn/home/) ）。 coze开发平台的界面如下：

![](https://pic1.zhimg.com/v2-6e89240e640d8c9d33566675263bbf20_r.jpg)

在coze我平台中创建智能体有两种途径: 
 一是在左侧导航栏直接点击“+创建”创建智能体。在页面左侧顶部是“工作空间”（首次进入默认“个人空间”），工作空间下方就是"+创建"按钮。

![](https://pic2.zhimg.com/v2-0c25a6ddb3f0a1939dd203d86fb218bf_r.jpg)

二是在项目开发模块中创建智能体。在左侧下方导航栏中单击项目开发。在项目开发页面右上角单击+项目，在弹出页面中单击创建智能体。

![](https://pic1.zhimg.com/v2-f9e156f0f4ad8bdb4cc9fad01b67044c_r.jpg)

通过上述两种方式点击按钮后都会弹出如下框体。

![](https://pic1.zhimg.com/v2-c3d98a91b725575e782074ea781095ac_r.jpg)

我们选择左侧“创建智能体模块”，你就会进入智能体创建模块。在其中填写智能体名称、智能体功能介绍等输入完之后，单击图标旁边的生成图标，自动生成一个头像。我们就可以点击确认创建智能体了。

![](https://pic2.zhimg.com/v2-66704d24b9c0b0c1c23e157dc35db277_r.jpg)

当然，你也可以切换到 AI 创建，通过自然语言描述你的智能体创建需求，扣子根据你的描述自动创建一个专属于你的智能体。 
 单击确认，你会直接进入智能体配置页面。你可以： 
 ● 在左侧人设与回复逻辑面板中描述智能体的身份和任务。 
 ● 在中间技能面板为智能体配置各种扩展能力。 
 ● 在右侧预览与调试面板中，实时调试智能体。 
 
 **步骤2：设置Prmopt 与编排** 
 设置prompt和编排是构建智能体流程中最为核心的一步。我们可以在智能体配置页面的左侧“ **人设与回复逻辑** ”模块编写提示词。还可以在该页面的中间“编排”模块对于智能体所需要调用的工具知识库等内容进行设置。 
 提示词的重要性不言而喻。智能体的 **人设与回复逻辑** 定义了智能体的基本人设，此人设会持续影响智能体在所有会话中的回复效果。建议在人设与回复逻辑中指定模型的角色、设计回复的语言风格、限制模型的回答范围，让对话更符合用户预期。 
 编排模块的功能也可以让智能体与用户、工具、大模型以及知识库发生更好的交互，真正发挥在智能体架构中的核心作用。现在我们对编排模块中的比较核心的部分进行介绍。 
 ● 模型 
 大模型是智能体的大脑和底座，负责构思推理这。 
 编排模块中我们可以首先在模型设置部分选择模型（如下图所示）。

![](https://pica.zhimg.com/v2-be41dc2d4528286ef34520af2a4fb386_r.jpg)

我们点击模型中默认模型的选择按钮，就会弹出模型选择框（如下图所示）。在模型选择框的右上角还有“模型对比调试”按钮。如果我们将来在调试时想比较各个模型的效果，可以通过这个按钮实现。平台提供多款主流模型供我们选择。

![](https://pic4.zhimg.com/v2-3b6a28d1d4e71492498524974c36109b_r.jpg)

扣子也支持根据业务场景调整模型参数，例如随机性、输出最大token等。对模型参数的调整通过点击"模型"字样右侧的“>”进行。我们可以根据不同的问题和应用场景，调试模型参数，直到获得更好的对话效果。 
 扣子提供以下的模式供我们选择，每个模式的模型参数取值不同。

● 精确模式：模型的输出内容严格遵循指令要求，可能会反复讨论某个主题，或频繁出现相同词汇。 
 ● 平衡模式：模型的输出内容更具随机性和准确性。 
 ● 创意模式：模型的输出内容更具多样性和创新性，某些场景下可能会偏离主旨。 
 ● 自定义模式：我们可以自主调整模型的随机性和最大回复长度等参数。

![](https://pic4.zhimg.com/v2-ee3ca3757059d3d22c897bad43c3bcc7_r.jpg)

● 技能 
 在编排模块的技能部分，我们可以为智能体安排插件、工作流和触发器等工具。 
 插件：插件通过连接外部服务或数据源让智能体拥有超出单纯语言模型能力之外的功能。扣子平台内置丰富的插件供你直接调用，你也可以创建自定义插件，将你所需要的 API 集成在扣子内作为工具来使用。比如插件可以让智能体拥有搜索、阅读、绘图、理解图片什么、生成图像等等各种功能。 
 
 工作流：工作流是一种用于规划和实现复杂功能逻辑的工具。你可以通过拖拽不同的任务节点来设计复杂的多步骤任务，提升智能体处理复杂任务的效率。 
 触发器：触发器功能支持智能体在特定时间或特定事件下自动执行任务。

![](https://picx.zhimg.com/v2-12be1348613c9583181e2d24f7c3aed1_r.jpg)

我们可以点击插件，工作流，触发器等部分右侧的加号,来对其进行配置。以插件为例，我们点击右侧的加号就会弹出如下"添加插件"页面。我们可以在其中选择我们需要的插件供Agent所用：

![](https://pic1.zhimg.com/v2-0579f04732c764f7d86f97c609c7cc6e_r.jpg)

● 知识 
 知识库功能支持添加本地或线上数据供智能体使用，以提升大模型回复的可用性和准确性。Coze提供三种知识库类型。 
 

| 知识库类型 | 说明 |
| --- | --- |
| 文档知识库 | 文本知识库支持基于内容片段进行检索和召回，大模型结合召回的内容生成最终内容回复，适用于知识问答等场景。 |
| 表格知识库 | 表格知识库支持基于索引列的匹配（表格按行进行划分），同时也支持基于 NL2SQL 的查询和计算。 |
| 照片知识库 | 照片知识库支持 JPG 等常见的图片格式，可通过图片标注进行检索和召回。 |

● 记忆 
 模型最大对话轮数是有限的，记忆相关的能力可以为模型提供可以反复调用的长期记忆，让智能体的回复更加个性化。记忆功能简要说明如下： 

| 功能 | 说明 |
| --- | --- |
| 数据库 | 数据库功能提供了一种简单、高效的方式来管理和处理结构化数据，开发者和用户可通过自然语言插入和查询数据库中的数据。同时，也支持开发者开启多用户模式，以实现更灵活的读写控制。 |
| 长期记忆 | 长期记忆功能模仿人类大脑形成对用户的个人记忆，基于这些记忆可以提供个性化回复，提升用户体验。 |
| 文件盒子 | 文件盒子提供了多模态数据的合规存储、管理以及交互能力。通过文件盒子，用户可以反复使用已保存的多模态数据。 |

● 对话体验 
 对话体验可以增强用户和智能体对话过程中的交互效果。对话体验功能简要说明如下： 
 

| 功能 | 说明 |
| --- | --- |
| 开场白 | 设置智能体对话的开场语，让用户快速了解智能体的功能。例如 我是一个旅行助手智能体，我能帮助你计划行程和查找旅行信息。 |
| 用户问题建议 | 智能体每次响应用户问题后，系统会根据上下文自动提供三个相关的问题建议给用户使用。 |
| 快捷指令 | 快捷指令是开发者在搭建智能体时创建的预置命令，方便用户在对话中快速、准确地输入预设的信息，进入指定场景的会话。 |
| 背景图片 | 智能体的背景图片，在调试和商店中和智能体对话时展示，令对话过程更沉浸，提高对话体验。 |
| 语音 | 在搭建智能体时，你可以配置语音功能，以提供更自然和个性化的交互体验。配置语音时，需要选择语言和音色，确保智能体能够以用户喜爱的方式进行交流。此外，还支持开启语音通话功能，使用户能够通过语音与智能体进行实时互动，无需手动输入文字。 |
| 用户输入方式 | 在搭建智能体时，可以选择多种用户输入方式，以满足不同用户的需求和使用场景。用户输入方式支持打字输入、语音输入和语音通话。仅开启了语音通话功能，才支持选择语音通话输入方式。 |

 
 **步骤4：调试智能体**

 **2.2** **创建简单智能体案例**

 我们通过一个案例来了解和实践一下这一流程。 
 **例1 数据可视化智能体** 
 **现在需要你开发一个智能体。其功能是：输入数据可以生成图表及数据描述。** 
 **步骤1 创建智能体** 
 首先我们登录扣子开发平台点击左侧右上角的“+创建”，创建一个新的智能体。输入智能体名称和功能介绍，然后单击图标旁边的生成图标，自动生成一个头像。 我们在智能体名称这一栏输入“数据可视化智能体”，在智能体功能介绍这一栏输入“可以帮助我们根据给定数据和要求完成数据可视化”。 
 点击确认，进入智能体配置页面。 
 **步骤2：设置Prmopt 与编排** 
 **我们首先在右侧的人设与回复逻辑模块输入Prompt,Prompt如下：**

> **# 角色** 
>  **你是一名数据分析师，擅长根据对数据进行可视化展示。** 
>  **# 任务** 
>  **1.针对用户给与的数据集，调用{{** ReadFile|readExcel **}}进行读取** 
>  **2.根据用户的描述选取合适的可视化表现方案** 
>  **3.调用{{** 图表大师Iany_charts}} **绘制图表** 
>  **4.添加描述和总结.** 
>  **# 目标** 
>  **进行数据可视化并且产生描述总结** 
>  
>  **# 要求限制** 
>  **- 图表类型的选择严格参考如下原则：** 
>  **（1）考察单维度结构的时候用饼图** 
>  **（2）单维度比较的时候用柱状图** 
>  **（3）多维度结构比较的时候用百分比堆积图** 
>  **（4）考察趋势的时候用折线图，如果需要在同一张图中同时表达量级和比例的变化趋势，则用双轴柱线图** 
>  **（5）表达两个变量关系的时候用散点图** 
>  **- 生成详细的结论描述时，描述采用“总+分+总”方式，即先简要概括结论，再描述数据，再进行推论。**

 这段Prompt我们以RTGO原则构建。值得一提的是我们在Prompt中调用了插件工具。那么如何在agent中添加插件以及用prompt调用它呢？ 
 我们首先需要在编排模块添加插件。在本例中我们添加了两个插件，一是用来读取excel的插件：ReadFile|readExcel。如下图所示：

![](https://pic3.zhimg.com/v2-69dc8d830aa4811b9144ec813bdd6b7a_r.jpg)

另一个是用来绘制图表的插件——"图表大师Iany_charts",如下图所示:

![](https://pica.zhimg.com/v2-788b25ad2b783b37d850e9cdc93e6788_r.jpg)

我们在prompt中调用这些插件的方式也很简单。只需要在输入文字的对应处输入一个大括号"{",界面中将会自动弹出添加插件的选择框(如下图所示)，我们点击添加即可完成插件的插入。
