## 从零搭建一个 MCP

文章目的： **快速回忆起 MCP 怎么搭建、怎么用** 。

---

### 1. 什么是 MCP？

MCP 的中文名是 **模型上下文协议** 。它是一个 **开放标准** ，规定了：

- AI（模型）如何 **发现** 可用的工具；
- AI 如何 **调用** 这些工具（传什么参数）；
- 工具执行完如何把 **结果返回** 给 AI。

它的本质是一套 **“工具接口规范”** ——让不同公司、不同语言写的工具，都能被同一个 AI 无缝调用，就像 USB 插座统一了各种设备的充电接口一样。

---

### 2. 为什么需要 MCP？—— 一个比喻

> **囚犯（LLM）** 无法亲自出门，只能通过监狱的通信窗口与外界打交道。 他要给另一半送玫瑰花，于是呼叫 **外卖平台（函数库）** 。 
>  外卖平台不是一个人，而是一个 **服务菜单** ：送花、送外卖、送蛋糕……每项服务 = **一个工具/函数** 。 
>  囚犯不能进厨房，不知道花怎么包、饭怎么做——他只需按固定格式填一张 **标准点单单** ：服务编号（送花）、数量（几束）、地址（送到哪）、备注（几点到）。 
>  小哥按单执行，回一张 **标准回执** （花已送达 / 配送失败）。囚犯全程不碰执行细节。

**一句话：MCP 给了模型一双与世界交互的”手”——也就是”编写好的、特定功能的程序”。**

---

### 3. 实战目标：做一个”AI 股票行情分析”的 MCP

### 3.1 安装环境（慢的话用镜像源）

需要 **uv** 和 **Node.js** 两个工具：

- **uv** （Python 包管理器）： [https://uv.doczh.com/getting-started/installation/](https://uv.doczh.com/getting-started/installation/)
- **Node.js** ： [https://nodejs.org/en/download](https://nodejs.org/en/download)

> 国内安装 uv 慢？用镜像源： powershell -ExecutionPolicy Bypass -c "irm [https://ghproxy.com/https://raw.githubusercontent.com/astral-sh/uv/main/install.ps1](https://ghproxy.com/https://raw.githubusercontent.com/astral-sh/uv/main/install.ps1) | iex"  安装完务必重启终端（让 PATH 生效），然后验证： powershell uv --version

### 3.2 初始化项目

在你想放项目的目录（比如 `C:\Users\jia\Desktop\mcptool` ）下执行：

```powershell
# 1. 创建项目文件夹并进入
uv init gupiao
cd gupiao

# 2. 创建虚拟环境
uv venv

# 3. 激活虚拟环境（Windows）
#    执行后终端会提示符前出现 (.venv)，说明激活成功
.venv\Scripts\activate

# 4. 安装依赖：MCP SDK + httpx（用于发 HTTP 请求）
uv add "mcp[cli]" httpx
```

### 3.3 编写 MCP 文件（gupiao.py）

在 `gupiao` 文件夹里新建 `gupiao.py` ，内容如下：

```python
"""股票行情查询 MCP 服务器（数据源：Yahoo Finance 免费接口，无需 API Key）"""
import logging

import httpx
from mcp.server.mcpserver import MCPServer  # mcp 2.x 用 MCPServer，不是 FastMCP

logging.getLogger("httpx").setLevel(logging.WARNING)

server = MCPServer("gupiao")

def _fetch_quote(symbol: str) -> dict:
    """向 Yahoo Finance 请求指定股票的最新行情。"""
    url = f"https://query1.finance.yahoo.com/v8/finance/chart/{symbol}"
    with httpx.Client(timeout=15.0, follow_redirects=True) as client:
        resp = client.get(url)
        resp.raise_for_status()
        data = resp.json()["chart"]["result"][0]
    meta = data["meta"]
    return {
        "代码": meta.get("symbol", symbol),
        "当前价": meta.get("regularMarketPrice", "N/A"),
        "涨跌": meta.get("regularMarketChange", "N/A"),
        "涨跌幅%": meta.get("regularMarketChangePercent", "N/A"),
        "昨收": meta.get("previousClose", "N/A"),
        "最高": meta.get("regularMarketDayHigh", "N/A"),
        "最低": meta.get("regularMarketDayLow", "N/A"),
        "交易币种": meta.get("currency", "N/A"),
    }

@server.tool()
def get_stock_quote(symbol: str) -> str:
    """查询指定股票的实时行情。

    Args:
        symbol: 股票代码。美股如 "AAPL"；A股用交易所后缀，如贵州茅台 "600519.SS"、平安银行 "000001.SZ"。

    Returns:
        该股票的最新行情（现价、涨跌、昨收、最高最低等）。
    """
    try:
        result = _fetch_quote(symbol)
    except httpx.HTTPStatusError as e:
        return f"查询失败：接口返回 {e.response.status_code}，请检查股票代码是否正确。"
    except httpx.HTTPError as e:
        return f"查询失败：网络错误 {e.__class__.__name__}。请检查网络连接。"
    except (KeyError, ValueError, IndexError) as e:
        return f"查询失败：无法解析行情数据（{e}）。请确认股票代码有效。"

    return "\n".join(f"{k}：{v}" for k, v in result.items())

def main() -> None:
    """以 stdio 方式运行 MCP 服务器。"""
    server.run()

if __name__ == "__main__":
    main()
```

> 想让 AI 帮你写，也可以直接说： **“请帮我编写一个 MCP 服务器 python 文件，查询股票行情。（详细描述输入输出）”** 然后把 AI 生成的代码粘贴保存到 `gupiao.py` 。

### 3.4 在平台里添加 MCP

接下来在你要用的工具（如 Cline）里添加 MCP Server。

> **MCP Server** 你可以理解为”功能包”——一簇为了某个宏大功能聚合起来的 **函数组合** 。

打开工具的 **设置 → MCP** 部分，添加 MCP Server。注意： **有的是填 JSON 文件，有的是填选项表格** 。

**JSON 配置方式：**

```json
{
  "mcpServers": {
    "gupiao": {
      "command": "C:\\Users\\jia\\Desktop\\mcptool\\gupiao\\.venv\\Scripts\\python.exe",
      "args": [
        "C:\\Users\\jia\\Desktop\\mcptool\\gupiao\\gupiao.py"
      ]
    }
  }
}
```

- `command` 是 **虚拟环境的 python.exe 绝对路径** （不是裸 `python` ）；
- `args` 是你脚本的 **绝对路径** ；
- Windows 路径里要用 **双反斜杠 `\\`** （JSON 转义规则）。

**选项表格方式（如 Cline）：**

| 字段 | 填写 |
| --- | --- |
| 名称 | gupiao |
| 类型 | STDIO |
| 命令 | C:\Users\jia\Desktop\mcptool\gupiao\.venv\Scripts\python.exe |
| 参数 | C:\Users\jia\Desktop\mcptool\gupiao\gupiao.py |

### 3.5 验证与排错

保存后平台会自动识别并连接。 **如果超时/连接失败** ，先把”启动命令 + 参数”连起来，自己在终端跑一遍：

```powershell
C:\Users\jia\Desktop\mcptool\gupiao\.venv\Scripts\python.exe C:\Users\jia\Desktop\mcptool\gupiao\gupiao.py
```

- 能正常进入等待输入状态（不报错、不退出）→ 说明配置没问题；
- 报错则按提示检查路径、依赖是否安装。

连接成功后，直接在 AI 对话框里说：

> **“帮我查一下贵州茅台（600519.SS）的行情”**

就会触发 `get_stock_quote` 工具。
