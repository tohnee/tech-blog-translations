## 第 14 章 从零实现 Mini-Megatron

> **本章目标**：用一份可运行的教学代码，实现 **张量并行（列/行）+ 1F1B 流水线并行 + 数据并行** 的最小训练框架，把第 3–10 章的理论落到自己的键盘上。代码风格对照 Megatron-Core `core_v0.18.0`，但大幅简化。

---

### 14.1 本章导读

读懂源码和能写出来是两回事。本章带你从零实现一个 **Mini-Megatron**：功能上覆盖 TP（列/行并行）、1F1B PP、DDP 三大核心，代码控制在可通读的规模。我们会：

1. 初始化进程组（第 3 章的极简版）；
2. 实现 `ColumnParallelLinear` / `RowParallelLinear`（第 4 章）；
3. 实现 1F1B 调度与 P2P（第 5 章）；
4. 实现梯度桶 + all-reduce 的 DDP（第 6 章）；
5. 串成一个能在多卡上跑通的训练循环；
6. 对照 Megatron-Core，说明哪些被简化、生产级为何更复杂。

> **运行前提**：多 GPU 环境，`torch.distributed`。用 `torchrun --nproc_per_node=N mini_megatron.py` 启动。本章代码为教学用途，追求清晰而非性能/鲁棒性。

### 14.2 背景与设计目标

Megatron-Core 有数万行代码，覆盖无数边界情况。Mini-Megatron 只保留骨架，目标是：

- **能跑通**：在多卡上训练一个玩具 Transformer 到 loss 下降；
- **可通读**：每个组件对应书中一章，一眼看清”理论如何变成代码”；
- **可扩展**：作为你实验新并行策略的起点。

我们固定一个简单配置：`tp × pp × dp = world_size`，模型是几层 MLP-only 的”伪 Transformer”（省去 attention 细节，聚焦并行骨架）。

### 14.3 第一步：进程组初始化（对应第 3 章）

用最简单的方式把 `world_size` 切成 `tp/pp/dp` 三维（顺序 `tp-dp-pp`，tp 最低位落在节点内）：

```text
import os, torch, torch.distributed as dist

class ParallelState:
    tp_group = pp_group = dp_group = None
    tp_size = pp_size = dp_size = 1

def init_parallel(tp_size, pp_size):
    dist.init_process_group("nccl")
    world = dist.get_world_size()
    rank = dist.get_rank()
    torch.cuda.set_device(rank % torch.cuda.device_count())

    assert world % (tp_size * pp_size) == 0, "world 必须能被 tp*pp 整除"
    dp_size = world // (tp_size * pp_size)
    ParallelState.tp_size, ParallelState.pp_size, ParallelState.dp_size = tp_size, pp_size, dp_size

    # global_rank = tp + dp*tp_size + pp*tp_size*dp_size  （order = tp-dp-pp）
    for pp in range(pp_size):
        for dp in range(dp_size):
            ranks = [tp + dp*tp_size + pp*tp_size*dp_size for tp in range(tp_size)]
            g = dist.new_group(ranks)
            if rank in ranks: ParallelState.tp_group = g
    for pp in range(pp_size):
        for tp in range(tp_size):
            ranks = [tp + dp*tp_size + pp*tp_size*dp_size for dp in range(dp_size)]
            g = dist.new_group(ranks)
            if rank in ranks: ParallelState.dp_group = g
    for dp in range(dp_size):
        for tp in range(tp_size):
            ranks = [tp + dp*tp_size + pp*tp_size*dp_size for pp in range(pp_size)]
            g = dist.new_group(ranks)
            if rank in ranks: ParallelState.pp_group = g
```

这就是第 3 章 `generate_masked_orthogonal_rank_groups` 的手工特化版：用三重循环显式枚举 tp/dp/pp 三种正交分组。生产级用混合基数编址通用化了任意维度组合。

### 14.4 第二步：张量并行层（对应第 4 章）

### 14.4.1 通信 Function（f / g）

```text
class _CopyToTP(torch.autograd.Function):   # 论文 f：前向 identity，反向 all-reduce
    @staticmethod
    def forward(ctx, x): return x
    @staticmethod
    def backward(ctx, g):
        dist.all_reduce(g, group=ParallelState.tp_group)
        return g

class _ReduceFromTP(torch.autograd.Function):  # 论文 g：前向 all-reduce，反向 identity
    @staticmethod
    def forward(ctx, x):
        dist.all_reduce(x, group=ParallelState.tp_group)
        return x
    @staticmethod
    def backward(ctx, g): return g

copy_to_tp    = _CopyToTP.apply
reduce_from_tp = _ReduceFromTP.apply
```

对照第 4 章 `mappings.py`：这就是 `_CopyToModelParallelRegion` 与 `_ReduceFromModelParallelRegion` 的最小实现，前向/反向严格对偶。

### 14.4.2 列并行与行并行

```text
def divide(a, b):
    assert a % b == 0; return a // b

class ColumnParallelLinear(torch.nn.Module):
    def __init__(self, in_features, out_features):
        super().__init__()
        tp = ParallelState.tp_size
        self.out_part = divide(out_features, tp)          # 按列切输出维
        self.weight = torch.nn.Parameter(torch.empty(self.out_part, in_features).cuda())
        torch.nn.init.normal_(self.weight, std=0.02)
    def forward(self, x):
        x = copy_to_tp(x)                                  # 插入 f
        return torch.matmul(x, self.weight.t())            # [*, out/tp]，不 gather

class RowParallelLinear(torch.nn.Module):
    def __init__(self, in_features, out_features):
        super().__init__()
        tp = ParallelState.tp_size
        self.in_part = divide(in_features, tp)             # 按行切输入维
        self.weight = torch.nn.Parameter(torch.empty(out_features, self.in_part).cuda())
        torch.nn.init.normal_(self.weight, std=0.02)
    def forward(self, x):                                   # x 已是列并行输出 [*, in/tp]
        out = torch.matmul(x, self.weight.t())             # 局部和
        return reduce_from_tp(out)                          # 插入 g：all-reduce
```

一个”伪 MLP”块 = ColumnParallel → GeLU → RowParallel，正是第 4 章的”列切+行切”结构：前向仅 `g` 一次 all-reduce，反向仅 `f` 一次。

```text
class ParallelMLP(torch.nn.Module):
    def __init__(self, h):
        super().__init__()
        self.fc1 = ColumnParallelLinear(h, 4*h)
        self.fc2 = RowParallelLinear(4*h, h)
    def forward(self, x):
        return self.fc2(torch.nn.functional.gelu(self.fc1(x)))
```

### 14.5 第三步：流水线并行 1F1B（对应第 5 章）

### 14.5.1 P2P 收发

```text
def pp_rank():   return dist.get_rank(ParallelState.pp_group)
def pp_world():  return dist.get_world_size(ParallelState.pp_group)

def _global(pp_local):  # PP 组内 rank → global rank
    return dist.get_global_rank(ParallelState.pp_group, pp_local)

def send_next(t):
    if pp_rank() != pp_world()-1:
        dist.send(t.contiguous(), _global(pp_rank()+1))
def recv_prev(shape, dtype=torch.float32):
    if pp_rank() == 0: return None
    t = torch.empty(shape, dtype=dtype, device="cuda", requires_grad=True)
    dist.recv(t, _global(pp_rank()-1)); return t
def send_prev(t):
    if pp_rank() != 0:
        dist.send(t.contiguous(), _global(pp_rank()-1))
def recv_next(shape, dtype=torch.float32):
    if pp_rank() == pp_world()-1: return None
    t = torch.empty(shape, dtype=dtype, device="cuda")
    dist.recv(t, _global(pp_rank()+1)); return t
```

> 教学简化：用阻塞 `send/recv`，靠”发/收方向天然错开”避免死锁；生产级用 batched isend/irecv 与偶发错位（第 5 章 5.9.3）。

### 14.5.2 1F1B 三阶段

```text
def forward_backward_1f1b(stage_model, data_iter, num_microbatches, seq_shape, loss_fn):
    p, r = pp_world(), pp_rank()
    num_warmup = min(p - r - 1, num_microbatches)     # 第 5 章 warmup 公式
    num_steady = num_microbatches - num_warmup
    inputs, outputs = [], []

    def fwd():
        x = recv_prev(seq_shape) if r > 0 else next(data_iter).cuda()
        x.requires_grad_(True)
        y = stage_model(x)
        send_next(y)
        inputs.append(x); outputs.append(y)
        return y

    def bwd():
        x, y = inputs.pop(0), outputs.pop(0)
        grad_y = recv_next(seq_shape) if r < p-1 else None
        if r == p-1:                      # 最后 stage 直接从 loss 反向
            loss = loss_fn(y); loss.backward()
        else:
            y.backward(grad_y)
        if x.grad is not None: send_prev(x.grad)

    for _ in range(num_warmup): fwd()     # warmup：纯前向
    for _ in range(num_steady):           # steady：1F1B
        fwd(); bwd()
    for _ in range(num_warmup): bwd()     # cooldown：纯反向
```

这是第 5 章标准 1F1B 的教学版：warmup 填流水线、steady 一前一后、cooldown 排空。省去了 batched 收发合并等优化。

### 14.6 第四步：数据并行梯度同步（对应第 6 章）

极简 DDP：反向后把所有梯度 all-reduce 平均。生产级的连续 buffer + 分桶 + 重叠在此简化为”一次性遍历参数”：

```text
def all_reduce_grads(model):
    dp = ParallelState.dp_size
    if dp == 1: return
    for p in model.parameters():
        if p.grad is not None:
            dist.all_reduce(p.grad, group=ParallelState.dp_group)
            p.grad /= dp                    # 平均（第 6 章缩放因子的最简形式）
```

> 教学简化：无连续 buffer、无分桶、无通信-计算重叠、无 fp32 main_grad、无 reduce-scatter(DistOpt)。这些正是 Megatron 生产级 DDP（第 6 章）与本简化版的差距所在。

### 14.7 第五步：串成训练循环

```text
def main():
    init_parallel(tp_size=2, pp_size=2)   # 需 world_size = 2*2*dp
    h, seq, micro = 256, (16, 8, 256), 8  # (s, b, h)
    layers_per_stage = 2
    stage = torch.nn.Sequential(*[ParallelMLP(h) for _ in range(layers_per_stage)]).cuda()
    all_reduce_grads_targets = stage

    opt = torch.optim.Adam(stage.parameters(), lr=1e-4)
    def data_iter_gen():
        while True: yield torch.randn(*seq)
    data_iter = data_iter_gen()
    def loss_fn(y): return y.float().pow(2).mean()   # 玩具 loss

    for step in range(100):
        opt.zero_grad()
        forward_backward_1f1b(stage, data_iter, micro, seq, loss_fn)
        all_reduce_grads(all_reduce_grads_targets)   # DP 同步
        opt.step()
        if dist.get_rank() == 0 and step % 10 == 0:
            print(f"step {step} done")
    dist.destroy_process_group()

if __name__ == "__main__":
    main()
```

启动：`torchrun --nproc_per_node=8 mini_megatron.py`（`tp=2, pp=2` → `dp=2`）。

> 注意：本示例聚焦并行骨架，`loss_fn` 与”伪 MLP”仅用于验证 loss 能反向、梯度能同步、程序能在多卡跑通。把 `ParallelMLP` 换成带 attention 的真正 Transformer 层、把 PP stage 切分做对、加上真实数据与词表并行 embedding，即可演进为真正的语言模型训练。

### 14.8 对照 Megatron-Core：被简化了什么

| 组件 | Mini-Megatron | Megatron-Core（生产级） |
| --- | --- | --- |
| 进程组 | 三重循环枚举 tp/dp/pp | RankGenerator 通用混合基数 + 十余个组（第 3 章） |
| TP 通信 | f/g 两个 Function | 8 个 Function + 序列并行 + 融合（第 4、7 章） |
| GEMM | torch.matmul | 梯度累加融合 + 异步通信 + TE FP8（第 4、11 章） |
| PP | 阻塞 send/recv + 标准 1F1B | batched 收发 + 交错式 1F1B + 变长 shape（第 5 章） |
| DDP | 遍历参数 all-reduce | 连续 buffer + 分桶 + 重叠 + main_grad（第 6 章） |
| 优化器 | 普通 Adam（每卡完整） | DistributedOptimizer ZeRO-1 分片（第 10 章） |
| 精度 | fp32 | 混合精度 + FP8（第 11 章） |
| 显存 | 无 | 重计算 + offload（第 12 章） |
| checkpoint | 无 | dist_checkpointing 可重分片（第 13 章） |

**结论**：Mini-Megatron 用约百行代码复现了核心思想，而 Megatron-Core 的绝大部分复杂度来自**性能优化**（融合、重叠、低精度）、**显存优化**（重计算、分片、offload）与**工程鲁棒性**（变长、容错、重分片）。理解了骨架，再读生产代码就知道每一处复杂性在解决什么问题。

### 14.9 练习：把 Mini-Megatron 扩展成真模型

1. **加 attention**：把 `ParallelMLP` 扩展成完整 Transformer 层（QKV 列并行、输出投影行并行，第 4 章）。
2. **词表并行 embedding**：实现第 4 章的 `VocabParallelEmbedding`（masked + all-reduce）与融合 cross-entropy。
3. **序列并行**：把 f/g 换成 all-gather/reduce-scatter（第 7 章），观察激活显存下降。
4. **梯度桶**：把 all_reduce_grads 改成连续 buffer + 异步重叠（第 6 章）。
5. **分布式优化器**：把梯度同步改成 reduce-scatter，每卡只更新 `1/dp` 参数（第 10 章）。
6. **交错式 1F1B**：给每个 stage 放多个 chunk，实现虚拟流水线（第 5 章），观察气泡下降。

每完成一项，你就把书中对应章节从”读懂”变成了”能造”。

### 14.10 本章总结

- Mini-Megatron 用约百行实现 TP（列/行并行 + f/g）+ 1F1B PP + DDP 的可运行训练骨架。
- 进程组是第 3 章正交分组的手工特化；TP 层是第 4 章 f/g 的最小实现；1F1B 是第 5 章三阶段的教学版；DDP 是第 6 章的极简 all-reduce。
- 与生产级的差距集中在性能优化（融合/重叠/FP8）、显存优化（重计算/分片/offload）、工程鲁棒性（变长/容错/重分片）。
- 沿练习逐步扩展，即可把整本书的理论落地成自己的训练框架。
