**文章名字：**Fast Inference from Transformers via Speculative Decoding

**作者与机构：**Yaniv Leviathan, Matan Kalman, Yossi Matias (Google Research)

**期刊与会议：**ICML 2023 (International Conference on Machine Learning, CCF-A 类顶会)

**论文类型：**Method / System

**一句话定位：**大模型投机推理（Speculative Decoding）赛道的开山奠基之作，首次在数学上证明并工程化实现了在严格保持目标分布无损的前提下打破自回归串行解码依赖，拉开现代推理系统并发投机加速新纪元。

## 一、 完整摘要 (The Perfect Abstract)

**问题：**自回归大语言模型（如大规模 Transformer）的生成推理极其缓慢。生成*K*个 Token 必须历经*K*次严格串行的模型前向计算。在小批次在线交互场景下，每步前向传播都受到显存带宽（Memory Bandwidth Bound）的硬性约束，高昂的硬件计算单元严重空转。

**方法：**论文提出了投机解码（Speculative Decoding）架构与投机采样（Speculative Sampling）机制。其核心洞察在于语言建模中包含大量可被轻量模型高精度拟合的局部低熵子任务。系统利用参数量小 1~2 个数量级的轻量近似模型*Mq*快速自回归猜测 γ 个候选 Token，随后利用庞大的目标模型*Mp*仅执行一次前向计算并行验证所有候选 Token 及其条件概率，并通过创新的残差修正采样算法修正首个被拒绝的位置。

**贡献：**其一，首次将体系结构的投机执行推广到随机采样场景，设计了在数学上保证采样分布与目标模型原始分布 100% 恒等无损的 Speculative Sampling 算法；其二，实现了无需修改目标模型架构、无需任何重新训练与权重微调即可开箱即用的推理加速流水线；其三，建立了完整的理论分析框架，给出了单次迭代生成 Token 期望、端到端延迟加速比、算力操作增量及最优推测步长 γ 的精确闭式解。

**结果：**在 11B 参数的 T5-XXL（覆盖机器翻译与文本摘要基准）以及 137B 的 LaMDA 模型上，该方法在完全不改变输出概率分布与文本质量的前提下，相比 Google 官方高强度优化的 T5X 工业级基线，取得了 2X~3X 的真实端到端墙钟加速（贪婪解码达 3.4X）。

## 二、 知识背景全景 (Background & Context)

### 1. 前置概念

**自回归解码 (Autoregressive Decoding)：**模型生成文本时，第*t*个 Token 的预测严格依赖于前*t*-1 个已知 Token，必须串行循环调用前向网络，单步因果依赖导致时间复杂度随序列长度线性累积。

**投机执行 (Speculative Execution)：**经典微处理器体系结构中利用分支预测（Branch Prediction）技术，在指令分支条件尚未计算完成前提前执行预测路径上的计算，若预测命中则极大掩盖流水线停顿。

**显存带宽瓶颈 (Memory-Bandwidth Bound)：**当 Batch Size 较小（如单并发交互）时，每生成一个 Token 都需将几十至上百 GB 的模型权重完整自 HBM 搬运至 SRAM，运算强度极低，GPU/TPU 算力单元在大部分时间内处于空闲等待数据搬运状态。

### 2. 赛道全景

在大模型推理加速的历史版图中，此前主要存在三大流派：其一是**通用压缩流派**（如知识蒸馏、量化 INT8/INT4、结构化稀疏），该流派减少了每步浮点运算量，但无法打破单步串行依赖，且往往导致生成质量劣化；其二是**自适应计算流派**（如 Early Exit、深度自适应网络、委员会投票决策），根据输入难度动态跳过部分网络层，但通常需要修改模型拓扑并重新训练，且不可避免地引入了输出分布漂移；其三是**算子与内存系统级优化**（如 FlashAttention、PagedAttention），彻底解决了注意力机制与显存碎片的系统工程瓶颈，但底层的序列生成依旧受限于自回归的单 Token 步进。

本论文提出的投机解码（Speculative Decoding）开创了第四个全新流派：**算法级并发投机验证流派**。它跳出了“减少单步计算量”的传统定势，转而在“显存受限但算力冗余”的客观物理现实下，通过小模型轻量推测、大模型批量并发验证的协同范式，首次在**零模型重训、零拓扑改动、零分布偏移**的严苛约束下打破了串行壁垒，成为了整个大模型投机推理领域的母体论文。

### 3. 出现契机 (Why Now?)

2022 年底至 2023 年初，千亿参数稠密语言模型（GPT-3、LaMDA、PaLM 等）席卷产业界，高昂的交互延迟成为实时人机交互的核心阻碍。与此同时，以 TPU-v4、NVIDIA A100/H100 为代表的现代加速硬件上，张量计算吞吐与片上带宽的剪刀差持续扩大——算力极大过剩而显存带宽严重告急。业界急需一种能够“用冗余算力换取时间”且不损伤商用大模型严肃生成质量的技术方案，投机解码应运而生。

## 三、 痛点与动机 (Problem & Motivation)

### 1. 技术瓶颈

传统 Transformer 自回归解码存在着不可调和的三重瓶颈：

**（1）串行时延刚性锁死：**生成*K*个 Token 必须在物理时间轴上排布*K*次前向传播，无法简单通过增加集群卡数来压缩端到端物理耗时；

**（2）算力资源极端闲置：**在交互场景下，单 Token 解码的算术强度不足 1 FLOP/Byte，数以百计的 TFLOPs 算力在等待内存总线传输，系统计算能力利用率（MFU）常年处于 5% 以下的低迷区间；

**（3）工业化无损替换阻力：**闭源大模型或经过严苛微调与对齐（RLHF）的生产级模型，其输出概率分布具备极高商业价值，任何破坏分布等价性的近似算法都面临不可控的安全与逻辑崩塌风险。

### 2. 研究动机

作者敏锐地捕获了两个关键事实：首先，语言中存在极高的信息冗余，大量常规 Token（虚词、惯用语、简单语法结构）并不需要百亿或千亿级参数进行深思熟虑，参数量仅占 1% 的轻量小模型即可达到极高的预测准确率；其次，现代 Transformer 具备前缀并行计算能力——目标大模型对*L*个 Token 前缀打分并验证下一个 Token 的计算延迟，与对单 Token 计时的延迟近乎持平。因此，若能利用廉价小模型迅速生成前瞻序列，再让大模型执行单次并行校验，便能将串行执行转化为并行并发，从本质上破除显存墙的束缚。

## 四、 核心方法 (Innovation & Methods)

### 1. 创新概述与算法整体架构

设目标大模型为*Mp*，其输出条件概率为*p*(*x*) =*p*(*xt*|*x*<*t*)；近似小模型为*Mq*，其条件概率为*q*(*x*) =*q*(*xt*|*x*<*t*)。算法的核心执行逻辑分为三个阶段构成的单步迭代循环：

**第一阶段（投机猜测）：**由轻量模型*Mq*串行自回归生成 γ 个候选 Token 序列 [*x*1,*x*2, ...,*x*γ] 及其对应的概率分布*q*1(*x*), ...,*q*γ(*x*)。由于*Mq*参数量极其轻巧，此步时间开销极低；

**第二阶段（并行评估）：**将当前前缀及所有候选 Token 一同输入目标大模型*Mp*，在一次前向计算中利用因果注意力掩码并行计算出这 γ+1 个位置的真实条件概率分布*p*1(*x*), ...,*p*γ+1(*x*)；

**第三阶段（修正与接受）：**依序检查每个候选*xi*。以概率 min(1,*pi*(*xi*) /*qi*(*xi*)) 接受。若前*n*个候选均通过，第*n*+1 个候选被拒绝，则抛弃后续推测，并从归一化的残差分布*p'*(*x*) 中采样纠错 Token；若 γ 个候选全部被接受，则直接从大模型最后一步预测的*p*γ+1(*x*) 中无偿采样额外的一个 Token。单次迭代恒定产出*n*+1 个来自目标分布的合法 Token（1 ≤*n*+1 ≤ γ+1）。

### 2. 系统子板块细节穷尽拆解

**（1）投机采样数学原理与 100% 保分布无损证明 (Speculative Sampling)**

对于任意词表中采样的 Token*x*，设目标模型概率为*p*(*x*)，近似模型概率为*q*(*x*)。投机采样规定：当从*q*(*x*) 采得候选样本*x*时，其接受概率定义为：

*P*(接受*x*) = min(1,*p*(*x*)*q*(*x*))

若*q*(*x*) ≤*p*(*x*)，则必然 100% 接受；若*q*(*x*) >*p*(*x*)，则以 1 -*p*(*x*) /*q*(*x*) 的概率拒绝该样本。一旦拒绝，系统绝非简单地重新执行无谓的蒙特卡洛循环，而是精准地自下述归一化残差修正分布*p'*(*x*) 中抽取纠错 Token：

*p'*(*x*) = norm(max(0,*p*(*x*) −*q*(*x*))) =*p*(*x*) − min(*p*(*x*),*q*(*x*))1 − β

其中单步综合接受概率 β 为：

β =∑*x*min(*p*(*x*),*q*(*x*))

**无损保分布等价性证明（Appendix A.1）：**对于词表中任意特定目标 Token*x'*，其最终被采纳的物理总概率由两项互斥事件组成：

*P*(*x*=*x'*) =*P*(猜测被接受 且*x*=*x'*) +*P*(猜测被拒绝 且 重新采样为*x'*)

代入概率密度推导：

*P*(猜测被接受 且*x*=*x'*) =*q*(*x'*) · min(1,*p*(*x'*)*q*(*x'*))= min(*p*(*x'*),*q*(*x'*))

*P*(猜测被拒绝 且 重新采样为*x'*) = (1 − β) ·*p'*(*x'*) = (1 − β) ·*p*(*x'*) − min(*p*(*x'*),*q*(*x'*))1 − β=*p*(*x'*) − min(*p*(*x'*),*q*(*x'*))

两者相加：

*P*(*x*=*x'*) = min(*p*(*x'*),*q*(*x'*)) +*p*(*x'*) − min(*p*(*x'*),*q*(*x'*)) ≡*p*(*x'*)

证毕！由此在数学严密性上彻底证伪了“投机解码会破坏生成多样性或导致文本幻觉”的行业疑虑，确立了无损保真理论基石。

论文引入了对称散度*DLK*(*p*,*q*) 来刻画两个离散分布之间的距离：

*DLK*(*p*,*q*) =∑*x*|*p*(*x*) −*M*(*x*)| = 1 −∑*x*min(*p*(*x*),*q*(*x*))
