想在自己电脑上跑一个模型，不用先买服务器，也不用每月付调用费。

这篇只列 5 个入口，全部能在普通电脑上装，装完先跑小模型。

信息来路。说法来自 Ollama、LM Studio、GPT4All 与 Jan 的公开文档，以及 llama.cpp 仓库说明与第三方整理。

下面 5 个都不是模型本身。它们是装模型、跑模型的工具，模型要另外下载。

筛选标准是这样定的。能离线跑，能在普通电脑上装，装完不用先写复杂配置。

我的判断是，入口选错比模型选错更耽误时间。先把跑起来的路走通，再谈模型好坏。

### LM Studio

LM Studio 是一个桌面程序，点几下就能下载模型、打开对话。

它在应用里直接列出模型，选一个符合电脑内存的版本，下载后点加载就能聊。

它也带本地服务，能让别的工具通过本地接口调用已经加载的模型。

适合的人，是不想碰命令行、想先在图形界面里把模型跑起来的人。

注意一点。它是工具，不是模型。模型文件另外占磁盘，下载前先看文件大小。

### Jan

Jan 也是一个桌面程序，同样走图形界面，下载模型后就能离线对话。

它的特点是开源，代码可以公开查，本地对话默认不出本机。

它同样提供本地接口，别的工具可以把它当作本地模型服务来调用。

适合的人，是在意代码公开可查、想把对话留在本机的人。

注意一点。Jan 也能接云端模型，选云端那一路，对话就不再只留本机。

### GPT4All

GPT4All 是一个桌面程序，目标是让普通笔记本也能跑模型，不用显卡也能起步。

它内置模型列表，下载后就能对话，还能把本地文档做成问答资料。

它的文档写明，推理针对 3 到 13B 参数的模型做了优化，适合普通硬件。

适合的人，是想在普通笔记本上先跑起来、顺带问本地文档的人。

注意一点。模型参数越大，内存和速度要求越高，先从小模型试起。

### Ollama

Ollama 走命令行，一条命令拉取模型，一条命令开始对话。

它把下载、加载和本地服务包在一起，别的工具也能通过本地接口调用它。

它在 macOS、Windows 与 Linux 上都能装，模型库里有多个开源模型可选。

适合的人，是习惯用命令行、或者想把本地模型接进自己写的小工具的人。

注意一点。命令行只是操作方式，不是难度证明。怕命令行的人先用前面三个。

### llama.cpp

llama.cpp 是不少工具共用的推理程序，直接用它等于跳过图形界面。

它用 C 与 C++ 写成，能在 CPU 上跑，也能用显卡加速，支持 GGUF 格式模型。

它自带本地服务程序，能把模型变成一个本地接口，供别的程序调用。

适合的人，是想自己控制编译选项、量化格式与服务参数的人。

注意一点。直接用它要自己准备模型文件、自己起服务，步骤比图形程序多。

### 先用哪一个

默认先试 LM Studio。图形界面最省事，跑通一次之后，再判断要不要换。

已经习惯命令行，或者要把模型接进工具，就换 Ollama。

在意代码公开可查，就换 Jan。想问本地文档，就看 GPT4All。

想自己调参数，或者要在老机器上抠性能，再看 llama.cpp。

边界说清楚。本地模型跑得动，不等于跑得和线上大模型一样好。

小模型适合写草稿、做整理、练流程，难问题还是要留给更大的模型，或者留给人自己核对。

结尾动作只给一个。今天先装一个，跑一个小模型，问它一个你已经知道答案的问题。
