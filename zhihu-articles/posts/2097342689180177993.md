就在刚刚，Claude Code核心作者正式离职Anthropic！

Thariq Shihipar是Claude Code团队的核心灵魂人物、被开发者社区尊称为「解释之王」。

他在X上正式发布了一封长文告别信。

![](https://pic1.zhimg.com/v2-1e1fea0895f6c263cb4b69523bbd118a_r.jpg)

在短短45分钟，Claude团队最知名的两位成员相继离职。

到底发生了什么？

![](https://pic3.zhimg.com/v2-4e93f83e7b3c19402cdb5fd08a4c039e_r.jpg)

![](https://pica.zhimg.com/v2-c607b49f375d419947251902fbf331cc_1440w.jpg)

**体面的告别信：**

**什么是真正的「向上竞赛」？**

「在加入Claude Code 一年多，并亲眼见证它的规模扩展到远超我曾经的想象之后，我离开了 Anthropic。」

在告别信开篇，Thariq这样写道。

作为陪伴 Claude Code 从有争议的新工具到「无数开发者默认编码方式」的核心推手，他在最巅峰时刻，选择了离开。

紧接着，他抛出了整封信最核心的价值观： **「向上竞赛」。**

我真的非常热爱在 Anthropic的工作，深度认同公司的使命。最重要的是，我坚信『向上竞赛』的理念。如果我们努力且负责任地工作，我们就能抬高行业的标准，并激发其他人走向更好的结果。如果我们都能互相推着对方变得更好，事情就会变得极其美好。我将永远带着这种精神前行。

在大模型疯狂内卷的今天，Thariq 犹如一股清流。他眼里的AI竞赛，不是零和博弈，而是一场 **提高全人类标准、倒逼彼此变得更卓越的事业** 。

对于同事们，他给予了赞美—— 
 
 「我在 Anthropic 的同事们，是我一生中遇到过最有才华、最周到、最能干且最真诚的人。我很高兴现在是他们在掌舵，我深深地信任他们。」

在信的结尾，他将聚光灯交还给了团队，一口气@了多位 Anthropic 的核心开发者，呼吁大家继续关注他们。

虽然告别信十分官方，但Thariq在评论区，还是发出了一个亮点评论：「等等，是不是只有我一个人觉得 Opus 5.5 变蠢了？」

![](https://pic4.zhimg.com/v2-163cb0b8d0a682bb6a377faf2b6eb4a9_r.jpg)

![](https://pica.zhimg.com/v2-c607b49f375d419947251902fbf331cc_1440w.jpg)

**从MIT天才、YC明星创业者到AI先锋**

Thariq的履历，仿佛开了挂。

他不只是传统研究员，而是一个横跨学术界、顶级大厂与硅谷创投圈的「六边形战士」。

![](https://pic2.zhimg.com/v2-5d889b354ce208c6968bbfcfe24422e3_r.jpg)

早在多伦多大学攻读工程科学本科期间，他就展露出了极强的产品直觉，联合创办了聚合消息通知的插件 Chime，并在2013年直接被 HubSpot 收购。

随后，他进入科技极客的梦想圣地——MIT Media Lab深造，并担任研究科学家。

在那里，他联合主导了颠覆传统PDF的交互式学术出版平台 PubPub，试图用动态程序重塑人类知识的展现形式。

随后，带着对复杂交互的深刻理解，Thariq 一头扎进创业赛道。

他创办了浏览器端游戏创作平台 One More Multiverse，不仅成功杀入全球顶尖孵化器YC，更是一手将平台做到了百万级用户规模。

这款灵感来自跑团和Roblox的产品，斩获了超1700万美元的融资。

![](https://pica.zhimg.com/v2-4f9297817399c8f97098abc8c721c9f6_r.jpg)

直到2025年，在经历了一段专注AI可解释性研究的Fellowship沉淀后，这位CEO，选择以「技术人员」的身份加入 Anthropic。

可以看出，Thariq 的每一步都在解决同一个核心问题：如何让极度复杂的系统，变成普通人一眼就能看懂、上手就能用的绝佳体验？

正是这种「游戏CEO」与「MIT学者」的双重视角，让他在加入 Claude Code 团队后，敏锐地察觉到了当前AI开发的盲点——不要再执迷于给模型无脑堆算力了，应该重塑的，是人类与AI的交互。

**巅峰隐退背后：他留给AI行业的4条真相**

作为前 YC 明星创业者、MIT Media Lab 的研究员，Thariq 带着极强的产品直觉改造了 Claude Code。

![](https://pic4.zhimg.com/v2-ce3667c8e8b399755d8e8de3055e6e17_r.jpg)

此前，他曾输出以下观点。

**真相一：大模型的智力已经「过剩」，算力不再是第一瓶颈**

Thariq 曾尖锐地指出：现在的强模型（如 Opus 5）其实已经非常聪明了，真正的瓶颈根本不是原始算力，而是 **交互接口与人类自身的理解力** ！

![](https://pic2.zhimg.com/v2-4268216933ecc7c13789b563c651941d_r.jpg)

能力冗余，是指一个模型在配备合适的智能体运行框架（Harness）、获得环境访问权限和代码执行能力后，能够完成的任务，远远超出了它仅靠普通对话、缺乏外部工具支持时所展现出的能力。

**真相二：强模型时代，请勇敢砍掉80%的提示词！**

Thariq 团队在内部实验中，对强模型直接 **砍掉了超80%的系统提示词** ，结果发现代码能力根本没有下降！

![](https://pic4.zhimg.com/v2-a99dac5abc0fd55b58171744d1671db1_r.jpg)

链接： [https://claude.dev/blog/the-new-rules-of-context-engineering-for-claude-5-generation-models/](https://claude.dev/blog/the-new-rules-of-context-engineering-for-claude-5-generation-models/)

他主张：过度约束反而会限制更强模型的发挥。把规则做成按需调用的模块化「Skills」，给AI留出自由发挥的空间。

**真相三：告别 Markdown，HTML 才是高密度交互的未来**

程序员最爱的 Markdown，正在成为人机协作的阻碍。当 AI 输出的代码和计划越来越长，人类往往会因为阅读疲劳而「盲目点击同意」。

![](https://picx.zhimg.com/v2-aba9507a986c76895e1e785c7268e295_r.jpg)

Thariq 断言，带图表、带颜色差异比对、可交互的 HTML 界面，才是未来能让人类真正保持判断力的交互方式。

**真相四：未来人类的终极职业——「算力分配者」**

别怕AI写代码比你快。

在未来，你的角色将变成「计算资源分配者」。你的核心价值在于：决定把昂贵的 Agent 算力投入到哪个方向，并在关键节点利用主动提问工具（如 AskUserQuestion）消除盲点，时刻把控方向盘。

![](https://pic3.zhimg.com/v2-ae7354d081c3e322c7d147ed054a295c_r.jpg)

或许，Thariq Shihipar已经找到「向上竞赛」的方向，准备好下一个创业方向了？
