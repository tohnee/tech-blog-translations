## Stage 1：SPMD 入门 — Vector Addition

**时间：Day 1（2–3h）**

### 目标

建立 Triton 的 SPMD 心智模型，理解 Program 实例如何映射数据块。

### 核心概念

| 概念 | 关键理解 | | ————— | ————————————- | | `tl.program_id` | 当前程序实例 ID（类比 CUDA blockIdx） | | `BLOCK_SIZE` | 编译期常量，定义向量化宽度 | | `tl.arange` | 向量化 lane 索引 | | `mask` | 越界保护与条件执行 |

### 练习

- 实现 Vector Add
- 修改 `BLOCK_SIZE`（32/64/128/256）观察带宽变化
- 移除 `mask`，验证越界行为
- 使用 `torch.allclose` 进行正确性校验

## Stage 2：内存布局与广播 — Elementwise Kernel

**时间：Day 2（4h）**

### 目标

掌握 **stride 计算、广播机制、非连续张量支持**。

### 核心练习

实现：

```text
y = x * scale + bias
```

- `x: [B, C, H, W]`（非 contiguous，任意 stride）
- `scale/bias: [C]`（广播到 `[B,C,H,W]`）

### 验收标准

与 PyTorch 结果一致：

```text
x * scale.view(1,C,1,1) + bias.view(1,C,1,1)
```

### 关键技术点

- 手动 offset 计算<br>`ptr + pid_b*stride_b + pid_c*stride_c + ...`
- Kernel 内实现 `[C] → [B,C,H,W]` 广播映射
- 内存访问合并（coalesced access）
- 可选：`eviction_policy="evict_last"` 优化缓存

### 调试规范

- `TRITON_INTERPRET=1`：CPU 模式验证逻辑
- `print_if`：限制特定 PID 打印
- 打印 stride 与 `tensor.stride()` 对照验证

## Stage 4：Reduction 专项 — Softmax & LayerNorm

**时间：Day 5–6（6–8h）**

### Day 5 上午：Reduction 基础

- Row-wise `tl.sum`
- `tl.max` + `tl.where`
- 验证边界尺寸（32 / 64 / 129）

### Day 5 下午：Softmax Forward

- Online softmax 数值稳定性
- 分块融合计算
- 减少 HBM 往返
- 与 `torch.softmax` 数值一致

### Day 6：LayerNorm Forward + Backward

- Forward：mean / var / rstd 计算
- Backward：梯度公式与行级并行
- 与 PyTorch autograd 对齐验证
