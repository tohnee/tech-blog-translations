最近在做预训练，尝试了一圈各种框架（HF Trainer+DeepSpeed、Colossal、Torchtitan）后，终于痛下决心开始学习 Megatron。原因无外乎有两个：

1. 各种功能支持多、有个不错的 baseline 性能，尤其是看到光速支持 DeepEP
2. 使用的社区/公司多，到了业界早晚要学

而一直阻止我使用 Megatron 的原因也有两个：

1. Megatron一堆依赖库（国内）安装麻烦
2. 已有数据用HF格式存储的，Megatron 需要转换（最开始甚至不支持 HF Tokenizer）

因此本篇文章主要就是解决这两个问题，让 Researcher 也能快速上手 Megatron 训练。

## 一、安装

### 1. 虚拟环境

Megatron 两个最主要的依赖库是 APEX 和 Transformer Engine。

虚拟环境搭建：

```bash
pip install uv
uv venv
source .venv/bin/activate
```

设置加速源：

```bash
export MIRROR=https://ghfast.top/
```

### 2. Flash Attention

TransformerEngine 支持 Flash Attention 2 和 3，下面是 FA2 的安装：

```bash
# FA2从源码安装
git clone ${MIRROR}https://github.com/Dao-AILab/flash-attention
VERSION=v2.7.4.post1
git checkout ${VERSION}
awk '{gsub("https://", "'${MIRROR}'https://")}1' .gitmodules > .gitmodules.tmp
mv .gitmodules.tmp .gitmodules
uv pip install . --no-build-isolation

# 或者直接安装
uv pip install flash-attn -i https://mirrors.cernet.edu.cn/pypi/web/simple --no-build-isolation
```

更新——目前 Hopper 显卡可以安装 FA3 后，简单改动 TransformerEngine 代码就可以被识别了:

```text
# FA3仅能从源码安装
git clone ${MIRROR}https://github.com/Dao-AILab/flash-attention
VERSION=v2.7.4.post1
git checkout ${VERSION}
awk '{gsub("https://", "'${MIRROR}'https://")}1' .gitmodules > .gitmodules.tmp
mv .gitmodules.tmp .gitmodules
cd hopper
python setup.py install
```

改动 TransformerEngine 下 `transformer_engine/pytorch/attention/dot_product_attention/backends.py` 文件关于 `flash_attn_3` 相关的 import：即将`from flash_attn_3.flash_attn_interface`修改成`from flash_attn_interface`。

### 3. 安装 TransformerEngine 和 Pytorch

安装相关库：

```bash
uv pip install pybind11 torch transformers datasets einops
apt install python-dev cmake make build-essential  # python-config

# 安装 pytorch 版本的 TransformerEngine
git clone ${MIRROR}https://github.com/NVIDIA/TransformerEngine
cd TransformerEngine
awk '{gsub("https://", "'${MIRROR}'https://")}1' .gitmodules > .gitmodules.tmp
mv .gitmodules.tmp .gitmodules
git submodule update --init --recursive
NVTE_FRAMEWORK=pytorch uv pip install . --no-build-isolation
cd ..

# 安装 apex（注意，pypi 中的 apex 和此 apex 完全不是同一个东西）
git clone ${MIRROR}https://github.com/NVIDIA/apex
cd apex
awk '{gsub("https://", "'${MIRROR}'https://")}1' .gitmodules > .gitmodules.tmp
mv .gitmodules.tmp .gitmodules
git submodule update --init --recursive
# 不支持uv安装
pip install --no-cache-dir --no-build-isolation -C "--build-option=--cpp_ext" -C "--build-option=--cuda_ext" .
cd ..

# 安装 Megatron Core
git clone ${MIRROR}https://github.com/NVIDIA/Megatron-LM
uv pip install .
cd ..
```

### 4. 安装检查

如果下面检查没有报错，说明安装成功

```bash
python -c 'import flash_attn'
python -c 'import torch; import transformer_engine; _ = transformer_engine.pytorch'
python -c 'import torch; import transformer_engine; import transformer_engine_torch'
python -c 'import torch; import fused_weight_gradient_mlp_cuda'
```

### 5. 错误处理

如果遇到 module 'transformer_engine' has no attribute 'pytorch' 错误，可以尝试打印一下在 [transformer_engine/__init__.py#L14](https://github.com/NVIDIA/TransformerEngine/blob/4b523d298cb0ecbd2015c557346c33928569a268/transformer_engine/__init__.py#L14) 中打印一下相关错误，比如可能是 flash attention 版本不匹配。

如果遇到 from megatron.core.datasets.utils import compile_helpers 错误，需要修改 Megatron-LM/megatron/core/datasets/Makefile 中的`python3-config`为`python-config`

## 二、数据格式转换

这里贴一个写的脚本，功能是从之前已分词好的 Hugging Face 数据集直接转换为 Megatron 格式的数据集

[convert_hf_datasets_to_megatron.py](https://github.com/RUC-GSAI/YuLan-Mini/blob/main/pretrain/preprocess/convert_hf_datasets_to_megatron.py)

最后数据集和 Tokenizer 的设置如下：

```text
--data-path $DATA_PATH
--tokenizer-type HuggingFaceTokenizer
--tokenizer-model yulan-team/YuLan-Mini
```
