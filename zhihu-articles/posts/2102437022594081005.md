先说结论：这份报告里最值钱的数字不是 89%，而是藏在它旁边一个更冷的数字——**4%**。

把这两个数字放在一起看，事情才有意思：美国企业花在开源大模型上的钱，89% 流向了中国公司；但开源模型在整个企业 AI 支出的大盘子里，只分到了 4%。一边是中国模型在开源市场里近乎通吃，另一边是开源市场本身只占整个市场的二十五分之一。

这两个数字哪个是真相？都是。而把它们中间的逻辑拆开，基本就能看清 2026 年大模型商业化的真实格局——谁在赚大钱，谁在赚吆喝，以及为什么"赚吆喝"这件事，本身也可能是一门好生意。

## 一、先把四个词掰开：榜单、调用量、用量份额、支出份额

聊这类新闻，最常见的翻车方式是把四个完全不同的指标搅成一锅粥：**评测榜单成绩、平台调用量、token 用量份额、支出份额**。这四个词长得像，含义差得很远，而且互相之间推不出来。

评测榜单成绩，衡量的是模型"能做多难的事"；平台调用量，衡量的是"有多少请求经过它"；token 用量份额，衡量的是"它处理了多少字节的活儿"；而支出份额，衡量的是"客户真金白银付给它的钱占比多少"。一个模型可以榜单很亮但没人付费（能力过剩、场景不匹配），也可以调用量巨大但收入微薄（单价便宜到近乎白送），还可以用量不高但单价昂贵、贡献了不成比例的收入。

举个反例马上就能明白：某模型免费开放下载，全世界的开发者都拿它跑实验，调用量和用量份额可能冲到第一——但它一分钱收入都没有。用量和支出，是可以完全脱钩的。所以看"89% 付给了中国公司"这条新闻，第一反应不应该是激动或嘲讽，而是先问一句：**这个 89%，是哪个口径的 89%？**

答案在报告原文里写得很清楚：是美国企业**开源模型支出**的 89%。不是美国企业 AI 总支出的 89%，也不是全球市场的 89%。这是一个限定得非常窄的口径——而恰恰是这个窄口径，让这个数字有了别处替代不了的信息量：它是付费行为，不是跑分行为。

把这四个维度做成一张交叉表，你就能快速判断任何一个大模型"到底处在什么位置"：

|  | 支出份额高 | 支出份额低 |
| --- | --- | --- |
| 用量份额高 | 主力机型：客户又用又付钱，商业模式成立（Kimi 现在的位置） | 白嫖层：跑分跑量都行，但单价被卷穿，赚吆喝 |
| 用量份额低 | 高价小众：关键任务专用，量小利厚（部分闭源旗舰的位置） | 边缘：既没人用，也没人付钱 |

记住这张表，后面所有的数字都能各归其位。

## 二、这份报告是什么来头

发布方是门罗风投（Menlo Ventures），1976 年成立的老牌硅谷 VC，投过 Anthropic 和 Uber，不是那种靠发报告刷存在感的小机构。这份《The State of Enterprise AI in 2026》的样本是**近 400 名美国企业的 AI 业务负责人**，这些受访者管理的 AI 支出加起来**超过 40 亿美元**——所以它反映的是"买方怎么花钱"，而不是厂商怎么讲故事。

大盘的数字先摆出来：截至 2026 年 9 月，企业 AI 部署支出达到 **1768 亿美元**，2025 年这个数字是 330 亿——一年翻了五倍多。其中 Anthropic、OpenAI、Google 三家拿走了 **1227 亿美元，占 69%**。

这两个数字放在一起，能得出第一个重要判断：**闭源三巨头非但没有被开源动摇，反而拿走了大头，而且客户还在向上买更贵的模型。**报告里有个细节很说明问题：一年前美国企业最爱用的模型是 Claude Sonnet 4.5（每百万 token 输入 3 美元、输出 15 美元）和 GPT-5（1.25/10 美元），现在换成了 Claude Opus 5.5（4/20 美元）和 GPT-6 Astra（10/60 美元）。企业不但没省钱，还在升级到更贵的档位。

那开源模型在哪？在价格战的低端。闭源阵营自己的小模型（Haiku、Luna 这类）token 份额都从 29% 跌到了 13%——这部分"便宜但没那么聪明"的活儿，正在被开源模型整段整段地抢走。**开源抢的不是三巨头的旗舰，是三巨头的"经济舱"。**

## 三、最反直觉的一组数字：用量翻倍，收入份额反而缩水

![](https://pic1.zhimg.com/v2-457b379ed6dac8643b7ee9d548df3ada_r.jpg)

接下来是整份报告里我认为最有技术含量的一组数字，也是绝大多数转载稿漏掉的：

2025 年 9 月到 2026 年 9 月这一年里，开源模型处理的 token 数量暴涨 **22.5 倍**，达到每月约 2.9 千万亿（quadrillion）tokens，增速把闭源（12.1 倍）甩在身后；开源 token 在总盘子里的份额从 11% 涨到 19%，在 OpenRouter 这个全球最大的模型聚合平台上，开源权重模型的 token 占比更是从 26.8% 涨到了 **71.7%**。

听起来全是好消息？然后看下半句：同期开源模型的**支出份额**，从 6% 跌到了 4%。

为什么？因为开源 token 的平均单价一年跌了 **3.3 倍**，降到每百万 token 约 0.13 美元；闭源模型的混合均价虽然也降了 24%，但仍有每百万 token 约 0.70 美元。OpenRouter 自己的价目表更直白：闭源模型平均每百万 token 输入 1.27 美元、输出 6.36 美元，开源模型只要 0.28 和 1.62 美元——差着四倍。

把这笔账翻译成人话：**开源模型赢走了几乎所有的"用量增长"，但每一单位用量的价格跌得比用量涨得还快，所以收入份额不升反降。**这就是典型的"规模上涨、单价崩塌"，和当年云存储、短视频 CDN 走过的路一模一样。天平上 token 那一头越压越重，钞票那一头却始终翘在天上。

这个事实会筛掉一类乐观叙事——"开源马上要革闭源的命"。不会，至少在收入上不会。它同时也会筛掉另一类悲观叙事——"开源只是玩具，没人当真"。也不会，因为 2.9 千万亿 token 每月的用量是真实的、在翻倍增长的，只是这门生意的单价模型完全不同。

## 四、为什么买单的是 Kimi：一条技术上的连环逻辑

回到 89%。开源支出里，Kimi 占 61%，DeepSeek 占 15%，GLM 占 11%，Qwen 占 3%；西方阵营里最受欢迎的 Meta Llama，只有 7%。前三名清一色中国模型，加起来 87%。

为什么是它们？媒体喜欢归因于"便宜"，但便宜只是结果，不是原因。往技术链条上游走，能拆出一条环环相扣的逻辑：

**第一环：开放权重，且是真开放。**Kimi K2.5 的权重挂在 Hugging Face 上（moonshotai/Kimi-K2.5），任何企业可以下载、自部署、拿自己的数据继续训练。这解决了企业采购里一个闭源模型永远给不了的东西——**对模型本身的控制权**。数据不出域、行为可审计、供应商可以随时换，这三条在企业的采购清单上，权重比跑分高得多。

**第二环：够用的能力 + 长上下文 + Agent 工具调用。**K2.5 支持 262K 上下文、视觉输入、工具调用和推理模式，SWE-bench Verified 跑到 73.8%。注意，企业拿开源模型跑的绝大多数是"经济舱任务"——分类、抽取、摘要、代码补全、批处理，这类任务不需要旗舰闭源模型的最后一口气，但需要稳定、快速、可批量。开源模型在这段区间里的性价比是碾压级的。

**第三环：从"调用"升级到"再训练"。**这是这份报告里最容易被忽略、但长期最关键的一段：企业用开源模型已经不只是调 API 了，而是在它基础上做后训练（post-training），训练自己的专用模型。报告披露，AI 编程工具 Cursor 直接以 Kimi K2.5 为底座构建了自己的编程模型 Composer 2，推理基础设施由 Fireworks 提供，用于强化学习 rollout；法律科技公司 Harvey 也用同样的"开源底座 + 外部算力 + 专家数据"路径做了自己的模型。后训练在 AI 开发者中的采用率从 2025 年的 6% 涨到了 10%，其中 91% 借助外部伙伴——50% 用 Fireworks、Modal 这类推理云，41% 用 Mercor 这类专家数据平台。

这段话的含义是：中国开源模型正在从"被调用的基础设施"变成"被再加工的原材料"。前者赚 API 钱，后者进入了客户的**产品定义环节**——Cursor 的核心竞争力里，有一部分是长在 Kimi 的权重上的。这种绑定比 API 调用深得多，也难替换得多。

![](https://pica.zhimg.com/v2-d80433ec9c1d5001cdae432461af058c_r.jpg)
*插图 2 ｜ Agent 每周消耗 130.9 万亿 token，占全部用量的 80%（数据：Menlo Ventures / OpenRouter）*

**第四环：真正的最大客户是 Agent，而 Agent 对价格结构极度敏感。**报告里有个数字值得单独拎出来：在 OpenRouter 上，AI Agent 每周生成 **130.9 万亿**个 token，占全部用量的 80%，约为人类直接使用量的 7 倍。模型最大的"用户"已经不是人了。

而 Agent 的账单结构和人完全不同：一次 Agent 会话里，**缓存读取可以占到 95% 以上**的 token——Agent 反复读同一段上下文，命中缓存的部分按缓存价计费。以 Claude Opus 5.5 为例，缓存读取每百万 token 0.20 美元，而新输入是 4 美元、输出是 20 美元；按"3% 新输入 + 2% 输出 + 95% 缓存读"的典型配比，一次 Agent 会话的混合成本大约每百万 token 0.70 美元。看到没有——**Agent 越普及，单价就越是被摊薄，"贵但聪明"的模型反而被自己家的缓存机制拉低了客单价**。在这个结构里，谁的基础 token 便宜、谁的长上下文和工具调用稳，谁就能吃到 Agent 的量。这正好是 Kimi、DeepSeek 这批模型的主场。

四环连起来看：开放权重给了入场券，够用的能力吃下经济舱任务，后训练把模型变成客户产品的一部分，Agent 的用量结构放大了价格优势。89% 不是靠一条理由赢的，是这条链每一环都占住了。

## 五、89% 的边界在哪里

吹完了，必须泼冷水。这个 89% 有三条清晰的边界，写任何解读稿都应该带着：

**边界一：它是 4% 里面的 89%。**开源支出在整个企业 AI 支出里只占 4%，89% 乘以 4%，中国模型在企业开源支出这个口径里拿到的真实份额是全盘的 3.5% 左右。闭源三巨头手里的 69% 才是主战场。听到"89% 付给中国公司"就以为天塌了或者天亮了，都是没算这笔账。

**边界二：能力差距还在，只是被任务结构掩盖了。**有第三方分析基于 Artificial Analysis 综合能力指数做过统计，最强闭源模型与最强开源模型的差距仍在 10 分上下（57.6 对 46.3 的量级）。在多步推理、复杂代码、高风险分析这类任务上，差距是实打实的；只是企业的大部分 token 花在分类、抽取、摘要这类"差距不明显"的任务上，所以市场用脚投票选了开源。一旦任务难度上升，预算还是会流回闭源——这就是为什么闭源三巨头能同时实现"份额 69%"和"客单价上行"。

**边界三：低单价是双刃剑。**开源支出份额从 6% 跌到 4%，跌的就是中国模型自己的收入。用量 22.5 倍、单价跌 3.3 倍，意味着开源这条线上的所有人都在打一场毛利越来越薄的仗。MiniMax 创始人闫俊杰前几天公开说的路线——"开源到 AGI，靠把推理成本压到足够低来盈利，而不是涨价"——本质上是承认：这条赛道的终局打法是靠规模和成本控制赚辛苦钱，而不是靠模型本身收溢价。

## 六、对中国团队意味着什么：三句实话

第一句：**出海这件事，从"讲故事"变成了"有账单"。**过去讲国产模型国际化，拿得出手的是榜单和开源社区 star 数；现在第一次有了支付侧的第三方数据——美国企业、真实付费、61% 的份额。对做 AI 产品出海的团队来说，这份数据本身就是可以拿去说服投资人和客户的材料。

第二句：**别把份额当护城河。**61% 的背后是极低的单价和极快的迭代节奏，Kimi 从 K2 到 K2.5 再到 3.1 Pro（上下文做到 105 万 token），大半年里换了三代。开源模型之间几乎没有转换成本，客户今天用你，明天 DeepSeek 或者 GLM 降一次价就可能切走。这条链上真正的壁垒，是把模型嵌进客户产品定义环节的能力——Cursor 们不会被一次降价撬走，但纯 API 客户随时会。

第三句：**配套的算力和服务生态正在跟着钱走。**Fireworks、Modal 这类推理云今年的收入 run rate 都破了 10 亿美元，91% 做后训练的企业依赖外部伙伴。开源模型的胜利，真正落袋的除了模型厂，还有这条基础设施链——而这条链上，谁来承接中国模型在海外的托管和微调需求，还是个空白地带，可能比模型本身更值得创业。

最后回到开头那组数字。89% 和 4%，一个是中国模型在开源市场的统治力，一个是开源市场在整个企业 AI 支出里的真实地位。它们不矛盾，它们合起来才是 2026 年的完整图景：**闭源赚走了大钱，开源抢走了所有增量，而中国模型，把开源这条增量赛道几乎整条收入了囊中。**

榜单上的名次会过期，账单上的数字不会——<br>真正的话语权，是别人每个月都得给你续费。
