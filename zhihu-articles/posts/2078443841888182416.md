## 一、TensorRT 中显存是谁在用？

在 C++ TensorRT 推理流程中，显存主要来自 3 个地方：

| 显存来源 | 谁负责 | 是否手动 |
| --- | --- | --- |
| 输入 / 输出 Buffer | 你自己 | ✅ 必须 |
| TensorRT 内部 Workspace | TensorRT | ❌ 自动 |
| CUDA Stream / Context | CUDA | ❌ 自动 |

## 二、最核心：cudaMalloc/cudaFree

1️⃣申请显存

> void* deviceBuffer = nullptr;<br>size_t bytes = batchSize * channel * height * width * sizeof(float);<br>cudaMalloc(&deviceBuffer, bytes);

cudaMalloc申请的是GPU显存。

2️⃣释放显存

> cudaFree(deviceBuffer);<br>deviceBuffer = nullptr;

不释放 = 显存泄漏（程序退出前都不会回收）

## 三、TensorRT 推理中显存的完整生命周期

1️⃣ 创建 engine / context（不需要你管显存）

> ICudaEngine* engine = runtime->deserializeCudaEngine(...);<br>IExecutionContext* context = engine->createExecutionContext();

TensorRT 自动管理内部 workspace 显存

2️⃣ 申请 I/O Buffer（你必须做）

> int nbBindings = engine->getNbBindings();<br>std::vector<void*> buffers(nbBindings);<br>for (int i = 0; i < nbBindings; ++i) {<br> size_t size = getSizeByDim(engine->getBindingDimensions(i));<br> cudaMalloc(&buffers[i], size);<br>}

📌 `buffers[i]`：

- 输入 tensor → GPU
- 输出 tensor → GPU

3️⃣ Host ↔ Device 数据拷贝

> cudaMemcpy(buffers[inputIndex], hostInput, inputSize, cudaMemcpyHostToDevice);

推理完成后：

> cudaMemcpy(hostOutput, buffers[outputIndex], outputSize, cudaMemcpyDeviceToHost);

4️⃣ 推理（不额外申请显存）

> context->enqueueV2(buffers.data(), stream, nullptr);

5️⃣ 显存释放（最容易忘）

> for (void* buf : buffers) {<br> cudaFree(buf);<br>}<br>buffers.clear();

然后再释放 TensorRT 对象：

> context->destroy();<br>engine->destroy();<br>runtime->destroy();

## 四、使用 CUDA Stream 时的注意点（很关键）

> cudaStream_t stream;<br>cudaStreamCreate(&stream);

使用完毕：

> cudaStreamDestroy(stream);

**一定保证 stream 中任务完成后再释放显存**

> cudaStreamSynchronize(stream);<br>cudaFree(deviceBuffer);

## 五、显存优化（你做工程一定会用）

✅ 1. 复用 Buffer（推荐）

只申请一次，反复推理使用

> // 程序初始化<br>cudaMalloc(&inputBuffer, inputSize);<br>cudaMalloc(&outputBuffer, outputSize);<br>// 推理循环<br>for (...) {<br> cudaMemcpyAsync(...);<br> context->enqueueV2(...);<br>}

🚀 大幅减少 cudaMalloc / cudaFree 开销

## 一个【完整标准示例】

> // 1. 创建 stream<br>cudaStream_t stream;<br>cudaStreamCreate(&stream);<br>// 2. 申请显存<br>void* buffers[2];<br>cudaMalloc(&buffers[0], inputSize);<br>cudaMalloc(&buffers[1], outputSize);<br>// 3. 拷贝 + 推理<br>cudaMemcpyAsync(buffers[0], hostInput, inputSize, cudaMemcpyHostToDevice, stream);<br>context->enqueueV2(buffers, stream, nullptr);<br>cudaMemcpyAsync(hostOutput, buffers[1], outputSize, cudaMemcpyDeviceToHost, stream);<br>// 4. 同步<br>cudaStreamSynchronize(stream);<br>// 5. 释放<br>cudaFree(buffers[0]);<br>cudaFree(buffers[1]);<br>cudaStreamDestroy(stream);
