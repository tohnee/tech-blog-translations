## 魔搭社区 ModelScope

## ms-swift介绍

ms-swift（ModelScope SWIFT，全称 Scalable lightWeight Infrastructure for Fine-Tuning）是魔搭社区官方出品的大模型与多模态大模型训练 + 部署框架。

一句话：把"预训练 → 微调 → 对齐 → 推理 → 评测 → 量化 → 部署"整条链路，压缩成一条命令行。

它解决的核心痛点是：以前你要自己拼 transformers + peft + deepspeed + vLLM + 评测脚本，现在这些都在一个 `swift` 命令后面。

下一篇文章一起学习下这个的具体细节，简而言之就是一个进行微调的框架。

## 搭建运行docker运行环境

基础镜像挑 `pytorch/pytorch:2.7.1-cuda12.6-cudnn9-runtime` ，

两个理由：本机已经有这个镜像，不用重拉；这个 torch 版本在 550 驱动上被验证过。

```text
FROM pytorch/pytorch:2.7.1-cuda12.6-cudnn9-runtime

ENV DEBIAN_FRONTEND=noninteractive \
    TZ=Asia/Shanghai \
    PIP_INDEX_URL=https://pypi.tuna.tsinghua.edu.cn/simple \
    PIP_TRUSTED_HOST=pypi.tuna.tsinghua.edu.cn

# ffmpeg/libgl 是 qwen_vl_utils 解视频、pillow 读图要用的系统库
RUN sed -i 's|http://archive.ubuntu.com/ubuntu/|https://mirrors.aliyun.com/ubuntu/|g; \
            s|http://security.ubuntu.com/ubuntu/|https://mirrors.aliyun.com/ubuntu/|g' /etc/apt/sources.list \
 && apt-get update \
 && apt-get install -y --no-install-recommends \
      git curl wget vim tmux htop less ca-certificates \
      ffmpeg libgl1 libglib2.0-0 \
 && rm -rf /var/lib/apt/lists/*

COPY requirements.txt /tmp/requirements.txt
# 装完立刻断言 torch 没被依赖解析悄悄换掉 —— 换成 cu128 的轮子这台驱动就跑不了了
RUN pip install --no-cache-dir -r /tmp/requirements.txt \
 && python -c "import torch, sys; v=torch.__version__; print('torch', v); \
      sys.exit(0 if v.startswith('2.7.1') else 1)"

ENV USE_HF=0 \
    MODELSCOPE_CACHE=/workspace/models \
    HF_HOME=/workspace/models/hf \
    HF_ENDPOINT=https://hf-mirror.com \
    PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True \
    TOKENIZERS_PARALLELISM=false \
    PYTHONUNBUFFERED=1

WORKDIR /workspace
CMD ["sleep", "infinity"]

```

requirements.txt

```text
ms-swift==3.12.6
transformers==4.57.6
qwen-vl-utils==0.0.14

# torch 由基础镜像提供（2.7.1+cu126）。这里绝对不要写 torch/torchvision，
# 否则 pip 会拉 PyPI 默认的 cu128 轮子，550 驱动跑不起来。

accelerate
peft
trl
datasets
modelscope
bitsandbytes          # QLoRA 4bit，16G 单卡的保底方案
av                    # 视频解码，比 decord 好装（decord 要源码编译）
pillow
tensorboard
jieba                 # swift 算中文 rouge 指标要用
rouge-chinese
nltk

```

封装一个docker-compose文件

```text
# 起停：docker compose up -d --build   /   docker compose down
# 进去：docker exec -it qwen3vl bash
#
name: qwen3vl

services:
  qwen3vl:
    image: qwen3vl-swift:cu126-torch2.7
    container_name: qwen3vl
    build:
      context: .
      dockerfile: Dockerfile
    restart: unless-stopped
    # 和本机其它容器保持一致：host 网络省端口账本（swift web-ui / swift deploy 直接可达）
    network_mode: host
    # DataLoader 多 worker 要大 /dev/shm，默认 64MB 不够
    ipc: host
    ulimits:
      memlock: -1
      stack: 67108864
    stdin_open: true
    tty: true
    working_dir: /workspace
    volumes:
      - ./:/workspace                 # 代码/脚本实时挂载，宿主上编辑容器里跑
      - ./models:/workspace/models    # 模型权重（ModelScope 缓存）
      - ./data:/workspace/data        # 数据集
      - ./output:/workspace/output    # checkpoint
    environment:
      - CUDA_VISIBLE_DEVICES=0
    deploy:
      resources:
        reservations:
          devices:
            - driver: nvidia
              count: all
              capabilities: [gpu]
    command: sleep infinity

```

## 开始微调

```text
IMAGE_MAX_TOKEN_NUM=1024 swift sft \
    --model Qwen/Qwen3-VL-2B-Instruct \
    --dataset /workspace/data/latex_ocr/train.jsonl \
    --val_dataset /workspace/data/latex_ocr/val.jsonl \
    --split_dataset_ratio 0 \
    --train_type lora \
    --lora_rank 8 \
    --lora_alpha 32 \
    --target_modules all-linear \
    --freeze_vit true \
    --freeze_aligner true \
    --torch_dtype bfloat16 \
    --attn_impl sdpa \
    --gradient_checkpointing true \
    --per_device_train_batch_size 1 \
    --gradient_accumulation_steps 16 \
    --learning_rate 1e-4 \
    --num_train_epochs 5 \
    --max_length 2048 \
    --warmup_ratio 0.05 \
    --logging_steps 10 \
    --eval_steps 30 \
    --save_steps 60 \
    --save_total_limit 3 \
    --dataloader_num_workers 4 \
    --output_dir /workspace/output/latex-ocr \
    --report_to tensorboard

```

950 条数据量不大，5 轮起步、盯着 eval_loss 走势；它开始回升就是过拟合了，用 save_total_limit 留下的早期 checkpoint。

## 合并模型文件

```text
swift export \
    --adapters /workspace/output/latex-ocr/v1-20260907-092442/checkpoint-60 \
    --merge_lora true

```

不用指定 --model，它从 checkpoint-60/args.json 里自己读基座是 Qwen3-VL-2B-Instruct。产物落在同级目录、名字加 -merged 后缀：/workspace/output/latex-ocr/v1-20260907-092442/checkpoint-60-merged/   4.0G

```text
4.0G  model.safetensors            ← 基座 + LoRA 已融进去，单一权重文件
1.7K  config.json
5.2K  chat_template.jinja          ← 对话模板
390   preprocessor_config.json     ← 图像预处理参数
817   video_preprocessor_config.json
11M   tokenizer.json  2.7M vocab.json  1.6M merges.txt  707 added_tokens.json 

```

这是标准 HuggingFace 目录，不再依赖 adapter，也不再依赖 ms-swift。

合并后怎么用

```text
M=/workspace/output/latex-ocr/v1-20260907-092442/checkpoint-60-merged
# swift：注意是 --model 不是 --adapters
swift infer --model $M --val_dataset /workspace/data/latex_ocr/val.jsonl \
    --max_new_tokens 512 --temperature 0 --result_path /workspace/output/merged_test.jsonl
# 起服务
swift deploy --model $M --served-model-name latex-ocr --port 8010

```
