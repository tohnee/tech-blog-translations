18个插件，把大肥鱼调成工作台

DeepSeeK Harness（简称DSH）出来之后，插件的生态圈可以说是非常丰富的，但如何寻找适合自己的插件呢？不管你有没有在DeepSeek Harness，都推荐你安装以下这些插件，直接让你性能提升90%！

话不多说，下面就开始今天的介绍！

0 1 dsh-marke—插件商店，装上它你就不用再翻 GitHub 了

其实DSH 本身是有内置的插件市场，并且也是支持按分类浏览去看截图、版本号的，使用时也能一键安装。那为何还要自己安装插件商店呢？

相信大家都知道，现在的插件生态可以说是非常乱的，一个集中入口的价值不在于它收录得全，而在于它帮你把「这个插件到底还在不在维护」这件事前置了。

0 2 universal-plugin-hub—把MCP、Skills、插件源集中一起管理

插件装多了，真正的问题不是装，是「我到底装了什么、哪个版本、从哪儿来的」。这个插件把 MCP 服务、Agent Skills 和第三方插件源统一管起来，还能添加 Git 源和 marketplace。

0 3 dsh-Go—DSH的Android 客户端，就不用局限于电脑

手机上直接跑 DSH，也能遥控电脑上那一台。

0 4 dsh-qqbot—腾讯官方出的QQ 通道

需要扫码绑定，然后用才能用QQ 私聊或群聊给本机的Agent 派活。

0 5 dsh-wechat—微信当第二客户端

文字、图片、文件、语音双向同步，锁屏了也能从手机拿本机的文件。

0 6 dsh-context—看清上下文里塞了什么

让我们一眼看到上下文吃了多少、压缩过哪些内容、子 Agent 在干什么。长任务跑飞，十次有八次是上下文被悄悄塞满。

0 7 dsh-reasoning-only-guard—防「只思考不说话」把会话搞死

防止模型推理完不给正文、这一轮直接空转，然后整个会话就废了。

0 8dsh-cost-meter—Token 仪表盘

最怕的不是 AI 不会干活，是它一直干、一直烧钱。实时看会话费用、Token 消耗和余额，任务跑偏能第一时间发现。

0 9 dsh-memory-palace—跨会话的长期记忆

把记忆做成文件式的「记忆宫殿」，会话结束不等于全部忘光，重要背景能带到下一次。

1 0 dsh-bili-scroll—让AI 替你刷B站

每天自动扫一轮B站，读取字幕、提取知识点、筛选出真正值得看的，最后还会给你一份Markdown 日报，值得的留意它还会@你。把咱们刷视频的时间交出去，把值得看的内容留下来。

1 1 dsh-bili-humanism—给Agent 立规矩

跟dsh-bili-scroll是配套关系：一个负责看，一个负责管住手。它本身不提供评论能力，点赞、投币、收藏、历史这些动作各自有独立开关且默认关闭，把精力放在内容学习和知识整理上，还会在专用的human-world.md里积累反思。

1 2 oh-story-dsh—写小说和短剧的工作流

剧本、分镜、图片/视频提示词各有对应文件，还能看制作进度，内置小说、短剧、游戏、视频解说四个工作台。

1 3 dsh-univer-office—真做表、真写文档、真改 PPT

接的是 Univer 的表格/文档引擎。关键设计是「先出草稿，你点确认才落盘」AI 改办公文件最怕它自作主张，这个确认环节比功能多少更为重要。

1 4 dsh-ego-browser—给Agent 接一个真浏览器

点击、填写、鼠标滚动、截图都能干，而且你全程能看见它在点哪里，卡在哪里，这样你也能自己上手继续。

1 5 dsh-genui—回答里直接长出可点的界面

不再是一段文字配一张表，而是把可点的表格、图片、表单直接嵌在聊天里当小面板用。

1 6 DSH-EasyRewrite—修改自己发过的消息

发错的会话条件不用重开就能直接对话，就地修改，也能撤回后整段重发。

1 7 dsh-pet—桌面宠物

生成一个桌面宠物，让它透明置顶趴在桌面上，还能思考、干活、报错、等你确认各种动画。

1 8 dsh-nekowhale-stickers—表情包知识库

开发者号称投了32万token，把大肥鱼的表情包整理成可调用的知识库。听起来无聊，但它解决的是「AI 只有一个语气」这件事有了表达方式，才能像个同事而不是直接查询接口。
