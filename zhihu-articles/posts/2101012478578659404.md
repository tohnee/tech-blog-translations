昨天晚上，DeepSeek Harness 团队甩出了 7 大「创造模式」的玩法。

从海报设计、视频剪辑，再到论文阅读插件，我们的想法和需求一句话就能变成可运行的插件。

先跟不熟悉 DSH 的朋友说下，它是 DeepSeek 开源的一个 Agent 工作台，类似于 Codex。

在这个创造模式下，我们只需描述清楚需求，发送过去它就会开发插件，做好后直接装上可用。

![](https://pica.zhimg.com/v2-121a394e59ed2f285a074b34b6305e5a_r.jpg)

若是装好的插件哪里做的不符合要求的，可以继续在对话里让它进行修改。

这正贴合了 DeepSeek Harness 当初定下的理念「一切皆插件」紧紧关联上。

官方团队还生怕我们不会用，昨晚发布的视频里 7 个演示案例的提示词，也一并公开给我们。

比如这个「**海报设计工作台**」，就可以从会话里打开，海报上的标题、文字、背景颜色都能改。

它用的就是 Harness 官网那个动态背景，我觉得这种小工具拿来改几张活动海报，倒是挺方便。

![](https://pic2.zhimg.com/v2-c97948bd109455c6e13784a476d2cf3b_r.jpg)

再看「**视频编辑工作台**」，预览窗口在上面，时间轴在下面，多段素材可以导进去，再剪辑、导出。

这些剪辑操作能直接在对话框里提出来，想让它怎么处理素材，怎么剪辑视频都可以。

经常需要看论文的朋友，也可以在 DSH 里做一个「**论文阅读器**」，放在 DSH 右侧菜单栏。

打开上传论文 PDF 文件后，会保留了原文的字体、图片和排版，即刻开始阅读。

当读到不懂的地方，可以选中那句话，在弹出的菜单里向 AI 提问，还能随后高亮或做笔记。

![](https://pic1.zhimg.com/v2-be6541d244b377258a2a6ea105743416_r.jpg)

上面三个案例的制作提示词，均可以在官方公开的提示词页面上找到。

另外，还有 3D 地标馆、Transformer 可视化、界面换肤和会话统计，感兴趣的可以一起看看。

提示词合集：[DeepSeek Harness creator mode demo prompts](https://cdn.deepseek.com/harness/dsh-creator-mode-prompt-collection-en.html)

![](https://pica.zhimg.com/v2-acc2eb4fa5705c0a79e63de1c509e23c_r.jpg)

还没安装 DeepSeek Harness 的朋友，可以到官网上下载提供的桌面端安装包。

支持 Windows、macOS 系统，也可以把项目地址发给 Agent，让它帮忙在本地部署网页使用。

第一次打开先把模型配好，除了能用 DeepSeek 外，也支持其他 OpenAI、Anthropic 等第三方模型提供商。

![](https://pic4.zhimg.com/v2-967702b1d5df9f010088bb2139f24dfb_r.jpg)

配好模型后，新建会话时把模式切到「创造模式」，可挑下上面一段提示词发过去尝试。

比如我挑了做一个「会话数据的统计」插件，做完之后直接在左侧栏新增了「用量」入口。

可以看到真实会话使用了多少 Token、以及估算到的价格成本，还能监测 CPU 与内存占用。

![](https://pica.zhimg.com/v2-f8d23cfb0e6a239fb8fa7cd1428d498c_r.jpg)

另外，当我们想把自己做好的插件公开给其他人使用，或者想找找 DSH 可用的开源插件。

可以安装一款专门给 DeepSeek Harness 做的社区插件市场，叫 **dsh-market**。

这个插件本身也是开源的，目前已经斩获了 10000+ Star，且收录了 8500+ 插件。

想要使用它，先在插件管理里搜索并安装 `dshmarket`，装好后就切换到插件市场。

GitHub：*[https://github.com/dsh-market/dsh-market](https://github.com/dsh-market/dsh-market)*

![](https://picx.zhimg.com/v2-84f4d4e52dcc111d5564dd31954a5ef3_r.jpg)

在里面可以按分类浏览、搜索，也能按热度和上新时间排序，挑选自己想要的插件一键安装。

装过的插件可以检查更新，也支持收藏和分组，插件多了也方便整理。

后面自己做出的插件，也可以先把代码公开到 GitHub，然后到 dsh-market 申请收录。

![](https://pic3.zhimg.com/v2-27d51d9bf7b3eefaa68ccee1f37ea4f4_r.jpg)

### **写在最后**

经过这一次了解，发现 DeepSeek Harness 现在的开源生态已相当丰富完善了。

大家都在围绕着它开源了很多插件，包括记忆、文档、编程、浏览器、远程访问等等方向。

这些第三方开源插件，也让 DSH 现在能做的事情越来越多，我觉得大家可以上手试试它了。

而且，这次的「创造模式」，更是把做插件的门槛再次降低了，人人都能手搓插件出来。

方便大家将 DSH 打造成自己专属的 Agent 工作台，也可以把插件代码开源，公开给他人使用。

我还是挺喜欢这种自由的，碰到自己想用的小功能时，随手就能自己的需求开发一个插件出来。

随着 DSH 的插件越来越丰富，是否也能追上 Claude Code 或 Codex，就让我们拭目以待。

GitHub 项目地址：*[https://github.com/deepseek-ai/deepseek-harness](https://github.com/deepseek-ai/deepseek-harness)*
