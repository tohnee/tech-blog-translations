## 从上一篇接着走：读得快，还剩一半

第六篇的清单里，“读得快”的含义是：写每个字，黑盒要把**全部权重**和这一路的**全部缓存**从内存里读一遍，却只为 1 个位置做一点点计算。第七篇把缓存那一半瘦下来了，权重那一半没变：本系列设定下是 0.91 GB，读一遍，出一个字。

要减少“读权重”的次数，思路只有两条：让权重变小（量化、稀疏，后面再说），或者**让读一遍权重，出不止一个字。**这一篇走第二条。

## 1 投机解码的概念与作用

投机解码（Speculative Decoding）是一种加速大语言模型推理的技术。其核心思想是利用小模型快速预测后续多个 Token，再由大模型一次性并行验证这些候选 Token，接受符合大模型概率分布的部分，对不符合的部分进行拒绝和重新采样。它利用 GPU 的并行计算能力，将传统大模型逐个 Token 串行生成的过程转化为批量验证，从而减少大模型重复执行 Decode 的次数，在保持原有生成质量的前提下，提高推理速度、降低响应延迟。

## 2 小模型每个位置都产生一个概率分布

假设上下文是：

```text
今天，OpenAI 发布了一项新的
```

小模型 Draft Model 预测下一个 Token 时，并不是只知道一个答案，而是得到词表上的概率分布。为了讲解，我们只展示其中三个候选：

| 候选 Token | 小模型概率 q |
| --- | --- |
| 技术 | 50% |
| 产品 | 25% |
| 研究 | 15% |
| 服务 | 10% |

假设小模型按自己的分布采样，抽中了“技术”。它把“技术”作为草稿 Token 交给验证流程，同时其概率分布信息仍用于后续的接受/拒绝计算。
