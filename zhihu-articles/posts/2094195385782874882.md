在这篇文章的最后只介绍了投机推理中的贪心取样法，但我们在使用大模型回答问题时，可以发现，其实一份完全相同的prompt，大模型的回答每次也不是完全相同。

这是因为大模型并不是贪心选择下一个token，而是“掷色子”按照一定概率分布进行选择下一个token。

如果这样的话，就会产生一个问题，如果不是贪心选择，那么用这种draft-model和大参数模型搭配的投机推理能不能和大参数模型独自生成的结果保持一致呢？

本文就来展示这件事情。

## 前置知识

### logits、概率表和 token ID，分别是什么？

先看普通的生成循环：

```python
logits = gpt2(inputs, params, n_head=n_head)
next_id = torch.argmax(logits[-1]).item()
```

在我的实现中，`logits` 是一个形状为 `[T, V]` 的张量：T 是输入 token 数，V 是词表大小。每一列对应一个 token ID，每一行给出读到相应位置后，对下一个 token 的评分。

因此，`logits[-1]` 是长度为 V 的评分向量。`argmax` 返回最大分数所在的下标，也就是选中的 token ID，它只与分词器有关，在我的代码中分词器不变，每个模型虽然参数不一样，但是词表大小和每个token ID对应的token都是同一个规则。

如果希望随机采样，需要先把评分变成概率：

```python
q = torch.softmax(logits[-1], dim=-1)
next_id = torch.multinomial(q, 1, generator=generator).item()
```

用softmax 把它们转换成非负、总和为 1 的概率表。随后 `multinomial` 按这些概率抽一个下标（抽的就是token ID）。

### 如何进行随机取样？

这份代码我就采用了两个有关随机取样的函数：`multinomial`和`rand`

同时在每次传入prompt时，也可以选择传入随机种子，并且构建每次生成专用的随机生成器。

而且需要保持这个随机生成器的传输，继续推进随机状态，而不是每次都随机过程都定义生成器。

```text
generator = torch.Generator(device="cpu")#初始构建随机生成器
...
next_id = torch.multinomial(p,num_samples=1,replacement=True,generator=generator).item()
#按概率抽取draft-model的候选token
...
random_tensor = torch.rand((), generator=generator).item()#决定这个候选token是否被接受
...
extra_id = torch.multinomial(p,num_samples=1,replacement=True,generator=generator).item()
#最理想情况下，K个候选都被接受，从目标模型的下一位置分布抽一个额外 token
...
new_id = torch.multinomial(p_reject, 1, generator=generator).item()
#按特殊的概率表来决定被拒绝状态下的token
```

## 关键部分

投机推理最关键的部分是两个地方

1. 如何判定这个候选token是否被接受？
2. 候选token不被接受，怎么选择当前位置的token？

**目标要求是让投机推理的模型生成效果和target模型生成效果保持一致**

**下面就是实现办法：**

$定义q_i(x)、p_i(x)分别是draft-model和target-model在第i个位置上，生成x这个token的概率，更加形象的说： p(x)=P_{\mathrm{target}}(x\mid c),q(x)=P_{\mathrm{draft}}(x\mid c)，其中c表示共同前缀（各种约束条件）$ **判定候选token是否被选择的公式：**

$$ \alpha_i(x)=min(1,\frac{p_i(x)}{q_i(x)}) $$ **当生成的随机数random_tensor>a，执行按照特殊公式定义概率：**

$$ r_i(x)=\frac{max(0,p_i(x)-q_i(x))}{\sum_{v\subset{词表中的所有token}}{max(0,p_i(v)-q_i(v))}} $$ 之后再进行抽取。

下面我们证明这样选择token的规则是严格满足要求的：

$只需证明：p_i(x)=P_i(x),其中P_i(x)定义为此处如此操作后token在i位置出现的概率，x表示为词表任意token$

$$ P_i(x)=q_i(x)\alpha_i(x)+\sum_{}^{}{q_i(v)}(1-\alpha_i(x))r(v) $$ 前面部分是x作为候选token被选择的概率，后面是在候选token被拒绝后重新取样被选择的概率。

化简，得：

$$ P_i(x)=min(q_i(x),p_i(x))+\sum_{}^{}{(q_i(v)-min(q_i(v),p_i(v)))}r(v)\Rightarrow min(q_i(x),p_i(x))+\sum_{}^{}{max(0,q_i(v)-p_i(v)))}r(v) $$ $$ p(v)-q(v) = \max\bigl(0,p(v)-q(v)\bigr) - \max\bigl(0,q(v)-p(v)\bigr) $$ $$ \sum_v\bigl(p(v)-q(v)\bigr) =\sum_v p(v)-\sum_v q(v) =1-1=0 $$

$$ 0=\sum_v\max\bigl(0,p(v)-q(v)\bigr) - \sum_v\max\bigl(0,q(v)-p(v)\bigr) $$ $$ 所以，\sum_{}^{}{max(0,q_i(v)-p_i(v)))}r(v)=max(0,p_i(x)-q_i(x)) $$ $$ 综上，P_i(x)=min(q_i(x),p_i(x))+max(0,p_i(x)-q_i(x))=p_i(x) $$ 因此，在每一步使用正确的条件分布，并按上述规则接受或补抽时，投机采样与目标模型单独采样具有相同的输出分布。即：

$$ \[ P_{\mathrm{spec}}(x\mid c)=P_{\mathrm{target}}(x\mid c). \] $$

## 源码：（里面需要下载一些解码器，分词器，模型；如果有感兴趣的朋友想试试我的这份代码，可以把这份代码发给AI，让AI生成相应需要的文件）

```text
import numpy as np
import torch
import time
import math
torch.set_printoptions(8)

def gelu(x): 
    return 0.5 * x * (1 + torch.tanh(math.sqrt(2 / math.pi) * torch.add(x, 0.044715 * torch.pow(x, 3)))) 
def softmax(x): 
    return torch.exp(x - torch.max(x, dim=-1, keepdim=True)[0]) / torch.sum(torch.exp(x - torch.max(x, dim=-1, keepdim=True)[0]), dim=-1, keepdim=True) 
def layer_norm(x, g_b, eps:float = 1e-5): 
    g, b = torch.Tensor(g_b['g']), torch.Tensor(g_b['b']) 
    m = torch.sum(x, dim=-1, keepdim=True) / x.shape[-1] 
    s = torch.sum(torch.pow(x - m, 2), dim=-1, keepdim=True) / x.shape[-1] 
    return g * (x - m) / torch.sqrt(s + eps) + b 
def linear(x, w_b): 
    w, b = w_b['w'], w_b['b'] 
    return x @ w + b 
def ffn(x, mlp):  
    w_b1, w_b2 = mlp['c_fc'], mlp['c_proj'] 
    return linear(gelu(linear(x, w_b1)), w_b2) 
 
def attention(q, k, v, mask, pastkvcache=None, head_idx=None, block_idx=None, hint=None):  
    if hint == "generate":
        if pastkvcache is None: 
            draft_kvcache[block_idx][head_idx][0] = k
            draft_kvcache[block_idx][head_idx][1] = v
            return softmax(q @ k.T / math.sqrt(k.shape[-1]) + mask) @ v
        else:
            draft_kvcache[block_idx][head_idx][0] = torch.cat((pastkvcache[block_idx][head_idx][0], k), dim=0) 
            draft_kvcache[block_idx][head_idx][1] = torch.cat((pastkvcache[block_idx][head_idx][1], v), dim=0)
            k = draft_kvcache[block_idx][head_idx][0]
            v = draft_kvcache[block_idx][head_idx][1]
            return softmax(q @ k.T / math.sqrt(k.shape[-1])) @ v
    else:
        if pastkvcache is None: 
            target_kvcache[block_idx][head_idx][0] = k
            target_kvcache[block_idx][head_idx][1] = v
            return softmax(q @ k.T / math.sqrt(k.shape[-1]) + mask) @ v
        else:
            target_kvcache[block_idx][head_idx][0] = torch.cat((pastkvcache[block_idx][head_idx][0], k), dim=0) 
            target_kvcache[block_idx][head_idx][1] = torch.cat((pastkvcache[block_idx][head_idx][1], v), dim=0)
            k = target_kvcache[block_idx][head_idx][0]
            v = target_kvcache[block_idx][head_idx][1]
            return softmax(q @ k.T / math.sqrt(k.shape[-1]) + mask) @ v
 
def mha(x, attn, n_head, pastkvcache=None, block_idx=None ,hint=None):  # [n_seq, n_embd] -> [n_seq, n_embd] 
    c_attn, c_proj = attn['c_attn'], attn['c_proj'] 
    # qkv projection 
    x = linear(x, c_attn)  # [n_seq, n_embd] -> [n_seq, 3*n_embd] 
    qkv = x.chunk(3, dim=-1)  # need to modify 
 
    # Split into heads 
    qkv_heads = [qkv_part.chunk(n_head, dim=-1) for qkv_part in qkv]  # 3 * [n_seq, n_embd] -> 3 * n_head * [n_seq, n_embd/n_head] 
    qkv_heads = list(zip(*qkv_heads))  # [3, n_head, n_seq, n_embd/n_head] 

    if hint == "generate":
        if pastkvcache is None: 
            causal_mask = torch.triu(torch.full((x.shape[0], x.shape[0]), float('-inf')), diagonal=1)
        else:
            causal_mask = None
    else:
        length_past = 0 if pastkvcache is None else pastkvcache[0][0][0].shape[0]
        total_length = length_past + x.shape[0]
        full_mask = torch.triu(torch.full((total_length, total_length), float('-inf')),diagonal=1)
        causal_mask = full_mask[length_past:, :]
 
    
    out_heads = [attention(q, k, v, causal_mask, pastkvcache, head_idx=head_idx, block_idx=block_idx, hint=hint) for head_idx, (q, k, v) in enumerate(qkv_heads)]  
     
    x = torch.cat(out_heads, dim=-1)  
    x = linear(x, c_proj)  # 组装到一起然后进行线性变换 
     
    return x 
 
def transformer_block(x, block, n_head, pastkvcache=None, block_idx=None, hint=None):  # [n_seq, n_embd] -> [n_seq, n_embd] 
    mlp, attn, ln_1, ln_2 = block['mlp'], block['attn'], block['ln_1'], block['ln_2'] 
    # multi-head causal self attention 
    x = x + mha(layer_norm(x, ln_1), attn, n_head=n_head, pastkvcache=pastkvcache, block_idx=block_idx, hint=hint)  # [n_seq, n_embd] -> [n_seq, n_embd] 
 
    # position-wise feed forward network 
    x = x + ffn(layer_norm(x, ln_2), mlp)  # [n_seq, n_embd] -> [n_seq, n_embd] 
 
    return x 
 
def gpt2(inputs, params, n_head, pastkvcache=None, hint=None, K=None):  # [n_seq] -> [n_seq, n_vocab] 
    wte, wpe, blocks, ln_f = params['wte'], params['wpe'], params['blocks'], params['ln_f'] 
    # token + positional embeddings 
    if hint == "generate":
        if pastkvcache is None: 
            x = wte[inputs] + wpe[range(len(inputs))] 
        else: 
            x = wte[inputs[-1:]] + wpe[len(inputs)-1:len(inputs)]
    else:
        if pastkvcache is None: 
            x = wte[inputs] + wpe[range(len(inputs))]
        else:
            new_len = K + 1
            x = (wte[inputs[-new_len:]]+ wpe[len(inputs)-new_len : len(inputs)])
             
    
    x = torch.Tensor(x) 
    if hint is not None:
        if hint == "generate":
            global draft_kvcache 
            draft_kvcache = [[[None, None] for _ in range(n_head)] for _ in range(len(blocks))]
        elif hint == "greedy_speculative_generate":
            global target_kvcache
            target_kvcache = [[[None, None] for _ in range(n_head)] for _ in range(len(blocks))]
    for block_idx, block in enumerate(blocks): 
        x = transformer_block(x, block, n_head=n_head, pastkvcache=pastkvcache, block_idx=block_idx, hint=hint)  
    # projection to vocab 
    x = layer_norm(x, ln_f) 
    return x @ wte.T 

def generate(inputs, params, n_head, n_tokens_to_generate, pastkvcache=None, generator=None): 
    from tqdm import tqdm 
    hint = "generate"
    draft_logits=[]
    for _ in range(n_tokens_to_generate):  # auto-regressive decode loop 
        logits = gpt2(inputs, params, n_head=n_head, pastkvcache=pastkvcache, hint=hint)  # model forward pass 
        pastkvcache = draft_kvcache
        p=torch.softmax(logits[-1],dim=-1)
        next_id = torch.multinomial(p,num_samples=1,replacement=True,generator=generator).item() #实行随机取样
        inputs.append(int(next_id))  # append prediction to input
        draft_logits.append(logits[-1]) 
 
    return inputs[len(inputs) - n_tokens_to_generate :],torch.stack(draft_logits)  # only return generated ids 

def greedy_speculative_generate(inputs, draft_params, target_params, hparams_draft, hparams_target, n_tokens_to_generate, K, seed=2147483647):
    # Create once per request; never reseed inside the decoding loop.
    # All model tensors in this implementation are on CPU.
    generator = torch.Generator(device="cpu")
    if seed is None:
        generator.seed()
    else:
        generator.manual_seed(seed)
    if K < 1:
        raise ValueError("K must be >= 1")
    generated_ids = []
    current_inputs = list(inputs)
    global draft_kvcache 
    draft_kvcache = None
    global target_kvcache
    target_kvcache = None
    hint = "greedy_speculative_generate"
    total_accepted_tokens = 0
    total_proposed_tokens = 0
    num_verify_steps = 0
    acceptance_rate = 0.0
    while len(generated_ids) < n_tokens_to_generate:
        K=min(K, n_tokens_to_generate - len(generated_ids)) #这里做一个处理，防止K大于剩余需要生成的token数
        total_proposed_tokens += K
        current_inputs_copy=list(current_inputs)#做一个副本
        output_ids ,draft_logits= list(generate(current_inputs_copy, draft_params, hparams_draft["n_head"], K, pastkvcache=draft_kvcache, generator=generator))#小模型进行预测，同时更新draft_kvcache
        target_logits = gpt2(current_inputs_copy, target_params, n_head=hparams_target["n_head"], pastkvcache=target_kvcache, hint=hint,K=K)  #大模型进行score
        num_verify_steps+=1
        target_logits = target_logits[-K-1:]  # 截取最后（K+1）个token的logits
        for _  in range(K):  
            x=output_ids[_]
            p=torch.softmax(target_logits[_],dim=-1)
            q=torch.softmax(draft_logits[_],dim=-1)
            a=torch.clamp(p[x]/q[x], max=1.0).item()
            random_tensor = torch.rand((), generator=generator).item()#掷色子，确定这个候选token是否被选择
            if random_tensor<a:#接受的情况
                total_accepted_tokens += 1
                current_inputs.append(int(x))  
                generated_ids.append(int(x))
                # 当draft token和target token一致时，直接append,并且记录接受的token数
                if _ == K - 1:
                    if len(generated_ids) < n_tokens_to_generate:#这里我们需要判断一下，防止生成的token数超过n_tokens_to_generate
                        _ = gpt2(current_inputs,draft_params,n_head=hparams_draft["n_head"],pastkvcache=draft_kvcache,hint="generate")#更新draft_kvcache
                        p=torch.softmax(target_logits[-1],dim=-1)
                        extra_id = torch.multinomial(p,num_samples=1,replacement=True,generator=generator).item()
                        current_inputs.append(int(extra_id))
                        generated_ids.append(int(extra_id))#添加最理想情况下，由大模型产生的token
            else:#被拒绝时的采样逻辑
                p_reject = torch.clamp(p - q, min=0)
                p_reject = p_reject / p_reject.sum()

                # 使用拒绝采样来生成新的token
                new_id = torch.multinomial(p_reject,num_samples=1,replacement=True,generator=generator).item()
                current_inputs.append(int(new_id))
                generated_ids.append(int(new_id))

                keep_len = len(current_inputs) - 1
                for layer_idx in range(len(target_kvcache)):
                    for head_idx in range(len(target_kvcache[layer_idx])):
                        target_kvcache[layer_idx][head_idx][0] = target_kvcache[layer_idx][head_idx][0][:keep_len]  
                        target_kvcache[layer_idx][head_idx][1] = target_kvcache[layer_idx][head_idx][1][:keep_len]
                for layer_idx in range(len(draft_kvcache)):  
                    for head_idx in range(len(draft_kvcache[layer_idx])):  
                        draft_kvcache[layer_idx][head_idx][0] = draft_kvcache[layer_idx][head_idx][0][:keep_len]  
                        draft_kvcache[layer_idx][head_idx][1] = draft_kvcache[layer_idx][head_idx][1][:keep_len]
                
                break  # 截停，添加大模型的正确token，并且不再继续添加
    if total_proposed_tokens > 0:
        acceptance_rate = total_accepted_tokens / total_proposed_tokens#计算接受度
        
    print(f"Acceptance rate: {acceptance_rate:.4f}")
    print(f"Number of verification steps: {num_verify_steps}")
    return generated_ids

def main(prompt: str, n_tokens_to_generate: int = 5, draft_model_size: str = "124M",target_model_size: str = "1558M", models_dir: str = "models", K: int = 4, seed: int = 2147483647):
    from utils import load_encoder_hparams_and_params

    encoder, hparams_target, params_target = load_encoder_hparams_and_params(target_model_size, models_dir)
    _,hparams_draft, draft_params= load_encoder_hparams_and_params(draft_model_size, "models")

    input_ids = encoder.encode(prompt)

    assert len(input_ids) + n_tokens_to_generate < hparams_target["n_ctx"]

    start = time.time()
    output_ids = greedy_speculative_generate(input_ids, draft_params, params_target, hparams_draft, hparams_target, n_tokens_to_generate, K, seed=seed)
    end = time.time()
    print(f"Time taken to greedy_speculative_generate{n_tokens_to_generate} tokens: {end - start:.2f}s")
    

    # decode the ids back into a string
    output_text = encoder.decode(output_ids)
    return output_text

if __name__ == "__main__":
    import fire
    fire.Fire(main)
```
