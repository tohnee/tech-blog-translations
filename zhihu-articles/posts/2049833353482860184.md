又名： Vibe Coding 小白入门指北（2026.06版）

### 工具选型

- VS Code + 插件
- CodeX
- Claude Code

在2026年6月的今天，推荐最简单的Vibe Coding 工具，

我依旧推荐是 **"VS Code + 插件"。**

无他。在非科学上网情况下，它是最容易安装配置的。

无他。在可科学上网的情况下，它可以搭配CodeX 、Claude Code使用。

无他。在使用国内模型情况下，各种平台都有对应的支持教程。

So，选它没错。

### VS Code

下载地址：

[Download Visual Studio Code](https://code.visualstudio.com/download)

同时，把Git 也安装一下（不需要了解它，安装了就可以。）

[https://git-scm.com/install/windows](https://git-scm.com/install/windows)

安装都没撒，都下一步下一步就完事了。

如果是macOS的，Git安装可能麻烦点，不过自己折腾下也没撒。

[https://git-scm.com/install/mac](https://git-scm.com/install/mac)

### CodeX | Claude Code 安装

[https://developers.openai.com/codex/app](https://developers.openai.com/codex/app)

[https://code.claude.com/docs/zh-CN/overview](https://code.claude.com/docs/zh-CN/overview)

三选一就可以，起步阶段没必要每个都安装，后面可以自己折腾。

左侧边栏： **资源管理器** 、搜索、Git分支、运行和调试、远程资源（你不一定有）、 **扩展插件**

- 对应的就是电脑的一个文件夹
- 这里可以放你的数据、图片、程序代码
- 结果文件一般也会放在这里

### Session 会话

在网页端，一般和GPT 或者Kimi聊天，一个事情开一个聊天对话。

在VS Code 的AI Agent插件里面，如 Kimi Code 或者CodeX，也是差不多的逻辑。

但是，这里要先有个概念，我们在VS Code中打开了一个文件夹，这个文件夹对应的是，我们这个项目的所有文件。

如：一个产品的需求和代码、一个实验数据分析、一个论文报告、一个数据处理任务等等。

然后，在这个会话对话框里面，开始指挥AI去开始干活了。
