**核心结论**

FSDP2 在训练时会按需收集完整权重，用完后释放回 shard 状态。

```text
all-gather 权重 -> 计算 -> reshard/free 权重
```

开启重计算后，backward 阶段会重新执行一遍 forward 来恢复中间激活。这个 recompute forward 本身也会触发 FSDP 的 `pre_forward`，所以它会负责重新 all-gather 权重。

**不加重计算时**

```text
原始 forward:
  all-gather 权重
  forward compute
  reshard/free full weight

backward:
  all-gather 权重
  backward compute
  reduce-scatter grad
  reshard/free full weight
```

因为 forward 后完整权重已经释放，所以 backward 到该 FSDP module 时，需要重新 all-gather。

**加重计算时**

```text
原始 forward:
  all-gather 权重
  forward compute
  不保存中间激活
  reshard/free full weight

backward 到 checkpoint 区域:
  all-gather 权重
  recompute forward
  保留 full weight
  backward compute
  reduce-scatter grad
  reshard/free full weight
```

这里的关键是：**backward 中的 recompute forward 已经 all-gather 了权重，重算完成后不会立刻 reshard/free，因此真正开始 backward compute 时可以直接复用这份完整权重，不会再次 all-gather。**

**FSDP2 如何判断是不是重计算**

FSDP2 并不是直接判断“是否开启了 activation checkpointing”，而是判断当前 forward 是否发生在 autograd backward 过程中。

实现上可以理解为：

```text
def is_bw() -> bool:
    return torch._C._current_graph_task_id() != -1
```

普通 forward：

```text
is_bw() == False
```

checkpoint recompute forward：

```text
is_bw() == True
```

FSDP2 的 `post_forward()` 逻辑可简化为：

```text
def post_forward():
    if not is_bw():
        reshard()
        record_post_forward_order()

    training_state = IDLE
```

所以：

```text
普通 forward 结束:
  post_forward 会 reshard/free full weight

backward 中的 recompute forward 结束:
  post_forward 不 reshard
  full weight 保留给马上到来的 backward compute
```

**为什么真正 backward 不会再次 all-gather**

因为 FSDP 的 `unshard()` 是按当前参数状态判断的，可以理解为幂等操作：

```text
def unshard():
    if already_unsharded:
        return
    all_gather()
```

因此：

```text
无重计算:
  backward pre-hook 调用 unshard()
  发现参数是 sharded
  执行 all-gather

有重计算:
  recompute forward 的 pre_forward 已经 unshard()
  recompute forward 的 post_forward 没有 reshard()
  backward pre-hook 再调用 unshard()
  发现参数已经是 unsharded
  直接 return，不再 all-gather
```

**梯度收集和释放过程**

backward 真正计算参数梯度后，FSDP 会对梯度做通信聚合：

```text
local grad / partial full grad
  -> reduce-scatter
  -> 每个 rank 只保留自己的 grad shard
```

之后完整权重会被释放：

```text
backward compute
  -> reduce-scatter grad
  -> reshard/free full weight
```

**最终时间线**

无重计算：

```text
FWD block:
  all-gather param
  forward
  reshard param

BWD block:
  all-gather param
  backward
  reduce-scatter grad
  reshard param
```

有重计算：

```text
FWD block:
  all-gather param
  forward
  reshard param

BWD block with checkpoint:
  all-gather param
  recompute forward
  keep full param
  backward
  reduce-scatter grad
  reshard param
```

一句话总结：

**FSDP2 不需要显式知道“这里用了重计算”。它只要发现当前 forward 发生在 backward graph task 里，就不在 recompute forward 后释放完整权重。这样 recompute forward 的 all-gather 可以直接服务随后的 backward，避免重复 all-gather。**
