## 数据并行的局限

上一篇文章提到的数据并行虽然通过all-reduce操作将梯度同步与反向传播计算重叠，从而节省时间，但当我们不断增加GPU数量时，它们间的协调开销会显著增长，网络通信需求也变得过于庞大，以至于其带来的收益被抵消。结果是，每增加一块的新GPU，整体配置的效率会越来越低。

另外，数据并行的前提是能够将一个输入样本的前向传播放入GPU内存中(既包括模型实例本身占用的内存以及样本训练过程中的激活值内存等)，对于更大的模型，无法将其放入单个GPU内存中。因此，接下来介绍解决该问题的第一个方法张量并行。

## 张量并行

不仅对权重、参数、优化器状态、激活值进行分片，而且在计算前无需将所有分片重新聚合。

### a）原理

张量并行利用了矩阵乘法A*B的数学特性，实现这种并行化的核心等式如下：

![](https://pic4.zhimg.com/v2-1eb0c397786efb468d7837eb14c3fbaf_r.jpg)

从上述公式可看出，通过分别乘以矩阵B的每一列或每一行然后合并结果，可实现矩阵乘积。神经网络中，矩阵乘法可表示为X*W，其中X表示输入或激活值，W表示线性层的权重，示例如下：

![](https://pic2.zhimg.com/v2-01c16e9cee3f8944cf5fad3585b2490d_r.jpg)

张量并行中，张量会沿着某个维度被切分为N个分片，并分发到N个GPU上，矩阵可按照列后行进行切分，从而形成列并行或行并行；

### b）列切分

权重矩阵W按列切分后，将它和完整的输入矩阵X复制到每个工作节点(即GPU)上，这需要broadcast操作；每个节点使用局部的权重分片与输入进行矩阵乘法运算，最后通过all-gather操作将各节点的计算结果拼接起来，得到完整的输出。示例如下：

![](https://pic3.zhimg.com/v2-72a422511ad88ba12c0973622227453a_r.jpg)

### c）行切分

将权重矩阵W按行切分后，再将输入X按照列切分，使用scatter操作(而不是行切分中的broadcast操作)，每个工作节点(即GPU)完成局部结果的计算，通过all-reduce操作将所有节点的结果相加得到最终输出。示例如下：

![](https://pic4.zhimg.com/v2-af58a191f8babc7a975f30d77a00951f_r.jpg)

## Transformer张量并行

一个Transformer模型主要由两个核心构建块组成：前馈多层感知机(Feedforward MLP)和多头注意力。可分别对这两部分应用张量并行。

### a）前馈多层感知机张量并行

可通过列并行->行并行实现张量并行化。这种做法相当于在前向传播中，进行一次广播来复制输入，然后执行一次all-reduce操作。

实际训练过程中，这个广播操作通常是不需要的，因为我们可保证输入在不同的张量并行进程间已经是同步的，这种“列并行->行并行”比“行并行->列并行”更高效，可省去两次切分间的all-reduce通信，从而提高整体效率；

![](https://pic2.zhimg.com/v2-040c780bc0e303054911facaefb38701_r.jpg)

### b）多头注意力张量并行

query、key和value矩阵采用列切分，而输出投影层按照行切分；

![](https://pica.zhimg.com/v2-952184f64d714853f698142009f70f30_r.jpg)

在attention模块中，可沿着num_attention_heads(注意力头数量)这一维度进行并行化，因为每个注意力头的计算彼此独立(不过张量并行度不应超过注意力头的数量，因为在实现中，QKV投影是沿着num_attention_heads这一维度切分的)；在MLP模块中，可沿着hidden_dim(隐藏层维度)进行并行化，因为前馈网络中该维度的操作也是相互独立的。

### c）序列并行

张量并行并不是训练的万能方案，因为模型计算路径中引入了多种分布式通信操作，这些通信很难像ZeRO完全被计算过程隐藏或重叠；

![](https://pic1.zhimg.com/v2-35172b54e41553272f8538d8ec20858c_r.jpg)

每一层解码器的前向传播中，会遇到一个同步点(即all-reduce操作)，这一步无法与计算重叠进行。这些通信开销是必须的，因为我们需要在多个张量并行间合并各自的部分计算结果，然后才能最终的LayerNorm操作；

张量并行确实减少矩阵乘法部分的激活值内存，因为中间激活值分片存储在多个GPU上，但LayerNorm和Dropout这样的操作仍然需要完整的激活值，意味着无法完全获得理论上的内存节省效果。

当张量并行规模扩展超过8个GPU时，通信开销尤为明显。单个节点内，张量并行可通过高速的NVLink互连，但跨节点时，需依赖较慢的网络连接，当张量并行度从8扩展到16时，性能显著下降，扩展到32时，下降更为剧烈，在更高并行度下，通信开销变得极高，迅速成为主导训练时间的主要因素。

将模型中未被张量并行处理的部分(如dropout和LayerNorm等)的激活值和计算，沿着输入序列维度(而非隐藏层维度)进行切分，即序列并行。之所以按输入序列维度而非隐藏层维度划分，是因为这些操作在正确计算时需要访问完整的隐藏层维度，如LayerNorm需要完整的隐藏层维度来计算均值和方差

![](https://pic1.zhimg.com/v2-3307f319c7ed585d48ae5b1dd18ac188_r.jpg)

下面是通过不同的集合通信操作(标记f和g)在张量并行区域和序列并行区域间进行切换：

![](https://pic2.zhimg.com/v2-e889895fc3806870fe7c169fbf545769_r.jpg)

左侧的张量并行，前向传播过程中f是一个空操作(激活值已经在各个进程间被复制)，f*是一个all-reduce操作(用于同步激活值确保计算的正确性)，反向传播过程中f*是一个空操作(梯度已经在各个进程间被复制)，f是一次all-reduce操作(用于同步梯度)；

右侧的序列并行，依次执行如下操作(详细如下图)：

LayerNorm层(序列并行)，输入张量X(shape为(b, s, h))沿序列维度切分(如X1*和X2*，shape为(b/ s/2, h))，分发到各个GPU上，每个GPU独立对其负责的序列片段执行LayerNorm计算，得到分片输出(如Y1*和Y2*)。

第一次转换(序列并行->张量并行)：执行g操作(即all-gather)，将LayerNorm层的分片输出(如Y1和Y2)沿序列维度重新聚合，恢复为完整序列长度，得到完整的输出Y(shape为(b, s, h))，之所以沿序列维度重新聚合，是因为后续的列线性层需要完整的隐藏层维度h才能进行正确得矩阵运算；

第一个线性层(张量并行)：A1和A2是列线性层，因此将输入Y沿隐藏层h进行切分；每个GPU使用对应的权重分片对局部的输入进行矩阵乘法，然后独立应用GELU激活函数；输出Z1*和Z2*(shape为(b, s, h/2))，即每个GPU只持有输出张量在隐藏层维度的一半；

第二个线性层(张量并行)：B1和B2是行线性层，因此对Z1*和Z2*分别进行矩阵乘法运算，恢复完整的隐藏层维度h；每个GPU的输出W1和W2的shape为(b, s, h)，但由于输入在隐藏层维度上被切分，这两个输出实际上是最终结果的分片，需要通过求和来合并；通过all-reduce操作实现跨GPU的求和，得到最终的shape为(b, s, h)的张量；

最终转换(张量并行->序列并行)：执行g*操作(即reduce-scatter)，对来自前一线性层的输出W1和W2在对应位置进行求和(保证线性计算正确性)，然后将求和后的结果沿序列维度进行切分(scatter)；经过reduce-scatter后，得到W1*和W2*(shape为(b, s/2, h))，即每个GPU仅保留序列的一半，但拥有完整的隐藏层维度h；

![](https://pic1.zhimg.com/v2-87defe0c5d52e1224d0908d6c20b9fc4_r.jpg)

序列并行减少了需要存储的激活值的内存，仅使用张量并行，在多个阶段需要存储shape为(b, s, h)的激活值，使用序列并行后，存储激活值内存大小减少为b*s*h/tp，其中tp表示序列并行度；

在原始的张并行的前向传播过程中，每个transformer模块包含两次all-reduce操作，而在序列并行中，每个transformer模块包含两次all-gather和两次reduce-scatter操作，因此序列并行的通信操作数量是张量并行的两倍，但由于一个all-reduce操作可分解为一次all-gather和一次reduce-scatter，在通信成本上它们实际上是等价的，反向传播也是类似。

![](https://pic3.zhimg.com/v2-6e9b9344224dbc37eaa0ca6951c833cc_r.jpg)

较高的并行度虽然可通过减少激活值内存使得能够处理更大的batch size，但也会降低每个GPU的吞吐量(并行度超过单个节点可用GPU数量的阈值后，需要跨节点通信)；

## 代码实现

将嵌入层(即embedding参数)按行进行切分(即VocabParallelEmbedding类型)，将注意力层的query、key和value投影矩阵(即q_proj、k_proj、v_proj)按列进行划分(即ColumnParallelLinear类型)，输出投影矩阵(即out_proj)按行进行切分(即RowParallelLinear类型)，前向反馈层的up_proj和gate_proj按列进行划分(即ColumnParallelLinear类型)，down_proj按行划分(即RowParallelLinear)，将最后的投影层(即final_proj)按列进行划分(即ColumnParallelLinear)，详见apply_tensor_parallel函数；

### a）VocabParallelEmbedding

初始化：num_embeddings表示嵌入的embedding数，embedding_dim表示embedding维度，vocab_start_index和vocab_end_index记录每个张量并行进程处理的embedding的起始下标和结束下标(总embedding数num_embeddings除以张量并行进程数，得到每个进程需要处理的embedding数，这样每个进程根据进程rank得到分配给它的连续多个embedding)；初始化一个shape为(num_embeddings，embedding_dim)的空张量，并按照均值为0.0，方差为1.0进行随机初始化，然后按行进行切分，每个张量并行进程根据进程rank获取对应的子张量；

前向传播：每个张量并行进程从输入中挑选出属于该进程需要处理的token id(得到一个输入mask)；将输入的token id减去当前进程处理的起始token索引(即vocab_start_idx)，得到输入token在当前进程中的索引；根据输入mask将不属于当前进程处理的token id设置为0；通过F.embedding从当前进程中获取输入token对应的embedding(不属于当前进程处理的token的embedding全都设置为0.0)；最后，通过dist.all_reduce操作收集从各个进程输出的embedding；

```text
class VocabParallelEmbedding(nn.Module):
    def __init__(
        self,
        num_embeddings: int,
        embedding_dim: int,
        padding_idx: Optional[int] = None,
        max_norm: Optional[float] = None,
        norm_type: float = 2.0,
        scale_grad_by_freq: bool = False,
        sparse: bool = False
    ):
        super(VocabParallelEmbedding, self).__init__()

        self.tp_world_size = pgm.process_group_manager.tp_world_size
        self.tp_rank = pgm.process_group_manager.tp_rank

        self.num_embeddings = num_embeddings
        self.embedding_dim = embedding_dim
        self.padding_idx = padding_idx
        self.max_norm = max_norm
        self.norm_type = norm_type
        self.scale_grad_by_freq = scale_grad_by_freq
        self.sparse = sparse
        # Divide the weight matrix along the vocaburaly dimension.
        self.vocab_start_index, self.vocab_end_index = self._vocab_range_from_global_vocab_size(
            self.num_embeddings, pgm.process_group_manager.tp_rank, pgm.process_group_manager.tp_world_size
        )
        self.num_embeddings_per_partition = self.vocab_end_index - self.vocab_start_index

        self.weight = nn.Parameter(torch.Tensor(self.num_embeddings_per_partition, self.embedding_dim))

        self.reset_parameters()
    
    def _vocab_range_from_global_vocab_size(self, global_vocab_size: int, rank: int, world_size: int):
        #TODO: do some padding for the vocab size
        assert global_vocab_size % world_size == 0, f"{global_vocab_size} is not divisible by {world_size}"
        per_partition_vocab_size = global_vocab_size // world_size
        # vocab_range_from_per_partition_vocab_size
        index_f = rank * per_partition_vocab_size
        index_l = index_f + per_partition_vocab_size
        return index_f, index_l

    def reset_parameters(self):
        master_weight = torch.empty(
            self.num_embeddings, 
            self.embedding_dim, 
            dtype=self.weight.dtype,
            device=self.weight.device, 
            requires_grad=False
        )
        torch.nn.init.normal_(master_weight, mean=0.0, std=1.0)
        # Split the model into size of self.num_embeddings_per_partition
        weight_list = torch.split(master_weight, self.num_embeddings_per_partition, dim=0)
        self.weight.data = weight_list[self.tp_rank].contiguous()

    def forward(self, x):
        """
        Performs an embedding lookup for input tokens in the parallelized embedding layer
        1. Masks tokens that fall outside the specified vocabulary range and adjusts the input
        2. Performs embedding lookups for valid tokens, setting embeddings of out-of-vocabulary tokens to zero
        3. Reduces the embeddings across model parallel GPUs using all-reduce for synchronization
        """
        # Build the mask for out-of-vocabulary tokens.
        input_mask = (x < self.vocab_start_index) | (x >= self.vocab_end_index)
        # Mask the input.
        masked_input = x.clone() - self.vocab_start_index
        masked_input[input_mask] = 0
        # Get the embeddings for the valid tokens.
        output_parallel = F.embedding(
            masked_input,
            self.weight,
            self.padding_idx,
            self.max_norm,
            self.norm_type,
            self.scale_grad_by_freq,
            self.sparse,
        )
        # Embedding of out-of-vocabulary tokens is set to 0.
        output_parallel[input_mask, :] = 0.0
        output = ReduceFromModelParallelRegion.apply(output_parallel)
        return output
```

### b）ColumnParallelLinear

初始化：初始化一个shape为(in_features, out_features)的空张量，并进行随机初始化，然后按列进行切分，每个进程根据进程rank获取对应的子张量，shape为(in_features, out_features/tp_world_size)，其中tp_world_size表示张量并行进程数；

前向传播：每个进程将输入x乘以该进程的子张量后，加上bias，并返回结果；

```text
class ColumnParallelLinear(torch.nn.Module):
    """Column Parallel Linear layer
    Y = XW + b, where weight matrix W is parallelized along its second dimension. W = [W_1, ..., W_p]
    This module returns the results of Y_i = XW_i + b_i in the forward method, Y_i is parallelized in the second dimension.
    Arguments:
        in_features: first dimension of weight matrix W.
        out_features: second dimension of weight matrix W.
        bias: If true, add bias
        init_method: method to initialize weights
        gather_output: If true, gather the output from all the partitions. This is used for the last linear layer
    """

    def __init__(
        self,
        in_features: int,
        out_features: int,
        bias: bool = False,
        gather_output: bool = False,
        async_all_reduce: bool = False,
    ) -> None:
        super(ColumnParallelLinear, self).__init__()

        self.tp_world_size = pgm.process_group_manager.tp_world_size
        self.tp_rank = pgm.process_group_manager.tp_rank 

        self.in_features = in_features
        self.out_features = out_features
        assert out_features % self.tp_world_size == 0, "Hidden dimension must be divisible by the tensor parallel world size"
        self.output_size_per_partition = out_features // self.tp_world_size
        self.gather_output = gather_output
        self.async_all_reduce = async_all_reduce
        # Allocate space for the weight and bias
        # Note: torch.nn.functional.linear performs XW^T + b so we exchange the order of dimensions
        self.weight = nn.Parameter(torch.Tensor(self.output_size_per_partition, self.in_features)) # W_i
        if bias:
            self.bias = nn.Parameter(torch.Tensor(self.output_size_per_partition))
            with torch.no_grad():
                self.bias.zero_()
        else:
            self.register_parameter("bias", None)

        self.reset_parameters()

    def reset_parameters(self):
        # Initialize weight tensor with the default initialization method used for nn.Linear in PyTorch
        master_weight = torch.empty(
            self.out_features, 
            self.in_features, 
            dtype=self.weight.dtype,
            device=self.weight.device,
            requires_grad=False
        )
        
        # Calculate bound based on master weight's input dimension
        k = 1 / master_weight.size(1)
        bound = math.sqrt(k)
        torch.nn.init.uniform_(master_weight, -bound, bound)
        
        # Split the model into size of self.output_size_per_partition
        weight_list = torch.split(master_weight, self.output_size_per_partition, dim=0)
        self.weight.data = weight_list[self.tp_rank].contiguous()
    
    def forward(self, x: torch.Tensor) -> torch.Tensor:  
        if self.async_all_reduce:
            output = linear_with_async_all_reduce(x, self.weight, self.bias) 
        else:
            output = linear_with_all_reduce(x, self.weight, self.bias) 
        if self.gather_output:
            output = GatherFromModelParallelRegion.apply(output)
        return output          
```

### c）RowParallelLinear

初始化：初始化一个shape为(in_features, out_features)的空张量，并进行随机初始化，然后按行进行切分，每个进程根据进程rank获取对应的子张量，shape为(in_features/tp_world_size, out_features)，其中tp_world_size表示张量并行进程数；

前向传播：每个进程将输入x乘以该进程的子张量后，加上bias，并返回结果；

```text
class RowParallelLinear(nn.Module):
    """Linear layer with row parallelism.
    Y = XW + b. W is parallelized along its first dimension and X along its second dimension as:
               -   -
              | W_1 |
              | .   |
          W = | .   |        X = [X_1, ..., X_p]
              | .   |
              | W_p |
               -   -
    We assume that X is already parallelized. This is the case after ColumnParallelLinear.
    This module returns the results of Y = sum(X_i * W_i + b_i) in the forward method.
    Arguments:
        in_features: first dimension of matrix W.
        out_features: second dimension of matrix W.
        bias: If true, add bias
        init_method: method to initialize weights.
    """
    def __init__(self, in_features: int, out_features: int, bias: bool):
        super(RowParallelLinear, self).__init__()

        self.tp_world_size = pgm.process_group_manager.tp_world_size
        self.tp_rank = pgm.process_group_manager.tp_rank 

        self.in_features = in_features
        self.out_features = out_features
        assert in_features % self.tp_world_size == 0, "Hidden dimension must be divisible by the tensor parallel world size"
        self.input_size_per_partition = in_features // self.tp_world_size

        self.weight = nn.Parameter(torch.Tensor(self.out_features, self.input_size_per_partition))
        if bias:
            self.bias = nn.Parameter(torch.Tensor(self.out_features))
            # Always initialize bias to zero.
            with torch.no_grad():
                self.bias.zero_()
        else:
            self.register_parameter("bias", None)

        self.reset_parameters()

    def reset_parameters(self):
        # Initialize weight tensor with same dtype and device as self.weight
        master_weight = torch.empty(
            self.out_features, 
            self.in_features, 
            dtype=self.weight.dtype,
            device=self.weight.device,
            requires_grad=False
        )
        
        # Calculate bound based on master weight's input dimension
        k = 1 / master_weight.size(1)
        bound = math.sqrt(k)    
        torch.nn.init.uniform_(master_weight, -bound, bound)
        
        # Split the model into size of self.input_size_per_partition
        weight_list = torch.split(master_weight, self.input_size_per_partition, dim=1)
        self.weight.data = weight_list[self.tp_rank].contiguous()

    def forward(self, x):
        # X_i * W_i^T + b
        output_parallel = F.linear(x, self.weight)
        # All-reduce across all the partitions.
        output = ReduceFromModelParallelRegion.apply(output_parallel)
        return output if self.bias is None else output + self.bias
```
