## 多模态理解和生成大模型技术发展综述

下面按时间线梳理近几年 **多模态理解与生成大模型** 的发展，包括：多模态理解、LLM、图像生成、视频生成、音频/音乐生成，并重点分析架构设计、训练方式、模块设计、业界主流方案、问题与趋势。

本文重点总结多模态理解和生成大模型的技术发展、当前问题与未来趋势：技术上，领域从 Transformer、CLIP、ViT、LLM 和扩散模型等基础模块出发，逐步演进到视觉编码器 + LLM、统一多模态 token、Diffusion Transformer、Flow Matching、视频世界模型和实时 Omni 交互系统；应用上，能力从图文理解、图像生成扩展到长视频理解、视频生成、音频音乐生成和多模态 Agent；当前主要问题集中在多模态幻觉、细粒度视觉理解不足、长视频一致性、生成可控性、物理世界建模、版权安全和高成本部署；未来趋势则是原生多模态统一架构、理解与生成融合、Video World Model、Flow/DiT/MoE 化、实时交互、可控编辑和数据治理体系化。

## 一、总体技术脉络

过去几年，多模态大模型大致经历了几条并行演进路线：

```text
2017-2020：
Transformer / ViT / CLIP / 自回归语言模型奠基

2021-2022：
扩散模型成为图像生成主流；
CLIP 对齐推动文本-图像生成；
PaLM、Chinchilla、Flamingo 等推动 LLM 与多模态结合

2023：
LLM + 视觉编码器 + 投影层成为多模态理解主流；
Stable Diffusion、DALL·E 2/3、Midjourney 推动图像生成工业化；
AudioLM、MusicLM、MusicGen 推动音频音乐生成

2024：
GPT-4o、Gemini 1.5、Claude 3、Qwen-VL、InternVL、LLaVA-NeXT 等推动原生多模态理解；
Sora、Veo、Runway Gen-3、Movie Gen 推动视频生成进入大模型阶段；
DiT、Flow Matching、Rectified Flow 成为生成模型核心方向

2025-2026：
多模态统一模型、Omni 模型、视频世界模型、实时语音视觉交互、长上下文多模态推理、可控生成、Agent 化成为重点
```

## 二、关键技术发展时间线

### 1. Transformer 与 LLM 基础阶段

| 时间 | 技术/模型 | 关键贡献 |
| --- | --- | --- |
| 2017 | Transformer, Attention Is All You Need | 自注意力机制成为语言、视觉、音频、视频建模基础 |
| 2018 | BERT | Masked Language Modeling，推动预训练-微调范式 |
| 2018 | GPT-1 | 自回归语言建模范式 |
| 2019 | GPT-2 | 大规模自回归语言模型展现生成能力 |
| 2020 | GPT-3 | In-context learning，证明模型规模带来涌现能力 |
| 2020 | ViT | 将图像切分为 patch，用 Transformer 处理视觉任务 |
| 2021 | CLIP | 文本-图像对比学习，对齐视觉与语言语义空间 |
| 2022 | Chinchilla | 提出参数量与训练 token 数量的 compute-optimal scaling |
| 2022 | PaLM | 大规模 dense Transformer LLM |
| 2023 | LLaMA / GPT-4 | 开源 LLM 与商业大模型进入主流 |
| 2024 | GPT-4o / Gemini 1.5 / Claude 3 | 原生多模态、长上下文、实时交互能力增强 |

LLM 的核心架构仍然是：

```text
Token Embedding
    ↓
多层 Transformer Decoder
    ↓
Causal LM Head
    ↓
Next Token Prediction
```

主要训练方式：

1. **预训练**

- 自回归 next-token prediction。
- 大规模网页、代码、书籍、论文、对话数据。

1. **监督微调 SFT**

- 指令数据、问答数据、多轮对话数据。

1. **偏好对齐**

- RLHF、RLAIF、DPO、IPO、KTO 等。

1. **工具增强 / Agent 训练**

- Function calling、工具调用轨迹、浏览器/代码执行轨迹。

1. **长上下文训练**

- RoPE scaling、YaRN、NTK-aware interpolation、分块注意力、稀疏注意力。

### 2. 多模态理解大模型发展

多模态理解模型主要解决：

- 图像问答；
- 图像描述；
- OCR；
- 图表理解；
- 文档理解；
- 视频理解；
- 多图推理；
- GUI/Agent 操作；
- 视觉 grounding；
- 机器人感知与规划。

### 2.1 早期视觉语言模型

| 时间 | 模型/技术 | 核心思想 |
| --- | --- | --- |
| 2019 | ViLBERT | 双流 Transformer，图像与文本分别编码，再交互 |
| 2019 | VisualBERT | 单流 Transformer，将图像区域特征和文本 token 一起输入 |
| 2019 | UNITER | 统一图文预训练，任务包括 MLM、ITM、区域-词对齐 |
| 2020 | OSCAR | 引入 object tag 作为图文对齐锚点 |
| 2021 | CLIP | 大规模图文对比学习，成为后续多模态模型基础 |

早期模型多使用：

```text
图像检测器，例如 Faster R-CNN
    ↓
Region features
    ↓
BERT-style Transformer
    ↓
VQA / Caption / Retrieval
```

问题：

- 依赖目标检测器；
- 图像表示粒度粗；
- 难以扩展到开放世界；
- 生成能力弱；
- 与 LLM 没有深度结合。

---

### 2.2 CLIP 之后的多模态对齐

**CLIP，2021** 是一个关键节点。

CLIP 架构：

```text
Image Encoder, ResNet 或 ViT
Text Encoder, Transformer
    ↓
Contrastive Loss
    ↓
图像-文本共享语义空间
```

训练目标：

```text
给定 batch 内 N 对图文样本：
最大化匹配图文对相似度；
最小化非匹配图文对相似度。
```

CLIP 的影响：

1. 成为 Stable Diffusion、DALL·E 2 等生成模型的文本/图像语义基础；
2. 成为多模态理解模型的视觉编码器；
3. 推动 zero-shot 分类、图文检索；
4. 证明弱标注大规模图文数据可以训练强泛化模型。

---

### 2.3 LLM + Vision Encoder + Adapter 范式

2022-2024，多模态理解大模型主流架构变成：

```text
Image / Video / Audio
    ↓
Modality Encoder, 例如 ViT / CLIP / SigLIP / Whisper
    ↓
Projector / Adapter / Q-Former / Perceiver Resampler
    ↓
LLM
    ↓
Text Response / Tool Call / Action
```

代表模型：

| 时间 | 模型 | 关键贡献 |
| --- | --- | --- |
| 2022 | Flamingo | 冻结视觉编码器与 LLM，用 Perceiver Resampler + cross-attention 做 few-shot 多模态学习 |
| 2023 | BLIP-2 | Q-Former 连接 frozen image encoder 和 frozen LLM |
| 2023 | LLaVA | CLIP ViT + projector + Vicuna，使用 GPT-4 生成视觉指令数据 |
| 2023 | MiniGPT-4 | 将视觉特征对齐到 Vicuna |
| 2023 | InstructBLIP | 多任务指令微调的视觉语言模型 |
| 2023 | Qwen-VL | 中文/英文视觉语言模型，支持 grounding |
| 2024 | LLaVA-NeXT | 提升分辨率、多图、视频能力 |
| 2024 | InternVL | 更强视觉编码器和视觉语言对齐 |
| 2024 | GPT-4o | 原生文本、图像、音频多模态交互 |
| 2024 | Gemini 1.5 | 长上下文多模态理解，包括长视频、长文档 |
| 2024 | Claude 3 | 文档、图表、视觉理解增强 |

### 2.4 多模态理解模型的架构类型

### 类型一：Encoder-Projector-LLM

这是当前开源模型最常见结构。

```text
Image
 ↓
Vision Encoder, CLIP/SigLIP/ViT
 ↓
MLP Projector
 ↓
LLM Token Space
 ↓
LLM Decoder
```

优点：

- 简单；
- 训练成本低；
- 可复用强 LLM；
- 易扩展。

缺点：

- 视觉 token 压缩严重；
- 细粒度定位、OCR、复杂空间推理不足；
- 视觉信息主要作为前缀输入，深层融合有限。

代表：

- LLaVA，2023；
- MiniGPT-4，2023；
- Qwen-VL，2023；
- InternVL，2024。

---

### 类型二：Q-Former / Query-based Bridge

代表：BLIP-2，2023。

```text
Image Encoder
    ↓
Q-Former with learnable queries
    ↓
Fixed number of visual tokens
    ↓
LLM
```

优点：

- 将大量视觉 token 压缩成固定数量 query；
- 训练成本较低；
- 适合图像描述、VQA。

缺点：

- query 数量限制信息容量；
- 细节理解容易丢失；
- 对高分辨率、多图、视频扩展不够自然。

---

### 类型三：Cross-attention Fusion

代表：Flamingo，2022。

```text
Text tokens → LLM layers
                 ↑
Visual tokens → Cross-attention blocks
```

优点：

- 多层深度融合；
- few-shot 多模态学习强；
- 可处理交错图文。

缺点：

- 修改 LLM 结构；
- 训练成本高；
- 工程复杂。

---

### 类型四：统一 Tokenization / 原生多模态 Transformer

代表方向：

- GPT-4o，2024；
- Gemini，2023-2024；
- Chameleon，2024；
- Emu3，2024；
- Janus，2024；
- 部分 image tokenizer + autoregressive 模型。

核心思想：

```text
Text tokens
Image tokens
Audio tokens
Video tokens
Action tokens
    ↓
统一序列
    ↓
一个 Transformer 建模
```

优点：

- 理解和生成可统一；
- 模态间融合更自然；
- 支持 interleaved multimodal reasoning。

缺点：

- 多模态 tokenization 难；
- 图像/视频 token 数量巨大；
- 训练成本极高；
- 不同模态的尺度、信息密度差异大。

### 3.4 扩散模型基本原理

扩散模型包含两个过程。

### 加噪过程

```text
x0 → x1 → x2 → ... → xT
```

逐步加入高斯噪声：

```text
q(xt | x0) = N(√α_t x0, (1 - α_t)I)
```

最终图像变成近似高斯噪声。

### 去噪过程

模型学习：

```text
pθ(x_{t-1} | xt, condition)
```

常见预测目标：

1. 预测噪声 `ε` ；
2. 预测原图 `x0` ；
3. 预测 velocity `v` ；
4. Flow Matching 中预测速度场 `v_t` 。

---

### 3.5 Latent Diffusion

Stable Diffusion，2022 的核心贡献是把扩散过程放到 VAE latent 空间。

```text
Image
 ↓
VAE Encoder
 ↓
Latent z
 ↓
Diffusion / Denoising
 ↓
VAE Decoder
 ↓
Image
```

优势：

- 降低计算量；
- 可以生成高分辨率图像；
- 易于文本条件控制；
- 适合开源社区扩展。

---

### 3.6 U-Net 到 DiT

早期扩散模型多用 U-Net：

```text
Noisy latent
 ↓
U-Net with ResNet + Attention
 ↓
Predicted noise
```

2023 年 DiT 提出后，生成模型逐渐转向 Transformer。

DiT 架构：

```text
Noisy image latent
 ↓
Patchify
 ↓
Time embedding + condition embedding
 ↓
Transformer blocks
 ↓
Unpatchify
 ↓
Predicted noise / velocity
```

优点：

- scaling law 更清晰；
- 更适合大规模训练；
- 可复用 LLM 工程优化；
- 更适合图像、视频、3D 等统一建模。

缺点：

- 小规模训练不如 U-Net 高效；
- 对数据、算力要求更高；
- 长序列注意力成本高。

---

### 3.7 文本条件与多模态融合

图像生成常见条件注入方式：

### 1. Cross-Attention

Stable Diffusion 使用：

```text
Image latent features as Query
Text embeddings as Key / Value
```

优点：

- 文本控制强；
- 支持 prompt 组合；
- 可扩展 ControlNet、LoRA、IP-Adapter。

---

### 2. AdaLN / AdaLN-Zero

DiT 常用：

```text
LayerNorm 参数由 timestep + condition 调制
```

例如：

```text
h = AdaLN(h, condition)
```

优点：

- 结构简洁；
- 适合 Transformer；
- 大规模训练稳定。

---

### 3. MMDiT

Stable Diffusion 3，2024 使用多模态 Diffusion Transformer。

核心思想：

```text
Text tokens 和 Image tokens 分别有自己的权重流；
在 attention 中进行跨模态交互。
```

比传统 cross-attention 更统一，适合文本-图像深度融合。

---

### 3.8 采样方式演进

| 时间 | 方法 | 特点 |
| --- | --- | --- |
| 2020 | DDPM sampler | 高质量但步数多 |
| 2021 | DDIM | 确定性采样，步数减少 |
| 2022 | PNDM | 数值 ODE solver 思路 |
| 2022 | DPM-Solver | 高阶求解器，快速采样 |
| 2023 | UniPC | 统一 predictor-corrector |
| 2023 | Consistency Model | 一步/少步生成 |
| 2023-2024 | LCM | Latent Consistency Model，少步图像生成 |
| 2024 | Rectified Flow | 学习从噪声到数据的直线流 |
| 2024-2025 | Distillation | 蒸馏多步模型到少步/一步模型 |

当前业界趋势：

```text
多步扩散  →  少步扩散  →  Flow Matching / Rectified Flow  →  一步/少步高质量生成
```

## 四、视频生成模型发展

视频生成比图像生成难得多，因为要同时建模：

1. 空间一致性；
2. 时间一致性；
3. 物体运动；
4. 摄像机运动；
5. 物理规律；
6. 长时记忆；
7. 多镜头叙事；
8. 音画同步。

---

| 2022 | Imagen Video | 级联视频扩散模型 |
| 2022 | Make-A-Video | 文本到视频生成 |
| 2023 | VideoCrafter | 开源视频扩散模型 |

### 4.2 视频生成核心架构

### 早期：2D U-Net + Temporal Module

```text
Image diffusion U-Net
    +
Temporal Attention / Motion Module
```

代表：

- AnimateDiff，2023；
- VideoCrafter，2023。

优点：

- 可复用图像生成模型；
- 训练成本较低；
- 适合短视频。

缺点：

- 长视频一致性差；
- 复杂运动容易崩；
- 物体身份保持困难。

---

### 主流：3D U-Net / Spatio-temporal U-Net

```text
Video latent: T × H × W × C
    ↓
3D convolution / spatial attention / temporal attention
    ↓
Denoised video latent
```

优点：

- 显式建模时间维；
- 适合短时动态。

缺点：

- 算力消耗大；
- 扩展长视频困难。

---

### 新趋势：Video DiT / Spacetime Patch Transformer

Sora，2024 技术报告提到核心思想：

```text
Video
 ↓
Latent representation
 ↓
Spacetime patches
 ↓
Diffusion Transformer
 ↓
Denoised patches
 ↓
Video decoder
```

也就是将视频压缩到 latent 空间后切成时空 patch：

```text
patch = t × h × w
```

再作为序列输入 Transformer。

优点：

- 图像和视频可以统一；
- 不同分辨率、宽高比、时长可以统一建模；
- scaling 能力强；
- 适合大规模训练。

缺点：

- 序列极长；
- 训练成本极高；
- 长程物理一致性仍然不足；
- 数据质量与版权问题严重。

---

### 4.3 视频中的位置编码

视频位置编码需要同时表示：

```text
时间 T
高度 H
宽度 W
```

常见方案：

1. **绝对 3D 位置编码**

- 对 `t, h, w` 分别编码后相加或拼接。

1. **RoPE 扩展到 2D/3D**

- 用旋转位置编码建模空间和时间相对关系。

1. **相对位置偏置**

- 类似 Swin Transformer。

1. **分解式位置编码**

- spatial position + temporal position。

1. **可变分辨率位置编码**

- 支持不同宽高比和动态 patch packing。

视频模型里，位置编码非常关键，因为它直接影响：

- 运动连续性；
- 镜头一致性；
- 空间结构；
- 多分辨率泛化。

---

### 4.4 视频训练方式

主流训练流程：

```text
大规模图像预训练
    ↓
短视频训练
    ↓
高质量视频数据微调
    ↓
指令/偏好对齐
    ↓
人类反馈或自动评估优化
```

常见技巧：

1. **图像-视频联合训练** 

- 图像可视为 1 帧视频；
- 增加数据规模；
- 提升静态质量。

1. **多分辨率训练** 

- 支持不同分辨率、比例、时长。

1. **Caption 重写** 

- 用强 VLM/LLM 生成详细视频描述；
- 类似 DALL·E 3 的 prompt rewriting。

1. **运动增强** 

- 光流、深度、相机轨迹、姿态条件。

1. **分阶段训练** 

- 低分辨率 → 高分辨率；
- 短时长 → 长时长；
- 无条件 → 文本条件 → 指令条件。

1. **后训练对齐** 

- 偏好数据；
- 安全过滤；
- prompt following 优化。

## 五、音频与音乐生成大模型

音频生成包括：

- 语音合成；
- 音效生成；
- 音乐生成；
- 语音理解；
- 语音对话；
- 音频事件识别；
- 音画同步。

---

### 5.1 音频大模型时间线

| 时间 | 模型/技术 | 贡献 |
| --- | --- | --- |
| 2016 | WaveNet | 自回归波形生成，高质量语音合成 |
| 2018 | Tacotron 2 | 文本到语音端到端系统 |
| 2020 | Jukebox | 神经网络音乐生成，VQ-VAE + Transformer |
| 2022 | AudioLM | 语义 token + 声学 token 的音频语言模型 |
| 2022 | Whisper | 大规模语音识别与翻译 |
| 2023 | MusicLM | 文本到音乐生成 |
| 2023 | MusicGen | 单阶段 Transformer 音乐生成 |
| 2023 | AudioLDM | latent diffusion 音频生成 |
| 2023 | Bark | 文本到语音/音频生成 |
| 2023 | Stable Audio | 长音频生成 |
| 2024 | GPT-4o | 端到端实时语音多模态交互 |
| 2024 | Gemini / Qwen-Audio / SALMONN | 音频理解与多模态对话能力增强 |
| 2024-2025 | Suno / Udio 等 | 商业级整首歌曲生成爆发 |

---

### 5.2 音频生成的两条路线

### 路线一：离散音频 Token + 自回归 Transformer

代表：

- AudioLM，2022；
- MusicLM，2023；
- MusicGen，2023；
- Jukebox，2020。

流程：

```text
Audio waveform
 ↓
Neural codec, 例如 SoundStream / EnCodec
 ↓
Discrete audio tokens
 ↓
Autoregressive Transformer
 ↓
Generated tokens
 ↓
Codec decoder
 ↓
Audio waveform
```

优点：

- 与 LLM 架构一致；
- 适合长序列；
- 可做语音、音乐、音效统一建模；
- 可与文本 token 混合。

缺点：

- 音频 token 序列非常长；
- 自回归生成慢；
- 长音乐结构难控制；
- 多声部、和声、节奏稳定性仍有问题。

---

### 路线二：Latent Diffusion / Flow 音频生成

代表：

- AudioLDM，2023；
- Stable Audio，2023；
- 后续 diffusion/flow 音乐模型。

流程：

```text
Audio
 ↓
Mel spectrogram 或 latent representation
 ↓
Diffusion / Flow denoising
 ↓
Vocoder / Decoder
 ↓
Waveform
```

优点：

- 生成质量高；
- 并行采样；
- 适合音效、音乐纹理；
- 文本条件控制较好。

缺点：

- 长时结构难；
- 精确歌词、节拍、编曲控制困难；
- 需要强 vocoder 或 codec。

---

### 5.3 音乐生成的关键问题

音乐比一般音频更难，因为它有多层结构：

```text
音色
节奏
旋律
和声
段落结构
歌词
人声
混音
风格
情绪
```

当前音乐生成模型主要挑战：

1. **长程结构**

- verse / chorus / bridge 的结构控制难。

1. **歌词一致性**

- 发音、押韵、语义、节拍对齐难。

1. **人声质量**

- 高音、咬字、多语言、情绪表达仍不稳定。

1. **版权问题**

- 训练数据来源敏感。

1. **可编辑性不足**

- 用户很难指定某一小节、某个乐器、某段旋律。

1. **专业工作流集成不足**

- 与 DAW、MIDI、分轨编辑结合还不够。

## 六、有效模块设计总结

下面总结多模态理解和生成中被证明有效的模块。

---

### 1. 位置编码

### LLM 中

| 方法 | 时间 | 特点 |
| --- | --- | --- |
| Sinusoidal PE | 2017 | Transformer 原始位置编码 |
| Learned PE | 2018-2020 | BERT/GPT 常用 |
| RoPE | 2021 | 旋转位置编码，适合相对位置和长上下文 |
| ALiBi | 2021 | 线性 attention bias，长上下文外推 |
| NTK-aware RoPE Scaling | 2023 | 扩展 LLM 上下文 |
| YaRN | 2023 | 更稳定的 RoPE extrapolation |
| 2D/3D RoPE | 2023-2024 | 图像、视频 Transformer 常用 |

当前认可度最高：

```text
文本 LLM：RoPE 及其 scaling 变体
图像/视频 DiT：2D/3D RoPE、分解式时空位置编码、可变分辨率位置编码
```

---

### 2. 加噪与去噪目标

| 方法 | 时间 | 特点 |
| --- | --- | --- |
| ε-prediction | 2020 | 预测噪声，DDPM 常用 |
| x0-prediction | 2020-2021 | 预测干净样本 |
| v-prediction | 2022 | Imagen/Stable Diffusion v2 等使用，稳定性好 |
| EDM preconditioning | 2022 | 改进噪声参数化 |
| Flow Matching | 2023 | 学习概率路径速度场 |
| Rectified Flow | 2022-2024 | 更直的噪声到数据路径，利于少步采样 |
| Consistency Training | 2023 | 一步/少步生成 |

当前趋势：

```text
传统 DDPM/DDIM 逐步向 Flow Matching / Rectified Flow / Consistency Distillation 演进
```

---

### 3. 采样方式

效果与速度平衡较好的方案：

1. **DPM-Solver / DPM-Solver++** 

- 图像扩散常用；
- 20-30 步可获得不错质量。

1. **Euler / Heun / EDM sampler** 

- Stable Diffusion 社区常用。

1. **DDIM** 

- 简单稳定，适合编辑和 inversion。

1. **LCM / Turbo / Distillation** 

- 少步生成；
- 适合实时场景。

1. **Flow-based sampler** 

- 逐渐成为 SD3、Flux 等新模型核心。

---

### 4. 多模态融合模块

### 理解模型中

| 模块 | 代表 | 特点 |
| --- | --- | --- |
| Linear/MLP Projector | LLaVA | 简单有效 |

| LoRA | 2021 起，AIGC 广泛使用 | 低成本个性化微调 |
| IP-Adapter | 2023 | 图像提示控制 |

| MMDiT | SD3, 2024 | 文本图像多模态 Transformer 融合 |

## 七、当前业界最认可/效果最好的结构与训练方式

### 1. 多模态理解

当前最主流、工程性最强的方案：

```text
强视觉编码器, SigLIP / CLIP / InternViT
    +
高质量 projector / resampler
    +
强 LLM, LLaMA/Qwen/Mistral/DeepSeek 等
    +
多阶段视觉语言对齐训练
    +
高质量指令微调
    +
偏好对齐
```

典型训练流程：

```text
阶段 1：视觉-语言对齐预训练
    冻结 LLM 或部分冻结
    训练 projector
    数据：图像-caption、OCR、图文对

阶段 2：多模态指令微调
    训练 projector + 部分/全部 LLM
    数据：VQA、图表、文档、多图、推理

阶段 3：高分辨率/多图/视频扩展
    引入 tiling、frame sampling、token compression

阶段 4：偏好对齐
    DPO/RLHF/RLAIF
    降低幻觉，提高 helpfulness 与安全性
```

业界认可的关键点：

1. **LLM 能力决定上限**

- 推理、语言组织、工具调用主要依赖 LLM。

1. **视觉编码器决定细节感知能力**

- OCR、图表、空间定位、细粒度识别依赖视觉 encoder。

1. **数据质量比单纯数据量更关键**

- 高质量图文描述、复杂推理数据、真实用户数据很重要。

1. **高分辨率处理是核心能力**

- 文档、UI、图表、OCR 都需要高分辨率。

1. **多模态幻觉仍是关键问题**

- 模型容易把语言先验当视觉事实。

---

### 2. 图像生成

当前效果最好的主流方向：

```text
VAE latent space
    +
Diffusion Transformer / MMDiT
    +
Flow Matching / Rectified Flow
    +
强文本编码器, T5/CLIP/LLM encoder
    +
高质量 caption 数据
    +
偏好优化 / aesthetic filtering
    +
少步蒸馏
```

代表方向：

- Stable Diffusion 3，2024：MMDiT + Flow Matching；
- Flux，2024：Transformer + Rectified Flow 类路线；
- Midjourney v6/v7：闭源，但普遍认为审美、构图、风格控制强；
- DALL·E 3，2023：prompt following 与文本渲染能力较强。

当前最被认可的训练方式：

1. **大规模图文预训练**

- 使用高质量 image-text pairs。

1. **caption recaptioning**

- 用强 VLM 生成详细描述；
- 提升 prompt adherence。

1. **多分辨率/多宽高比训练**

- 支持真实创作场景。

1. **Flow Matching / Rectified Flow**

- 训练和采样更高效。

1. **偏好数据优化**

- aesthetic preference；
- prompt alignment；
- safety alignment。

1. **蒸馏加速**

- 4 步、2 步、1 步生成。

---

### 3. 视频生成

当前最认可方向：

```text
Video latent tokenizer / VAE
    +
Spacetime patching
    +
Diffusion Transformer / Video Transformer
    +
图像-视频联合训练
    +
高质量视频 caption
    +
多分辨率、多时长训练
    +
偏好对齐与安全过滤
```

代表：

- Sora，2024；
- Veo/Veo 2，2024；
- Runway Gen-3，2024；
- Movie Gen，2024；
- Kling、HunyuanVideo、Wan 等 2024-2025。

业界共识：

1. **Video DiT 是核心方向**

- 比 3D U-Net 更适合 scaling。

1. **图像-视频联合训练非常重要**

- 图像提升静态质量；
- 视频提升运动建模。

1. **详细视频 caption 是关键**

- 动作、主体、镜头、风格、物理关系都要描述。

1. **长视频仍然未解决**

- 目前多数模型擅长短片段，不擅长复杂叙事。

1. **物理一致性是下一阶段竞争点**

- 重力、碰撞、因果、遮挡、物体恒常性。

---

### 4. 音频与音乐生成

当前认可方向分两类：

### 音频理解/语音交互

```text
Audio encoder, Whisper / wav2vec / codec encoder
    +
LLM
    +
实时流式解码
```

代表：

- GPT-4o，2024；
- Gemini；
- Qwen-Audio；
- SALMONN。

### 音乐/音频生成

```text
Neural audio codec
    +
Discrete token LM
或
Latent diffusion / flow
    +
Text / melody / rhythm condition
```

业界有效训练方式：

1. codec tokenization；
2. text-audio contrastive alignment；
3. autoregressive token modeling；
4. diffusion/flow acoustic generation；
5. 高质量音乐 caption；
6. 人类偏好对齐；
7. 分轨/乐器/歌词条件控制。

## 八、当前面临的核心问题

### 1. 多模态理解问题

### 1.1 幻觉

模型会回答图像中不存在的内容。

原因：

- LLM 语言先验太强；
- 视觉 token 信息不足；
- 训练数据中 caption 偏概括；
- 缺少视觉 grounding 约束。

解决方向：

- 更强视觉 encoder；
- grounding 数据；
- 检索增强；
- uncertainty estimation；
- DPO/RLHF 抑制幻觉；
- explicit visual verification。

---

### 1.2 细粒度视觉理解不足

包括：

- 小字 OCR；
- 表格；
- 图表；
- 医学影像；
- 遥感图像；
- UI 元素；
- 空间关系。

原因：

- 图像被压缩成少量 token；
- 分辨率不足；
- 视觉 encoder 不专门针对 OCR/文档训练；
- LLM 对二维结构建模弱。

---

### 1.3 长视频理解困难

问题：

- 长时事件记忆；
- 多人物跟踪；
- 因果推理；
- 跨镜头一致性；
- 视频问答需要定位证据。

技术瓶颈：

- 视频 token 数量过大；
- attention 成本高；
- 数据标注困难；
- 评测体系不完善。

---

### 2. 图像生成问题

### 2.1 文本渲染仍不稳定

虽然 DALL·E 3、Ideogram、SD3、Flux 已明显改善，但复杂文字仍可能出错。

原因：

- 文字是离散符号，图像扩散是连续生成；
- 字符级精确约束困难；
- 训练集中图文对应不精确。

---

### 2.2 可控性不足

用户想精确控制：

- 人物姿态；
- 构图；
- 光照；
- 镜头；
- 局部编辑；
- 角色一致性。

目前依赖：

- ControlNet；
- IP-Adapter；
- LoRA；
- Inpainting；
- Reference attention。

但仍不如专业设计工具可控。

---

### 2.3 版权与风格模仿

生成模型可能学习艺术家风格、商标、人物肖像。

这是商业落地中的关键法律风险。

---

### 3. 视频生成问题

### 3.1 物理世界建模不足

常见错误：

- 手部变形；
- 物体凭空出现/消失；
- 碰撞不合理；
- 反射错误；
- 液体、烟雾、布料不稳定；
- 人物身份漂移。

---

### 3.2 长时一致性差

包括：

- 角色外观变化；
- 背景变化；
- 物体数量变化；
- 镜头切换不自然；
- 情节无法持续推进。

---

### 3.3 成本极高

视频生成需要：

```text
更长序列 × 更高分辨率 × 更多帧 × 更复杂条件
```

训练和推理成本远高于图像生成。

---

### 4. 音频/音乐问题

### 4.1 长结构控制难

音乐不是简单连续声音，而是具有结构：

```text
intro → verse → chorus → bridge → outro
```

当前模型容易：

- 重复；
- 段落不清；
- 高潮不足；
- 长程和声不稳定。

---

### 4.2 歌词与旋律对齐难

尤其是：

- 多语言；
- 快节奏；
- Rap；
- 情绪变化；
- 合唱；
- 和声。

---

### 4.3 专业可编辑性不足

用户希望编辑：

- 某个乐器；
- 某一轨；
- 某一句歌词；
- 某一小节旋律；
- 某个鼓点。

当前多数模型仍是“一次性生成”，缺乏可控分轨编辑。

---

## 九、未来技术发展趋势

### 1. 从拼接式多模态走向原生多模态

当前很多模型仍然是：

```text
视觉 encoder + projector + LLM
```

未来会更多走向：

```text
统一多模态 token
    +
统一 Transformer / MoE
    +
统一理解与生成
```

也就是模型可以同时处理：

```text
文本
图像
视频
音频
3D
动作
工具调用
传感器数据
```

并统一建模。

---

### 2. 理解与生成融合

未来模型不只是：

```text
看图回答
```

而是：

```text
看图 → 推理 → 修改图像
看视频 → 分析 → 生成后续视频
听音乐 → 理解结构 → 改编
读文档 → 生成图表/视频讲解
```

理解模型和生成模型会逐渐融合。

可能架构：

```text
Multimodal Encoder / Tokenizer
    ↓
World Model / Reasoning LLM
    ↓
Multimodal Generator
```

---

### 3. Video World Model

Sora 之后，一个重要趋势是：

```text
视频生成模型 ≈ 世界模拟器雏形
```

未来视频模型会更强调：

- 物体恒常性；
- 3D 几何；
- 物理规律；
- 因果关系；
- 可交互环境；
- 动作条件生成；
- 机器人仿真。

这会连接到：

- 自动驾驶；
- 机器人；
- 游戏；
- AR/VR；
- 具身智能。

---

### 4. Flow Matching / Rectified Flow 继续替代传统扩散

图像、视频、音频生成都在从传统 diffusion 走向：

```text
Flow Matching
Rectified Flow
Consistency Models
Few-step Generation
One-step Generation
```

目标：

- 更快采样；
- 更稳定训练；
- 更容易蒸馏；
- 更适合实时交互。

---

### 5. DiT / Multimodal Transformer 成为生成模型核心

U-Net 在早期扩散模型中非常成功，但未来大模型化更适合 Transformer。

原因：

1. scaling law 更清晰；
2. 适合统一图像、视频、音频 token；
3. 工程优化成熟；
4. 适合 MoE；
5. 适合长上下文和条件融合。

未来图像/视频生成主干大概率是：

```text
Diffusion Transformer
Flow Transformer
Multimodal Transformer
MoE Transformer
```

---

### 6. 多模态 MoE

由于不同模态计算需求差异巨大，MoE 会越来越重要。

可能结构：

```text
共享 attention
    +
文本 expert
图像 expert
视频 expert
音频 expert
代码 expert
工具 expert
```

优势：

- 扩大参数量但控制计算量；
- 模态专用能力更强；
- 支持大规模统一模型。

问题：

- router 稳定性；
- 模态间负载均衡；
- 训练复杂；
- expert collapse。

### 7. 高质量数据和自动数据工程成为核心壁垒

## 十一、后续最值得关注的技术方向

按重要性排序：

1. **原生多模态统一模型** 

- 文本、图像、视频、音频统一 token 和统一 Transformer。

1. **Video World Model** 

- 视频生成从“像视频”变成“理解物理世界”。

1. **Flow Matching / Rectified Flow** 

- 逐渐成为图像、视频、音频生成核心训练范式。

1. **DiT / MoE-DiT** 

- 生成模型继续 Transformer 化、规模化。

1. **长上下文多模态推理** 

- 长视频、长音频、长文档、多图推理。

1. **高分辨率细粒度理解** 

- OCR、图表、UI、医学、遥感。

1. **可控生成与多轮编辑** 

- 从 prompt generation 走向 professional editing。

1. **实时多模态交互** 

- 语音、视觉、动作低延迟闭环。

1. **数据工程自动化** 

- 自动 caption、自动过滤、自动偏好标注。

1. **安全、版权与可追溯** 

- 水印、内容溯源、数据授权、风格保护。

---

一句话总结：

> 近几年多模态大模型的发展主线，是从“单模态 Transformer/扩散模型”走向“统一多模态 Transformer/Flow 模型”；从“理解或生成单点能力”走向“理解、推理、生成、编辑、交互、行动一体化”。当前最被认可的方向是：理解侧采用强 encoder + 强 LLM + 高质量对齐训练；生成侧采用 latent representation + DiT/MMDiT + Flow Matching/Rectified Flow + 高质量多模态数据。未来的核心竞争会集中在原生多模态统一架构、视频世界模型、实时交互、可控生成、数据治理和安全对齐上。
