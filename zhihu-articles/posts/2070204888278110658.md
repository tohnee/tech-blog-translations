## 一、什么是MCP？

想象你买了一台超级强大的电脑（=AI大模型），但它只有一个聊天窗口。你想让它帮你查邮件？不行。想让它读你的Notion笔记？不行。想让它操作浏览器？也不行。

MCP就是给这台电脑装上了 **USB-C接口** 。有了MCP，AI可以接邮件、接笔记、接浏览器、接数据库—— **一套协议通吃。**

![](https://pica.zhimg.com/v2-0d9c64a1b2f24849a0ab2327c4bbe3d2_r.jpg)

- **Host（宿主）** ：你用的AI应用，比如Claude Desktop、Cursor、ChatGPT
- **Client（客户端）** ：宿主内部的协议翻译层，负责发现和调用工具
- **Server（服务端）** ：提供具体工具能力的外部服务，比如读写Notion、操作浏览器、查询数据库

## 二、最推荐的3个MCP Server

### 2.1 Context7：让AI不再写出过时的代码

如果你是程序员，这个MCP是必装的。

你用AI写代码时，有没有遇到过这种情况：让AI写一个Next.js 15的中间件，它给你返回Next.js 13的写法？问它React 19的新语法，它用的老API已经被废弃了两个版本？

Context7的解决方式很直接： **在你提问的瞬间，实时去拉取目标库的最新文档和代码示例** ，注入到AI的上下文窗口中。它覆盖了React、Next.js、Supabase、MongoDB等数千个主流库。

官网地址： [Install Context7 — One command for every coding agent | Context7](https://context7.com/install)

安装方法：

![](https://pic1.zhimg.com/v2-30d51c8ae5b0687e551fcb23a71c9dfe_r.jpg)

只要你用AI辅助编程，Context7都能显著提升代码准确率。它不挑语言、不挑框架

### 2.2 Playwright MCP：让AI像人一样操作浏览器

AI最大的局限之一是"看不到网页"。它能写代码、能分析文本，但让它打开一个网页、填个表单、点个按钮，很难做到。

Playwright MCP（微软官方出品）换了一种思路： **不截图，直接通过网页的无障碍树（Accessibility Tree）与页面交互。** AI拿到的是结构化的页面数据。结果是速度更快、操作更准，而且支持40多种工具——导航、点击、输入、滚动、截图、提取内容，一应俱全。

**官方网址：** [面向现代 Web 应用的快速、可靠端到端测试 | Playwright - Playwright 测试框架](https://playwright.cn/)

**安装方式：**

```text
# 使用npm全局安装
npm install -g @playwright/mcp

# 安装Playwright所需的浏览器
npx playwright install
```

**使用方式：**

```text
"请使用Playwright MCP打开百度首页(https://www.baidu.com)，在搜索框中输入'Playwright教程'，点击搜索按钮，然后对结果页面截图并返回给我。"
```

**基本浏览器操作**

- **页面导航** ( `playwright_navigate` )：让浏览器跳转到指定URL
- **元素操作** ( `playwright_click` , `playwright_fill` )：点击页面元素，填写表单
- **内容获取** ( `playwright_get_visible_text` )：获取页面可见文本
- **截图功能** ( `playwright_screenshot` )：对页面或元素截图

**高级功能**

- **文件操作** ( `playwright_upload_file` )：上传文件到网页
- **PDF导出** ( `playwright_save_as_pdf` )：将页面保存为PDF
- **网络监控** ：实时监控网络请求和响应
- **性能监控** ：监控页面加载时间、资源使用情况等性能指标

### 2.3 Firecrawl：把任何网页变成AI能处理的干净文本

Firecrawl专门解决这个问题：给它一个URL，它返回干净的Markdown格式文本——去掉了所有干扰元素，只保留正文内容。它还能处理需要JavaScript渲染的页面、爬取整站内容、甚至执行搜索。

要使用 API，您需要在 [Firecrawl](https://firecrawl.org.cn/) 上注册并获取 API 密钥，免费层每月有500次抓取额度

**官方网站** ： [Firecrawl - 面向人工智能的网页数据 API - Firecrawl 平台](https://firecrawl.org.cn/)

**手动安装：**

```text
npm install -g firecrawl-mcp
```

## 三、 使用MCP的5个实用技巧

### 技巧1：从一个MCP开始，不要贪多

新手最常犯的错误是一次装10个MCP，出了问题不知道哪个环节出错。建议每次只装一个，确认能用再加下一个。

### 技巧2：注意权限最小化

很多MCP需要API Key或Token。给Token授权时， **只给必要的权限** ：

- GitHub Token只勾 `repo` 读权限（除非你需要AI创建PR）
- Notion Token只授权特定页面范围
- 数据库类MCP默认用只读连接

### 技巧3：遇到连接问题时的排查清单

1. **检查Node.js版本** ： `node -v` ，确保 ≥ v18
2. **检查npm能否正常访问** ： `npm ping`
3. **检查JSON格式** ：用在线JSON校验工具检查配置文件
4. **重启客户端** ：修改配置后必须完全重启
5. **查看日志** ：Claude Desktop可以通过菜单 View → Toggle Developer Tools 查看控制台日志

MCP不是一个新概念，但它终于到了一个 **普通人也能用** 的临界点。

你不需要理解JSON-RPC 2.0，不需要知道什么是stdio和SSE，不需要会写代码。你只需要：

1. 选一个AI客户端（推荐Cherry Studio或Claude Desktop）
2. 装一两个MCP Server（从Context7开始）
3. 用自然语言告诉AI你想做什么

剩下的，MCP会帮你搞定。
