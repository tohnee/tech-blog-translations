## 目标

本教程带你一步一步实现 `mini_nanotron.py`，学会在多卡多节点环境下对 LLM 进行 **3D 并行训练**：

- **数据并行（Data Parallelism, DP）**：多份数据同时训练，梯度同步
- **张量并行（Tensor Parallelism, TP）**：把单层的权重矩阵切分到多张卡
- **流水线并行（Pipeline Parallelism, PP）**：把不同层分到不同卡，形成流水线

最终实现只有约 400 行代码，但涵盖了 Megatron-LM 的核心思想。

### 第一步：理解 3D 并行的进程组织方式

### 1.1 为什么需要 3D 并行？

单张 GPU 的显存有限，大模型无法放在一张卡上。解决方案：

| 并行方式 | 解决什么问题 | 通信代价 |
| --- | --- | --- |
| DP | batch 太大，吞吐低 | 梯度 all-reduce，开销中等 |
| TP | 单层权重太大，一张卡放不下 | 前向/后向各需一次 all-reduce/all-gather，延迟敏感 |
| PP | 层数太多，总参数量超过单卡 | 流水线传 activation，延迟敏感 |

三者组合后，`world_size = dp × tp × pp`。

### 1.2 进程排布约定

`mini_nanotron` 采用如下 rank 排布（与 Megatron-LM 一致）：

```text
rank = dp_idx * (pp * tp) + pp_idx * tp + tp_idx
```

以 `dp=2, tp=2, pp=2`（8 卡）为例：

```text
rank 0: dp=0, pp=0, tp=0
rank 1: dp=0, pp=0, tp=1   <- 与 rank0 同 TP 组
rank 2: dp=0, pp=1, tp=0
rank 3: dp=0, pp=1, tp=1
rank 4: dp=1, pp=0, tp=0   <- 与 rank0 同 DP 组
rank 5: dp=1, pp=0, tp=1
rank 6: dp=1, pp=1, tp=0
rank 7: dp=1, pp=1, tp=1
```

### 1.3 实现 MiniMPU

MPU（Model Parallel Unit）负责管理上面的进程组关系。

```text
class MiniMPU:
    def __init__(self, dp_size=1, tp_size=1, pp_size=1, backend=None):
        self.rank = int(os.environ.get("RANK", "0"))
        self.local_rank = int(os.environ.get("LOCAL_RANK", "0"))
        self.world_size = int(os.environ.get("WORLD_SIZE", "1"))
        self.dp_size = dp_size
        self.tp_size = tp_size
        self.pp_size = pp_size

        # 初始化 torch.distributed
        if self.world_size > 1 and not dist.is_initialized():
            backend = backend or ("nccl" if torch.cuda.is_available() else "gloo")
            if backend == "nccl":
                torch.cuda.set_device(self.local_rank)
            dist.init_process_group(backend=backend)

        self.groups = self._build_groups()
```

**`_build_groups`** 的关键：对每种并行模式，枚举出共享该模式的所有 rank 列表，然后创建 `dist.new_group`，自己在其中的那个 group 就是本进程所属的通信组。

```text
def _build_groups(self):
    # 张量并行组：固定 dp, pp，遍历 tp
    for dp in range(self.dp_size):
        for pp in range(self.pp_size):
            ranks = [dp * pp_size * tp_size + pp * tp_size + tp
                     for tp in range(self.tp_size)]
            group = dist.new_group(ranks=ranks)
            if self.rank in ranks:
                groups[ParallelMode.TENSOR] = group
    # 流水线并行组：固定 dp, tp，遍历 pp
    # 数据并行组：固定 pp, tp，遍历 dp
    ...
```

**`get_local_rank`** 的实现：

```text
def get_local_rank(self, mode):
    if mode == ParallelMode.TENSOR:
        return self.rank % self.tp_size               # tp_idx
    if mode == ParallelMode.PIPELINE:
        return (self.rank // self.tp_size) % self.pp_size  # pp_idx
    if mode == ParallelMode.DATA:
        return self.rank // (self.tp_size * self.pp_size)  # dp_idx
```

这三行公式就是从 rank 数字反推出在每个维度的位置。

### 第二步：数据并行（DP）

### 2.1 原理

DP 的做法是：每个 DP rank 各拿一份不同的数据，独立前向+后向，然后把梯度 **all-reduce** 求均值，相当于用了更大的 batch。

### 2.2 实现

最简单的方式是给每个参数注册一个反向钩子：

```text
class DataParallelWrapper(ParallelizationWrapper):
    def _parallelize(self):
        world_size = self.mpu.get_world_size(ParallelMode.DATA)
        group = self.mpu.get_group(ParallelMode.DATA)
        if world_size == 1:
            return
        for p in self.model.parameters():
            if not p.requires_grad:
                continue
            def hook(grad, group=group, world_size=world_size):
                dist.all_reduce(grad, group=group)  # 求和
                grad.div_(world_size)               # 求均值
                return grad
            p.register_hook(hook)
```

每次 backward，当某个参数的梯度计算完成，立刻触发 all-reduce，与同 DP 组的其他卡同步。这就是 DDP 的最简实现。

### 第三步：张量并行（TP）

### 3.1 原理

TP 的核心是把 `nn.Linear` 的权重矩阵沿列（Column）或行（Row）切分到多张卡上，每张卡只存和计算一部分，最后通过一次集合通信（all-gather 或 all-reduce）得到完整输出。

**线性层 `y = xW^T` 的两种切分方式：**

**① Column Parallel（沿输出维切分 W）**

```text
W: [out, in] → 每卡持有 [out/tp, in]

rank0: y0 = x * W0^T   shape: [batch, out/tp]
rank1: y1 = x * W1^T   shape: [batch, out/tp]

all-gather → y = [y0, y1]  shape: [batch, out]
```

适合 q/k/v_proj、gate/up_proj（后面接 RowParallel，不需要 gather，直接把切分后的输出传下去）。

**② Row Parallel（沿输入维切分 W）**

```text
W: [out, in] → 每卡持有 [out, in/tp]

前提：输入 x 也已经被切分（来自上游 ColumnParallel，gather_output=False）

rank0: y0 = x[..., :in/tp] * W0^T
rank1: y1 = x[..., in/tp:] * W1^T

all-reduce（sum）→ y = y0 + y1   shape: [batch, out]
```

适合 o_proj、down_proj。

**关键配对**：`ColumnParallel(gather_output=False)` → `RowParallel`，这对之间不需要额外通信，形成最小通信单元。只有最后 `lm_head` 用 `gather_output=True`，输出完整 logits。

### 3.2 实现 ColumnParallelLinear

```text
class ColumnParallelLinear(nn.Module):
    def __init__(self, linear, mpu, gather_output=True):
        ...
        per_out = out_features // self.world_size
        start = self.rank * per_out
        end = start + per_out
        self.weight = nn.Parameter(linear.weight.detach()[start:end].contiguous())
        self.bias = None if linear.bias is None else nn.Parameter(
            linear.bias.detach()[start:end].contiguous())

    def forward(self, x):
        y = F.linear(x, self.weight, self.bias)
        if not self.gather_output or self.world_size == 1:
            return y
        return _AllGatherLastDim.apply(y, self.group, self.world_size, self.rank)
```

注意 all-gather 必须用自定义 `autograd.Function` 才能正确传播梯度：

```text
class _AllGatherLastDim(torch.autograd.Function):
    @staticmethod
    def forward(ctx, x, group, world_size, rank):
        ctx.world_size = world_size
        ctx.rank = rank
        parts = [torch.empty_like(x) for _ in range(world_size)]
        dist.all_gather(parts, x.contiguous(), group=group)
        return torch.cat(parts, dim=-1)

    @staticmethod
    def backward(ctx, grad_output):
        # 反向时把梯度切回本 rank 对应的 shard
        chunks = grad_output.chunk(ctx.world_size, dim=-1)
        return chunks[ctx.rank].contiguous(), None, None, None
```

> **注意**：直接用 `dist.all_gather` 不会产生梯度，backward 会报 “does not require grad”。必须包成 `autograd.Function`。

### 3.3 实现 RowParallelLinear

```text
class RowParallelLinear(nn.Module):
    def __init__(self, linear, mpu):
        ...
        per_in = in_features // self.world_size
        start = self.rank * per_in
        end = start + per_in
        self.weight = nn.Parameter(linear.weight.detach()[:, start:end].contiguous())

    def forward(self, x):
        y = F.linear(x, self.weight, None)   # 输入已经是本 rank 的 shard
        if self.world_size > 1:
            dist.all_reduce(y, group=self.group)   # sum → 完整输出
        if self.bias is not None:
            y = y + self.bias
        return y
```

RowParallel 的 `all_reduce` 天然可微（all_reduce 对应的反向也是 all_reduce），所以不需要额外包 autograd.Function。

### 3.4 替换模型中的线性层

```text
class TensorParallelWrapper(ParallelizationWrapper):
    def _replace_linears(self, module):
        for name, child in list(module.named_children()):
            if isinstance(child, nn.Linear):
                if name in {"q_proj", "k_proj", "v_proj", "gate_proj", "up_proj", "fc1"}:
                    setattr(module, name, ColumnParallelLinear(child, self.mpu, gather_output=False))
                elif name in {"o_proj", "down_proj", "fc2"}:
                    setattr(module, name, RowParallelLinear(child, self.mpu))
                elif name == "lm_head":
                    setattr(module, name, ColumnParallelLinear(child, self.mpu, gather_output=True))
            else:
                self._replace_linears(child)   # 递归处理子模块
```

### 第四步：流水线并行（PP）

### 4.1 原理

PP 把模型的层（通常是 Transformer Block）按阶段（stage）分到不同卡。比如 4 层模型跑 PP=2：

```text
stage 0（rank pp=0）：layer0, layer1
stage 1（rank pp=1）：layer2, layer3
```

这份 `mini_nanotron` 实现的是最简化的 naive PP：不同 stage 的 rank 直接跑完整模型，但只保留本 stage 的层，其余层换成 `nn.Identity()`（相当于直接透传 activation）。

这简化了实现，但没有做真正的流水线调度，本质上 stage 0 算完才到 stage 1，存在 bubble（闲置时间）。真实的 Megatron 实现了 1F1B 等调度算法来减少 bubble，这里不展开。

### 4.2 实现

```text
def partition_layers(num_stages, num_layers):
    # 把 num_layers 尽量均匀分给 num_stages 个阶段
    base = num_layers // num_stages
    remainder = num_layers % num_stages
    parts = [0]
    for stage in range(num_stages):
        parts.append(parts[-1] + base + (1 if stage < remainder else 0))
    return parts

class PipelineParallelWrapper(ParallelizationWrapper):
    def _parallelize(self):
        stage = self.mpu.get_local_rank(ParallelMode.PIPELINE)
        layers = getattr(self.model, self.layers_attr)
        parts = partition_layers(pp_size, len(layers))
        start, end = parts[stage], parts[stage + 1]
        for i in range(len(layers)):
            if i < start or i >= end:
                layers[i] = nn.Identity()   # 本 stage 不负责的层直接透传
```

### 第五步：包装器注册机制

以上三种并行通过统一的包装器接口组合在一起。

### 5.1 ParallelizationWrapper

```text
class ParallelizationWrapper:
    priority = 0
    def __init__(self, model, mpu):
        self.model = model
        self.mpu = mpu

    def _parallelize(self):
        raise NotImplementedError
```

每种并行继承此类并实现 `_parallelize()`，通过 `priority` 控制执行顺序（DP 最先、TP 其次、PP 最后），避免相互干扰。

### 5.2 register_wrapper

```text
def register_wrapper(model, mode, wrapper):
    if not hasattr(model, "__mini_wrappers__"):
        model.__mini_wrappers__ = OrderedDict()

        def parallelize(self):
            wrappers = sorted(self.__mini_wrappers__.values(),
                              key=lambda w: w.priority, reverse=True)
            for wrapper in wrappers:
                wrapper._parallelize()
            return self

        model.parallelize = types.MethodType(parallelize, model)
    model.__mini_wrappers__[mode] = wrapper
    return model
```

注册后，`model.parallelize()` 会按优先级顺序执行所有 `_parallelize()`，一次性完成 3D 并行的全部替换和设置。

### 5.3 便捷 API

```text
def TensorParallel(model, mpu):
    wrapper = TensorParallelWrapper(model, mpu) if mpu.get_world_size(ParallelMode.TENSOR) > 1 \
              else NoParallelWrapper(model, mpu)
    return register_wrapper(model, ParallelMode.TENSOR, wrapper)

def PipelineParallel(model, mpu): ...
def DataParallel(model, mpu): ...
```

调用顺序无所谓，最终 `model.parallelize()` 会保证正确顺序。

### 第六步：定义一个玩具模型

完整运行需要一个 Transformer 模型作为验证目标，`mini_nanotron` 内置了一个最小化版本：

```text
class MiniTransformerBlock(nn.Module):
    def __init__(self, hidden_size, intermediate_size):
        super().__init__()
        self.norm1 = nn.LayerNorm(hidden_size)
        self.q_proj = nn.Linear(hidden_size, hidden_size)   # TP: ColumnParallel
        self.k_proj = nn.Linear(hidden_size, hidden_size)   # TP: ColumnParallel
        self.v_proj = nn.Linear(hidden_size, hidden_size)   # TP: ColumnParallel
        self.o_proj = nn.Linear(hidden_size, hidden_size)   # TP: RowParallel
        self.norm2 = nn.LayerNorm(hidden_size)
        self.gate_proj = nn.Linear(hidden_size, intermediate_size)  # TP: ColumnParallel
        self.up_proj = nn.Linear(hidden_size, intermediate_size)    # TP: ColumnParallel
        self.down_proj = nn.Linear(intermediate_size, hidden_size)  # TP: RowParallel
```

层名称与 Megatron / LLaMA 命名一致，TensorParallelWrapper 通过层名称直接识别该用哪种切分。

```text
# 6. 正常训练

optimizer.zero_grad()

loss.backward()    # 自动触发 DP all-reduce hook
optimizer.step()
```

### 常见问题

**Q: TP all-gather 为什么要自定义 autograd.Function？**

`dist.all_gather` 不会自动注册到 PyTorch 的自动微分图中，对 autograd 来说结果 tensor 没有 `grad_fn`，backward 会直接报错。通过 `autograd.Function` 手动定义 forward/backward 才能把梯度流接通。

**Q: TP 的 ColumnParallel → RowParallel 中间为什么不需要通信？**

ColumnParallel(gather_output=False) 的输出是本 rank 的切片 `y[..., shard]`，RowParallel 的权重也切了对应的输入维，两者相乘后 all-reduce 恰好还原完整输出。这是 Megatron-LM 论文（Shoeybi et al. 2019）的核心设计，一个 Attention/FFN 模块只需 **2 次 all-reduce**（Attention 一次，FFN 一次），通信量最小。

**Q: 这份实现的 PP 和真实 Megatron 的差别？**

这里用 `nn.Identity()` 替换非本 stage 的层，所有 rank 都跑完整 forward，没有真正的流水线调度。真实实现需要 rank 之间通过 send/recv 传递 activation，并实现 1F1B micro-batch 调度。这部分代码量较多，本教程省略。

### 完整代码

```text
from collections import OrderedDict
from dataclasses import dataclass
from enum import Enum
import os
import types

import torch
import torch.distributed as dist
import torch.nn as nn
import torch.nn.functional as F

class ParallelMode(Enum):
    GLOBAL = "global"
    DATA = "data"
    TENSOR = "tensor"
    PIPELINE = "pipeline"

class MiniMPU:
    def __init__(self, dp_size=1, tp_size=1, pp_size=1, backend=None):
        self.rank = int(os.environ.get("RANK", "0"))
        self.local_rank = int(os.environ.get("LOCAL_RANK", "0"))
        self.world_size = int(os.environ.get("WORLD_SIZE", "1"))
        self.dp_size = dp_size
        self.tp_size = tp_size
        self.pp_size = pp_size

        expected = dp_size * tp_size * pp_size
        if self.world_size != expected:
            raise ValueError(f"WORLD_SIZE({self.world_size}) must equal dp_size*tp_size*pp_size({expected})")

        if self.world_size > 1 and not dist.is_initialized():
            if backend is None:
                backend = "nccl" if torch.cuda.is_available() else "gloo"
            if backend == "nccl":
                device_count = torch.cuda.device_count()
                local_world_size = int(os.environ.get("LOCAL_WORLD_SIZE", "1"))
                if local_world_size > device_count:
                    raise RuntimeError(
                        f"torchrun started {local_world_size} local processes, but only {device_count} CUDA devices are visible. "
                        "Use --nproc_per_node no larger than the visible GPU count, or set CUDA_VISIBLE_DEVICES correctly."
                    )
                if self.local_rank >= device_count:
                    raise RuntimeError(f"LOCAL_RANK({self.local_rank}) is out of range for {device_count} visible CUDA devices")
                torch.cuda.set_device(self.local_rank)
            dist.init_process_group(backend=backend)

        self.groups = self._build_groups()

    def _new_group(self, ranks):
        if self.world_size == 1:
            return None
        return dist.new_group(ranks=ranks)

    def _build_groups(self):
        groups = {
            ParallelMode.GLOBAL: None,
            ParallelMode.DATA: None,
            ParallelMode.TENSOR: None,
            ParallelMode.PIPELINE: None,
        }
        if self.world_size == 1:
            return groups

        for dp in range(self.dp_size):
            for pp in range(self.pp_size):
                ranks = [dp * self.pp_size * self.tp_size + pp * self.tp_size + tp for tp in range(self.tp_size)]
                group = self._new_group(ranks)
                if self.rank in ranks:
                    groups[ParallelMode.TENSOR] = group

        for dp in range(self.dp_size):
            for tp in range(self.tp_size):
                ranks = [dp * self.pp_size * self.tp_size + pp * self.tp_size + tp for pp in range(self.pp_size)]
                group = self._new_group(ranks)
                if self.rank in ranks:
                    groups[ParallelMode.PIPELINE] = group

        for pp in range(self.pp_size):
            for tp in range(self.tp_size):
                ranks = [dp * self.pp_size * self.tp_size + pp * self.tp_size + tp for dp in range(self.dp_size)]
                group = self._new_group(ranks)
                if self.rank in ranks:
                    groups[ParallelMode.DATA] = group

        return groups

    def get_group(self, mode):
        return self.groups[mode]

    def get_global_rank(self):
        return self.rank

    def get_world_size(self, mode=ParallelMode.GLOBAL):
        if mode == ParallelMode.DATA:
            return self.dp_size
        if mode == ParallelMode.TENSOR:
            return self.tp_size
        if mode == ParallelMode.PIPELINE:
            return self.pp_size
        return self.world_size

    def get_local_rank(self, mode=ParallelMode.GLOBAL):
        if mode == ParallelMode.TENSOR:
            return self.rank % self.tp_size
        if mode == ParallelMode.PIPELINE:
            return (self.rank // self.tp_size) % self.pp_size
        if mode == ParallelMode.DATA:
            return self.rank // (self.tp_size * self.pp_size)
        return self.rank

    def destroy(self):
        if dist.is_available() and dist.is_initialized():
            dist.destroy_process_group()

class ParallelizationWrapper:
    priority = 0

    def __init__(self, model, mpu):
        self.model = model
        self.mpu = mpu
        self.original_forward = model.forward

    def _parallelize(self):
        raise NotImplementedError

    def _forward(self, *args, **kwargs):
        return self.original_forward(*args, **kwargs)

def register_wrapper(model, mode, wrapper):
    if not hasattr(model, "__mini_wrappers__"):
        model.__mini_wrappers__ = OrderedDict()

        def parallelize(self):
            wrappers = sorted(self.__mini_wrappers__.values(), key=lambda w: w.priority, reverse=True)
            for wrapper in wrappers:
                wrapper._parallelize()
            return self

        model.parallelize = types.MethodType(parallelize, model)
    model.__mini_wrappers__[mode] = wrapper
    return model

class DataParallelWrapper(ParallelizationWrapper):
    priority = 2

    def _parallelize(self):
        world_size = self.mpu.get_world_size(ParallelMode.DATA)
        group = self.mpu.get_group(ParallelMode.DATA)
        if world_size == 1:
            return
        for p in self.model.parameters():
            if not p.requires_grad:
                continue

            def hook(grad, group=group, world_size=world_size):
                dist.all_reduce(grad, group=group)
                grad.div_(world_size)
                return grad

            p.register_hook(hook)

class _AllGatherLastDim(torch.autograd.Function):
    @staticmethod
    def forward(ctx, x, group, world_size, rank):
        ctx.world_size = world_size
        ctx.rank = rank
        parts = [torch.empty_like(x) for _ in range(world_size)]
        dist.all_gather(parts, x.contiguous(), group=group)
        return torch.cat(parts, dim=-1)

    @staticmethod
    def backward(ctx, grad_output):
        chunks = grad_output.chunk(ctx.world_size, dim=-1)
        return chunks[ctx.rank].contiguous(), None, None, None

class ColumnParallelLinear(nn.Module):
    def __init__(self, linear, mpu, gather_output=True):
        super().__init__()
        self.mpu = mpu
        self.gather_output = gather_output
        self.rank = mpu.get_local_rank(ParallelMode.TENSOR)
        self.world_size = mpu.get_world_size(ParallelMode.TENSOR)
        self.group = mpu.get_group(ParallelMode.TENSOR)
        out_features, in_features = linear.weight.shape
        if out_features % self.world_size != 0:
            raise ValueError(f"out_features({out_features}) must be divisible by tensor parallel size({self.world_size})")
        per_out = out_features // self.world_size
        start = self.rank * per_out
        end = start + per_out
        self.in_features = in_features
        self.out_features = per_out
        self.weight = nn.Parameter(linear.weight.detach()[start:end].contiguous())
        self.bias = None if linear.bias is None else nn.Parameter(linear.bias.detach()[start:end].contiguous())

    def forward(self, x):
        y = F.linear(x, self.weight, self.bias)
        if not self.gather_output or self.world_size == 1:
            return y
        return _AllGatherLastDim.apply(y, self.group, self.world_size, self.rank)

class RowParallelLinear(nn.Module):
    def __init__(self, linear, mpu):
        super().__init__()
        self.mpu = mpu
        self.rank = mpu.get_local_rank(ParallelMode.TENSOR)
        self.world_size = mpu.get_world_size(ParallelMode.TENSOR)
        self.group = mpu.get_group(ParallelMode.TENSOR)
        out_features, in_features = linear.weight.shape
        if in_features % self.world_size != 0:
            raise ValueError(f"in_features({in_features}) must be divisible by tensor parallel size({self.world_size})")
        per_in = in_features // self.world_size
        start = self.rank * per_in
        end = start + per_in
        self.in_features = per_in
        self.out_features = out_features
        self.weight = nn.Parameter(linear.weight.detach()[:, start:end].contiguous())
        self.bias = None if linear.bias is None else nn.Parameter(linear.bias.detach().clone())

    def forward(self, x):
        y = F.linear(x, self.weight, None)
        if self.world_size > 1:
            dist.all_reduce(y, group=self.group)
        if self.bias is not None:
            y = y + self.bias
        return y

class TensorParallelWrapper(ParallelizationWrapper):
    priority = 1

    def _replace_linears(self, module):
        for name, child in list(module.named_children()):
            if isinstance(child, nn.Linear):
                if name in {"q_proj", "k_proj", "v_proj", "gate_proj", "up_proj", "fc1"}:
                    setattr(module, name, ColumnParallelLinear(child, self.mpu, gather_output=False))
                elif name in {"o_proj", "down_proj", "fc2"}:
                    setattr(module, name, RowParallelLinear(child, self.mpu))
                elif name == "lm_head":
                    setattr(module, name, ColumnParallelLinear(child, self.mpu, gather_output=True))
            else:
                self._replace_linears(child)

    def _parallelize(self):
        if self.mpu.get_world_size(ParallelMode.TENSOR) == 1:
            return
        self._replace_linears(self.model)

def partition_layers(num_stages, num_layers):
    base = num_layers // num_stages
    remainder = num_layers % num_stages
    parts = [0]
    for stage in range(num_stages):
        parts.append(parts[-1] + base + (1 if stage < remainder else 0))
    return parts

class PipelineParallelWrapper(ParallelizationWrapper):
    priority = 0

    def __init__(self, model, mpu, layers_attr="layers"):
        super().__init__(model, mpu)
        self.layers_attr = layers_attr

    def _parallelize(self):
        pp_size = self.mpu.get_world_size(ParallelMode.PIPELINE)
        if pp_size == 1:
            return
        stage = self.mpu.get_local_rank(ParallelMode.PIPELINE)
        layers = getattr(self.model, self.layers_attr)
        parts = partition_layers(pp_size, len(layers))
        start, end = parts[stage], parts[stage + 1]
        for i in range(len(layers)):
            if i < start or i >= end:
                layers[i] = nn.Identity()

class NoParallelWrapper(ParallelizationWrapper):
    priority = -1

    def _parallelize(self):
        return

def TensorParallel(model, mpu):
    wrapper = NoParallelWrapper(model, mpu) if mpu.get_world_size(ParallelMode.TENSOR) <= 1 else TensorParallelWrapper(model, mpu)
    return register_wrapper(model, ParallelMode.TENSOR, wrapper)

def PipelineParallel(model, mpu):
    wrapper = NoParallelWrapper(model, mpu) if mpu.get_world_size(ParallelMode.PIPELINE) <= 1 else PipelineParallelWrapper(model, mpu)
    return register_wrapper(model, ParallelMode.PIPELINE, wrapper)

def DataParallel(model, mpu):
    wrapper = NoParallelWrapper(model, mpu) if mpu.get_world_size(ParallelMode.DATA) <= 1 else DataParallelWrapper(model, mpu)
    return register_wrapper(model, ParallelMode.DATA, wrapper)

@dataclass
class MiniOutput:
    loss: torch.Tensor | None
    logits: torch.Tensor

class MiniTransformerBlock(nn.Module):
    def __init__(self, hidden_size, intermediate_size):
        super().__init__()
        self.norm1 = nn.LayerNorm(hidden_size)
        self.q_proj = nn.Linear(hidden_size, hidden_size)
        self.k_proj = nn.Linear(hidden_size, hidden_size)
        self.v_proj = nn.Linear(hidden_size, hidden_size)
        self.o_proj = nn.Linear(hidden_size, hidden_size)
        self.norm2 = nn.LayerNorm(hidden_size)
        self.gate_proj = nn.Linear(hidden_size, intermediate_size)
        self.up_proj = nn.Linear(hidden_size, intermediate_size)
        self.down_proj = nn.Linear(intermediate_size, hidden_size)

    def forward(self, x):
        h = self.norm1(x)
        q = self.q_proj(h)
        k = self.k_proj(h)
        v = self.v_proj(h)
        attn = torch.softmax(q @ k.transpose(-1, -2) / (q.size(-1) ** 0.5), dim=-1)
        x = x + self.o_proj(attn @ v)
        h = self.norm2(x)
        x = x + self.down_proj(F.silu(self.gate_proj(h)) * self.up_proj(h))
        return x

class MyTransformerModel(nn.Module):
    def __init__(self, vocab_size=128, hidden_size=32, intermediate_size=64, num_layers=2):
        super().__init__()
        self.embed_tokens = nn.Embedding(vocab_size, hidden_size)
        self.layers = nn.ModuleList([MiniTransformerBlock(hidden_size, intermediate_size) for _ in range(num_layers)])
        self.norm = nn.LayerNorm(hidden_size)
        self.lm_head = nn.Linear(hidden_size, vocab_size, bias=False)

    def forward(self, input_ids, labels=None):
        x = self.embed_tokens(input_ids)
        for layer in self.layers:
            x = layer(x)
        logits = self.lm_head(self.norm(x))
        loss = None
        if labels is not None:
            loss = F.cross_entropy(logits[..., :-1, :].contiguous().view(-1, logits.size(-1)), labels[..., 1:].contiguous().view(-1))
        return MiniOutput(loss=loss, logits=logits)

def build_demo_batch(batch_size=2, seq_len=16, vocab_size=128, device=None):
    device = device or ("cuda" if torch.cuda.is_available() else "cpu")
    input_ids = torch.randint(0, vocab_size, (batch_size, seq_len), device=device)
    labels = input_ids.clone()
    return input_ids, labels
```
