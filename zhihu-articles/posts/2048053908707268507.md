## NVIDIA TensorRT：深度学习推理加速的开源组件库

TensorRT 在 GitHub 上已经拿到 13K Star 了。

NVIDIA 开源的这个仓库，是 TensorRT 推理引擎的 OSS 组件集合。包含插件、解析器和示例代码，帮开发者在 GPU 上把训练好的模型跑出更高吞吐。

### 1、TensorRT 干了什么事

做过模型部署的人都清楚：训练出来的 PyTorch 或 TensorFlow 模型，直接上线推理，GPU 利用率可能不到 30%。

TensorRT 做的就是在推理前对整个计算图做一轮优化。算子合并、内存分配策略调整、低精度量化校准。比如把卷积、BatchNorm 和 ReLU 三层融合成一个 kernel，减少显存读写次数。QKV 注意力机制里能合并的操作也一并处理。最终效果是延迟更低、吞吐更高，同样的硬件服务更多请求。

这个仓库是 TensorRT 的开源部分。核心优化引擎和 Builder 在商业 GA 版本里闭源发布，插件、解析器、示例全部公开在了这里。

### 2、仓库里有什么

三块内容。

插件库。TensorRT 原生支持的算子覆盖了主流模型结构，但遇到自定义算子或新论文里的操作，需要插件来扩展。插件 API 用 C++ 写自己的算子实现，编译后注册进 runtime。

解析器。目前提供 Caffe 和 ONNX 两种。作用是把训练框架产出的模型文件解析成 TensorRT 能优化的内部表示。ONNX 解析器用得最广，几乎所有训练框架都能导出 ONNX 格式。

示例代码。覆盖图像分类、目标检测、语义分割、NLP 推理等常见任务。每个示例包含完整的构建配置和推理代码，拿来改改就能嵌进自己的项目。

### 3、构建流程

支持 Linux x86、Windows、Jetson（aarch64）和 QNX 四个平台。推荐用 Docker 做容器化构建，仓库提供了 Ubuntu 18.04、CentOS 7 和 Jetson 交叉编译的 Dockerfile。

构建命令不复杂：

```text
mkdir build && cd build
cmake .. -DTRT_LIB_DIR=$TRT_LIBPATH -DTRT_OUT_DIR=$(pwd)/out
make -j$(nproc)
```

几个有用的参数：GPU_ARCHS 可以指定目标 GPU 架构来缩减编译时间，A100 写 80、T4 写 75。BUILD_PARSERS 和 BUILD_PLUGINS 按需开关解析器和插件编译。依赖项包括 CUDA 11.4、cuDNN 8.2、cmake 3.13+、protobuf 3.0.0，都在 NVIDIA 开发者官网能下到。

### 4、平台覆盖

![](https://pic3.zhimg.com/v2-eb899bd9c00aa36f9a1b5f1e8c0199c4_r.jpg)

TensorRT OSS 的平台覆盖比较全面。数据中心用 Linux x86 加 Docker 容器化构建，工作站可以用 Windows 加 VS 2017 原生编译。边缘端支持 Jetson 平台，通过 JetPack SDK 和交叉编译工具链出 aarch64 二进制。QNX 工具链也给了，适合车载和工控场景。

### 5、谁适合用这个仓库

做 GPU 推理部署的 AI 工程师，在用 TensorRT 但缺少某个自定义算子的参考实现，这里有现成代码。给 TensorRT 贡献插件或解析器功能的开发者，仓库里有完整的贡献指南和编码规范。做边缘推理的团队，Jetson 平台的交叉编译支持能省掉一套 CI 配置。代码贡献走 Pull Request，需要签署 NVIDIA 的 CLA 协议。Changelog 里有每次版本更新的明细。
