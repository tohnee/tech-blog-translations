两个月没写知乎了。技术文章的话四个月没写了，以后可能也写的越来越少了，一年能憋个一两篇就算胜利～究其原因还是这几个月 llm模型的提升有点小狠，大多数问题直接丢给 ai 让它写个 html 的报告出来，基本上可读性都比我写文章要好。所以对于后面还要做些啥，我想了两个月也是暂时没啥思路，产生了是否要离开 llm infra 这个行业的一些想法。所以今天也是来杂谈下这个行业可能还有啥想继续做做的事，以及对跑路的一些心得体会。

领导也是找我谈话，说我最近产出有点少，之前也很多事没能闭环，让我赶紧编点产出出来。但是我想我跟他的站位还是不太一样。这家 start up 是他第一家公司，他 phd 刚毕业对事业很有热情，还是老板们嫡系能去参加高层会议。我么今年已经打工第五年了，依然大头兵一个，跟老板们开不上会也不知道老板们想干啥。而且也不是太想去抗压力带团队，并且颇有跑路经验。而且我都来start up还要去装样子编点产出，那我不是白来了，想不到啥要干的不如直接不干，等着喜提 n+1。不过打工嘛其实就是这个样子，很多事情其实大家都知道没啥意思，但还是得闭环给老板们提供个情绪价值。

回顾我过去四年的工作历程，80% 的工作都是毫无意义的，现在还在线上服役的优质代码也没多少，倒是传统 coding 年代留的几个逆天 bug 至今无人能解，每次看到有人吐槽我都要笑开花了(哈哈就是我写的～)。 而到了今天，在 llm infra 这个方向，我觉得这个比例提高到 95%都啥没问题，尤其是行业里有着 deepseek 这位源神的存在。也就是每年最有价值的产出，我觉得就是那么几周写出来的，剩下的时间就是纯在给领导老板画饼，混个工资领领。除此之外还有个心态上大的变化，就是代码都是 ai 在写之后，也是剥夺了写代码本身的乐趣，让我不仅对 llm infra 的兴趣降低了很多，甚至是对整个计算机行业的兴趣都开始大幅降低了。如果说 coding 这件事本质上就是 ai 干的更好，那人还去干 coding 干啥，不如早早转行去当产品得了，可能还更有意思些。

最近面了不少明年的应届生，想要加入 llm infra 的大军。看着他们热情洋溢的神情，真的是感叹自己老了，真成老登了。很多人在面试提问阶段，问我进来后会让他们去做什么。做什么呢？我也在懵逼呢。我要知道要做什么 agent 上去夸夸就干完了，还等得到明年你进来让你干？尤其是还在写算子的哥们，我都不知道咋面，明年还有没有需要人的算子这个岗位都不知道。所以应届大哥们，别问我这个问题了，问的我很慌。我怕我饼画的不好直接露馅了，你们就不来了 QAQ。

源神最近也是已经把DeepInfer开源了，说白了也就那样了，也没啥真三体科技，当然吊打下我还是绰绰有余。其实对于推理来说最有价值的还是线上数据和调度，那部分是不会开源的，也是各个公司创造推理营收的核心部分。不过我就只参与算子和框架，上线那边我是从来没参与过，所以说肉眼可见的，我做的部分在变得越来越没有价值，agent 框框干全干完了我就一边看就完事了。所以说开源的意义是什么，我觉得开源最重要的就是体现一个公司在商业价值上的判断，什么东西是赚不到钱的。那么开源了之后，赚个好的口碑以及让底下干活的人更有普世价值的目标感，以及干开源跑路更方便大家也更有干劲。如果有信心在人才招募上能占据市场头部位置，那么人才培养和流通越强，对头部玩家是越有利的。

而且DeepInfer在这个时间点开源，也是有点耐人寻味，感觉可能是小难梁给昇腾下达了最高指示，让 960 加速上市。我觉得其实看推理公司的融资多少能看出点门道，llm 推理在coding 上虽然落地了，但是落地的很不 sexy，利润率远远没有想象中高，纯纯的长周期重资产行业，比奶头乐都差得远。所以 vc 在跑路，更多的是地方国资和产业资金在进来，他们喜欢投这样能看到显性现金流产出的方向。小难梁之前开会也说，没有哪家能把这个市场全部吃光，核心就是硬件厂不可能把卡全卖给一家公司。既然硬件产能就那么多，能分到的份额就那么多，那不如开源出来给昇腾背个书，让某些资金放心去买。反正到时候这些人买了去跑 deepseek 的模型，到时候营收口径就直接改成“deepseek 系列模型产生的 gdp”，上市了让国家队去拉，说不定还能进社保养老的标的。反正爱国大模型的情绪价值到位了，散户就来了，流动性就有了。

按照DeepInfer里给出的 v4.1 flash 的吞吐来算，等明年的 960 全部上线，如果 960 的软硬件没问题，这个行业也没有大的突破，那么国内在 flash 这个级别的 token 基本上就能完全满足了。所以 960 提前上市的优势就是，昇腾把国内硬件产能占了大半，deepseek 的 v4.1 flash 把 flash 级别的 token 生态位立住了，那么在 970 发之前 960 差不多就回本了，当然也不知道到时候 960 是不是坐地起价就是了 hhh。至少按现在的行情来看，deepseek的这个背书是成立的，这波就是卖家秀了。

然后另一点就是目前看起来 1T以内的flash 效果很不错，但是 1～2T 的尺寸比起1T的能力提升不大成本却增加很多。所以我感觉等flash暂时训到头了之后，下面的大尺寸的模型会直接到 3～5T 以上。但是3～5T的模型推理的成本，还能不能在 coding 场景去落地，这件事我还是存疑的。从oa 大战也能看出来，即使美国人力资源贵的多，对新的 sota 模型带来的成本，也是吃不消了，营收上涨在放缓。而且说白了就是很多领导都不在一线写代码了，真写过就知道 v4.1 能干非常多的活了，有些活压根没有上大大模型的必要。尤其是最近 astra 跟弱智一样，还不如 v4.1 ，我都打算退订了。

所以从这个角度来说，昇腾除了能拿来推理，还能有点未来训练大大模型的可能性。再加上把产能占了不少，应该还是能好好再卖个几年。但是对于其他几家国产硬件厂么，感觉前途是有那么点堪忧。那几家现在可能也就在异构 pd 场景能有点性价比了。不过之后如果 L1.5 的 hbm pool 要能落地的话，异构 pd 这个事儿还有没有价值我是存疑的。反正那几家不配 n 卡做 decode肯定是推不动 3～5T 的模型，我觉得是板上钉钉的事。

其实 llm 本身能跑出来也是个挺奇迹的事儿了，要是到 30t 才能智能涌现，然后再蒸馏成小模型的话，那可能干到一半就没钱了直接挂了。所以抛开 linear 和 sparse 到底哪个效果会更好，这个谁也不知道的神之提问，sparse看起来至少是个更务实点的选择。先确保手头的钱能把路跑通，再试试其他的思路效果如何。我想flash模型也是这样的思路，模型小了更好落地也更好尝试更多训练方向，这个思路也是比较符合亚洲人的心路历程的。

随着现在计算和 data 的成本倒挂，我也是在想能做些啥，让数据量和数据移动减少。linear最有价值的点就是那个状态矩阵大小固定，但是么在现在的模型架构和 gpu 架构上，即使是固定大小的一个小矩阵，还是要在 hbm 和寄存器间搬来搬去。不知道状态矩阵增大会不会让 linear 的效果提升很多，如果能把纯linear的模型跑通，那么把状态矩阵留在比 hbm 更上一层的存储介质里就有价值的多了，功耗会降低非常多，更有那么些 asic 的潜力。我觉得现在 agent 的能力越来越强，在编程和软件设计上不再是按照原来的人类审美来看了。即使编程模型很复杂，只要效果好，就有让硬件去暴露更多给上层使用的价值。

然后另一个想法就是压缩 + 重算去代替纯 cache 的结果。在 agent 有现在的能力之前，我是肯定不去想这些玩意的，迟早把存储干成 L0 , L0.5 , L1 , L1.5 , L2 , L2.5 , L3 ……要没有 agent 让我自己去想这种事儿我肯定是懒得想，想出来了也写不出来or2。 但是有了 agent 那直接 pua agent 去想这些问题，多是一件美事。所以我是更喜欢 ds 最近的模型，在 agent 时代来说，很有设计和探索感，也符合中国人把所有东西干成白菜价的心态。k3 就是给人感觉很拧巴，感觉很想在 3T 这个节点上一定要拿出点什么来，也不知道之前到底是谁在传 3T 斩杀线。要是能把纯linear的极限去探一探，感觉也是更有意思的探索。

这些想法也是动摇我要不要离开当前公司的想法。我们现在是个纯推理的公司，一直被夹在模型厂和硬件厂中间，没什么主动出击的机会。都说要在 system 层面做 co-design，但是我们这样的定位只有被 design 的被动挨打的机会。不过感觉纯硬件厂也是被动挨打的局面了，昇腾只有被 deepseek 去 design，那天小难梁就自己造卡一脚给它踢了。不过就 llm 现在的卷度，外面能有机会做这些事儿的地方，可能也没位置就是了。就算去了又要熟悉新环境，取得领导信任，完了带团队抗压力去干，也挺操蛋的。而且在 sparse 和 linear 之间还是大肥鱼更香，每天上班摸摸鱼下班看大肥鱼，这样的生活也挺舒适的。我一直是个不太爱努力的人，觉得要拼去获得的位置，多半就是当前也不适合我的位置。人生几十年，也不是特别想被一定要做点啥的想法 push，做做咸鱼看别人发挥神力也挺好。

至于说到想离开llm infra行业嘛，就是对这个方向当前的叙事逻辑不太认同。一个打算上市的公司，招股书里写着如何把大家搞失业，如何毁灭全人类。我觉得语言本身的上限就在那了，把数字世界语言相关的部分加速的再多，其他部分也还是停在原地。如果只是为了把更多的人搞失业，那 agi 就算彻底失败了。我觉得 agi 的突破还是得看如何融入对物理世界的理解，去创造一些人类世界还没有的东西出来。所以作为一个人来说，llm 对我来说是不如aigc。llm 让我失去了编程的乐趣，aigc 却给我带来了看大肥鱼的乐趣，当然我也没想回到古法 coding 的年代。古法 coding 只是计算机科学发展中的一个小插曲，是计算机科学发展早期的手工业特质。如今的计算机才算是真正进入了新的自动化工业体系时代。

说白了，一堆人生活不能过得更好，难道是生产力太落后了吗？老家猪肉六块多一斤，大闸蟹二十五一只，照样储蓄率继续提升没人去吃。所以说还是aigc好，大家吃不起螃蟹，还看不起红果吗？如果我要离开llm infra行业的话，大概率会想先去看看游戏行业了。或者说现在开始自己一个人做游戏试试也完全 ok 了。如今的模型的能力已经够我用了，硬件拐点也到了，但是却没啥好的游戏能玩。最近出现了很多用 agent 去做跨平台转译的项目，我想热爱游戏又做技术的人，最近基本上都能看到这个趋势。

不知道华为是真有牛的产品还是刚好撞上了，我觉得如今的经济周期，对大多数人来说，就是从工作脱身出来，更多转向休养生息的时间点。阔直板和阔折叠那样的比例，我是非常爱的，给手机平板用的手柄最近买了得有十几个，都尝试了一遍，就是该死的存储把消费电子快干死了。反正最近能自己折腾的东西也不少，暂时也不用马上做跑路决定就是。而且在agent 时代，下一段旅程有没有必要再给别人打工了，也是个未知数呢。

其实说白了，最终就是 bound 在人这里。人生而有涯而人类文明也无涯，人类文明如果发展到小部分人螺旋飞升，那是它的归宿。作为一个大概率赶不上飞升的原始人，在灵气复苏后该如何去自居是这个时代每个人都要去面对的问题。攀上宗门，忙忙碌碌一生筑个基，最后被炼化成药渣；天命之子飞升，舍我其谁；还是做个散修，趁着还有些灵气外溢，玩一波就嘎。其实比起我们这些老登，感觉应届的学生还要更迷茫。宗门入门考核也进不去，也没有旧时代的修炼经验，散修也做不明白。害，还是继续看大肥鱼吧 0^0
