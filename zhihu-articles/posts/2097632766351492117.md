最近 Agent Memory 的研究越来越热。从 Mem0、MemOS 到 EverMemOS，大家都在尝试让 Agent 拥有更强的长期记忆能力，包括记忆提炼、动态更新、知识图谱和分层存储。

上交、西交等学校的新论文《Is Complex Agentic Memory Always Needed》提出了一个很有意思的问题：花了这么大力气设计复杂的 Memory 系统，真的比直接检索原始历史记录更好吗？

![](https://pic2.zhimg.com/v2-39925dcac0e37b74b4c90f1604bab373_r.jpg)

研究者提出了一个非常朴素的方法 RAW-RAG，并与多个主流 Agent Memory 系统进行比较。

结果有些出乎意料。

## 1. 朴素 RAG，竟然赢了大部分复杂 Memory

RAW-RAG 的设计很简单：

- 保留原始对话历史，不提前提炼成结构化记忆。
- 通过 Embedding 召回相关片段，再用 Reranker 精排。
- 将检索到的证据交给 LLM，由模型理解历史、处理时间关系并回答。

没有复杂的记忆管理 Agent，也不需要知识图谱或动态更新策略。

![](https://pic3.zhimg.com/v2-c477845dbde53f3d3cd30d45fd3c5c3c_r.jpg)

研究者在 LoCoMo、LongMemEval、MEME、MemoryAgentBench 四个长期记忆基准上进行了评测。

7 组基准与模型组合中，RAW-RAG 在 6 组取得第一，最高领先最强的复杂记忆系统 5.53 个百分点。

需要说明，这里的第一是相对于参与比较的独立记忆系统。

这至少说明，复杂 Memory 带来的能力提升，并没有我们想象中那么确定。

## 2. 记忆提炼得越多，效果可能反而越差

论文还有一组很有意思的消融实验。

在 MemoryAgentBench 上，原始 RAW-RAG 的准确率为 48.32%。

研究者分别加入不同的记忆处理能力：

- 加入摘要：降至 42.51%。
- 加入知识图谱扩展检索：降至 42.54%。
- 提取原子事实：直接降至 28.70%。

尤其是原子事实提取，准确率下降了近 20 个百分点。

因为很多时候，Agent 需要的不只是某个结论，还包括结论背后的上下文、操作步骤、时间关系和依赖路径。

例如，一段完整对话记录了用户如何修改方案，以及每次修改的原因。

如果 Memory 系统只提炼出最终方案，就可能丢失中间的决策依据。

![](https://pic3.zhimg.com/v2-6ba1ce87eb4c841c7183e6dd6caf9428_r.jpg)

未来 Agent 再遇到类似问题时，虽然记住了结果，却未必能还原整个过程。

过度提炼记忆，可能让 Agent 丢失真正有价值的信息。

## 3. Memory 的关键指标，可能是 Evidence Coverage

这是我觉得论文最有价值的观点。

作者将记忆能力拆成两个维度：

- Evidence Coverage：是否找回了回答问题需要的充分证据？
- Evidence Utilization：模型能否正确理解和利用这些证据？

实验发现，RAW-RAG 的优势主要来自更高的证据覆盖率。

很多复杂 Memory 系统虽然组织了更精炼的信息，但在提炼、合并、更新过程中，可能丢失重要的关联。

特别是涉及状态变化的任务。

比如用户先说下周出差，后来取消，又重新调整时间。

Agent 需要理解的是整个变化过程，仅仅记住其中一条事实可能不够。

论文还发现，即使能够完整访问部分复杂系统已经转换好的记忆存储，也不一定能恢复原始历史中的全部信息。

原始证据的完整性，可能比记忆结构的复杂程度更重要。

## 4. Agent Memory 可能需要重新审视设计优先级

读完论文，我有两个感受。

首先，构建 Agent Memory 时，应该先把基础检索做好。

Chunk、Embedding、Rerank、上下文扩展、时间关系恢复，这些看起来传统的 RAG 能力，仍然有很大的优化空间。

在此基础上，再引入摘要、画像、图谱和记忆更新机制，并通过评测验证它们是否真正带来收益。

其次，越来越觉得，长期记忆应该保留两种形态：

一类是完整、可追溯的原始证据，确保历史信息可以被重新理解。

另一类是面向特定任务的抽象记忆，例如用户偏好、项目状态、工作经验和可复用 Skill。

两者可以相互补充。

当然，这篇论文主要验证的是长期对话理解任务。对于持续运行的 Agent、复杂状态维护、多 Agent 协作和经验学习，复杂 Memory 仍然可能有独特价值。

但它至少提醒我们：Agent Memory 的进步，不能只看系统能够提炼和组织多少信息，更要看 Agent 能否在需要时找回正确、完整的证据。

有时候，把简单的事情做好，可能比引入更多复杂机制更重要。
