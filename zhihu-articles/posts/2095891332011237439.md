最近 Cursor 出了个跟 Grok、X 绑在一起的统一订阅。如果你是冲着 Claude 去的，千万别订。

我就订了，结果 Claude 直接没了。

订完一看模型列表，Claude 一个都没有，只剩 Grok 和 Composer。

想继续用 Claude，得自己另外接 API，按量再付一份钱。

而我那会儿，Cursor 已经是我手上唯一还能用 Claude 的地方了。

之前 Claude 账号被封，我就靠 Cursor 撑着。结果我这一订阅，连这个也没了。

后来重新订 Claude，刚登录就被封。去找云服务商的 Claude，也被拒了。

说实话，真有点眼前一黑。这么好用的模型，怎么就这么难用上了。

好在最后，我想起了以前用过的 **GitHub Copilot** ，Claude 在里面能用。

这篇我就把这一路讲一遍，尤其是 Cursor 统一订阅这个坑，你别再踩。

大概分这几块：

> Cursor 统一订阅，Claude 没了 
>  Claude 订阅被封，云服务商也被拒 
>  最后用上了 GitHub Copilot，还有它的套餐和额度

**一、Cursor 统一订阅，Claude 没了**

先说这个统一订阅。Grok、X、Cursor，现在合成了一个套餐。

![](https://pic2.zhimg.com/v2-cc492f5527f30eb9633f962dde991999_1440w.jpg)

如果你本来就是 X 用户，这个 Plus 一个月 8 美元，其实挺值得入手的。

![](https://picx.zhimg.com/v2-29c28d811a0bbc8a33e44b6efdcdd825_1440w.jpg)

问题出在 Cursor 这一块。

订阅之后，你原来的 Cursor 套餐，会被它直接替换掉。

最大的变化是： **Claude 这类第三方模型，不再包含在套餐里，得另外收费。**

我订的就是 Plus。订完再打开 Cursor，模型列表是这样的：

![](https://pic2.zhimg.com/v2-4a211faf637467f43750d81c57f57e71_1440w.jpg)

再看看我以前 Cursor Pro 的：

![](https://pic1.zhimg.com/v2-43c25fdf5d11ab22554537d43a09a770_1440w.jpg)

两张放一起，差距不用我多说。

就算往上升套餐等级，能选的也还是 Grok 自家的模型，顶多多给你一个推理强度高的档位。

想用 Claude，只能自己接第三方 API，按量另外付费。

这样一来，Cursor 最大的吸引力，也就是想换哪个模型就换哪个，一下子就没了。

**二、订阅被封，云服务商也被拒**

Cursor 里没了 Claude，我只剩一条路：重新订阅 Claude 账号。

这回得先做实名认证，认证倒是过了。

![](https://pic3.zhimg.com/v2-21c97a73e7aa66d8349d5be633978458_1440w.jpg)

结果到付款那一步，又卡住了。

![](https://pic2.zhimg.com/v2-30093abd99958255661c3a8eb69b75e9_1440w.jpg)

后来换到 Safari，总算订阅成功。

然后我在 Claude 桌面端再登录，账号直接被暂停了。

![](https://pic4.zhimg.com/v2-23148a6c92ffe50201932b6ce48c0e9d_1440w.jpg)

钱付了，实名认证也做了，换来的是一个被暂停的账号。真的很坑。

账号这条路走不通，我又想绕一下：从云服务商那边用 Claude。

我在 Google Cloud 上申请了 Claude Sonnet 的调用额度，结果也被拒了。

![](https://pic4.zhimg.com/v2-3e76011b43ecbc289dc31b9de6fdc983_1440w.jpg)

说真的，Claude 这是欺人太甚啊。

**三、最后用上了 GitHub Copilot**

能想到的路，基本都试过了。

我只好去找跟 Cursor 类似的、能自己选模型的产品。

想起了以前用过的 **GitHub Copilot** 。

它在 VS Code 里就能写代码。现在还多了一个桌面端，有点像 work 模式。

![](https://pica.zhimg.com/v2-7c11a3ced0555018c8ecea012d66cdb4_1440w.jpg)

这个桌面端 Mac、Windows、Linux 都有，任何一档 Copilot 套餐都能用。

![](https://picx.zhimg.com/v2-4ac1577109b2757a0c0023ed42598c69_1440w.jpg)

模型列表里，Claude 的几个型号都在。我现在用的是 Sonnet 5.5。

![](https://pic3.zhimg.com/v2-0a7e4f82e2aa858a5c4bd05c2deb11b8_1440w.jpg)

Cursor 以前那种想换哪个模型就换哪个的感觉，在这里又有了。

用上之后，我先去看了它的额度怎么算。

Copilot 现在按 **AI Credits** 计费，1 个 Credit 值 1 美分。

你用的模型越贵、聊得越长，扣得越多。说白了，就是按用量折成钱，从当月额度里扣。

个人套餐一共四档：Free、Pro、Pro+、Max。

![](https://pic2.zhimg.com/v2-f5b4d31bb0dbc3c71503ea235c53f88f_1440w.jpg)

Free 是免费的，只能让它自动选模型，没法自己挑 Claude。后面三档是收费的：

| 套餐 | 月费 | 基础额度 | 附送额度 | 每月合计 | 折合 |
| --- | --- | --- | --- | --- | --- |
| Pro | $10 | 1,000 | 500 | 1,500 | 约 $15 |
| Pro+ | $39 | 3,900 | 3,100 | 7,000 | 约 $70 |
| Max | $100 | 10,000 | 10,000 | 20,000 | 约 $200 |

基础额度刚好等于月费。 **附送的那部分，官方说会随模型价格变** ，以后数字可能不一样。

能用哪些模型，也跟档位有关。Claude 这几个，Pro 能用 Sonnet 和 Haiku，Opus 和 Fable 要 Pro+ 起：

| Claude 模型 | Pro | Pro+ | Max |
| --- | --- | --- | --- |
| Haiku 4.5 / 5.5 | 可用 | 可用 | 可用 |
| Sonnet 5 / 5.5 | 可用 | 可用 | 可用 |
| Opus 5 / 5.5 | 没有 | 可用 | 可用 |
| Fable 5 / 5.1 | 没有 | 可用 | 可用 |

再跟原来包含 Claude 的 Cursor 订阅比一下：

| 档位 | GitHub Copilot | Cursor 原订阅（统一前） |
| --- | --- | --- |
| 入门 | Pro $10/月，约 $15 额度，可用 Sonnet | Pro $20/月，含 $20 第三方模型额度，可用 Sonnet、Opus |
| 进阶 | Pro+ $39/月，约 $70 额度，Opus 也能用 | Pro+ $60/月，含 $70 第三方模型额度 |
| 高用量 | Max $100/月，约 $200 额度 | Ultra $200/月，含 $400 第三方模型额度 |

这里比的是能拿来用 Claude 等模型的额度。Cursor 原套餐还包含单独的自有模型用量，那部分和 Cursor 不固定的赠送额度，都没有算进表里。

只看 Sonnet，Copilot Pro 的月费是原来 Cursor Pro 的一半。想用 Opus 则要留意：Cursor 原来的 Pro 就能选，Copilot 要 Pro+ 的 $39 起。到了高用量档，两边都是月费对应约两倍的额度：Copilot Max 的月费更低，Cursor Ultra 给的总额度也更多。

Copilot 的刷新规则，订阅之前最好先搞清楚。

额度 **每个月 1 号统一刷新** ，用的是世界标准时间 0 点。换成北京时间，就是 **1 号早上 8 点** 。

这个日子是固定的，跟你哪天订阅没关系。

用不完的额度不累计，月底直接作废。

扣的时候，先扣基础额度，用完了才会动附送的那部分。

> 刷新日：每月 1 号，北京时间早上 8 点 
>  扣费日：一般从你订阅那天算起，两个别搞混 
>  没用完的额度，不带到下个月 
>  先用基础额度，再用附送额度

额度提前用完了，官方给了三条路：

> 升级套餐，只补差价，这个月已经用掉的也算进新套餐的额度里 
>  设一个美元预算，超出的部分按量付费 
>  等下个月 1 号，额度重新给满

回头看，这一路最冤的，就是那次订阅。

统一套餐本身不差，尤其是 X 用户。但它把 Claude 这类第三方模型，挪到了套餐外面，要另外付费。

你订之前，先想清楚自己是不是为了 Claude 来的。

如果你也被 Claude 卡住了，Cursor 回不去，账号和云服务商又都走不通，可以试试 GitHub Copilot。

我现在，就在里面用 Claude。

大家安心去干活，咱们下篇见！
