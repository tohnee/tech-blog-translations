SGLang 在峰会上把版本号打到了 1.0。官方宣布帖里写的是给大模型和多模态用的高性能推理框架，热路径用 Rust 重写了，还有零开销调度、推测解码、PD 分离、层次缓存这些。他们说已经被 330 多家组织采用，217 个模型能做到当天支持。更细的发布说明还说要另发，所以先别急着对跑分。

![](https://pic2.zhimg.com/v2-d4af5cfa98a4f85f4789e4da33767777_r.jpg)

同一场峰会，LMSYS 还宣布成立了 SGLang Consortium，创始成员里有 NVIDIA、AMD、Intel、Google、Meta 这些。维护者仍负责技术决策。这事可以记一笔，不过我更盯着另一张现场幻灯片。

幻灯片标题就叫 V1.0 -> AI Automation，上面写着：合并进去的 PR，大约 95% 已经是 agent 写的。This is what we built around them. 仓库里 36 个 skill，Review Inbox 审了 328 个 PR，agent 重构了大约 20 万行。

![](https://pic1.zhimg.com/v2-0b0c70000bb18056a554de2c4bc907da_r.jpg)

层次缓存那项，官方的说法是为了让长 agent 历史在显存装不下的时候还能复用。推理框架开始按 agent 工作流来改，连自己仓库的开发也交给 agent 了。服务端这边，真正要看的可能不只是吞吐又高了一点。
