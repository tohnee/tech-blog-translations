最近在学习强化学习，在挑战完 [Gynasium](https://gymnasium.farama.org/) 上的月球降落（Moonlander）、双足机器人（Bipedal Walker）和高速公路（Highway Env）之后，都很顺利，但在解决 [Car Racing](https://gymnasium.farama.org/environments/box2d/car_racing/) 的时候还真撞上了一面墙，从未如此受挫。

Car Racing这个环境（游戏）看似复杂，因为Observation Space是一个图，而不是Moonlander、Bipedal Walker那样清晰量化的状态，当然，利用CNN，这种鸟瞰图，96x96像素级别的，提取特征也根本毫无难度，这种量级的神经元网络训练在普通桌面上就能进行。

顺道一说，有没有GPU没差别，Gymnasium的环境是在CPU上运行的，如果用GPU来训练网络，GPU和CPU之间来回的通讯可能让整体训练速度更慢。

| --- | --- |
| Observation Space | Box(0, 255, (96, 96, 3), uint8) |

但实际训练的时候，用DQN和PPO的方法，效果居然都非常不好，我以自己的算法实现有问题，改用Stable Baseline 3的算法实现，得分也是一样烂。

看了一下实际渲染效果，发现赛车基本上一动不动。

咋回事？

去看了一下CarRacing的官方文档。

> The reward is -0.1 every frame and +1000/N for every track tile visited, where N is the total number of tiles visited in the track. For example, if you have finished in 732 frames, your reward is 1000 - 0.1*732 = 926.8 points.

这个reward的定义，设想的是游戏每进行一帧，就扣0.1分，以此鼓励赛车尽早完成比赛，尽量多去走过赛道上的tile。

嗯~ 看起来挺合理，仔细一想，不对呀！

这个每帧扣0.1分的机制，实际上是time cost，并不是progress reward，只会在比赛结束的时候才计算，计算的时候是要打折扣的。

每个状态的回报(Return)计算公式是这样， $\gamma$  就是折扣系数。

$ G_t = \sum_{k=0}^{T-t-1} \gamma^{k}\, r_{t+k+1}, $

只要折扣系数$\gamma$是小于1的，那往前对计算Q-value的影响，越往前越小，而RL我肯定用了<1的折扣系数啊（实际上$\gamma$=0.99）。

在这种reward体系下，是这样的：

- 开300帧，完成50%的tile之后crash——扣144
- 开50帧，完成5%的tile之后crash——扣25.6，也就是得+25.6
- 摸鱼1000帧，一个tile都不踩——扣-4，也就是得+4

实际上就是鼓励摸鱼，一下子都不动弹，在这个reward体系下反而得分最高！

所以，的改一下reward机制， **要及时地惩罚摸鱼行为，不要等到比赛结束的时候才算摸鱼的惩罚，在每一步就算。**

还好Gymnasium提供了改环境的方法，增加一个wrapper新类PunishActionReward，我用的实现方式比较简单粗暴，只要每次决策的action和上一次一样，就要在reward里扣-0.1。

```python
class PunishActionReward(gym.RewardWrapper):
    """Subtract a penalty whenever a given action is chosen."""

    def __init__(self, env, action=0, penalty=0.1):
        super().__init__(env)
        self.action = action
        self.penalty = penalty
        self.last_action = None

    def reset(self, **kwargs):
        self.last_action = None
        return super().reset(**kwargs)

    def step(self, action):
        self.last_action = action
        return super().step(action)

    def reward(self, reward):
        if self.last_action is not None and int(self.last_action) == self.action:
            reward = reward - self.penalty
        return reward

```
