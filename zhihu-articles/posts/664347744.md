深度学习是一个很普遍的概念，对于深度学习的讲解可谓多如牛毛。但是我觉得绝大多数资料对深度学习的入门讲解都太抽象了，没有讲出深度学习的精髓。本文用最通俗的语言告诉你什么是深度学习，基本可以保证你轻轻松松理解什么叫深度学习。我一直认为深度学习（对入门来说）本质上是个很简单的东西，本来也可以用非常简单的方式来理解。

深度学习其实是这么一个过程：

## 例子

### 例子1：猜数字游戏

你和小王玩猜数字游戏。小王在纸上写下一个范围是1-100的数字，你来猜。你猜：50，小王说：你猜少了。你猜：75，小王说：你猜多了。你猜：62，小王说：你猜多了。你猜：56。小王说：你猜少了。你猜：59。小王说：你猜对了。

这个过程是这样：猜测-》小王给你反馈-》你根据反馈调整，继续猜测，这三个过程循环下去，直到猜对。

### 例子2：通过求导来求极值的近似值

求极值有一种近似的方法，是利用导数：

![](https://pic2.zhimg.com/v2-c1b53110ea0d04956a9eab4d1bc46201_r.jpg)

比如这个曲线，假设我们不知道这个曲线的函数表达式，或者虽然知道表达式，但是表达式过于复杂，那么我们怎么求极值呢？一种方法是可以利用导数。看那个极值点的位置，极值点左侧的点，导数大于0，意味着越往右走，值会变大；极值点右侧的点，导数小于0，意味着越往左走，值会变大。

![](https://pica.zhimg.com/v2-a6aee80e6fb61f6173f10c56d9d66b50_r.jpg)

也就是，只要是在极值点附近的点，只要判断导数是正的还是负的，就可以知道它在极值点左侧还是右侧了。所以我们求极值点的近似值可以这么求：

随便选一个看起来在附近的点，设为x1。

如果f'(x1)>0，x1'=x1+0.1；如果f'(x1)<0，x1'=x1-0.1。

如果f'(x1')>0，x1''=x1'+0.1；如果f'(x1')<0，x1''=x1'-0.1。

如果......

![](https://pica.zhimg.com/v2-43f331ad769ec53799be378680c39af0_r.jpg)

如果本次和上一次的移动方向不一样（例如本次向左移动，上次向右移动），说明x到达了位于x*附近0.1个单位的距离，那么这个x就是我们要的近似值。

我们写成伪代码的形式：

```text
let x=random
is_same_direction=true
while (is_same_direction){
  last_label=label
  if (f'(x)>0) { x=x+0.1;label=right; }
  else { x=x-0.1;label=left; }
  if (last_label==label) is_same_direction=true;
  else is_same_direction=false;
}
```

但是，这里还可以改进一下：我们看那个曲线，在极值点附近的时候，曲线特别的平缓，导数只是轻微大于0或轻微小于0；远离极值点的时候，曲线很陡峭，导数会剧烈大于0或剧烈小于0。所以，如果导数剧烈大于0或者剧烈小于0，我们就可以一次移动的幅度大一些，反之就移动的幅度小一些，这样可以快速接近极值点。也就是说，每次的移动幅度和导数值大小是正相关的。于是我们可以把上面的操作改一下：

如果f'(x1)>0，x1'=x1+ $\alpha$ f'(x1)；如果f'(x1)<0，x1'=x1- $\alpha$ f'(x1)。

*细节：*

*什么时候可以结束探索呢？注意这里的每次移动幅度是跟f'(x)有关的，它可能很大，也可能很小，所以它可能会剧烈波动，比如说极值点是x=7，它从x=3开始，这时候导数绝对值很大（坡度很陡），于是它大幅度移动到x=12，这时候它来到了另一侧的坡，于是导数绝对值又很大（坡度很陡），于是大幅度移动到x=4。虽然两次移动方向不一样，一次往左，一次往右，但是它是剧烈波动的，很显然它根本没到极值点附近。所以我们不能把终止条件设置为本次移动方向和上次一样，而是应该设置为波动幅度不大的时候，也就是一次的移动幅度很小，也就是导数绝对值不大。因为越靠近极值点的地方导数绝对值越小，所以这时候我们知道x接近极值点了。*

![](https://pic1.zhimg.com/v2-f0ec9b15c04bbe219c4a99e87777dd2a_r.jpg)

*这个* $\alpha$ *（alpha）是我们自己设置的一个常数。我们还应该设置一个阈值，小于这个阈值的时候，说明移动幅度就很小了。*

*所以伪代码改成下面这样：*

```text
let x=random
is_step_small=false
let alpha=0.05
while (!is_step_small){
  step = alpha * f'(x)
  x = x + step;
  if (step < alpha) is_step_small=true;
}
```

## 深度学习-神经网络

深度学习其实就是靠一个神经网络，而神经网络本质上就是一堆参数。最简单的神经网络其实就是矩阵（向量）的乘法运算和求导运算，再加上一个简单的函数。

拿最简单的图像识别为例：先看二分类：我们要识别一个图像是桌子还是不是桌子，如果是桌子，它是0，如果不是桌子，它是1。

![](https://pica.zhimg.com/v2-93f8c1a367a248da717c3d349859ab34_r.jpg)

然后我们开始训练：图像本质上就是一堆像素点，假设这个图像是100×100的，像素点是有10000个，加上RGB通道（图像由红绿蓝三个颜色组成），这个图像是由10000×3=30000个数字构成，每个数字都是0-1的浮点数。我们把这些数字全部展开，铺展成一个一维的数组，它是一个向量，记为x。现在我们再随机地初始化30000个参数，这些参数构成一个向量，记为w，将w和x点乘，得到一个数字，然后把这个数字转换成一个0-1之间的数字。

![](https://pic3.zhimg.com/v2-bc8d7f2c6b88bdc696094b716537a84c_r.jpg)

这个数字越接近0，它就越“是”桌子，越接近1，它就越“不是”桌子。也就是，我们的目的就是要通过调整w，让所有的桌子算出来的值都接近0，所有不是桌子的算出来的值都接近1。这样，我们再给它一张新的图片，它就通过这样的运算，告诉我们这个图片到底是不是桌子。

也就是，这个过程有两部分：第一部分是训练，我们随机初始化一堆参数，然后给它看一堆图片，告诉它这些图片中的每一张是不是桌子，然后它根据这个结果来调整参数。等它看完了一堆图片之后，参数调整的差不多了，我们就可以让它识别新的图片了：它看到新的图片，就知道是不是桌子了。

![](https://pic3.zhimg.com/v2-27efcbab4235e9b9e55ec18ae4899806_r.jpg)

问题来了：我们要怎么调整这个参数w呢？答案就是：求导。

回到刚才这个例子：

![](https://pic3.zhimg.com/v2-bc8d7f2c6b88bdc696094b716537a84c_r.jpg)

这个的正确结果是1，但它算出来的是0.9。它是让z=w×x，然后对z进行了运算（这个运算叫做sigmod），然后得到了a。我们的目标是让a接近1，也就是让a增大0.1，于是我们要让z变大一些。怎么变大呢？让z增加0.1×一个数字，这个数字就是 $\alpha$ × $\frac{da}{dz}$ （ $\alpha$ 是一个常数）。至于为什么是 $\frac{da}{dz}$ ，这个先不讲。然后z要增加0.04（比方说算出来是这个数字）。怎么让z增加0.04呢？那要让w增加一点，让0.04×一个数字，这个数字就是 $\alpha$ × $\frac{dz}{dw}$ 。为什么是 $\frac{dz}{dw}$ 呢？因为如果我们改变一点点w，z就变化很大，说明w离最优值（极值点）还很远，所以我们要一次性地大幅度更新w。而如果我们改变一点点w，z也只变化一点点，说明w离最优值（极值点）比较近了，所以我们要一次性少更新一点w就行了。回顾一下这张图（离极值点越近的地方，导数越接近于0，所以导数的大小可以反应这个点离极值点的远近）：

![](https://pica.zhimg.com/v2-a6aee80e6fb61f6173f10c56d9d66b50_r.jpg)

当然这么说不严谨，有可能它是离右边那个极值点近呢。这就是局部最优值问题，这个我们先不讲。我们就认为一般情况下我们只讨论离左边极值点比较近的情况。

所以，这就是一个反推的过程：

![](https://pica.zhimg.com/v2-d0327b94cb0f3086ca3f44abb510b8f0_r.jpg)

我们先算出来最终结果a，跟真实值y比较，然后知道a应该怎么改变。因为a是来源于z，所以为了让a改变，我们要改变z。而为了让z改变，我们要改变w。

这就是反推的过程。

我们类比这个：

![](https://pica.zhimg.com/v2-a6aee80e6fb61f6173f10c56d9d66b50_r.jpg)

我们把w理解为横轴的值，把a理解为纵轴的值，我们的目标是让a尽量接近0（如果图像是桌子的话），所以我们就左右调整这个w，让a尽量接近极值点。可以这么来类比。

讲完了二分类，再讲下多分类。比如一堆图片，有的是桌子，有的是电脑，有的是飞机，有的是床，桌子用0表示，电脑用1表示，飞机用2表示，床用3表示……那我们识别的时候，输出2.3代表什么意思呢？是介于飞机和床之间的吗？那如果是介于电脑和床之间的一个图像，该怎么表示呢？是1-3之间的数字吗？比方说2.3吧，那么2.3也可以理解为飞机和床之间的图像。所以就混乱了。所以不能这么表示。

我们要引入一个新的东西，叫独热编码（one-hot）：桌子是[1 0 0 0]，电脑是[0 1 0 0]，飞机是[0 0 1 0]，床是[0 0 0 1]，这样的话，如果神经网络计算出来的结果是[0.8 0.15 0.02 0.03]，那么它就是80%的概率是桌子，15%的概率是电脑，2%的概率是飞机，3%的概率是床。这样就说的通了。

于是我们修改一下刚才那个过程：

把w改成一个30000×4的矩阵，和x进行矩阵相乘，你可以理解为有四条30000的参数，分别和x相乘，最后就形成了四个数字。然后这四个数字经过下面的运算（叫做softmax）：

![](https://pic3.zhimg.com/v2-09a4b81256b6a78a4c2ee7dd7c5f1034_1440w.jpg)

它的作用是，把这四个数字转换为0-1之间且和为1的数字。比方说[100 20 -5 7]这四个数字，转换完以后大概就是[0.99 0.008 0.0001 0.00019]，就是原来很大的数字转换完还很大，原来很小的数字转换完还很小。其实就是把之前那个sigmod给扩展了。

现在这个过程变成这样：

![](https://pic3.zhimg.com/v2-bc8d7f2c6b88bdc696094b716537a84c_r.jpg)

随机初始化一堆参数，然后对图像进行运算，得出一个值，然后拿这个值跟真实值比较，根据差距调整这堆参数，调整很多次以后，它就能比较准确地识别图像了。
