## 一、GAE (Generalized Advantage Estimation, 广义优势估计)

• 回顾一下优势函数的定义：<br>$A_{\pi}(s_{t}, a_{t}) = Q_{\pi}(s_{t}, a_{t}) - V_{\pi}(s_{t}) \\$

• 它告诉我们当前动作比平均动作好/坏多少，并且以乘积的形式影响策略梯度的方向和大小。在先前的 RL 实践中，我们提到过有两种方法可以估计相对优势 $A_{\pi}(s_{t}, a_{t})$：蒙特卡洛法和 TD 误差法

• **蒙特卡洛法**（例如早期的 REINFORCE）：使用从该点出发的采样轨迹的回报 $G_{t}$ 估计动作价值 $Q_{\pi}(s_{t}, a_{t})$，进而计算相对优势 $A_{\pi}(s_{t}, a_{t})$：

$\hat{A}_{t} = G_{t} - v_{\boldsymbol{w}}(s_t) \\$

• 由于回报 $G_{t}$ 是动作价值 $Q_{\pi}(s_{t}, a_{t})$ 的无偏估计，因此这种方法的偏差很小，但同时方差太高，导致模型难以收敛

• **TD 误差法**（例如 Actor-Critic）：使用 TD 误差 $\delta_{t}$ 估计相对优势 $A_{\pi}(s_{t}, a_{t})$：

$\hat{A}_{t} = \delta_{t} = r_{t} + v_{\boldsymbol{w}}(s_{t+1}) - v_{\boldsymbol{w}}(s_{t}) \\$

• 这种方法的方差更小，但其缺点是依赖模型对状态价值 $V_{\pi}(s_{t})$ 的估计精度，存在预测误差

• **广义优势估计 (Generalized Advantage Estimation, GAE)**：为了平衡蒙特卡洛法的高方差和 TD 误差法的高误差而提出的一种评估相对优势 $A_{\pi}(s_{t}, a_{t})$ 的方法，其计算公式是：<br>$\bbox[#FFB]{ \hat{A}_{t} = \sum_{l=0}^{\infty} (\gamma \lambda)^{l} \delta_{t+l} } \\$• 其中，$\lambda$ 是平滑参数，用于平衡优势估计中的方差和误差：

• 当 $\lambda = 0$ 时，GAE 退化为单步TD 误差：$\hat{A}_{t} = \delta_{t}$

• 当 $\lambda = 1$ 时，GAE 退化为蒙特卡洛法：

$\begin{align*} \hat{A}_{t} &= \sum_{l=0}^{\infty} \gamma^{l} \delta_{t+l} \\ &= (r_{t} + \gamma v_{\boldsymbol{w}}(s_{t+1}) - v_{\boldsymbol{w}}(s_{t})) + \gamma (r_{t+1} + \gamma v_{\boldsymbol{w}}(s_{t+2}) - v_{\boldsymbol{w}}(s_{t+1})) + \cdots \\ &= (r_{t} + \gamma r_{t+1} + \cdots) - v_{\boldsymbol{w}}(s_{t}) \\ &= G_{t} - v_{\boldsymbol{w}}(s_{t}) \end{align*} \\$

• 在实践中，GAE 通常通过反向递推计算，类似的做法在之前的 Actor-Critic 等算法中已经用过：

$\begin{align*} &\textbf{Do} \\ &\quad \text{用当前策略网络 } \pi_{\boldsymbol{\theta}_{\mathrm{old}}} \text{ 采样一条轨迹片段 } s_{0}, a_{0}, r_{0}, s_{1}, a_{1}, r_{1}, \dots, s_{T} \\ &\textbf{Until} \text{ } s_{T} \text{ is terminal state } \textbf{or} \text{ } T = T_{\mathrm{max}} \\ &\text{用当前价值网络 } v_{\boldsymbol{w}_{\mathrm{old}}} \text{ 对所有 } t = 0, 1, \dots, T \text{ 计算状态价值：} \\ &\quad v(s_{t}) \leftarrow \begin{cases} 0, & \text{if } t = T \text{ and } s_{T} \text{ is terminal state} \\ v_{\boldsymbol{w}_{\mathrm{old}}}(s_{t}), & \text{otherwise} \end{cases} \\ &\text{初始化 } \hat{A}_{T} \leftarrow 0 \\ &\textbf{For} \text{ } t = T-1, T-2, \dots, 0 \text{ (反向计算) } \textbf{do} \\ &\quad \text{计算 TD 误差：} \delta_{t} = r_{t} + \gamma v(s_{t+1}) - v(s_{t}) \\ &\quad \text{计算相对优势：} \hat{A}_{t} \leftarrow \delta_{t} + \gamma \lambda \hat{A}_{t+1} \\ &\textbf{End For} \end{align*}$

## 二、PPO (Proximal Policy Optimization)

• 回顾一下 TRPO 的优化目标：<br>$\bbox[#FFB]{ \mathcal{J}_{\mathrm{TRPO}}(\boldsymbol{\theta}) = \mathbb{E}_{\tau \sim \pi_{\boldsymbol{\theta}_{\mathrm{old}}}} \mathbb{E}_{t} \left[ \frac{\pi_{\boldsymbol{\theta}}(a_{t} \mid s_{t})}{\pi_{\boldsymbol{\theta}_{\mathrm{old}}}(a_{t} \mid s_{t})} A_{\pi_{\boldsymbol{\theta}_{\mathrm{old}}}}(s_{t}, a_{t}) \right] \\[1.5ex] \text{s.t.} \quad \mathbb{E}_{\tau \sim \pi_{\boldsymbol{\theta}_{\mathrm{old}}}} \mathbb{E}_{t} \Bigl[ D_{\mathrm{KL}} \bigl( \pi_{\boldsymbol{\theta}_{\mathrm{old}}}(\cdot \mid s_{t}) \, \| \, \pi_{\boldsymbol{\theta}}(\cdot \mid s_{t}) \bigr) \Bigr] \leq \delta } \\$

• 这是一个带约束的优化问题。为了求解这个问题，TRPO 采用一种二阶优化方法（自然梯度法）以获取更精确的参数更新方向。但是，无论是自然梯度法，还是围绕自然梯度法引入的共轭梯度法等策略，其计算复杂度都非常高，不利于在大规模 GPU 集群上并行部署

• PPO 可以视为对 TRPO 的一种简化，它的思想是用一阶优化方法近似 trust region，既保留 trust region 的优势（策略更新的稳定性和单调性），同时大幅提高训练并行度，本质上是一种在“更高的迭代效率”和“更精确的迭代方向”之间的 trade-off

• 既然约束项的作用是控制模型每次更新参数后策略分布的变化程度，那么，直接把它作用到 Loss 上不是也可以取得类似的效果吗？基于这种思想，PPO 提出了两种变体，称为 Clipped Surrogate Objective 和 Adaptive KL Penalty Coefficient

• **Clipped Surrogate Objective**：不再显式计算 KL 散度，而是通过直接修剪目标函数的方法实现控制迭代步长的目的：

$\bbox[#FFB]{ \mathcal{J}_{\mathrm{CLIP}}(\boldsymbol{\theta}) = \mathbb{E}_{\tau \sim \pi_{\boldsymbol{\theta}_{\mathrm{old}}}} \mathbb{E}_{t} \left[ \min \left( \frac{\pi_{\boldsymbol{\theta}}(a_{t} \mid s_{t})}{\pi_{\boldsymbol{\theta}_{\mathrm{old}}}(a_{t} \mid s_{t})} \hat{A}_{t}, \operatorname{clip} \left( \frac{\pi_{\boldsymbol{\theta}}(a_{t} \mid s_{t})}{\pi_{\boldsymbol{\theta}_{\mathrm{old}}}(a_{t} \mid s_{t})}, 1 - \epsilon, 1 + \epsilon \right) \hat{A}_{t} \right) \right] } \\$

• 其中，$\epsilon$ 是一个超参数，直接作用到重要性采样系数上，决定裁减的上下界。关于**重要性采样 (Importance Sampling)**，在 TRPO 中已经提到过：$\mathbb{E}_{x \sim p(x)} \left[ f(x) \right] = \mathbb{E}_{x \sim \tilde{p}(x)} \left[ \frac{p(x)}{\tilde{p}(x)} f(x) \right] \\$• 其作用是调整随机变量的分布：

• 如果 $\frac{p(x)}{\tilde{p}(x)} \gt 1$，表示该样本在目标分布 $p(x)$ 下出现的概率高于采样分布 $\tilde{p}(x)$，即该样本被**低估**了，因此需要提高其权重（提高其对最终期望的贡献）

• 如果 $\frac{p(x)}{\tilde{p}(x)} \lt 1$，表示该样本在目标分布 $p(x)$ 下出现的概率低于采样分布 $\tilde{p}(x)$，即该样本被**高估**了，因此需要降低其权重（降低其对最终期望的贡献）

• 而当新旧策略下采样概率差异过大时，$\epsilon$ 就会发挥作用，将重要性权重限制在 $[1 - \epsilon, 1 + \epsilon]$ 范围内。然后比较裁剪后（如果实际发生过裁剪）和裁剪前的相对优势，始终选择其中更保守（数值更小）的一项。设 $r_{t}(\boldsymbol{\theta}) = \frac{\pi_{\boldsymbol{\theta}}(a_{t} \mid s_{t})}{\pi_{\boldsymbol{\theta}_{\mathrm{old}}}(a_{t} \mid s_{t})}$：

• 如果 $r_{t}(\boldsymbol{\theta}) \lt 1 - \epsilon$ ，则 $\hat{A}_{t} \gt 0$（好动作）时，min 操作取原始项；$\hat{A}_{t} \lt 0$（坏动作）时，min 操作取 clip 项

• 如果 $r_{t}(\boldsymbol{\theta}) \gt 1 + \epsilon$ ，则 $\hat{A}_{t} \gt 0$（好动作）时，min 操作取 clip 项；$\hat{A}_{t} \lt 0$（坏动作）时，min 操作取原始项

• 如果 $1 - \epsilon \lt r_{t}(\boldsymbol{\theta}) \lt 1 + \epsilon$，则 clip 和 min 操作不发挥作用

• **Adaptive KL Penalty Coefficient**：将 KL 散度作为惩罚项直接添加进目标函数中：$\bbox[#FFB]{ \mathcal{J}_{\mathrm{KLPEN}}(\boldsymbol{\theta}) = \mathbb{E}_{\tau \sim \pi_{\boldsymbol{\theta}_{\mathrm{old}}}} \mathbb{E}_{t} \left[ \frac{\pi_{\boldsymbol{\theta}}(a_{t} \mid s_{t})}{\pi_{\boldsymbol{\theta}_{\mathrm{old}}}(a_{t} \mid s_{t})} \hat{A}_{t} - \beta D_{\mathrm{KL}} \bigl( \pi_{\boldsymbol{\theta}_{\mathrm{old}}}(\cdot \mid s_{t}) \, \| \, \pi_{\boldsymbol{\theta}}(\cdot \mid s_{t}) \bigr) \right] } \\$• 其中，$\beta$ 是一个自适应权重：如果 $D_{\mathrm{KL}}$ 太小，则减小 $\beta$，增大模型的迭代步长；反之，则增大 $\beta$，减小模型的迭代步长。具体更新规则如下：

• 如果 $D_{\mathrm{KL}} \lt d_{\mathrm{targ}} / 1.5$，那么 $\beta \leftarrow \beta / 2$

• 如果 $D_{\mathrm{KL}} \gt d_{\mathrm{targ}} \times 1.5$，那么 $\beta \leftarrow \beta \times 2$

• 否则，$\beta$ 保持不变

• 根据 KL 散度的定义： $D_{\mathrm{KL}}(P \, \| \, Q) = \mathbb{E}_{x \sim P} \left[ \log \frac{P(x)}{Q(x)} \right] \\$

• $D_{\mathrm{KL}}$ 可以按如下公式计算：

$D_{\mathrm{KL}} \bigl( \pi_{\boldsymbol{\theta}_{\mathrm{old}}}(\cdot \mid s_{t}) \, \| \, \pi_{\boldsymbol{\theta}}(\cdot \mid s_{t}) \bigr) = \mathbb{E}_{a_{t} \sim \pi_{\boldsymbol{\theta}_{\mathrm{old}}}(\cdot \mid s_{t})} \left[ \log \frac{\pi_{\boldsymbol{\theta}_{\mathrm{old}}}(a_{t} \mid s_{t})}{\pi_{\boldsymbol{\theta}}(a_{t} \mid s_{t})} \right] \\$

• 这里由于 KL 散度是不对称的，因此交换参数顺序后二者并不等价，即：<br>$D_{\mathrm{KL}} \bigl( P \, \| \, Q \bigr) \neq D_{\mathrm{KL}} \bigl( Q \, \| \, P \bigr) \\$• 由此引申出了实践中常用的两种 KL 散度设计，分别代表了不同的行为倾向：

• $D_{\mathrm{KL}} \bigl( \pi_{\boldsymbol{\theta}_{\mathrm{old}}}(\cdot \mid s_{t}) \, \| \, \pi_{\boldsymbol{\theta}}(\cdot \mid s_{t}) \bigr)$：称为 **Forward KL**，在这种模式下，如果新策略试图把参考策略喜欢的动作概率压得很低，将会受到更大的惩罚，因此新策略被鼓励充分覆盖参考策略支持范围内的动作概率 (mass-covering)，这会使生成内容更全面、激进

• $D_{\mathrm{KL}} \bigl( \pi_{\boldsymbol{\theta}}(\cdot \mid s_{t}) \, \| \, \pi_{\boldsymbol{\theta}_{\mathrm{old}}}(\cdot \mid s_{t}) \bigr)$：称为 **Reverse KL**，在这种模式下，如果新策略试图在参考策略不喜欢的区域内生成内容，将会受到更大的惩罚，因此新策略被鼓励在参考策略支持范围内的动作中进行筛选 (mode-seeking)，这会使生成内容趋于保守、安全

• PPO 论文中使用的是前者，而后续的 InstructGPT（PPO）和 DeepSeekMath（GRPO）中使用的是后者

• **损失函数设计**：在实际训练过程中，为了优化上述目标函数，PPO 设计了一个组合 loss。以裁剪法为例，其最终损失函数形如：$\bbox[#FFB]{ \mathcal{L}_{\mathrm{CLIP+VF+S}}(\boldsymbol{\theta}) = \mathbb{E}_{\tau \sim \pi_{\boldsymbol{\theta}_{\mathrm{old}}}} \mathbb{E}_{t} \left[ \mathcal{L}_{\mathrm{CLIP},t}(\boldsymbol{\theta}) + c_{1} \mathcal{L}_{\mathrm{VF}}(\boldsymbol{\theta}) - c_2 S \left[ \pi_{\boldsymbol{\theta}} \right] \left( s_{t} \right) \right] } \\$• 其中：

• $\mathcal{L}_{\mathrm{CLIP},t}(\boldsymbol{\theta}) = - \mathcal{J}_{\mathrm{CLIP},t}(\boldsymbol{\theta})$：用于监督 actor model

• $\mathcal{L}_{\mathrm{VF}}(\boldsymbol{\theta}) = \left( V_{\boldsymbol{\theta}}(s_{t}) - V_{\mathrm{tar}}(s_{t}) \right)^{2}$：价值网络输出和 target 之间的均方误差，用于监督 critic model。其中 $V_{\mathrm{tar}}(s_{t})$ 由当前状态价值和相对优势（GAE）共同决定：

$V_{\mathrm{tar}}(s_{t}) = V_{\boldsymbol{\theta}_{\mathrm{old}}}(s_{t}) + \hat{A}_{t} \\$

• $S \left[ \pi_{\boldsymbol{\theta}} \right] \left( s_{t} \right) = - \sum_{a_{t}} \pi_{\boldsymbol{\theta}}(a_{t} \mid s_{t}) \log \pi_{\boldsymbol{\theta}}(a_{t} \mid s_{t})$：称为**熵奖励 (Entropy Bonus)**。策略越随机（各动作概率均匀），这一项的取值越高；反之，策略越确定（例如某个动作概率接近 1），这一项的取值越低。也就是说，PPO 希望策略输出保持一定的随机性，这可以起到鼓励模型探索，防止策略过早收敛，避免陷入局部最优的作用

## 三、RLHF (RL from Human Feedback, 基于人类反馈的强化学习)：RL 在 LLM 领域中的应用

![](https://picx.zhimg.com/v2-ed0fc6f1541c15d4f669f0628cd688af_r.jpg)

• **RLHF (RL from Human Feedback)** 可以被视为将 RL 技术大规模应用到 LLM 领域的开端，它提供了一套完整的范式，以解决大语言模型的**对齐 (Alignment)** 问题。这套范式后来被很多主流大语言模型采纳作为必要的后训练流程

• 所谓 Alignment，就是将大语言模型的输出文本和人类偏好对齐。尽管大语言模型在预训练阶段通过海量通用文本数据掌握了丰富的语言规律，但它生成的内容仍然可能存在严重问题。具体来说，这些内容可能是：

• 虚假的 (untruthful)：捏造事实

• 有害的 (toxic)：生成带有偏见、歧视，或对人类、环境造成生理、心理和社会伤害的文本

• 对用户无帮助的 (not helpful to the user)：不遵循用户指令

• 之所以会存在这些问题，核心原因是预训练阶段的建模方式，只能让模型学习到 next token 的统计规律，无法建立对人类价值观、安全边界和具体任务需求的高阶理解

• RLHF 的目标就是通过强化学习方法，将人类偏好系统性地注入大语言模型，以确保模型输出的文本能够满足**有帮助 (helpful)、诚实 (honest)、无害 (harmless)** 的 3H 标准

• RLHF 标准范式由以下三个步骤组成（不包括预训练）：

• Supervised Fine-Tuning (SFT, 监督微调)

• Reward Model (RM) Training

• Reinforcement Learning (RL) via PPO

### Supervised Fine-Tuning (SFT, 监督微调)

• **目标**：基于上述背景，SFT 的目标就是让模型初步学会“遵循指令”。和预训练阶段使用通用文本作为训练数据不同，SFT 的核心差异是：它使用明确的 question+answer 作为训练数据（其中 question 部分作为初始 prompt，不需要模型预测），以使模型初步理解应该如何对提问作出回答

• **训练集**：SFT 采用人工收集的高质量 prompt-response pair 作为训练数据，其中 prompt 规模为 13k。这些 prompt 来源于从 OpenAI Playground 中收集的用户 prompt 以及少量由标注员手工编写的 prompt（实验初期），被分成三份，分别用于 RLHF 的三个阶段；而 response 则是由标注员人工撰写的示例回复

• **数据格式**：$(x, y)$，其中 $x$ 表示 prompt， $y$ 表示 response

• **损失函数**：和预训练阶段类似，SFT 采用负对数似然损失函数，区别是 prompt 部分不需要模型预测。其计算公式为：$\mathcal{L}_{\mathrm{SFT}}(\boldsymbol{\theta}) = - \mathbb{E}_{(x, y) \sim \mathcal{D}_{\mathrm{SFT}}} \left[ \sum_{t=1}^{\left| y \right|} \log \pi_{\boldsymbol{\theta}}(y_{t} \mid x, y_{\lt t}) \right] \\$

### Reward Model (RM) Training

• **目标**：一般来说，对于简单的强化学习任务，即时奖励可以通过规则直接计算。但是对于复杂的自然语言生成任务来说，一条输出文本的好坏很难通过规则进行量化描述。为此，RLHF 引入了 **Reward Model (RM)**，其核心作用是训练一个打分器，将人类对输出文本质量的偏好系统性地转化为标量信号

• **模型结构**：在论文中，RM 采用的是一个规模更小的语言模型（6B 模型），仅将最后的 lm_head 替换为线性回归层。它接受完整的 prompt-response pair 作为输入，输出对该 response 质量的打分（标量 reward 值）

• **输入**：prompt-response pair

• **输出**：单个标量 reward 值 $r(x, y)$

• 需要注意的是，RM 输出对整段文本质量的打分（记为 $r(x, y)$），而非之前提到的单步 reward $r(s_{t}, a_{t})$。在实践中，这个 score 往往作为最后一步的 reward $r_{T-1}$（假设 $s_{T}$ 是终止状态），而设前面时间步的 reward $r_{t} = 0$，进而通过 GAE 计算出每一步的相对优势（在 GRPO 及其衍生方法中，由于无法利用 GAE，reward 的处理方式又略有不同）

• **训练集**：RM 的训练数据同样来自上述高质量 prompt，prompt 规模为 33k。对于每条 prompt，由 SFT 模型生成 $K$ 条候选回答（实践中 $K = 9$），再将这些回答两两配对（得到 $\binom{K}{2}$ 对），由标注员回答“这两条回答中哪个更好”

• **数据格式**：最终得到的数据形如： $(x, y_{w}, y_{l})$ ，其中 $x$ 表示 prompt，$y_{w}$ 是标注员认为更好的回答（winner），$y_{l}$ 是标注员认为更差的回答（loser）

• **损失函数**：RM 的损失函数要求模型尽可能最大化 $r(x, y_{w})$，同时最小化 $r(x, y_{l})$，其计算公式为：$\mathcal{L}_{\mathrm{RM}}(\boldsymbol{\theta}) = - \frac{1}{\binom{K}{2}} \mathbb{E}_{(x, y_{w}, y_{l}) \sim \mathcal{D}_{\mathrm{RM}}} \left[ \log \bigl( \sigma(r_{\boldsymbol{\theta}}(x, y_{w}) − r_{\boldsymbol{\theta}}(x, y_{l})) \bigr) \right] \\$

• 之后会提到：这个公式的本质是最大化 Bradley-Terry 模型建模的人类偏好概率。其中 $\sigma$ 表示 sigmoid 函数：$\sigma(x) = \frac{1}{1 + e^{-x}} \\$

### Reinforcement Learning (RL) via PPO

• **模型结构**：RLHF 的强化学习算法基于 PPO 实现（更准确地说，是基于 PPO-Penalty 版本）。和原版 PPO 不同的是，除了标准的 Actor-Critic 模块以外，RLHF 还引入了 reward model 和 reference model 两个组件：前者代替 reward function，用于估计输出文本的相对优势；后者作为分布锚点，在 KL 散度计算中代替历史策略 $\pi_{\boldsymbol{\theta}_{\mathrm{old}}}$。具体来说：

• **策略模型 (Policy Model)**：对应 Actor-Critic 中的 actor model，用于建模动作分布 $\pi_{\boldsymbol{\theta}}(a_{t} \mid s_{t})$。policy model 使用 SFT 模型初始化，因为 LLM 采用 next-token prediction 的建模方式，根据当前状态（prompt + 已生成的历史 response）输出词表中下一个 token 的概率分布，这可以和策略梯度算法自然衔接

• **价值模型 (Value Model)**：对应 Actor-Critic 中的 critic model，用于估计当前状态的价值 $V_{\pi}(s_{t})$。value model 通常和 policy model 共享 backbone，仅在最后增加一个价值头

• **奖励模型 (Reward Model)**：用于对输出文本质量进行打分，以评估大语言模型的输出在人类看来是否表现不错

• **参考模型 (Reference Model)**：参与计算 KL 散度惩罚项 $D_{\mathrm{KL}} \bigl( \pi_{\mathrm{ref}}(\cdot \mid s_{t}) \, \| \, \pi_{\boldsymbol{\theta}}(\cdot \mid s_{t}) \bigr)$，在其中替代历史策略 $\pi_{\boldsymbol{\theta}_{\mathrm{old}}}$，作为后续所有时刻的分布锚点（注意重要性采样中的历史策略仍为 $\pi_{\boldsymbol{\theta}_{\mathrm{old}}}$），reference model 使用和 policy model 相同的参数初始化，并且在后续训练过程中始终保持 freeze 状态

• **训练集**：RL 阶段使用的 prompt 规模为 31k，完全来自从 API 中收集的用户 prompt

## 四、DPO (Direct Preference Optimization)

![](https://pica.zhimg.com/v2-6cfba93d248da0184fa5c8ab54b781fc_r.jpg)

• DPO 可以视为对 RLHF 范式的直接简化，其核心思想是将 RM Training 和 RL 两个阶段合并，不再显式训练 reward model，而是直接让模型从人类偏好数据对 $(x, y_{w}, y_{l})$ 中学习人类偏好信息

• 人类偏好通常用 Bradley-Terry 模型建模：对于给定的 prompt $x$ 和两个 response $y_{w}$ 和 $y_{l}$，人类认为 $y_{w}$ 比 $y_{l}$ 更好的概率为：$P(y_{w} \succ y_{l} \mid x) = \frac{\exp(r(x, y_{w}))}{\exp(r(x, y_{w})) + \exp(r(x, y_{l}))} \\$• 上式可以等价写成 sigmoid 形式：

$P(y_{w} \succ y_{l} \mid x) = \sigma \bigl( r(x, y_{w}) - r(x, y_{l}) \bigr) \\$

• 不难看出，RM Training 的目标正是最大化这一人类偏好概率。RLHF 以 reward model $r(x, y)$ 作为桥梁，将人类偏好信息注入到策略网络 $\pi_{\boldsymbol{\theta}}(y \mid x)$ 中

• DPO 要考虑的是，假如不借助这一桥梁，能否只通过策略输出 $\pi_{\boldsymbol{\theta}}(y_{w} \mid x)$ 和 $\pi_{\boldsymbol{\theta}}(y_{l} \mid x)$，构建出最大化人类偏好概率的优化目标。这在直观上应该是可行的，因为我们的优化方向一定是提高 $y_{w}$ 的输出概率，降低 $y_{l}$ 的输出概率

• 具体来说，PPO-Penalty 的最优策略应该满足以下公式：$\pi^{*}(y \mid x) = \underset{\pi_{\boldsymbol{\theta}}}{\arg\max} \left[ \mathbb{E}_{x \sim \mathcal{D}} \mathbb{E}_{y \sim \pi_{\boldsymbol{\theta}}(\cdot \mid x)} \left[ r(x, y) \right] - \beta D_{\mathrm{KL}} \bigl( \pi_{\boldsymbol{\theta}}(\cdot \mid x) \, \| \, \pi_{\mathrm{ref}}(\cdot \mid x) \bigr) \right] \\$• 从上述公式出发，可以推导出最优策略 $\pi^{*}(y \mid x)$ 的解析解（**推导过程略**）：

$\pi^{*}(y \mid x) = \frac{1}{Z(x)} \pi_{\mathrm{ref}}(y \mid x) \exp \left( \frac{1}{\beta} r(x, y) \right) \\$

• 其中 $Z(x)$ 是归一化系数，和 $y$ 无关： $Z(x) = \sum_{y} \pi_{\mathrm{ref}}(y \mid x) \exp \left( \frac{1}{\beta} r(x, y) \right) \\$

• 将上式简单变换可以得到：

$r(x, y) = \beta \log \frac{\pi^{*}(y \mid x)}{\pi_{\mathrm{ref}}(y \mid x)} + \beta \log Z(x) \\$

• 这样就成功地建立了 $\pi^{*}(y \mid x)$ 和 $r(x, y)$ 之间的联系。将上式代入人类偏好概率中：

$P(y_{w} \succ y_{l} \mid x) = \sigma \left( \beta \log \frac{\pi^{*}(y_{w} \mid x)}{\pi_{\mathrm{ref}}(y_{w} \mid x)} - \beta \log \frac{\pi^{*}(y_{l} \mid x)}{\pi_{\mathrm{ref}}(y_{l} \mid x)} \right) \\$

• 不难发现，$Z(x)$ 是可以被消掉的，而剩下的部分不依赖显式的 $r(x, y)$，只和策略网络输出有关

• 由于最优策略 $\pi^{*}(y \mid x)$ 本身就是当前策略 $\pi_{\boldsymbol{\theta}}(y \mid x)$ 的优化目标，因此我们使用当前策略 $\pi_{\boldsymbol{\theta}}(y \mid x)$ 构建负对数似然损失：

$\bbox[#FFB]{ \mathcal{L}_{\mathrm{DPO}}(\boldsymbol{\theta}) = - \mathbb{E}_{(x, y_{w}, y_{l}) \sim \mathcal{D}} \left[ \log \sigma \left( \beta \log \frac{\pi_{\boldsymbol{\theta}}(y_{w} \mid x)}{\pi_{\mathrm{ref}}(y_{w} \mid x)} - \beta \log \frac{\pi_{\boldsymbol{\theta}}(y_{l} \mid x)}{\pi_{\mathrm{ref}}(y_{l} \mid x)} \right) \right] } \\$• 在最大化人类偏好概率的过程中，$\pi_{\boldsymbol{\theta}}(y \mid x)$ 也会逐渐向理想的最优策略 $\pi^{*}(y \mid x)$ 靠近

## 五、GRPO (Group Relative Policy Optimization)

![](https://pica.zhimg.com/v2-efe2809b66d455a63a9fddf1239e7aa8_r.jpg)

• GRPO 是随 DeepSeekMath 一同提出的强化学习方法，本质上也是 PPO 的一种变体：GRPO 放弃了 Actor-Critic 中的 critic model，而是一次 rollout 出多条输出文本，将其视为一个 group，利用 group 内的相对优势估计全局相对优势。由于不需要训练 critic model，因此 GRPO 可以显著降低对计算资源的需求

• GRPO 的原理并不复杂：对于每个输入 query $q$，GRPO 从旧策略中采样一组输出文本 $\mathbf{o} = \{o_{1}, o_{2}, ..., o_{G}\}$，并通过 reward model 对这些输出文本进行打分，得到一组标量 reward 值 $\mathbf{r} = \{r_{1}, r_{2}, ..., r_{G}\}$

• 之后，不需要通过 critic model 估计状态价值和 GAE 估计相对优势，而是直接将这些 reward 在组内标准化（减去均值再除以标准差），作为每条输出文本在组内的相对优势

• 这里由于一个 group 内的每条输出文本都是独立 rollout 的，对于某个中间时刻 $t > 1$，不同 response 的历史输出 $o_{i, \lt t}$ 存在分叉，因此 GRPO 无法像 GAE 那样计算每个中间时刻的相对优势。作为替代，GRPO 将 reward 标准化后 broadcast 到所有历史输出上，换句话说，GRPO 的组内相对优势是 sequence-level 的

• 这样，我们就得到了 GRPO 的目标函数：<br>$\bbox[#FFB]{ \small \begin{align*} &\mathcal{J}_{\mathrm{GRPO}}(\boldsymbol{\theta}) = \mathbb{E}_{ q \sim \mathcal{D}, \left\{ o_{i} \right\}_{i=1}^{G} \sim \pi_{\boldsymbol{\theta}_{\mathrm{old}}}(\cdot \mid q) } \left[ \frac{1}{G} \sum_{i=1}^{G} \frac{1}{ \left| o_{i} \right| } \sum_{t=1}^{ \left| o_{i} \right| } \left\{ \min \left( r_{i, t}(\boldsymbol{\theta}) \hat{A}_{i, t}, \operatorname{clip} \left( r_{i, t}(\boldsymbol{\theta}), 1 - \epsilon, 1 + \epsilon \right) \hat{A}_{i, t} \right) - \beta D_{\mathrm{KL}} \left( \pi_{\boldsymbol{\theta}} \, \| \, \pi_{\mathrm{ref}} \right) \right\} \right], \quad \text{where} \\[1.5ex] &\qquad r_{i, t}(\boldsymbol{\theta}) = \frac{\pi_{\boldsymbol{\theta}}(o_{i, t} \mid q, o_{i, \lt t})}{\pi_{\boldsymbol{\theta}_{\mathrm{old}}}(o_{i, t} \mid q, o_{i, \lt t})}, \quad \hat{A}_{i, t} = \tilde{R}_{i} = \frac{R_{i} - \operatorname{mean}(\mathbf{R})}{\operatorname{std}(\mathbf{R})} \end{align*} } \\$

• 不难看出，GRPO 同时保留了 PPO 的裁剪系数和 KL 散度惩罚项。在计算 KL 散度惩罚项时，GRPO 采用了 [Approximating KL Divergence](http://joschu.net/blog/kl-approx.html) 中提出的 k3 estimator。相较于原始的 KL 散度计算方法，k3 estimator 的取值始终非负，并且方差更小，稳定性更高<br>$D_{\mathrm{KL}} \left( \pi_{\boldsymbol{\theta}} \, \| \, \pi_{\mathrm{ref}} \right) = \frac{\pi_{\mathrm{ref}}(o_{i, t} \mid q, o_{i, \lt t})}{\pi_{\boldsymbol{\theta}}(o_{i, t} \mid q, o_{i, \lt t})} - \log \frac{\pi_{\mathrm{ref}}(o_{i, t} \mid q, o_{i, \lt t})}{\pi_{\boldsymbol{\theta}}(o_{i, t} \mid q, o_{i, \lt t})} - 1 \\$

> • k3 estimator：令 $r = \frac{P(x)}{Q(x)}$，有：<br>$\begin{align*} D_{\mathrm{KL}} \bigl( P \, \| \, Q \bigr) &: r \log r - (r - 1) \\[1ex] D_{\mathrm{KL}} \bigl( Q \, \| \, P \bigr) &: (r - 1) - \log r \end{align*} \\$

## 六、RLVR (RL from Verifiable Rewards, 基于可验证奖励的强化学习)

• RLVR 最早在 2024 年的 Tülu 3 论文中被提出，目标是补全 RLHF 范式的一块重要短板，称为 **reward hacking (奖励作弊)** 问题。该范式被证明在处理复杂逻辑推理任务（如数学、编程等）时具有很出色的潜力，因此后来在 DeepSeek-R1 等模型中被广泛采用，成为目前 LLM 强化学习后训练领域的主流方案之一

• 所谓 reward hacking，就是指 policy model 在优化过程中利用 reward model 的漏洞和偏差，生成表面上能获得高 reward，但实际质量低劣、结论错误或不符合人类真实意图的文本。其本质上印证了 Goodhart 定律，即代理指标被当作优化目标，和真实目标之间必然存在一定的固有 gap，只要采用可训练的 reward model 对人类偏好建模，这种 gap 就很难完全消除

• 因此，RLVR 选择抛弃传统 RLHF 范式的可训练 reward model，转而采用确定性的、可验证的奖励信号为 policy model 提供监督，称为 **rule-based reward**，该奖励信号由**基于规则的验证器 (rule-based verifier)** 直接给出，不依赖 learnable 的 reward model

• 当然，尽管 RLVR 在数学、编程等可验证推理任务中表现优异，它仍然存在一定的局限性：rule-based verifier 难以评估人类主观偏好，因此在构建通用大语言模型时，RLVR 有时还需要与 RLHF 组合使用，以使其输出文本更加“拟人”，从而在推理能力和用户体验上取得更好的平衡（DeepSeek-R1 就采用了这种策略）

> • 接下来就以 DeepSeek-R1 为代表展开 RLVR 范式

![](https://pic1.zhimg.com/v2-c7ce597bed6fc09952a0412c054e909a_r.jpg)

• Deepseek-R1 的完整训练流程可以视为由三个阶段或五个小阶段组成，其中：

• 阶段一：从 DeepSeek-V3-Base 模型出发，采用纯 rule-based RL 对模型进行微调，得到第一阶段产物 **DeepSeek-R1-Zero** 模型

• 阶段二：从 DeepSeek-V3-Base 模型出发，经过 SFT 和 rule-based RL（增加了 language consistency reward 以提升语言一致性）两个阶段对模型进行微调，得到第二阶段产物 **DeepSeek-R1 Dev-2** 模型。其中 SFT 的训练数据来自从 DeepSeek-R1-Zero 中采样并精修的冷启动 long CoT 数据

• 阶段三：从 DeepSeek-V3-Base 模型出发，经过 SFT 和混合 RL 两个阶段对模型进行微调，得到最终产物 **DeepSeek-R1** 模型。其中 SFT 的训练数据来自从 DeepSeek-R1 Dev-2 中采样的 reasoning data 和从 DeepSeek-V3 中采样的 non-reasoning data；RL 阶段则混合了 rule-based reward 和 model-based reward。这两步都可以视为在保持模型推理能力的同时，兼顾输出文本的可读性

### RL w/ Rule-Based Reward

• **目标**：如前文所述，rule-based RL 通过可验证奖励的推理任务鼓励模型自由探索并不断试错，从而自主归纳出有效的推理路径

![](https://pic1.zhimg.com/v2-7e9f1f900ce95e2f4b69da70b1028ee4_r.jpg)

• **基础模型**：DeepSeek-V3-Base

• **产物**：DeepSeek-R1-Zero

• **训练集**：由大量可验证奖励的推理任务构成。论文中未直接提及数据规模，但通过训练配置可以推算出本阶段的训练数据包含 ~208k 条独立的 question

• 每个 question 都会被置于如下模版中，作为一个整体的 prompt 输入给模型

![](https://pic4.zhimg.com/v2-896f4e06678be56f5d7cbca07aa35d27_r.jpg)

• **Reward 设计**：DeepSeek-R1 的 rule-based reward 由两部分组成：accuracy reward 和 format reward。其中：

• **accuracy reward**：用于评估模型输出结果的正确性。以数学问题为例，验证器会要求模型将答案放在指定格式（例如方框“\box{}”）内，然后通过 sympy 将答案解析为表达式并与 ground truth 进行匹配：如果匹配成功，则 $R_{\mathrm{acc}} = 1$；否则 $R_{\mathrm{acc}} = 0$

• **format reward**：作为对 accuracy reward 的补充，用于强制输出文本满足特定的格式要求。这一步通常要求模型将思考过程和总结分别输出到 <think>...</think> 和 <answer>...</answer> 标签中，并且标签内部包含有效信息（这里可以参考如下 open-r1 的处理逻辑，采用正则表达式匹配的方式实现）。如果满足上述条件，则 $R_{\mathrm{format}} = 1$；否则 $R_{\mathrm{format}} = 0$

```python
def format_reward(completion_contents):
    pattern = r"^<think>\n.*?\n</think>\n<answer>\n.*?\n</answer>$"
    matches = [re.match(pattern, content, re.DOTALL | re.MULTILINE) for content in completion_contents]
    return [1.0 if match else 0.0 for match in matches]
```

• 最后，将二者相加，就得到了本阶段的最终 reward：

$R_{\mathrm{rule}} = R_{\mathrm{acc}} + R_{\mathrm{format}} \\$

### SFT w/ Cold Start Long CoT

• **目标**：通过基于上一步模型采样并精修的少量高质量 long CoT 数据对基础模型进行预热，使其快速掌握结构化、逻辑清晰的推理过程

• **基础模型**：DeepSeek-V3

• **产物**：DeepSeek-R1 Dev-1

• **训练集**：本阶段和下一阶段 SFT 所依赖的训练数据由以下五部分构成，共 800k prompt。其中，Math、Code、STEM 和 Logic 属于 reasoning prompt，General 属于 non-reasoning prompt

![](https://picx.zhimg.com/v2-23467346ab0baf59d88f72cbe23dec6b_r.jpg)

• 其中，本阶段使用的训练数据包含数千条 reasoning prompt，全部是可以通过 rule-based verifier 判断正误的（有明确答案的）问题。对于每条 prompt：

• 先由 DeepSeek-R1-Zero 模型在较高的 temperature（1.0）下生成多条 response

• 然后，采用 **Rejection Sampling** 策略，通过上述 accuracy reward 和 format reward 过滤掉那些结果不正确、格式不规范的答案（$R_{\mathrm{acc}} \neq 1 \, \operatorname{or} \, R_{\mathrm{format}} \neq 1$）

• 接着由人工标注员选取少量样本，将推理过程转换为更自然、更贴近人类对话的风格。将这些修改前后的文本作为 few-shot 示例，引导 DeepSeek-V3 模型按照类似风格修改其它数据

• 此外，由于 DeepSeek-R1-Zero 生成的总结部分较为简略，只包含最终答案，因此还要指示 DeepSeek-V3 根据如下提示词生成一个简单易懂的解题步骤；为了解决语言混用的问题，所有文本都要翻译成和 prompt 相同的语言

![](https://pic2.zhimg.com/v2-87e3ea22711f58c3c7647cd5f545ca9d_r.jpg)

• 最后，所有由 LLM 生成的结果均需要经过人工二次验证，以确保质量和一致性

### RL w/ Rule-Based Reward and Language Consistency Reward

• **目标**：基于第一阶段 SFT 模型的强化学习后训练。在 accuracy reward 和 format reward 的基础上，进一步引入了 language consistency reward 以解决语言混用的问题

• **基础模型**：DeepSeek-R1 Dev-1

• **产物**：DeepSeek-R1 Dev-2

• **训练集**：本阶段和下一阶段 RL 所依赖的训练数据由以下五部分构成。其中，Math、Code、STEM 和 Logic 属于 reasoning prompt，共 80k prompt，用于 rule-based RL；General 部分属于 non-reasoning prompt，共 66k prompt，用于 model-based RL

![](https://pic4.zhimg.com/v2-9f397fe9666edda1c82d42d637b6d161_r.jpg)

• 本阶段只用到其中的 reasoning prompt

• **Reward 设计**：本阶段的 reward 在原有的 accuracy reward 和 format reward 以外，还新增了一个 language consistency reward，以增强语言一致性。其具体做法是：计算 response 中目标语言（即与 prompt 相同的语言）的单词占比，作为 reward 得分，目标语言占比越高则奖励得分越高$R_{\mathrm{language}} = \frac{\operatorname{num}(\mathrm{words}_{\mathrm{target}})}{\operatorname{num}(\mathrm{words})} \\$

### SFT w/ Reasoning Data and Non-Reasoning Data

• **目标**：通过前面的步骤得到的 DeepSeek-R1 Dev-2 模型，已经展现出了很强的长链推理能力，但它在通用文本生成方面相对于 DeepSeek-V3 仍然存在劣势，例如可读性差、语言混用等。后面两个阶段的目标就是让模型同时学习 reasoning 和 non-reasoning 任务，在保持推理能力的同时，进一步提高通用文本生成能力

• **基础模型**：DeepSeek-V3

• **产物**：DeepSeek-R1 Dev-3

• **训练集**：如之前所述，本阶段使用的训练数据同时包含 reasoning prompt 和 non-reasoning prompt，对 reasoning prompt 也进行了扩充，两者合计达到 800k prompt。其中：

• reasoning prompt 使用 DeepSeek-R1 Dev-2 模型生成 response。除了可以明确使用 rule-based verifier 进行 rejection sampling 的任务以外，还有部分任务要指示 DeepSeek-V3 根据如下提示词进行判断

![](https://pica.zhimg.com/v2-3f252c4125fc4428aa2dff0f1975c656_r.jpg)

• non-reasoning prompt 使用 DeepSeek-V3 生成 response

### Reward Model Training

• **目标**：和 RLHF 的 reward model 类似，为第二阶段 RL 提供 model-based reward（preference reward）。包含两个模型：helpful reward model 和 safety reward model，分别用于提供两种人类偏好奖励

• **模型结构**：helpful reward model 和 safety reward model 采用了和 DeepSeek-R1 相同的模型结构，前者在模型的最后增加了一个预测有用性奖励的 head，后者增加了一个预测安全性奖励的 head

•**训练集**：

• helpful reward model 的训练数据由 66k 个基于 non-reasoning 任务生成的人类偏好数据对构成。对于每个数据对，指示 DeepSeek-V3 根据如下提示词估计人类更偏好其中的哪个 response。共进行四次查询，每次查询都随机调整顺序以避免位置偏好。最终偏好得分由四次查询的平均值决定，仅保留分差大于 1 的配对以确保可以进行有效的区分。为了避免长度偏好，还会确保两条 response 具有相似的长度

![](https://pic3.zhimg.com/v2-5848e89dfd313244e1c6136760d5c1f8_r.jpg)

• safety reward model 的训练数据由 106k 条 prompt 构成。对于每条 prompt，都会由模型生成 response，并通过预定义的安全准则标注为“safe”或“unsafe”

• **损失函数**：

• helpful reward model 的损失函数采用最大化人类偏好概率的方式实现，和 RLHF 的 reward model training 类似：

$R_{\mathrm{helpful}} = \operatorname{RM}_{\mathrm{helpful}}(\mathrm{response}_{\mathrm{A}}, \mathrm{response}_{\mathrm{B}}) \\$

• safety reward model 的损失函数采用最大化对数似然的方式实现：

$R_{\mathrm{safety}} = \operatorname{RM}_{\mathrm{safety}}(\mathrm{response}) \\$

### RL w/ Rule-Based Reward and Preference Reward

• **目标**：如之前所述，引入 perference reward，进一步提高模型的通用文本生成能力，最终得到正式发布的 DeepSeek-R1 模型

• **基础模型**：DeepSeek-R1 Dev-3

• **产物**：DeepSeek-R1

• **训练集**：如之前所述，RL 阶段的训练数据共 80k reasoning prompt 和 66k non-reasoning prompt

• **Reward 设计**：本阶段的 reward 由 rule-based reward 和 model-based reward 两部分构成，具体来说：$\begin{align*} R &= R_{\mathrm{reasoning}} + R_{\mathrm{general}} + R_{\mathrm{language}}, \quad \text{where} \\[1.5ex] R_{\mathrm{reasoning}} &= R_{\mathrm{rule}} \ ( = R_{\mathrm{acc}} ) \\[1.5ex] R_{\mathrm{general}} &= R_{\mathrm{reward\_model}} + R_{\mathrm{format}} \end{align*} \\$

• 其中 $R_{\mathrm{reasoning}}$ 和 $R_{\mathrm{format}}$ 构成了 rule-based reward，$R_{\mathrm{language}}$ 对应 language consistency reward，而 $R_{\mathrm{reward\_model}}$ 则对应 perference reward，也就是由 reward model 输出的人类偏好得分

## 扩展一：DAPO (Decoupled Clip and Dynamic sAmpling Policy Optimization)

> • 接下来的几篇工作，都可以视为在 GRPO 基础上所作的微调，相对来说理解成本并不高，但是否 work 要视具体任务需求而定

• DAPO 在 GRPO 基础上又做了一些优化，它的主要贡献包括以下几点：

• **移除 KL 散度惩罚项**：DAPO 认为，KL 散度惩罚项的意义在于限制 policy model 和 reference model 不要偏差太远，但是对于 long CoT 任务来说，这种偏差是必要的，因此选择去掉了 KL 散度惩罚项

$\small \text{step 1:} \quad \mathcal{J}(\boldsymbol{\theta}) = \mathbb{E}_{ q \sim \mathcal{D}, \left\{ o_{i} \right\}_{i=1}^{G} \sim \pi_{\boldsymbol{\theta}_{\mathrm{old}}}(\cdot \mid q) } \left[ \frac{1}{G} \sum_{i=1}^{G} \frac{1}{ \left| o_{i} \right| } \sum_{t=1}^{ \left| o_{i} \right| } \left\{ \min \left( r_{i, t}(\boldsymbol{\theta}) \hat{A}_{i, t}, \operatorname{clip} \left( r_{i, t}(\boldsymbol{\theta}), 1 - \epsilon, 1 + \epsilon \right) \hat{A}_{i, t} \right) \color{red}{ \xcancel{ \color{black}{ - \beta D_{\mathrm{KL}} \left( \pi_{\boldsymbol{\theta}} \, \| \, \pi_{\mathrm{ref}} \right) } } } \right\} \right] \\$

• **Rule-Based Reward**：DAPO 论文中的实验基于 DeepSeek-R1 的 rule-based reward，也就是 RLVR 范式展开

$\small \text{step 2:} \quad \mathcal{J}(\boldsymbol{\theta}) = \mathbb{E}_{ \color{red}{ (q, a) \sim \mathcal{D} }, \left\{ o_{i} \right\}_{i=1}^{G} \sim \pi_{\boldsymbol{\theta}_{\mathrm{old}}}(\cdot \mid q) } \left[ \frac{1}{G} \sum_{i=1}^{G} \frac{1}{ \left| o_{i} \right| } \sum_{t=1}^{ \left| o_{i} \right| } \left\{ \min \left( r_{i, t}(\boldsymbol{\theta}) \hat{A}_{i, t}, \operatorname{clip} \left( r_{i, t}(\boldsymbol{\theta}), 1 - \epsilon, 1 + \epsilon \right) \hat{A}_{i, t} \right) \right\} \right] \\$

• 其中：$\hat{A}_{i, t} = \tilde{R}_{i} = \frac{R_{i} - \operatorname{mean}(\mathbf{R})}{\operatorname{std}(\mathbf{R})}, \quad R_{i} = R_{\mathrm{rule}}(a, o_{i}) = \begin{cases} 1, & \operatorname{is\_equivalent}(a, o_{i}) \\ -1, & \text{otherwise} \end{cases} \\$

• 这里 $\operatorname{is\_equivalent}(a, o_{i})$ 就是 RLVR 的 rule-based verifier。为了配合实验，论文还提出了一个包含约 17k 条 prompt 的推理数据集 **DAPO-Math-17K**，其数据通过网络爬虫和人工标注相结合的方式从互联网和官方竞赛网站中收集。由于数学问题的答案可能会以多种形式呈现，例如表达式、公式或数字，其中的部分答案可能难以通过公式解析器进行精准匹配。为了解决这个问题，作者从答案中提取易于解析的整数作为模型的预测目标。形如：

```text
Prompt:

  Solve the following math problem step by step. The last line of your response should be of the form Answer: $Answer (without quotes) where $Answer is the answer to the problem.

  Let $a, b, c$ be distinct numbers such that the equations $x^2 + ax + 1 = 0$ and $x^2 + bx + c = 0$ have a common real root, and the equations $x^2 + x + a = 0$ and $x^2 + cx + b = 0$ also have a common real root. Compute the sum $a + b + c$.

  Remember to put your answer on its own line after "Answer:".

Answer: -3
```

• **Clip-Higher**：DAPO 认为，过低的裁剪上界会抑制模型探索新策略（称为 exploration token，即在旧策略中采样概率较低的 token）的尝试，并且强化保持旧策略（称为 exploitation token）的倾向，这会使模型在训练初期就迅速收敛，进而陷入局部最优

![](https://pica.zhimg.com/v2-6f26670611d79426679e7edd0155afdc_r.jpg)

• 因此，DAPO 提出将 PPO-clip 的裁剪上下限 $[1 - \epsilon, 1 + \epsilon]$ 解耦，由两个参数分别控制，即 $[1 - \epsilon_{\mathrm{low}}, 1 + \epsilon_{\mathrm{high}}]$，再单独提高 $\epsilon_{\mathrm{high}}$，以鼓励模型自由探索$\small \text{step 3:} \quad \mathcal{J}(\boldsymbol{\theta}) = \mathbb{E}_{ (q, a) \sim \mathcal{D}, \left\{ o_{i} \right\}_{i=1}^{G} \sim \pi_{\boldsymbol{\theta}_{\mathrm{old}}}(\cdot \mid q) } \left[ \frac{1}{G} \sum_{i=1}^{G} \frac{1}{ \left| o_{i} \right| } \sum_{t=1}^{ \left| o_{i} \right| } \left\{ \min \left( r_{i, t}(\boldsymbol{\theta}) \hat{A}_{i, t}, \operatorname{clip} \left( r_{i, t}(\boldsymbol{\theta}), 1 - \color{red}{ \epsilon_{\mathrm{low}} }, 1 + \color{red}{ \epsilon_{\mathrm{high}} } \right) \hat{A}_{i, t} \right) \right\} \right] \\$

• **Dynamic Sampling**：由于 rule-based reward 通常在满足/不满足规则二者中取值，因此经常会出现一个 group 内的所有 response 均满足/不满足规则的情况，这会导致该组的相对优势和策略梯度为 0，进而导致训练过程对噪声更加敏感（因为一个 batch 内包含无效数据）。为此，DAPO 选择过滤掉那些 accuracy 等于 0 或 1 的 group，并重新采样直到一个 batch 内的所有 group 的 accuracy 都不为 0 或 1

$\small \begin{align*} &\text{step 4:} \quad \mathcal{J}(\boldsymbol{\theta}) = \mathbb{E}_{ (q, a) \sim \mathcal{D}, \left\{ o_{i} \right\}_{i=1}^{G} \sim \pi_{\boldsymbol{\theta}_{\mathrm{old}}}(\cdot \mid q) } \left[ \frac{1}{G} \sum_{i=1}^{G} \frac{1}{ \left| o_{i} \right| } \sum_{t=1}^{ \left| o_{i} \right| } \left\{ \min \left( r_{i, t}(\boldsymbol{\theta}) \hat{A}_{i, t}, \operatorname{clip} \left( r_{i, t}(\boldsymbol{\theta}), 1 - \epsilon_{\mathrm{low}}, 1 + \epsilon_{\mathrm{high}} \right) \hat{A}_{i, t} \right) \right\} \right] \\[1.5ex] &\qquad \color{red}{ \text{s.t.} \quad 0 \lt \left| \operatorname{is\_equivalent}(a, o_{i}) \right| \lt G } \end{align*} \\ $

• **Token-Level Policy Gradient Loss**：GRPO 的损失函数先对一条 response 的所有 token 求平均，再对一个 group 内的所有 response 求平均，DAPO 认为这样会强行拉平长序列和短序列的 loss 权重，对 long CoT 等场景不友好。DAPO 提出使用 token-level 的 loss 聚合方式替代 sequence-level，即先累加所有 token，再按 token 总数求平均，从而使每个 token 都享有相同的 loss 权重

$\small \begin{align*} & \text{step 5:} \quad \mathcal{J}(\boldsymbol{\theta}) = \mathbb{E}_{ (q, a) \sim \mathcal{D}, \left\{ o_{i} \right\}_{i=1}^{G} \sim \pi_{\boldsymbol{\theta}_{\mathrm{old}}}(\cdot \mid q) } \left[ \color{red}{ \frac{1}{\sum_{i=1}^{G} \left| o_{i} \right| } \sum_{i=1}^{G} \sum_{t=1}^{ \left| o_{i} \right| } } \left\{ \min \left( r_{i, t}(\boldsymbol{\theta}) \hat{A}_{i, t}, \operatorname{clip} \left( r_{i, t}(\boldsymbol{\theta}), 1 - \epsilon_{\mathrm{low}}, 1 + \epsilon_{\mathrm{high}} \right) \hat{A}_{i, t} \right) \right\} \right] \\[1.5ex] &\qquad \text{s.t.} \quad 0 \lt \left| \operatorname{is\_equivalent}(a, o_{i}) \right| \lt G \end{align*} \\ $

• **Overlong Reward Shaping**：DAPO 认为，直接对截断样本赋予惩罚性 reward 可能会对模型造成困扰，因为某些合理的推理过程可能仅仅因为长度超过限制就受到惩罚。DAPO 重新设计了对于过长序列的惩罚机制（称为 **Soft Overlong Punishment**）：对于那些长度超过 $L_{\mathrm{max}} - L_{\mathrm{cache}}$ 但不超过 $L_{\mathrm{max}}$ 的序列，其惩罚性 reward 会随序列长度逐步叠加到 -1，而非直接跳跃到 -1

$R_{\mathrm{length}}(o_{i}) = \begin{cases} 0, & \left| o_{i}y \right| \leq L_{\mathrm{max}} - L_{\mathrm{cache}} \\ \frac{ \left( L_{\mathrm{max}} - L_{\mathrm{cache}} \right) - \left| o_{i} \right| }{L_{\mathrm{cache}}}, & L_{\mathrm{max}} - L_{\mathrm{cache}} \leq \left| o_{i} \right| \leq L_{\mathrm{max}} \\ -1, & L_{\mathrm{max}} \leq \left| o_{i} \right| \end{cases} \\$• 综上，DAPO 损失函数的最终形式为：

$\bbox[#FFB]{ \small \begin{align*} &\mathcal{J}_{\mathrm{DAPO}}(\boldsymbol{\theta}) = \mathbb{E}_{ (q, a) \sim \mathcal{D}, \left\{ o_{i} \right\}_{i=1}^{G} \sim \pi_{\boldsymbol{\theta}_{\mathrm{old}}}(\cdot \mid q) } \left[ \frac{1}{\sum_{i=1}^{G} \left| o_{i} \right| } \sum_{i=1}^{G} \sum_{t=1}^{ \left| o_{i} \right| } \left\{ \min \left( r_{i, t}(\boldsymbol{\theta}) \hat{A}_{i, t}, \operatorname{clip} \left( r_{i, t}(\boldsymbol{\theta}), 1 - \epsilon_{\mathrm{low}}, 1 + \epsilon_{\mathrm{high}} \right) \hat{A}_{i, t} \right) \right\} \right], \quad \text{where} \\[1.5ex] &\qquad r_{i, t}(\boldsymbol{\theta}) = \frac{\pi_{\boldsymbol{\theta}}(o_{i, t} \mid q, o_{i, \lt t})}{\pi_{\boldsymbol{\theta}_{\mathrm{old}}}(o_{i, t} \mid q, o_{i, \lt t})}, \quad \hat{A}_{i, t} = \tilde{R}_{i} = \frac{R_{i} - \operatorname{mean}(\mathbf{R})}{\operatorname{std}(\mathbf{R})}, \quad R_{i} = R_{\mathrm{rule}}(a, o_{i}) + R_{\mathrm{length}}(o_{i}), \\[1.5ex] &\qquad R_{\mathrm{rule}}(a, o_{i}) = \begin{cases} 1, & \operatorname{is\_equivalent}(a, o_{i}) \\ -1, & \text{otherwise} \end{cases}, \quad R_{\mathrm{length}}(o_{i}) = \begin{cases} 0, & \left| o_{i} \right| \leq L_{\mathrm{max}} - L_{\mathrm{cache}} \\ \frac{ \left( L_{\mathrm{max}} - L_{\mathrm{cache}} \right) - \left| o_{i} \right| }{L_{\mathrm{cache}}}, & L_{\mathrm{max}} - L_{\mathrm{cache}} \leq \left| o_{i} \right| \leq L_{\mathrm{max}} \\ -1, & L_{\mathrm{max}} \leq \left| o_{i} \right| \end{cases} \\[1.5ex] &\qquad \text{s.t.} \quad 0 \lt \left| \operatorname{is\_equivalent}(a, o_{i}) \right| \lt G \end{align*} } \\$

## 扩展二：Dr. GRPO

• Dr. GRPO 在 GRPO 的基础上做出了两个非常简洁的改动，以修复 GRPO 引入的两个偏差，称为 Response-Level Length Bias 和 Question-Level Difficulty Bias。具体来说：

• **移除 $\frac{1}{ \left| o_{i} \right| }$**：和 DAPO 的观点类似，Dr. GRPO 认为对一条 response 的所有 token 求平均会导致短序列在策略学习中占据优势，因此选择去掉这个系数

$\small \text{step 1:} \quad \mathcal{J}(\boldsymbol{\theta}) = \mathbb{E}_{ q \sim \mathcal{D}, \left\{ o_{i} \right\}_{i=1}^{G} \sim \pi_{\boldsymbol{\theta}_{\mathrm{old}}}(\cdot \mid q) } \left[ \frac{1}{G} \sum_{i=1}^{G} \color{red}{ \xcancel{ \color{black}{ \frac{1}{ \left| o_{i} \right| } } } } \sum_{t=1}^{ \left| o_{i} \right| } \left\{ \min \left( r_{i, t}(\boldsymbol{\theta}) \hat{A}_{i, t}, \operatorname{clip} \left( r_{i, t}(\boldsymbol{\theta}), 1 - \epsilon, 1 + \epsilon \right) \hat{A}_{i, t} \right) \right\} \right] \\$ • **移除标准差 $\operatorname{std}(\mathbf{r})$**：Dr. GRPO 认为，组内相对优势计算中除以标准差的操作会导致那些标准差较低的任务（例如所有 response 的 reward 几乎全为 0 或全为 1）在训练中占据更多权重，进而导致不同任务之间存在难度偏差，因此同样去掉了除以标准差的操作

$\small \begin{align*} &\text{step 2:} \quad \mathcal{J}(\boldsymbol{\theta}) = \mathbb{E}_{ q \sim \mathcal{D}, \left\{ o_{i} \right\}_{i=1}^{G} \sim \pi_{\boldsymbol{\theta}_{\mathrm{old}}}(\cdot \mid q) } \left[ \frac{1}{G} \sum_{i=1}^{G} \sum_{t=1}^{ \left| o_{i} \right| } \left\{ \min \left( r_{i, t}(\boldsymbol{\theta}) \hat{A}_{i, t}, \operatorname{clip} \left( r_{i, t}(\boldsymbol{\theta}), 1 - \epsilon, 1 + \epsilon \right) \hat{A}_{i, t} \right) \right\} \right], \quad \text{where} \\[1.5ex] &\qquad r_{i, t}(\boldsymbol{\theta}) = \frac{\pi_{\boldsymbol{\theta}}(o_{i, t} \mid q, o_{i, \lt t})}{\pi_{\boldsymbol{\theta}_{\mathrm{old}}}(o_{i, t} \mid q, o_{i, \lt t})}, \quad \hat{A}_{i, t} = \tilde{R}_{i} = \frac{R_{i} - \operatorname{mean}(\mathbf{R})}{ \color{red}{ \xcancel{ \color{black}{ \operatorname{std}(\mathbf{R}) } } } } \end{align*} \\$

• 综上，Dr. GRPO 改进后的损失函数最终形式为：

$\bbox[#FFB]{ \small \begin{align*} &\mathcal{J}_{\mathrm{Dr. GRPO}}(\boldsymbol{\theta}) = \mathbb{E}_{ q \sim \mathcal{D}, \left\{ o_{i} \right\}_{i=1}^{G} \sim \pi_{\boldsymbol{\theta}_{\mathrm{old}}}(\cdot \mid q) } \left[ \frac{1}{G} \sum_{i=1}^{G} \sum_{t=1}^{ \left| o_{i} \right| } \left\{ \min \left( w_{i, t}(\boldsymbol{\theta}) \hat{A}_{i, t}, \operatorname{clip} \left( r_{i, t}(\boldsymbol{\theta}), 1 - \epsilon, 1 + \epsilon \right) \hat{A}_{i, t} \right) \right\} \right], \quad \text{where} \\[1.5ex] &\qquad r_{i, t}(\boldsymbol{\theta}) = \frac{\pi_{\boldsymbol{\theta}}(o_{i, t} \mid q, o_{i, \lt t})}{\pi_{\boldsymbol{\theta}_{\mathrm{old}}}(o_{i, t} \mid q, o_{i, \lt t})}, \quad \hat{A}_{i, t} = \tilde{R}_{i} = R_{i} - \operatorname{mean}(\mathbf{R}) \end{align*} } \\$

## 扩展三：GSPO (Group Sequence Policy Optimization)

• GSPO 是阿里 Qwen 团队发表的一篇论文，同时也是 Qwen-3 系列采用的 RL 后训练方法。它同样是在 GRPO 的基础上做了一些优化，主要优化方向是将重要性采样系数从 token-level 扩展到 sequence-level，以提升模型在 MoE 场景中的表现

• 我们已经知道，重要性权重的作用是评估一个 action 在新策略和在旧策略中相比，在多大程度上被高估/低估。它在数值上等于该动作在新旧策略中被采样到的概率的比值，并且直接乘到该动作的相对优势上以校准这一偏差

• 重要性权重的取值对 RL 训练的效果有显著影响。在先前的算法中，PPO 通过裁剪重要性权重的方法限制新旧策略之间的偏差，以提高训练稳定性；DAPO 通过提高裁剪上界的方法鼓励模型探索，避免陷入局部最优

• 在上述方法中，重要性权重都是 token-level 的：

$r_{i,t}(\boldsymbol{\theta}) = \frac{\pi_{\boldsymbol{\theta}}(o_{i, t} \mid q, o_{i, \lt t})}{\pi_{\boldsymbol{\theta}_{\mathrm{old}}}(o_{i, t} \mid q, o_{i, \lt t})} \\$

• GSPO 认为，由于 MoE 的稀疏激活特性，同一条 response 在新旧策略中激活的专家可能会发生显著变化（约有 10% 的专家不同），这意味着新旧策略中用于计算重要性权重的采样概率是由不同的专家网络给出的，这会导致重要性权重出现剧烈的数值波动，影响 RL 训练的正常收敛

• 为了应对这个问题，团队过去会采用 **Routing Replay** 策略：将旧策略中激活的专家缓存起来，在计算重要性权重时强制新策略重放这些专家路由以激活相同的专家网络。但是这一方法会产生额外的内存和通信开销，并且可能会限制 MoE 的容量

![](https://pic1.zhimg.com/v2-dd99c7aec19afd02f83c660fc45457b6_r.jpg)

• GSPO 认为，token-level 的重要性权重在 MoE 场景下并不能充分反映出一个决策被高估/低估的程度，相反，这应当由该决策所在的 sequence 决定。为此，GSPO 设计了如下 sequence-level 的重要性权重：

$s_{i}(\boldsymbol{\theta}) = \left( \frac{\pi_{\boldsymbol{\theta}}(o_{i} \mid q)}{\pi_{\boldsymbol{\theta}_{\mathrm{old}}}(o_{i} \mid q)} \right)^{\frac{1}{ \left| o_{i} \right| }} = \exp \left( \frac{1}{ \left| o_{i} \right| } \sum_{t=1}^{ \left| o_{i} \right| } \log \frac{\pi_{\boldsymbol{\theta}}(o_{i, t} \mid q, o_{i, \lt t})}{\pi_{\boldsymbol{\theta}_{\mathrm{old}}}(o_{i, t} \mid q, o_{i, \lt t})} \right) \\$

• 它等于各 token 重要性权重的几何平均。由于 sequence-level 的重要性权重只关注序列整体的似然，对单个 token 的似然变化不敏感，因此可以摆脱对 routing replay 等复杂机制的依赖，从根本上解决 MoE 中专家激活波动的问题，提高 RL 训练的稳定性

• 在应用 sequence-level 的重要性权重后，$\min(\cdot)$ 内的变量已经和时间 $t$ 无关，因此 GSPO 的损失函数可以不需要在 token 维度上取平均

• 由此可以得到 GSPO 损失函数的最终形式为：$\bbox[#FFB]{ \small \begin{align*} &\mathcal{J}_{\mathrm{GSPO}}(\boldsymbol{\theta}) = \mathbb{E}_{ q \sim \mathcal{D}, \left\{ o_{i} \right\}_{i=1}^{G} \sim \pi_{\boldsymbol{\theta}_{\mathrm{old}}}(\cdot \mid q) } \left[ \frac{1}{G} \sum_{i=1}^{G} \left\{ \min \left( s_{i}(\boldsymbol{\theta}) \hat{A}_{i}, \operatorname{clip} \left( s_{i}(\boldsymbol{\theta}), 1 - \epsilon, 1 + \epsilon \right) \hat{A}_{i} \right) \right\} \right], \quad \text{where} \\[1.5ex] &\qquad s_{i}(\boldsymbol{\theta}) = \left( \frac{\pi_{\boldsymbol{\theta}}(o_{i} \mid q)}{\pi_{\boldsymbol{\theta}_{\mathrm{old}}}(o_{i} \mid q)} \right)^{\frac{1}{ \left| o_{i} \right| }} = \exp \left( \frac{1}{ \left| o_{i} \right| } \sum_{t=1}^{ \left| o_{i} \right| } \log \frac{\pi_{\boldsymbol{\theta}}(o_{i, t} \mid q, o_{i, \lt t})}{\pi_{\boldsymbol{\theta}_{\mathrm{old}}}(o_{i, t} \mid q, o_{i, \lt t})} \right) \end{align*} } \\$

## 扩展四：SAPO (Soft Adaptive Policy Optimization)

• SAPO 的优化目标仍然是裁剪系数，它的动机也不难理解：用平滑的衰减代替硬性的截断控制新策略的变化幅度

• 为此，SAPO 提出了一个温度控制的软门控 (Temperature-Controlled Soft Gate) 机制，其计算方式为：$\bbox[#FFB]{ \small \begin{align*} &\mathcal{J}_{\mathrm{SAPO}}(\boldsymbol{\theta}) = \mathbb{E}_{ q \sim \mathcal{D}, \left\{ o_{i} \right\}_{i=1}^{G} \sim \pi_{\boldsymbol{\theta}_{\mathrm{old}}}(\cdot \mid q) } \left[ \frac{1}{G} \sum_{i=1}^{G} \frac{1}{ \left| o_{i} \right| } \sum_{t=1}^{ \left| o_{i} \right| } f_{i,t}(r_{i,t}(\boldsymbol{\theta})) \hat{A}_{i, t} \right], \quad \text{where} \\[1.5ex] &\qquad f_{i,t}(x) = \sigma \left( \tau_{i,t}(x - 1) \right) \cdot \frac{4}{\tau_{i,t}}, \quad \tau_{i,t} = \begin{cases} \tau_{\mathrm{pos}}, & \text{if } A_{i,t} \gt 0 \\ \tau_{\mathrm{neg}}, & \text{otherwise} \end{cases} \end{align*} } \\$

• 其中：

• $\tau$ 是温度参数，用于控制门控函数的陡峭程度： $\tau$ 越大，门控函数越接近硬性截断。此外，SAPO 针对好动作（$A_{i,t} \gt 0$）和坏动作（$A_{i,t} \lt 0$）设计了不同的 $\tau$，并且设置 $\tau_{\mathrm{neg}} \gt \tau_{\mathrm{pos}}$，以控制坏动作具有更高的衰减速率，从而提高训练稳定性
