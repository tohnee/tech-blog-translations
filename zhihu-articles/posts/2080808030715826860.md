云端大模型用着方便，但有些场景总让人犹豫：公司资料不能随便贴给外部服务，断网就干不了活，API 账单按月涨。其实只要有一台还凑合的电脑，这些问题都有解——把模型跑在自己机器上。这篇记录我用 Ollama 部署模型、再接进 WorkBuddy 的完整过程，全程二十分钟左右。

## 一安装 Ollama

装完验证一下：按**Win + R**输入 cmd 回车，敲：

ollama -v

能看到版本号，就是装好了。

▲ 命令行里 ollama pull / run 一气呵成

## 二把模型跑起来

Ollama 装完是空的，不带任何模型。不用单独下载，直接输入：

如果本地还没有这个模型，Ollama 会自动下载 Qwen3.5 的 4B 版本，大概 2~3 GB，几分钟的事，下完自动进入对话。想先把模型单独下载好，也可以用 ollama pull qwen3.5:4b。

ollama run qwen3.5:4b

先随便问两句确认模型活着，再进行下一步。

模型怎么选：先看自己电脑的内存和显存，再决定跑多大的——

**8G 内存**：4B 就能跑，往下的 2B、0.8B 更轻，适合先试水<br>**12G 以上显存**：可以上 8B 或 14B，回答明显更聪明<br>**24G 显存**（比如 4090）：直接试 27B 的量化版，能力上一个台阶

拿不准就先跑 4B，觉得不够聪明再往上换——换模型就是换个名字的事，成本几乎为零。

## 三调一下 Ollama 的设置

打开 Ollama 的桌面客户端进 Settings，有两处值得看：

**模型存储位置（Model location）**：默认在 C 盘，模型动辄几个 G，建议改到空间宽裕的盘。

**Context length（上下文长度）**：这个滑块决定模型一次能"记住"多少内容。在电脑配置允许的情况下，上下文长度越长越好，长文写作、读文档都靠它，但吃显存，量力而行。我设在了 64k。

![](https://pic3.zhimg.com/v2-f96d0547aa318483feba418d4adb506a_r.jpg)

▲ 拖动滑块调整上下文长度

## 附常见问题小抄

· 测试连接失败：确认 Ollama 在运行（任务栏有图标），端口 11434 没被占用<br>· 提示模型不存在：模型名称要和 ollama run 的名字一字不差<br>· 回复很慢：换更小的模型，或把 Context length 调低<br>· C 盘告急：Settings 里改 Model location，模型可以搬家

整套流程走下来，唯一花的是电费。模型下载完之后，断网也能用，数据全程不出你的硬盘。如果你也有不能往外贴的资料，或者单纯不想再交 API 费，值得一试。
