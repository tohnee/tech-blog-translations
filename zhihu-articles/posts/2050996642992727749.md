## 模块二：训练框架

**训练后端**

1. [NVIDIA Megatron-LM / Megatron-Core](https://github.com/NVIDIA/Megatron-LM) — 大规模训练事实标准，TP/PP/DP/EP/CP + FP8
2. [Microsoft DeepSpeed](https://github.com/deepspeedai/DeepSpeed) — ZeRO 系列 + 激进 offload
3. [TorchTitan](https://github.com/pytorch/torchtitan) — 原生 PyTorch 大模型训练参考实现
4. [字节 veScale](https://github.com/volcengine/veScale) — PyTorch 原生自动并行训练框架
5. [阿里 Pai-Megatron-Patch](https://github.com/alibaba/Pai-Megatron-Patch) — 在 Megatron 上适配主流开源模型
6. [EleutherAI GPT-NeoX](https://github.com/EleutherAI/gpt-neox) — 基于 Megatron-DeepSpeed 的开源训练库

**RL 后训练框架**

1. [slime](https://github.com/THUDM/slime) — 智谱，专为 RL Scaling 设计（Megatron + SGLang）
2. [verl (HybridFlow)](https://github.com/volcengine/verl) — 字节，工业级 RL 后训练，FSDP/Megatron + vLLM/SGLang
3. [HybridFlow: A Flexible and Efficient RLHF Framework](https://arxiv.org/abs/2409.19256) — verl 论文（EuroSys’25）
4. [OpenRLHF](https://github.com/OpenRLHF/OpenRLHF) — 基于 Ray + DeepSpeed + vLLM 的 RLHF 框架
5. [NVIDIA NeMo-RL](https://github.com/NVIDIA/NeMo-RL) — NeMo 生态 RL 后训练，原生 FP8
6. [HuggingFace TRL](https://github.com/huggingface/trl) — SFT/DPO/PPO/GRPO 轻量后训练库
7. [蚂蚁 AReaL](https://github.com/inclusionAI/AReaL) — 异步 RL（Async RL）后训练系统
8. [阿里 ROLL](https://github.com/alibaba/ROLL) — 面向大规模 RL 的强化学习库
9. [ReaLHF: Optimized Placement & Parallelism for RLHF](https://arxiv.org/abs/2312.11819) — RLHF 资源放置优化

**微调 / 工具**

1. [LLaMA-Factory](https://github.com/hiyouga/LLaMA-Factory) — 一站式微调（LoRA/QLoRA/全参/对齐）
2. [Unsloth](https://github.com/unslothai/unsloth) — 单卡高效微调，定制 Triton kernel 提速降显存
3. [Liger-Kernel](https://github.com/linkedin/Liger-Kernel) — 训练用融合 Triton 算子库
4. [Ray / Ray Train](https://github.com/ray-project/ray) — RL 与分布式训练常用调度编排底座
