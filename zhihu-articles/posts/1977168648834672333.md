无论是在 AI Studio 还是 Gemini App 中，Gemini 给我的感觉都是幻觉严重、智力不足，不仅长文本遗忘，指令服从也比较差，用起来很不顺手还特别固执，甚至不如最初2.5Pro的智力。

后来我将 API 从免费版升级到 Tier 1，明显感觉到回答细腻了很多，表述也清晰流畅，不再有之前那种模糊的感觉。

我还测试了一道之前无论怎么提示都无法解决的算法题，题目使用 GPT-5.1 也没能做出来，说明难度还是有的。这次用 API 提交后，几分钟就给出了答案，而且还一次通过，我看了是没有开Search的，可见API智力确实大幅提高。

免费的智力果然就低不少，感觉可能量化过头了，尽管在一般任务性能差距不大，求解复杂问题的能力大幅下降。

我还感觉我的GPT可能也降智了，OpenAI也是恶心人，IP有一点不纯净就降智，之前我甚至遇到开Thinking给我偷偷换到GPT 4o mini的情况。

现在各大厂商都在降本增效，消费者花钱都不一定得到保障，不知道哪天就偷偷换模型。
