在大模型的多机训练中，节点间的通信往往成为性能瓶颈。如果未正确配置 InfiniBand，通信将回退至基于 socket 的方式，可能严重拖慢训练速度。例如，在一个由 20 台 H100 机器组成的集群上进行分布式训练时，若未启用 InfiniBand，每个迭代耗时约为 5–6 秒；而启用后，迭代时间可降至约 1.5 秒，提升显著。

题主使用的集群采用 Docker 管理运行环境，因此除了确保宿主机已正确安装并配置了 InfiniBand 驱动和相关通信中间件（建议联系管理员确认），还需在容器镜像内安装必要的库支持。实测表明，仅需安装以下两个软件包，即可正常启用 InfiniBand 通信：

```bash
apt install rdma-core ibverbs-providers
```

除此之外，还需要正确设置环境变量，下面是一个例子，具体取值与集群配置有关。

```text
export NCCL_IB_DISABLE=0
export NCCL_IB_HCA=mlx5
export NCCL_DEBUG=WARN
export NCCL_IB_GID_INDEX=3
```
