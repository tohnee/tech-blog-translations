## 1.摘要

**一句话结论**

**具身智能的主线已经从“预测下一段动作”，升级为“主动获取信息—维护状态—预测未来—执行动作—验证结果—从经验继续学习”。**

本综述系统整理 2025 年 7 月至 2026 年 7 月具身智能领域的主要技术进展。研究发现，Vision-Language-Action（VLA）模型仍然是通用机器人策略的核心载体，但其角色正在发生变化：VLA 不再被视为单独解决全部问题的端到端“大脑”，而逐步成为多层闭环系统中的动作专家。围绕 VLA，行业正在补齐高层 Agent 编排、情景记忆、世界状态跟踪、主动感知、世界模型、触觉与力觉、实时动作衔接、成功验证、失败恢复以及强化学习后训练等能力。

过去一年最明显的结构性趋势包括：

- 异构数据从简单混合转向表示—运动—行为对齐；
- 子任务划分升级为高低层 Agentic 系统；
- 长程任务优化从扩大上下文转向记忆—验证—恢复；
- RTC 从推理期拼接发展到原生动作延续和动态 horizon；
- RL 从少量技能优化进入通用 VLA 后训练；
- 世界模型由视频生成工具转向训练、规划、评测与价值估计基础设施；
- 主动感知从物理移动相机扩展到视觉 token、历史帧和多相机资源调度；
- 动作表示从连续向量扩展为语义 token、语义事件和 latent action；
- 控制对象从固定机械臂扩展到头部、腰部、底盘、双臂、灵巧手和双腿；
- 评测重点则从单次成功率转向泛化、恢复、吞吐量和长期自主运行。

在公司路线方面，Figure、Google DeepMind、NVIDIA、Physical Intelligence、1X 与 Sanctuary AI 分别代表全身多模态控制、Agentic 具身推理、双系统与实时执行、真机经验强化学习、视频世界模型以及主动触觉。

国内则形成了更丰富的路线分化：阿里 Qwen 强调异构数据对齐与可配置视觉流；字节 GR-3 强调网页语义、机器人数据与人类轨迹联合训练；腾讯 HY-Embodied 强调大模型推理向边缘模型蒸馏；小米通过超过十万小时 UMI 轨迹验证规模化；自变量探索事件级世界模型和语义动作 tokenizer；千寻推进开源 VLA 与真机评测；苏度探索纯仿真训练与高频逐步闭环；星海图从双系统走向统一自回归和训练期世界建模；无界动力探索无动作视频与潜动作；原力灵机则强调具身原生预训练和开发基础设施。

![](https://pic3.zhimg.com/v2-c01f4bd4cdf07417b46fcef5289878d2_r.jpg)

传统 VLA 的核心映射是“图像＋语言指令→动作序列”。这一范式极大简化了机器人系统，但在长程、遮挡、接触、实时控制和开放环境中暴露出结构性缺口：模型可能忘记已经完成的步骤，无法判断动作是否成功，固定 action chunk 与现实事件边界不一致，视觉无法覆盖被遮挡的接触状态，失败后也缺少回滚和重规划机制。

过去一年的改进不再集中于单个网络模块，而是开始围绕完整执行循环优化。HELM 将长程失败归纳为 memory gap、verification gap 和 recovery gap，并显示单纯增加上下文的收益显著小于加入情景记忆、状态验证器和回滚重规划。[1] Google 的 Gemini Robotics-ER 将任务规划、进度估计、成功检测和工具调用放到高层具身推理模型中，再由低层 VLA 执行动作。[10][11] Figure、GR00T 和 Galaxea 则把高层推理、中频动作策略和高频身体控制拆成不同时间尺度。[8][12][32]

范式变化

VLA 正从“完整机器人系统”退回到更合适的位置：它是强大的视觉运动专家，但长期自主性需要 Agent、记忆、世界模型、Verifier、低层控制器和数据闭环共同完成。

## 3. 十二项核心技术趋势

### 3.1 数据扩展：从“更多小时”转向异构数据对齐

具身数据天然包含机器人构型、坐标系、控制频率、行为粒度和语言标注差异。过去的简单混合容易产生负迁移，近一年更强调在表示、运动和行为三个层面完成对齐后再规模化。Qwen-RobotManip 通过跨表示、运动和行为的统一对齐，结合人类第一视角视频生成多平台机器人轨迹，并构建约 3.81 万小时预训练语料；小米 Xiaomi-Robotics-1 则以超过 10 万小时 UMI 真实操作轨迹验证数据规模，并使用自动标注描述场景状态变化。[17][25]

- 跨本体数据不再直接拼接，而是增加统一坐标、相对动作表示、动作 adapter 或 canonical action space。
- 高价值数据从“完美成功轨迹”扩展到偏差、修正、人工接管、恢复和自主 rollout。
- 语言标注从任务名称升级为子任务、状态变化、对象关系和事件边界。

仍待解决

```text
核心瓶颈：不同来源数据的质量、任务分布和控制接口仍难统一；数据规模并不能自动转化为开放世界泛化。
```

### 3.2 Agentic 分层：子任务划分升级为动态编排

子任务划分正在从离线生成一个固定步骤列表，升级为执行中的动态循环：观察当前状态、估计进度、生成下一子目标、调用动作策略、验证结果并必要时重规划。Gemini Robotics-ER 1.5/1.6 体现了高层具身推理模型与低层 VLA 的协同；Galaxea G0 采用 VLM 慢思考与 VLA 快执行；Qwen-RobotNav 则允许上层 Agent 在推理时修改视觉历史、多相机权重和导航模式。[10][11][16][32]

- 高层模型处理语义、计划、工具调用和任务状态。
- 低层策略处理连续动作、局部避障和接触。
- 两层之间的接口从自然语言子任务扩展到目标框、视觉子目标、状态谓词和动作事件。

仍待解决

```text
核心瓶颈：高层规划错误会放大到物理执行；自然语言接口容易丢失几何、时序和可行性信息。
```

### 3.3 长程任务：记忆、Verifier 与失败恢复成为核心组件

HELM 的结果显示，将历史窗口扩大到 32 帧只带来有限提升，而情景记忆、动作前状态验证和 rollback/replanning 能显著提高长程任务成功率。[1] 这说明长任务并非简单的“大上下文问题”，而是部分可观测系统中的状态维护和控制问题。

- 情景记忆保存关键帧、已完成步骤、物体位置和失败历史。
- Verifier 在执行前检查动作与子目标是否可行，执行后判断是否完成。
- Recovery 策略决定重试、换抓法、回滚到前一事件，还是重新规划整个任务。

仍待解决

```text
核心瓶颈：自动成功标签和失败原因难获取；错误恢复策略本身也需要长尾数据。
```

### 3.4 实时控制：RTC 之后走向原生动作延续与动态 horizon

RTC 让模型在执行当前动作块时并行生成下一动作块，但外部插值和拼接可能造成模式切换与轨迹不连续。Legato 将 continuation 写入训练目标，使策略原生学习从已执行动作继续生成；FASTER 则通过 horizon-aware 调度提高即时动作反应速度。[2][3] GR00T N1.6 也公开采用训练期和测试期 RTC 提升异步 rollout 的平滑性。[12]

- 自由空间运动可使用较长 action chunk，减少推理开销。
- 精细接近和接触阶段需要短 horizon 或逐步闭环。
- 出现观测偏差、动作熵升高或碰撞风险时，应立即截断并重规划。

仍待解决

```text
核心瓶颈：动作连续性、反应速度和计算成本之间仍存在三方权衡。
```

### 3.5 强化学习：从小技能优化进入通用 VLA 后训练

Physical Intelligence 的 RECAP 将演示、纠正、自主 rollout 和 advantage-conditioned policy 结合，使 π*0.6 在咖啡、叠衣和装箱任务上显著提高成功率与每小时吞吐量。[6] Z-1 则将 GRPO 系统化应用于 flow-based VLA，在 RoboCasa 任务上从策略自身失败中继续优化。[7]

- 奖励不再只有任务成功，还包括任务进度、速度、轨迹质量、接管次数和安全约束。
- 失败轨迹不再被直接删除，而可用于价值估计、偏好学习和 advantage 条件训练。
- 训练流程从预训练→SFT 扩展为预训练→SFT→仿真 RL→真机经验→持续更新。

仍待解决

```text
核心瓶颈：真机探索成本高，自动奖励容易被策略利用，在线分布变化也可能造成灾难性退化。
```

### 3.6 世界模型：从“生成视频”变成预测基础设施

世界模型的角色正在分化。Qwen-RobotWorld 和 1XWM 采用显式未来视频预测，分别用于数据生成、虚拟评测、规划信号，以及从未来视频反推动作。[18][41] Fast-WAM 则发现，视频预测的主要价值可能来自训练期物理表征，部署时无需显式生成未来画面。[34] WALA、LaWAM 等工作进一步将预测转移到语义特征、深度或 latent state 中，降低像素生成冗余。[35]

- 显式 imagination：生成未来视频，再筛选或解码动作。
- 训练期世界建模：联合视频与动作训练，推理时只输出动作。
- 隐空间世界模型：预测任务相关特征、深度、事件或 latent action。
- 世界价值模型：用未来建模能力判断轨迹质量和任务进度。

### 3.7 主动感知：机器人开始学习“怎么看”

主动感知把转头、移动相机、靠近观察、切换相机、保留历史帧和主动触摸都视为信息获取动作。ActiveVLA 通过关键三维区域定位、视角选择和 3D zoom-in 改善精细操作；SaPaVe 将相机动作与机械臂动作解耦训练但协调执行。[4][5] Qwen-RobotNav 展示了“计算主动感知”：上层 Agent 可以动态改变视觉 token 预算、历史帧衰减和多相机权重。[16]

- 物理主动感知：转头、移动底盘、改变手腕或身体姿态。
- 计算主动感知：决定看哪台相机、哪些历史帧和哪些区域。
- 交互式感知：轻推、轻夹、滑动或触摸以获取物理属性。

仍待解决

```text
核心瓶颈：观察动作有时间和运动成本，相机移动还会造成视觉分布变化。
```

### 3.8 视觉—触觉—力觉融合：接触阶段形成专用闭环

Figure Helix 02 将掌心相机、触觉与全身本体感觉用于瓶盖、药片等精细操作；Sanctuary AI 强调视觉遮挡时的 blind picking、滑移检测和过大力防止；VTAO-BiManip 则从视觉—触觉—动作联合预训练角度验证多模态接触建模。[8][42][38]

- 视觉负责语义、全局几何与对象定位。
- 触觉负责接触位置、滑移和局部形状。
- 力觉负责交互动力学、夹持强度和插入力。
- 未来方向是预测动作后的视觉与触觉共同变化。

仍待解决

```text
核心瓶颈：触觉传感器形态差异大，缺少类似互联网图文的大规模通用数据。
```

### 3.9 动作表示：连续向量扩展为 token、事件与 latent action

X-Tokenizer 将动作 tokenizer 从压缩器提升为多模态语义接口：第一层离散代码学习粗粒度动作意图，残差层保存连续控制细节。[27] WALL-WM 以语义完整的动作事件作为学习单元，支持可变长度事件执行。[26] WALA 则从无动作视频学习语义—几何 latent action，再通过机器人数据将其解码为可执行控制。[35]

- 语义动作 token：适合语言—动作对齐和跨本体共享。
- 事件级动作：让执行长度匹配真实任务阶段。
- latent action：从无动作视频提取状态变化，再绑定机器人控制。

仍待解决

```text
核心瓶颈：高层动作表示必须兼顾语义可迁移性和低层精确性；过度离散会损失接触细节。
```

### 3.10 跨本体与全身控制：从机械臂走向移动、双臂和人形

GR-3、GR00T、LingBot-VLA 2.0、Xiaomi-Robotics-1 和 Figure Helix 02 都在扩大动作空间与本体覆盖：移动底盘、双臂、头部、腰部、灵巧手和双腿逐渐进入统一策略。[12][19][23][25][8] Galaxea G0 的实验同时提醒，跨本体预训练并非越多越好，充分的单本体预训练仍然关键。[32]

- 跨本体共享语义、视觉和高层运动先验。
- 本体专用 adapter/decoder 负责具体关节和动力学。
- 全身移动操作要求手、躯干、腿和视角在同一任务目标下协同。

仍待解决

```text
核心瓶颈：不同机器人在自由度、动作频率、传感器、负载和接触模型上差异显著。
```

### 3.11 多时间尺度与端侧部署：大模型“想”，小模型“动”

具身系统逐渐形成 System 2、System 1 和 System 0 的分工：低频模型负责推理和规划，中高频策略输出动作块或全身目标，高频控制器负责平衡、接触和关节稳定。Gemini Robotics On-Device 强调断网条件下的本地低延迟；HY-Embodied-0.5 通过大模型到 2B 激活参数模型的 on-policy distillation 提升边缘能力。[13][20]

- 高层模型无需以 1 kHz 控制关节。
- 动作专家可独立量化、蒸馏和端侧部署。
- 低层安全控制与学习策略并行，而不是被完全替代。

仍待解决

```text
核心瓶颈：模块间延迟、坐标和状态同步会产生新的系统级故障。
```

### 3.12 工程与评测：从演示视频转向真机榜单、吞吐量和持续运行

RoboChallenge 尝试将大量 VLA 模型放到统一真机任务上测试，推动可扩展、可复现的真实机器人评测。[30] Physical Intelligence 将每小时成功完成数作为重要指标，HELM 则发布扰动注入的恢复评测。[6][1] 原力灵机 Dexbotic 2.0 代表另一趋势：把数据、训练、仿真、评测、硬件和部署工作流标准化。[37]

- 除成功率外，关注吞吐量、任务时长、人工接管和恢复能力。
- 公开未剪辑长时间测试和失败类型。
- 模型、数据格式、硬件接口和评测工具逐步形成基础设施。

仍待解决

```text
核心瓶颈：真机评测成本高，任务重置和不同硬件间的公平比较仍很困难。
```

## 4. 主动感知专题：机器人如何学习“怎么看”

主动感知的核心不是增加一台可动相机，而是让系统显式判断“当前缺少什么信息、获取信息的成本是多少、哪种观察最有利于下一动作”。它将机器人决策从单纯的任务奖励扩展为任务进度与信息价值的联合优化。

4.1 能解决的问题

4.2 五类实现方式

1.  Next-Best-View：生成候选相机位姿，按任务相关性、信息增益、遮挡、移动成本和安全性打分。

2.  端到端相机策略：共享视觉语言表征，分别输出相机动作与机械臂动作；SaPaVe 采用解耦动作空间和协调训练。[5]

3.  分阶段状态机：Search→Localize→Inspect→Manipulate→Verify，工程可解释性高。

4.  不确定性触发：只有检测置信度、动作熵、多策略分歧或世界模型偏差超过阈值时才重新观察。

5.  交互式感知：轻推、触摸、晃动、沿边缘滑动，用动作主动获取重量、摩擦、软硬和接触位置。

## 5. 技术路线的收敛、分化与产业判断

**7.1 已形成共识的收敛点**

1.  纯粹扩大 VLA 参数量不足以解决长程、遮挡和失败恢复；系统必须维护状态并验证结果。

2.  动作生成必须与实时执行解耦，大模型推理、动作策略和低层控制需要不同时间尺度。

3.  数据规模仍是基础，但异构对齐、失败数据和自主经验比“总小时数”更能决定后训练收益。

4.  世界模型的价值不必等同于在线生成高清未来视频；事件、深度、特征和 latent state 都可以承担预测接口。

5.  视觉不是接触操作的充分模态，掌心视觉、触觉和力觉将逐步进入通用策略。

6.  真正的通用化要求跨本体，但单本体高质量预训练、硬件可控性和低层控制仍不可替代

**7.2 尚未收敛的关键分歧**

![](https://pic1.zhimg.com/v2-9ad52c593007a90adb7c3b91696ab7ce_r.jpg)

7.3 最值得优先投入的五项优化

1.  记忆＋State Verifier＋Recovery：直接决定长程任务能否从演示进入连续运行。

2.  RL 后训练＋自主经验闭环：让模型从真实部署中的失败和纠正持续提高。

3.  事件/latent 世界模型：在控制相关表示中预测未来，兼顾物理先验和实时性。

4.  主动感知＋视觉触觉融合：减少遮挡、精细定位和接触确认导致的失败。

5.  跨本体全身多时间尺度控制：把通用语义能力转化为可靠的人形和移动操作。

## 6. 关键瓶颈与未来 12—24 个月展望

![](https://pic4.zhimg.com/v2-7daffb2d38b531f25c50abbeebd4c443_r.jpg)

6.1 对下一阶段模型形态的判断

| 可能的主流架构低频 Agent 维护任务和世界状态；主动感知模块决定观察策略；世界模型/价值模型提供候选未来与可行性；VLA/WAM 生成动作；高频 System 0 保证平衡、接触和安全；执行数据经奖励与人工纠正进入持续后训练。 |
| --- |

这一结构并不意味着回到传统手工模块化。各模块仍可端到端或联合训练，但其接口、时间尺度和职责将更加明确。未来竞争的关键不是“端到端或模块化”二选一，而是能否让可学习模块在可靠的闭环架构中协同。

6.2 对产业落地指标的判断

从单任务成功率转向每小时有效完成数和连续运行时长。

从零样本展示转向新环境下降幅度、扰动恢复率和人工接管频率。

从模型 checkpoint 转向包含数据、部署、诊断、升级和安全边界的完整产品。

从“机器人能做什么”转向“机器人在多少不同现场、以什么维护成本稳定做”。

## 7. 结论

过去一年具身智能最重要的变化，不是出现了某一种绝对占优的 VLA 架构，而是行业开始正视物理世界执行的完整问题。机器人必须在部分可观测、实时、接触丰富且存在失败的环境中运行，因此单次动作生成能力只是起点。

数据层面，规模化正在与异构对齐、人类视频、无动作视频、仿真和自主经验结合；模型层面，VLA 与世界模型、动作 token、事件和 latent action 相互融合；系统层面，Agent、记忆、主动感知、Verifier、Recovery 和多频率控制逐渐成为标准组件；工程层面，开源模型、真机榜单、部署框架和数据回流开始决定迭代速度。

因此，下一阶段真正拉开差距的，将不是谁在单个 benchmark 上多几个百分点，而是谁能够把“理解任务—主动观察—维护状态—预测未来—实时执行—确认成功—失败恢复—经验学习”做成稳定、低成本和可扩展的统一闭环。

| 最终判断VLA 会继续扩大，但它将越来越像闭环具身系统中的“运动与交互专家”；真正的通用机器人能力，来自模型周围的世界状态、主动信息获取、实时控制和自我改进机制。 |
