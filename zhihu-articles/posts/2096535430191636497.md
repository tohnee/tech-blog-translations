## **【ECCV 2026】Learning to Compose: Revisiting Proxy Task Design for Zero-Shot Composed Image Retrieval**

**作者列表：** Jingjing Zhang, Lei Zhang, Zheren Fu, Zhendong Mao（中国科学技术大学）

**文章概述**

零样本组合图像检索（ZS-CIR）用图文对构造代理任务，绕开了昂贵的三元组标注，但存在一个被普遍忽视的结构性缺陷：现有方法只是让视觉与文本特征去 **迎合** 一个预先写死、 **不可学习** 的组合规则（把图像特征投影成伪词塞进冻结文本编码器，或做线性特征算术）， **组合函数本身从未被建模** ，自然无法表达细粒度、多样的语义修改。 **FoCo** （Focus-then-Complete）把组合重构成一个 **可学习的两阶段过程** ，灵感取自人类「先聚焦、再补全」的认知习惯：第一步是 **文本锚定的视觉聚合** ，在局部文本语义引导下从参考图中挑出与修改相关的视觉证据；第二步是 **上下文条件语义补全** ，把这些局部表征连同剩余场景上下文一起变换成完整的目标语义。监督信号来自 **字幕分解** ——用 Llama-3.1-8B-Instruct 把每条全局 caption 拆成一组 **局部 caption** 加一条 **上下文 caption** ，天然对应「聚焦」与「补全」两个阶段；训练再配一套 **跨实例对比** 方案，用多个正样本与跨实例负样本，缓解多语义视图带来的优化困难并抑制捷径学习。在 FashionIQ、CIRR、CIRCO、GeneCIS 四个基准上全面领先，ViT-L/14 上 CIRR R@1 达 34.5、CIRCO mAP@50 达 20.8，换 ViT-G/14 后分别升至 38.5 与 28.9。

## **【CVPR 2026】G-MIXER: Geodesic Mixup-based Implicit Semantic Expansion and Explicit Semantic Re-ranking for Zero-Shot Composed Image Retrieval**

**作者列表：** Jiyoung Lim, Heejae Yang, Jee-Hyong Lee（韩国成均馆大学）

**代码链接：** [https://github.com/maya0395/gmixer](https://github.com/maya0395/gmixer)

**文章概述**

组合图像检索的查询天然同时携带 **显式语义** （明确说要改什么）与 **隐式语义** （画面里有、文字却没说的东西，比如「猫」和「篮子」）。已有的免训练方法普遍让 MLLM 把隐式语义 **全部转写成显式文本** 再检索，结果是过度依赖文本模态、检索空间被过度约束，反而丢掉了检索本该有的模糊性与多样性。 **G-MIXER** 改为 **先扩后筛** 的两阶段策略：第一阶段是 **隐式语义扩展检索** ，在 CLIP 嵌入空间对参考图与修改文本做 **测地线混合（geodesic mixup）** ，且是在一个 **混合比例区间** 上连续插值而非取固定值，从而构造出既保留隐式语义、又足够多样的组合查询特征与候选集；第二阶段是 **显式语义重排序** ，由 MLLM 生成 Include / Exclude 形式的属性描述，对候选做二次排序、滤除语义噪声。论文指出区间式测地线混合比固定比例更稳定、候选多样性更好。ViT-B/32 上 CIRCO mAP@50 达 24.98、CIRR R@1 达 35.18；ViT-L/14 上分别为 37.98 与 46.91；ViT-G/14 上 CIRCO mAP@50 进一步到 44.77、CIRR R@1 到 61.98，在多个基准上同时超过训练型与免训练型基线。

## **【CVPR 2026】ReCALL: Recalibrating Capability Degradation for MLLM-based Composed Image Retrieval**

**作者列表：** Tianyu Yang, Chenwei He, Xiangzhao Hao, Tianyue Wang, Jiarui Guo, Haiyun Guo, Leigang Qu, Jinqiao Wang, Tat-Seng Chua（中国科学院自动化研究所 / 中国科学院大学人工智能学院 / 东南大学 / 北京邮电大学 / 新加坡国立大学 / 武汉人工智能研究院）

**代码链接：** [https://github.com/RemRico/Recall](https://github.com/RemRico/Recall)

**文章概述**

把生成式多模态大模型压成单向量判别式检索器，这条看似自然的技术路线其实藏着一个陷阱：生成式与判别式两种 **范式冲突** 会让检索适配之后，模型 **原有的细粒度推理能力反而退化** ——在 CIRR 与 FashionIQ 上，微调后的检索器 R@1 明显下滑。 **ReCALL** 正面处理这一「能力退化」现象，提出一个与骨干无关的 **诊断—生成—精修** 三段式框架： **诊断** 阶段用自引导的信息量实例挖掘，定位检索器当前的认知盲区； **生成** 阶段提示基础 MLLM 产出纠正性指令与三元组，并用 **基于 VQA 的一致性过滤** 做质量把关； **精修** 阶段则以 **分组对比** 目标在这批三元组上持续训练，把细粒度视觉-语义区分内化进检索器，让判别式嵌入空间与 MLLM 内在的组合推理重新对齐。CIRR 与 FashionIQ 上刷新 SOTA；在 Qwen2.5-VL-7B 与 Qwen3-VL-8B 两个基座上的实验进一步表明，即便基线本身更强，ReCALL 仍能稳定带来增益，框架泛化性良好。

## **【ECCV 2026】CMDR: Contextual Multimodal Document Retrieval**

**作者列表：** Ryota Tanaka, Taku Hasegawa, Kyosuke Nishida（日本电信电话株式会社 NTT Human Informatics Labs.）

**代码链接：** [https://github.com/nttmdlab-nlp/CMDR-Bench](https://github.com/nttmdlab-nlp/CMDR-Bench)

**文章概述**

多模态文档检索要从图文混排的文档里找回相关页面，但现有基准基本只考词汇匹配或简单语义匹配，方法也普遍 **逐页独立编码** ——文档上下文被整个丢掉了，而现实中不少查询恰恰需要 **跨页聚合信息** 才能定位答案。论文为此提出全新的任务与基准 **CMDR / CMDR-Bench** ，从 Common Crawl 与 Manualslib 收集页数超过 100 页的英文 PDF，手工归入手册、研究报告与论文、学位论文、项目申请书、图书、会议纪要六个领域，并设计出四个必须建模文档上下文才能完成的子任务。对应的方法 **CMDR-Embed** 把上下文显式写进编码流程： **联合编码多页** ，再从共享的上下文表征中 **派生出页级嵌入** ；配套的 **CMCL** （上下文多模态对比学习目标）则在「context 建模能力」与「页级可分性」之间做平衡，避免联合编码把页级区分度抹平。实验显示，CMDR-Embed 显著优于各类无上下文的嵌入模型，印证了上下文感知的多模态嵌入对文档检索乃至 RAG 场景的必要性。
