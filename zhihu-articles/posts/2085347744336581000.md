> 我们昨天给大家介绍了 2026 年值得生信人关注的 AI 智能体。其中说到智能体的核心是一个循环。而让智能体强大的还有 Skill 和 MCP，我们今天就来了解一个 AI 资源大全仓库 - Awesome Genomic Skills： 
>  `https://github.com/GoekeLab/awesome-genomic-skills.git` ，看看有没有你想要的。

**Awesome Genomic Skills** 是一个专门整理基因组学、生物信息学和生命科学相关 AI 资源的项目，主要包括：

- • 生物信息学与基因组学 Skills
- • 生命科学 MCP 服务器
- • AI 科学家与研究智能体系统
- • AI 智能体评估数据集
- • 通用 AI 编程 Skills
- • 其他值得关注的 AI 资源列表

**什么是 Skill？** 简单来说，就是一组指挥 AI 干活的 SOP，通常是一个 Markdown 文件，有可能还有可选的脚本、模板等。 
 **什么是 MCP？** 可以理解为一组暴露给 AI 的工具的标准接口。AI 通过 MCP 提供的工具访问外部世界。

### 生物信息学与基因组学 Skills

专门面向基因组学、生物信息学和生命科学工作的 AI Coding Agent Skills 与工具集合。

- • **science-skills** 开发者： **Google DeepMind** 。包含约 36 个 Agent Skills，覆盖基因组学、结构生物学、化学信息学和文献检索，并封装 AlphaGenome、AlphaFold DB、UniProt、Ensembl、gnomAD、GTEx、ClinVar、dbSNP、ChEMBL、PubChem、PDB、Foldseek、JASPAR、Reactome、STRING、Open Targets、Human Protein Atlas、PyMOL 等 30 多个数据库和工具。
- • **openai/plugins — life-science-research** 开发者： **OpenAI** 。OpenAI 面向 Codex 的 Life Sciences 研究插件，包含 50 个模块化 Skills，覆盖人类遗传学、功能基因组学、基因表达、通路生物学、蛋白质结构、化学和临床证据等领域，并封装 50 多个公共数据库和工具。
- • **anthropics/life-sciences** 开发者： **Anthropic** 。Claude Code 的 Life Sciences Marketplace，采用混合模式，包含 `single-cell-rna-qc` 、 `scvi-tools` 、 `nextflow-development` 、 `clinical-trial-protocol-skill` 等 Skills，同时集成 10x Genomics、ChEMBL、Open Targets、PubMed、bioRxiv、Synapse、ToolUniverse、BioRender 等 MCP Server 和数据服务。
- • **sample-kiro-power-life-sciences** 开发者： **AWS Samples** 。面向 Kiro IDE 的生命科学示例集合，包含 24 个 MCP Server、10 个领域 Skills 和 16 个工作流，覆盖基因组学、蛋白质组学、结构生物学、临床和制药等领域。
- • **ClawBio** 生物信息学原生 AI Agent Skill 库，包含 95 个可复现、local-first 的基因组学 Skills，覆盖变异检测、RNA-seq、群体遗传学等任务，可用于 Claude Code、Copilot、Codex 等 Agent。
- • **SciAgent-skills** 开源 Skill 集合，包含 197 个 Skills，覆盖基因组学与生物信息学、蛋白质组学、结构生物学、药物发现、系统生物学、生物统计和科学写作等领域。
- • **scientific-agent-skills** 开发者： **K-Dense AI** 。包含 135 个 Skills，覆盖基因组学以及地理空间科学等多个科学研究领域。
- • **bioSkills** 开发者： **GPTomics** 。提供用于 Claude Code 的生物信息学 `SKILL.md` 文件，覆盖 RNA-seq、变异分析、ChIP-seq、scRNA-seq、空间转录组、Hi-C、蛋白质组学、微生物组、CRISPR、代谢组学、多组学、免疫治疗和孟德尔随机化等完整分析流程。
- • **Clair-skills** 开发者： **Ruibang Luo's BioAI Lab，香港大学** 。面向 Clair 系列变异检测工具，包括 Clair3、ClairS、Clair3-RNA 和 Clair-Mosaic，可根据分析任务进行模型选择、命令生成和问题排查。
- • **ToolUniverse** 开发者： **Harvard Zitnik Lab** 。用于构建 AI Scientist 系统的生态，集成 1,000 多个机器学习模型、数据集和科学 API，并提供 68 个预构建 Agent Skills，覆盖药物发现、精准肿瘤学和罕见病诊断等领域。
- • **operon** 开发者： **Swarup Lab，University of California, Irvine** 。AI 驱动的生物信息学 IDE，包含 180 多个 `SKILL.md` 格式的分析协议，覆盖 RNA-seq、scRNA-seq、ATAC-seq、ChIP-seq、WGS/WES、空间转录组、蛋白质组学和 GWAS 等分析。
- • **OpenClaw-Medical-Skills** 开发者： **FreedomIntelligence** 。从 12 个以上上游仓库中汇总了 872 个 Skills，覆盖临床工作流、基因组学、药物发现、生物信息学流程和医疗器械监管框架等领域。

### 生命科学 MCP 服务器

为 AI Agent 提供直接访问生物信息学数据库、工具和分析流程能力的模型上下文协议（MCP）服务器。

- • **ChatSpatial** 用于通过自然语言进行空间转录组分析的 MCP Server，支持 Scanpy、Squidpy、细胞通讯分析和空间域识别。
- • **biomcp** 一个可以查询多种信息来源的 MCP Server，包括临床试验、遗传数据和已发表的医学文献。
- • **gget-mcp** 封装 Pachter Lab 的 gget 生物信息学工具包，提供 13 个工具，覆盖 Ensembl 基因搜索与元数据、序列获取、BLAST/BLAT/MUSCLE 比对、ARCHS4 表达数据、Enrichr 功能富集、PDB/AlphaFold 蛋白质结构、COSMIC 癌症突变以及 CellxGene 单细胞查询。
- • **Seqera MCP** Seqera Labs 提供的托管 MCP Server，可访问 Seqera Platform 工作流启动与管理、Wave 容器配置、nf-core 模块以及 SRA/ENA/GEO 数据获取功能。
- • **knowledgebase-mcp** BioContextAI Knowledgebase MCP Server，集成 STRINGDb、Open Targets、Reactome、UniProt、Human Protein Atlas、KEGG、AlphaFold、Ensembl、 [http://ClinicalTrials.gov](http://ClinicalTrials.gov) 、bioRxiv 等多个生命科学数据源。
- • **ClawBio MCP** ClawBio Skill Library 的 MCP 模式，将全部 95 个基因组学 Skills 暴露为可调用工具，使 Cursor、Zed 等不同 Agent 可以执行变异检测、RNA-seq、群体遗传学等分析。
- • **roda-mcp** AWS Labs 的 MCP Server，用于发现和探索 Registry of Open Data on AWS 中的公共数据集，覆盖 1,100 多个数据集，并支持搜索、筛选、查看数据集信息以及浏览和采样公共 S3 数据。
- • **plant-genomics-mcp** 面向植物基因组学的 MCP Server，提供 50 个工具、覆盖 23 个后端，支持 12 种作物和模式植物，并整合 Ensembl Plants、Phytozome、Gramene、Planteome、PlantCyc、AraGWAS、1001 Genomes、JASPAR 等资源。

现有 MCP Server 注册表和资源列表：

- • **BioContextAI Registry** 社区维护的生物医学 MCP Server 目录，要求收录项目具有生物医学方向、免费学术访问、OSI 批准的开源许可证以及 MCP 规范兼容性。
- • **MCPmed** 提供 GEO、STRING、UCSC Cell Browser、PLSDB 等 MCP 实现，同时提供用于将传统服务转换为 MCP 的模板和发现机制。
- • **awesome-mcp-servers** 通用 MCP Server 资源列表，其中包含 Biology、Medicine 和 Bioinformatics 分类。

MCP 相关的工具：

- • **BioinfoMCP** 一个可以根据现有工具文档自动生成 MCP Server 的转换工具，同时提供针对转换后工具的 Benchmark。

### AI 科学家和研究智能体系统

能够独立运行完整科研工作流的多 Agent 应用，例如假设生成，而不是作为其他 Agent 的组件使用。

- • **Co-Scientist** 开发者： **Kaimen Inc** 。Google DeepMind AI Co-Scientist 的独立实现，根据自然语言科研目标生成经过多轮竞争排序的研究假设，并通过 Generation、Reflection、Elo-tournament Ranking、Evolution、Proximity 和 Meta-review 六个 Agent 完成研究过程。

### 基准测试

用于评估 AI Agent 在生物信息学和科研任务中的能力。

智能体能力基准测试：

- • **BioAgent Bench** 包含 10 个端到端生物信息学流程任务，覆盖 RNA-seq、变异检测、宏基因组、单细胞和转录本定量等，并通过损坏输入、干扰参考文件和超长 Prompt 等方式测试 Agent 的鲁棒性。
- • **BioMed-AQA** 包含 327 个开放式生物医学分析任务，覆盖组学、可视化、机器学习、统计学和精准医学等领域，同时提供 172 道选择题子集。
- • **BiomniBench** 过程级评估框架：由原始作者或领域专家从高影响力论文中精选的 100 个生物医学数据分析任务；通过 LLM 裁判对照专家设计的评分标准对完整代理轨迹（推理追踪+最终答案）进行评分。
- • **BixBench** 面向基于 LLM 的 Agent 的综合 Benchmark，用于测试 Agent 探索生物数据集、执行多步骤分析以及解释分析结果的能力。
- • **CompBioBench** Genentech 开发的计算生物学 Benchmark，包含 100 个问题，覆盖单细胞、表观基因组学、基因组学、转录组学、人类遗传学和机器学习等方向。
- • **LAB-Bench** 包含 2,400 多道选择题，覆盖文献检索、图表解释、数据库访问、实验室操作流程和序列分析等 8 类生物学研究任务。

技能基准测试：

- • **SkillsBench** 用于评估 Agent Skills 是否能够提升 Agent 能力的通用 Benchmark，包含 86 个任务、11 个领域，并比较无 Skills、人工整理 Skills 和 Agent 自生成 Skills 等不同条件。

### 通用 AI 编码智能体技能集合

面向 AI Coding Agent 的通用 Skill 集合，其中的资源同样可以用于基因组学和生物信息学代码开发。

技能规范：

- • **agentskills** Agent Skills 标准的官方规范和文档，定义了 Claude Code、Copilot、Codex、Cursor 和 Gemini CLI 等平台使用的跨平台 Skill 格式。

通用技能集合：

- • **superpowers** 面向 Coding Agent 的完整软件开发方法论和 Skills 框架，强调 TDD、规范驱动开发和子 Agent 驱动开发等实践。
- • **anthropics/skills** Anthropic 官方的 Claude Agent Skills 参考实现和规范，可作为构建自定义 Skills 的基础。
- • **openai/skills** OpenAI 官方 Codex Skills Catalog，提供 system、curated 和 experimental 等 Skills，并基于跨平台 Agent Skills 开放标准构建。
- • **andrej-karpathy-skills** 基于 Andrej Karpathy 对 LLM 常见问题的观察整理而成的单文件 Coding Guidelines，强调简单性、精确修改和目标驱动执行。
- • **awesome-copilot** 社区整理的 GitHub Copilot 指令、Agent、Skills 和配置集合，其中包括可用于科学和数据分析工作的 Prompt 模板。
- • **awesome-llm-skills** 整理 LLM 和 AI Agent Skills、资源与工具，用于定制 Claude Code、Codex、Gemini CLI 以及其他 AI Agent 工作流。
