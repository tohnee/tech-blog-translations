现在有一股非常恶劣的风气，大量自称 Memory 的项目，正在给"上下文工程"这个词抹黑。

相当一部分所谓的 Memory ，其实还是在做 RAG ，在做知识图谱。

所谓的"长短期记忆"等等，根本上不了台面，是 dirty trick. 倒不是说它没用，但它实际仅仅配做 tool

RAG 始终应该只是 tool ，绝不能 hack 进 agent-loop 里面。

有种相当恶劣的做法（点名 CrewAI 的 memory），是直接在每次 llm-call 之前，强行进行一次 RAG ，把结果注入到上下文中。这种做法闻到就觉得恶臭，完全是机械式的注入，并不是 llm 来决定是否注入，而是人工提前决定。毫无技术品味，这根本不配称为上下文工程。
