《DFlash: Block Diffusion for Flash Speculative Decoding》

[https://arxiv.org/pdf/2602.06036](https://arxiv.org/pdf/2602.06036) Jian Chen UCSD

Block Diffusion: Interpolating Between Autoregressive and Diffusion Language Models

自回归 LLM 的解码是串行、memory-bound 的；EAGLE-3 一类方法仍用自回归 draft，draft 成本随猜测长度线性涨，实用加速大约为2–3倍。扩散模型能并行输出token，但独立作为生成器时质量不够，而且多步 denoise 会影响速度。DFlash 把扩散模型作为speculative decoding 里的 drafter：5 层 block diffusion 在一次前向里并行预测一个 block，同时把目标模型抽取的 hidden state 融合成 context feature，注入每一层 draft 的 K/V，而不是只在输入端融合一次。在训练对齐上，从 response 里随机抽 anchor 当 block 起点，只 mask 其余位置，块内双向、块间隔离。Qwen3-4B/8B greedy 平均加速约 4.9倍，相对 tree size 16 的 EAGLE-3 约 2.4倍。

《DSpark: Confidence-Scheduled Speculative Decoding with Semi-Autoregressive Generation》

[https://arxiv.org/pdf/2607.05147](https://arxiv.org/pdf/2607.05147) Xin Cheng DeepSeek-AI

DFlash: Block Diffusion for Flash Speculative Decoding

并行 drafter把 draft 延迟降低为近似常数，但每个位置独立预测，块内会出现多模态碰撞，后缀接受率快速下降的问题；同时把整块都送给 target 验证，在高并发时会占满本可以服务别的请求的batch。DSpark在 DFlash 式并行 backbone 后接轻量 Markov/RNN 头补块内依赖，再用置信度 × 引擎 SPS 曲线按请求裁验证长度。Qwen3-4B/8B/14B 的平均接受长度相对 Eagle3 提高 30.9% / 26.7% / 30.0%，相对同数据重训的 DFlash 提高 16.3% / 18.4% / 18.3%。线上 DeepSeek-V4-Flash/Pro（preview）相对原生产基线 MTP-1，匹配吞吐下人均 tokens/s 提高 60%–85%
