上一篇把语料洗好了，这一篇讲”怎么训”。先感受一下问题有多严肃：Llama 3 405B 的预训练跑了约 120 万步、持续数周，而大模型训练的第一性约束是 **数值稳定性** ——任何一步出现 NaN，整个 run 可能就废了。几千张卡烧了几周的算力，容错率是零。

所以这一章的两条主线是 **效率** （优化器、调度、混合精度）与 **稳定** （初始化、裁剪、溢出诊断）。内容对应《大模型：从 Transformer 到部署》第 6 章。

### 一、优化器：为什么预训练只用 AdamW

预训练几乎不纠结优化器选型——AdamW 是绝对主流。但”只用”不等于”不需要懂”，它的设计里藏着三个精巧的机关。

**机关一：自适应步长。** Adam 对每个参数维护梯度的一阶矩（均值）$m_t$ 和二阶矩（平方的均值）$v_t$ 的指数移动平均，更新时用 $m$ 定方向、$\sqrt{v}$ 逐元素缩放：

$$
\theta_{t+1} = \theta_t - \eta \, \frac{\hat{m}_t}{\sqrt{\hat{v}_t} + \epsilon}
$$

如果梯度分布稳定，$\hat{m}_t/\sqrt{\hat{v}_t}$ 的量级恰好是 $\pm 1$—— **Adam 的有效步长近似为 $\pm\eta$，与梯度量级无关** 。大模型里 embedding、归一化层、注意力权重的梯度量级差异巨大，这个性质让它们能被同一套学习率和谐地训练。

**机关二：偏差修正。** 初始 $m_0 = v_0 = 0$，早期的移动平均偏小。除以修正系数 $(1-\beta^t)$ 还原无偏估计——不加这一项，训练开头几十步的更新量会小一个数量级，模型”起步”就输在起跑线。

**机关三：$\beta_2 = 0.95$，不是默认的 0.999。** 这是 Llama、GLM-130B 等公开报告共同的选择：$\beta_2$ 越小，二阶矩越快遗忘早期的大梯度——训练后期一次梯度尖峰就不会长期”污染”步长。一个小数点的改动，防的是几百步之后的慢性病。

至于 AdamW 的”W”（解耦权重衰减）：把 L2 正则直接加进梯度，$\lambda\theta$ 会同时进入 $m_t$ 和 $v_t$，衰减项也被 $\sqrt{\hat v}$ 归一化，”所有参数同步收缩”的语义就没了。AdamW 把衰减从梯度里拿出来、直接作用于参数（等价于每步乘 $1-\eta\lambda$），衰减强度才在全模型一致。细节也要抠：归一化层的增益和所有 bias 通常不做权重衰减——它们只做缩放平移，不增加模型复杂度。

### 二、学习率调度：warmup + 余弦衰减

预训练的标准调度是一条两段曲线：前 $t_w$ 步从极小值线性升到峰值，之后按余弦平滑降到终值。两个”为什么”：

**为什么要 warmup？** 训练初期 Adam 的二阶矩还没积累（偏差修正只能部分弥补），参数也远离收敛区，大步长容易一步把参数推进坏区域。小学习率起步，让统计量先稳定。典型 warmup 占总步数的 0.2%–1%——Llama 2 用 2000 步，Llama 3 405B 用 8000 步。

**为什么不衰减到零？** 终值取峰值的 1%–10%（Llama 2 取 10%，Llama 3 405B 从 $8\times10^{-5}$ 衰减到 $8\times10^{-7}$）——衰减到零等于最后彻底停止学习。

还有一条经验趋势： **峰值学习率随模型变大而下降** （8B 用 $3\times10^{-4}$、70B 减半、405B 只用 $8\times10^{-5}$）。注意它只是同架构同数据下的趋势，换了架构或批大小必须重新扫——照抄大模型的学习率，是小模型训练翻车的常见原因。另外，大模型的批大小以 **token 数** 计（百万级 token/步），而不是样本数。

### 三、混合精度：FP16 与 BF16 的一念之差

训练提速的主力是混合精度：矩阵乘用低精度（Tensor Core 快数倍），权重主副本和优化器状态留在 FP32。但低精度格式选 FP16 还是 BF16，稳定性天差地别——差别全在 **指数位** ：

|  | FP16 | BF16 |
| --- | --- | --- |
| 指数/尾数位 | 5 / 10 | 8 / 7 |
| 最大值 | 65504 | 与 FP32 同（约 3.4\times10^{38}） |
| 最小正规数 | 约 6\times10^{-8} | 与 FP32 同量级 |
| 后果 | 梯度易下溢、激活易上溢 | 几乎不溢出，但尾数精度低 |

FP16 的动态范围窄，小梯度（$< 6\times10^{-8}$）直接下溢为 0。补救是 **loss scaling** ：把 loss 乘上缩放因子 $S$（约 $2^{16}$），链式法则让所有梯度同步放大 $S$ 倍，避开下溢区；更新前再除回去。$S$ 动态调整——出现 Inf/NaN 就跳过该步并把 $S$ 减半，长期无溢出就翻倍。

而 **BF16 的指数域与 FP32 完全相同** ，梯度几乎不可能下溢，$S=1$，整套机制直接省掉。这就是 A100/H100 时代 BF16 成为默认的原因：训练怕溢出选 BF16。它也有代价——尾数只有 7 位，所以累加、归一化、主权重仍必须 FP32。

一个容易踩的坑顺带说了：FP16 下 **必须先 unscale 再做梯度裁剪** ，否则你裁剪的是放大了 $S$ 倍的梯度，等效阈值被 $S$ 绑架、随缩放因子漂移。更前沿的是 FP8（H100 起，前向 E4M3、反向 E5M2、按矩阵块动态缩放），DeepSeek-V3 用它完成了 671B 模型的主体预训练。

### 四、loss spike：每个炼丹师的噩梦

就算以上全做对，大模型训练几乎必然遭遇 loss spike——loss 突然跳升若干点，可能自行恢复，也可能直接发散成 NaN。诊断与止血有标准套路：

1. **溢出检测** ：在注意力 logits、FFN 输出等关键位置插 `isfinite` 断言，定位首次 Inf/NaN 出现的地方；
2. **坏 batch 跳过** ：某步 loss 超过滑动平均 3 倍就跳过这步更新——spike 频发时最常用的止血手段；
3. **回滚 + 降学习率** ：持续不恢复时，回滚到 spike 前的 checkpoint、跳过之后一段数据（怀疑是坏数据）、lr 乘个小于 1 的因子再慢慢恢复；
4. **持续监控梯度范数** ——GLM-130B 的报告有条特别值钱的观察： **训练崩溃通常滞后于梯度范数尖峰若干步** 。梯度范数是预警指标，别等 loss 跳起来才动手。

同一份报告还指出 spike 多来自 **embedding 层** ：训练早期它的梯度范数能比其它层大几个数量级。他们的解法（embedding 梯度收缩）只改一行代码：$W_{\text{emb}} \leftarrow \alpha W_{\text{emb}} + (1-\alpha)\cdot\mathrm{detach}(W_{\text{emb}})$，$\alpha=0.1$——前向数值完全不变（两项相加仍是 $W_{\text{emb}}$），但反向时梯度被缩小到十分之一。预防端还有 z-loss：惩罚 softmax 归一化因子 $\log Z$，把 logits 整体幅度往零拉，PaLM 用它换来了显著更稳的训练。

### 一句话总结

预训练不崩的秘诀没有任何玄学： **AdamW + $\beta_2=0.95$、warmup 余弦调度、BF16、梯度裁剪、梯度范数预警、坏 batch 跳过** ——每一件都是针对一个具体失效模式的工程对策。把这套组合拳理解到”每个超参为什么是这个值”，你就能看懂任何一份开源模型的技术报告。
