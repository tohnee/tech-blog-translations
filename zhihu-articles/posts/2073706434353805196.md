### **AI 编译器工程师详解**

### ***2.1.1 一句话理解：“芯片架构与 AI 框架之间的翻译官”；四大分工线***

**AI 编译器工程师是”芯片架构与 AI 框架之间的翻译官”**——PyTorch 里的模型说的是”框架语言”，芯片只听得懂”机器指令”，中间的翻译工作就是他们做的。摩尔线程在校招 JD 里直接把这个岗位叫作”GPU 的首席翻译官”（来源：摩尔线程校招 JD，2024-09）。

翻译不是一步到位，而是一条流水线，对应四条分工线。你看 JD 时第一件事就是判断客户要的是哪条线的人：

| 分工线 | 人话解释 | 干什么 | 代表 JD 证据 |
| --- | --- | --- | --- |
| 图编译器（Graph Compiler） | 先翻译”整篇文章的结构” | 计算图解析与转换（对接 ONNX/PyTorch/MHLO）、算子融合、内存规划、动态 shape、图级优化 Pass | 寒武纪校招岗：“基于 MHLO 的图编译器，MLIR+Linalg 框架，图优化、算子融合、自动调优”（来源：牛客，2025-03） |
| 算子编译器 / DSL 编译器 | 再翻译”每个段落的写法” | Triton/TileLang/CuTe 等 Tile 级 DSL 的适配与定制、算子自动调优（AutoTVM/MetaSchedule/Ansor）、Kernel 代码生成 | 天数智芯”对 Triton Compiler 做适配开发”（来源：BOSS 直聘，2025-08）；燧原”Tile-based DSL 编译器后端，覆盖 GEMM、分组 GEMM、FMHA 算子”（来源：猎聘，2026-08） |
| 后端 Codegen / 传统编译器 | 最后落到”逐字逐句” | LLVM/GCC 后端、指令选择、寄存器分配、指令调度、汇编器/链接器 | 摩尔线程”前端 MUSA IR 设计、LLVM 后端开发，参与 GPU ISA 与架构设计”（来源：牛客，2024-09）；海光”GCC/LLVM 在海光平台的优化实现”（来源：猎聘，2025） |
| 分布式编译器 | 把文章拆给一群人一起抄 | 模型/数据/流水并行的自动切分、通信算子插桩、通算融合，支撑千亿级大模型训推 | 艾捷科芯”分布式编译、数据流编译、通算融合，熟悉 NCCL 优先”（来源：猎聘，2025-02）；某头部 GPU 企业”突破分布式编译、图编译、通算融合，支撑千亿级大模型”（来源：脉脉，2025-02） |

**表格解读：**四条线的技术栈和人才来源完全不同，不能混着推人。图编译和算子编译（DSL）离 AI 最近，要懂模型结构，候选人多来自 AI 框架/推理背景；后端 Codegen 是传统编译器功底（LLVM/GCC），候选人常来自体系结构科班甚至 CPU 编译器团队；分布式编译是 2024 年后大模型催生的新线，人最少、溢价最高，通常要求同时懂编译和 NCCL 类通信。同一家公司往往多条线同时在招（天数智芯就分 MLIR 和 Triton 两个方向），**接单时务必向客户问清是哪条线、用什么框架底座**，否则你搜”TVM”人家要的是”LLVM 后端”，白忙一场。

### ***2.1.2 真实 JD 拆解：寒武纪、华为昇腾、摩尔线程三例***

新人看 JD 最容易两眼一抹黑。下面把三家代表性公司的 JD 原文逐条翻译成你能执行的动作。读法固定为三步：**原文要求** **→ 人话翻译 → 对猎头意味着什么**。

**例一：寒武纪** **· C++/AI 编译器（Triton + MHLO 图编译方向，校招）**（来源：牛客，2025-03）

| JD 原文要求 | 人话翻译 | 对猎头意味着什么 |
| --- | --- | --- |
| “基于 MLIR + Linalg 框架开发 MHLO 图编译器，负责图优化、算子融合、自动调优” | 用 MLIR 这套工具搭翻译流水线，做”结构级”翻译 | 搜”MLIR”“Linalg”“MHLO/StableHLO”“算子融合”，做过后端 Codegen 的纯 LLVM 人不是首选 |
| “熟悉 CNN/Transformer/LLM 等主流模型结构与算子” | 得知道模型里有哪些计算，才知道怎么翻 | 简历里只有传统编译器项目、没有任何深度学习模型认知的，降档 |
| “ACM/OI 竞赛获奖、开源社区贡献者优先” | 竞赛和 GitHub PR 是硬通货 | 校招候选人先看这两个信号，比 GPA 更有区分度 |

**例二：华为昇腾** **· AI 编译器工程师（CANN/毕昇编译器方向，社招 5–10 年，杭州 35–65K/月）**（来源：猎聘挂牌，2025）

| JD 原文要求 | 人话翻译 | 对猎头意味着什么 |
| --- | --- | --- |
| “负责昇腾异构编程语言编译优化、图及算子编译” | 给昇腾 NPU 的自研软件栈 CANN 做编译器 | 目标池：寒武纪、海光、摩尔线程的编译器团队，以及 NVIDIA/AMD 中国编译器组 |
| “熟悉 LLVM 框架，有编译器后端开发经验” | 传统编译器功底是门槛 | 5 年以上 LLVM 后端经验是硬条件，年限不够别强推 |
| “参与 NPU 微架构和指令集协同设计” | 不只是写软件，要能对硬件提意见 | 有”软硬协同”经历（参与过 ISA/架构评审）的候选人议价能力高一档 |

**例三：摩尔线程** **· GPU 编译器工程师（MUSA IR / LLVM 后端方向，校招+社招）**（来源：牛客，2024-09；国聘，2025-01）

| JD 原文要求 | 人话翻译 | 对猎头意味着什么 |
| --- | --- | --- |
| “前端 MUSA IR 设计、LLVM 后端开发” | 给自研 MUSA 架构造一套 CUDA 式编译器 | 摩尔线程走 CUDA 兼容路线，NVIDIA CUDA 工具链背景的人可直接平移 |
| “从编译器角度参与 GPU ISA 与架构设计” | 岗位天花板高，能摸到硬件定义权 | 挖人卖点：对候选人强调”从 0 到 1 参与架构定义”，这是大厂螺丝钉岗给不了的 |
| “图形/通用计算/AI 编译器三线并行” | 一家公司三种编译器岗 | 接单时确认 HC 属于哪条线，三条线的简历信号不一样 |

把三个 JD 放在一起能看出市场共性：**硬性要求几乎家家相同**——精通 C/C++、熟练 Python、编译原理+体系结构基础、MLIR/TVM/LLVM/Triton/XLA 至少一项的实操经验（来源：8 个在招 JD 交叉验证，2025–2026）；**拉开差距的是加分项**——开源 PR、顶会论文、竞赛。下一节专门讲怎么识别。

### ***2.1.3 技能关键词树与简历识别信号***

下面这棵树按”出现频率从高到低”排列，**可以直接当 BOSS/猎聘/脉脉的搜索词用**（第 4 章会教组合搜索，这里先把词备齐）：

| 层级 | 关键词（直接可用作搜索词） | 说明 |
| --- | --- | --- |
| L1 编译框架（最高频） | MLIR、TVM、Triton、LLVM、XLA | 五个词至少中一个才称得上 AI 编译器工程师；MLIR 是 2025–2026 年 JD 最高频词 |
| L2 MLIR 细分 | Dialect、Linalg、Affine、Pass、IR、Lowering、mlir-opt、多面体优化（isl） | 简历出现这些词=真做过 MLIR，不是”了解” |
| L3 其他框架/方言 | IREE、Glow、TorchInductor、BladeDisc、TVM Relax、MHLO/StableHLO、OpenXLA、AKG | 用于扩大或收窄搜索 |
| L4 算子/DSL | CUDA、CuTe、CUTLASS、TileLang、Ascend C、MUSA、Bang C | 与算子岗交叉，双线人选靠这层词识别 |
| L5 优化技术 | 算子融合、AutoTVM、MetaSchedule、Ansor、CodeGen、指令调度、寄存器分配、内存规划、动态 shape、量化、通算融合 | 区分”用过框架”和”改过框架” |
| L6 分布式方向 | 模型并行、流水并行、NCCL、NVSHMEM、MPI、AllReduce、通信插桩、DeepEP | 分布式编译线专用，稀缺词 |
| L7 工程语言 | C++（精通）、Python、CMake、Git、Linux；Rust（黑芝麻前端岗）、汇编/PTX（加分） | C++ 是底线，看到只有 Python 的简历直接过 |

**简历识别信号（高区分度，按含金量排序）：**

**1.** **开源 PR**：TVM/MLIR/LLVM/Triton/IREE/XLA 仓库的 GitHub commit 或 PR 记录，是最硬的信号——多家 JD 明示”在开源编译器社区有影响力者优先”（来源：猎聘在招 JD，2025-03）。

**2.** **顶会论文**：PLDI、CGO、ASPLOS、MICRO（体系结构/编译四大顶会），其次 POPL、ISCA、NeurIPS/ICLR 的 MLSys 方向。一作硕博对应校招高分候选人。

**3.** **竞赛**：ACM-ICPC、OI、超算竞赛（ASC/SC/ISC）、华为 ICT 大赛获奖。

**4.** **国产芯片工具链经历**：寒武纪/壁仞/燧原/昇腾/沐曦/天数智芯的编译器或性能优化经历——上海人工智能实验室的 JD 直接点名要这类背景（来源：牛客，2025-08）。

反过来，**低信号词**也要认：简历只写”熟悉 TVM/了解编译原理”、项目是课程作业级的 toy compiler，这类候选人最多推到校招初级岗，别推社招。

### ***2.1.4 薪酬水位与人才画像***

**薪酬带宽**（全部为招聘平台**挂牌价**，税前，非成交价；统计时点 2025–2026）：

| 层级 | 年薪总包参考 | 数据点（挂牌价口径） |
| --- | --- | --- |
| 应届（校招） | 约 30–55 万 | 华为校招 18–35K·16 薪（来源：牛客，2023-07）；黑芝麻校招综合年薪 40–55 万（来源：应届生求职网，2025-09）；寒武纪校招第三方估算 22–35K/月（来源：WatchJobs AI 估算，2026-08，估算口径）；行业综述”应届 35–55 万”（来源：与非网，2026-06） |
| 3–5 年 | 约 50–100 万 | 黑芝麻 35–55K·15 薪、猎聘样本：北京 60–90K、独角兽 50–80K·16 薪、深圳 45–60K·16 薪（来源：猎聘/BOSS 挂牌，2025–2026）；行业综述”3–5 年 70–120 万”（来源：与非网，2026-06，偏乐观，取交集） |
| 5–8 年（高级/资深） | 约 80–150 万 | 壁仞 AI 编译器架构 50–80K·15 薪（来源：猎聘，2025）；燧原异构编译器 45–75K·15 薪（来源：猎聘，2024-12）；华为上海高级岗 60–65K（来源：BOSS 直聘，2025-08） |
| 8 年+ / 专家/架构师 | 100–300 万 | “AI 芯片编译器专家”北上深杭 80–110K·15 薪（来源：BOSS 直聘，2024-03）；“人工智能编译器架构师”100–160K·15 薪（来源：猎聘，2025）；另有”深圳/南京编译器专家月薪 16–18 万”的报道（来源：微信公众号，2025，单一来源，属极端值，只作谈资不作报价依据） |

**表格解读：**三个规律要记住。第一，**带宽随年限加速变宽**——应届差 25 万，专家段差 200 万，因为专家段定价看的是”有没有做过架构设计/自动调优系统/顶会论文”这类稀缺标签，而不是年限本身。第二，**城市打折明显**：成都/西安/南京/合肥报价约为一线的 70–85%（海光成都 20–40K·16 薪、飞腾长沙 16.7K×18 薪，来源：猎聘/牛客求职者实录，2025–2026），跨城挖人时谈薪预期要前置管理。第三，**别把”AI 编译器”和泛”编译器开发”混为一谈**：泛编译器岗 72% 落在 20–50K/月区间（来源：职友集，2025-05），比 AI 编译器低一档，客户给泛编译器的预算招 AI 编译器的人，大概率成不了单。

**人才画像一句话：科班 + 开源 + 竞赛。**学历上硕士是主流门槛（摩尔线程、黑芝麻、后摩校招均要求硕士起，奕斯伟部分岗点名博士，来源：各公司校招 JD，2024–2025），专业集中在计算机/软件/电子工程/数学。三类典型来源：编译原理/体系结构/PL 方向的实验室硕博（中科院计算所、清华、上交、浙大、中科大、华科密集出货——黑芝麻披露员工半数以上来自这五校，来源：黑芝麻校招材料，2025-09）；ACM/OI/超算竞赛圈；TVM/MLIR/Triton 开源社区贡献者。候选人侧供需极紧：知乎社区观点认为该方向”找工作比较好找，Triton 方向很多大厂都在做”（来源：知乎，2025-10）——这意味着你手上的候选人大概率同时拿着多个 offer，推进节奏要快。
