$\enclose{horizontalstrike}{\text{你说的对，但是 Triton 是由「Philippe Tillet」自主研发的一款开放世界冒险游戏，后面忘了，总之和它们一起击败 CUDA，找回写 kernel 的真相}}$

Triton 是当下写 kernel 的一个十分热门的选择了，它比 CUDA 的学习门槛低很多，又能获得不错的性能。最近刚好也在做 Triton 相关的工作，于是便想到顺便写一个教程（CUDA 教程下篇在路上了 咕咕咕.jpg）

其实我很久以前写过一篇[Pointer Arithmetics in Triton](https://zhuanlan.zhihu.com/p/639423790)，讲的是我认为写 Triton 中最重要的怎么做指针运算的问题，但是依然难以作为一个 Tutorial；同时官方文档里的 Tutorial 我认为有点太跳跃了，相当于是直接给了几个成品 kernel 的例子让你自己研读。

然后我找到了这么个东西：[Triton-Puzzles](https://github.com/srush/Triton-Puzzles)。这个项目通过让你做 12 道 Puzzles 来入门 Triton，你在其中会实现包括 Quantized Matmul、FlashAttention 等大模型时代中非常常见的算子，从而获取许多经验。做 Puzzles 来学东西本身就是我非常喜欢的一个方式（有点像在玩 baba is you 那种解谜游戏），粗略做完之后感觉也不错，但也发现很多人在使用它的时候遇到了一些问题。

于是，本着改进这个 Triton-Puzzles 的想法，我抽了点时间写了个它的亲民+改进版：

[GitHub - SiriusNEO/Triton-Puzzles-Lite: Puzzles for learning Triton (Lite Version). Play it with minimal environment configuration!](https://github.com/SiriusNEO/Triton-Puzzles-Lite)

Triton-Puzzles-Lite 是 Triton-Puzzles 的一个改进版本，主要改动包括：

- **大幅减少依赖，只需要最小的环境就能运行**，包括删掉了 triton-viz 的可视化部分（这里的可视化兼容性很不好，尤其对于国内用户还有一些网络的问题，同时 Issue 区里也出现了相关版本问题）以及其它无用依赖。甚至我把 Jupyter Notebook 的依赖也删了（因为我自己不太爱用 x）。现在是一个纯 Python 单文件，不过后续如果大家比较爱用 Notebook 我也可以再附一个。总之，Triton-Puzzles-Lite 现在只依赖 triton、torch、numpy 等基本包。由于 Torch2.0 自带 triton 依赖，所以理论上你只需要安装一个合适的 torch 就可以开始做题了！
- **进行了大量校对与修正，改进了很多题面描述和代码。**原来的版本在后面的某些 Puzzles 的描述与符号上都比较混乱，比如 Puzzle 9 的注意力部分。我本着尽量不改动题目原意的原则，换了更准确、更容易理解的描述。
- **提供了更丰富的 Debug 信息。**由于删掉了可视化，如果只对着输出对比，Debug 肯定是非常困难的。我通过魔改了原来的一些代码，能在终端显示出更多更丰富的信息（包括每个 block 的访存地址、访存是否合法等等），同时在 Interpreter 模式下你还能通过 print 直接 debug，可以 print 值或者 shape 等等，都非常方便。
- **提供了一份参考答案。**这是我自己做的答案，变量名尽量取得比较清晰明了，并且有一些注释可以帮助读者理解做法思路。
- **允许在 GPU 下运行。**这其实是顺便支持的 feature，也许有人要用呢？不过 GPU 模式下会失去一些 trace 信息，可能只能通过输出比对 debug 了。

### 食用方式

- 第一步，确保你有一个带 Triton 和 Torch 的 Python 环境。我们不要求你要有 GPU 运行环境，并且推荐使用 CPU（即 Triton 的 interpreter 模式）来做这一系列 Puzzles。
- 第二步，

```text
git clone https://github.com/SiriusNEO/Triton-Puzzles-Lite.git
```

- 第三步，运行一下看看有没有出问题。`TRITON_INTERPRET=1` 表示开启 Triton 的解释器模式，即在 CPU 上运行。我们推荐以这个方式运行。如果不带这个，那默认会在 GPU 上运行。现在的情况是 Puzzle 11/12 的标准答案无法通过。

```text
TRITON_INTERPRET=1 python3 puzzles_ans.py -a
```

如果全都 pass 了，说明标准答案在你的环境上可以正常通过测试。现在就开始填 [puzzles.py](http://puzzles.py/) 吧！具体的命令行参数可以通过 -h 参数来查看

```text
python3 puzzles.py -a
```

`puzzles.py`和`puzzles_ans.py`是完全一样的，只是一份是留空给用户做的，一份是参考答案。此外，`puzzles.md`是一份带图的题面，因为有一些计算示意图不好直接在代码注释里写，也可以配合查看。
