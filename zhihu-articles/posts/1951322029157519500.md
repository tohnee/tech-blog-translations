## Attention介绍

我们首先回顾attention的定义： $\begin{aligned} &\mathbf{Q} \in \mathbb{R}^{N_Q \times D};\ \mathbf{K},\mathbf{V} \in \mathbb{R}^{N_K \times D} \\ &\mathbf{S} \gets \frac{\mathbf{Q}\mathbf{K}^T}{\sqrt{D}} \in \mathbb{R}^{N_Q \times N_k} \\ &\mathbf{P}_{ij} \gets \text{softmax}(\mathbf{S}_{ij}) = \frac{\exp(\mathbf{S}_{ij} - \max_j(\mathbf{S}_{ij}))}{\sum_j \exp(\mathbf{S}_{ij} - \max_j(\mathbf{S}_{ij}))}\\ &\mathbf{O} \gets \mathbf{P}\mathbf{V} \in \mathbb{R}^{N_Q \times D} \end{aligned}$

LLM里面常用的是Causal Self-Attention，在它里面我们还需要： $\begin{aligned} &N_Q = N_K \\ &\mathbf{S}_{ij} \gets \left\{ \begin{array}{lr} \mathbf{S}_{ij}, & i \leq j, \\ -\infty, & i > j \end{array} \right. \end{aligned}$

## Flash Attention的动机

我们首先讲为什么我们要把上面的计算fuse成一个kernel，如下图所示，主要的计算发生在两个矩阵乘法里面，但中间的element-wise操作反而占了绝大多数时间。

![](https://pica.zhimg.com/v2-567426825c63b01a836d4d11f13251c8_r.jpg)

为什么会这样呢，每个attention head的hidden_dim一般比较小，在 $\mathbf{S} \gets \mathbf{Q}\mathbf{K}^T$ 和 $\mathbf{O} \gets \mathbf{P}\mathbf{V}$ 这两个矩阵乘法上都会形成**访存密集型**算子，并且主要的时间用于读或写S和P这样的 $N \times N$ 大矩阵（相比之下，Q,K,V,O这种扁的矩阵访存时间可以忽略不计），时间约等于一次global memory访问；而中间的每一个操作都要读和写一次 $N \times N$ 的大矩阵，时间约等于两次global memory访问。我们分析一下每个操作的计算和访存，如下图所示：

![](https://pic2.zhimg.com/v2-0dadb65de4e07c3261982052ea143d05_r.jpg)

如果我们把前三行操作fuse起来，我们就不需要存储attention矩阵，访存里面 $N_QN_K$ 就省去了，节省了大部分的时间。

然而我们知道softmax这一步是需要用到一整行的max和sum_exp的，所以fused attention需要先解决softmax的数据依赖问题。下面我们先介绍online softmax算法：

## Online Softmax

在[第一节课](https://zhuanlan.zhihu.com/p/1931780102540211448)里面，我们写了softmax算子，但hidden_dim不能超过16384。而对于更大的hidden_dim，就需要使用online softmax这个算法。

假设我们有一个长度等于2T大于16K的矩阵S需要算softmax，我们把它拆成两个长度为T的部分，先对他们分别做一个局部的softmax：

$\begin{aligned} \left\{ \begin{array}{l} \mathbf{P}^0_{ij} = \dfrac{\exp(\mathbf{S}^0_{ij} - \max_{0 \leq l \leq T}(\mathbf{S}^0_{il}))}{\sum_{l=0}^T \exp(\mathbf{S}^0_{ij} - \max_{0 \leq l \leq T}(\mathbf{S}^0_{il}))} := \dfrac{\exp(\mathbf{S}_{ij}^0 - M^0_i)}{L_i^0} \\ \mathbf{P}^1_{ij} = \dfrac{\exp(\mathbf{S}^1_{ij} - \max_{T \leq l \leq 2T}(\mathbf{S}^1_{il}))}{\sum_{l=T}^{2T} \exp(\mathbf{S}^1_{ij} - \max_{T \leq l \leq 2T}(\mathbf{S}^1_{il}))} := \dfrac{\exp(\mathbf{S}_{ij}^1 - M^1_i)}{L_i^1} \end{array} \right. \end{aligned}$

在这里，我们多定义了两个标量M和L，这两个标量需要全局的操作：

$\begin{aligned} &M^{[0,1]} = \max(M^0_i, M^1_i) \\ &L^{[0,1]} = \exp(M_i^0 - M_i^{[0,1]})L_i^0 + \exp(M_i^1 - M_i^{[0,1]})L_i^1 \end{aligned} $

获得了全局的M和L之后，我们再去算全局的P：

$\mathbf{P}^{[0,1]}_{ij} = \dfrac{\exp\big(\mathbf{S}^{[0,1]}_{ij} - \max_{T \leq l \leq 2T} (\mathbf{S}^{[0,1]}_{il})\big)} {\sum_{l=T}^{2T} \exp\big(\mathbf{S}^{[0,1]}_{ij} - \max_{T \leq l \leq 2T} (\mathbf{S}^{[0,1]}_{il})\big)} := \dfrac{\exp(\mathbf{S}_{ij}^{[0,1]} - M^{[0,1]}_i)} {L_i^{[0,1]}}$

如果矩阵维度更大，我们分成N/T组，先算每个局部的M和L，然后根据上面的式子算全局的M和L，最后算出全局的P。

**Online softmax的思想可以把attention的计算拆解为多个类似矩阵乘法的子问题，每个子问题之间只需要交换两个标量。**

## Forward推导

FlashAttention的Forward部分是和online softmax差不多的，我们像上面一样先假设只有两个部分。FlashAttention的计算分为三步：

- 第一步计算 $\mathbf{Q}$ 乘以 $\mathbf{K}$ 的矩阵乘法部分：

$\begin{aligned} \left\{ \begin{array}{l} \mathbf{S}^0_{ij} = D^{-\frac{1}{2}} \sum_{k=0}^D \mathbf{Q}_{ik}\,\mathbf{K}^0_{jk} \\ \mathbf{S}^1_{ij} = D^{-\frac{1}{2}} \sum_{k=0}^D \mathbf{Q}_{ik}\,\mathbf{K}^1_{jk} \end{array} \right. \end{aligned}$

- 第二步是**局部**softmax的计算，因为我们想避免存储attention矩阵，所以先不着急去计算全局的softmax。

$\begin{aligned} \left\{ \begin{array}{lr} \mathbf{P}^0_{ij} = \frac{\exp(\mathbf{S}^0_{ij} - \max_{0 \leq l \leq T}(\mathbf{S}^0_{il}))}{\sum_{l=0}^T \exp(\mathbf{S}^0_{ij} - \max_{0 \leq l \leq T}(\mathbf{S}^0_{il}))} := \frac{\exp(\mathbf{S}_{ij}^0 - M^0_i)}{L_i^0} \\ \mathbf{P}^1_{ij} = \frac{\exp(\mathbf{S}^1_{ij} - \max_{T \leq l \leq 2T}(\mathbf{S}^1_{il}))}{\sum_{l=T}^{2T} \exp(\mathbf{S}^1_{ij} - \max_{T \leq l \leq 2T}(\mathbf{S}^1_{il}))} := \frac{\exp(\mathbf{S}_{ij}^1 - M^1_i)}{L_i^1} \end{array} \right. \end{aligned}$

- 第三步是乘以output的计算。

我们首先计算局部的output $\begin{aligned} \left\{ \begin{array}{lr} \mathbf{O}^0_{ik} = \sum_{j=0}^T \mathbf{P}^0_{ij} \mathbf{V}^0_{jk} \\ \mathbf{O}^1_{ij} = \sum_{j=T}^{2T} \mathbf{P}^1_{ij} \mathbf{V}^1_{jk} \end{array} \right. \end{aligned}$

使用online softmax的技巧计算全局的output：

$\begin{aligned} \mathbf{O}^{[0,1]}_{ik} &= \sum_{j=0}^{2T} \mathbf{P}_{ij}^{[0,1]} \mathbf{V}_{jk}^{[0,1]} = \sum_{j=0}^T \mathbf{P}_{ij}^{[0,1]} \mathbf{V}_{jk}^{0} + \sum_{j=T}^{2T} \mathbf{P}_{ij}^{[0,1]} \mathbf{V}_{jk}^{1} \\ &= \frac{\exp(-M_i^0)}{\exp(-M_i^{[0,1]})} \cdot \frac{L_i^0}{L_i^{[0,1]}} \mathbf{O}^0_{ik} + \frac{\exp(-M_i^1)}{\exp(-M_i^{[0,1]})} \cdot \frac{L_i^1}{L_i^{[0,1]}} \mathbf{O}^1_{ik} \\ &= \alpha^0 \beta^0 \mathbf{O}^0_{ik} + \alpha^1 \beta^1 \mathbf{O}^1_{ik} \end{aligned}$

**Tips:** （1）在forward的时候我们把全局的M和L存下来以便backward使用;（2）加mask的操作，只要跳过被mask掉的K/V Blocks就行了。

### 外循环实现

```python
@triton.jit
def flash_attn_fwd_kernel(
    q_ptr, k_ptr, v_ptr, o_ptr, lse_ptr,
    stride_qb, stride_qh, stride_qm, stride_qd,
    stride_kb, stride_kh, stride_kn, stride_kd,
    stride_vb, stride_vh, stride_vn, stride_vd,
    stride_ob, stride_oh, stride_om, stride_od,
    stride_lb, stride_lh, stride_lm,
    sm_scale, num_tokens, num_heads, CAUSAL: tl.constexpr,
    BLOCK_SIZE_M: tl.constexpr,
    BLOCK_SIZE_N: tl.constexpr,
    BLOCK_SIZE_D: tl.constexpr, #等于head_dim
):
    start_m = tl.program_id(0) * BLOCK_SIZE_M
    off_h = tl.program_id(1) % num_heads # head index
    off_b = tl.program_id(1) // num_heads # 当前sequence在batch里面的index

    # Initialize offsets
    offs_m = start_m + tl.arange(0, BLOCK_SIZE_M)
    offs_n = tl.arange(0, BLOCK_SIZE_N)
    offs_d = tl.arange(0, BLOCK_SIZE_D)

    # 因为num_token不一定是BLOCK_SIZE_M的整数倍，最后面几行需要一个mask
    mask_m = offs_m < num_tokens

    q_ptrs = q_ptr + off_b * stride_qb + off_h * stride_qh + offs_m[:, None] * stride_qm + offs_d[None, :] * stride_qd
    k_ptrs = k_ptr + off_b * stride_kb + off_h * stride_kh + offs_n[:, None] * stride_kn + offs_d[None, :] * stride_kd
    v_ptrs = v_ptr + off_b * stride_vb + off_h * stride_vh + offs_n[:, None] * stride_vn + offs_d[None, :] * stride_vd
    o_ptrs = o_ptr + off_b * stride_ob + off_h * stride_oh + offs_m[:, None] * stride_om + offs_d[None, :] * stride_od
    lse_ptrs = lse_ptr + off_b * stride_lb + off_h * stride_lh + offs_m * stride_lm
```

## Backward推导

下面我们用链式法则进行求导。

- 对 $\mathbf{V}$ 的导数 $\[ \frac{\partial \phi}{\partial \mathbf{V}} = \mathbf{P}^T \cdot \frac{\partial \phi}{\partial \mathbf{O}} \]$

因为我们采用fused kernel，所以需要对forward的$\mathbf{S}$进行重算。

- 对 $\mathbf{S}$ 每一块的求导

$\begin{aligned} &\frac{\partial \phi}{\partial \mathbf{S}_i} = \frac{\partial \phi}{\partial \mathbf{P}_i} \bigl(\operatorname{diag}(\mathbf{P}_i) - \mathbf{P}_i^\mathsf{T}\mathbf{P}_i \bigr) = \frac{\partial \phi}{\partial \mathbf{P}_i} \circ \mathbf{P}_i - \Bigl(\frac{\partial \phi}{\partial \mathbf{P}_i} \cdot \mathbf{P}_i^\mathsf{T}\Bigr)\mathbf{P}_i \\[6pt] &\frac{\partial \phi}{\partial \mathbf{P}_i} \cdot \mathbf{P}_i^\mathsf{T} = \Bigl(\frac{\partial \phi}{\partial \mathbf{O}_i} \cdot \mathbf{V}^\mathsf{T}\Bigr) \cdot \mathbf{P}_i^\mathsf{T} = \frac{\partial \phi}{\partial \mathbf{O}_i} \cdot \mathbf{O}_i := \Delta_i \end{aligned}$

- 对 $\mathbf{Q}$ 和 $\mathbf{K}$ 的求导 $\[ \frac{\partial \phi}{\partial \mathbf{Q}} = \frac{\partial \phi}{\partial \mathbf{P}} \mathbf{K}, \qquad \frac{\partial \phi}{\partial \mathbf{K}} = \Bigl(\frac{\partial \phi}{\partial \mathbf{S}}\Bigr)^\mathsf{T} \mathbf{Q}. \]$

## Backward实现

我们竖着切分，这样对于dV和dK可以直接累加，而对于dQ，我们需要使用atomic_add进行threadblock之间的同步。这里有5个矩阵乘法；有几次读写呢？ $K_j$ 是一列共用的，Q是一次，dQ是float32相当于两次写，dO也是一次读，有4次读写。所以backward是compute bounded kernel。

### 预处理部分

我们先预处理得到$\Delta_i$，这部分不用写triton kernel，我们直接用torch.complile就行~

```python
@torch.compile
def flash_attn_bwd_calc_delta(
    o: torch.Tensor,   # [batch_size, num_tokens, num_heads, head_dim]
    do: torch.Tensor,  # [batch_size, num_tokens, num_heads, head_dim]
):
    return torch.sum((o * do).swapaxes(1, 2), dim=-1, dtype=torch.float32)
```

```python
    mask_n = offs_n < num_tokens
    q_ptrs = q_ptr + off_b * stride_qb + off_h * stride_qh + offs_m[:, None] * stride_qm + offs_d[None, :] * stride_qd
    k_ptrs = k_ptr + off_b * stride_kb + off_h * stride_kh + offs_n[:, None] * stride_kn + offs_d[None, :] * stride_kd
    v_ptrs = v_ptr + off_b * stride_vb + off_h * stride_vh + offs_n[:, None] * stride_vn + offs_d[None, :] * stride_vd
    
    #dq是反过来写得，不是M*D是D*M，为了减少总体的转置次数
    dq_ptrs = dq_ptr + off_b * stride_qb + off_h * stride_qh + offs_m[None, :] * stride_qm + offs_d[:, None] * stride_qd
    
    dk_ptrs = dk_ptr + off_b * stride_kb + off_h * stride_kh + offs_n[:, None] * stride_kn + offs_d[None, :] * stride_kd
    dv_ptrs = dv_ptr + off_b * stride_vb + off_h * stride_vh + offs_n[:, None] * stride_vn + offs_d[None, :] * stride_vd
    do_ptrs = do_ptr + off_b * stride_ob + off_h * stride_oh + offs_m[:, None] * stride_om + offs_d[None, :] * stride_od
    lse_ptrs = lse_ptr + off_b * stride_lb + off_h * stride_lh + offs_m * stride_lm
    delta_ptrs = delta_ptr + off_b * stride_db + off_h * stride_dh + offs_m * stride_dm
```

下面是主体部分，如果从上往下分的话分为三块，如果从下往上分的话和forward一样分成两块，但是注意到读写的起点必须是整的，所以只能从上往下分。第一个Block要处理causal，第二个到倒数第二个block是没有mask的，最后一个block要处理越界。

```python
# Initialize dK and dV
dk = tl.zeros([BLOCK_SIZE_N, BLOCK_SIZE_D], dtype=tl.float32)
dv = tl.zeros([BLOCK_SIZE_N, BLOCK_SIZE_D], dtype=tl.float32)

# Load K and V
k = tl.load(k_ptrs, mask=mask_n[:, None], other=0.0)
v = tl.load(v_ptrs, mask=mask_n[:, None], other=0.0)
k = (k * (sm_scale * 1.4426950408889634)).to(k_ptr.type.element_ty)

# Split the main loop into 3 parts
if CAUSAL:
    causal_start = start_n // BLOCK_SIZE_M * BLOCK_SIZE_M
    causal_end = tl.minimum(causal_start + tl.maximum(BLOCK_SIZE_M, BLOCK_SIZE_N), num_tokens)
    full_start = causal_end
    full_end = num_tokens // BLOCK_SIZE_M * BLOCK_SIZE_M
    mask_start = tl.maximum(full_end, causal_end)
    mask_end = num_tokens
else:
    causal_start, causal_end = 0, 0
    full_start, full_end = 0, num_tokens // BLOCK_SIZE_M * BLOCK_SIZE_M
    mask_start, mask_end = full_end, num_tokens

# Main loop part 3: mask last rows that exceed the sequence length
dk, dv = _attn_bwd_loop(
    k, v, dk, dv, dq_ptrs, q_ptrs, do_ptrs, lse_ptrs, delta_ptrs,
    offs_m, offs_n, stride_qm, stride_om, stride_lm, stride_dm,
    mask_start, mask_end, BLOCK_SIZE_M=BLOCK_SIZE_M,
    CAUSAL=False, MASK_M=True, SKIP_DQ=SKIP_DQ,
)
# Main loop part 2: no mask
dk, dv = _attn_bwd_loop(
    k, v, dk, dv, dq_ptrs, q_ptrs, do_ptrs, lse_ptrs, delta_ptrs,
    offs_m, offs_n, stride_qm, stride_om, stride_lm, stride_dm,
    full_start, full_end, BLOCK_SIZE_M=BLOCK_SIZE_M,
    CAUSAL=False, MASK_M=False, SKIP_DQ=SKIP_DQ,
)
# Main loop part 1: causal mask
dk, dv = _attn_bwd_loop(
    k, v, dk, dv, dq_ptrs, q_ptrs, do_ptrs, lse_ptrs, delta_ptrs,
    offs_m, offs_n, stride_qm, stride_om, stride_lm, stride_dm,
    causal_start, causal_end, BLOCK_SIZE_M=BLOCK_SIZE_M,
    CAUSAL=True, MASK_M=True, SKIP_DQ=SKIP_DQ,
)

# Write back dK and dV
tl.store(dk_ptrs, (dk * sm_scale).to(dk_ptr.type.element_ty), mask=mask_n[:, None])
tl.store(dv_ptrs, dv.to(dv_ptr.type.element_ty), mask=mask_n[:, None])
```

### 内循环部分

因为代码比较长，我们这里仍然只给出实现思路，具体见[Github这一段](https://github.com/Starmys/TritonStudyGroup/blob/main/6_Triton_Flash_Attn/triton_flash_attn.py#126)，这里有两个个trick，一个是反过来遍历可以更好利用二级缓存，第二个是减少转置次数。

```python
@triton.jit
def _attn_bwd_loop(
    k, v, dk, dv, dq_ptrs, q_ptrs, do_ptrs, lse_ptrs, delta_ptrs,
    offs_m, offs_n, stride_qm, stride_om, stride_lm, stride_dm,
    start, end, BLOCK_SIZE_M: tl.constexpr,
    CAUSAL: tl.constexpr, MASK_M: tl.constexpr, SKIP_DQ: tl.constexpr,
):
    # Reverse loop to maximize L2 cache hit rate when causal
    for start_m in range(tl.cdiv(end, BLOCK_SIZE_M) * BLOCK_SIZE_M - BLOCK_SIZE_M, start - BLOCK_SIZE_M, -BLOCK_SIZE_M):

        # Load Q, dO, LSE (= M + log(L)), Δ (= sum(dO * O)), with mask
        ...

        # Calc P <- exp(Q @ K^T - M) / L
        # 因为下面用到P的转置比较多，所以这里计算P的转置
        pT = tl.math.exp2(tl.dot(k, q.T) - lse[None, :])
        ...
    
        # Update dV <- dV + P^T @ dO
        dv += tl.dot(pT.to(do.type.element_ty), do)
        ...

        # Calc dS <- P * (dO @ V^T - Δ)
        # 我们同时把s也转置，减少转置次数
        dsT = (pT * (tl.dot(v, do.T) - delta[None, :])).to(q.type.element_ty)
        ...
        
         # Update dQ <- dQ + dS @ K by atomic_add
         # 这里也回答了为什么dq要转置的问题
         dqT = tl.dot(k.T, dsT.to(k.type.element_ty)) * 0.6931471824645996
         tl.atomic_add(dq_ptrs + start_m * stride_om, dqT, sem='relaxed')
        
        # Update dK <- dK + dS^T @ Q
        ...

    return dk, dv
```

## Backward的优化——绕过Atomic_Add

我们测试一下，发现比官方的flash attention的backward慢了80%-100%。下面我们来看怎么优化它。大概原因呢，是triton在有很多复杂（转置不转置）的操作的时候不能编译出一个很好计算流出来，同时triton的atomic add一直不是最优的。

既然atomic add不好，我们就不用它。我们launch一个新的kernel，横着遍历，这样就不需要用atomic add了。但这里又需要重新计算P和dS，多出来两次矩阵乘法。
