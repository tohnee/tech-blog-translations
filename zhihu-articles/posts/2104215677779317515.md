参考来自于sglang的user guide[LoRA Serving - SGLang Documentation](https://docs.sglang.io/docs/advanced_features/lora#lora-serving)。这个面向需要部署lora推理服务、调用接口的开发者，帮助user理解相关配置的作用与限制。我这边手上有一个用sglang做lora推理的项目（lora已经训练好），这边顺便学习一下相关知识。

先说一下流程吧：

1. 加载base model并启动服务
2. 启动时注册lora，这边加载的参数是”lora_name""lora_path""pinned"，其中pinned表示让adapter加载后常驻gpu
3. 配置lora的容量与计算方式（见下表）
4. 服务启动后，发起请求时选择对应的lora

| 配置 | 当前值 | 作用 |
| --- | --- | --- |
| LoRA 后端 | csgmv | 执行 LoRA 增量计算 |
| 最大 rank | 8 | 设置支持的 rank 上限 |
| 目标模块 | all | 为支持的全部目标模块准备 LoRA 能力 |
| GPU 槽位容量 | 2 | 限制可同时容纳的适配器 ID 种类 |
| CPU 加载上限 | 2 | 限制 CPU 中加载的适配器数量 |
| LoRA chunk 上限 | 16 | 控制 CSGMV 分块 |
| overlap loading | 开启 | 允许权重传输与已有计算重叠 |

## lora后端

lora是比较通用的一种算法了（现在业务后训练会用这种多一点还是全参多一点？我有点好奇）

lora后端负责执行lora分支的增量计算。backend端负责把它的 A、B 权重用到模型计算中。sglang源码中注册表里包含的实现包括：

| 后端 | 计算方式与用途 |
| --- | --- |
| triton | 用 Triton 编写的 LoRA kernel，支持按请求元数据选择权重 |
| csgmv | 按适配器聚集 token，再分块执行 LoRA 计算，面向多适配器批处理 |
| torch_native | 使用 PyTorch 原生算子实现 LoRA 计算 |
| ascend | 使用昇腾 NPU 的专用算子 |
| flashinfer | 该分支已弃用，选择后会报错并提示改用 triton |

下面我们 讲讲csgmv（**Chunked Segmented Gather Matrix Vector**）是怎么做的。

考虑一批有三个请求，有两个选择lora x，一个选择lora y。可以使用multi lora来处理。

对使用第 i 个适配器的输入 x，计算可以写成： $ y=xW_0^T+s_i(xA_i^T)B_i^T $ ，csgmv优化的就是后面的lora增量计算，把相同的adapter的请求整理到一起，生成 `permutation` 索引（即每个token对应的adapter映射，并把相同adapter的token放在一起），让 kernel 能按这个顺序访问 token，

```text
原始顺序：X 的 20 个 token | Y 的 6 个 token | X 的 20 个 token
计算分组：X 的 40 个 token | Y 的 6 个 token
```

每个adapter的token组切成chunk，假设设定的chunksize是16

```text
X：16 + 16 + 8
Y：6

共四个 chunk，每个 chunk 只使用一个适配器。
```

执行两阶段计算，kernel 根据每块的 slot （GPU 上存放一套 LoRA 权重的位置）索引选择权重，可以在一次批量计算中处理多个适配器，减少逐请求调用小算子的开销。

```text
Shrink：输入 × LoRA A → 低 rank 中间结果
Expand：中间结果 × LoRA B → 输出维度的增量
```

另外还有一种triton backend嘛，这个就是比较朴素的lora计算，使用triton来写kernel按部就班地做lora，csgmv就像上面说的那样，会做一些aggregation。

## lora overlap

**就是让“下一套 LoRA 权重从 CPU 搬到 GPU”与“GPU 上已有请求的推理计算”同时进行。** 通过 `--enable-lora-overlap-loading` 开启。

```text
同步加载：
[计算 A] → [搬运 B] → [计算 B]

重叠加载：
计算流：[计算 A────────] → [计算 B]
加载流：[搬运 B──]
```

通算融合也算现在hpc里面比较通用的优化方法了，官网说这样可以减少35%的ttft
