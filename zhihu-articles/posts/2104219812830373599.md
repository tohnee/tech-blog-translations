## 一、信息查找的类型

信息查找有三种类型：

![](https://pic1.zhimg.com/v2-516d105f87eed0368518ff6eadc16818_r.jpg)

1. 预训练知识：模型本身就会，不用联网，快，适合基础常识；

2. 网页搜索：联网查少量资料，适合实时、本地信息；

3. 深度研究：批量查阅大量资料、整合推导，耗时久，适合复杂课题。

## 二、提示词工程-老手与新手的区别

提示词工程的目的是输入一个困难问题ai也有回答

### 1. 询问困难问题

如对比后进行决策、期待ai进行新的知识点的关联，并分析取舍

![](https://pic2.zhimg.com/v2-c702f0c901c398aeb78232223816fcfd_r.jpg)

Ai要对你足够了解，才能输出满足你需求和审美的答案

我们可以从中看到要足够具体详细，而不是泛泛而谈要让ai解决一个问题。

### 2. 提供正确文本

Ai需要提供完整文本以完成你想完成的任务，而完成任务所需文本则需要一些范式（公式）

![](https://pica.zhimg.com/v2-ec9439d3bf36baa06e998f0e9274ed1e_r.jpg)

### 3. 获得真实反馈

因为ai公司目的是为了让顾客留在页面，从而训练时有意的让顾客得到偏见的答案，而顾客需要获得真实的反馈

![](https://pica.zhimg.com/v2-36dc8377279f2a5c21c27fac43d06e20_r.jpg)

- 提供中性问题，如果提供偏见的问题或者是一个宏观的太大的问题，会一头雾水
- 提供评分标准进行评分
- 可以用于如何改进业务

### 4. 写作指令的区别

![](https://pic4.zhimg.com/v2-1da456ac0b4c85ef2078e92b1d03aaaf_r.jpg)

新手：让ai直接代写内容，而不是给出具体的需求

老手：不让ai直接写作，先列出提纲，构建内容，再生成稿件，反馈喜欢的和不喜欢的部分然后不断反馈修改，直至生成完整内容。

### 5. Ai犯的错误

![](https://picx.zhimg.com/v2-d609f29477f09b9f2c41adb3fe631733_r.jpg)

Ai更擅长那些具体数据的事情，对于生活中需要自主决策，对不同人有不同选择的事情，常常会给出错误。

因此要基于数据和常识，而不是强调倾向性和主观选择。

### 6. Ai的益处

![](https://pic2.zhimg.com/v2-b5117255faa2846252e203d619434c15_r.jpg)

省时省力，创造新东西，获得新技能

## 六、深度研究-ai对网页信息的处理

选择出最佳答案需要对比，我们可以输入要求，除非答案有明显差距，否则我们可以让其开始输出

![](https://pica.zhimg.com/v2-5aef6d0445c776beed029071c106cd36_r.jpg)

### 1.Ai agent

![](https://picx.zhimg.com/v2-fc21a37ca55ef534ee28c7f5e6ede089_r.jpg)

也可以用gemini制作网页等内容

一句话：**AI Agent = 以大模型为大脑，能自己规划、自主调用工具（网页搜索、深度研究等）、循环反思，把一个复杂目标一步步做完的 AI**。<br>普通 ChatGPT 是**你问一句，它答一句（被动回复）**；Agent 是**你给一个目标，它自己拆任务、自己动手、自己校验，直到交付结果**。

✅ 核心 4 个组件

1. **LLM 大脑**：负责推理、思考、判断（就是你平时用的大模型）
2. **规划**：把大目标拆成多个子步骤（比如 “研究每日步数对健康的影响”→先搜论文、再读文献、再汇总对比）
3. **工具调用（重点！对应你图里三种信息查找）**

- 预训练知识：直接用模型内置知识
- Web search：调用网页搜索
- Deep research：批量检索几十篇资料、精读、综合<br>还可以调用代码、表格、邮件等外部能力<br>
- **记忆 + 反思**：记住前面做了什么；做完一步看结果好不好，不行就调整方案，循环迭代

🆚 和普通大模型的对比

- 普通大模型：**回答问题**，单次输出，不会主动去搜、不会自己拆流程，每一步都要你指挥
- AI Agent：**完成任务**，自主决定什么时候去搜索、搜多少次、读多少资料，自动走完多步流程（就是你图里的深度研究，就是典型 Agent 能力）

📌 例子（对应你刚才的图）

你直接说：**帮我研究每日步数对长期健康的影响，整理一份综述**

- 普通大模型：凭内部知识直接写，容易过时、缺少文献
- Agent：

1. 规划：我需要找多篇权威研究
2. 调用深度研究工具，批量检索论文
3. 读取、提炼、对比
4. 发现信息不足，继续补充搜索
5. 最后整合输出完整报告

> 吴恩达的观点：Agent 不是一个 “有 / 无” 的开关，是**自主性的光谱**：简单调用一次搜索的也算轻量 Agent；能自主反复研究、反思调整的是复杂 Agent。

### 2.Ai对网页信息的处理流程

如下：总而言之：搜集信息，评估可靠性，充足可靠性则进行总结与思考，起草文件，加上引用，输出文件。

![](https://pica.zhimg.com/v2-a5ad93d415f00f15f42d46f996c67cae_r.jpg)

网络搜索和深度研究的不同在于：一个用ai从网络上面爬取答案，但是另一个得到答案后要进行处理和总结。

### 3.何时使用二者

![](https://pica.zhimg.com/v2-364cd0d7cd84f014ed9574bb77f8f1dc_r.jpg)

网页搜索适合单点、简单、即时信息查询，轻量快速；深度研究是多子问题的复杂综合调研，需要阅读大量材料，通常由用户主动开启。

| 对比项 | Web search 网页搜索 | Deep research 深度研究 |
| --- | --- | --- |
| 示例 | 找附近高分健身房、迪拜本周天气 | 每日步数对长期健康的影响；天气如何影响迪拜旅游业 |
| 待解决问题 | 单个问题 | 多个子问题 |
| 人完成耗时 | 几秒 | 数分钟～数小时 |
| 参考资料数量 | 少量 | 几十到上百份 |
| 触发方式 | 可自动触发，也可手动开启 | 一般需要用户手动发起 |
