## DP

数据并行，模型每个副本都是全量的参数，主要实现有Torch-DDP、Deepspeed Zero、FSDP

### Torch-DDP

![](https://pic2.zhimg.com/v2-7d2cebac7e6f0565b49e51c29356e5e1_r.jpg)

内存效率低

![](https://pica.zhimg.com/v2-1568e61ab83287a1b7b6b57d613961ba_r.jpg)

### Deepspeed Zero

Paper：[ZeRO: Memory Optimizations Toward Training Trillion Parameter Models](https://arxiv.org/abs/1910.02054v3)

![](https://pic2.zhimg.com/v2-f97a9d747cbd59bde231c42d7fb2d985_r.jpg)

利用多卡对参数、梯度、优化器状态进行分片，但在计算时还是要gather到一起，属于数据并行的一种，优化显存占用

### FSDP

![](https://pic3.zhimg.com/v2-a4f2465d73563bb8738254039363b258_r.jpg)

FSDP就是Torch对Zero的实现，在需要计算时gather所有参数，计算完再释放掉

## TP

模型参数并行，主要实现基本都是参照Megatron-LM tensor并行演化而来的

### Megatron-LM

Megatron第一篇论文

Paper：[Megatron-LM: Training Multi-Billion Parameter Language Models Using Model Parallelism](https://arxiv.org/abs/1909.08053)

![](https://picx.zhimg.com/v2-4fe85316c12ced1835669d33107ccafd_r.jpg)

对MLP先做了列切，然后又做了行切，只需要一次all-reduce

对MHA每一个head都是完整的计算，天然具备切分性质，按照head维度进行切分，算完之后再gather

## PP

模型流水线并行，将模型按照stage横向切分，不同stage划分到不同显卡上，核心问题是解决划分stage之后的bubble空泡，主要方法有Micro Batch、1F1B、Interleaved 1F1B等

### Micro Batch

Paper：[GPipe: Efficient Training of Giant Neural Networks using Pipeline Parallelism](https://arxiv.org/abs/1811.06965)

![](https://pica.zhimg.com/v2-448d46ad8158eb0a0f68d7691b4e5552_r.jpg)

将batch进一步拆分成micro-batch进行流水，主要涉及p2p通信

### 1F1B

Paper：[PipeDream: Fast and Efficient Pipeline Parallel DNN Training](https://arxiv.org/abs/1806.03377)

![](https://pic1.zhimg.com/v2-05b75f8cac92e33415d1bf06b04551b2_r.jpg)

前向和反向交叉进行

### Interleaved 1F1B

Megatron第二篇论文

Paper：[Efficient Large-Scale Language Model Training on GPU Clusters Using Megatron-LM](https://arxiv.org/abs/2104.04473)

![](https://picx.zhimg.com/v2-3846b44f8fb53a4df151c1e6772313d9_r.jpg)

Interleaved-1F1B 是对 1F1B 的改进，通过更灵活的调整不同 Micro Batch 的 Forward 和 Backend 的顺序，可以进一步减少 Bubble，调度也更加复杂

## SP

主要针对Attention计算时序列维度过长导致计算和activation显存都需要非常大的问题，核心思路是对序列维度进行切分，主要方案有：Megatron TP-SP、Deepspeed Ulysses、Ring Attention

### Megatron TP-SP

Megatron第三篇论文

Paper：[Reducing Activation Recomputation in Large Transformer Models](https://arxiv.org/abs/2205.05198)

![](https://pic3.zhimg.com/v2-8489929f672fe4b494ed270a16a8bf52_r.jpg)

在Megatron TP基础上发展而来，主要是对LayerNorm和Dropout做了序列切分，进一步降低由这两个计算带来的Activation显存，实际Attention计算前还需要进行all-gather得到全部序列

### Deepspeed Ulysses

Paper：[DeepSpeed Ulysses: System Optimizations for Enabling Training of Extreme Long Sequence Transformer Models](https://arxiv.org/abs/2309.14509)

![](https://pica.zhimg.com/v2-1a6859400df77dd48d5b93bccb5111ac_r.jpg)

主要是围绕MHA每一个head都是完整计算的特性进行设计，巧妙的通过alltoall通信将s维度的切分转换为head维度的切分，需要在attention计算前后插入两次alltoall通信，且head_num必须要能被并行维度整除

### Ring Attention

Paper：[Ring Attention with Blockwise Transformers for Near-Infinite Context](https://arxiv.org/abs/2310.01889)

![](https://pica.zhimg.com/v2-7a01ef80b7f524062ce749a2dce661ae_r.jpg)

可以理解为Flash Attention的分布式版本，KV分块进行计算，将通信隐藏在计算里面

### Megatron-CP

![](https://pic3.zhimg.com/v2-a5321b802a065dc9c2b3b8da38cb55e6_r.jpg)

收了Ring Attention，在Megatron TP-SP的基础上，对Attention的计算进一步做切分，GPU0和GPU2组成一个CP组，互相交换KV
