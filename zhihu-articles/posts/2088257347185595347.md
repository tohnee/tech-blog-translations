            image (原图像素坐标)
              │ letterbox 1280x1280              letterbox 1024x1024
              ▼                                        ▼
   ┌────────────────────────┐            ┌──────────────────────────┐
   │ vision.engine          │            │ aux_vision.engine        │
   │ Qwen3.5 ViT 27L + merge│            │ C-RADIOv4 so400m (4层)   │
   │ (bf16, 固定分辨率)      │            │ (bf16, 固定分辨率)        │
   └───────┬────────────────┘            └────────────┬─────────────┘
           │ image_embeds (1600,4096)                 │ 4x (1,1152,64,64)
           │ vt_feat_map (1,4096,40,40)               │
           │            boxes(vt坐标) / boxes(aux坐标)
           │                 ▼                        ▼
           │        ┌──────────────────────────────────────┐
           │        │ hfre.engine                           │
           │        │ SimpleFPN + RoIAlign + sine pos       │
           │        │ + mm_projector_aux (mlp2x_gelu)      │
           │        └──────────────┬───────────────────────┘
           │                       │ object_embeds (100,4096)
           ▼                       ▼
   ┌────────────────────────────────────────────────────────────┐
   │ llm_chunk.engine (K=256 定长续推)   llm_decode.engine (K=1) │
   │  Qwen3.5 hybrid LLM：embed+scatter → 24 GDN + 8 full attn   │
   │  → lm_head(最后位置)                                        │
   │  外置状态：KV cache (8 层) + conv_state/recurrent_state (24 层)│
   └──────────────────────────┬─────────────────────────────────┘
                              │ host AR loop (generate.py)
                              ▼
                  <ground>..</ground><objects><objN>..</objects>
                              │ parse.py (排序索引 remap)
                              ▼
                    boxes（原图像素坐标）+ labels
