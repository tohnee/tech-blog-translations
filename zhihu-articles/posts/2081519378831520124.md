本次招聘面向社招， 2027 届应届毕业生，同时开放实习生岗位。

**岗位介绍:**

大模型推理模型优化方向主要研究如何通过模型、算法、数值表示与推理系统的联合设计，持续提升 TensorRT-LLM、vLLM，SGLang 等大模型推理框架在 NVIDIA GPU 上的性能、显存效率和部署能力。

我们关注的不只是单个算子的加速，而是从模型结构、低精度数值格式、Attention 与状态管理机制出发，结合 GPU 硬件特性和实际推理工作负载，在尽可能保持模型精度和能力的前提下，优化推理吞吐、首 Token 延迟、单 Token 延迟、长上下文扩展能力以及整体部署成本。

**具体方向包括但不限于：**

- 权重、激活、Attention Operand、KV Cache 的低比特量化；
- FP8、NVFP4、MXFP4以及其他更低比特格式的量化方法、数值分析和混合精度策略分析；
- KV Cache 压缩、稀疏化、分层存储和跨请求复用；
- MHA、GQA、MQA、MLA、SWA、Sparse Attention、Linear Attention、SSM 等架构的推理优化
- Speculative Decoding、状态复用、计算复用等模型系统联合优化；
- Long context和Agentic workload推理场景下的性能建模与优化；
- 面向新模型架构和新一代 GPU 的软硬件协同设计。

**任职要求:**

- 计算机、电子工程、应用数学或相关专业硕士及以上学历，或具有同等工程与研究经验；
- 熟悉 Transformer、大模型推理流程以及 Attention、MoE、KV Cache 等核心模块；
- 熟悉至少一种大模型推理框架，例如 TensorRT-LLM、vLLM、SGLang 或其他相关推理框架；
- 熟练使用 Python 和 PyTorch，具备良好的实验设计、数据分析与问题定位能力；
- 熟悉 C++、CUDA、Triton 或其他 GPU 编程技术中的至少一种；
- 理解 GPU 体系结构、显存层次、Tensor Core、并行计算和性能分析的基本原理；
- 对低精度计算有较深入理解，熟悉量化误差、scale、rounding、clipping、group/block quantization 和 mixed precision 等概念；
- 能够从模型精度、算子性能和端到端推理表现三个层面评价一个优化方案；
- 具备良好的技术沟通、文档写作和跨团队协作能力。
