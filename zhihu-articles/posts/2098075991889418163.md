MCP Server已经成为AI引用的一个重要功能。目前，我们有很多的AI Clients。同时，为了支持多种编程语言来实现MCP Server，提供了很多SDK。本文对MCP Server在AI Clients和编程语言SDK的支持情况进行记录。同时，我们使用Java和Python语言来实现MCP Server并使用这些MCP Server。

## Program Language

下面是不同编程语言创建MCP Server的SDK支持情况和综合性能对比。总结如下：

- 有AI/ML需求(调用模型、向量库、数据分析)，首选python (FastMCP);
- 需要快速开发原型，使用TypeScript(Anthropic官方首推，SDK最完整)；
- 需要部署到企业内网且已有Java技术栈，使用Java (Spring AI MCP，企业级特性开箱即用，包括监控，安全和配置中心)；
- 追求极致性能，使用Rust或Go；

## MCP Knowledge

### MCP Transport

MCP transports支持3种：stdio, http sse, streamable http。

- **Stdio**

1. Communicates over stdin/stdout
2. Server runs as a subprocess launched by the MCP host
3. Simplest, no networking needed
4. Best for local tools (Claude Desktop, IDE extensions)

- **SSE (Server-Sent Events)**

1. HTTP server with two endpoints: POST /messages (client→server) + GET /sse (server→client stream)
2. Stateful — each client gets a persistent SSE connection
3. **Deprecated in MCP spec as of 2025-03-26**(still supported, but not recommended for new projects)

- **Streamable HTTP**

1. Single endpoint (POST /mcp) handles everything
2. Server can respond with either plain JSON (for simple request/response) or an SSE stream (for long-running/streaming operations) — same endpoint, decided per-request
3. Supports both stateful (session ID in header) and stateless modes
4. Replaces SSE as the recommended HTTP transport per the current MCP spec

HTTP通信通常是client与server建立connection，client发送request到server，server返回response到client，关闭connection。MCP需要双向通信，client发送request，server返回response，response可以立即返回，也可以返回events stream。

**SSE两个endpoints作用**

为了解决双向通信，SSE使用两个独立的channels，使用不同的HTTP机制。

- Client通过“GET /sse”打开长链接，SSE协议允许server能够在任何时间向client发送text events(server->client channel)；
- Client通过标准的HTTP请求“POST /message”发送request到server(client->server channel)。

![](https://picx.zhimg.com/v2-dcdaae1a4d3a1937c3cbfe53cf28eae7_r.jpg)

SSE协议的问题：

- Server对每个client必须维护一个长链接；
- Client关闭连接并重新连接后，session丢失；
- Proxy和load balancer经常杀死长链接；
- 它是有状态的且很脆弱；

**Streamable HTTP**

Streamable HTTP不维护长链接，而是让response自己决定是否stream，使用标准的HTTP POST request，server针对每个request基于操作的需要决定返回JSON或者SSE stream。Session state通过header(Mcp-Session-Id)来处理，这样server就能够不通过长链接来关联这些requests。

**Complex Use Case**

我们上面的tools的input/output都比较简单。我们测试一个拥有稍微复杂input/output的tools。

<u>MathTools.java</u>

```java
package com.aiexplorer.mcp.tools;

import com.aiexplorer.mcp.model.CalculationRequest;
import com.aiexplorer.mcp.model.CalculationResult;
import java.math.BigDecimal;
import java.math.RoundingMode;
import java.util.List;
import org.springframework.ai.tool.annotation.Tool;
import org.springframework.ai.tool.annotation.ToolParam;
import org.springframework.stereotype.Service;

@Service
public class MathTools {

  @Tool(
      description =
          "Perform an arithmetic calculation (ADD/SUBTRACT/MULTIPLY/DIVIDE) on an ordered list of numbers")
  public CalculationResult calculate(
      @ToolParam(description = "The calculation request") CalculationRequest request) {

    List<Double> nums = request.operands();
    if (nums == null || nums.isEmpty()) {
      throw new IllegalArgumentException("operands must not be empty");
    }

    int precision = request.precision() != null ? request.precision() : 2;

    double raw =
        switch (request.operation()) {
          case ADD -> nums.stream().mapToDouble(Double::doubleValue).sum();
          case SUBTRACT ->
              nums.stream().mapToDouble(Double::doubleValue).reduce((a, b) -> a - b).orElseThrow();
          case MULTIPLY ->
              nums.stream().mapToDouble(Double::doubleValue).reduce(1.0, (a, b) -> a * b);
          case DIVIDE -> {
            if (nums.stream().skip(1).anyMatch(n -> n == 0)) {
              throw new IllegalArgumentException("Division by zero is not allowed");
            }
            yield nums.stream()
                .mapToDouble(Double::doubleValue)
                .reduce((a, b) -> a / b)
                .orElseThrow();
          }
        };

    double result = BigDecimal.valueOf(raw).setScale(precision, RoundingMode.HALF_UP).doubleValue();

    String summary =
        "%s of %s = %s (precision: %d dp)".formatted(request.operation(), nums, result, precision);

    return new CalculationResult(result, summary, precision);
  }
}

```

这个tool中接收CalculationRequest并返回CalculationResult，定义如下。

```java
package com.aiexplorer.mcp.model;

import com.fasterxml.jackson.annotation.JsonClassDescription;

@JsonClassDescription("Supported arithmetic operations")
public enum Operation {
  ADD,
  SUBTRACT,
  MULTIPLY,
  DIVIDE
}

package com.aiexplorer.mcp.model;

import com.fasterxml.jackson.annotation.JsonClassDescription;
import com.fasterxml.jackson.annotation.JsonProperty;
import com.fasterxml.jackson.annotation.JsonPropertyDescription;
import java.util.List;

@JsonClassDescription("A mathematical calculation request")
public record CalculationRequest(
    @JsonProperty(required = true)
        @JsonPropertyDescription(
            "The arithmetic operation to perform: ADD, SUBTRACT, MULTIPLY, or DIVIDE")
        Operation operation,
    @JsonProperty(required = true)
        @JsonPropertyDescription(
            "Ordered list of numbers to apply the operation on (e.g. [10.0, 4.0, 2.0])")
        List<Double> operands,
    @JsonProperty(required = false)
        @JsonPropertyDescription("Decimal precision for the result, between 0 and 10 (default: 2)")
        Integer precision) {}

package com.aiexplorer.mcp.model;

import com.fasterxml.jackson.annotation.JsonClassDescription;
import com.fasterxml.jackson.annotation.JsonPropertyDescription;

@JsonClassDescription("Result of a mathematical calculation")
public record CalculationResult(
    @JsonPropertyDescription("The computed numeric result") double result,
    @JsonPropertyDescription("Human-readable summary of the calculation performed") String summary,
    @JsonPropertyDescription("Number of decimal places applied to the result") int precision) {}
```

```python
import ast
import math

def add(a: float, b: float) -> float:
    return float(a + b)

def subtract(a: float, b: float) -> float:
    return float(a - b)

def multiply(a: float, b: float) -> float:
    return float(a * b)

def divide(a: float, b: float) -> float:
    if b == 0:
        raise ValueError("division by zero")
    return float(a / b)

_ALLOWED_BIN_OPERATORS = (ast.Add, ast.Sub, ast.Mult, ast.Div, ast.Pow, ast.Mod)
_ALLOWED_UNARY_OPERATORS = (ast.USub,)

def _safe_eval(node: ast.expr) -> float:
    if isinstance(node, ast.Constant):
        if isinstance(node.value, bool) or not isinstance(node.value, (int, float)):
            raise ValueError("unsupported expression")
        return float(node.value)
    if isinstance(node, ast.BinOp):
        if not isinstance(node.op, _ALLOWED_BIN_OPERATORS):
            raise ValueError("unsupported expression")
        left = _safe_eval(node.left)
        right = _safe_eval(node.right)
        if isinstance(node.op, ast.Div) and right == 0:
            raise ValueError("division by zero")
        if isinstance(node.op, ast.Mod) and right == 0:
            raise ValueError("division by zero")
        try:
            result = {
                ast.Add: lambda: left + right,
                ast.Sub: lambda: left - right,
                ast.Mult: lambda: left * right,
                ast.Div: lambda: left / right,
                ast.Pow: lambda: left ** right,
                ast.Mod: lambda: left % right,
            }[type(node.op)]()
        except OverflowError:
            raise ValueError("result is too large")
        if math.isinf(result):
            raise ValueError("result is too large")
        return float(result)
    if isinstance(node, ast.UnaryOp):
        if not isinstance(node.op, _ALLOWED_UNARY_OPERATORS):
            raise ValueError("unsupported expression")
        return -_safe_eval(node.operand)
    raise ValueError("unsupported expression")

def evaluate(expression: str) -> float:
    if not expression.strip():
        raise ValueError("empty expression")
    try:
        tree = ast.parse(expression.strip(), mode="eval")
    except SyntaxError:
        raise ValueError("unsupported expression")
    return _safe_eval(tree.body)
```

```python
    """Add two numbers and return the result.

    Args:
        a: The first operand.
        b: The second operand.
    """
    return str(calculator.add(a, b))

    """Subtract b from a and return the result.

    Args:
        a: The minuend.
        b: The subtrahend.
    """
    return str(calculator.subtract(a, b))

def multiply(a: float, b: float) -> str:
    """Multiply two numbers and return the result.

    Args:
        a: The first factor.
        b: The second factor.
    """
    return str(calculator.multiply(a, b))

@mcp.tool()
def divide(a: float, b: float) -> str:
    """Divide a by b and return the result. Returns an error if b is zero.

    Args:
        a: The dividend.
        b: The divisor. Must not be zero.
    """
    try:
        return str(calculator.divide(a, b))
    except ValueError as e:
        return f"Error: {e}"
```

```python
import statistics as stats

from pydantic import BaseModel, field_validator

class DatasetInput(BaseModel):
    label: str
    numbers: list[float]

    @field_validator("numbers")
    @classmethod
    def numbers_must_not_be_empty(cls, v):
        if not v:
            raise ValueError("numbers must not be empty")
        return v

    @field_validator("label")
    @classmethod
    def label_must_not_be_blank(cls, v):
        if not v.strip():
            raise ValueError("label must not be blank")
        return v

class AnalyzeRequest(BaseModel):
    datasets: list[DatasetInput]

    @field_validator("datasets")
    @classmethod
    def datasets_must_not_be_empty(cls, v):
        if not v:
            raise ValueError("datasets must not be empty")
        return v

class StatResult(BaseModel):
    label: str
    count: int
    mean: float
    median: float
    min: float
    max: float
    range: float
    variance: float
    std_dev: float

def analyze_datasets(request: AnalyzeRequest) -> list[StatResult]:
    results = []
    for dataset in request.datasets:
        numbers = dataset.numbers
        n_min = min(numbers)
        n_max = max(numbers)
        results.append(StatResult(
            label=dataset.label,
            count=len(numbers),
            mean=stats.mean(numbers),
            median=stats.median(numbers),
            min=n_min,
            max=n_max,
            range=n_max - n_min,
            variance=stats.pvariance(numbers),
            std_dev=stats.pstdev(numbers),
        ))
    return results
```
