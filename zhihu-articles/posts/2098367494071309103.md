在《[AGI之路](https://mp.weixin.qq.com/s?__biz=MzIzMjU1NTg3Ng==&mid=2247490681&idx=1&sn=d50a804e8dddade1cce2520cb2d6b877&scene=21&poc_token=HAxB8GmjpEk50ywJXm_wkDDBejlNPcVhEsX3HXBY#wechat_redirect)》里面，提到对话(C)、推理(R)、智能体(A)、创新（I）、组织(O) 5层结构。当时我认为：

**L4 = 多模态 + 多Agent + RL + COT + 仿真 等等的一个综合体。**

**L5 = 安全边界控制 + 超级对齐(Advanced Alignment) + 规模化编排(Scalable Orchestration) + 超长记忆评价（Super Long Memory**

**Supervision）。**

现在回看，自己还是目光短浅，还是不能看到真正的L4和L5。而2025年，我认为的L4和L5，已经被当前智能体时代全部融合了。

**三类智能体**

当前爆火的有三类智能体：

1. **基础模型Agent RL**：以DeepSeek V4为代表的Agent RL。 通过MOE 融合多模态， 通过MT-OPD实现多Agent的RL， 通过 DSec SandBox实现任务仿真。

**2. 类OpenClaw智能体**：以编排(Agent + SubAgent的Cooperation)， 以Skills来对齐， 以Memory来实现超长记忆。 2026年，OpenClaw‘[小龙虾OpenClaw四十问](https://mp.weixin.qq.com/s?__biz=MzIzMjU1NTg3Ng==&mid=2247492142&idx=1&sn=041933929f96b88a59c20f526577de66&scene=21#wechat_redirect)’的大爆炸， 直接把Agent时代提升到了前所未有的高度。

**3. 本体思想指导的智能体：**在“[Anthropic和Palantir的合作模式？](https://mp.weixin.qq.com/s?__biz=MzIzMjU1NTg3Ng==&mid=2247492046&idx=1&sn=9754a9a263a41ee04fd77fef44010180&scene=21#wechat_redirect)”提到， 真正有效的Ontology不是用于Sandbox的仿真(Digital Twin)，而是真实物理世界的仿真的胶水，没有Ontology这个胶水， 物理世界的Digital Twin的仿真成本极高。 想要建设真实世界的智能体， 必然离不开Ontology的应用。

![](https://pic3.zhimg.com/v2-fadf6e374b15e5c2b272214f09269a10_r.jpg)

目前三类智能体Agent在齐头并进， 其中前两类智能体， 因为都是以Sandbox可控小环境为对象， 他们已经立足这个基础在融合发展。

可以看到，我之前讨论的L4和L5，在这三大类智能体上都有体现了。

**一. 基础模型的智能体Agent 【 LLM-Alpha-Zero(agent时代) 】**

在[DeepSeek V4的结构化寻优](https://mp.weixin.qq.com/s?__biz=MzIzMjU1NTg3Ng==&mid=2247492222&idx=1&sn=e8c74b483259da1494a3358a0fb5a088&scene=21#wechat_redirect)里面，我们谈到, DeepSeek伟大的地方在于给出开源范式：

1） LLM-Apha-Zero(reasonning时代) = deepseek R1;

2） LLM-Alpha-Zero(agent时代) = **GRM+MT-**OPD+DSec Sandbox;

在当前穷尽了互联网数据的前提下， 未来无中生有Alpha-Zero永远是重中之重！

类比Alpha-Zero，关键要解决几个问题：

**1） 数据**： AlphaZero是对弈沙箱； DS R1是大模型CoT生成； DS V4是 DSec SandBox的Agent Track。

**2）稀疏收敛优化**： AlphaZero是多步前瞻； DS R1是GRPO； DS V4是MT-OPD。

**3）奖励机制**：AlphaZero是结果；DS R1是RLVR+LLM-as-a-Judge； DS V4是GRM (RLHF + RLAIF)+Agent-as-a-Judge。

![](https://pic3.zhimg.com/v2-206c3f6ace79d208e1f71e61a950a094_r.jpg)

4）通过规模化训练， 追求的**涌现能力**： AlphaZero是下棋提前挖坑；DS R1是 顿悟(Aha Moment)； DS V4是任务可执行拆解。

![](https://pic3.zhimg.com/v2-e68ebe05b5b5016c22f9487dde58cfde_r.jpg)

**二. 类OpenClaw自主智能体Agent 【 SKILL->Harness->Hermess 】**

在[HermesAgent源码解读](https://mp.weixin.qq.com/s?__biz=MzIzMjU1NTg3Ng==&mid=2247492186&idx=1&sn=b287cef9d8d15c8c8ddda4dc12696613&scene=21#wechat_redirect)里面，我们谈到, Hermes第一次打通了智能体Agent Context 和 微调大模型的循环：

**OpenClaw Agent** = Lazy-Context(Skill+Memory)+Plan-Act-Observe+Heartbeat

**Harness Agent**= Context Engineer (Skill) + Memory + Orchestration + Tools + Verification + Constraint

**Hermes Agent** = Lazy-Context+ Plan-Act-Observe-Learn

![](https://pic4.zhimg.com/v2-d65162a6a22504cf85e7271fa168d3c3_r.jpg)

对比OpenClaw与早期自主智能体的简单设计， 会看到对任务拆解的编排能力(Orchestration)， 和记忆能力(Memory)，以及上下文工程（Context Engineer / Skills）的大幅度提升。

![](https://pic1.zhimg.com/v2-1c2abebc3a2468d726fac886f922ea94_r.jpg)

**三. Ontology 赋能下的Agent**

**Palantir 的 Ontology Agent 走的是一条截然不同的路：在其架构中，Ontology位于核心位置，优先保障世界仿真。 而Agent可以查询数十亿业务对象、编排成千上万的操作，并在与人类员工相同的安全治理框架下运行。**

**其实Ontology在Agent看来就是物理世界的关系约束， 只有满足这些约束才能确保安全与确定性。因此Agent 的动作被严格限制在Ontology定义的规则内，进而保障极高的合规性和业务真实性。**

**正如“[Anthropic和Palantir的合作模式？](https://mp.weixin.qq.com/s?__biz=MzIzMjU1NTg3Ng==&mid=2247492046&idx=1&sn=9754a9a263a41ee04fd77fef44010180&scene=21#wechat_redirect)”里面提到的， 当前的Ontology建设成本太高， 过于依赖复合型人才，难以规模化。 需要创新之路。**

**四， 三种智能体的互动**

在“[大模型的2026年展望](https://mp.weixin.qq.com/s?__biz=MzIzMjU1NTg3Ng==&mid=2247491490&idx=1&sn=f6c7c606db8a3c778cfc3c2ef37aa88c&scene=21#wechat_redirect)”，我们提到， To C 和 To B大模型建设的分道扬镳是2026年最大的变化之一。 因此， 面向个人和企业开发者， 类小龙虾的智能体必然大有帮助， 但是真正想建设AI原生企业， 依然离不开对Ontology智能体的探索。 而基础大模型公司，当前还是主要抢夺个人市场。 目前，Hermes 的出现表面，个体赋能的大模型微调已经可以和智能体进行联动。 相信企业市场的大模型微调， 还有待同Onology协同发展， Ontology RL时代呼之欲出！！！

![](https://pic1.zhimg.com/v2-58e27e7fc7957d6691ec98b48231bcde_r.jpg)

**小结：**

目前， OpenAI的5步AGI之路依然是行业发展的核心驱动力。 在创新方向， 很多Co-Scientist的出现， 以及OpenAI的Prism工具的开发，表明万众科研开始发力。 通过以上的分析也可以看到， AGI的发展并非完全按阶段限制的，而是多阶段协同发展， 到一定程度出现现象级突破。
