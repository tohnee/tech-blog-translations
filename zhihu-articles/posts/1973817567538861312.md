我学量化，最兴奋的事就是写出一条“收益漂亮得离谱”的回测曲线。

涨幅稳定、回撤轻微、曲线平滑得像画出来的。

然后你拿去给真正做量化的人看，他只会说一句：

> **“你这他娘的纯放屁”**

回测是量化世界里最大的陷阱。 你以为自己在“验证想法”，实际上你在：

- 偷看未来
- 使用今天才知道的标的
- 挖出噪声
- 忽略成本
- 忽略滑点
- 忽略停牌
- 忽略报表延迟、财务可见性
- 忽略指数成分变化

最后你得出的不是策略，只是**历史噪声的艺术品**。

这一篇，我们不讲定义，不讲概念，不讲玄学。 我们用 **代码** 让你亲眼看到：

- 幻觉回测是如何产生的
- 真实回测有多丑
- 你的脑子是如何被伪阿尔法欺骗的

读完这篇，你会明白：

> **回测不会告诉你未来能赚钱吗？ 它只会告诉你：你的假设有没有在历史上作弊。**

## 一、最致命的幻觉：前视偏差（未来函数）

未来函数是所有回测灾难的大魔王。

为了让你明白它有多毒，我们用一个极简单的例子。

你想测试一个“低价买入”的策略，于是你写：

```text
signal = data['Close'] < data['Close'].rolling(30).mean()
```

这看起来很合理，对吧？ 30 日均线是过去 30 天的平均价。 这个也叫做MA

> MA（Moving Average，移动平均线）就是“过去 N 天价格的平均值”。 例如 30 日 MA，就是把过去 30 天的收盘价加起来除以 30。 它的作用是：把每天乱跳的价格变平滑，让你看到“最近一个月的整体趋势”。

但是你忘了：

> **rolling(30).mean() 在当天收盘后才知道。**

如果你用它来决定当天买不买，你在作弊。

为了让你感受到“偷看未来”的巨大差别，我直接给你对比代码。

---

## 幻觉回测：当日信号吃当日收益

**用“当天收盘价”去产生“当天的交易信号”，然后还让这个信号买到“当天的收盘价”。**

这在日线回测里就是赤裸裸的未来函数。

我们看看典型错误的代码：

```text
import yfinance as yf
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

df = yf.download("AAPL", start="2020-01-01", end="2025-01-01", auto_adjust=True)

# 未来函数：rolling(30).mean() 用到了“当天收盘价”
ma30 = df['Close'].rolling(30).mean()

# 未来函数：用当天的信号去吃当天的收益
signal_fake = df['Close'] > ma30

returns = df['Close'].pct_change()

# 致命未来函数：当日信号 × 当日收益
equity_fake = (1 + returns * signal_fake).cumprod()
```

画一下曲线：

```text
equity_fake.plot(figsize=(12,6))
plt.title("Illusion Strategy: Backtesting with Future Data")
plt.show()
```

![](https://pica.zhimg.com/v2-919ac2c9bd416189bc591161c2e56dbe_r.jpg)

你看到的会是这样一条曲线：

- 几乎没有回撤
- 趋势抓得完美
- 黑天鹅都像提前预知
- 整体平滑得像“自动印钱机”

为什么？

因为这段代码假设：

> **你每天在收盘前提前知道收盘价，然后用这个信息下单。**

你不是在做量化，你是在当神。 当然赚钱。

---

## 真实回测：只用“昨天能看到的数据”来做决策

正确的写法只有一个重点：

> **今天的仓位，只能根据昨天收盘前已经发生的事情决定。**

这意味着两件事：

1. rolling(30) 必须 shift(1)，保证只用到昨天的收盘价
2. 交易信号也必须 shift(1)，确保用的是“昨天的信号”执行“今天的交易”

正确代码：

```text
# 正确：滚动均线必须只用到 t-1 的价格
ma30_real = df['Close'].rolling(30).mean().shift(1)

# 正确：今天的信号基于昨天的 MA
signal_real = df['Close'] > ma30_real

# 正确：今天的交易使用昨天的信号
equity_real = (1 + returns * signal_real.shift(1)).cumprod()

equity_real.plot(figsize=(12,6))
plt.title("Real Strategy: Avoiding Look-Ahead Bias")
plt.show()
```

![](https://pic3.zhimg.com/v2-269e2f37cd89e03872d32197bc519994_r.jpg)

对比真实回测，你会看到：

- 曲线明显更抖
- 会出现真正的回撤
- 会错过趋势
- 会买在错误时机
- 会经历几年横盘
- 收益不稳定

也就是说，它终于变成：

> **一个正常人能做到的策略。 一个接近现实世界的策略。**

而不是“上帝视角 + 吃当天收盘价”的作弊品。

---

## 为什么两者差这么多？

原因很简单：

### 幻觉回测 = 当天收盘价生成信号 + 当天收盘价买入

→ 这是假设你可以在看到 K 线收盘后再回到收盘位置下单。

### 真实回测 = 昨天数据生成信号 + 今天开盘或今天整体收益

→ 这是你在现实中真正能做到的。

一句话总结：

> **差的不是一个 shift，差的是“你是不是在用未来数据交易”。**

## 二、幸存者偏差：你回测的股票，今天已经是巨头了

这类偏差比未来函数更阴险。 你没有偷看“未来的价格”， 你偷看的是：

> **未来谁能活下来、谁能做大、谁能变成巨头。**

如果你用“今天还活着的明星公司”回测 10 年前的行情， 你实际假设的是：

> **十年前你就已经知道苹果不会死、微软不会倒、英伟达不会横盘、特斯拉不会破产。**

这当然是作弊。

为了让你直观感到恶心，我们用一个**完全可运行**的方式重新演示：

---

## 幻觉回测：用“今天还活着的赢家”回测十年前

这就是入门者最常犯的错误：

- 打开 yfinance
- 选一堆今天的科技巨头
- 回测 2010–2020
- 发现一切都完美得像印钱

看代码：

```python3
import pandas as pd

# 这些是 2025 年仍然风头正盛的巨头 —— 典型幸存者
survivors = [

ret_surv = data_surv.pct_change().mean(axis=1).fillna(0)
equity_surv = (1 + ret_surv).cumprod()

equity_surv.plot(figsize=(12,6))
plt.title("Illusion Backtest: Backtesting the \"Today's Survivors\" from Ten Years Ago”")
plt.show()
```

## 真实回测：每一年都重新抽取“当时活着的公司”

真正的世界不是“赢家俱乐部”， 是“每天有人死、有人上岸、有人变垃圾股”。

为了让你看到真实的丑陋，我们用一个 rất 简单但真实的方式模拟：

- 把 S&P 500 股票当作“宇宙集”（yfinance 能获取）
- 每一年随机选 30 个当做“当年市场上存在的公司” → 模拟退市、替换、IPO、崩盘 → 非常贴近真实世界的混乱
- 对每一年的股票池单独回测，然后拼起来

可运行代码如下：

```python3
equity_real = pd.Series(dtype=float)

prev_equity = 1.0

for year in range(2010, 2020):

    tickers = pick_yearly_stocks(universe)

    df_year = yf.download(
        tickers,
        start=f"{year}-01-01",
        end=f"{year+1}-01-01",
        auto_adjust=True
    )["Close"]

    ret_year = df_year.pct_change().mean(axis=1).fillna(0)

    # 关键：把每年的收益 **连续累积** 拼回整条曲线
    year_curve = prev_equity * (1 + ret_year).cumprod()
    prev_equity = year_curve.iloc[-1]

    equity_real = pd.concat([equity_real, year_curve])
```

画图：

```text
equity_real.plot(figsize=(12,6))
plt.title("Real-world backtesting: A stock pool including delisted, replaced, and losing stocks.")
plt.show()
```

虽然长得很像，但是看看Y轴的数量级就知道差距了

这条曲线会：

- 抖
- 乱
- 有几年不赚钱
- 甚至长期跑输幸存者池

但这才是真实世界。

不是每家公司都能成为苹果、英伟达、特斯拉。 大多数公司最后的命运，都不是“巨头”，而是：

- 破产
- 被并购
- 长期横盘
- 缩水成垃圾股

如果你的回测只包含赢家，那不是策略，那是历史筛选器。

## 为什么幸存者偏差会让回测变漂亮？

因为你假设了一个离谱的能力：

> **我能提前十年知道谁会成为巨头。**

如果你真的有这种能力，你也不会在这里写 Python 了。

幸存者偏差不是“数据不干净”的问题， 而是**你无意中把未来信息塞进了历史**。

真实回测的结果很丑， 但丑得更真实。

## 三、数据挖掘偏差：你不是找因子，你是在调参骗自己

最典型的错法：

- 试 100 个参数
- 试 100 种窗口
- 试 100 个阈值
- 最后挑出历史上“最赚钱的那一个”

你以为你发现了因子。 实际上你只是从 10,000 个噪声里挑了一个幸运儿。

为了让你感受到这种荒谬，我给你一个小实验：

> **我们用纯随机数构造一个“因子”——完全没有金融含义。 但你仍然能找到“赚钱的策略”。**

---

## 实验：纯随机因子，也能长出一条“好到离谱”的曲线

下面这段是可运行代码（你可以真的跑一遍）：

```python
import yfinance as yf
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

# 1. 下载数据
df = yf.download(
    "AAPL",
    start="2015-01-01",
    end="2025-01-01",
    auto_adjust=True
)

df = df[["Close"]]   # 只保留收盘价
df["ret"] = df["Close"].pct_change().fillna(0)

# 2. 构造纯随机“因子”
np.random.seed(42)
df["factor"] = np.random.randn(len(df))

# 分位数排名（看起来像“信号”）
df["signal"] = (df["factor"].rank(pct=True) > 0.5).shift(1)
df["signal"] = df["signal"].fillna(False).astype(int)

# 3. 回测：随机信号决定是否持仓
df["strategy_ret"] = df["ret"] * df["signal"]

# 4. 累计收益曲线
df["equity_strategy"] = (1 + df["strategy_ret"]).cumprod()
df["equity_buyhold"]   = (1 + df["ret"]).cumprod()

# 5. 作图
plt.figure(figsize=(12, 6))
df["equity_strategy"].plot(label="Random Factor Strategy")
df["equity_buyhold"].plot(label="Buy & Hold AAPL", linestyle="--")

plt.title("Random Noise Factor Backtest vs Buy & Hold")
plt.ylabel("Equity Curve")
plt.xlabel("Date")
plt.legend()
plt.grid(True)
plt.tight_layout()
plt.show()
```

## 为什么纯随机也能“赚钱”？

因为当你尝试足够多的噪声时：

> **总会有一条噪声刚好长成漂亮曲线，这和中彩票概率一样。**

而你以为那是“因子发现”。

事实上你只是：

- 对历史“调参”
- 对噪声“刷榜”
- 对过拟合“制造幻觉”

换句话说：

> **你不是在找因子，你是在骗自己。**

## 四、交易成本与滑点：回测的杀手

绝大多数“漂亮回测”在现实里只有一个下场：

> **被交易成本和滑点直接打成植物人。**

你在回测里看到的年化 30%， 到了真实市场，经常只剩 5%，甚至负的。

为什么？

因为你在回测里交易是免费的。

现实里不是。

---

## 成本怎么杀死策略？

成本的本质是：

> **你只要动一下，就要付钱。**

入门者常犯的错：

- 信号波动很快 → 一天调仓三次
- 每天都在换仓 → 手续费爆炸
- 交易量大 → 你自己把价格冲高（写代码的人把自己当做市场冲击 0 的幽灵）

结果很简单：

> **回测：你是天才 实盘：你是慈善家**

下面我们用一段代码，让你直观看到死亡现场。

---

## 构造一个“无成本 vs 含成本”的对比

我们先弄一个信号（例如前面章节的动量信号）： 为了简单，这里用随机信号代替（只演示成本影响，不演示策略逻辑）。

```text
import yfinance as yf
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

# 下载数据
df = yf.download(
    "AAPL",
    start="2015-01-01",
    end="2025-01-01",
    auto_adjust=True
)

df["ret"] = df["Close"].pct_change().fillna(0)

# 伪造一个信号：一半时间持仓、一半时间空仓
np.random.seed(0)
df["signal"] = (np.random.rand(len(df)) > 0.5).astype(int)
df["signal"] = df["signal"].shift(1).fillna(0)  # 避免未来函数
```

---

## 不含成本的策略收益（幻觉版本）

```text
df["strategy_ret"] = df["ret"] * df["signal"]
df["equity_nocost"] = (1 + df["strategy_ret"]).cumprod()
```

这代表你的“幻觉回测”效果。

---

## 加入现实世界的成本

假设：

- 每次换仓成本 = 千二（0.2%）
- 对量化来说已经算非常乐观了

```text
cost = 0.002  # 0.2%

# 换仓信号：持仓状态变化的次数
df["turnover"] = (df["signal"] != df["signal"].shift(1)).astype(int)

# 每次交易都要付成本
df["cost"] = df["turnover"] * cost

# 实际收益 = 策略收益 - 成本
df["strategy_ret_after_cost"] = df["strategy_ret"] - df["cost"]

df["equity_cost"] = (1 + df["strategy_ret_after_cost"]).cumprod()
```

---

## 画图对比

```text
plt.figure(figsize=(12,6))
df["equity_nocost"].plot(label="No cost (illusion)")
df["equity_cost"].plot(label="Including costs (realistic)")
plt.legend()
plt.title("The devastating impact of transaction costs on strategies")
plt.show()
```

## 专业量化怎么处理成本？

真实量化团队根本不会用上面这种“千二手续费”模型，它太乐观了。

专业机构会模拟：

- **滑点模型**（交易冲击、吃单深度、盘口模型）
- **交易量约束**（不能吃超过某只股票流动性的 5%）
- **下单方式**（VWAP、TWAP、POV、冰山单）
- **冲击函数**（你买得越凶，价格升得越快）
- **交易延迟**（信号 → 下单 → 成交之间的时间差）
- **隔夜风险**

你的策略只要不满足流动性限制，在真实市场里几乎必死。

## 五、让我们把所有东西放在一起：

## 幻觉策略 vs 真实策略

你现在已经知道四种主要幻觉：

- 未来函数
- 幸存者偏差
- 噪声挖掘
- 忽略成本

这四个错加在一起，会产生一条“完美曲线”。

真实曲线长什么样？ 往往像一个**心电图**。

你如果把幻觉曲线和真实曲线放在一起，会第一次感到反胃：

因为你会意识到：

> **所有看起来“轻松赚钱”的回测，背后都藏着某种作弊。**

量化不是靠“找漂亮曲线”， 量化是靠排除所有幻觉之后， 仍然能剩下一点点真实信号。
