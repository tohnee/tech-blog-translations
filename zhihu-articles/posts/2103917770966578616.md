为什么一天涨了 790 颗星

ha-mcp 这个项目创建才 423 天，总 star 数已经到了 6857，单日新增 790 颗，这个速度在 GitHub 上属于明显异常的爆发状态。

背后的逻辑其实很直接：Home Assistant 是全球最大的开源智能家居平台，装机量以百万计，但它的配置一直是个门槛。要写 YAML 文件、要懂自动化逻辑、要查文档——普通用户装上之后往往只用了 20% 的功能。

ha-mcp 做的事是把这个门槛干掉。它通过 MCP（Model Context Protocol）协议，让 Claude、ChatGPT 这类 AI 助手直接「接管」Home Assistant 的控制权。用户说一句话，AI 自动完成配置，不需要自己写任何代码。

这个时间节点很关键。MCP 协议是 Anthropic 在 2024 年底推出的，2025 年开始被大量项目采用，本质上是给 AI 插上「手」——让它不只是回答问题，还能真正操作软件和系统。ha-mcp 是这个趋势在智能家居方向上最成熟的落地之一，项目还有 440 个 fork，说明已经有大量人在此基础上二次开发。

普通人能用它赚钱的三个方向

方向一：智能家居「AI 配置」收费服务

做什么：帮已经安装了 Home Assistant 的用户，接入 ha-mcp，然后用 AI 帮他们把家里的设备全部配置好——灯光场景、安防联动、能耗监控、起床/离家/回家自动化一套跑通。

卖给谁：已经买了智能家居设备但「设备都在，自动化没用起来」的业主，这类用户在各大智能家居交流群里随处可见。

怎么收费：按项目报价，一套完整配置服务 800～2000 元（估计），设备数量越多越贵；也可以做「包年维护」套餐，每年 500～1000 元（估计），负责持续优化自动化规则。

成本和技能：需要会安装 Home Assistant 和 ha-mcp，自己动手测通整个流程大概需要一个周末。不需要编程基础，主要技能是耐心和沟通。

第一步：在自己家跑通一套演示，录一段「用 AI 对话配置智能家居」的视频，发到抖音或小红书，用真实效果吸引第一个付费客户。

方向二：面向安装公司的「AI 增值包」外包

做什么：很多做智能家居安装的小公司，有硬件安装能力，但没有软件配置能力。你可以作为外包方，专门为这些公司的客户提供 ha-mcp 接入和配置服务，安装公司把这个包装成「AI 智能管家」卖给终端用户。

卖给谁：本地智能家居安装公司、别墅装修公司的智能家居部门，他们有稳定的客户来源，缺的是技术服务能力。

怎么收费：按台收费，每套房子 1500～3000 元（估计）的技术服务费，安装公司加价后卖给业主。如果谈成长期合作，单月跑 5～8 单是可预期的量级。

成本和技能：需要能稳定复现安装流程，建议做一份标准化的操作手册。初期可以先找 1～2 家公司谈「免费试跑一单」，用结果建立信任。

第一步：在本地智能家居、装修类微信群里找主动发项目信息的安装商，直接私信说「我做 AI 配置，第一单免费」。

方向三：教程和工具包销售

ha-mcp 有 440 个 fork，说明有大量爱好者想自己动手，但文档是英文的，上手门槛还是存在。

做什么：写一套中文从零上手教程，或者做一个「常用自动化场景模板包」——比如「租房党灯光自动化」「双职工家庭安防模板」「节能监控套件」，打包成 PDF 或可直接导入的配置文件。

卖给谁：Home Assistant 中文社区（论坛、B站、微信群）里的 DIY 爱好者，这个群体对质量好的中文资料付费意愿明显。

怎么收费：教程课程 99～299 元（估计）；模板包 29～69 元（估计）一套，可在爱发电、咸鱼、小报童等平台上架。

成本和技能：主要成本是时间，整理一套完整教程大概需要 2～3 周。有截图和视频录制能力就够了。

第一步：先在 B 站或小红书发 1～2 篇免费教程测试反响，评论区问「想要完整版吗」，有人回应再做付费版。

门槛和风险

这个项目目前有几个现实问题值得留意。

第一，依赖链比较长。需要有 Home Assistant、有 AI 账号（Claude 或 ChatGPT）、会安装插件，任何一环出问题都要排查。对于想做服务的人来说，自己要能稳定复现安装流程，才能承接客户。

第二，Home Assistant 本身版本迭代快，ha-mcp 的 README 里就提到某些功能要 2026.8.0 以上版本才支持，说明对 HA 的版本要求较新，客户如果版本旧了会有兼容问题。接单前要先确认客户的系统版本。

第三，这个项目是开源的，技术门槛本身不高，做同样事情的人会越来越多。想做服务的话，越早建立口碑和案例积累越有价值，做「模板包」和「教程」这类内容资产的话，同样是越早越有先发优势。

第四，AI 接口费用是长期成本。Claude 或 ChatGPT API 按调用次数收费，如果帮客户做「包年维护」，要把这部分成本算进去，或者引导客户用自己的 API Key。
