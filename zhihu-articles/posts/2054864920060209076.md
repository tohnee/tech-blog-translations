1. 环境搭建
1.1 检查驱动

确保输出有 GPU 信息：
NVIDIA GeForce RTX 3060 Laptop GPU

1.2 安装 Miniconda（推荐，环境隔离）

# CUDA 12.6 版本的 PyTorch（可在 13.3 驱动上运行）
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu126

# 验证 GPU 可用

输出应为：
GPU: NVIDIA GeForce RTX 3060 Laptop GPU
VRAM: 6.0 GB
1.4 安装训练框架
# 核心套件
pip install transformers accelerate peft bitsandbytes trl datasets

# 辅助
pip install wandb tensorboard xformers scipy

cd ~/Projects

验证安装：
llamafactory-cli version

2. 数据准备
2.1 数据格式（最关键的步骤）
标准格式：ShareGPT 格式（JSON 数组）
[
  {
    "messages": [
      {"role": "system", "content": "你是一个有帮助的助手。"},
      {"role": "user", "content": "Linux 怎么查看磁盘空间？"},
      {"role": "assistant", "content": "用 `df -h` 命令，-h 表示人类可读格式。"}
    ]
  },
  {
    "messages": [
      {"role": "user", "content": "Python 列表和元组的区别？"},
      {"role": "assistant", "content": "列表可变（mutable），元组不可变（immutable）。列表用 []，元组用 ()。"}
    ]
  }
]
2.2 创建你的数据集
mkdir -p ~/Projects/my-training/data
把上面的 JSON 格式数据保存到 ~/Projects/my-training/data/train.json
2.3 注册数据集（LLaMA-Factory）
cd ~/Projects/LLaMA-Factory
编辑 data/dataset_info.json，添加：
{
  "my_custom_data": {
    "file_name": "my_training_data.json",
    "format": "sharegpt",
    "columns": {
      "messages": "messages"
    }
  }
}
然后把你的数据文件复制过去：
cp ~/Projects/my-training/data/train.json data/my_training_data.json

3. LoRA 微调 7B 模型
3.1 准备训练配置
创建 ~/Projects/my-training/train_lora.yaml：
### 模型
model_name_or_path: Qwen/Qwen2.5-7B
trust_remote_code: true

### 方法
finetuning_type: lora
lora_target: all
lora_rank: 16           # LoRA 秩，16-32 够用
lora_alpha: 32
lora_dropout: 0.05

### 数据集
dataset: my_custom_data
template: qwen
cutoff_len: 1024        # 最大序列长度
preprocessing_num_workers: 16

### 量化（关键！6GB VRAM 必须用 QLoRA）
quantization_bit: 4
quantization_method: bitsandbytes

### 训练参数
per_device_train_batch_size: 2
gradient_accumulation_steps: 8    # 等效 batch size = 16
learning_rate: 2.0e-4
num_train_epochs: 3.0
max_grad_norm: 1.0
warmup_ratio: 0.05

### 优化器
optim: paged_adamw_8bit
lr_scheduler_type: cosine

### 日志
logging_steps: 10
save_steps: 100
save_total_limit: 3

### 输出
output_dir: ./output/qwen7b-lora
overwrite_output_dir: true

### 混合精度（bfloat16 需要 Ampere 以上架构，RTX 3060 支持）
bf16: true
fp16: false
为什么可以用 bf16？ RTX 3060 是 Ampere 架构（Compute Capability 8.6），原生支持 bfloat16。
3.2 开始训练
cd ~/Projects/LLaMA-Factory

# 单卡训练
llamafactory-cli train ~/Projects/my-training/train_lora.yaml
第一次运行会自动下载模型（Qwen2.5-7B 约 15GB 磁盘）。训练过程：
[INFO] VRAM 占用: ~4.8GB / 6GB
[INFO] 每步耗时: ~2秒
[INFO] 总步数: ~1800步（5000条数据，3个epoch）
[INFO] 预计总时间: ~60分钟
3.3 训练参数调优指南
VRAM 不够时优先调整（按效果排序）：
1. 减小 per_device_train_batch_size → 1
2. 增大 gradient_accumulation_steps → 16（保持等效 batch size）
3. 减小 cutoff_len → 512
4. 降低 lora_rank → 8
3.4 监控训练
# 开另一个终端
tensorboard --logdir ~/Projects/LLaMA-Factory/output/qwen7b-lora/runs
# 浏览器打开 http://localhost:6006

5. 常见问题
Q: CUDA out of memory（6GB VRAM 不够）
# 解决方法：缩小配置
per_device_train_batch_size: 1
gradient_accumulation_steps: 16
cutoff_len: 512
quantization_bit: 4
还要确保没有其他程序占用显存：
# 检查显存占用
nvidia-smi
# 释放
sudo fuser -v /dev/nvidia*
Q: RTX 3060 支持 flash attention 吗？
# 安装 xformers（提供 memory-efficient attention）
pip install xformers

# 在训练配置加
flash_attn: auto
Q: 训练 Loss 不下降
    • 数据有问题（最常见）：检查 JSON 格式、是否有空值
    • 学习率太高：降到 1e-4
    • 数据量太少：至少 200 条以上才有意义
Q: 下载模型太慢
# 用 huggingface 镜像
export HF_ENDPOINT=https://hf-mirror.com

# 或从 ModelScope 下
pip install modelscope
python -c "from modelscope.hub.snapshot_download import snapshot_download; snapshot_download('Qwen/Qwen2.5-7B', cache_dir='~/cache')"
