DeepSeek 新发布的公告里有这样一句：开发者用新接口，“甚至 1:1 复刻出完整的 DeepSeek App”。App 里的联网搜索、深度思考搜索、文件输入、读链接和安全校验，都并进了原来的对话接口，开一个参数就能用。想做联网聊天助手的小团队，不用再自己接搜索服务、拼上下文。

真要对外上线，绕不开两件事，一个回答到底花多少钱，DeepSeek 管到哪一步。公告给了一半答案，工具按次另收费。另一半写在模型安全那一条：“如您对外提供应用服务，请务必开启该参数，并承担内容安全审核、大模型登记、AI 标识等义务。”

![](https://pic2.zhimg.com/v2-a1fde9db074bbbbf9ecc1839640cc89b_r.jpg)

*DeepSeek API 文档里的发布公告（2026-11-13 发布），2026-11-14 截图。*

这套东西叫“全家桶应用 API”，11 月 13 日上线。搜索、网页抓取、OCR、语音识别和语音合成另开了独立接口，可以单独调。

一个月前的 10 月 17 日，DeepSeek 先开放了自研搜索引擎的 Search 和 Fetch 接口，更新日志说它索引了“全球千亿级网页”。这回把搜索放进对话接口，搜不搜、搜什么交给模型。

目前只有 deepseek-flash，也就是 V4.1-Flash 支持这些功能，Messages、Responses、Chat Completions 三种接口格式都能用。

### 一个回答多少钱？

token 照旧按 flash 的价格收。工作日北京时间 9 点到 12 点、14 点到 18 点是高峰，每百万 token 未命中缓存的输入 2 元、输出 8 元；其余时间都是半价，周末和法定节假日全天也算闲时。

搜索和网页抓取另收工具费，每 1000 次 5 元，文件解析和 OCR 每 1000 页 1.5 元。直接调 Search、Fetch 接口，和让模型在对话里自己去搜，价钱一样。

![](https://pic4.zhimg.com/v2-cfe77f05b43313fb9839801e596d1613_r.jpg)

*DeepSeek API 价格页，2026-11-14 截图。语音两项现在是 5 折限时价，页面没写截止日期。*

DeepSeek 的“构建 Chatbot”文档放了一个完整示例：开着思考、联网和安全审核，问“DeepSeek V4.1 有哪些更新？”。

响应里的用量是未命中缓存的输入 9,078 个 token、命中缓存 4,096 个、输出 1,686 个，计费搜索 2 次。

按价格页折算，这一问高峰时段约 0.042 元，空闲时段约 0.026 元。

![](https://pic3.zhimg.com/v2-2639f9deb23a957720a7819a21cda7c8_r.jpg)

*按文档示例的用量乘价格页单价推算。输出 token 里包含思考和安全审核产生的 token。*

搜索费固定是 1 分钱，token 费闲时减半，闲时跑，搜索能占到总价近四成。

照这个例子粗估，一个每天 1 万次联网问答的应用，全在高峰时段约 418 元一天，全在闲时约 259 元。

深度思考搜索的账难估得多。

文档的说法是模型“最多调用约 20 次工具后作答”。可搜索按查询词计费，不按调用次数，一次调用带 3 个查询词就算 3 次。

文档里另一个例子问埃菲尔铁塔和东京塔哪个高，模型搜了两轮共 7 个查询词，打开了 5 次网页，另做了 3 次页内查找，往多了算，工具费 0.06 元。

20 次调用全是单个查询词的搜索，是 0.10 元。每次都像那个例子的第一轮一样带 4 个查询词，就到 0.40 元。

![](https://pic1.zhimg.com/v2-88550e9cc999a988f5c6006d855b8068_r.jpg)

*按 DeepSeek 联网工具文档的计费规则推算，不含 token 费。打开网页只在实际从网络抓取时收费，重复打开、翻页和页内查找不收费。*

搜索失败或没搜到结果不计费，抓取失败的链接也不计费。图片搜索每张图算 1 次，模型在图里框出一块区域再搜，每块另算 1 次。

回答生成到一半出错时，HTTP 状态码已经是 200，出错前的推理、搜索和读网页照常收费。

![](https://pica.zhimg.com/v2-841450b8d98979bcb70c7f14c59907f6_r.jpg)

*DeepSeek 联网工具文档“用量与计费”一节，2026-11-14 截图。对账看 usage 里的 tool_search、tool_fetch、tool_image_search，web_search_requests 只用于展示。*

Anthropic 的 Claude API 联网搜索每 1000 次 10 美元，OpenAI 的 web search 工具每 1000 次调用也是 10 美元。按 1 美元约合 7 元人民币粗算，是 70 元。

DeepSeek 的单价约为它们的十四分之一。

三家的计数口径各不相同，DeepSeek 一个查询词算一次，Anthropic 一次搜索算一次，OpenAI 按调用算。Anthropic 的网页抓取不收工具费，只收 token；DeepSeek 抓一个网页收半分钱。

*三家官方价格页，2026-11-14 读取。Anthropic、OpenAI 的搜索结果进上下文后另按 token 计费。*

语音合成刊例价每 1 万字符 3 元，一个汉字算 2 个字符。朗读一段 500 字的回答约 0.3 元，限时价 0.15 元，比生成这段回答贵好几倍。

语音识别便宜得多，刊例价每小时 0.78 元，用户说 30 秒不到 1 厘钱。

解析一份 100 页的 PDF 收 0.15 元，只收一次。之后每次对话引用它，只收拼进上下文的 token。

### 模型说了算的部分

公告说，工具调用和上下文拼接“均由服务端自动完成”。开发者省了事，不少开关也就不在自己手里。

搜不搜、读不读链接由模型判断，tool_choice 指定 deepseek_web_search 或 deepseek_read_url 会直接报 400。

联网工具不接受 allowed_domains、blocked_domains 和 user_location。想只搜某几个网站，得改用独立的 Search 接口，自己在搜索词里写 site: 语法。

开了联网工具、安全审核或会话标题，temperature、top_p 这些采样参数由服务端决定，传了会被忽略。联网工具暂时不能和其他服务端工具一起声明，在 Responses 接口里同时声明 web_search 工具会报 400。

读链接只识别最后一条用户消息里的 URL，最多看前 10 个不同的链接，读哪几个由模型挑。一次读好几个，每个网页能用的长度会缩短，长网页会被截断。

开着思考又声明了联网搜索时，这一轮走深度思考搜索，不单独读链接。

读到的网页正文不返回给开发者，加密后放在 signature 字段里，下一轮要原样传回去，网页才会拼回上下文。网关或框架丢了这个字段，请求照样成功，读过的网页却不再进上下文。

用过联网工具的回复也不能续写，会返回 400，只能重发上一个请求。

Search 每个账号每秒 100 次请求，Fetch 每秒 25 次，Fetch 对目标域名另有限速。

语音识别一次最长 120 秒、8 MiB，不支持流式，长录音要自己切段。语音合成一次最多 1 万个计费字符，不能调语速。对话里一个请求最多引用 20 个文档，单个文件不超过 100 MiB、1,000 页。

开源的 chat-demo 也只走到演示这一步。

它是个纯前端的静态页面，MIT 协议，浏览器直接连 DeepSeek 的接口，API Key 存在浏览器的 localStorage 里。自己用很方便，填上 Key 就能导入 DeepSeek 网页端导出的历史对话。

拿它直接给外部用户，要么让每个用户自己填 Key，要么把你的 Key 放在前端谁都看得见。

DeepSeek 文档里说，这个客户端“仅供演示”。

*chat-demo 在线版的设置页，2026-11-14 截图：先填 API Key 才能用，Key 和对话都存在本机浏览器里。*

### “请务必开启该参数”

safety_check 设成 high，就是公告说的基础风控，审核用户输入、工具返回的内容和模型输出，命中风险时返回拒答标识。

chat-demo 的代码里，这个参数写死成了 high。

审核产生的 token 也要钱，按输出 token 计费；输入没过审、请求返回 400 时，输入 token 按缓存命中的价格收；被拒答之前用掉的 token 照常收。

开了审核，模型输出完连接不会马上关，服务端还要把完整输出再审一遍，之后仍可能以拒答结束。

已经流式推给用户的文字撤不回来，开发者要在前端把显示出来的回答删掉，换成自己的拒答文案。

接口不说拒答的原因。

没开 safety_check 但用了联网工具的请求，同样可能被拒答。

安全文档里还有一句：这个参数“不能替代您作为服务提供者的内容安全审核等义务。您是内容安全审核的第一责任人。”

大模型登记和 AI 标识，DeepSeek 的文档没有展开，规矩出自网信办。

通过 API 直接调用已备案模型的应用或功能，由地方网信办登记。据新京报报道，网信办 9 月 14 日的公告说，截至 8 月 31 日，已有 731 款生成式 AI 应用或功能完成登记。

网信办 2024 年 4 月的备案公告还要求，已上线的应用在显著位置或产品详情页公示所用的已备案模型，注明模型名称和备案号。

AI 标识的依据是网信办等四部门的《人工智能生成合成内容标识办法》，2025 年 9 月 1 日起施行。生成的文字、图片、音频、视频要加显式标识，文件元数据里加隐式标识。

DeepSeek 网页端的做法可以照着看，输入框下面有一行小字“内容由 AI 生成，请仔细甄别”。

用 TTS 朗读回答的应用，合成出来的语音也属于生成内容。

![](https://pic4.zhimg.com/v2-58cff99dba580927e6aa98c28c715ef1_r.jpg)

*DeepSeek“构建 Chatbot”文档配图：网页端一次回答里，思考、搜索、读网页、带引用的正文各对应哪种内容块。输入框下方是网页端的 AI 生成提示。*

给每个终端用户传一个 user_id，DeepSeek 会按它区分用户身份做内容安全处理，并做缓存和调度隔离。

限速文档提醒，user_id 里不要放用户的隐私信息。
