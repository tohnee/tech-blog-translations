## **【CVPR 2026】SpaceMind: Camera-Guided Modality Fusion for Spatial Reasoning in Vision-Language Models**

**作者列表：** Ruosen Zhao, Zhikang Zhang, Jialei Xu, Jiahao Chang, Dong Chen, Lingyun Li, Weijian Sun, Zizhuang Wei（华为诺亚方舟 / 香港中文大学（深圳） / 香港大学）

**代码链接：** [https://github.com/RealMikeDuke/SpaceMind](https://github.com/RealMikeDuke/SpaceMind)

**文章概述**

多模态大模型在 3D 空间推理上普遍吃力：距离估计、尺寸比较、跨视角一致性都做不稳。现有 3D-aware 方案要么依赖点云、深度图这类外部 3D 输入，要么用几何编码器跟 RGB 特征做浅层拼接，融合得并不充分。 **SpaceMind** 的关键动作是把 **相机参数从「被动元数据」升格为「主动引导模态」** ：模型采用双编码器架构，VGGT 负责空间理解、InternViT 负责 2D 视觉编码，并在进入语言模型之前用一个轻量的 **相机引导模态融合模块** 替换掉浅层融合——具体包含三步：给空间 token 施加相机条件偏置、按与查询无关的方式为 token 分配反映其几何重要性的权重、再用相机嵌入对融合后的表征做门控。整套流程仅需纯 RGB 输入。在 VSI-Bench、SQA3D、SPBench 上均取得新 SOTA，其中 VSI-Bench 与 SPBench 大幅超过开源与商用系统。对做具身智能、空间问答的团队，这篇提供了「把传感器参数用成模态而非附属信息」的有益范式。

## **【ICCV 2025】TemCoCo: Temporally Consistent Multi-modal Video Fusion with Visual-Semantic Collaboration**

**作者列表：** Meiqi Gong, Hao Zhang, Xunpeng Yi, Linfeng Tang, Jiayi Ma（武汉大学电子信息学院）

**代码链接：** [https://github.com/Meiqi-Gong/TemCoCo](https://github.com/Meiqi-Gong/TemCoCo)

**文章概述**

现有多模态融合方法大多是把静态图像融合的套路直接搬到视频上逐帧处理，忽略了视频固有的时序依赖，结果是帧与帧之间颜色、亮度、结构对不上。 **TemCoCo** 是首个把 **时序建模与视觉-语义协同** 显式结合起来做视频融合的框架，三层设计层层递进：一是 **视觉-语义交互模块** ，拆成语义分支与视觉分支，用 DINOv2 和 VGG19 做定向蒸馏，让视觉保真度与语义准确度同步提升；二是 **时序协同模块** ，首创把视频退化增强任务并进融合管线，利用帧间时序依赖去恢复信噪比低区域丢失的弱信息；三是 **时序增强机制 + 时序损失** 在网络内部与优化目标两端同时约束一致性。此外论文还提出两个专门度量视频融合时序一致性的评价指标，填补了该方向长期缺少专门评价工具的空白。

## **【ICCV 2025】Balancing Task-invariant Interaction and Task-specific Adaptation for Unified Image Fusion**

**作者列表：** Xingyu Hu, Junjun Jiang, Chenyang Wang, Kui Jiang, Xianming Liu, Jiayi Ma（哈尔滨工业大学 / 武汉大学）

**代码链接：** [https://github.com/huxingyuabc/TITA](https://github.com/huxingyuabc/TITA)

**文章概述**

统一图像融合试图用一套框架吃下红外-可见光、多曝光、多焦点等所有融合任务，靠「把所有任务当成同一个问题」来共享知识，但这样会丢掉任务本身的特性；而已有的通用融合方法则通过显式的任务识别来适配不同任务，代价是推理时必须先知道自己属于哪一类， **无法泛化到未见过的融合任务** 。 **TITA** 提出的解法是动态平衡两头：任务无关交互侧用 **IPA 模块** （Interaction-enhanced Pixel Attention）强化逐像素级别的交互，把多源互补信息提取得更充分；任务特定适配侧用 **OAF 模块** （Operation-based Adaptive Fusion）按任务属性动态调整各操作的权重；联合训练阶段再引入 **FAMO** 策略缓解多任务之间的梯度冲突。实验显示它在三类图像融合场景上能与各任务的专用方法掰手腕，同时对训练中未出现的融合任务展现出强泛化能力。

## **【CVPR 2026】CCF: Complementary Collaborative Fusion for Domain Generalized Multi-Modal 3D Object Detection**

**作者列表：** Yuchen Wu, Kun Wang, Yining Pan, Na Zhao（新加坡科技设计大学 SUTD）

**代码链接：** [https://github.com/IMPL-Lab/CCF](https://github.com/IMPL-Lab/CCF)

**文章概述**

多模态融合做 3D 目标检测很吃香，可一换到训练域之外就大幅掉点。SUTD 团队把原因拆成两条：其一，在雨夜这类恶劣域中 **某一模态会严重退化** ；其二， **LiDAR 分支往往主导整个检测流程** ，导致视觉线索被系统性低估、点云一旦被污染模型就格外脆弱。 **CCF** 针对这两点给出三个组件： **Query-Decoupled Loss** 为 2D-only、3D-only 与融合 query 提供彼此独立的监督，重平衡跨模态的梯度流； **LiDAR-Guided Depth Prior** 把图像预测深度与 LiDAR 导出深度做概率融合，为 2D query 注入实例感知的几何先验，显著改善空间初始化； **Complementary Cross-Modal Masking** 对图像与点云施加互补的空间掩码，迫使两个模态的 query 在融合 decoder 中相互竞争，从而倒逼出真正的自适应融合。实验表明该方法在保持源域性能的同时显著超越现有基线。
