我那个安稳用了快半年的 Claude 账号，终于还是阵亡了。

以前看到别人说被封，总想着自己小心一点应该没事。用了这么久都好好的，也就慢慢放松了。结果还是没躲过去。

Claude 的模型好用是真好用，这家公司丧心病狂也是真丧心病狂。现在就是这么个心情。

### 两个怀疑，都还没坐实

封号原因还没弄清楚，回头想了想，最近有两个变化，可能跟这次有关。

一个是代理。

之前每次用 Claude，我都会先看一眼全局代理正不正常。后来用久了，改成规则模式，打开就用，没再像以前那样检查。

现在怀疑是不是规则有遗漏，有些请求没走代理。到底漏没漏，还没查清楚，但确实是我最近疏忽的地方。

另一个是那 250 美元。

Claude 最近送了云端代码额度，我也领了。用这个功能又涉及绑定个人 GitHub 账号。最近看到一些人说，自己也是领完额度之后被封的，所以我也怀疑是不是跟这个有关。

当然，这两件事都只是猜测。领完被封，也不代表一定是领取额度导致的。

只是账号一没，连官方送的东西都开始怀疑，这个使用体验实在让人无语。早知道会这样，当时何必去领。

用 Claude 最烦的就是这个。每次先检查代理，用久了稍微放松一点，又担心是不是哪里出了问题。 **一个干活的工具，用起来还得这么小心，真的累。**

### **骂归骂，它好用是真的**

**但让我说它不好用，我又说不出口。**

**之前 Claude 宕机，我换过 Codex 顶主调度，活能继续干，就是有些地方没那么顺。尤其是调用工具、派任务，失败了得重派。Claude Code 也会出错，但我当时用下来，明显少折腾一些。**

**这些以前的笔记里都写过，没必要因为这次被封了，就把之前夸过的话收回去。**

**也正因为用得顺手，才更烦。要是它本来就不好用，封了拉倒，根本犯不着写这么一篇。**

**我笔记里还收藏过一篇《离开 Claude，发现外面根本没下雨》。不过自己换过工具之后，也知道有些地方暂时还是 Claude 做得好。** 别人说能替代，跟自己用着省不省事，是两回事。

### 其他几家，能不能有点出息

所以现在最想说的，反而是其他几家能不能有点出息。

我也用别家的模型，当然希望它们赶紧把这些地方补上。别让我换过去干一阵活，又想起 Claude 的好。

一个用了快半年的账号就这么没了，还得自己猜为什么。想到这里，实在不想再夸它了。

其他家赶紧争点气吧，早点让我把 Claude 删了，再也不用。

你的 Claude 号还在吗？被封过的，最后查清原因了没有？评论区说说。
