连续两个claude号被封，麻了。

第一个claude账号，在用的时候，比较粗心，以为和gpt一样“抗用”， 🪜的全局和局部代理来回切换。

果然，喜提封号：

![](https://pic1.zhimg.com/v2-79b4913e2377562e1a0ec4278a8b3292_r.jpg)

第二个claude账号，用的还是比较小心的，使用claude都是开全局代理，浏览器都设置英文模式。

用了很长时间，就昨天，我在命令端让claude在debug一个问题。

然后我就想，闲着也是闲着，再用一个claude的mac客户端吧。

mac的客户端一登录，估计是客户端没有走代理（不是所有app都自动走全局代理）

这就是典型的CLI / App / API 混用不规范

- Claude Code（CLI）走代理
- Claude Desktop（App）没走
- API 用另一条线路

结果：

同一个账号，三条不同网络路径

claude直接又异常了。。。

![](https://picx.zhimg.com/v2-b7c61797c77df68bab3961d8318980f3_r.jpg)

没有claude，我还如何工作?

唯有休息。。。。
