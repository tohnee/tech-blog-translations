DeepSeek等国产大模型以极低成本实现突破，让"算力即护城河"的传统逻辑受到冲击。DeepSeek-V3以557万美元的训练成本，在多项基准测试中接近甚至超越GPT-4o的表现，证明了算法优化可以在一定程度上弥补硬件差距。

GPU作为AI算力的核心载体，其战略地位不言而喻。在国际供应链不确定性加剧、美国出口管制持续收紧的背景下，梳理国产GPU的技术路线、性能水平和落地进展，对理解中国算力自主化进程具有重要意义。

本文将从技术架构、性能参数、落地应用三个维度，系统分析国产GPU产业的现状与挑战。

## **概念辨析：CPU、GPU与GPGPU**

在深入分析之前，有必要厘清几个易混淆的概念。这些概念在媒体报道中常被混用，造成理解偏差。

### **CPU（中央处理器）**

CPU是服务器的"大脑"，擅长逻辑控制和串行运算，具有复杂的分支预测、乱序执行等机制。国产CPU代表包括：

- • **龙芯**：采用自研LoongArch指令集，主要用于政务、教育等领域
- • **飞腾**：基于ARM架构，用于服务器和PC
- • **鲲鹏**：华为基于ARM架构的服务器CPU
- • **海光**：基于AMD Zen架构授权的x86处理器

CPU主要负责通用计算任务，通常不参与大规模并行图形计算。在AI服务器中，CPU负责数据预处理、任务调度等控制逻辑，GPU/GPGPU负责并行计算。

### **GPU（图形处理器）**

GPU最初专为图形渲染设计，具有大量并行计算单元，后逐渐扩展至通用计算领域。国产GPU代表有：

- • **景嘉微**：产品主要用于军用显控和信创图形
- • **摩尔线程**：采用"全功能GPU"路线，同时覆盖AI计算和图形渲染

这类芯片保留了完整的图形管线（顶点处理、光栅化、像素着色等），可同时支持渲染和计算任务。摩尔线程的S系列显卡支持vGPU虚拟化，在云桌面、云游戏等场景有独特优势。

### **GPGPU（通用图形处理器）**

GPGPU专为AI训练和高性能计算设计，屏蔽了图形接口，专注于算力输出。这是当前数据中心最紧缺的芯片类型。国产代表包括：

- • **壁仞科技**：BR系列采用Chiplet技术
- • **天数智芯**：天垓/智铠系列
- • **海光DCU**：基于AMD CDNA架构

GPGPU采用与英伟达数据中心GPU类似的架构思路，在计算密度和能效比上持续优化，但不支持图形渲染功能。

### **NPU（神经网络处理器）**

NPU是专为AI推理优化的专用芯片，采用数据驱动并行计算架构。华为昇腾系列采用达芬奇架构，属于NPU范畴。虽然技术路线与GPU不同，但在应用场景上存在重叠，常被归为广义的"AI加速卡"阵营。

NPU的优势在于针对神经网络计算进行了深度优化，在特定AI任务上能效比更高；劣势是通用性不如GPGPU，难以支持科学计算等非AI任务。

## **群雄逐鹿：国产GPU厂商图谱**

![](https://pic3.zhimg.com/v2-faa06c87ced9c8f00bdc56918f8c7cb2_r.jpg)

图1：国产GPU厂商技术路线与发展历程

国产GPU厂商按技术路线可分为三大阵营：GPGPU阵营（通用计算）、全功能GPU阵营（计算+图形）、NPU阵营（神经网络处理器）。各阵营的产品定位、技术特点和商业化策略各不相同。

### **GPGPU阵营：专注通用计算**

GPGPU（通用图形处理器）专为AI训练和高性能计算设计，屏蔽了图形接口，专注于算力输出。这是当前数据中心最紧缺的芯片类型。

### **壁仞科技（BR系列）**

壁仞科技是国内最早实现Chiplet技术商用的GPU企业。BR100采用7nm制程与2.5D CoWoS封装，将两颗计算核心集成于同一硅中介层，创下当时全球通用GPU算力纪录。

BR100核心规格：

| 参数项 | 规格 |
| --- | --- |
| 制程工艺 | 7nm + Chiplet |
| 封装技术 | 2.5D CoWoS |
| FP32算力 | 256 TFLOPS |
| FP16算力 | 1024 TFLOPS |
| INT8算力 | 2048 TOPS |
| 显存 | 64GB HBM2e |
| 典型功耗 | 400W |

BR100的Chiplet设计是其最大亮点。通过将两颗计算核心封装在一起，在7nm制程受限的情况下实现了接近5nm单芯片的性能。这种技术路线在先进制程获取困难的情况下，为国产GPU提供了可行的性能提升路径。

BR106已实现量产，壁仞科技已在中国移动智算中心（哈尔滨）等项目实现规模化部署，并与三大运营商建立深度合作。

软件生态方面，壁仞自研BIRENSUPA平台兼容CUDA生态及主流AI框架，已完成通义千问等国产大模型适配，降低了客户迁移成本。

### **天数智芯（天垓/智铠系列）**

天数智芯是国内首家实现7nm GPGPU量产的企业。天垓100采用7nm工艺，集成240亿晶体管，从流片到量产仅用了一年左右时间。

天垓100核心规格：

| 参数项 | 规格 |
| --- | --- |
| 制程工艺 | 7nm |
| 晶体管数量 | 240亿 |
| FP32算力 | 47 TFLOPS |
| FP16算力 | 94 TFLOPS |
| 显存 | 32GB HBM2 |
| 典型功耗 | 300W |

天数智芯的核心竞争力在于量产能力和供应链稳定性。截至2025年6月，天数智芯已向超过290名客户交付超过5.2万片通用GPU产品，在金融、教育、科研领域有大量落地案例。2024年至2025年上半年，天数智芯通用GPU产品收入分别为3.7亿元和2.77亿元。

智铠100于2023年量产，专注推理场景，与天垓系列形成"训练+推理"的完整产品矩阵。天数智芯还拓展了AI算力解决方案业务，为客户提供软硬协同、训推一体的完整方案。

### **沐曦股份（曦云系列）**

沐曦股份对标AMD路线，专注通用计算。曦云C系列主攻训推一体，软件栈支持6000多个CUDA应用。

沐曦的优势在于较高的CUDA兼容度，降低了客户迁移成本。在DeepSeek爆火后，沐曦迅速宣布完成模型适配，展现了较快的软件生态响应能力。

### **海光信息（DCU系列）**

海光DCU采用GPGPU架构，基于AMD CDNA技术授权深度优化，是国内少数同时掌握CPU和DCU技术的厂商。

深算二号（Z100）核心规格：

| 参数项 | 规格 |
| --- | --- |
| 制程工艺 | 7nm |
| 架构 | CDNA深度定制 |
| FP32算力 | ~24 TFLOPS |
| FP16算力 | ~48 TFLOPS |
| FP64算力 | ~12 TFLOPS |
| 显存 | 32GB GDDR5 |
| 显存位宽 | 384bit |
| 典型功耗 | 350W |

海光DCU的核心优势在于与x86生态的高度兼容性。ROCm（Radeon Open Compute）平台与CUDA具有较高相似度，可实现对CUDA应用的无缝迁移。对于已有大量CUDA代码的用户，迁移至海光DCU的学习成本相对较低。

海光DCU已在中国移动、各大银行的数据中心规模化部署。2025年中国移动全球合作伙伴大会上，海光展示了与中国移动联合打造的"水利大模型一体机"，基于海光DCU提供算力支撑，已在洪水预警、水资源智能调度等场景落地。

### **全功能GPU阵营：计算+图形双栈**

全功能GPU同时覆盖AI计算和图形渲染，保留了完整的图形管线，技术难度最高，与英伟达路线最为接近。

### **摩尔线程（MTT系列）**

摩尔线程采用"全功能GPU"路线，同时覆盖AI计算和图形渲染。

摩尔线程产品演进：

- • **S10**：面向信创PC需求
- • **S3000**：服务云桌面场景
- • **S4000**：支撑千卡集群
- • **S5000**：构建万卡集群

S5000是摩尔线程当前旗舰AI训练卡，已实现万卡集群部署。2025年底开发者大会上，摩尔线程宣布下一代"花港"架构将于2026年发布，算力密度提升50%，支持FP4至FP64全精度计算，可支持十万卡以上规模智算集群。

"花港"架构的技术亮点包括：

- • 全精度端到端技术，特别优化FP8/FP6/FP4等低精度单元
- • 异步编程模型提升集群整体利用率
- • 新一代AI生成式渲染架构（AGR）与第二代光线追踪加速引擎

摩尔线程还规划了"华山"和"庐山"两条芯片路线：华山系列专注AI训推一体，庐山系列专攻高性能图形渲染，光线追踪性能提升50倍，瞄准3A游戏、CAD/CAE等专业场景。

### **景嘉微（JM系列）**

景嘉微是国内老牌GPU厂商，产品主要面向军用显控和信创台式机。JM9230等型号对标英伟达低端显卡，满足党政军办公和简单3D渲染需求，但在通用计算能力上相对薄弱。

景嘉微的优势在于进入时间早、客户关系稳定，在军用和信创市场有较高渗透率。但在AI训练、高性能计算等新兴领域，产品竞争力相对有限。

### **NPU阵营：神经网络处理器**

NPU（神经网络处理器）采用数据驱动并行计算架构，专为AI推理优化。虽然技术路线与GPU不同，但在应用场景上存在重叠。

### **华为昇腾（Ascend）**

昇腾系列是目前国产AI芯片的标杆产品，采用自研达芬奇架构。2025年一季度发布的昇腾910C核心规格如下：

| 参数项 | 规格 |
| --- | --- |
| 制程工艺 | 7nm |
| 架构 | 达芬奇3D Cube |
| FP16算力 | 800 TFLOPS |
| HBM容量 | 128GB |
| 内存带宽 | 3.2 TB/s |
| 互联带宽 | 784 GB/s |
| 典型功耗 | 400W |

华为在2025年全联接大会上公布了五年路线图：2026年Q1推出昇腾950PR、Q4推出950DT，2027年Q4推出昇腾960，2028年Q4推出昇腾970。昇腾950系列将支持FP8/FP4等更低精度计算，互联带宽提升至2TB/s，算力密度较910C提升50%以上。

昇腾的优势在于华为完整的软硬件生态。CANN（Compute Architecture for Neural Networks）异构计算架构提供了从算子开发到模型部署的全栈工具，MindSpore框架与昇腾芯片深度优化。在运营商智算中心、政务云等场景中，昇腾凭借生态完整性占据领先地位。

### **寒武纪（思元系列）**

寒武纪采用自研MLUarch架构，覆盖云端、边缘端、终端全场景。

思元370核心规格：

| 参数项 | 规格 |
| --- | --- |
| 架构 | MLUv02 |
| FP32算力 | 24 TFLOPS |
| INT8算力 | 128 TOPS |
| 能效比 | 1.8 TFLOPS/W |
| 内存带宽 | 1.2 TB/s |

思元590是旗舰级云端芯片：

| 参数项 | 规格 |
| --- | --- |
| 制程工艺 | 7nm |
| 架构 | MLUarch05 |
| NPU核心 | 128个 |
| FP16算力 | 256 TFLOPS |
| 显存 | 64GB HBM2 |
| 集群算力 | 8卡级联达2.048 PF |

寒武纪与字节跳动建立了深度合作关系。思元590性能对标英伟达A100，在部分大模型推理任务中性能达到A100的80%-90%，且功耗更低。

思元690将采用Chiplet异构集成方案，通过12nm+7nm混合封装突破制程限制，单卡算力密度较现行产品提升400%。

### **百度昆仑芯**

昆仑芯已发布多款云端全功能AI芯片。2025年百度世界大会上发布了新一代昆仑芯M系列芯片，并公布了未来五年产品路线图。

昆仑芯P800核心规格：

| 参数项 | 规格 |
| --- | --- |
| 制程工艺 | 7nm |
| FP16算力 | 345 TFLOPS |
| 显存 | 64GB HBM2e |
| 功耗 | 300W |

昆仑芯已成为少数在多场景实现万卡级规模部署的国产AI芯片厂商，在中国移动等智算中心项目中获得规模化应用。

### **阿里平头哥（含光/PPU系列）**

平头哥半导体是阿里巴巴旗下芯片公司，2019年发布首款AI推理芯片"含光800"，采用自研架构+算法协同设计模式，在ResNet-50测试中性能达78563 IPS。

2024年央视《新闻联播》曝光了平头哥最新研发的PPU（AI处理单元）芯片，主要参数：

| 参数项 | 规格 |
| --- | --- |
| 制程工艺 | 7nm |
| 显存 | 96GB HBM2e |
| 片间带宽 | 700 GB/s |
| 接口 | PCIe 5.0×16 |
| 功耗 | 400W |

平头哥PPU在显存容量（96GB）、片间带宽（700GB/s）、PCIe接口（5.0×16）等指标上已超越英伟达A800，与H20相当，功耗（400W）低于H20（550W），展现出更高的能效比。该芯片已在中国联通三江源绿电智算中心等项目落地。

### **字节跳动（SeedChip）**

字节跳动自2022年起布局芯片研发，目前已形成"AI芯片+端侧芯片"双线布局。

**AI芯片（SeedChip）**：

- • 项目代号SeedChip，专为AI推理任务设计
- • 计划2026年生产10万片，逐步提升至35万片
- • 采用ASIC路线，针对特定场景每年迭代
- • 已与博通合作开发，原计划台积电代工，现与三星洽谈代工事宜

**端侧芯片**：

- • PICO自研头显专用芯片已于2024年完成回片并量产
- • 主要用于MR场景高清高帧率视频实时处理
- • 系统端到端延迟低至约12毫秒

字节跳动2025年计划在AI基础设施投入超1600亿元人民币，其中超过一半用于购买海外AI芯片及推进自研芯片。作为寒武纪的最大客户，字节跳动在自研芯片量产前，主要依赖外采满足算力需求。

### **燧原科技、登临科技、芯动科技**

这些厂商主要聚焦AI推理和边缘计算场景，产品以低功耗、高性价比为特点。在特定垂直领域（如智能安防、自动驾驶边缘计算）有一定市场份额，但整体规模相对较小。

### **算力对比分析**

从FP16算力指标看，国产AI芯片已形成明显梯度：

**高端梯度（800+ TFLOPS）**：

- • 壁仞BR100：1024 TFLOPS，采用Chiplet技术实现突破
- • 华为昇腾910C：800 TFLOPS，达芬奇架构优化

这一梯度已接近英伟达H100水平（H100 FP16为989 TFLOPS），在特定场景下可实现对标替代。

**中端梯度（200-400 TFLOPS）**：

- • 百度昆仑芯P800：345 TFLOPS，是英伟达H20的2.3倍
- • 寒武纪思元590：256 TFLOPS
- • 摩尔线程S5000：约200 TFLOPS

这一梯度接近英伟达A100水平（A100 FP16为312 TFLOPS），适合中小规模训练和推理任务。昆仑芯P800在该梯度中表现突出，2024年出货量达6.9万片，在国内市场位列第三。

**入门梯度（50-100 TFLOPS）**：

- • 天数智芯天垓100：94 TFLOPS
- • 海光DCU Z100：48 TFLOPS

这一梯度适合推理任务和轻量级训练，在成本敏感场景有竞争力。

### **显存与带宽**

显存容量决定了可处理模型的规模。华为昇腾910C的128GB HBM处于领先地位，可支持更大规模的模型训练。阿里平头哥PPU以96GB HBM2e显存位居第二，已超越英伟达A800（80GB）。壁仞BR100、摩尔线程S5000、寒武纪思元590、百度昆仑芯P800的64GB显存，可满足大多数大模型训练需求。

内存带宽直接影响数据吞吐效率。昇腾910C的3.2TB/s带宽最高，海光DCU Z100的GDDR5带宽相对较低，在内存密集型任务中可能成为瓶颈。

### **功耗与能效**

国产GPU典型功耗在250W-400W之间，与英伟达同类产品相当。寒武纪思元590以250W功耗实现256 TFLOPS算力，能效比表现突出，适合大规模推理部署。

**中国电信、中国联通**：在AI服务器建设中，华为昇腾、海光、壁仞、天数智芯等国产芯片获得应用。

### **互联网大厂**

互联网大厂是GPU的主要应用场景，其技术选型对国产GPU产业发展具有重要影响。

**字节跳动**：与寒武纪建立合作，部署的寒武纪集群覆盖推荐、广告等核心业务场景。推荐系统对延迟敏感、对精度要求相对较低，是国产GPU的理想切入点。

**百度、阿里**：在自研芯片（昆仑芯、含光）的同时，也在采用国产GPGPU。在训练任务中，英伟达仍占主导；在推理任务中，国产GPU占比逐步提升。

**DeepSeek效应**：DeepSeek爆火后，国产芯片厂商纷纷宣布完成模型适配，包括昇腾、沐曦、壁仞、天数智芯、摩尔线程、海光信息、燧原科技、云天励飞、昆仑芯、海光等。这标志着国产算力与国产大模型的协同正在加速。DeepSeek-V3/R1的低成本训练模式，降低了对极致算力的依赖，为国产GPU提供了更多机会。

### **政务云与智算中心**

各地政府主导的智算中心通常会采用国产芯片，这是国产GPU的重要应用场景。

华为昇腾在各地智算中心建设中占据主导地位。科大讯飞、智谱AI等大模型企业均有采用昇腾芯片用于模型训练。"东数西算"工程的推进，为国产GPU提供了广阔的应用空间。

### **金融与关键行业**

金融行业对数据安全有严格要求，国产替代意愿较强。海光DCU凭借与x86生态的兼容性，在金融机构的数据中心算力底座建设中获得应用。

金融量化交易、风险分析等场景对双精度浮点（FP64）计算有较高要求。海光DCU在FP64性能上相对领先，适合这类科学计算场景。

壁仞科技的BR系列也在金融量化、科学仿真等领域获得应用。壁仞的BIRENSUPA平台支持主流金融计算框架，降低了迁移成本。

## **Chiplet技术：突破制程限制的国产方案**

![](https://pica.zhimg.com/v2-6a27b92efdc3a145c8ef496c85df630a_r.jpg)

图4：Chiplet技术架构解析

### **技术背景**

7nm以下先进制程的获取受限，是国产GPU面临的最大挑战之一。在这种情况下，Chiplet（芯粒）技术成为突破制程限制的重要路径。

Chiplet技术的核心思想是：将原本应该集成在一块硅晶片上的元件分割成若干部分，通过先进封装工艺重新集成到一个更大的芯片上。这种"化整为零"的思路，可以在保持制程工艺不变的情况下，直接提升整体性能。

### **技术实现**

壁仞BR100是国内最早实现Chiplet技术商用的GPU产品。其技术实现包括：

**2.5D CoWoS封装**：

- • 将两颗7nm计算核心封装在同一硅中介层（Silicon Interposer）上
- • 通过硅中介层实现芯片间的高速互联
- • 集成多颗HBM显存芯片，提供高带宽内存访问

**混合制程组合**：

- • 计算核心采用7nm工艺，保证计算密度
- • I/O芯片可采用12nm等成熟工艺，降低成本
- • 通过封装技术实现不同制程芯片的协同工作

### **优势与挑战**

**优势**：

1. 1. **突破制程限制**：在先进制程受限的情况下，通过封装技术实现性能提升
2. 2. **提升良率**：小芯片的制造良率高于大芯片，降低整体成本
3. 3. **灵活组合**：可根据需求灵活搭配计算核心、显存、I/O等模块
4. 4. **技术延续性**：可在现有制程上持续优化，延长技术生命周期

**挑战**：

1. 1. **封装成本**：2.5D CoWoS封装成本较高，需要与性能提升进行权衡
2. 2. **散热设计**：多芯片集成带来更高的热密度，对散热系统提出更高要求
3. 3. **设计复杂度**：Chiplet间的高速互联设计需要更强的系统级设计能力
4. 4. **供应链依赖**：先进封装产能主要集中在台积电等海外厂商

### **国产应用**

除壁仞BR100外，寒武纪思元690也将采用Chiplet方案，通过12nm+7nm混合封装突破制程限制。华为昇腾的部分产品也采用了类似的多芯片封装技术。

Chiplet技术已成为国产GPU在先进制程受限背景下的重要技术路线。随着国内封装能力的提升，这一技术路线的成本效益将进一步改善。

## **挑战与未来**

### **软件生态**

CUDA生态的垄断是国产GPU面临的最大挑战。英伟达经过十余年积累，建立了完整的软件生态护城河，包括：

- • **CUDA Toolkit**：编程模型、编译器、调试器
- • **cuDNN/TensorRT**：深度学习加速库
- • **RAPIDS**：数据科学加速库
- • **Omniverse**：仿真与协作平台

虽然各厂商都在推进CUDA兼容层：

- • 壁仞BIRENSUPA平台
- • 摩尔线程MUSA架构
- • 海光ROCm平台

但完全无缝迁移仍需时间。开发者习惯、现有代码库的迁移成本，是国产GPU推广的现实障碍。

解决思路包括：

1. 1. **兼容层优化**：持续提升CUDA兼容度，降低迁移成本
2. 2. **原生生态建设**：发展自有编程模型和工具链
3. 3. **开源社区合作**：与PyTorch、TensorFlow等框架深度合作
4. 4. **垂直场景突破**：在特定领域建立优势，逐步扩展

### **先进制程受限**

7nm以下先进制程的获取受限，是国产GPU性能追赶的主要障碍。当前国产GPU主要采用7nm工艺，而英伟达Blackwell已采用4nm工艺。

应对策略包括：

1. 1. **Chiplet技术**：通过封装技术弥补制程差距
2. 2. **架构优化**：通过架构创新提升单位晶体管效率
3. 3. **先进封装**：发展2.5D/3D封装能力
4. 4. **特色工艺**：在特定工艺节点上深度优化

### **量产能力与供应链**

芯片设计只是第一步，量产能力和供应链稳定性同样关键。天数智芯在2024年底至2025年初曾因美国出口管制规则影响，遭遇主要供应商暂停发货的危机。

建立自主可控的供应链体系，是国产GPU产业长期健康发展的基础。这包括：

- • 晶圆制造：中芯国际等国内厂商的能力提升
- • 先进封装：长电科技、通富微电等厂商的技术突破
- • 设备材料：光刻机、EDA工具等关键环节

### **量产能力与商业模式**

GPU研发需要大量资金投入，流片一次需数亿甚至十几亿元。国产GPU企业的商业化路径可能包括：

1. 1. **规模效应**：通过放量降低单位成本
2. 2. **解决方案**：提供软硬一体化的解决方案，提升附加值
3. 3. **生态服务**：通过软件服务、技术支持等获得持续收入

## **结语**

国产GPU产业正处于从"能用"到"好用"的关键阶段。华为昇腾910C、壁仞BR100等产品在算力指标上已接近国际主流水平，在特定场景下可实现规模化替代。

2026年将是国产GPU的关键年份：

- • 华为昇腾950系列将发布，算力密度进一步提升
- • 摩尔线程"花港"架构将登场，支持十万卡集群
- • 寒武纪思元690将采用Chiplet方案，单卡算力密度提升400%

软件生态的完善、供应链的自主可控、商业模式的可持续，将是下一阶段的核心议题。DeepSeek等国产大模型的崛起，为国产GPU提供了更多的应用场景和优化方向。

在AI算力需求持续爆发的背景下，国产GPU的崛起不仅是技术问题，更是产业安全和数字主权的重要保障。虽然道路曲折，但方向明确，国产GPU产业正在加速前进。
