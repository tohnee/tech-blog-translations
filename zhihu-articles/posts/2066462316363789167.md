AI Agent 正在改变科研工作的方式，而 Skill 则让这些 Agent 真正具备了完成科研任务的能力。

如今，科研 Skill 已经不只是帮你写论文，而是逐渐覆盖文献检索、实验设计、数据分析、科研绘图、论文投稿、返修等完整流程。最近，我整理了 GitHub 上热度最高的 10 个科研 Skill 项目，按 Star 数量从低到高做了一个盘点。

## **科研 Skill 排行榜（按 GitHub Star 从低到高）**

**10 Auto Empirical Research Skills ⭐ 3.1k**

主要面向经济学、金融学等实证研究，覆盖数据清洗、变量构建、计量分析、稳健性检验以及论文返修等完整流程，更强调研究过程的规范性和结果的可复现性。

🔗 GitHub：[https://github.com/brycewang-stanford/Auto-Empirical-Research-Skills](https://github.com/brycewang-stanford/Auto-Empirical-Research-Skills)

**9 PaperSpine ⭐ 4.4k**

与传统写作工具不同，它更关注论文的"骨架"。能够分析优秀论文的研究动机和论证逻辑，帮助梳理论点、优化结构，同时兼顾 LaTeX 文档安全修改，适合论文初稿完善阶段。

🔗 GitHub：[https://github.com/WUBING2023/PaperSpine](https://github.com/WUBING2023/PaperSpine)

**8 Supervisor Skills ⭐ 4.4k**

把科研导师的经验整理成可调用的 Skill，从选题、实验设计到投稿前检查，都能提供类似导师视角的分析，更适合作为科研过程中的 AI 副导师。

🔗 GitHub：[https://github.com/HKUSTDial/Supervisor-Skills](https://github.com/HKUSTDial/Supervisor-Skills)

**7 Claude Scholar ⭐ 4.9k**

覆盖科研工作的主要环节，包括文献管理、代码开发、实验分析、论文写作和投稿准备，并兼容 Claude Code、Codex 等多个 AI Agent。

🔗 GitHub：[https://github.com/Galaxy-Dawn/claude-scholar](https://github.com/Galaxy-Dawn/claude-scholar)

**6 Research Paper Writing Skills ⭐ 5.6k**

主要面向机器学习、计算机视觉和自然语言处理领域，重点优化论文结构、研究动机、实验分析以及学术表达，能够帮助研究成果快速整理成规范的论文。

🔗 GitHub：[https://github.com/Master-cai/Research-Paper-Writing-Skills](https://github.com/Master-cai/Research-Paper-Writing-Skills)

**5 AI Research SKILLs ⭐ 11.2k**

专注 AI 研究与工程实践，覆盖模型训练、强化学习、RAG、推理优化、MLOps、模型评测等热门方向，可将 Claude Code、Codex、Gemini 等工具扩展为专业的 AI 研究助手。

🔗 GitHub：[https://github.com/Orchestra-Research/AI-Research-SKILLs](https://github.com/Orchestra-Research/AI-Research-SKILLs)

**4 ARIS ⭐ 13.9k**

Auto-Research-In-Sleep 是一套轻量级科研自动化工作流，可围绕选题、实验、分析、论文写作以及多模型交叉审查构建完整流程，同时兼容 Claude Code、Codex、OpenClaw 等多种 Agent。

🔗 GitHub：[https://github.com/wanshuiyin/Auto-claude-code-research-in-sleep](https://github.com/wanshuiyin/Auto-claude-code-research-in-sleep)

**3 Nature Skills ⭐ 31.6k**

围绕高水平论文产出打造，集成论文阅读、文献检索、科研绘图、语言润色、审稿回复、基金申请、专利撰写等能力，各模块既可独立使用，也能串联成完整科研工作流。

🔗 GitHub：[https://github.com/Yuan1z0825/nature-skills](https://github.com/Yuan1z0825/nature-skills)

**2 Scientific Agent Skills ⭐ 31.9k**

目前功能最丰富的科研 Skill 库之一，内置 156 项科研技能，可连接 100 多个科学数据库，覆盖生物、医学、化学、药物研发等多个领域，同时支持文献检索、数据分析、科研写作和科研可视化。

🔗 GitHub：[https://github.com/K-Dense-AI/scientific-agent-skills](https://github.com/K-Dense-AI/scientific-agent-skills)

**1 Academic Research Skills ⭐ 39.8k**

目前 GitHub Star 数最高的科研 Skill 项目，也是综合能力最全面的一套方案。覆盖文献调研、系统综述、论文写作、同行评审、参考文献核查、论文修改等科研全过程，并支持多 Agent 协同工作，可直接搭建完整的科研工作流。

🔗 GitHub：[https://github.com/Imbad0202/academic-research-skills](https://github.com/Imbad0202/academic-research-skills)

**建议**

如果你刚开始接触科研 Skill，建议优先安装最后这三个项目：Academic Research Skills、Scientific Agent Skills 和 Nature Skills。它们基本覆盖了科研全过程，大多数科研任务都可以在这三套 Skill 的基础上完成，剩余项目则可以根据自己的研究方向按需补充。
