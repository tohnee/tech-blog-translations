> 刚刚，Claude Code 产品一姐 Cat Wu 官宣离职，不到两周，Anthropic 连失三员大将。<br>十多天前，她还在给离职的同事送行，这回轮到她自己了。

Claude Code 的元老，又走了一位。

这次是产品一姐 Cat Wu。

就在刚刚，她发帖官宣，上周五（10 月 30 日）是她在 Anthropic 的最后一天。

![](https://pic4.zhimg.com/v2-71bb272587c0f7993051e0ef7307e0c9_1440w.jpg)

算上她在内，Claude Code 不到两周痛失三员大将，而 Anthropic 10 月 26 日才公开递交招股书，正在冲刺上市。

10 月 24 日，Claude Code 二当家 Thariq Shihipar 和 Claude Code 桌面版之父 Anthony Morris 前后相隔 44 分钟官宣离职。

Cat Wu 还专门到 Thariq 的帖子底下送行，让他好好放个假。

![](https://pic4.zhimg.com/v2-9fea37ead4f5d283b2ae281c9fbed2c1_1440w.jpg)

告别帖里，Cat Wu 先回忆了自己当初是怎么「上头」的。

「两年前，Claude Code 还只是个内部小工具。我让它帮我搭建一个强化学习环境，前前后后带着它干了几十个小时，自己一行代码都没写。结果还真跑通了。我一下就上头了，转头加入了这个团队。」

刚发布那会儿，Claude 每次弹出权限请求，大多数人都要手动点同意，用它也主要是问问题、写写测试。

如今，默认就是交给 Claude 自己判断、自动批准。Claude 已经在执行大规模代码迁移、开发新产品了。

来自评论区老用户的感慨。

![](https://pic1.zhimg.com/v2-b7ddd31a2ae8020b938e7e9a1a53fbe2_1440w.jpg)

---

Cat Wu 是 Claude Code 的产品负责人，Claude 桌面端的办公智能体 Cowork（目前已合并入 Claude 主应用）也由她负责。

Claude Code 之父 Boris Cherny 带队把产品做出来，而功能优先级、怎么测试、什么时候上线，都由她来定。

![](https://pic4.zhimg.com/v2-f2a1e78b54fae6f0ba2a2506bfc2b3bf_1440w.jpg)

她是工程师出身，早年在 Scale AI、Dagster 当产品工程师，后来转行做过风险投资。

2024 年 8 月，她加入 Anthropic，起初在研究团队当产品经理，给研究员和真实客户牵线，后来才转到 Claude Code 团队。

她和 Boris，还有过一段闪电回归的往事。

2025 年 7 月初，两人一起被 Cursor 母公司 Anysphere 挖走，她去当产品负责人，Boris 当首席架构师兼工程负责人。结果只过了两周左右，两人又双双回到了 Anthropic。

这一次，她在告别帖里感谢了 Claude Code、Cowork 和 Claude Tag（Slack 里的 Claude）团队，也感谢了用户，最后一句是「期待看到你们接下来会做出什么！」

---

至于 Cat Wu 为什么离职、下一站去哪，暂时未知。

评论区网友们一片惋惜声。

不少人追问离职原因，也有网友开始起哄，一路点名到了 Anthropic CEO Dario Amodei 头上。

「下一个是谁，Boris？还是 Dario？😀」
