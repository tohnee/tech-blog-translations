当AI遇上边缘计算，如何让复杂的深度学习模型在移动设备上高效运行？本文将带你深入了解一个真实的医疗超声AI项目的端侧部署全流程。

## 一、项目背景：为什么要做端侧部署？

在医疗影像AI领域，我们面临着这样的挑战：

- **实时性要求：超声检查需要即时反馈，云端推理延迟不可接受**
- **隐私保护：患者医疗数据不能随意上传云端**
- **离线可用：基层医疗机构网络条件有限**
- **成本控制：大规模云端推理成本高昂**

因此，我们选择了**端侧部署**方案，让AI模型直接在Android设备上运行。

## 二、技术选型：构建高效推理引擎

#### 2.3 模型推理核心代码

```text
std::pair<int,float>runInference(constcv::Mat& image){
 // 1. 准备输入张量 [1, 3, 224, 224]
  std::vector<int64_t> input_shape = {1,3,224,224};
 std::vector<float>input_data(1*3*224*224);

 // 2. HWC -> CHW 格式转换
  std::vector<cv::Mat> channels;
  cv::split(image, channels);

 size_tchannel_size =224*224;
 for(intc =0; c <3; c++) {
   memcpy(input_data.data() + c * channel_size,
       channels[c].data,
       channel_size *sizeof(float));
  }

 // 3. 创建输入Tensor
  Ort::MemoryInfo memory_info =
    Ort::MemoryInfo::CreateCpu(OrtArenaAllocator,
                  OrtMemTypeDefault);

  Ort::Value input_tensor = Ort::Value::CreateTensor<float>(
    memory_info,
    input_data.data(),
    input_data.size(),
    input_shape.data(),
    input_shape.size()
  );

 // 4. 执行推理
 constchar* input_names[] = {"input"};
 constchar* output_names[] = {"output"};

 autooutputs = session->Run(
    Ort::RunOptions{nullptr},
    input_names,
    &input_tensor,
   1,
    output_names,
   1
  );

 // 5. 解析输出
 float* logits = outputs[0].GetTensorMutableData<float>();

 // Softmax
 std::vector<float>probs(4);
 floatmax_logit = *std::max_element(logits, logits +4);
 floatsum_exp =0.0f;

 for(inti =0; i <4; i++) {
    probs[i] = std::exp(logits[i] - max_logit);
    sum_exp += probs[i];
  }

 for(inti =0; i <4; i++) {
    probs[i] /= sum_exp;
  }

 // 6. 返回最优类别
 intpred = std::max_element(probs.begin(), probs.end())
       - probs.begin();

 return{pred, probs[pred]};
}

```
