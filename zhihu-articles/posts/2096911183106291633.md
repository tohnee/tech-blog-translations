上一篇写的是方法论，讲“四层建模法”。后台问得最多的一句是：“算子库到底长什么样，能不能给个模板？”

这篇就是模板。

先说清楚它是什么：把每一个高频题型压缩成一个“算子”，每个算子只记四件事——见到什么、怎么做、答案长什么样、什么时候不能用。

大多数人只记前三个。第四个（失效条件）才是分数差的地方。

下面这份清单，是我备考后期一直在用的版本。按章节排，你可以直接拿去抄，但更建议你自己重写一遍——抄一遍没用，写一遍才有用。

先看战场：数学一的分值结构

以近几年的卷面为例（以当年大纲为准）：

科目 占比 约合分值

高等数学 约 56% 84 分

线性代数 约 22% 33 分

概率论与数理统计 约 22% 33 分

题型结构：单选 10 题、填空 6 题、解答 6 题。

这个结构决定了两件事：

第一，高数是主战场，但不能只打高数。 线代和概率加起来 66 分，而且这两科的题型高度固定，是性价比最高的部分。很多人高数投入 70% 的时间，线代概率各 15%，最后在简单题上丢分。

第二，选填占 80 分。 这是最容易被忽视的分数池。解答题有过程分，选填是全对才给分。所以“算得准”比“算得深”更重要。

算子清单（前面那几行是最高频、最该先掌握的）

高等数学

① 未定式极限

见到：0/0、∞/∞、1^∞、0^0、∞^0

动作：0/0 和 ∞/∞ 按 等价无穷小 → 洛必达 → 泰勒 的顺序试；幂指型先取对数

输出：一个数，或者“不存在”

失效条件：加减法里不能随意做等价替换。 判据很简单——如果替换后主项抵消了，就不能换。sinx − x 直接换成 0 是错的，真实结果是 −x³/6

② 数列极限

见到：递推式、n 项和、n 项积

动作：递推用单调有界准则；n 项和考虑夹逼或定积分定义；出现根号连乘考虑取对数

失效条件：递推数列必须先证有界，再求极限。 直接令 aₙ₊₁ = aₙ = A 解方程，只有在极限存在的前提下才成立，这一步不写会被扣分

③ 中值定理证明

见到：结论里有 f′(ξ)、f(b)−f(a)、f″(ξ)

动作：一阶导用罗尔或拉格朗日；比值形式用柯西；二阶导用泰勒在极值点展开

核心动作：构造辅助函数。把结论整理成 F′(ξ) = 0 的形式，F 就是你要构造的

失效条件：注意开闭区间。 罗尔要求闭区间连续、开区间可导，少一个条件就不成立

④ 一元积分

见到：不定积分、定积分、反常积分

动作：换元（对称区间优先看奇偶性）→ 分部（按“反对幂指三”的顺序选 u）→ 有理函数做部分分式

失效条件：定积分换元必须换限。 这是最高频的低级失分点，没有之一。反常积分要先判敛散，再算值

⑤ 多元微分

见到：隐函数、方向导数、条件极值

动作：隐函数用公式法或两边求导；条件极值用拉格朗日乘数法；梯度是方向导数最大的方向

失效条件：分清“偏导存在”“可微”“连续”三者的关系。 这是选择题的常客——偏导存在推不出连续，偏导连续才能推可微

⑥ 重积分

见到：二重、三重

动作：先画区域，再选坐标系。圆/环用极坐标，柱体用柱坐标，球用球坐标；被积函数含 f(x) 且区域可分离时考虑交换积分次序

失效条件：极坐标的 r 和 θ 范围最容易错。 尤其圆心不在原点的圆，r 的上限是 2a·cosθ 这种形式，不是常数

⑦ 曲线曲面积分

见到：第二类曲线/曲面积分

动作：闭合或可补成闭合 → 格林公式/高斯公式；否则参数化直接算

失效条件：补线补面之后的符号。 补的那部分要单独减掉；如果区域内有奇点，必须挖洞，不能直接用公式

⑧ 级数

见到：判敛、求和函数、傅里叶

动作：正项级数用比值/根值/比较；交错用莱布尼茨；幂级数先求收敛半径，再逐项求导或积分凑成已知展开式

失效条件：区间端点必须单独判。 收敛半径只保证开区间，两个端点是两种情况，要分别代入原级数

⑨ 微分方程

见到：一阶、高阶常系数、欧拉方程

动作：一阶按类型套（可分离/齐次/一阶线性/伯努利）；高阶先解特征方程，非齐次用待定系数法设特解

失效条件：共振情况特解要乘 x。 如果非齐次的指数和特征根重了，特解形式必须多乘一个 x，漏了必错

线性代数

⑩ 行列式

见到：n 阶行列式求值

动作：识别特殊结构——范德蒙德、爪型、三对角、加边

失效条件：|kA| = kⁿ|A|，不是 k|A|。 n 是阶数，这个 n 次方是最高频的送分/送命点

⑪ 矩阵与秩

见到：秩的讨论、分块矩阵、伴随矩阵

动作：初等变换不改变秩；A·A* = |A|E 是万能钥匙

失效条件：r(A) 分三种情况*——r(A)=n 时 r(A*)=n；r(A)=n−1 时 r(A*)=1；r(A)<n−1 时 r(A*)=0。这三种必须背死

⑫ 向量组

见到：线性相关性、极大无关组

动作：拼成矩阵做初等行变换，看秩

失效条件：向量个数和维数不是一回事。 m 个 n 维向量，m > n 时必相关；m ≤ n 时要看秩

⑬ 线性方程组

见到：含参数的方程组、解的结构

动作：齐次解空间维数 = n − r(A)；非齐次通解 = 一个特解 + 齐次通解

失效条件：含参数必须分类讨论。 系数矩阵行列式为 0 和不为 0 是两种完全不同的情况，这是解答题的标准考点，不讨论直接丢一半分

⑭ 特征值与相似对角化

见到：能否对角化、求可逆矩阵 P

动作：先求特征值，再求每个特征值对应的线性无关特征向量个数；实对称矩阵一定可以正交对角化

失效条件：可对角化 ≠ 有 n 个不同特征值。 重根也可能可对角化，判据是“几何重数 = 代数重数”，不是“特征值互异”

⑮ 二次型

见到：化标准形、判正定

动作：配方法或正交变换；正定用顺序主子式全大于 0

失效条件：合同和相似是两回事。 合同看正负惯性指数，相似看特征值，别混

概率论与数理统计

⑯ 条件概率与全概率

见到：分情况、已知结果反推原因

动作：正推用全概率，反推用贝叶斯

失效条件：互斥 ≠ 独立。 互斥是两个不能同时发生，独立是 P(AB)=P(A)P(B)，除了零概率的情况，这两个概念几乎是对立的

⑰ 一维随机变量

见到：求分布函数、密度、期望

动作：分布函数法最万能——先写 F(x)=P(X≤x)，再分段讨论

失效条件：分段点要单独处理。 连续型在分段点的取值不影响分布函数，但离散型会影响

⑱ 二维随机变量

见到：联合分布、边缘分布、独立性

动作：联合 → 边缘靠积分/求和；条件分布 = 联合 / 边缘；独立性判据是 f(x,y)=f_X(x)f_Y(y)

失效条件：边缘分布推不出联合分布。 这是选择题最爱设的陷阱，除非已知独立

⑲ 随机变量函数的分布

见到：Y = g(X) 或 Z = X+Y

动作：分布函数法（先求 F_Y(y)=P(g(X)≤y)）永远有效；单调变换可以用公式法；和的分布用卷积

失效条件：非单调变换不能用公式法。 比如 Y = X²，必须用分布函数法分段

⑳ 数字特征

见到：期望、方差、协方差、相关系数

动作：D(X)=E(X²)−[E(X)]²；Cov(X,Y)=E(XY)−E(X)E(Y)

失效条件：不相关 ≠ 独立。 只有二维正态分布下两者等价，其他情况不相关推不出独立

㉑ 大数定律与中心极限定理

见到：近似计算、证明收敛

动作：求和近似用中心极限定理标准化；依概率收敛用切比雪夫或辛钦

失效条件：分清“依概率收敛”和“依分布收敛”。 前者是弱大数定律的语言，后者是中心极限定理的语言

㉒ 抽样分布

见到：χ²、t、F 的构造

动作：记死三个构造式——正态平方和 → χ²；正态 / √(χ²/n) → t；两个 χ² 之比 → F

失效条件：自由度。 样本方差里除以 n−1 就是为了配自由度，这里错一步后面全错

㉓ 参数估计

见到：矩估计、最大似然

动作：矩估计令样本矩 = 总体矩；最大似然先写 L(θ)，取对数再求导

失效条件：似然函数要对参数求导，不是对样本求导。 而且要先写清楚 L 的分段形式

㉔ 假设检验

见到：两类错误、拒绝域

动作：先写原假设和备择假设，再定统计量，再定拒绝域

失效条件：单侧和双侧的拒绝域不同。 而且“拒绝 H₀”和“接受 H₀”在统计上不对称，措辞要小心

这份清单怎么用

三条，按顺序：

1. 别抄，重写。 拿一张白纸，遮住右边，只看“见到什么”，自己写“怎么做”和“失效条件”。写不出来的，就是你的漏洞。

2. 每道错题，往清单里加一行。 不是抄题目，是抽象出“这题属于哪个算子、我错在哪个环节”。三个月后这份清单会变成你自己的版本，那才是真正值钱的东西。

3. 考前只看“失效条件”那一列。 因为“怎么做”你在考场上想得起来，“什么时候不能用”你想不起来。而后者，恰恰是命题人设陷阱的地方。

最后

一份清单救不了任何人。

真正有用的是建立清单的过程——你必须自己把题目拆开、归类、找出边界，这个动作本身就在塑造你的判断力。
