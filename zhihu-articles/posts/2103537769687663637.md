最近帮团队招一位做 **大模型推理系统 / 性能优化** 的同学（全职）。工作内容如下

**1. 大模型推理加速**

包括 Speculative Decoding、多 Token 预测、Draft Model、KV Cache 优化等。核心问题是如何在保证模型效果的前提下，进一步提升吞吐量、降低推理延迟。

**2. MoE 推理系统优化**

包括专家路由、Expert Cache、动态加载与调度等。如何在有限显存和带宽下，高效运行大规模 MoE 模型，是很有挑战的问题。

**3. 异构硬件推理优化**

包括模型量化、算子优化、内存管理，以及面向国产 CPU/GPU 等硬件平台的性能适配。

**希望找到什么样的同学？**

- 有不错的 C++ / Python 基础，具备 Linux 环境下的系统开发和性能分析能力。
- 对 LLM inference 有实际经验，或者深入研究过某个推理优化方向。
- 熟悉 vLLM、SGLang、TensorRT-LLM、llama.cpp、ONNX Runtime 等其中一种框架会很加分。
- 不要求以上方向全部精通。如果你在其中一个方向上做得比较深入，同时愿意研究底层系统问题，也非常欢迎交流。
