DeepSpeed是一个针对PyTorch开发的开源深度学习优化库。它的目标是减少训练LLM时的计算和内存开销,通过更好地利用现有硬件的并行性来加速分布式模型的训练。 DeepSpeed进行了优化,可以实现低延迟和高吞吐量的训练。它使用Zero Redundancy Optimizer(简称ZeRO)技术,可以训练超过万亿参数规模的模型。主要功能包括混合精度训练、单机多卡训练、多机分布式训练,以及自定义的模型并行训练。

本文将对官方入门DeepSpeed案例[HelloDeepSpeed](https://github.com/microsoft/DeepSpeedExamples/tree/master/training/HelloDeepSpeed)对代码进行讲解，分别介绍无DeepSpeed的 fine-tuning和结合DeepSpeed的fine-tuning，帮助大家快速入门DeepSpeed。

本文会分为两个部分，

- 第一个部分，介绍不使用DeepSpeed来训练一个Roberta模型做Masked Language Modeling(MLM)任务
- 第二个部分，介绍集成DeepSpeed，做更高效的训练，比如开启混合精度训练，使用ZeRO等。

代码的主要的功能包括:

1. 创建数据集的相关函数,包括遮盖文本的masking函数,以及生成无限数据流的InfiniteIterator
2. 创建模型的相关函数,包括自定义的RobertaMLMModel,其中的LM prediction只在masked tokens上进行,可以节省计算资源
3. 实验管理的相关函数,包括创建实验目录,保存参数配置、Git信息等,方便复现实验
4. 检查点保存和加载的相关函数,可以恢复训练
5. 主要的训练函数train,将上述模块拼接起来,构建数据集、模型、优化器,并进行训练迭代。有定期保存检查点、记录日志与Tensorboard等功能

主要的可配置超参数包括:mask比例、替换比例、序列长度、模型大小、训练批大小、学习率等。 这个代码遵循了比较好的工程实践,模块化,参数化,易于扩展与迁移。总体来说,代码质量比较高,基本上涵盖了Transformer在MLM任务上的训练需要的主要组件。

接下来，我们看一下train函数的输入和返回值。

train函数的输入变量为：

- checkpoint_dir: checkpoint保存目录
- load_checkpoint_dir: 加载检查点的目录
- 注意：以上两个参数只能配一个，如果使用checkpoint_dir，则是新建一个实验，如果使用load_checkpoint_dir，则是加载之前的实验
- mask_prob: 掩码比例，也就是掩盖多少比例的token，token会被转换为mask token
- random_replace_prob: 随机替换比例，也就是掩盖的token中，有多少用随机token代替，而不是mask token
- unmask_replace_prob: 原位保留比例 ，也就是掩盖的token中，有多少不用随机token代替，保持mask token
- max_seq_length: 最大序列长度
- tokenizer: 用什么tokenizer
- num_layers: Transformer层数
- num_heads: 多头attention的头数
- ff_dim: FeedForward层的维度
- h_dim: 隐层的维度
- dropout: Dropout的概率
- batch_size: Batch size
- num_iterations: 总迭代step
- checkpoint_every: 隔多少个step保存一次
- log_every: 隔多少step打印日志
- local_rank: 使用的GPU编号，默认为-1，也就是cpu，**建议在运行的时候设置为0，来使用GPU**

返回值:

- final_experiment_dir: 最终的实验目录，里面包含了该词训练实验的所有主要参数,涵盖了数据集、模型结构、训练超参等等的记录。

首先看masking_function。

```python
def masking_function(
        text: str,
        tokenizer: TokenizerType,
        mask_prob: float,
        random_replace_prob: float,
        unmask_replace_prob: float,
        max_length: int,
) -> Tuple[List[int], List[int]]:
    """Given a text string, randomly mask wordpieces for Bert MLM
    training.
​
    Args:
        text (str):
            The input text
        tokenizer (TokenizerType):
            The tokenizer for tokenization
        mask_prob (float):
            What fraction of tokens to mask
        random_replace_prob (float):
            Of the masked tokens, how many should be replaced with
            random tokens (improves performance)
        unmask_replace_prob (float):
            Of the masked tokens, how many should be replaced with
            the original token (improves performance)
        max_length (int):
            The maximum sequence length to consider. Note that for
            Bert style models, this is a function of the number of
            positional embeddings you learn
​
    Returns:
        Tuple[List[int], List[int]]:
            The masked token ids (based on the tokenizer passed),
            and the output labels (padded with `tokenizer.pad_token_id`)
    """
    # Note: By default, encode does add the BOS and EOS token
    # Disabling that behaviour to make this more clear
    # 对输入文本进行tokenize,并添加特殊标记<BOS>和<EOS>，也就是开始和结束符，并让它们最长不超过max_length个token
    tokenized_ids = ([tokenizer.bos_token_id] +
                     tokenizer.encode(text,
                                      add_special_tokens=False,
                                      truncation=True,
                                      max_length=max_length - 2) +
                     [tokenizer.eos_token_id])
    # 记录tokenize之后的序列长度
    seq_len = len(tokenized_ids)
    # 将tokenized_ids转为numpy数组
    tokenized_ids = np.array(tokenized_ids)
    # mask标记，首先初始化全为False，最后要的结果是，如果哪个位置的token被mask掉，那么subword_mask对应位置为True
    subword_mask = np.full(len(tokenized_ids), False)
    
    # Masking the BOS and EOS token leads to slightly worse performance
    # 如果mask的是BOS和EOS，会稍微影响性能，因此只在[1,len(subword_mask)-1]这个区间搜索，避开BOS/EOS
    low = 1
    high = len(subword_mask) - 1
    
    # mask_choices = [1,2,3,...,high-1]
    mask_choices = np.arange(low, high)
    # 这些字符里有多少个要被mask掉，至少要有1个
    num_subwords_to_mask = max(
        int((mask_prob * (high - low)) + np.random.rand()), 1)
    # 在[1,2,3,...,high-1]中，随机选num_subwords_to_mask个做mask
    # 并把subword_mask对应的下标设置为True，它代表对应哪个位置要做mask
    subword_mask[np.random.choice(mask_choices,
                                  num_subwords_to_mask,
                                  replace=False)] = True
​
    # Create the labels first
    # 构造标签,长度和tokenized_ids，初始值都为 tokenizer.pad_token_id
    labels = np.full(seq_len, tokenizer.pad_token_id)
    # 接着，把labels中要做mask的位置赋值为对应的tokenized_ids的值
    labels[subword_mask] = tokenized_ids[subword_mask]
    # tokenized_ids要做mask的位置赋值为tokenizer.mask_token_id，隐藏起来
    tokenized_ids[subword_mask] = tokenizer.mask_token_id
    
    # Now of the masked tokens, choose how many to replace with random and how many to unmask
    # 首先把随机或unmask的概率加起来
    rand_or_unmask_prob = random_replace_prob + unmask_replace_prob
    # 如果这个概率>0，那么执行下面的内容
    if rand_or_unmask_prob > 0:
        # rand_or_unmask是一个bool数组
        # 首先要subword_mask为True，且生成len(tokenized_ids)个[0, 1]之间的随机数，且这个数小于rand_or_unmask_prob
        # 两者都为True，则rand_or_unmask数组对应的bool值为True
        # 所以subword_mask为True的token中，会有rand_or_unmask_prob的概率被选中为对应的rand_or_unmask为True
        rand_or_unmask = subword_mask & (np.random.rand(len(tokenized_ids)) <
                                         rand_or_unmask_prob)
        # 如果random_replace_prob是0，那么全部选中的rand_or_unmask都是做unmask
        if random_replace_prob == 0:
            unmask = rand_or_unmask
            rand_mask = None
        # unmask_replace_prob是0，那么全部选中的rand_or_unmask都是做rand_mask
        elif unmask_replace_prob == 0:
            unmask = None
            rand_mask = rand_or_unmask
        # 如果都不是0，那么
        else:
            # unmask的概率是 unmask_replace_prob / rand_or_unmask_prob
            unmask_prob = unmask_replace_prob / rand_or_unmask_prob
            # 生成len(tokenized_ids)个[0,1]之间的随机数，并判断其是否小于unmask_prob
            # 也就是unmask_prob概率的token会被选中
            decision = np.random.rand(len(tokenized_ids)) < unmask_prob
            # 那么就要对这些被选中的token做unmask
            unmask = rand_or_unmask & decision
            # 剩下的则是最rand musk
            rand_mask = rand_or_unmask & (~decision)
        # 如果unmask存在，那么tokenized_ids会被赋回真实的值，真实的值可用从labels中获取
        if unmask is not None:
            tokenized_ids[unmask] = labels[unmask]
        # 如果rand_mask存在，那么给其随机赋值
        if rand_mask is not None:
            # weights是个向量，为tokenizer.vocab_size个1
            weights = np.ones(tokenizer.vocab_size)
            # weights全部的special_ids(特殊符号)为0
            weights[tokenizer.all_special_ids] = 0
            # 除了特殊符号外的每个token被选中的概率为 1/weights.sum()
            probs = weights / weights.sum()
            # num_rand为随机mask的个数
            num_rand = rand_mask.sum()
            # 在tokenizer.vocab_size标中选择num_rand个值，切选择每个值的概率为probs，把它赋给tokenized_ids[rand_mask]
            tokenized_ids[rand_mask] = np.random.choice(tokenizer.vocab_size,
                                                        num_rand,
                                                        p=probs)
    # 返回tokenized_ids和labels
    return tokenized_ids.tolist(), labels.tolist()
```

```python
def collate_function(batch: List[Tuple[List[int], List[int]]],
                     pad_token_id: int) -> Dict[str, torch.Tensor]:
    """Collect a list of masked token indices, and labels, and
    batch them, padding to max length in the batch.
    """
    # 计算这batch中最长token最多的序列的长度
    max_length = max(len(token_ids) for token_ids, _ in batch)
    # 对每个样本的token_ids做padding,使用pad_token在后面补全,使得每个token_ids的长度都相同，方便计算。
    padded_token_ids = [
        token_ids +
        [pad_token_id for _ in range(0, max_length - len(token_ids))]
        for token_ids, _ in batch
    ]
    # 对每个样本的label也做padding,补全到max_length的长度，保证长度它们相同。
    padded_labels = [
        labels + [pad_token_id for _ in range(0, max_length - len(labels))]
        for _, labels in batch
    ]
    # 将经过padding的token_ids转成LongTensor类型
    src_tokens = torch.LongTensor(padded_token_ids)
    # 将labels转成LongTensor类型
    tgt_tokens = torch.LongTensor(padded_labels)
    # 构建attention mask,标记出非pad部分为1
    # src_tokens.ne(pad_token_id) 输出的是bool值，等于pad_token_id为false，不等于为true,然后再转换成LongTensor
    attention_mask = src_tokens.ne(pad_token_id).type_as(src_tokens)
    # 返回一个字典,包含经过padding后的src_tokens,tgt_tokens,和attention_mask。
    return {
        "src_tokens": src_tokens,
        "tgt_tokens": tgt_tokens,
        "attention_mask": attention_mask,
    }
```

- InfiniteIterator

之前它被用在`return InfiniteIterator(dataloader)`

它的代码很简单，就是每次在迭代到最后的时候，重新从头迭代，保证可用无限迭代。

```python
T = TypeVar("T")
​
class InfiniteIterator(object):
    def __init__(self, iterable: Iterable[T]) -> None:
        self._iterable = iterable
        self._iterator = iter(self._iterable)
​
    def __iter__(self):
        return self
​
    def __next__(self) -> T:
        next_item = None
        try:
            next_item = next(self._iterator)
        except StopIteration:
            self._iterator = iter(self._iterable)
            next_item = next(self._iterator)
        return next_item
```

RobertaMLMModel类的代码如下，forward过程为：

- 用encoder输出，输出的shape: (batch, seq_len, h_dim)

```python
class RobertaMLMModel(RobertaPreTrainedModel):
    def __init__(self, config: RobertaConfig, encoder: RobertaModel) -> None:
        super().__init__(config)
        self.encoder = encoder
        self.lm_head = RobertaLMHeadWithMaskedPredict(
            config, self.encoder.embeddings.word_embeddings.weight)
        self.lm_head.apply(self._init_weights)
​
    def forward(
            self,
            src_tokens: torch.Tensor,
            attention_mask: torch.Tensor,
            tgt_tokens: torch.Tensor,
    ) -> torch.Tensor:
        """The forward pass for the MLM task
​
        Args:
            src_tokens (torch.Tensor):
                The masked token indices. Shape: (batch, seq_len)
            attention_mask (torch.Tensor):
                The attention mask, since the batches are padded
                to the largest sequence. Shape: (batch, seq_len)
            tgt_tokens (torch.Tensor):
                The output tokens (padded with `config.pad_token_id`)
​
        Returns:
            torch.Tensor:
                The MLM loss
        """
        # shape: (batch, seq_len, h_dim)
        sequence_output, *_ = self.encoder(input_ids=src_tokens,
                                           attention_mask=attention_mask,
                                           return_dict=False)
​
        pad_token_id = self.config.pad_token_id
        # (labels have also been padded with pad_token_id)
        # filter out all masked labels
        # shape: (num_masked_tokens,)
        #  (tgt_tokens != pad_token_id) 对tgt_tokens进行判断,找到不是padding标记pad_token_id的位置,生成一个bool类型的tensor。
        #  .view(-1) 将其reshape为一维。
        # torch.nonzero() 找到bool tensor中非零元素(True)的索引。
        #  .view(-1) 将索引reshape为一维。
        # 这样最终得到的masked_token_indexes就是一个一维tensor,包含了目标标记tgt_tokens中所有非padding标记的索引。
        # 之所以要这么做的是因为:
        # 1. tgt_tokens中包含了一些填充标记pad_token_id。
        #2. 在计算masked language model的损失时,我们只考虑那些真正的标记,忽略填充标记。
        #3. 所以需要通过上面的操作提取出非填充标记的索引,然后在损失计算时只基于这些索引对应的标记来计算。
        #这行代码实现了从tgt_tokens中提取真实标记索引的功能,是计算masked language model损失的重要前置步骤。
        masked_token_indexes = torch.nonzero(
            (tgt_tokens != pad_token_id).view(-1)).view(-1)
        
        # shape: (num_masked_tokens, vocab_size)
        # 下面代码是使用MLM(masked language model)预测头模块来生成mask token的预测分数。主要包含以下步骤:
        # self.lm_head是masked language modeling的预测头，预测头模块只基于被mask的token的表示来计算输出。
        # 终输出prediction_scores,其shape为(num_masked_tokens, vocab_size),每行是一个mask token在词表上对应的预测分数。
        # 所以这一步使用了专门的预测头模块,基于编码器输出的特征和被mask的token的索引来计算mask token的预测分布。这是masked language model任务的关键之处,相当于只预测被mask的token,而忽略其他位置。后续会基于这个预测分布和目标token计算损失,优化模型参数。
        prediction_scores = self.lm_head(sequence_output, masked_token_indexes)
        # shape: (num_masked_tokens,)
        # 根据masked_token_indexes中的索引,从tgt_tokens中选择出相应的目标token。具体分为以下几步:
        # 1. tgt_tokens.view(-1) 将目标标记展平成1维。
        # 3. torch.index_select根据所有被mask的索引,从展平后的tgt_tokens中选择出相应的标记。
        # 4. 因此目标标记target的shape为(num_masked_tokens,),包含所有被mask的token的目标id。
        # 这个操作的目的是获取masked language modeling任务中所有被预测的token的真实id,以便后续计算预测得分prediction_scores和目标target之间的损失。
        # 只有被mask的token才会贡献损失,而该操作正是提取出这些被mask的token的目标id。后面交叉熵损失函数只基于这些被mask的token来进行计算。
​
        # 总之,这行代码实现了根据masked token的索引,从目标标记中选取对应的目标id,为计算损失准备目标值target。
        target = torch.index_select(tgt_tokens.view(-1), 0,
                                    masked_token_indexes)
        
        # 交叉熵损失函数
        loss_fct = nn.CrossEntropyLoss(ignore_index=-1)
        # 计算交叉熵损失
        masked_lm_loss = loss_fct(
            prediction_scores.view(-1, self.config.vocab_size), target)
        # 返回交叉熵损失
        return masked_lm_loss
```

def log_dist(message: str,
             ranks: List[int] = [],
             level: int = logging.INFO) -> None:
    """Log messages for specified ranks only"""
    my_rank = int(os.environ.get("RANK", "0"))
    if my_rank in ranks:
        if level == logging.INFO:
            logger.info(f'[Rank {my_rank}] {message}')
        if level == logging.ERROR:
            logger.error(f'[Rank {my_rank}] {message}')
        if level == logging.DEBUG:
            logger.debug(f'[Rank {my_rank}] {message}')
​

log_dist是用于在分布式训练时,打印指定rank的日志信息。

其主要逻辑是:

1. 获取当前进程的rank,一般从环境变量RANK中获取。
2. 判断如果当前rank在指定的ranks列表中,则打印日志。
3. 支持打印不同级别的日志,如INFO、ERROR、DEBUG。
4. 打印日志时会在前面加上`[Rank ${my_rank}]`的标记。

这样在分布式训练时,可以只在指定的进程打印日志,避免日志重复打印。

举个例子,在单机多卡训练时:

```python
log_dist("Loss is %f" % loss, ranks=[0]) 
```

这条日志只会在rank=0的进程中打印,也就是主GPU上。

而:

```python
log_dist("Gradient norm is %f" % grad_norm, ranks=[0,1,2,3])
```

这条日志会在所有4个GPU进程上打印出来。

因此log_dist提供了一种控制分布式训练日志打印的简单机制。

接下来是创建DeepSpeed引擎。

首先创建了一个字典，ds_config,里面是DeepSpeed相关的配置。主要有:

1. `train_micro_batch_size_per_gpu`: 每个GPU上的micro-batch大小。
2. `optimizer`: 使用的优化器类型和超参数。
3. `dtype`: 是否启用混合精度。
4. `zero_optimization`: ZeRo优化器的配置。控制优化器状态存储在CPU还是GPU等。

接着，做`deepspeed.initialize`初始化DeepSpeed引擎。把模型,模型参数,以及ds_config输入给它。并做初始化。

它做的内容大致包括:

1. 根据`ds_config` 给模型包一层,改变计算图。比如使用混合精度,使用ZeRo优化器等。
2. 初始化优化器,将参数分区到不同GPU。
3. 模型和优化器进行状态初始化。
4. 返回初始化好的模型引擎,可以直接用于训练。

所以 `ds_config`定义了DeepSpeed的运行配置,在用`deepspeed.initialize`根据这些配置进行初始化并包装模型,使模型运行加速。

两者结合起来,可以轻松加速PyTorch程序,使用分布式/混合精度训练等DeepSpeed功能。
