今天早上腾讯发布了个包： `@tencent-weixin/openclaw-weixin` ，提供了一个合法的、不会封号的接口，让你可以通过 API 收发微信消息。

我一看就来劲了。这东西如果能包装成 MCP Server，那任何支持 MCP 的 AI——Claude、OpenCode、Cursor——都能直接变成微信机器人。不用逆向，不用 Hook，不用企业资质，扫码登录就能用。

等了半天，发现很多大佬都用 Claude Code 的 Tunnel 功能让 Claude Code 也能在微信上跑，但都依赖 Claude Code，没有独立的 MCP Server 实现。

于是我花了半天时间搓了一个出来。

## 它是什么？

简单来说它把微信的 QClaw 接口翻译成了 MCP 协议的标准工具。

你的 AI 客户端（Claude Desktop、OpenCode、Cursor 等）只需要知道怎么调用 MCP 工具，就能自动收发微信消息。整个过程不需要你写任何代码，配一行 JSON 就行。

它的工作方式是这样的：

- 你给 Agent 发一条微信消息
- Agent 自动收到这条消息
- Agent 思考、处理、生成回复
- 回复通过微信自动发送给你
- 整个过程中，你的微信会显示「对方正在输入...」

下面我详细讲讲怎么用它。

---

## 准备工作

你只需要一样东西： [Bun](https://bun.sh/) 。

Bun 是一个超快的 JavaScript 运行时，安装很简单，macOS / Linux 一行命令搞定，Windows 也有安装包。装好之后，剩下的全交给 `bunx` ——它会自动从 npm 下载并运行需要的包，你不需要手动 clone 仓库，也不需要手动安装任何东西。

---

## 接入 Claude Code

Claude Code 使用 CLI 命令来添加 MCP Server，一行搞定：

```text
claude mcp add --transport stdio wechat -- bunx mcp-wechat-server
```

添加成功后，你可以在 Claude Code 里输入 `/mcp` 查看已连接的 MCP Server 列表。

Claude Code 也支持直接编辑配置文件。在你项目的根目录下创建 `.mcp.json` ：

```text
{
  "mcpServers": {
    "wechat": {
      "command": "bunx",
      "args": ["mcp-wechat-server"]
    }
  }
}
```

两种方式选一种就行。

## 接入 Claude Desktop

Claude Desktop 通过 JSON 配置文件来添加 MCP Server。

打开 Claude Desktop 的配置文件：

- **macOS** : `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows** : `%APPDATA%\Claude\claude_desktop_config.json`

在文件中添加：

```text
{
  "mcpServers": {
    "wechat": {
      "command": "bunx",
      "args": ["mcp-wechat-server"]
    }
  }
}
```

保存，重启 Claude Desktop。

## 接入 OpenCode

OpenCode 是一个终端里的 AI 编程助手，原生支持 MCP。

在你的项目根目录下创建或编辑 `opencode.json` ：

```text
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "wechat": {
      "type": "local",
      "command": ["bunx", "mcp-wechat-server"],
      "enabled": true
    }
  }
}
```

重启 OpenCode。之后你可以在提示词里用 `use wechat` 来调用微信相关的工具。

## 第一次使用：扫码登录

配置好之后，第一次使用需要扫码登录。

你只需要跟 AI 说一句：「帮我登录微信」。AI 会自动调用 `login_qrcode` 工具，然后执行以下操作：

1. 在你的终端里展示一个二维码（彩色字符画）
2. 生成一张二维码图片，路径是 `~/.mcp-wechat-server/qrcode.png`
3. 给你一个链接，你可以复制到微信里打开

你用微信扫其中任何一个就行。

扫码之后，AI 会自动调用 `check_qrcode_status` 来确认登录状态。确认成功后，你的微信就接入了。

![](https://pica.zhimg.com/v2-cd93aba601cf2fd613e8959e5f7c23a4_r.jpg)

**登录只需要做一次。** 之后所有的凭证都保存在 `~/.mcp-wechat-server/account.json` 里，哪怕你关掉电脑、重启 AI 客户端，都不需要重新登录。

## 日常使用

登录之后，你什么都不用管了。AI 会自动处理一切。

### 接收消息

AI 会在后台持续监听你的微信新消息。你给它发一条「今天北京天气怎么样」，AI 立刻就能收到。

### 自动回复

收到消息后，AI 会自动开始处理。处理的过程中，你的微信会显示「对方正在输入...」，就像真的有个人在打字一样。

AI 处理完之后，回复会直接发到你的微信上。

## 一些实用技巧

### 让 Agent 始终使用微信与你聊天

只需要输入以下的提示词即可：

> 接下来请你用 wechat 工具和我聊天，当你完成相应任务后就一直等待直到我用微信给你发送新消息 
> 

### 同时对多个用户服务

如果你有多个微信号（每个微信号对应不同的 bot 实例），只需要在不同目录下启动不同的 mcp-wechat-server 实例就行。每个实例用独立的配置文件。

### 查看数据存储

所有数据都在 `~/.mcp-wechat-server/` 目录下：

- `account.json` — 登录凭证
- `state.json` — 消息游标（记录你已经收到了哪些消息）
- `qrcode.png` — 上一次生成的二维码图片

如果你想把数据清空重新来过，删掉这个目录就行。或者跟 AI 说「帮我退出登录」，它会自动清理所有数据。

## 常见问题

### 扫码后页面一直加载怎么办？

这是最常见的问题。大概率是你的手机 WiFi 网络有问题（我也不知道为什么，反正切换到移动数据就好了）

**解决方案：关闭手机 WiFi，切换到移动数据网络，然后重新扫码。**

### 登录状态会过期吗？

会的。如果长时间没有活动，登录会话会失效。到时候重新扫码就行。不过你不用担心消息丢失——消息游标是独立持久化的，重新登录后会从上次的位置继续拉取。

### AI 不回消息怎么办？

可能的原因：

1. MCP 客户端的工具调用超时时间太短。
2. AI 没有主动调用 `get_messages` 来监听消息。你可以明确跟它说「请持续监听我的微信消息」。
3. MCP Server 没有正常启动。检查终端日志有没有报错信息。

## 六个工具一览

如果你想更精细地控制 AI 的行为，可以直接让 AI 调用这些工具：

| 工具 | 作用 | 使用场景 |
| --- | --- | --- |
| login_qrcode | 生成登录二维码 | 首次使用或重新登录 |
| check_qrcode_status | 检查扫码状态 | 扫码后自动调用 |
| logout | 退出登录并清除数据 | 切换账号或重置 |
| get_messages | 拉取新消息 | 持续监听，wait=true 阻塞等待 |
| send_text_message | 发送文本消息 | AI 自动调用回复 |
| send_typing | 显示/取消打字状态 | AI 收到消息后自动调用 |

你不需要记这些。正常使用的话，AI 会自己决定什么时候调用哪个工具。
