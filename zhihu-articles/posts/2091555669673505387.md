刷 GitHub，能明显感觉到 AI Agent 的玩法变了。

开发者开始同时运行 Codex、Claude Code、OpenCode，给不同 Agent 分配独立工作区。

于是，8 月涨得最快的一批项目中，出现了大量 Agent 工作台、编程 Agent 和任务控制层。如何调度、约束和管理 Agent，成了开发者最关心的问题。

**01**

**项目简介**

- **Orca：同时指挥一群编程 Agent**

Orca 是一套多 Agent 调度工作台，可以同时运行 Codex、Claude Code、OpenCode 和 Pi，并为每个 Agent 创建独立的 Git worktree。

开发者可以把不同任务交给多个 Agent 并行处理，统一查看进度、代码改动和运行状态。Orca 支持桌面端、移动端和 VPS 部署，出门后也能继续查看任务。

已经同时使用两三款编程 Agent 的开发者，会更容易感受到 Orca 的价值。

![](https://pic3.zhimg.com/v2-c3fd568b6ea4116d756ca3711edd0c40_r.jpg)

```text
项目地址：https://github.com/stablyai/orca
```

- **Pi：可以自己改造自己的编程 Agent**

Pi 是一套面向开发者的 Agent Harness，提供完整的编程 Agent CLI、Agent 运行时、工具调用、状态管理、多模型接口和终端 UI。

Pi 最有意思的设计是自扩展能力。开发者可以为 Pi 添加命令、工具、技能和提示词，让 Pi 逐渐适应团队自己的开发流程。

项目还统一封装了多个模型供应商，适合需要同时接入 OpenAI、Anthropic、Google 或本地模型的开发者。

![](https://pic4.zhimg.com/v2-7ee7a53c813c27bca2e076f515df0135_r.jpg)

```text
项目地址：https://github.com/earendil-works/pi
```

- **OpenMAIC：清华多智能体课堂**

OpenMAIC 来自清华大学 MAIC 团队，目标是把一个主题或一组资料变成完整的 AI 课堂。

输入学习主题后，OpenMAIC 可以生成课程内容、幻灯片、测验、互动模拟和项目制学习任务。课堂里还会出现 AI 教师和 AI 同学，围绕课程内容展开讨论。

8 月发布的 1.0 版本加入了 Agent 工作台、持久化会话、教学资料管理和 20 个内置技能，已经具备一套垂直 Agent 产品的基本形态。

![](https://pic4.zhimg.com/v2-e488199d4c80ba825e2ddc6d56706f5d_r.jpg)

```text
项目地址：https://github.com/THU-MAIC/OpenMAIC
```

- **Oh My Pi：把 IDE搬进终端**

Oh My Pi 是 Pi 的一个增强分支，重点补上 IDE 级代码理解和调试能力。

项目支持超过 60 家模型供应商，内置 31 种工具，并接入 LSP 和 DAP。Agent 可以查询符号定义、查找引用、诊断类型错误，也能设置断点和读取调试状态。

Rust 核心和跨平台支持让 Oh My Pi 在 Windows、macOS 和 Linux 上都能运行。对于习惯终端操作，又希望 Agent 获得 IDE 上下文的开发者，Oh My Pi 很有吸引力。

![](https://pic4.zhimg.com/v2-eb0c5e614b2831c93ae9dc8fd0fedb97_r.jpg)

```text
项目地址：https://github.com/can1357/oh-my-pi
```

- **T3 Code：用手机查看 Agent 写代码**

T3 Code 是一个跨设备的 Agent 控制台，可以从桌面、浏览器或手机管理本机运行的编程 Agent。

目前支持 Codex、Claude Code、Cursor、Grok Build 和 OpenCode。开发者可以在电脑上启动任务，离开工位后继续用手机查看进度和处理状态。

T3 Code 抓住了一个很具体的需求：Agent 任务越来越长，人不可能一直守在终端前。远程查看和接管任务，会逐渐成为编程 Agent 的常用能力。

![](https://pica.zhimg.com/v2-902e8a8483b0b65d735c050bc18d3810_r.jpg)

```text
项目地址：https://github.com/pingdotgg/t3code
```

- **LoopX：让 Agent 记住最近在做什么**

LoopX 是一套长期任务控制层，可以与 Codex、Claude Code、Cursor 和自定义 Agent 配合使用。

很多 Agent 在单次对话里表现很好，一旦任务跨越多个会话，目标、待办事项、审批记录和证据就容易丢失。LoopX 会把这些状态保存下来，让任务在多轮执行和多人交接后仍能继续推进。

LoopX 还提供配额、关卡和人工接管机制。涉及危险权限、正式发布或最终决策时，系统会把控制权交还给人。

![](https://pic3.zhimg.com/v2-2372090882d15430f180cbfae7de384c_r.jpg)

```text
项目地址：https://github.com/huangruiteng/loopx
```

- **Qwen Code：国产开源编程 Agent**

Qwen Code 是通义千问团队推出的终端编程 Agent，支持自动记忆、自动技能、子 Agent、Agent Teams 和 MCP。

除了 Qwen 系列模型，Qwen Code 还能接入 OpenAI、Anthropic、Gemini，以及通过 Ollama、vLLM 部署的本地模型。项目同时提供 IDE、桌面端、后台服务、SDK 和即时通信机器人等使用方式。

![](https://pic3.zhimg.com/v2-348d2fa49b2969f9189e54db13a6672e_r.jpg)

```text
项目地址：https://github.com/QwenLM/qwen-code
```

**02**

**挖一挖**

当 Agent 真正参与项目后，开发者很快会遇到并行冲突、远程控制、状态丢失和权限失控。模型能否生成代码，只是整套系统中的一个环节。

Agent 使用规模越大，管理成本越容易超过软件订阅费，这也给控制台、审计系统和托管服务留下了空间。

所以这批开源项目覆盖了 Agent 落地的几个关键环节。Pi、Oh My Pi 和 Qwen Code 负责执行任务；Orca、T3 Code 和 LoopX 处理并行调度、远程控制与长期状态；OpenMAIC 把 Agent 放进教育业务，直接生成课程、课件和互动课堂。

提高编码和原型开发速度，让多个 Agent 并行完成测试、重构和功能开发已经成为新潮流； OpenMAIC 还瞄准了学校和培训机构的课程生产和数字化教学。

模型价格会继续下降，代码生成能力也会逐渐接近。能把 Agent 管起来、接进生产流程并交付可核验结果的产品，才有机会把 GitHub Star 变成持续收入。
