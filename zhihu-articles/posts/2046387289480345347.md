你每天用LLM做科研，但你知道它从结构上就无法理解物理世界吗？

不是说它偶尔犯错，也不是说它有时候幻觉——这是一个数学层面的结构性限制，刚刚被形式化证明。

2026年5月25日，Cold Spring Harbor Laboratory的David Klindt、图灵奖得主Yann LeCun和Randall Balestriero在arXiv上发布了论文《When Does LeJEPA Learn a World Model?》（arXiv:2605.26379）。这篇论文的贡献不只是在说”LLM不好”——它用可识别性定理（identifiability theorem）从数学上划清了一条边界： **什么样的架构能学到真实世界的结构，什么样的架构在理论上就做不到。**

主流LLM站在那条线的错误一侧。

这对每天用GPT-4o、Claude、Gemini做生信分析、药物筛选、临床文献综述的科研人员来说，不是哲学问题，是实操问题。

---

### 一、这篇论文到底证明了什么

先说背景。LeCun近年来的核心主张是：语言模型不是通向通用智能的正确路径，世界模型（world model）才是。他提出的架构叫JEPA（Joint Embedding Predictive Architecture，联合嵌入预测架构），2025年11月推出了视觉版本LeJEPA（Le World Model with Joint Embedding Predictive Architecture）。

LeJEPA和LLM的根本差别在于训练目标：

- LLM：预测下一个词（token prediction）
- LeJEPA：在抽象隐空间里预测世界状态的变化（latent state prediction）

LeJEPA的架构由三部分组成：一个上下文编码器、一个目标编码器，和一个在隐空间做预测的预测器。它使用一个叫SIGReg的高斯正则化器，强迫模型把世界状态编码成各向同性的高斯分布，而不是任意形状的表示。

**2026年5月的这篇论文问的是：在什么条件下，LeJEPA学到的隐空间表示能真实对应世界的真实状态，而不只是某种扭曲的投影？**

作者证明了：在满足”稳态、加性噪声”环境的前提下，LeJEPA能达到 **线性正交可识别性（linear orthogonal identifiability）** 。这个术语的意思是：模型学到的隐变量和真实世界变量之间存在线性正交映射——不会把两个独立的物理量混在一个神经元里，不会把一个量拆散到多个方向上。

更重要的是：论文进一步证明，这个线性正交可识别性在理论上足以支撑直接在隐空间中进行 **最优规划** 。也就是说，满足条件的世界模型不需要把抽象表示重建回像素，就能做出物理上正确的决策。

**这是JEPA范式第一次拿到形式化数学背书。**

而对LLM的反面结论是隐含的但清晰的：LLM用token序列训练，它的表示空间没有这个正交可识别性保证。它学到的是语言的统计结构，不是世界的因果结构。这不是工程上的缺陷，可以靠更多数据或更大参数量修复——这是训练目标本身决定的结构性上限。

### 二、”脆而不智”：实验数据怎么说

定理是定理，但科研人员更关心的是：这个结构性限制在实际任务上有多严重？

答案是：比大多数人想象的严重。

**WITS基准测试（arXiv:2505.15929）**

WITS（”Wits” for Physical Reasoning）是专门针对物理推理能力设计的基准，涵盖力学、流体、热力学等领域的推理任务。2025年的测试结果：

| 模型 | 物理推理准确率 |
| --- | --- |
| GPT-4o | 32.5% |
| Claude 3.7 Sonnet | 42.2% |
| GPT-o4-mini | 45.8% |

对比参考：随机猜测在典型多选任务上约为25%。最好的模型只比随机猜测高出约20个百分点。

**SimuPhy基准测试**

SimuPhy针对物理定律推理（不只是描述现象，而是推导结果）。即便是参数量最大的Deepseek-671B，通过率只有 **20.6%** 。这意味着在需要真正运用物理定律的任务上，旗舰级LLM的成功率只有五分之一。

**AutumnBench对比测试**

对517名人类参与者和三个前沿LLM的对比结果是：人类显著优于模型，且加大算力只在部分环境下有效，无法系统性提升物理推理能力。这说明问题不是计算量不够，而是架构本身的限制。

**失败模式的特点**

LeCun团队用来描述LLM物理推理的词是”brittle”（脆）——在文字表述的标准场景里表现不错，换成需要真实物理直觉的变体版本，立刻崩溃。

一个典型例子：你问LLM”一个玻璃杯从桌上落到水泥地上会怎样”，它能回答正确。但如果你改变问法——”同一个玻璃杯，从相同高度落到沙袋上，会怎样”——很多模型会犯错，因为它调用的不是物理模型，而是”杯子+落+地面”的文本关联模式。它读过一百万次”玻璃会碎”，不等于它理解了接触力和材料韧性之间的关系。

### 三、为什么会这样：从训练目标说起

要理解这个限制，需要理解LLM的训练目标在结构上做了什么。

LLM训练的核心任务是：给定前面的词，预测下一个词。整个训练过程是在最大化token序列的条件概率。在这个目标下，模型学到的是语言的统计规律——什么词后面跟什么词，在什么上下文里用什么表达。

这里有一个根本性的信息丢失： **物理世界的因果结构，在语言层面是欠约束的。**

同样一个物理现象，可以用很多不同的方式描述。描述的差异是语言的，物理本身是一个。LLM看到的是描述的集合，它优化的是在这些描述里预测词的能力，而不是恢复描述背后共同的物理机制。

打个比方：你有一千本从不同角度描述同一栋建筑的书，但你从来没有建筑的平面图。读完这一千本书，你能流畅地回答大多数关于这栋建筑的文字问题。但如果有人拿着图纸问你一个结构力学问题，你的回答只能基于”类似建筑的类似描述里通常是怎么说的”，而不是基于真正理解了这栋建筑的力学结构。

这就是为什么LeCun坚持认为世界模型是更正确的方向：JEPA的训练目标直接针对世界状态的动力学——给定当前状态，预测未来状态的隐表示——而不是语言的统计规律。这个目标逼着模型学习”什么会导致什么”，而不只是”什么经常跟什么一起出现”。

### 四、LeCun的世界模型路线：现在到哪一步了

JEPA的思路LeCun提了很多年，真正有实质进展是2023年以后。

**核心架构演进**

- **I-JEPA（2023）** ：图像版本，在自监督学习基准上表现出色，不需要数据增强就能学到语义表示
- **V-JEPA（2024）** ：视频版本，在时序预测任务上优于像素重建方法
- **LeJEPA（2025年11月）** ：更完整的世界模型实现，引入SIGReg正则化，强化了隐空间的结构性

2026年3月，LeCun创立的AMI Labs完成10亿美元种子轮融资，估值约35亿美元。这个规模的融资意味着资本市场对世界模型路线的判断：这不是学术上的思想实验，是下一代AI系统的候选架构。

**和Transformer的本质区别**

| 维度 | Transformer/LLM | JEPA |
| --- | --- | --- |
| 训练目标 | 预测下一个token | 预测隐空间状态变化 |
| 表示对象 | 语言统计规律 | 世界动力学 |
| 输入模态 | 主要是文本 | 视觉、物理时序 |
| 可识别性保证 | 无 | 线性正交可识别性（满足条件时） |
| 规划能力 | 依赖语言推理链 | 直接在隐空间规划 |

**JEPA的局限也要说清楚**

目前LeJEPA的可识别性保证有前提：”稳态、加性噪声”环境。真实世界的很多场景是非稳态的——生物系统、动态市场、临床个体差异——这些还不在当前的理论覆盖范围内。此外，JEPA在语言理解和复杂推理任务上还远不如成熟的LLM。这是两类不同的能力，不是简单的替代关系。

### 五、学术界的分歧

这不是一个所有人都同意LeCun的领域。

**支持世界模型方向的证据**

除了LeCun团队自己的论文，有几个独立发现支持”LLM缺乏真实世界理解”这个判断：

- 2024年，MIT的研究发现LLM在系统性地处理空间推理（spatial reasoning）时存在一致的错误模式，与人类错误分布明显不同（不是随机错误，是结构性错误）
- 2025年，多个物理推理基准（包括PhysBench、WITS、SimuPhy）独立得出相似结论：LLM的物理推理能力远低于其语言理解能力，且扩大参数量对这一差距的改善有限
- Google DeepMind的Gemini团队在2025年的技术报告中承认，物理世界理解是当前多模态模型的”核心短板之一”

**反对或质疑的声音**

也有研究者持不同看法：

- 部分Transformer研究者认为，GPT-o4-mini在WITS基准上达到45.8%是从2023年GPT-4的约30%显著提升来的，说明scaling和推理增强（chain-of-thought, tool use）在持续改善物理推理能力，LeCun的结论过于悲观
- 还有观点认为，物理推理能力的上限不是由训练目标决定的，而是由物理知识的密度和质量决定的——如果训练数据里包含足够多高质量的物理推理过程，LLM也可以学到有效的物理直觉
- OpenAI的o系列模型通过引入显式搜索和验证机制（而非改变架构），在部分推理任务上取得了明显进步，这表明工程路径也有空间

**带带科研的判断**

从证据整体来看，LeCun的方向在物理世界理解这个特定维度上更有说服力。原因在于：

WITS、SimuPhy、AutumnBench这几个基准的结论高度一致，且它们来自不同机构，不是LeCun团队自己的实验。这种独立复现减少了”自家论文偏颇”的可能性。

另一方面，Transformer+scaling+reasoning的路线的进步是真实的，但更多体现在语言推理（数学、代码、逻辑）这类任务上，物理推理的进步相对缓慢且不稳定。这个分化模式本身支持”两类能力有不同的获取机制”这个假设。

当前最诚实的结论： **LLM在物理推理上的限制是真实的，但这个限制的深度（是根本性的还是工程可克服的）仍然开放。世界模型路线在理论上更干净，但规模和通用性还没有被证明。**

对科研人员来说，这个学术争论的实操含义是确定的： **现阶段，任何涉及物理世界因果推断的科研任务，都不应该直接信任LLM的判断。**

### 六、按研究方向分类：哪些任务可信，哪些要验证

**生信 / 药学方向**

可相对信任的任务：

- 文献检索和摘要生成（检查幻觉率，抽查引用真实性）
- 基因功能注释的初步整理（有明确数据库来源的）
- 网络药理学中靶点-通路的文字整理（基于既有数据库的关联，不是推理新关联）
- 写作辅助、格式规范

需要人工验证或专用工具交叉验证的任务：

- 分子对接结果的合理性评估（LLM能复述打分函数概念，但在新情境下无法真正判断哪个构象更稳定，用AutoDock/Vina的实际打分数值，不要让LLM做最终判断）
- 蛋白质结构预测的物理合理性（用AlphaFold/Rosetta的能量值，不是LLM的文字判断）
- 药物ADMET性质的新预测（这涉及物化性质的因果推断，LLM的回答基于训练数据里的统计关联）
- 实验方案中的操作可行性（温度、浓度、时间等物理化学约束）

**计算机科学 / AI方向**

可相对信任的任务：

- 已有算法的解释和对比（知识型任务）
- 代码审查和调试（逻辑层面，不涉及物理世界）
- 论文写作和格式规范

需要验证的任务：

- 物理模拟相关的代码（流体、固体力学、粒子系统）：LLM生成的代码语法可能正确，但物理公式的实现可能有量纲错误或边界条件处理不当
- 机器学习模型在特定物理系统上的可泛化性预测
- 涉及反事实推理的系统设计决策（”如果我改这个参数，系统会怎样”类的问题）

**临床医学方向**

可相对信任的任务：

- 文献系统综述的初步检索和摘要
- 统计方法选择的建议（需确认核心假设）
- 病例报告的格式规范

需要谨慎验证的任务：

- 诊断推理（临床决策是因果推断，不是模式匹配，LLM的”诊断”是统计关联）
- 治疗方案的风险预测（涉及个体生理动力学，高度情境依赖）
- 影像 + 文本 + 检验数据的联合解读（跨模态的物理一致性判断）
- 药物相互作用的新预测（训练数据里没有的组合）

### 七、LLM可信度检查清单（5条，通用版）

在让LLM参与科研任务之前，用这五个问题快速判断风险级别：

**1. 这个问题的答案需要物理世界的因果推断吗？** 如果是（比如”这个反应在这个温度下会不会发生”“这个结构稳不稳定”），输出必须用实验或专用工具验证，不能只凭LLM的文字判断。

**2. 训练数据里可能有这个答案的直接覆盖吗？** 如果问的是一个相对罕见的组合（新靶点、新分子结构、新临床情境），LLM的回答更多是插值和关联，不是真正的推理。可信度下降。

**3. 这个任务对结果的量纲和数值精度有要求吗？** LLM在量纲换算和数值计算上经常出错，尤其是物理量（能量、压力、浓度单位转换）。所有涉及精确数值的判断都要独立验证。

**4. 这是一个”描述”任务还是”推断”任务？** 描述现有知识（”三七总皂苷的主要成分是什么”）：LLM相对可靠。 推断新情境（”这种给药方式会不会导致系统性炎症”）：LLM的可信度显著下降。

**5. 如果这个回答是错的，代价是什么？** 文章格式错误：低代价，错了改。实验方案设计错误：高代价，浪费时间金钱。临床判断错误：不可接受，LLM不应该是决策者。根据代价级别决定验证力度。

### 结语

LeCun团队的这篇论文重要性不在于告诉你”LLM不好用”——它仍然是科研流程中强力的工具，在文献整理、写作辅助、代码生成等任务上每天帮科研人员省出大量时间。

**重要性在于：你现在有了一个数学层面的解释，知道边界在哪里，以及为什么边界在那里。**

这不是暂时的工程缺陷，不是靠下一个版本能完全修复的问题。在架构和训练目标没有根本性改变之前，物理世界的因果推断能力都是LLM的结构性短板。

世界模型路线（JEPA和类似架构）提供了一个更有数学保证的方向，但它现在还没有在通用场景被证明，距离进入科研工具链还有距离。

对当下的科研人员来说，最实用的态度是： **在边界内把LLM用到极致，在边界外保持验证习惯。**

这条边界，现在有了数学的坐标。
