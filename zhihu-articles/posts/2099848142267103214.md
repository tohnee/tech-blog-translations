> 一句话定位：**从数学地基到多智能体生产落地的完整开源 AI 工程实战课程体系**；核心教学理念「先手写简易版本，再对比生产库」，每节课产出可复用工件（代码、Prompt、Skill、MCP Server）；自带整套 Agent 学习 Skill，可直接接入 claude‑skills，完整覆盖整套 MCP‑Agent 生态的学习实验环境。

1. **不是生产业务库，是活态教学课程仓库**，产出学习实验代码，不直接用于线上生产；每节课遵循「从零手写简易实现 → 和工业级库对照理解差异」的教学范式，消除框架黑盒认知。
2. 自带一整套学习用 Agent Skill 集合（`start‑learning`、`learn`、`learn‑mcp`等），可导入 claude‑skills，**让 AI Agent 辅助你完成课程学习、自测、进度管理**；课程本身包含 MCP 协议、Agent 编排、多智能体 swarm 的完整实验课时，可实操前面调研过的 OpenRig / Paperclip / Octop /billion‑context /text‑to‑cad 等组件原理与 Demo。
3. 输出产物：可运行实验代码、测验题、Skill、MCP 教学示例、六卷电子书、交互式路线图、243 术语词汇表；支持多语言网页翻译，但课程正文仅英文完整，其他语言仅网页展示翻译。

## 一、诞生背景与核心痛点

AI 工程学习普遍现实痛点：

1. 大量教程只教调用高层 API，底层原理黑盒；只会调用库，但不理解内部运行逻辑，遇到故障很难排查定位。
2. 知识点碎片化：数学基础、ML、深度学习、LLM、Agent、MCP 协议、多智能体、生产部署散落在不同资料，缺少一条连贯递进学习路径。
3. Agent/MCP 相关资料大多只有 Hello‑World 示例，缺少状态管理、故障处理、安全防护、可观测性、多智能体协同等工程实战内容。
4. 缺少 Agent 辅助学习的闭环：学习者需要手动管理学习进度、自测、实验复现；本项目把学习流程本身封装为 Skill，交给编码 Agent 辅助完成学习流程。

项目核心设计思想：**逐层构建 AI 系统，地基优先；每一个核心组件先手写最小可行版本，再对标成熟工业库做对比；每节课产出可留存工件；把学习流程本身 Agent 化；完整覆盖从数学到多智能体生产全链路；课程本身可编译为网页、电子书、可执行代码资产**。

## 二、核心课程架构拆解

整体分为**20 个 Phase（阶段）**，由底层向上逐层递进，分为 6 大卷，对应 PDF/EPUB 六卷出版物；每个 Phase 包含多节 Lesson，每节课固定结构：文档讲解 + 可运行源码 + 测验习题 + 输出工件目录`outputs/`（prompt / skill / MCP / agent）GitHub。

### 20 个阶段总览（6 卷划分）

**卷 1 基础 Foundations（Phase00‑02）**

- Phase00：开发环境搭建；工具链；如何使用本课程；Agent 学习 Skill 初始化
- Phase01：数学基础：线性代数、微积分、概率统计
- Phase02：传统机器学习基础，手工实现经典 ML 算法

**卷 2 深度学习 Deep Learning（Phase03‑04、06）**

- Phase03：深度学习基础，手写神经网络、反向传播
- Phase04：计算机视觉基础
- Phase06：NLP 基础、音频语音处理

**卷 3 语言 Language（Phase05、07）**

- Phase05：Tokenizer 从零实现；BPE；对标 tiktoken
- Phase07：Transformer 深度拆解，手写极简 Transformer；生成式 AI 基础

**卷 4 大语言模型 LLM（Phase08‑11）**

- Phase08：从零实现小型 GPT 模型；训练、分布式训练基础
- Phase09：RLHF / DPO、量化；主流大模型架构拆解（DeepSeek‑V3 等）
- Phase10：LLM 工程；Prompt 工程、RAG、评估
- Phase11：多模态模型，图文、音视频大模型

**卷 5 智能体 Agents（Phase12‑16）【重点，MCP‑Agent 生态集中区】**

- Phase12：工具调用基础，Agent 循环、思考框架（ToT、ReWOO、Reflexion）
- Phase13：**MCP 模型上下文协议完整教学**：MCP 客户端、MCP 服务端传输层、安全防护、工具投毒防护、A2A 协议；从零手写教学 MCP Server；可以实操理解前面调研所有 MCP 项目
- Phase14：Agent 工程 42 节课：记忆系统 MemGPT / Hindsight、规划、LangGraph、AutoGen、CrewAI、OpenAI Agents SDK、可观测性、提示注入防御、任务移交、Agent 工作台
- Phase15：自主系统；计算机使用 Agent；语音 Agent
- Phase16：多 Agent、Agent Swarm 集群；编排范式，OpenRig/Paperclip 类控制平面原理实验

**卷 6 生产 Production（Phase17‑19）**

- Phase17：AI 系统生产基础设施；推理服务、监控、可观测性
- Phase18：安全、对齐、伦理、风险评估
- Phase19：Capstone 综合顶点项目，17 个完整可交付综合大作业，每个项目 20‑40 小时工作量，包含编码 Agent、硬件 Agent 等综合实践项目。

### 仓库核心组件

1. **Lesson 课程单元**：每一课包含`README.md`讲解文档、`code/`可运行源码、测验、`outputs/`存放本节课产出工件（prompt、skill、MCP 示例）。
2. **Agent 学习 Skill 套件（重点）**> 可以直接导入 claude‑skills，让 Claude‑Code/Cursor 作为助教，带领完成课程学习。

- `start‑learning`：初始化学习者档案，生成`LEARNING.md`学习计划；做能力测评，定位学习起点；规划每周学习节奏
- `learn`：Agent 辅助执行单节课，运行代码，核对输出结果，做自测，记录进度
- `course‑guide`：课程全局导航
- `learn‑mcp`：专门学习 MCP 协议的 Skill

配套资产：交互式依赖路线图、243 术语词汇表、课程校验审计脚本。

### 和整套 MCP‑Agent 生态层级关系

```text
学习者 ↔ Claude‑Code / Cursor（加载ai‑engineering‑from‑scratch skill套件）
  ↓
ai‑engineering‑from‑scratch课程仓库
  ├─Phase13 MCP实验：手写MCP Server/Client；安全实验
  ├─Phase14‑16 Agent工程：记忆、编排、多Agent swarm
  │  ├─实验复现理解：OpenRig会话编排、Paperclip控制平面、Octop一体化平台
  │  ├─实验组件：billion‑context上下文折叠、Hindsight记忆、tester‑army/e2e测试、text‑to‑cad硬件Agent
  │  └─Skill资产：asd‑ste100‑skill等
  └─Phase19 Capstone顶点综合项目（组合上述组件做完整Agent产品）
底层依赖：Python / TS / Rust / Julia；各类开源库

```

> 定位：**这是学习研究整套 MCP‑Agent 生态的教学实验载体，不是业务运行系统**。课程提供原理 + 最小 Demo，真正生产级实现还是使用对应项目的官方仓库。

## 三、能力清单

支持能力

1. 教学范式：**先手写最小简易实现，再对标工业库对照理解**，消除黑盒；每节课产出可留存工件（代码、prompt、skill、MCP Server 示例），可作为个人作品集。
2. 自带完整 Agent 学习 Skill 集合，导入 claude‑skills 后，AI 编码 Agent 可以作为助教，完成测评定位起点、生成学习计划、辅助完成课程、自测、记录进度。
3. MCP 与 Agent 工程部分内容详实：包含 MCP 传输层、安全防护、Agent 循环、记忆系统、可观测性、提示注入防御、多 Agent Swarm 编排；覆盖前面调研全部 Agent 组件的原理实验。
4. Phase19 提供 17 个 Capstone 顶点综合项目，训练端到端完整 AI 产品开发。
5. 多编程语言实验代码：Python、TypeScript、Rust、Julia；配套术语词典、交互式路线图、测验习题。

明确局限与风险

1. **是教学课程仓库，不是生产 SDK 库；仓库内代码以教学演示为目的，性能、健壮性不足以直接线上生产使用**。
2. 课程正文仅英文完整；网页支持机器翻译，但课程代码、习题、Skill 均无完整中文版本，对英文弱的学习者门槛高。
3. 学习成本高，完整走完全部课程需要数百小时，对零基础学习者负担很重；适合有编程基础学习者。
4. 高速迭代活态课程，课程内容、文件结构会持续变动；引用课程内容建议锁定 Release 版本，不要直接依赖 main 分支。
5. 只是教学 Demo，MCP、Agent 实验示例是简化教学版本，和 OpenRig/Paperclip 等正式项目存在差距。
6. 需要本地配置多语言开发环境（Python、Node、Rust 等），环境搭建存在一定门槛。

## 五、优势、风险分析

### 优势

1. **完整连贯逐层递进的 AI 工程学习路径**，从数学地基一直延伸到 MCP、多 Agent swarm、生产部署安全；很多同类课程到 LLM 就结束，缺少 Agent 工程与 MCP 协议实战。
2. 优秀教学方法论：手写最小可行版本，再对标成熟工业库，破除框架黑盒；每节课产出可留存工件，可以作为个人作品集。
3. 学习流程 Agent 化：自带 Skill，可交给 Cursor/Claude‑Code 作为助教，做测评、规划、辅助实验、自测、进度跟踪。
4. 重点 Phase13‑16 包含 MCP 安全、提示注入防御、Agent 故障处理、可观测性等工程现实问题，不止 Hello‑World 示例。
5. MIT 宽松协议；可生成电子书、网页；可自由修改用于个人学习。

### 风险与现实约束

1. 仓库代码是教学演示代码，健壮性性能不足，**严禁直接用于线上生产业务**。
2. 课程正文完整版本只有英文，有语言门槛；完整学习需要数百小时，时间成本很高。
3. 高速迭代活态课程，结构持续变化，生产引用要锁定 Release 版本。
4. 需要配置多语言开发环境，环境搭建有门槛。
5. MCP/Agent 部分只是教学 Demo；正式项目仍然要使用 OpenRig、Paperclip 等官方仓库。

## 六、适用场景 & 不适用场景

### 适合选型

1. 具备编程基础，希望系统学习 AI 工程，尤其是**MCP、Agent、多智能体编排整套生态原理**，不只调用高层 API，希望理解底层实现。
2. 希望使用编码 Agent（Cursor/Claude‑Code）作为 AI 助教辅助自己系统学习 AI 工程。
3. 研究整套 Agent 生态，做 PoC 实验：复现理解 OpenRig、Paperclip、Octop、billion‑context 等组件原理。
4. 作为个人学习作品集，每节课产出 prompt、skill、MCP 示例工件；完成 Phase19 Capstone 综合项目。
5. 作为团队内部培训材料，学习 MCP 协议、Agent 工程、Agent 安全风险。

### 不适合选型

1. 零基础，没有编程基础，无法承受数百小时学习投入。
2. 需要中文完整课程正文。
3. 想要直接拿仓库内代码上线生产业务。
4. 只想快速调用现成 Agent 库，不想理解底层原理，不想手写简易版本。

## 七、落地实践建议

1. **定位：教学实验课程仓库，不是生产库；仓库代码只用于学习理解，不要直接用于线上业务；使用时锁定 Release 版本，不要直接使用 main 分支**。
2. 最佳学习工作流：导入 Skill 套件 → 运行`start‑learning`做能力测评，生成`LEARNING.md`学习计划，定位自己的起始 Phase；Agent 辅助完成每节课，运行代码，完成自测，留存`outputs/`工件。
3. Agent 生态学习重点：优先关注 Phase13 (MCP 完整协议 + 安全)、Phase14‑16 (Agent 工程 + 多智能体编排)，可以在此复现理解前面调研的全部 MCP‑Agent 项目原理。
4. 学完 Demo 实验之后，再去阅读 OpenRig / Paperclip / Octop /billion‑context 对应官方仓库，对比教学 Demo 和生产级实现差异。
5. 学有余力完成 Phase19 Capstone 顶点项目，组合多个 MCP/Skill 组件，交付完整端到端 Agent 作品。
6. 注意环境：需要准备 Python、Node.js，部分课时需要 Rust、Julia 环境。

## 八、总结

ai‑engineering‑from‑scratch 是 MIT 协议的**活态开源 AI 工程完整课程体系**，遵循「手写最小实现，再对标工业库」的教学范式；20 个阶段 523 课时，从数学基础一直延伸到 LLM、MCP 协议、Agent 工程、多智能体 Swarm、生产部署与安全对齐。

它的一大特色：自带 Agent 学习 Skill 套件，可以导入 claude‑skills，由编码 Agent 充当助教完成测评、学习规划、实验自测；课程包含整套 MCP‑Agent 生态的原理教学与 Demo 实验，可以用来理解 OpenRig、Paperclip、Octop、billion‑context、text‑to‑cad 等项目底层逻辑。

注意仓库代码是教学演示，不能直接用于生产；课程正文完整版本仅英文，完整学习时间投入巨大，适合有编程基础希望系统吃透 AI 与 Agent 底层原理的学习者。
