mcp-ssh-manager - 是一个 MCP 工具，用于通过 SSH 远程管理服务器，提供 37 种不同的实用功能，旨在自动化 DevOps 任务、备份操作、数据库操作以及系统状态监控。

其核心功能包括支持现代 SSH 算法、兼容 OpenSSH 9.x 版本，支持使用 ProxyCommand 通过 SOCKS5 或其他代理进行连接，以及将 SSH 会话与多种 shell 环境同步，包括 Windows PowerShell。

此外，该工具还提供增强的身份验证能力，支持多种加密方式，并兼容多种操作系统，包括 Windows 与 Linux。
