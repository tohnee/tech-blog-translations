# MATH 289: Mathematical Practice in a Changing World

A course for current math PhD students on AI for Mathematical Research.

Lecture
:   Monday, Wednesday, 10:30–11:50am

Location
:   Sloan Hall (Bldg 380), Room 380W

Units
:   3 units

## Latest news

- Make sure you have joined the course Slack and GitHub organization. All announcements and discussions will be in Slack.

## About this course

This is a seminar course for current math PhD students. The course will introduce them to the
tools needed to navigate a rapidly evolving research landscape. No prior coding or AI experience
is required.

**Enrollment:** Permission required. Please email the instructor to request permission. May be
repeated for credit.

**Note:** This course is not open to undergraduates or master's students.
