今天，我们将 [Agent Skills](https://agentskills.io/home)——这一赋予 AI 智能体专业化知识与工作流的开放标准——捐赠给 Agentic AI 基金会（AAIF）。自我们于 2025 年 12 月发布该标准以来，包括 ChatGPT、Cursor、GitHub Copilot 和 VS Code 在内的 70 多个智能体平台已经集成了 Agent Skills。

### 以简洁实现智能体互操作

一个技能（skill）就是一个文件夹，其中包含一个向智能体传授特定任务或领域知识的 SKILL.md 文件，以及它所需的任何脚本或参考材料。我们在开发 Claude Code 的过程中提出了技能这一概念。它能很好地处理一般性知识工作，但往往缺乏真实业务任务所需的程序性知识。在我们于 2025 年 10 月发布后的几周内，开发者就在 GitHub 上发布了数千个技能，并为 Codex、Cursor 和 OpenCode 编写了加载器。随后，我们将 Agent Skills 作为开放标准发布，交由独立的 GitHub 组织和域名管理，使任何智能体都能使用它。到目前为止，已发布了 100 万个技能，安装量接近 2.8 亿次。

### 将 Agent Skills 捐赠给 AAIF

我们致力于保持 Agent Skills 的开放、社区驱动与供应商中立。今天，我们将这一标准捐赠给 Linux 基金会旗下的 Agentic AI 基金会（AAIF）——该基金会由我们于去年与 Block 和 OpenAI [共同创立](https://www.anthropic.com/news/donating-the-model-context-protocol-and-establishing-of-the-agentic-ai-foundation)，Model Context Protocol（MCP）也已捐赠至此。今后，AAIF 将为这一标准提供一个中立之家，确保社区对 Agent Skills 的未来方向拥有发言权。

我们将捐赠 Agent Skills 的名称与标识、GitHub 组织以及 [agentskills.io](https://agentskills.io/home) 域名。你可以继续使用这一标准或为其做贡献，而无需加入 AAIF。

来自 Anthropic、Google、OpenAI 及其他公司的工程师将以个人身份维护这一标准，由 David Soria Parra 与 Mahesh Murag 担任首席维护者。

### 接下来做什么

我们已提议从一份路线图起步，涵盖版本化发布、正式的提案流程，以及面向技能编写者与安装者的安全指引。与 MCP 一样，该项目将继续优先考虑社区意见与透明决策。你可以加入该项目的 [Discord](https://discord.gg/MKPE9g8aUy)，就拟议的规范变更提供反馈。

感谢从一开始就用 Agent Skills 构建的开发者，也感谢将技能引入其产品的各个团队。规范全文见 [agentskills.io](https://agentskills.io)，欢迎在 [GitHub](https://github.com/agentskills/agentskills) 上参与讨论。
