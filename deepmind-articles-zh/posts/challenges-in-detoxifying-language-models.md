# 语言模型去毒化的挑战

> 原文：[Challenges in Detoxifying Language Models](https://deepmind.google/blog/challenges-in-detoxifying-language-models/) · Google DeepMind

## 语言模型的不良行为

在大规模文本语料上训练的语言模型能够生成[流畅的文本](https://cdn.openai.com/better-language-models/language_models_are_unsupervised_multitask_learners.pdf)，并展现出作为[小样本/零样本学习器](https://arxiv.org/abs/2005.14165)和代码生成工具的潜力，此外还有其他诸多能力。然而，先前的研究也指出了语言模型使用中亟待解决的若干问题，包括[分布性偏差](https://arxiv.org/abs/1911.03064)、[社会刻板印象](https://arxiv.org/abs/2004.09456)、可能泄露[训练样本](https://arxiv.org/abs/2012.07805)，以及其他[潜在的语言模型危害](https://dl.acm.org/doi/pdf/10.1145/3442188.3445922)。其中一类特定的语言模型危害是生成[有毒语言](https://arxiv.org/abs/2009.11462)，包括仇恨言论、侮辱、脏话和威胁。

在本文中，我们关注语言模型及其[生成有毒语言的倾向](https://arxiv.org/abs/2009.11462)。我们研究了不同方法缓解语言模型毒性的有效性及其副作用，并考察了基于分类器的自动毒性评估的可靠性与局限。

按照 [Perspective API](https://perspectiveapi.com/) 提出的毒性定义，我们把一条话语视为有毒的，条件是它是粗鲁、不尊重他人或不合理的语言，且很可能导致某人退出讨论。不过，我们要指出两个重要注意事项。第一，毒性判断是主观的——它既取决于评估毒性的评分者及其文化背景，也取决于所推断的语境。虽然这不是本文的重点，但未来的工作应继续完善上述定义，并澄清如何在不同情境中公平地应用它。第二，我们注意到毒性只是潜在语言模型危害的一个方面，并不涵盖例如由模型分布性偏差带来的危害。

## 度量与缓解毒性

为了实现更安全的语言模型使用，我们着手度量、理解语言模型中有毒文本生成的根源并加以缓解。已有研究从多个角度考虑降低语言模型毒性的方法，包括对[预训练语言模型](https://arxiv.org/abs/2009.11462)进行[微调](https://arxiv.org/abs/2004.10964)、[引导模型生成](https://openreview.net/forum?id=H1edEyBKDS)，或直接在[测试时过滤](https://arxiv.org/abs/2104.06390)。此外，先前的[工作](https://arxiv.org/abs/2009.11462)已引入了度量语言模型毒性的自动指标，既适用于不同类型提示词的条件下，也适用于无条件生成场景。这些指标依赖于广泛使用的 [Perspective API](https://perspectiveapi.com/) 模型的毒性分数，该模型在标注了毒性的在线评论上训练而成。

在我们的研究中，我们首先表明：把几个相对简单的基线组合起来，就能按照先前提出的语言模型毒性[指标](https://arxiv.org/abs/2009.11462)带来大幅下降。具体而言，我们发现以下三项组合在按自动毒性指标衡量时对降低语言模型毒性非常有效：i) 过滤掉被 [Perspective API](https://perspectiveapi.com/) 标注为有毒的语言模型训练数据；ii) 使用另一个经过微调、用于检测毒性的 BERT 分类器过滤生成文本中的毒性内容；iii) [引导](https://arxiv.org/abs/1912.02164)生成过程使其毒性更低。当使用来自 [RealToxicityPrompts](https://arxiv.org/abs/2009.11462) 数据集的有毒（或无毒）提示词时，与先前报道的最优水平相比，我们在总体毒性概率（Probability of Toxicity）指标上看到了 6 倍（或 17 倍）的下降。在无提示的文本生成场景中，我们达到了零值，这表明该指标已走到极限。鉴于自动指标衡量的毒性水平在绝对值上已经如此之低，一个问题随之而来：这是否也同样体现在人类判断中，这些指标上的改进是否仍有意义——尤其考虑到它们来自一个并不完美的自动分类系统。为了获得更深入的洞见，我们转向由人类进行评估。

## 由人类进行评估

我们开展了一项人类评估研究，由评分者对语言模型生成的文本进行毒性标注。该研究的结果表明，人类平均结果与基于分类器的结果之间存在直接且基本单调的关系，且按人类判断衡量，语言模型毒性有所降低。

![散点图：纵轴为人类平均毒性分数，横轴为 Perspective API 平均分数。代表"干预强度递增"的不同标记显示，随着去毒化干预强度的增强（图例中由向下蓝色箭头表示），人类平均毒性分数与 Perspective API 平均毒性分数均下降。](https://lh3.googleusercontent.com/m6FUNlOtHhVXzOe7UbXpUmKfjy4UlWmve2c3gfBPEvMJPEgQOhdcwK4AfsQCA26EUbhooP16FV3dfw90UGEaj_ihegesU6CFRZKWqnzgwIWQXEcZiaQ=w1440)

我们发现评分者之间的一致性与其他度量毒性的研究相当，同时毒性标注也存在主观和模糊的一面。例如，我们发现模糊性经常源于讽刺、关于暴力行为的新闻式文本，以及引用有毒文本（无论是中性地引用，还是为表达反对而引用）。

此外，我们发现一旦施加去毒化措施，语言模型毒性的自动评估可靠性就会下降。在干预之前，人类评分与 Perspective API 分数耦合得很好；但对于（自动）毒性分数较高的样本，一旦我们施加并增强语言模型毒性削减干预，这种联系便消失了。

![水平条形图：显示对于 Perspective API 分数较高（> 0.75）的样本，随着去毒化干预强度增强，人类平均毒性分数（浅绿色条）骤降至接近零，而 Perspective API 平均分数（深蓝色条）始终保持在 0.85 左右的高位。](https://lh3.googleusercontent.com/zNxDsESHZJAUMPQKK_ffq-b0rMGOn3IoEMKmTc_zwQSeeCTqdAtG6NkeWe4t63TLZZpXjFIaHgVEOyo4KTqnaOOKE_nHNZq9yZwuf7brBTWICtwt1A=w1440)

进一步的人工检查还揭示，误报文本以不成比例的高频率提及某些身份相关词汇。例如，对于某个去毒化后的模型，我们观察到在自动毒性分数较高的一桶样本中，30.2% 的文本提到了「gay」一词，这反映了此前已在自动毒性分类器中观察到的偏差（社区已经在[着手改进](https://research.google/pubs/pub46743/)这一问题）。综上，这些发现表明：在判断语言模型毒性时，仅依赖自动指标可能导致具有误导性的解读。

## 去毒化的意外后果

我们进一步研究了语言模型毒性削减干预可能带来的意外后果。对于去毒化后的语言模型，我们看到语言建模损失显著上升，且这一上升与去毒化干预的强度相关。然而，与毒性分数较低的文档相比，自动毒性分数较高的文档上损失上升幅度更大。与此同时，在人类评估中，我们没有发现语法、理解能力以及保留先前条件文本风格方面存在显著差异。

去毒化的另一个后果是，它会不成比例地削弱语言模型对与某些身份群体相关文本（即主题覆盖率）的建模能力，也会削弱对不同身份群体、不同方言使用者所写文本（即方言覆盖率）的建模能力。我们发现，与白人对应英语（White-Aligned English）文本相比，非裔美国人英语（AAE）文本的语言建模损失上升幅度更大。

![条形图：比较白人对应英语（浅绿色条）与非裔美国人英语（紫色条）的语言建模损失差距（纵轴）随去毒化干预强度增强（横轴）的变化。随着干预强度增强，两种方言的损失差距都增大，且非裔美国人英语的损失差距始终高于白人对应英语。](https://lh3.googleusercontent.com/ErvL0KN9hohWf_QYVLf2_-ZjIXnxUO0umKL6qfRarcIP1iSjkBS0DJvWDl6oTy73k3_8f--NpZufMM0LBTNZAOanWZLwib-sh50lNVzlGh4rszhUTA=w1440)

在语言建模损失退化方面，与男性人物相关的文本相比，与女性人物相关的文本也呈现类似的差距。对于涉及某些族裔亚群体（如西班牙裔美国人）的文本，其性能退化相对其他亚群体再次偏高。

## 核心要点

我们在度量与缓解语言模型毒性方面的实验，为减少与毒性相关的语言模型危害的下一步工作提供了宝贵洞见。

从自动与人类评估研究中，我们发现现有的缓解方法确实非常有效地降低了自动毒性指标，而且这一改进在很大程度上与人类判断的毒性下降相吻合。然而，我们可能已经触及了自动指标在语言模型毒性评估中的极限：在施加毒性削减措施之后，剩余的自动毒性分数较高的样本中，大多数实际上并未被人类评分者判为有毒，这表明自动指标对去毒化后的语言模型变得不再可靠。这促使我们努力设计更具挑战性的自动评估基准，并在未来的语言模型毒性缓解研究中纳入人类判断。

此外，鉴于人类毒性判断本身存在模糊性，并且不同用户与应用场景下的判断可能不同（例如描述暴力的语言在新闻文章中可能是恰当的，而在其他场合可能被标记为有毒），未来的工作应继续针对不同情境开发并调整毒性的概念，并针对不同的语言模型应用加以细化。希望我们发现的标注者意见分歧现象清单能在这方面提供帮助。

最后，我们还注意到语言模型毒性缓解的意外后果，包括语言模型损失恶化，以及社会偏差的意外放大——以主题覆盖率和方言覆盖率衡量——这可能导致语言模型对边缘化群体的性能下降。我们的发现表明，除毒性之外，未来的工作关键在于不要只依赖单一指标，而应考虑能够捕捉不同问题的「指标集合（ensemble of metrics）」。未来的干预措施，例如进一步降低毒性分类器中的偏差，有望帮助避免我们观察到的这类权衡，从而实现更安全的语言模型使用。
