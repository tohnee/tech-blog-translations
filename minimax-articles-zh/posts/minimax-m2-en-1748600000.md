# MiniMax M2 与 Agent：大道至简

> 原文：[MiniMax M2 & Agent: Ingenious in Simplicity](https://www.minimax.io/blog/minimax-m2-en-1748600000) · MiniMax

2025-10-27

AIAgent

自公司成立的第一天起，我们就始终致力于「Intelligence with Everyone（与大众共享智能）」的愿景。

今天，我们正式开源并发布 **MiniMax M2——一个为智能体（Agent）与代码而生的模型。价格仅为 Claude Sonnet 的 8%，速度却是它的两倍，现限时免费开放！**

- **顶尖的编程能力：** 为端到端开发工作流而打造，在 Claude Code、Cursor、Cline、Kilo Code、Droid 等各类应用中表现出色。
- **强大的智能体性能：** 在复杂的长链条工具调用任务中展现出出色的规划与稳定的执行能力，可协调调用 Shell、浏览器、Python 代码解释器以及各类 MCP 工具。
- **极致的性价比与速度：** 通过对激活参数的高效设计，我们在智能、速度与成本之间实现了最优平衡。

我们的团队一直在构建各种各样的智能体，以帮助应对公司快速发展带来的挑战。这些智能体正在完成越来越复杂的任务：从分析线上数据、调研技术问题，到日常编程、处理用户反馈，甚至筛选 HR 简历。这些智能体与我们的团队并肩工作，共同推动公司的发展，构建出一个**从「研发 AGI」走向「与 AGI 共同前进」、不断进化的 AI 原生组织。** 我们愈发坚信：AGI 是一种生产力，而智能体是承载这种生产力的绝佳载体，代表着从对话式助手的简单问答到智能体独立完成复杂任务的演进。

然而，我们发现没有任何一个单一模型能够完全满足我们对这些智能体的需求。挑战在于找到一个在性能、价格和推理速度之间取得恰当平衡的模型——这几乎是一个「不可能三角」。**海外最好的模型性能出色，但价格昂贵且速度相对较慢；国内模型更便宜，但在性能和速度上存在差距。** 这导致现有的智能体产品往往非常昂贵，或者要取得好的效果就得很慢。

**我们一直在探索：能否打造一个在性能、价格和速度之间取得更好平衡的模型，从而让更多人受益于智能体时代的智能红利，延续我们「Intelligence with Everyone」的愿景。** 这样的模型需要多样化的能力，包括编程、工具使用、逻辑推理和知识，同时还要有极快的推理速度和极低的部署成本。为此，我们开发并已于今日开源了 MiniMax M2。

先来看智能体最关键的三项能力：编程、工具使用和深度搜索。我们将 M2 与若干主流模型进行了对比：

![](https://filecdn.minimax.chat/public/6379df73-178f-4d3e-849e-8bc52619328c.PNG)

如你所见，该模型在工具使用和深度搜索上的能力已非常接近海外最好的模型。虽然在编程上略落后于海外顶尖模型，但在国内市场已属顶尖水平。

这背后有若干算法与认知层面的进展，我们将在合适的时机分享。但**核心原则很简单：要打造一个满足我们要求的模型，我们必须首先自己用上它。** 为此，我们的开发者——包括业务和后端团队——与算法工程师并肩工作，投入大量精力搭建环境和评测，并越来越多地将其融入日常工作。

一旦掌握了这些复杂场景，我们发现，将积累的方法迁移到知识与数学等传统大模型任务上，自然而然也能取得出色的成绩。例如，在整合了 10 项测试任务的热门基准 Artificial Analysis 上，我们的模型位列全球前五：

![](https://filecdn.minimax.chat/public/3cdfba08-4c91-4c43-9faf-2a934a122d0e.PNG)

我们将该模型的 API 价格定为**每百万输入 token $0.30/¥2.1 人民币，每百万输出 token $1.20/¥8.4 人民币**，同时提供 TPS（每秒 token 数）约 100（且仍在快速提升）的在线推理服务。**这一价格是 Claude 4.5 Sonnet 的 8%，推理速度接近其两倍。**

刚刚过去的这个周末，许多来自海内外的热情开发者与我们一同进行了大量测试。为了方便大家探索模型能力，我们将免费试用期延长至 11 月 7 日 00:00 UTC。与此同时，我们已在 Hugging Face 上**开源了完整的模型权重**。感兴趣的开发者可以自行部署，SGLang 和 vLLM 均已提供支持。

我们相信，这一价格与推理速度的组合在当前主流模型中是极佳的选择。让我们从两个角度来分析。

为了方便大家使用智能体相关能力，我们已在国内上线由 M2 驱动的智能体产品，并升级了海外版本。在 MiniMax Agent 中，我们提供两种模式：

- **闪电模式（Lightning Mode）：** 高效、高速的智能体，适用于对话问答、轻量搜索和简单编程等需要即时输出的场景。它以强大的智能体（agentic）能力增强对话式产品的体验。
- **Pro 模式：** 在复杂、长时间运行的任务上以最优性能提供专业级智能体能力。擅长深度研究、全栈开发、制作 PPT/报告、Web 开发等。

得益于 M2 与生俱来的推理速度，由 M2 驱动的智能体不仅具备成本效益，完成复杂任务的流畅度也显著提升。
