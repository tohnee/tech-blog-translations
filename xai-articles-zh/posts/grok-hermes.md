# 把 Grok 接入 Hermes Agent

> 原文：[Connect Grok to Hermes Agent](https://x.ai/news/grok-hermes) · xAI

2026 年 5 月 15 日

在 Nous Research 开源、自我改进的 Hermes 智能体中使用你的 Grok 账号和订阅。

---

从今天起，你可以直接在 Hermes Agent 中使用你的 Grok 订阅。

Hermes Agent 是 Nous Research 推出的开源、自我改进型智能体。它可以在任何电脑、沙箱或 VPS 上持久运行，并跨会话建立长期记忆，越用越懂你。与其他开源个人智能体一样，Hermes 可以接入 WhatsApp、Discord、Telegram、Signal 或其他消息服务。

在 Hermes 中使用你的 Grok 订阅，你可以用上：

- Grok 4.3，用于文本对话和高级推理
- Grok 文本转语音，用于语音回复
- Grok Imagine，让你的智能体创作图像和视频

将 Grok 连接到你的 Hermes 智能体，所有档位均可用。

### [设置](#setup)

安装 Hermes Agent：

bash

```
# Linux / macOS / WSL2 / Android (Termux)
curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh | bash
```

选择 Grok 提供方：

bash

```
hermes model
```

选择 **xAI Grok OAuth（SuperGrok 订阅）**，通过浏览器登录，然后开始聊天：

bash

```
hermes --tui
```

更多信息请参阅 [Hermes Agent xAI Grok OAuth 文档](https://hermes-agent.nousresearch.com/docs/guides/xai-grok-oauth)。
