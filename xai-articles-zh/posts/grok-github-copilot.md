# Grok 4.5 登陆 GitHub Copilot

> 原文：[Grok 4.5 in GitHub Copilot](https://x.ai/news/grok-github-copilot) · xAI

[返回新闻列表](/news)

2026 年 7 月 28 日

我们最聪明的编码模型 Grok 4.5，现已在 GitHub Copilot 中可用。

---

[在 API 中试用 Grok 4.5](https://console.x.ai/team/default/api-keys?campaign=grok-github-copilot-blog)[打开 GitHub Copilot](https://github.com/features/copilot)

Grok 4.5 现已在 GitHub Copilot 中面向每天使用 VSCode 和 GitHub 产品的数百万开发者提供。

### [快速上手](#getting-started)

GitHub Copilot 覆盖多个产品，包括云端智能体、Copilot CLI 和 VSCode IDE。在模型选择器中选择「Grok 4.5」，即可开始使用我们最新的编码模型。对部分商业和企业用户，需要先在 Copilot 设置中启用该模型。

Grok 4.5 也可以直接通过 [SpaceXAI 控制台](https://console.x.ai/) 使用，定价为每百万输入 token 2 美元、每百万输出 token 6 美元。欲了解更多关于该模型的信息（包括编码性能），请阅读 [Grok 4.5 发布公告](/news/grok-4-5)。
