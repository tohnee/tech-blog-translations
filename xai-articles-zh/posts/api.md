# API 公测

> 原文：[API Public Beta](https://x.ai/news/api) · xAI

2024 年 11 月 4 日

从今天起，开发者可以通过我们新发布的 API，基于我们的 Grok 基础模型进行构建。我们将运行公测计划直至 2024 年底，期间所有人每月可获得 25 美元的免费 API 额度。

---

我们很高兴地宣布，我们的 API 即刻可用，开发者可以通过它以编程方式访问我们的 Grok 系列基础模型。要开始使用，请前往 [console.x.ai](https://console.x.ai) 注册并创建账户。我们期待看到开发者用 Grok 构建出的作品。

## 模型

我们以一个新 Grok 模型的预览版开启本次公测，该模型目前正处于开发的最后阶段。这个以临时名称 grok-beta 发布的模型拥有 128,000 token 的上下文长度，同时支持函数调用与系统提示词。我们稍后将发布关于该模型的更多信息。

除了纯文本版本的 grok-beta 之外，我们还将发布一个可接收图像的多模态版本。该视觉模型将于下周上线。

## 免费额度

我们将在年底前持续运行公测计划。所有人每月可获得 25 美元的免费 API 额度，用于测试 API 并开始使用 Grok。

凡是此前购买过预付额度的用户，在年底之前的每个月都将获得等额的免费月度额度。例如，如果你已购买 50 美元预付额度，那么在 11 月和 12 月，你将拥有 25 美元 + 50 美元的额外免费额度。

## API

要了解更多关于我们 API 的信息，请查阅 [docs.x.ai](https://docs.x.ai) 上的文档。我们的 REST API 与 OpenAI 和 Anthropic 提供的 API 完全兼容，这让迁移变得简单。例如，如果你正在使用 OpenAI Python SDK，只需把 `base_url` 改为 `https://api.x.ai/v1` 并使用你在 [console.x.ai](https://console.x.ai) 上创建的 xAI API 密钥，就可以开始使用 Grok。
