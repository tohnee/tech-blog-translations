# Grok-1 模型卡

> 原文：[Grok-1 Model Card](https://x.ai/news/grok/model-card) · xAI

2023 年 11 月 3 日

## 宣布 Grok

Grok 是一款以《银河系漫游指南》（Hitchhiker's Guide to the Galaxy）为蓝本打造的 AI。它旨在回答几乎任何问题，而更难的是，它甚至能建议你该问什么问题！

---

## Grok-1 模型卡

|  |  |
| --- | --- |
| 模型细节 | Grok-1 是一个基于 Transformer 的自回归模型，经预训练以执行下一个 token 预测。随后，该模型使用来自人类和早期 Grok-0 模型的大量反馈进行了微调。初版 Grok-1 的上下文长度为 8,192 个 token，于 2023 年 11 月发布。 |
| 预期用途 | Grok-1 旨在作为 Grok 背后的引擎，用于自然语言处理任务，包括问答、信息检索、创意写作和编码辅助。 |
| 局限性 | 尽管 Grok-1 在信息处理方面表现出色，但由人类审查 Grok-1 的工作以确保准确性仍然至关重要。Grok-1 语言模型本身不具备独立搜索网络的能力。搜索工具和数据库增强了该模型部署在 Grok 中时的能力与事实准确性。尽管可以访问外部信息源，该模型仍可能出现幻觉。 |
| 训练数据 | 用于 Grok-1 发布版本的训练数据，一方面来自截至 2023 年第三季度的互联网，另一方面来自我们的 [AI 导师（AI Tutors）](https://boards.greenhouse.io/xai/jobs/4101903007)提供的数据。 |
| 评测 | Grok-1 在一系列推理基准任务以及精选的外国数学考试题上进行了评测。我们邀请了早期 alpha 测试者对一个包含对抗性测试在内的 Grok-1 版本进行了评测。我们正在通过 Grok 早期访问计划将早期用户扩展至封闭测试阶段。 |
