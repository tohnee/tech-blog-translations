# 在 OpenClaw 中使用 Grok

> 原文：[Use Grok in OpenClaw](https://x.ai/news/grok-openclaw) · xAI

2026 年 5 月 22 日

在开源、本地优先的智能体与个人助手 OpenClaw 中使用你的 SuperGrok 或 X Premium 订阅。

---

从今天起，登录并在 OpenClaw 中使用你的 SuperGrok 或 X Premium 订阅。

OpenClaw 是一个开源、本地优先的智能体和个人助手。它可以在任何硬件上运行——Mac Mini、笔记本、服务器、VPS，甚至树莓派——并跨会话保持持久记忆。

OpenClaw 可接入 WhatsApp、Telegram、Slack、Discord、Signal、iMessage 等众多消息平台，让你在你平时聊天的地方就能与智能体互动。

如果你已拥有 Grok 或 X Premium 订阅，现在就可以在 OpenClaw 中使用 Grok 模型。将 Grok 连接到你的 OpenClaw 智能体，所有档位均可用。

### [设置](#setup)

安装 OpenClaw：

macOS / LinuxWindows

bash

```
curl -fsSL https://openclaw.ai/install.sh | bash
```

运行引导式入门：

bash

```
openclaw onboard --install-daemon
```

在 VPS 上或通过 SSH 使用时，请使用设备码（device-code）。OpenClaw 会打印一个短代码和 URL，你可以在任意浏览器中打开以完成登录：

bash

```
openclaw onboard --auth-choice xai-device-code
```

也可以连接一个消息应用——Telegram、WhatsApp、Slack、Discord、Signal、iMessage 等——直接在那里与你的智能体对话。

更多信息请参阅 [OpenClaw 快速上手](https://docs.openclaw.ai/start/getting-started)和 [xAI 提供方文档](https://docs.openclaw.ai/providers/xai)。
