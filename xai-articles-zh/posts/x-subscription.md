# 推出 X 订阅

> 原文：[Introducing The X Subscription](https://x.ai/news/x-subscription) · xAI

2026 年 10 月 12 日

推出 X 订阅

Grok、Grok Bot、Cursor 和 X Premium，尽在一个订阅方案。

对比订阅方案

今天，我们推出 X 订阅（The X Subscription），它把 Grok、Grok Bot、Cursor 和 X Premium 汇聚到一个订阅方案中。未来几天内，我们将向全球所有人开放。

有史以来第一次，一份 AI 订阅就能覆盖从思考、创作到构建、分享的完整路径。

Grok

支持聊天、语音，以及图像和视频生成。

Grok Bot

为你提供能切实干活的 AI 队友。

Cursor

提供领先的本地与云端编程智能体。

X

带来认证标识、创作者工具和更少的广告，更高档位则可彻底移除时间线中的广告。

X 订阅的付费方案包含一份丰厚的 Grok 模型用量额度，在 Grok 和 Cursor 之间共享。

每个对应的新档位，每美元可获得的用量都高于它所替代的订阅方案。

无论你在 Grok 应用、X 上的 Grok 标签页还是 Cursor 中使用 Grok 模型，共享额度都同样适用。每个 X 订阅方案包含的我们模型的编程用量至少是对应 Cursor 方案的两倍。在新的方案下，Premium 及以上档位的 Cursor 中仍然可以使用第三方模型。这部分用量按 API 目录价单独计费，通过充值支付。

X 订阅从今天起面向新客户开放。

我们也在陆续为现有的 SuperGrok、Cursor 和 X Premium 订阅者推出切换选项。当该选项对你可用时，你会在账户账单设置中看到。你可以保留当前的订阅方案，也可以选择切换，并为旧方案获得按比例折算的退款。
