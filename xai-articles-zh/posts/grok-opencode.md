# 在 OpenCode 中使用 Grok

> 原文：[Use Grok in OpenCode](https://x.ai/news/grok-opencode) · xAI

2026 年 5 月 21 日

在 OpenCode 中使用你的 SuperGrok 或 X Premium 订阅。

---

现在，你可以在 OpenCode 中使用你的 SuperGrok 或 X Premium 订阅了。OpenCode 是一个开源编码智能体，既可以在终端中使用，也可以作为独立的桌面应用运行。

连接你的 Grok 账号后，即可开始使用 Grok Build 编码——它与 xAI [基于终端的编码智能体](https://x.ai/cli)所采用的模型相同。

### [安装](#setup)

安装 OpenCode：

bash

```
curl -fsSL https://opencode.ai/install | bash
```

运行引导式入门流程：

bash

```
opencode
```

当提示选择模型提供商时，选择 xAI Grok OAuth，登录后即可开始编码。更多信息请参阅 OpenCode 文档。
