eToro 的 AI 智能体 Tori 使用 SpaceXAI 的模型，把实时市场情绪直接融入 Tori 的投资工作流。

SpaceXAI 与 [eToro](https://www.etoro.com/) 很高兴地宣布，AI 智能体 Tori 现已由来自 X 的实时信息驱动。Tori 现在可以在市场情绪转变时即时读取，追踪实时信号，并用 SpaceXAI 最先进的文本模型分析信息。

## [市场以 X 的速度运转](#markets-move-at-the-speed-of-x)

最新信息总是最先出现在 X 上。SpaceXAI 的模型和平台为该平台提供了第一方支持，使 eToro 用户得以通过 Tori 询问并分析市场情绪。

近二十年来，eToro 打造了一个人们共同投资的地方，如今在 75 个国家拥有超过 4,000 万注册用户。用 SpaceXAI 模型驱动 Tori，进一步延续了「按需为所有用户带来最佳信息」的这一愿景。

## [基于 SpaceXAI API 构建](#built-on-spacexai-apis)

助力驱动 Tori 的同款实时情报和 X 实时感知，任何团队都可以通过 [API 控制台](https://console.x.ai/) 使用。无论你要构建研究副驾驶、情绪仪表盘，还是每日简报助手，都可以通过 API 控制台在几分钟内完成配置。
