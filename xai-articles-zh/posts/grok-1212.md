# 让所有人都能用上 Grok

> 原文：[Bringing Grok to Everyone](https://x.ai/news/grok-1212) · xAI

2024 年 12 月 12 日

Grok 现在更快、更敏锐，并改进了多语言支持。它已向 𝕏 平台上的所有人开放。

---

自 8 月发布 Grok-2 以来，我们一直在努力改进 𝕏 上的 Grok，新增了网页搜索、引用来源以及我们近期的图像生成器 Aurora 等功能。

过去几周，我们一直在悄悄测试新版本的 Grok-2 模型，它的速度快了三倍，并在准确性、指令遵循和多语言能力上有所提升。

今天，我们很高兴地宣布开始向 𝕏 上的所有用户免费推出这个新版本的 Grok-2。与以往一样，Premium 和 Premium+ 用户拥有更高的用量上限，并将率先使用未来的任何新能力。

## 搜索结果与引用

Grok 借助 𝕏 平台实时了解世界上正在发生什么。我们最近上线了两项额外功能来进一步增强这一体验：网页搜索和引用来源。现在，Grok 会同时利用 𝕏 上的帖子和更广泛互联网上的网页，为你的查询提供及时而准确的回答。我们还加入了引用功能，你可以轻松深入某个来源了解更多，或核实 Grok 提供的信息。

## Grok，画我！

Grok 擅长创作有创意的照片和有趣的梗图。现在，随着我们尖端的自回归图像生成模型 Aurora 的加入，它变得更强了。Aurora 为你的 Grok 图像生成带来了新的写实水平，看到大家分享的各种图片和梗图，我们非常兴奋。

作为与 X 平台集成的一部分，我们最近还发布了「画我」功能，让用户利用其 𝕏 个人资料中的信息生成自己的重新想象版本。如果你在 𝕏 上看到其他用户的「画我」帖子并想亲自试试，只需点击「用 Grok 创建你的版本」按钮！

## Grok，分析！

今天我们还推出 Grok 按钮，这项新功能将出现在你主页时间线的帖子上。这个按钮旨在帮助你发现相关背景、了解实时事件，并深入热门讨论。

## API 访问

一个月前，我们发布了企业 API 公测以及预览模型 `grok-beta` 和 `grok-vision-beta`。今天，我们为 API 新增两个模型：`grok-2-1212` 和 `grok-2-vision-1212`。这些模型在准确性、指令遵循和多语言能力上均有提升，为寻找高可控性、高智能模型的开发者提供了出色的选择。

得益于效率方面的改进，我们还将这些模型的价格降至每 100 万输入 token 2 美元、每 100 万输出 token 10 美元。

你现在就可以注册并以 25 美元的免费额度使用 API。
