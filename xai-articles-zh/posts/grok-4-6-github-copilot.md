Grok 4.6 现已在 GitHub Copilot 中上线，服务每天在 VS Code 和 GitHub 上工作的数百万开发者。

### [开始使用](#getting-started)

GitHub Copilot 覆盖多个产品，包括云端智能体、Copilot CLI 和 VS Code IDE。打开模型选择器并选择「Grok 4.6」，即可开始使用我们最新的编码模型。部分商业和企业用户需要在 Copilot 设置中启用该模型。

Grok 4.6 也可通过 [SpaceXAI 控制台](https://console.x.ai/?campaign=grok-4-6-github-copilot-blog&utm_source=website&utm_medium=referral&utm_campaign=grok-4-6-github-copilot-blog)使用，价格为每百万输入 token 2 美元、每百万输出 token 6 美元。关于该模型的更多信息（包括编码表现），请阅读 [Grok 4.6 发布公告](/news/grok-4-6)。
