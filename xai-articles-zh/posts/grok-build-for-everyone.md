# Grok Build 登陆 Web 与移动端

> 原文：[Grok Build on web and mobile](https://x.ai/news/grok-build-for-everyone) · xAI

[返回新闻列表](/news)

2026 年 8 月 19 日

Grok Build 现已在所有套餐上可用，覆盖 Web 端和移动端。

[开始构建](https://grok.com/?referrer=website&mode=build)

在 [Grok](https://grok.com/?referrer=website&mode=build) 里描述一个应用、游戏、网站或仪表盘，Grok 就会在你的聊天中实时构建出一个可用版本——无论是在 Web、iOS 还是 Android 上。

我们 [7 月首次发布](/news/grok-build-mode) 时，Grok 中的构建还是一个仅限 SuperGrok Heavy 的早期测试版（Early Beta）。此后我们让它变得更快，教会它发布和分享你的作品，把它接入了 X，并让它构建的应用可以调用我们自己的模型。这些能力今天全部向所有人开放。

## [发布为一个链接，随处分享](#publish-to-a-link-share-it-anywhere)

你发布的每个应用都会在 `grok.me` 上获得自己的地址，并由你决定谁能打开它：仅你自己、任何拥有链接的人，还是整个互联网。愿意的话也可以绑定你自己的域名。

Grok 还会生成随链接一同传播的配图。每个应用都会得到一张封面，粘贴到任何地方——消息、聊天、文档、时间线——都会展开为富预览。它是专为你的应用生成的，你可以重新生成、上传自己的图，或者在对话中让 Grok 重新设计。

## [为时间线而生](#made-for-the-timeline)

你在 X 上分享的应用不会以光秃秃的链接形式出现。横幅会内联渲染并带上你的账号 handle，游戏还会在卡片中获得播放入口，人们无需离开信息流就能与应用见面。

## [构建强大的应用](#build-powerful-apps)

为某个应用开启 SpaceXAI API，它就可以在自己的代码内部调用 Grok 进行聊天、图像和语音——无需创建、粘贴或轮换任何密钥。问答游戏可以按需生成新题目，支持页面可以用你的语气回答问题，笔记应用可以自我总结。访问权限按应用粒度授予，你随时可以撤销。

早期测试版之后的另一批新能力：

- **混编（Remix）。** 让其他人复刻（fork）已发布的应用，改造成他们自己的版本。
- **自定义域名。** 把你自己的域名指向你的应用。
- **导出到 GitHub。** 将整个项目推送到仓库，然后在编辑器或 [终端版 Grok Build](/news/grok-build-cli) 中继续开发。
- **密钥（Secrets）。** 将第三方服务的 API 密钥存储在应用代码之外。
- **连接器（Connectors）。** 接入对你的业务重要的数据，把它变成实时、可筛选的仪表盘。
