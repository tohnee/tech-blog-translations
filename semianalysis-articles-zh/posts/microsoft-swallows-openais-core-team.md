# 微软吞下 OpenAI 核心团队——GPU 产能、激励结构、知识产权、OpenAI 残余政权

> 原文：[Microsoft Swallows OpenAI’s Core Team – GPU Capacity, Incentive Structure, Intellectual Property, OpenAI Rump State](https://newsletter.semianalysis.com/p/microsoft-swallows-openais-core-team) · SemiAnalysis

> ⚠️ 付费订阅文章：以下为公开可见的预览部分翻译，正文在付费墙处截断，并非全文。

**离开这些人，OpenAI 什么都不是。**

OpenAI 内爆了。Satya Nadella 竟然精妙地驾驭了周末这一连串疯狂事件，最终把 OpenAI 的核心研究团队收入了微软麾下。

> 我们非常兴奋地宣布，Sam Altman 和 Greg Brockman 将与同事们一起加入微软，领导一个新的高级 AI 研究团队。
>
> [Satya Nadella](https://twitter.com/satyanadella/status/1726509045803336122)

为那些没被这场大戏卷进去、好好享受了周末的人快速复盘一下：[Sam Altman（CEO）被 OpenAI 董事会以含糊的理由解雇](https://openai.com/blog/openai-announces-leadership-transition)。此举事先未与 OpenAI 的任何投资者（包括微软）商量。Greg Brockman（董事长兼总裁）也被踢出董事会并遭降职，[随后愤而辞职](https://x.com/gdb/status/1725736242137182594?s=20)。OpenAI 董事会[对股东乃至除 AI 安全之外的任何事物都没有法律义务](https://openai.com/our-structure)，本有充分机会解释这一激进举动，但[迄今为止他们没有，甚至连内部都没解释](https://x.com/karpathy/status/1726289070345855126?s=20)。GPT-4 与 GPT-5 的[其他多位关键负责人](https://openai.com/contributions/gpt-4)，如 Jakub Pachocki 和 Szymon Sidor，也已辞职。

CTO Mira Murati 被[任命为临时 CEO](https://openai.com/blog/openai-announces-leadership-transition)。周六晚上，在我们称之为[百心之夜](https://twitter.com/E0M)的夜晚，大多数 OpenAI 员工[包括 Mira 本人在内](https://x.com/miramurati/status/1726126391626985793?s=20)公开[表态支持 Sam 和 Greg](https://twitter.com/E0M)。员工和微软都希望 Sam 回来。

![](https://substack-post-media.s3.amazonaws.com/public/images/86b3a1a4-5f69-417a-8fad-812d996a1e23_1036x340.png)
*这是推特历史上最精彩的一个周末——就梗图而言也一样，不只是上面这种正经事。*

周日，曾有[让 Sam 回归公司的谈判](https://x.com/sama/status/1726345564059832609?s=20)，但董事会最终决定拒绝。他们转而任命 Twitch.tv 创始人及长期 CEO Emmett Shear 为 CEO。Emmett Shear 曾公开表示希望[大幅放慢 AI 的进展](https://twitter.com/eshear/status/1703178063306203397)。

Sam 和 Greg 曾考虑创办一家全新的初创公司，但那很可能造成超过 1 年的减速。取而代之的，是微软内部出现了一个新的子公司。

> Sam，我非常高兴你加入并担任这个新集团的 CEO，为创新设定新的节奏。多年来，我们在如何给创始人和创新者在微软内部留出打造独立身份与文化的空间方面积累了很多经验，包括 GitHub、Mojang Studios 和 LinkedIn，我期待你也能做到。
>
> [Satya Nadella](https://twitter.com/satyanadella/status/1726516824597258569)

OpenAI 核心团队正在大规模出走并加入微软。微软内部的这个新组织将获得**来自 OpenAI 的数百名技术人员**。

## **激励结构**

OpenAI 的营利性子公司原本即将以 800 亿美元以上的估值进行老股转让。这些「利润参与单位」（PPUs）对关键员工而言价值将超过 1,000 万美元。不用说，这现在泡汤了，OpenAI 董事会愚蠢地毁掉了团队中许多人实现世代财富的机会。尽管他们真的把到手的袋子摔了，但离职的关键 OpenAI 员工将会得到极好的安置。

Satya 与 Sam、Greg 达成的惊人协议中，很可能包括这一点：加入微软的这些 OpenAI 关键员工，手中如今一文不值的 PPUs 将以微软股权的形式变相重置，并在数年内归属。对那些在 OpenAI 待了多年的人，薪酬包将达到 1,000 万美元以上（$1e7+）。

这个新团队将做出的各种豪赌与冒险，很可能还配有巨额的激励性薪酬，从而让 OpenAI 团队保持一致并受激励去做他们最擅长的事——加速。

那种认为追逐世代财富的冒险者不愿加入微软、而要去过初创生活的论调，现在已没什么意义。这个子公司也有可能获准以非微软股票直接形式向员工授予自己的股权。

## **算力为王**

微软此前对 OpenAI 押下重注，计划[每年投入超过 500 亿美元数据中心开支](https://www.semianalysis.com/p/microsoft-infrastructure-ai-and-cpu)，竞逐 AGI 并部署其基于 GPT-4 的副驾驶产品。我们的数据显示，OpenAI 下一代训练超算之一位于亚利桑那州，到明年年中单一站点将拥有超过 75,000+ 张 GPU。

我们的数据还显示，微软明年将直接采购[超过 400,000 张 GPU](https://www.semianalysis.com/p/microsoft-infrastructure-ai-and-cpu)，用于训练和副驾驶/API 推理。此外，微软还将通过与 CoreWeave、Lambda 和 Oracle 的云交易获得数万张 GPU。

OpenAI 获得了哪些保证，目前还有几个大问号。微软对 OpenAI 的投资大部分以算力额度的形式存在。虽然双方就必交付的超算规模有协议约定，但我们认为微软原本的推进就远超这些目标、将向 OpenAI 交付超出法律义务的算力，这意味着重新平衡是可能的。

微软很可能收回或不交付相当一部分原本为 OpenAI 计划的算力。这些算力资源可以调拨给新的内部团队。更有甚者，鉴于微软法务团队的强悍，已交付或即将交付的算力中或许还有更大一部分可以被收回。

如果新团队分拆出去创办自己的初创公司，他们将极难在 Anthropic 或 Google 之前获得足够算力来训练 GPT-5 量级的模型。考虑到这里存在某种一骑绝尘的逃逸速度，这将使他们在 AGI 竞赛中处于巨大劣势。加入微软后，前 OpenAI 团队明年仍能获得所需的算力资源。

这一事态发展很可能进一步加速开支，微软的 GPU 订单将不得不再次上调，以履行对 OpenAI 的合同，并为新公司提供明年打造 GPT-5 所需的一切。

## **知识产权**

Sam 被解雇后几小时内，Satya 在推特上毫不掩饰地「支持」OpenAI 新领导层。这实际上是一句毫不遮掩的威胁：「我不需要你们。」（就副驾驶部署而言，他确实不需要）

> 我们与 OpenAI 有一项长期协议，可完全获取我们在推进创新议程和激动人心的产品路线图方面所需的一切。
>
> [Satya Nadella，微软 CEO](https://twitter.com/satyanadella/status/1725656554878492779)

微软拥有完全的法定权利，可获取 GPT-4 基础模型的权重，以及各种微调版本和 DALL-E 3。

如果这个团队走初创公司的路，他们本需花费大量时间重建 GPT-4。而在微软，他们将能直接使用未来产品所需的大部分知识产权。

更重要的是要弄清楚，微软是否在法律上可以直接访问用于预训练和 RL 的全部数据与代码。这些显然都存储在 Azure 上，但如果 Sam 领导的新内部团队能自由访问，他们基本上可以毫无顿挫地从原来的进度继续推进。如果拿不到，我们估计可能只会比原计划推迟 4-6 个月。虽然这么短的延迟说出来听着很疯狂……但人才就是一切。

## **OpenAI 芯片**

没有 Sam 和某些关键人物，OpenAI 的芯片研发实质上已经死亡。这些努力与微软内部的芯片项目完全独立——后者的详细规格、性能等我们已在[此处](https://www.semianalysis.com/p/microsoft-infrastructure-ai-and-cpu)深入解析。

现在在微软子公司内部，这些计划变得更为近切、更可实现。
