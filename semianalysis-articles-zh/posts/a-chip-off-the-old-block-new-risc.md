# 有其父必有其子？新 RISC-V 初创公司网罗苹果、Google、Marvell、高通、英特尔和 AMD 众多资深 CPU 架构师

> 原文：[A Chip Off The Old Block? New RISC-V Startup Garners Many Senior CPU Architects From Apple, Google, Marvell, Qualcomm, Intel, and AMD](https://newsletter.semianalysis.com/p/a-chip-off-the-old-block-new-risc) · SemiAnalysis

[本文已更新，补充了公司名称及更多细节，见此处。](https://semianalysis.substack.com/p/rivos-inc-a-chip-off-the-old-block)

一家新的 CPU 初创公司出现了，而且人才济济。SemiAnalysis 发现，其工程师中有许多人来自苹果。苹果的资深 CPU 领导层出现了一定程度的人才外流，且波及 Google、Marvell、高通、英特尔（Intel）、AMD 等许多其他公司。

Nuvia 仍历历在目——那是一家领导层出身苹果的公司。他们横空出世，其工作成果刚一亮相，就被高通以 $1.4B 抢购。Nuvia 当时收到过多份达到或超过 $1B 的报价。

![](https://bucketeer-e05bbc84-baa3-437e-9518-adb32be77984.s3.amazonaws.com/public/images/29476f44-43b9-4b84-a3fc-4a75f5c8b163_1024x640.png)

这家公司成立几个月时的人才密集程度，可能比当年的 Nuvia 有过之而无不及。下面我们逐一介绍其高管，并简要盘点资深工程师们的来历。

首先是联合创始人之一 Brian Campbell。他因任职 SiByte 而闻名，该公司生产基于 MIPS 的 CPU 核心。这家公司被博通（Broadcom）收购后，他晋升至首席工程师（principal engineer）。此后他加入 P.A. Semi 担任工程总监。P.A. Semi 最终被苹果收购，该团队撑起了苹果极为成功的自研芯片事业。他一路升到苹果硬件技术总监（Director of Hardware Technologies）。这是一个非常高级的职位，负责为 iPhone、iPad、Apple Watch、Mac 和 AirPods 设计的庞大半导体产品线的芯片。

Belli Kuttanna 是 CTO 兼联合创始人。他的职业生涯可能更加传奇。Belli 先后在德州仪器（TI）、摩托罗拉和 Sun Microsystems 做设计，之后进入英特尔。在英特尔，他获得了令人艳羡的 Intel Fellow 头衔。此后他出任高通技术副总裁（VP of Technology），随后重返英特尔，担任新技术集团（New Technology Group）首席架构师。他又晋升为 Senior Fellow，并成为英特尔资本（Intel Capital）的 CTO。Intel Capital 负责管理企业风险投资、全球投资与并购。他负责评估众多投资项目的技术，并孵化了数十家初创公司。经手的名字数以百计，其中比较知名的包括 SiFive、BlueStacks 和 Ayar Labs。

Mark Hayter 是 LinkedIn 上明确列名的第三位联合创始人。他先后任职于 DEC、SiByte 和博通，在博通担任高级工程经理（Sr. Engineering Manager）。他的下一站是 P.A. Semi，出任硬件与系统架构副总裁。被收购后，他一度担任苹果总监，随后创立新公司 Agnilux，担任 COO 兼系统架构师。Google 收购了这家公司。Mark 的最后一个职务是 Google 工程总监。

叶克洲（Tse-Yu Yeh）是芯片工程副总裁。他从英特尔起步，同样经历了 SiByte 到博通的旅程，随后又全程参与了 P.A. Semi 到苹果的旅程。在苹果，他先后担任架构与验证工程经理、工程总监以及 CPU 设计高级总监。

Ken Dockser 是首席 CPU 架构师。他的足迹从 DEC 到 NexGen Microsystems、MIPS、VLSI 再到 IBM。他曾任高通数据中心总监，领导 Centriq 服务器 CPU 产品。该产品具备竞争力并开始斩获设计导入（design win），客户包括 CloudFlare 和中国超大规模云厂商。但一场激进的敌意收购企图迫使高通砍掉尚未盈利的团队以安抚股东，这款产品就此夭折。他后来出任高通研发总监，主导 Cloud AI 100。这是高通面向 AI 推理的产品，[正在边缘计算领域不断拿单，甚至赢得了一家超大规模云厂商](https://semianalysis.com/qualcomm-hits-a-homerun-ai-100-powerful-ai-inference-acceleration-for-the-edge/)。他还领导了高通的 RISC-V 业务，并且是 RISC-V 董事会成员！

![](https://bucketeer-e05bbc84-baa3-437e-9518-adb32be77984.s3.amazonaws.com/public/images/52aeb8dd-f9bb-4a59-9fbb-b3c7c04c1427_1024x769.jpeg)

除这些高管之外，我们还发现了十几名员工。我们不会列出他们，因为我们认为非高管人士的隐私不应被侵犯。不过我们会列举他们的一些成就。除了来自苹果的资深员工外，还有不少经验丰富的苹果老将。此外，他们还有一位 Google 的芯片负责人。Cavium/Marvell 团队的一些人也已加盟，包括首席架构师和总监。他们还有来自其他失败的 CPU 尝试的老兵，比如 Xeon Phi。专家名单还包括一位 JEDEC（制定内存等众多标准的组织）的董事会成员。我们还找到了其他来自英特尔和 AMD 的负责人。

**SemiAnalysis 认为，这将是第一个真正高性能的 RISC-V 设计！**

顺带一提，SiFive 有一些有意思的设计，但距离高端 Arm 和 x86 还差了十万八千里。即便是他们那些未经证实的营销说辞，也只敢说最新的 P550 核心勉强胜过 2017 年发布的 Arm Cortex A75。SiFive P550 CPU 要到 2022 年底或 2023 年初才计划实现晶圆量产。他们上一款「高性能」CPU 核心虽然号称打败 Arm Cortex A72，却从未流片。

关于这家尚未公开名称的公司的人员有多么资历深厚、战绩彪炳，我们已经兜了一大圈——但 3 到 4 年后请当心，他们劳动的果实极有可能震动整个行业。我们还不确定他们的商业模式是什么。IP 授权、数据中心、移动市场，或者一直做大直到被更大的公司收购，都可能行得通。无论如何，街区里似乎又出现了一家来势汹汹的初创公司——只不过这次是 RISC-V 口味的！
