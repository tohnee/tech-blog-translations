# 分辨现实与炒作——量子计算解析

量子计算机被炒作上了天又送了回来。时至今日，尽管口号不断、投资以十亿美元计，仍然没有一台有用的量子计算机被造出来。今天，我们想撕开围绕量子计算机的过度炒作，讲清楚量子计算产业的真实情况。本报告将讨论量子计算的用途、造出一台有用的量子计算机需要什么，以及为什么那一天仍遥遥无期。

我们还会讨论「数 qubit」的把戏，以及为什么那些争抢「最高 qubit 数量子计算机」名头的营销负责人正在出尽洋相。此外，我们将讨论量子计算机对经典计算产业的影响——这些影响已经在全行业显现，主要体现在新的加密方案上。

特别感谢 SPIE Lithography and Patterning 和 SPIE Optics and Photonics，他们帮助我们研究这一主题并提供了大量图片。特别感谢 [Domain of Science](https://www.youtube.com/channel/UCxqAWLTk1CmBvZFPzeZMd9A) 提供的优秀深度研究。

## **量子计算基础——纠缠、叠加、干涉**

要理解量子计算机为什么可能比经典计算机更快，关键是理解比特（bit）与量子比特（qubit）的区别。

在经典计算中，比特是信息的基本单位，它只能表示 0 或 1。

相比之下，qubit 是量子计算中信息的基本单位。qubit 不局限于只表示 0 或 1，它可以同时表示 0 和 1 的组合。这被称为**叠加（superposition）**。这意味着一个 qubit 可以同时处于 0 和 1 的一系列概率组合之中。然而，当 qubit 被测量时，它只会依据这些概率输出 0 或 1 之一。

所以，经典计算机一次只能处于两个状态之一，而量子计算机可以同时处于多个状态的**叠加**之中。这正是量子计算机的优势所在：它们可以同时探索多种不同的可能性，而不必像经典计算机那样一个一个地尝试。

现在来看经典计算机可处的状态数量如何影响其性能。在经典计算机中，每增加一个比特，状态数量按 2 的幂增长。例如，有 1 个比特，可以表示两个状态（0 或 1）；有 2 个比特，可以表示四个状态之一（00、01、10 或 11）；有 3 个比特，可以表示八个状态之一（000、001、010、011、100、101、110 或 111），依此类推。

相比之下，量子计算机可处的状态数量随 qubit 数指数增长。例如，有 2 个 qubit，同样有四个状态（00、01、10 或 11），与 2 比特的经典计算机一样，但由于比特之间**纠缠（entangled）**，量子计算机可以同时表示全部 4 个状态。有 3 个 qubit，可以表示八个状态（000、001、010、011、100、101、110 或 111）以及这些状态的所有叠加。这意味着量子计算机可表示的状态数量比经典计算机增长得快得多。

这正是量子计算机如此强大的原因：它们可以同时探索数量庞大的状态，从而比经典计算机快得多地解决特定问题。经典计算机也可以处于任意数量的状态，但任一时刻只能处于其中一个。

需要理解的最后一个核心概念是**干涉（interference）**。每个 qubit 实际上都是一个量子波函数的表示。量子波函数是对量子力学中一切事物的数学描述，它描述了在某个位置找到粒子、或粒子具有特定能量或自旋的概率。

当 qubit 相互纠缠时，它们的波函数相加，构成描述量子计算机整体状态的总体波函数。这种波函数相加称为**干涉**。

与水中的波一样，当量子波相加时，它们可以相长干涉、叠加成更大的波（放大），也可以相消干涉、彼此抵消（抑制）。在量子计算机中，总体波函数决定了各个状态出现的不同概率。通过改变不同 qubit 的状态，我们可以改变测量量子计算机时各个状态出现的概率。

![](https://substack-post-media.s3.amazonaws.com/public/images/d6627252-9561-45bc-9cdc-a5750820b5c1_1285x450.png)

理论上，通过精细操纵不同 qubit 的状态，量子计算机可以利用干涉改变概率分布，从而比经典计算机快得多地解决问题。

这就是干涉在量子计算中如此重要的原因：它让我们能够利用多状态的叠加，提高正确答案的概率、降低错误答案的概率，这样当我们测量量子计算机、使所有状态坍缩、只输出 1 个状态时，从计算机得到的结果更有可能是正确答案。

## **量子算法与用途**

量子算法是使用量子计算机解决问题的一种特定方法。量子算法的设计初衷是利用量子计算机的独特性质（如叠加和纠缠），比经典算法更快地解决问题。量子算法有很多种，我们只想聚焦其中几个关键的。

最著名的是 Shor 算法，它是一种能把大数分解得远快于任何经典算法的量子算法。分解一个数，是指找到那些相乘等于原数的质数。例如，15 的质因数分解是 3 和 5，因为 3 x 5 = 15。

在经典计算机和现代半导体上，乘法非常容易、硬件成本极低，即使数字变大也是如此。相比之下，对经典计算机而言，被分解的数字每多一位，分解难度就指数级上升。作为对照，Shor 算法随分解问题复杂度的增加呈多项式（而非指数）增长。

Shor 算法的原理是利用量子叠加和量子纠缠同时探索该数的许多种可能分解，再利用干涉放大正确分解的概率、抑制错误分解的概率。当量子系统被测量时，正确分解作为结果出现的可能性要大得多。

这很重要，因为 RSA 加密算法的安全性恰恰建立在「当前计算机很难分解大数」这一事实之上。许多其他加密和哈希算法与 RSA 命运相同。密码学是我们生活中安全的基石——无论是网站加密、电子邮件还是银行账户。

现代加密意味着用经典计算机破解银行账户、最高军事机密，或你与 [www.SemiAnalysis.com](http://www.SemiAnalysis.com) 的安全连接基本不可能。而理论上，一台拥有约 1,000,000 个 qubit 的量子计算机可以在几个月内攻破 AES 256 等加密算法。因此，美国国家标准与技术研究院（NIST）正在为经典计算机提出并批准 4 项抗量子标准。

有些标准会比其他的更早被需要，但重点是：未来销售的大多数处理器都将包含针对这些新标准的加速模块。经典计算机仍然可以使用这些新加密标准，而且即便量子计算机在未来一二十年内任何时候真正落地，也无法攻破它们。这些新加密标准极其重要，因为保险、政府、银行和医疗相关的信息往往会被保存极长时间——这意味着今天加密的数据，20 年后即便被破解仍可能是有价值的数据。

还有适合物理、化学、模拟和数据搜索/排序等许多其他问题的量子算法，在 AI 领域也有诸多用途。在半导体器件制造与图形化的最前沿，量子计算的角色可以有多种形态：从电子动力学研究，到曝光时 EUV 光刻胶二次电子效应，再到新兴存储器或先进 CMOS 的界面仿真与工程，乃至整个晶圆厂的工艺分析。

值得注意的是，**并非所有问题放到量子计算机上都更好**，因为它们运行的是与经典计算机不同的算法。同样值得注意的是，尽管营销宣传喧嚣，**目前尚不存在有用的量子计算机**。

## **造一台有用的「超级计算机」**

公司和初创企业在尝试许多途径来建造量子计算机，但无论哪条路，他们都要与同样的问题搏斗。首要问题是：qubit 必须彼此纠缠、而与系统之外的任何东西都不发生纠缠。系统一旦被观测，就会失去量子态并坍缩到最终答案，有点像薛定谔的猫。如果 qubit 与外界发生相互作用，模型就会受影响，退相干（decoherence）便会悄然侵入。

微弱的电磁辐射（包括宇宙射线）、温度或机械振动都可能影响 qubit。这些相互作用会使 qubit 失去量子特性，导致计算出错。最大的挑战在于：如何物理地造出一台在运行时与环境完全隔离、同时又可物理控制和测量的设备。而且，随着系统中加入越来越多的 qubit，这种噪声会越来越难屏蔽。我们必须接受的现实是：噪声一定存在。

![](https://substack-post-media.s3.amazonaws.com/public/images/fd4b5b5c-1302-4cb0-8f9e-3a858ac80d1e_3402x1659.png)
*PsiQuantum*

此外，qubit 的制造本身也有诸多复杂性。上图是 PsiQuantum 的 CEO 喜欢打的一个比方：qubit 很像广告里的汉堡——实际上，当你出门从一家在电视上打广告的连锁店买到汉堡时，你拿到的和广告里的相去甚远。

世界上没有任何单一工艺能对复杂器件做到 100% 的原子级精度。唯一接近的行业就是半导体产业，但即便如此仍存在巨大的困难和挑战。半导体产业靠着大量的良率 harvesting 和分 bin（binning）来补偿制造中的不完美。而 qubit 依赖量子现象，对制造过程中的任何波动都更加敏感。

现实是：让这些 qubit 纠缠起来很难，而且它们会因干扰很快失去相干性。经典计算产业使用大量冗余结构，如核心、互连、SRAM 和 ALU。量子产业由于其敏感性，需要更高程度的冗余。

![](https://substack-post-media.s3.amazonaws.com/public/images/a1e48136-1e24-4c2c-ba6e-0302741e0b17_3780x2121.png)

营销宣传会不断以某个 qubit 数量宣称「量子霸权（quantum supremacy）」——该数量在理论上能超越经典计算机的许多运算——但这些 qubit 无法在任何合理的时长内保持纠缠。一旦干涉介入、相干性丧失，数据就毫无价值，算法也没有完成任何有用的工作。当每个物理 qubit 直接代表量子计算机中的 1 个逻辑 qubit 时，错误率非常高。

因此，量子计算机需要 1,000 到 100,000 个相互纠缠的物理 qubit 来表示 1 个无噪声 qubit。这种无噪声 qubit 的错误率显著更低，因而可以运行多得多的时钟周期，才有可能进行真正的计算。即便按估计的下限，现实是量子计算机要完成任何有用的工作都需要超过一百万个 qubit。

![](https://substack-post-media.s3.amazonaws.com/public/images/179eba33-c5b7-414b-a1bb-cf85b7c3a1fb_3411x1662.png)

无论采用哪种技术路线，来自外界的噪声都必须最小化；因此几乎每一种量子计算方案都试图在尽可能接近 0 开尔文的温度下运行。这类低温冷却方案的问题在于：当计算机扩展到超过一百万个 qubit 时，那个系统会是什么样子。

关键的结论是：qubit 数量不是值得关注的指标，错误率才是。

数十家公司相信自己的量子计算机路线是可扩展的。各家有不同的量子计算模型和/或材料选择。我们并非各种类型与方法的专家，因此将以 PsiQuantum 的路线为例，因为它有助于为思考其他公司的方案搭建主要框架。每种路线都各有利弊。

PsiQuantum 的论点是：大多数量子方案依赖电域（electrical domain），在小规模上或许可行，但无法扩展到数百万 qubit。数百万 qubit 意味着一个由许多芯片和中间网络构成的系统，而网络本身也需要低温冷却和屏蔽以隔绝外界干扰。

光子在网络互连到其他芯片和系统时，理论上要容易保护得多、不易受干扰。如果计算在电域进行、网络在光域进行，就需要电-光转换器件来翻译。这些电-光器件会引入另一条干扰途径，因此计算和数据传输必须全部在光域完成。

由于计算和网络都在光域进行，PsiQuantum 认为其系统可以在比电域量子计算机更「正常」的温度下运行。他们的系统目前仍处于个位数开尔文区间，但与正在向毫开尔文区间推进的其他量子计算机相比，这已经容易实现得多。

让光子相互作用或纠缠非常困难，这是 PsiQuantum 面临的主要挑战之一。PsiQuantum 用微环谐振器（micro-ring resonator）控制其 qubit。微环谐振器的制造挑战重重：结构上哪怕 1 纳米的波动都会改变其工作方式。这一讨论将放在补充章节中。

PsiQuantum 还主张他们不需要那么低温的系统。PsiQuantum 的路线还用到了一些有意思的技术，例如[混合键合（hybrid bonding）](https://www.semianalysis.com/p/advanced-packaging-part-1-pad-limited)和[共封装光学（co-packaged optics）](https://www.semianalysis.com/p/globalfoundries-fotonix-the-leading)，通过[其合作伙伴 GlobalFoundries](https://www.semianalysis.com/p/globalfoundries-fotonix-the-leading) 实现。这一合作在代工领域非常有趣：PsiQuantum 自购设备并安装进了 GlobalFoundries 的制造设施。对于 GlobalFoundries、TSMC 等的正常代工关系而言，这是非常独特的。
