# 一条胳膊一条腿：Arm 兑现其真正价值之路

> 原文：[Arm and a Leg: Arm's Quest To Extract Their True Value](https://newsletter.semianalysis.com/p/arm-and-a-leg-arms-quest-to-extract) · SemiAnalysis

**若能收取高通式的版税，估值还算便宜？**

Arm 的成功可归因于其创新的架构、灵活的授权模式以及强大的合作伙伴生态。这种高度灵活的授权模式，加上对汽车、物联网（IoT）和数据中心的大举投资，使 Arm 的利润率多年来受到压制。

如今螺丝正在拧紧：Arm 希望通过逐步上调定价来维持可持续的商业模式，更加接近于提取它实际为市场创造的价值，而不是变相打折以换取市场份额增长。今天我们将深入探讨智能手机行业的各家版税率及其还能上调到多高、[Arm 在高通诉讼中动用核选项](https://www.semianalysis.com/p/arms-nuclear-option-qualcomm-must)会带来哪些情景、数据中心前景、Arm 在小芯片（chiplet）生态中的角色、Arm 中国以及 RISC-V。我们还将分享我们对公司未来前景的分析框架和模型。

Arm 与客户的合作选项覆盖一个区间，越沿曲线向右，变现能力越强——从单纯的指令集授权，一直到芯片设计合作乃至小芯片。

Arm 是一种指令集架构（ISA），即软件与硬件（具体说是微处理器）之间的接口。指令集是芯片能够执行的特定指令的集合。为特定设备编写的所有代码，本质上都是这些指令组合的一种抽象。Arm ISA 是世界上无处不在程度最高的指令集，另一个著名的指令集是我们在许多 CPU 中见到的 x86。[RISC-V 也正在急速崛起](https://www.semianalysis.com/p/ventana-risc-v-cpus-beating-next)。

Arm ISA 的护城河非常深，在智能手机领域尤甚。由于诸多软件层面的挑战，我们不认为智能手机能在短期内转向 RISC-V。设计 CPU 绝非易事，迄今为止只有少数几家公司（AMD、Intel、IBM、Apple 和 Arm）设计出过优秀的 CPU 并将其推向市场。这需要大量时间和工程人才——光有钱造不出好 CPU。Apple 通过架构许可协议（ALA）获得 Arm ISA 授权，多年来一直在自研核心。[HiSilicon 同样获得了 Armv9 架构授权、且采用自定义核心设计，这也是华为新 Kirin 9000S 消息中另一个令人震惊之处](https://www.semianalysis.com/i/136965104/huawei-kirin-s)。

由于自定义核心与 CPU 的设计难度极高——即便有 Arm 指令集加持——大多数客户选择使用外部 CPU。其他那几家设计 CPU 的公司只在你购买它们的芯片或整机时才让你用上其 CPU，而 Arm 灵活的商业模式允许你通过签订技术许可协议（TLA）购买 Arm「现货」CPU 设计，把 CPU 集成到自己的芯片里。

通过 TLA 获得的参考设计可以有不同程度的定制。MediaTek 等客户在其智能手机 SoC 中使用的 Arm Cortex 核心是完全的现货，而高通 Snapdragon SoC 的 CPU 核心（Kryo）则是在 Cortex 核心上稍作定制。在其他条件相同的情况下，TLA 比 ALA 更贵、版税率更高，因为 TLA 提供的增值更大，并为芯片设计公司省去了大量设计工作。

Arm 也在尝试提供更灵活的选项以适应不同客户用例，例如最近在 Hot Chips 2023 上宣布的、面向其数据中心与云计算 Neoverse 系列 CPU 核心的计算子系统（CSS）产品。CSS 是一块经过完整验证的模块，允许在内存、I/O 以及片上或片外所需的额外加速器方面做一定定制。这在保留一定定制空间的同时，带来了更低成本和更短的设计周期。

Arm 还在向更多细分市场扩张，包括合约芯片业务。这将使它与 [Broadcom](https://www.semianalysis.com/p/broadcoms-google-tpu-revenue-explosion)、[Marvell](https://www.semianalysis.com/p/marvelldeepdive2022) 等正面竞争。不只收取版税、而是设计整颗芯片，将允许 Arm 收取更高的价格。这一机会还会创造新客户——例如小米（Xiaomi）、vivo 等手机厂商正在与 Arm 一起设计定制芯片。这将绕过高通这个中间商，大幅提升 Arm 的总可服务市场（TAM）。Arm 庞大的 IP 阵列给客户提供了丰富选择，其 IP 之间的互操作性降低了开发成本、缩短了上市时间，也让许多新的物联网、边缘和数据中心玩家得以立身。

其他公司往往靠向客户追加销售产品和服务来成长，Arm 却陷入了截然相反的悖论：随着主要客户成长并日趋成熟，客户反而可能减少对 Arm 的依赖——它们开始自研核心，从 TLA 降级为仅签 ALA。

例如，高通一直是完全现货核心的买家。然而，在收购了设计全自定义 Arm 架构 Phoenix 核心的数据中心 CPU 初创公司 Nuvia 之后，高通表示未来有意在 Snapdragon 应用处理器中使用 Phoenix 核心。毫无疑问，[这是高通与 Arm 争议的一部分——这将让高通得以在事实上绕开向 Arm 支付技术授权费](https://www.semianalysis.com/p/arms-nuclear-option-qualcomm-must)。

![](https://substack-post-media.s3.amazonaws.com/public/images/c8b1592f-6a61-4be3-9b2c-3ccc33a74d7d_2560x1440.jpeg)

计算子系统也是 Arm 从客户手中承接更多设计工作的一种方式。以整体形式提供计算子系统后，客户若想转向自研架构会更加困难，因为一整套验证、确认和 NOC IP 都必须从头建立。

Arm 甚至可能为 Marvell、Google、Amazon、Microsoft、Meta 等主要数据中心客户提供数据中心 CPU 小芯片（chiplet）。这些公司正在设计从 CPU 到 ASIC 的各类芯片，但这并不妨碍它们使用 Arm 卖给它们的基于 Arm 的 chiplet。这将大幅削减设计成本——在设计成本节节攀升的当下，这一点很重要。

## **Arm 的产品组合（Cortex、Mali 等）**

Arm 的身影出现在种类繁多的芯片与设备中。采用 Arm 架构与核心的设备，从简单的微控制器，到全球几乎所有的智能手机应用处理器，再到 Nvidia Grace Hopper 超级芯片这类 HPC 用例设备，覆盖整个谱系。

就现货核心而言，Arm 的主打产品是 Cortex 系列 CPU 核心。Arm 还设计 GPU、NPU、ISP、互连等。

Arm 较近期的一项举措是设计专为数据中心和云量身定制的核心。Neoverse 核心于 2019 年首次推出，已在超大规模云厂商中获得采纳，AWS Graviton 和 Nvidia Grace 是其中的代表。

![](https://substack-post-media.s3.amazonaws.com/public/images/8656c424-f7ce-44b2-9ece-85f4473a6b2b_602x365.png)

## **Arm 的增长机会（或者说机会的匮乏）**

与许多人一样，我们读完 IPO 招股文件后的第一反应是不为所动。Arm 提供的是真正基础性的半导体技术，其 IP 每年随约 300 亿颗 IC 出货。在智能手机等一些应用中，Arm 是唯一的选择。

如果你问芯片分析师，世界上最重要的半导体公司有哪些，多数人的答案会包括台积电（TSMC）、三星（Samsung）、ASML、英特尔（Intel）和 Arm。然而 Arm 的营收只是这些公司的一小部分：截至 2023 年 3 月的财年，Arm 仅实现 27 亿美元营收、约 6.7 亿美元经营利润，利润率 25%。这个营业利润率不算差，但对一家在核心细分市场占据支配性份额的领先半导体 IP 公司而言，并不相称。

Arm 的营收增长尚可，但远称不上惊人：过去 10 年其营收复合年增长率（CAGR）为 12%。展望未来，Arm 最主要的终端市场智能手机很可能已是成熟且饱和的细分市场。在低端微控制器领域，RISC-V 的竞争正在浮现。云和数据中心是 Arm 未来渗透潜力最大的细分市场，但仅靠这一块也不足以把 Arm 的总设计导入（designed-in）出货量推高太多。

在这一背景下，传闻中 545 亿美元的 IPO 估值只有在 Arm 商业模式发生巨变的情况下才说得通——而这恰恰正在发生。如果你还记得，去年我们是率先报道这一变化的。

这一变化就是：从只向芯片制造商收费，改为也向手机厂商收费。

我们将先讨论进行 IPO 的短期逻辑，再转向长期「自救」的潜力——如今 Arm 重新成为 Softbank 的焦点。

## **IPO 的近期逻辑**

推动这些变化以及 IPO 交易本身的一个关键外部因素，是改善处境艰难的 Softbank 愿景基金和 Softbank 集团公司的命运。Softbank 愿景基金一期在 900 亿美元投资的基础上，成立以来累计盈利 124 亿美元——对一只已成立 6 年的基金而言回报欠佳；而愿景基金二期成立以来累计亏损 186 亿美元。

![](https://substack-post-media.s3.amazonaws.com/public/images/b3b307c7-f366-4f24-acdc-5ed2cba4f51e_903x504.png)

2017 年，Softbank 以 82 亿美元将 Arm 25% 的股权卖给愿景基金一期，却在 2023 年 8 月、IPO 前夕以 161 亿美元把这同一份股权买了回来。因此，愿景基金一期成立以来累计收益的 65%，来自 Softbank 集团在 IPO 预期下、以 644 亿美元的 Arm 估值让基金一号实质上套现离场。这一转让估值是 Softbank 2016 年收购 Arm 价格的 2 倍，与 500 亿美元以上的可能定价估值相差不远，而 8-9% 的潜在低自由流通比例还可能把 Arm 上市后的市值推上 600 亿美元以上。因此，644 亿美元的估值看起来并不算严重偏离市场——不过可以说，Softbank 集团这是在帮愿景基金一号一个忙，让基金在 IPO 之前锁定这些潜在收益，尽管代价是 Softbank 集团分两年分期付款。

![](https://substack-post-media.s3.amazonaws.com/public/images/17a30ca4-f969-4f88-aa0c-b4d3e1e69031_903x502.png)

IPO 若表现良好，还可能为 Softbank 集团带来可观的净资产价值（NAV）收益，因为其账面上 Arm 的持有价值约为 500 亿美元。上市还将显著提高 Softbank NAV 中上市股票的占比——这是提振 Softbank 下滑的信用评级的重要前提。

![](https://substack-post-media.s3.amazonaws.com/public/images/59e9bf31-df5f-4f49-ad9a-5072be66d737_903x207.png)

此前的一次尝试是把 Arm 卖给 Nvidia，但在反垄断顾虑下失败后，Softbank 组建了全新的管理层。长期担任 CEO 的 Simon Segars 被 Rene Haas 取代，此外包括前 CTO Dipesh Patel 在内的其他 C 级高管也相继离职。看来 Arm 有意把心态从长期技术投资转向利润最大化。

## **长期自救：Arm 能夺回多少价值？**

Arm 支撑着面向各种终端应用的大量芯片，而 Arm ISA 的性质决定了它特别适合某些应用。Arm 在智能手机应用处理器的指令集上拥有彻底的垄断——市占率接近 100%，根本没有替代选项。我们的分析显示，**在每年出货的超过 10 亿部智能手机上，Arm 从每颗应用处理器只赚约 50 美分**。对于每一部智能手机的基础要件、且芯片设计者无可行的替代选择而言，这个数字低得惊人。

Arm 心知肚明，如今正在做出这些改变。

管理层一直在向潜在的机构投资者表示，营收增长将加速：下一财年增长 20% 出头，此后保持百分之十几的增长。关键驱动因素是价格。Arm 将开始激进地上调向客户收取的价格。[鉴于 Arm 最大化自身价值的战略，我们已经看到它变得不那么以客户为重——其表现就是对大客户高通发起诉讼](https://www.semianalysis.com/p/arm-changes-business-model-oem-partners)。这就是 Arm 的多头逻辑。

对于每部智能手机都必需、且几乎没有替代品的一项关键 IP，我们该如何估值？每部手机 1 美元、2 美元，还是 3 美元？我们的看法是：可能高达每部手机 13 美元。这相当于当前定价的 24 倍！

以当前单位版税金额为锚，这听起来像天文数字，但它有正当依据，终端客户也有支付意愿。

以高通为例。任何使用 4G 或 5G 的设备，都会用到多项高通持有 IP 的技术。例如，高通拥有无线通信中的码分多址（CDMA）和正交频分多址（OFDMA）技术。全球 3G 网络完全基于 CDMA，而 4G 和 5G 网络使用 OFDMA 作为通信协议。

简而言之，要在 2G 之后的无线通信时代实现无线数据传输，CDMA 和 OFDMA 不可或缺，因此每一家智能手机厂商都要为使用这些及其他必要无线技术向高通支付版税，以实现无线通信。除版税之外，任何一家手机制造商也很可能还在向高通付费以使用其基带芯片组，因为高通在智能手机基带市场占有超过 30% 的份额（在 5G 基带市场超过 60%）。

举个具体例子：Apple 为使用无线传输 IP，向高通支付每台设备 13 美元的版税（不仅是智能手机，带无线功能的 iPad 和手表也包括在内），另外还要为基带芯片本身支付 25 美元。

实际上，对于一项对智能手机运行不可或缺的技术，高通面对这家可以说是全球议价能力最强的公司，每台设备收 13 美元竟然也收得成。

Arm ISA 同样是智能手机运行不可或缺的，为什么 Arm 不能收取和高通一样多的费用？为什么不收得更多？

另一个值得一提的有趣之处是，高通的定价模式基于使用其 IP 的整机物料清单（BOM）成本或售价的某个百分比，而不只是直接使用该 IP 的元器件。因此，当系统客户增加与无线通信完全无关的更贵配置——比如更大的 NAND 存储容量——高通也能分走其中一部分价值。难怪高通不受客户待见，尤其是 Apple，不断试图（并屡屡失败地）通过打官司来摆脱向高通支付如此高昂的费用。

显然，Arm 看到了自身与高通市场地位的相似之处，这也是它开始采取类似定价策略的原因。讽刺的是，高通正是对 Arm 新定价策略吵得最凶的大客户之一。归根结底，我们认为 Arm 的主导地位给了它足够的底气，去执行各种能提升每部智能手机出货收入的策略——前提是 Arm 在核选项中真正获胜。

## **这对 Arm 的财务可能意味着什么**

来看看这对 Arm 财务的影响。我们将采取保守立场，假设单设备收入的提升仅适用于非 Apple 智能手机——因为 Apple 已锁定未来 20 年的架构授权条款，且凭借其参与创立 Arm 的悠久历史，将始终享受优惠条件。

我们把不含 Apple 的智能手机出货分为高端、中端和低端。假设三个档位每台版税分别为 12 美元、6 美元、3 美元，由此带来的增量收入与利润（增量费用为零）将为 Arm 增加约 54 亿美元营业利润，几乎是其营业利润的 10 倍！

以 Arm 当前定价策略为锚，这听起来荒谬。但如果回到「Arm 的 IP 对客户而言价值几何」这个问题，从第一性原理出发，我们认为并不存在一个足以轻易推翻这条推理逻辑的有力反驳。

![](https://substack-post-media.s3.amazonaws.com/public/images/8688dd3c-a02a-4d9c-8b5b-a0d5f3895d65_1758x313.png)

当然，这是一种乐观情形，走到那一步需要很长时间。客户会试图反击。目前，只要高通在接下来几年仍能集成其自定义核心、而 Arm 又未能在诉讼中获胜，Arm 就无法上调对高通的费率。但这应当能让人感受到投资者押注的是什么——Arm 盈利能力的天花板远高于当前水平。如此一来，这个估值就开始说得通了，而不必执着于历史盈利能力、增长率或未来一两年的盈利预测。
