# Oracle 如何赢得 AI 算力市场

> 原文：[How Oracle Is Winning the AI Compute Market](https://newsletter.semianalysis.com/p/how-oracle-is-winning-the-ai-compute-market) · SemiAnalysis

> ⚠️ 付费订阅文章：以下为公开可见的预览部分翻译，正文在付费墙处截断，并非全文。

**Stargate、OpenAI、字节跳动、独特的数据中心战略、投资级新兴 GPU 云、营收与 EBIT 预测**

Oracle 的云基础设施业务全面发力，大幅超出预期。所有目光都聚焦在高调的 [Stargate 合资项目](https://semianalysis.com/2025/01/23/openai-stargate-joint-venture-demystified/)和得克萨斯州阿比林（Abilene）的超大型数据中心上——[我们 2024 年 9 月的多数据中心训练报告](https://semianalysis.com/2024/09/04/multi-datacenter-training-openais/#how-openai-and-microsoft-plan-to-beat-google)曾将其点名为 OpenAI 的吉瓦（GW）级训练枢纽。但除了这个巨型园区，Oracle 还有许多别的增长引擎。

![](https://substack-post-media.s3.amazonaws.com/public/images/66edfa5e-5414-4f18-a73a-9f021c7c1cdc_1841x1091.jpeg)
*来源：SemiAnalysis 数据中心模型——2025 年 6 月 11 日照片*

我们认为 Oracle 增长故事中最被低估的一面，是它与**字节跳动（ByteDance）的关系**。这带动了**马来西亚柔佛（Johor）崛起为全球第二大 AI 枢纽**，我们预计这一合作将扩展到更多国家，[扩张早已如火如荼](https://www.semianalysis.com/p/datacenter-model)。

![](https://substack-post-media.s3.amazonaws.com/public/images/9ab9d829-2b40-4bf6-b8c7-652550fe814c_1327x1123.png)
*来源：SemiAnalysis 数据中心模型*

两大旗舰客户均位列全球最大、增长最快的 GPU 租用方，且后续管线可观，我们在 2025 年 2 月就预测了**一轮强劲的资本开支爬坡**。Larry Ellison 两周前宣布预计未来十二个月将签订超过 $130B 的合同，印证了我们的判断。我们新推出的按月 GB200/300 机柜订单与出货[追踪器](https://semianalysis.com/accelerator-industry-model/)也证实了 Oracle 的极端需求。这不仅来自最大的客户，也来自大量因其技术专长而投奔 Oracle 的中小公司。Oracle 近期基于对软件、网络、安全、生命周期、存储等的独立测试，获得了 [ClusterMAX](https://semianalysis.com/2025/03/26/the-gpu-cloud-clustermax-rating-system-how-to-rent-gpus/) 金牌评级。

![](https://substack-post-media.s3.amazonaws.com/public/images/3e2d0d12-9d5d-4ea1-8c8d-d29e646ca8d2_1791x453.png)
*来源：SemiAnalysis Core Research，超大规模云厂商 AI 服务器、数据中心基础设施及总资本开支年度估算——2025 年 2 月 13 日*

在今天的报告中，我们更深入地剖析 Oracle 的基础设施战略。Larry 下了一些大胆的赌注，这些赌注是 Oracle 崛起为 AI 算力强手的关键。通过把**「传统」美国超大规模云厂商、AI 原生新兴 GPU 云（Neocloud）的特质，以及有选择地与速度飞快的中国数据中心开发商合作**相结合，Oracle 找到了制胜配方。本报告梳理 Oracle 全球各地的关键数据中心项目，拆解其独特战略，并点出具有巨大扩张潜力的领域。

此外，Oracle 还拥有独特的成本优势，最突出的是网络。我们运用新推出的 [AI 网络模型](https://semianalysis.com/ai-networking-model/)，提供 Oracle 相对新兴 GPU 云巨头的详细 TCO 对比。该模型详述每家超大规模云厂商针对每种 GPU 的精确网络配置，并按供应商预测出货量与营收。

然而，关于 Oracle 的财务回报、追加销售高毛利服务的能力，以及 GPU 业务在竞争加剧下的整体可持续性，仍有许多疑问。我们在报告末尾基于 [AI Cloud TCO 模型](https://semianalysis.com/ai-cloud-tco-model/)给出营收与 EBIT 预测——该模型受到领先 AI 实验室、超大规模云厂商、最大的 GPU 即服务厂商及其金融合作伙伴的信赖。结果可能会让许多投资者和利益相关方感到意外。

深入之前，先回顾一段历史，理解 Oracle 如何走到今天。

## GenAI 之前的 Oracle 云

### OCI 的一些背景

Oracle 长期是一家纯软件公司，比竞争对手 Azure、AWS 和 GCP 晚数年才加入云计算竞赛。在 GenAI 之前，Oracle 最出名的是其在企业软件领域的强势地位。Larry Ellison 的帝国建立在对关系型数据库的豪赌之上，至今这仍是其营收的重要部分。Oracle 在 ERP（企业资源计划）软件中还位居全球第二，仅次于德国公司 SAP。ERP 是记录财务、供应链、库存、人力资源等信息的核心企业应用。

要理解 Larry Ellison 的愿景以及 Oracle 如何走到今天，对比宿敌 SAP 与 Oracle 颇有启发。Larry 在 2000 年代是出了名的云计算怀疑者，当时的重心是从 SAP 的企业应用帝国抢份额。为了发挥其数据库与中间件的统治力，Oracle 在 2000 年代疯狂并购以拓宽产品线并垂直整合，例如 2004 年以 $10.3B 收购 PeopleSoft（软件）、2009 年以 $7.4B 收购 Sun Microsystems（硬件+软件）。

随着云计算在 2010 年代初加速，AWS 和 Azure 对 Oracle 的数据库护城河构成日益严峻的威胁，迫使 Oracle 掉头转向，推出云上数据库和 ERP。Larry 还看到了另一个从 SAP 手中抢份额的机会：向把数据迁往云的客户追加销售 ERP。这家德国公司反应激烈，2015 年推出云上 S4 HANA ERP，放弃对第三方数据库的支持，强制客户采用其新推出的数据库 HANA。

为支撑各自的云端转型，这两家软件巨头开始自建计算基础设施，资本开支在 2010 年代中期激增。

![](https://substack-post-media.s3.amazonaws.com/public/images/165bb709-7944-4ac5-8ce4-8880f5ec4fcf_1330x803.png)
*来源：SAP，Oracle*

正是在这时，两者的道路开始显著分化。为了服务全球企业客户，大规模基础设施建设必不可少。为避免利润率崩塌，SAP 不得不通过基础设施即服务（IaaS）业务变现，但几年后就放弃了——拒绝与 AWS、Azure 和 GCP 正面竞争，转而与它们合作。

Oracle 走了相反的路。2016 年它推出 Oracle Cloud Infrastructure（OCI）Gen2 云，标志着一次彻底的转变：**从为支撑 Oracle 软件而建的基础设施，转向端到端的完整云服务**。公开宣示的目标就是与 AWS 和 Azure 竞争，实现 Larry Ellison 的垂直整合愿景。

重要的是，OCI 还在云高性能计算（HPC）上投入了大量资源，这对今天影响深远。通过 2009 年收购 Sun Microsystems，Oracle 获得了 HPC 与网络专长，打造了高性能存储系统 Exadata，并开发了高速 RDMA over Converged Ethernet（RoCE v2）来连接多个节点。虽然 Oracle 最终出售了 Sun 的许多 HPC 资产，但网络能力保留了下来，成为 Oracle 2017-18 年推出云 HPC 的关键——通过 Mellanox ConnectX 系统使用 RoCEv2 网络。Oracle 还开始部署 Nvidia GPU，并在 2020 年扩大合作，成为最早部署 A100 的厂商之一。

![](https://substack-post-media.s3.amazonaws.com/public/images/4bec09f6-a492-4be4-8e49-edf6d02ea7ab_1920x1080.png)
*来源：Infolob Global*

### GenAI 之前的基础设施战略

更深入地看 Oracle 在 GenAI 之前的数据中心战略，它更像一家大型企业，而非 AWS 或 Azure。下面我们考察 Oracle 与关键数据中心合作伙伴 Digital Realty 从 2019 年至今的关系。虽然总容量五年增长约 3 倍，但合同性质的变化更能说明问题。

截至 2022 年年中，Oracle 与 Digital Realty 的历史合同加权平均**租期为 2-3 年，远低于 Microsoft 的 8-9 年**。由于规模小得多，Oracle 无需签订数十兆瓦级的大规模容量合同——这类合同通常需要长得多的合约承诺。虽然到 2022 年 OCI 已成长为数十亿美元的业务，但相对 Azure 和 AWS 仍小一个数量级。它在抢份额，但基数很低，且更多是受益于客户的云转型，而非赢得新客户或将客户从 AWS 和 Azure 迁出。

![](https://substack-post-media.s3.amazonaws.com/public/images/f24f6101-e240-435c-ad43-4f58eefeaed1_1322x821.png)
*来源：Digital Realty，SemiAnalysis 数据中心模型*

### Oracle 的 2024 年转型

随着 ChatGPT 的崛起与 Nvidia 的爬坡把数据中心市场推向产能受限的环境，数据中心开发商要求 10 年以上的合同才肯交付大规模容量。超大规模云厂商需求如此旺盛，分配给企业的 10MW 以下产能变得稀缺。

Oracle 必须做出抉择。没有对手超大规模云厂商那样的体量，以 15 年期承诺数百兆瓦容量，会带来**巨额费用搁浅的实质性风险**。这不仅有**相对营收增长过度承诺的风险，还有选址风险**：如果你的新数据中心在波特兰，而客户需求大部分来自达拉斯，怎么办？

Larry Ellison 愿意承担这一风险，从 2023 年 11 月到 2025 年 1 月承诺了超过 2GW 容量。那段时间，Oracle 是**美国最大的数据中心容量租赁方**。直观地说，2GW 租赁数据中心容量**大约对应每年 $3B 的费用……高于 OCI 2022 财年的营收**。合同期限也在飙升，10 年以上交易成为常态，上文 Digital Realty 图表即是明证。

而下图所示其在手订单（backlog）的增长表明，它随即就能把 GPU 集群卖给客户。

## Oracle 制胜的「混合」数据中心战略

### 自建、租赁与 Oracle 的劣势

我们认为 Oracle 成功的关键之一，是能够运用介于新兴 GPU 云与超大规模云厂商之间的混合基础设施战略——不妨称之为「投资级新兴 GPU 云」。

时至今日，Oracle 并不具备数据中心自建能力，相比其他能自建与租赁并举（且常用前者承载大型算力集群）的超大规模云厂商处于劣势。数据中心市场通常是这样的格局：

- 超大规模云厂商的自建数据中心承载大型算力集群，往往位于非常偏远的地区，例如 Google 在爱荷华州康瑟尔布拉夫斯（Council Bluffs），Meta 在俄勒冈州普赖恩维尔（Prineville）和新墨西哥州洛斯卢纳斯（Los Lunas）。超大规模云厂商自付光纤基础设施费用，寻找扩张潜力充足、电力便宜的地方。
- 数据中心开发商（如 Digital Realty）通常围绕大都市圈建设，连接充裕、贴近终端客户——例如阿什本（Ashburn，华盛顿特区附近）、硅谷或达拉斯，常被称为「一线市场」（Tier 1 Markets）。这是因为租赁市场历史上基本是一场房地产游戏，在高需求市场回报更好——资产在那里可能几十年都有价值。

值得注意的是，贴近终端客户与「云计算思维」高度契合，使位于一线市场的资产对 Azure、AWS、GCP 和 OCI 的云可用区（AZ）极具吸引力。这也完美契合 Satya Nadella 最爱的词：**可替换性（fungibility）**。

### 从一线市场到得克萨斯州阿比林

随着 AI 竞赛打响，超大规模云厂商加速自建，并于 2023 年底开始动工多个吉瓦级数据中心。Oracle 最初的选择是与 Digital Realty、QTS 等传统托管伙伴在大都市圈周边一同扩张。下图展示的是他们在一线市场的一个 AI 园区。

![](https://substack-post-media.s3.amazonaws.com/public/images/2041953a-0e89-4da0-b858-f70d9a85a646_1192x745.png)
*来源：SemiAnalysis 数据中心模型——2025 年 6 月 23 日照片*

它也在盐湖城等成熟度较低的市场获取了容量。但一线市场过度拥挤，许多二线城市又难以满足电力需求，想拿到接近吉瓦级的数据中心、赢下最大的 AI 合同非常困难。[而稀缺的合适站点，在 2023 年和 2024 年初已被 Microsoft 全部预租](https://www.semianalysis.com/p/datacenter-model)。

![](https://substack-post-media.s3.amazonaws.com/public/images/7f4f2ba9-136c-457d-840d-537563e80c33_859x1063.png)
*来源：SemiAnalysis 数据中心模型——2025 年 6 月 3 日照片*

由此催生出一个新的市场群体：AI 优先开发商。新入局者多来自加密挖矿行业，他们明白电力正成为头号问题，利用既有的并网协议在远离人口中心但电力充沛之地规划大型数据中心。Core Scientific 与 Coreweave 的 570MW 交易就是绝佳例证。然而，由于缺乏资历背书、加上超大规模云厂商还有自建这个选项，「AI 优先」开发商很难赢得超大规模云厂商客户。他们的目标市场仍局限在新 GPU 云客群，但许多玩家信用评级低、签不了 10 年以上合同，融资并不容易：

- 新兴 GPU 云的 GPU 合同通常 2-3 年，5 年已是上限。
- 数据中心开发商的回本周期一般为 7-9 年。

Oracle 把这一空档视为参与超大 AI 合同市场的机会，在得克萨斯州阿比林锁定了一处吉瓦级场址，并与 Crusoe 签下 15 年数据中心合同——按当时的纸面信息，Crusoe 是一家没有数据中心经验的加密挖矿公司。虽然 Crusoe 拥有值得信赖的人才，但公司从未真正执行过这种规模的项目。2024 年年中签署的首份合同覆盖约 220MW IT 容量（按我们的估算），2025 年初又签署了约 660MW 扩建，使合同总价值达到约 $15-20B。

换句话说：Oracle 承诺**在十五年里，每年向一家缺乏经验的开发商支付超过 10 亿美元**。这赌注之大，怎么说都不夸张！即便有 OpenAI 承诺买断该园区的全部算力容量，这些五年期合同加起来对 OpenAI 而言也接近每年 $10B 的费用——而这家初创公司 2024 年年中的年化营收约 20 亿美元，且严重亏损。Oracle 的赌注同时伴随**信用风险与久期风险**。

![](https://substack-post-media.s3.amazonaws.com/public/images/bef2a188-85d1-4530-a294-9b1ce4b61dc4_1841x1091.png)
*来源：SemiAnalysis 数据中心模型——2025 年 6 月 11 日照片*

当然，Oracle 的大胆举措是使其成为 [Stargate（这个宣称要在 GenAI 上投资 $500B 的高调合资项目)](https://semianalysis.com/2025/01/23/openai-stargate-joint-venture-demystified/)一员的关键。鉴于我们对 [Scaling Laws](https://semianalysis.com/2024/12/11/scaling-laws-o1-pro-architecture-reasoning-training-infrastructure-orion-and-claude-3-5-opus-failures/) 和 AI 行业整体增长的看法，我们认为这是一步天才棋，Oracle 将从与这家新兴行业巨头的长期关系中获益。

### Stargate 的上行空间有多大？

Oracle 到底能获益多少仍有疑问。Larry Ellison 公开表示尚未签署任何 Stargate 合同，许多投资者因此倾向于认为首期 $100B 投资尚未入账，另有 $400B 正在路上——这还不包括国际版 Stargate。

但我们认为现实并非如此。据我们所知，Stargate（合资实体）其实并不存在，也没有做过任何实质性的事——所以 Larry 说的属实。另一方面，位于得克萨斯州阿比林 Crusoe/Lancium 园区的约 880MW OpenAI 交易（常被称为 Stargate）非常真实……而且已计入 Oracle 账上。我们相信二期于 2025 年 1 月入账，这一点体现在 Oracle 的租赁活动和该季度的 RPO 增长上；一期则在两个季度前入账。

![](https://substack-post-media.s3.amazonaws.com/public/images/a368b280-01f3-4a93-85c6-6f2449fcafa3_886x859.png)
*来源：Oracle，SemiAnalysis 数据中心模型*

另一个被广泛讨论的「Stargate」交易[正在中东落地](https://semianalysis.com/2025/05/16/ai-arrives-in-the-middle-east-us-strikes-a-deal-with-uae-and-ksa/)。但据我们所知，它不会显著流入 Oracle 的财报，因为 [GPU 集群将由 G42/Core42 搭建](https://semianalysis.com/accelerator-industry-model/)。

那么，应该期待 Stargate 带来上行空间吗？

- 来自 OpenAI 及潜在新吉瓦级交易：有。Larry 目标 FY26 RPO 增长 >100%，我们预测的 >$30B 资本开支，离开 OpenAI 的贡献都说不通。
- 来自合资实体 Stargate：不多。Stargate 合同只会替代 OpenAI 的需求，不是净增量。在得州阿比林最初 1.2GW 之外的新 Stargate 才是增量。我们已在 [Core Research](https://semianalysis.com/core-research/) 上发布过相关内容。
- 来自国际 Stargate：视 Oracle 参与深度而定，实际上可能弊大于利。有意落地 OpenAI 的主权国家可能绕开 Oracle，直接与 Sam 的公司打交道。

把 Stargate 说成 OpenAI 合同之外的增量，意味着这些交易原本不会发生，但我们认为这种说法不准确。（OpenAI 的）营收增长已大幅跑赢目标，其先前的基础设施计划已被大幅上调。Oracle 正在全球四处寻找容量来服务这位关键客户，我们预计他们能交付——这又要归功于其数据中心战略。[但其他人也准备好分一杯羹](https://semianalysis.com/core-research/)。

### 亚太爬坡与字节跳动关系

当阿比林和 OpenAI 交易占据所有头条时，Oracle 与字节跳动合作的规模仍鲜为人知。我们相信，**TikTok 的母公司是全球最大、增长最快的 GPU 使用者之一**，规模可与美国超大规模云厂商比肩，是当今 Oracle 最大的 GPU 客户。我们认为他们在美国有几笔可观交易，尤其是在北弗吉尼亚，但更令人印象深刻的是其在东盟的增长——这催生了全球第二大 AI 数据中心枢纽：新加坡-柔佛-巴淡岛枢纽，如下图所示。市场普遍认为，Oracle 在东盟的大部分 GPU 容量都分配给了字节跳动。

## Oracle 的网络架构与成本优势

现在来讨论 Oracle 的一些成本优势，重点在网络。大规模 GPU 合同的竞争者有两类：

- 超大规模云厂商：Oracle 常靠更快、更便宜取胜。它们完全能匹配 Oracle 的定价，也多次这么做过，但通常更青睐回报更高的机会。债务融资也使 Oracle 的资本成本低于超大规模云厂商。
- 新兴 GPU 云巨头：竞争虽在升温，Oracle 拥有几项关键成本优势，使对手难以在匹配其价格的同时还能获得有吸引力的回报。

我们认为 Oracle 的成本优势有三：

1. 网络——下文将解释 Oracle 相对竞争对手的 GPU 集群 TCO 优化。
2. ODM 对 OEM——通过直接与富士康（Foxconn）合作，Oracle 绕开了 Dell 和 Supermicro 的额外利润。
3. 资本成本——凭借投资级评级同时对债务融资持开放态度，Oracle 的 GPU 云业务很可能拥有市场最低的资本成本。相比之下，多数新兴 GPU 云的债务成本为两位数，超大规模云厂商的 GPU 则靠股权融资。
