# Anthropic 增长与 Bedrock 业务组合推高 AWS 利润率，同行掉队

> 原文：[Anthropic Growth and Bedrock Mix Drive AWS Margins Higher While Peers Lag](https://newsletter.semianalysis.com/p/anthropic-growth-and-bedrock-mix) · SemiAnalysis

**亚马逊的 Bedrock 业务组合与 Anthropic 交易条款相叠加，展现出更强的经营杠杆**

过去几个季度，其他云服务商（CSP）的营业利润率不是下滑就是原地踏步，而亚马逊 AWS 的利润率在上个季度出现向上拐点，主要驱动力是客户通过 Bedrock 在 Claude 上的支出增长。AWS 在第三方（3P）模型 API 支出中占据更高份额、Anthropic/Bedrock 的交易结构，以及 Anthropic 在 1Q26 的 ARR 超预期表现，共同推动其 EBIT 利润率环比（Q/Q）上升 213bp，而其他 CSP 望尘莫及。SemiAnalysis 在全新 [Tokenomics 2.0 模型](https://semianalysis.com/tokenomics-model/)中的工作，展示了 AWS 如何一马当先，并找到了一条扩大利润率的强劲路径。我们的模型对超大规模厂商和 AI 实验室的每一个业务垂直领域估算季度营收、利润、ROIC 和算力需求，例如 Gemini API 的营收与利润率、Microsoft Copilot 的 ARR、OpenAI ChatGPT 各档位订阅等。

![](https://substack-post-media.s3.amazonaws.com/public/images/75b1ab04-af86-43e6-887a-58807b6790f7_936x501.png)

尽管所有 CSP 都在受益于 AI 与非 AI 营收的增长，利润率却完全是另一回事。Oracle 和 Coreweave 的云业务利润均不及预期，让市场失望。Azure 的利润率也呈下行趋势。Google Cloud 近来一路强劲上行，但其利润率存在虚高——GCP 分部并未计入 DeepMind 的训练成本。唯一利润率真正处于上升趋势的 CSP 是 AWS——考虑到其服务器折旧年限（5 年）在所有 CSP 中最短，这一成绩尤为了不起。

## **亚马逊的故事与背景**

我们认为，亚马逊的利润率成功建立在一种差异化战略之上，而且这一战略在未来几个季度乃至几年还会被进一步放大。这家公司对 AI 机遇的觉醒偏晚（[2023 年我们率先指出其丢掉了领导地位](https://newsletter.semianalysis.com/p/amazons-cloud-crisis-how-aws-will)）。两年之后，当整个市场都把亚马逊贴上 AI 输家标签的时候，[我们又率先指出其轨迹的改变和即将到来的营收加速](https://newsletter.semianalysis.com/p/amazons-ai-resurgence-aws-anthropics-multi-gigawatt-trainium-expansion)。

如今，我们看到 AWS 进入了一个新时代：营收增长加速与利润率跑赢兼得。亚马逊拥有以下几方面的独特组合：

- 风险偏好：AI 基础设施领域的赢家，从不害怕把资产负债表押上战场。正如我们的[数据中心行业模型](https://semianalysis.com/datacenter-industry-model/)所示，除 Google 之外，亚马逊锁定的电力比任何其他云厂商都多——它比同行更早想明白：在这个供给受限的环境里，能源决定市场份额，而这需要资本，需要数十亿美元级的 PPA。

- 商业模式：亚马逊是唯一一家以 token 即服务（TaaS）占其 AI 业务主导份额的 CSP，而其他所有厂商都聚焦于多年期 IaaS 合同。这不仅体现了更高的风险偏好，也体现了对 Bedrock 所提供独特机会的更深刻理解，下文将详述。

![](https://substack-post-media.s3.amazonaws.com/public/images/665334ea-ba75-48a0-8525-c8c3fd78243a_936x519.png)
*来源：SemiAnalysis Tokenomics 模型*

- 规模与速度：根据我们的数据中心行业模型，2025、2026 和 2027 年，没有任何厂商的建设体量能超过 AWS。AWS 让竞争对手相形见绌。这家 CSP 不仅采购了大量电力，执行速度也远快于同行，而且正在铺开一种全新的数据中心设计，将进一步拉大其速度优势。

- 垂直整合：我们最早于 2025 年 12 月报道了日益收紧的 CPU 供给约束，并解释了由强化学习（RL）和推理驱动的即将到来的 CPU 需求激增。亚马逊是布局最好的 CSP，其自研芯片 Graviton 比商用方案的经济性更优。在 AI 加速器市场，亚马逊希望复制同样的成功，而 Trainium 正在取得不错的成果。[正如我们的深度解析所解释的](https://newsletter.semianalysis.com/p/aws-trainium3-deep-dive-a-potential)，Trainium 对推理和 RL 负载很有吸引力。

让我们深入展开：先讲 Bedrock——亚马逊差异化最强的产品——的经济学与市场驱动因素；然后对比其数据中心足迹与同行的差异；报告最后再深入探讨其他 CSP 的前景。

## **Amazon Bedrock 深度解析**

Bedrock 是一项 AWS 服务，客户可以在众多选项中挑选自己青睐的 LLM，享受 AWS 的安全与合规、统一计费（以及其他好处），并运行 AI 负载。这个我们称之为“API endpoint（终端接入）”的市场竞争者众多，包括 Microsoft Foundry 和 Google Gemini Enterprise Agent Platform（前身 Vertex），以及众多专注开源模型的厂商，如 TogetherAI、Fireworks、Baseten 等。

各家 endpoint 通常宣称自己靠以下几点实现差异化：

- 模型库广度：厂商喜欢炫耀自家平台上可用的 LLM 数量。

- 价格：一些厂商拥有差异化的推理技术栈或成本结构，使它们能在保住利润率的同时给出更有吸引力的价格。

- 交互性：一些厂商的指标更好，例如更高的 token 吞吐、更低的 TTFT（首 token 时延）等。

这些标准中有一些确实重要，但它们都漏掉了唯一最重要的差异化因素：能否接入前沿 LLM。正如我们的 [Tokenomics 模型](https://semianalysis.com/tokenomics-model/)所证明的，前沿 LLM 占据了 AI API 行业营收的绝对多数。

在 API endpoint 市场上，这正是 AWS、Microsoft 和 Google 压过其他所有玩家的巨大优势。长期以来，AWS 能用 Claude，Google 同时能用 Claude 和 Gemini，Microsoft 能用 OpenAI 的模型。最近，AWS 拿到了 OpenAI 的接入权，Microsoft 则拿到了 Claude。目前没有其他 CSP 有能力同时售卖 OpenAI、Claude 和 Gemini 的 token。

拿到这些模型的接入权是一回事，围绕它们做成一门大生意是另一回事。众所周知，AI 推理的算力需求极其庞大。要理解这一点，让我们深入拆解 Bedrock、Vertex 和 Foundry 的经济学。

## **Token 即服务（TaaS）平台经济学**

TaaS 平台的经济学，取决于它是拥有 IP（或可以自由使用，例如开源），还是在“分销”别人的 IP，两者截然不同：

- IP 所有权：经济学与 AI 实验室相同。云/token 厂商的固定成本就是基础设施。这项成本主要由 GPU 折旧、CSP 自身的利润空间、数据中心成本和电费构成。营收是售出 token 数的函数：要赚到钱，token 定价必须足够高，硬件也必须得到充分利用。量与价必须大到足以吸收固定成本并留出利润。

- 模型分销：在这个模式下，亚马逊把 Claude 的 token 卖给支付 AWS 账单的亚马逊客户，但名义卖方（seller of record）是 Anthropic。Bedrock 的公开条款写得很清楚：产品由 Anthropic 售出，模型的使用受 Anthropic 条款约束；不过客户由 AWS 开票，条款注明模型“部署在 AWS 上（Deployed on AWS）”。实践中这意味着：

- 作为卖方，Anthropic 将售出 token 的全部营收入账。

- 作为算力和市场（marketplace）提供方，AWS 既收取一笔基础设施费用（类似 EC2 的 IaaS 费用），也收取一笔分销/营收分成费。正是后者推高了利润率，让在 Bedrock 上售卖 Claude 成为对 AWS 极具吸引力的生意。

![](https://substack-post-media.s3.amazonaws.com/public/images/bc920fde-1020-4d15-8b58-64e3599f9819_936x507.png)
*来源：SemiAnalysis 数据中心模型*

Anthropic 是第一个与 AWS 和 Google 落地这种模式的 AI 实验室，最近 OpenAI 也在 AWS 上跟进。安全性至关重要：理想情况下，CSP 完全接触不到模型权重，或只有极其有限的访问权限，但仍能使用模型、在自己的基础设施上运行它。

对 AI 实验室来说，主要有两大好处：

- 接入 CSP 的客户群

- 无需签订昂贵的多年期 IaaS 合同即可获得算力，但单位成本更高

对 CSP 来说，这意味着比标准 GPU IaaS 交易更高的风险，因为营收并没有 5 年期 IaaS 照付不议（take-or-pay）合同兜底。然而，利润率要诱人得多。凭借交易结构的设计与执行，亚马逊成为押注 Bedrock 的最大受益者，把竞争对手平台的体量甩出几个身位。

![](https://substack-post-media.s3.amazonaws.com/public/images/5b2803b1-498e-40f6-aa27-cbd4abd030f0_936x481.png)
*来源：SemiAnalysis Tokenomics 模型*

而这正是 AMZN、MSFT、GOOGL 与 ORCL 及新兴 GPU 云（neocloud）之间的主要差别。它们的 token 即服务（TaaS）业务如今的 ARR 都已超过 $10B。相比之下，neocloud 和 Oracle 在这方面几乎为零。正如我们在 Bedrock/Anthropic 交易一节所展示的，这些 TaaS 交易的利润率显著高于批发式出租 AI IaaS 算力。这些超大规模厂商如今握有的利润率结构与分发优势，正在显著拉大头部超大规模厂商与其他玩家之间的差距。

![](https://substack-post-media.s3.amazonaws.com/public/images/91b527ed-4b63-4288-bbd4-e62a69d76242_936x480.png)
*来源：SemiAnalysis Tokenomics 模型*

## **垂直整合让 AWS 拿到行业领先的利润率**

业务组合更偏向 Bedrock，与亚马逊押注自研芯片形成了绝佳搭配。在此前的报告中，我们已经深度覆盖过 Trainium2 和 Trainium3，论证了这些芯片在内存带宽最宝贵的某些场景（如高批量推理和 RL）中拥有领先的 perf/TCO。

在 Bedrock 中，底层硬件对客户是抽象的；他们看到的只有 token。这意味着一块为推理优化的芯片与 Bedrock 是天作之合，唯一的保留意见是模型移植可能比 Nvidia GPU 耗时更长，但通常也就是几天的事。这意味着 Trainium 天然拥有 Bedrock 这个承销出口（offtake），而亚马逊正充分利用这一点，其 CEO 表示：

“我们为 AI 负载自研设计的 AWS Trainium 芯片，如今支撑着超过 50% 的 Amazon Bedrock token 用量。”——Matt Garman，AWS CEO，2025 年 11 月

Google 也享受同样的优势，但存在一些限制条件，我们将在下文讨论。

除了 AI 加速器，CPU 对前沿 LLM 的训练和推理也愈发重要。在 CPU 领域，垂直整合是更大的差异化因素，而亚马逊的第五代自研芯片 Graviton 处于行业领先地位。[我们在此写过一篇完整的 CPU 深度解析](https://newsletter.semianalysis.com/p/cpus-are-back-the-datacenter-cpu)，其中解释了 Graviton4 和 Graviton5 为亚马逊带来了出色的 perf/TCO 优势。Graviton4 将作为头节点（head node）集成进 Trn3，并将单独用于承载 RL 负载和智能体负载。亚马逊如今与 Anthropic、OpenAI 和 Meta 都签有大型 CPU/Graviton 交易。向 Bedrock 客户向上销售（upsell）Graviton，对亚马逊来说也会更容易。在我们的 [Tokenomics 模型](https://semianalysis.com/tokenomics-model/)中，我们量化了这项非 AI 芯片业务对 AWS 营收增长的贡献。

## **AWS Bedrock 业务组合：数字说话**

我们的 [Tokenomics 模型](https://semianalysis.com/tokenomics-model/)深入每一家超大规模厂商的 AI 业务内部，拆出诸如 AWS 的 Bedrock、Azure 内部的 GitHub Copilot、Google Cloud 的 Gemini API 与 AI IaaS 之比等分部。我们对 AWS 的 AI 业务及 Bedrock 占比做了三角验证，以更好地帮助投资者和企业理解这些趋势。对 AWS 而言，AI 占总营收的比重已从 1Q24 的 2% 升至如今 1Q26 的 10%。我们面向 Tokenomics 订阅客户提供的未来估算显示，这一比例还会继续上升。1Q26，AI 占 GCP 和 Azure 总营收的比例分别为 36% 和 27%。不过我们认为，尽管 AWS 的 AI 总占比更低，IaaS 与 TaaS 之间的结构差异才是利润率差异的主要贡献因素。

![](https://substack-post-media.s3.amazonaws.com/public/images/dc2f263f-5ed0-4083-8afe-17c4f674ffd9_936x544.png)
*来源：SemiAnalysis Tokenomics 模型*

如上文所述，也如下文对交易经济学的深入拆解所示，AWS 的 Bedrock 占比对比 Azure Foundry 和 GCP Gemini API 十分关键。Bedrock 占 AWS AI 总营收的比例稳步上升，如今达到 37%，而 1Q25 时仅为 9%，当时 AI 业务还由 IaaS 主导。相比之下，AI IaaS 仍占 Azure 和 GCP AI 业务组合的 80% 以上。根据亚马逊 1Q26 和 4Q25 财报电话会，Bedrock 营收分别环比增长 170% 和 60%。SemiAnalysis 认为，Bedrock 如今是一项年化营收（run rate）$5.5B 的业务，且绝大多数客户（80-90% 以上）使用的是 Anthropic 的模型。

![](https://substack-post-media.s3.amazonaws.com/public/images/691c6923-84e5-4997-9c99-23c5dc3af0a2_936x493.png)
*来源：SemiAnalysis Tokenomics 模型*

显然，无论从营收增长还是业务组合看，亚马逊都靠 Bedrock 和 Anthropic 交易押中了赢家。相比之下，Microsoft 高度依赖 IaaS，365 和 GitHub 里的 Copilot 等其他 AI 业务也未能形成气候。Google 的 Gemini API 在 Gemini Enterprise Agent Platform 里表现不错，但并没有吃到那波推动 Anthropic API 营收同比增长约 13 倍的编码市场红利。

## **Bedrock/Anthropic 交易**

据我们了解，Anthropic 的 Bedrock 交易包含一笔固定 IaaS 费用、营收分成，以及在 token/支出吞吐量超过特定水平后可获超额收益的业绩门槛（performance hurdle）。

[Tokenomics](https://semianalysis.com/tokenomics-model/) 团队对 Anthropic 和 OpenAI 的业务做了详尽建模，按分部（消费者、商业/团队版、企业版）和档位（Free、Pro、Max20、API 等），在 ARR、营收、利润率、token 量和 token 定价层面展开，帮助投资者和企业战略部门理解客户、实验室与 CSP 之间这笔资金与 token 的流动。这项工作包括对 Anthropic 与 Bedrock 交易的建模，我们在下面做了预览，展示在不同“Bedrock 算力每 MW 承载的 Anthropic ARR”水平下，Anthropic 的毛利率与 Bedrock 的 EBIT 利润率。我们论证了 Bedrock（或任何 token 即服务产品）的利润率优于典型的 IaaS 收费业务。对超大规模厂商而言，结论是：只要交易结构对厂商和实验室双方都有利、能共同把营收做大，这些 TaaS 安排就是极佳的利润率增厚项。

![](https://substack-post-media.s3.amazonaws.com/public/images/fc87f4e2-a40b-43b8-afcf-a94bce1d65e1_1006x180.png)

我们认为，Anthropic 近期的营收超预期表现（下文讨论）使 1Q26 Anthropic 在 Bedrock 上的收入约为每 MW $26M，对应上述分析中 Bedrock 约 55% 的 EBIT 利润率。就 AWS 1Q26 同比 1Q25 而言，我们认为财报中新增的 EBIT 利润率主要由 Bedrock 驱动——Bedrock 虽只占 AWS 总营收的 4%，却贡献了毛利润额同比增量的 30%。展望 2Q，我们看到 Anthropic 总算力每 MW 的 ARR 约为 $42M，Bedrock 营收占比升至 AWS AI 营收的 53%，为 AWS 总营收增长额外贡献 9 个百分点。我们注意到，由于 Anthropic 的 ARR 按总额法（gross basis）确认，Bedrock 业务的利润率相对其当前 60% 出头（low 60s）的混合推理毛利率而言，在结构上略有稀释。

## **Anthropic 爆发的 Q1**

Anthropic 的 1Q26 主线是高速增长，这助推 Bedrock 的营收和利润率更上一层楼。公司单季净新增 ARR $21B，总 ARR 达到 $30B。Anthropic 的营收大多来自 API 和企业版，而 OpenAI 偏向消费者，且免费用户带来相对沉重的推理成本负担。这轮营收爆发由 Claude Code 驱动，它已横扫企业市场。消费者也开始涌向 Claude。在最近一期给订阅客户的简报中，我们指出，在银行卡消费面板数据里，Anthropic 相对 OpenAI 的净新增客户份额持续上升（如今已过半），平均交易金额也更高。我们看到对 Anthropic 的强劲需求——主要由企业 API 支出驱动——将持续到年底。我们最新的 Tokenomics 模型估算显示，到今年年底，ARR 有望远超 $100B。

![](https://substack-post-media.s3.amazonaws.com/public/images/f6a73862-a5f6-401d-a907-4de5ab786211_936x679.png)
*来源：SemiAnalyis Tokenomics 模型*

此外，Anthropic 的推理算力利润率大幅跃升。我们认为其推理毛利率如今已到 60% 中段（mid 60s）的水平，而 2025 年为 38%，2024 年为 -94%。根据《华尔街日报》2026 年 5 月 20 日的报道，Anthropic 预计在 2Q 经股权激励费用调整后实现经营利润（Operating Income）为正。我们的 Anthropic Tokenomics 模型将成本分配至免费与付费用户推理、训练与研发支出以及 OpEx。我们上周发布给客户的最新估算，在营收、成本桶结构与金额、以及整体 GAAP（未按股权激励调整）EBIT 盈利能力上，均与实际情况高度吻合。

## **超大规模厂商启示：亚马逊用产能接住了需求**

鉴于 AI 推理的高算力强度，要把 token 即服务平台部署到远超对手的规模，关键其实很简单：拥有更多算力产能。如下图所示，亚马逊新增的产能显著多于竞争对手，只有 Microsoft 在 2024-26 年与之接近并驾，但到 2027 年就被远远甩开。我们的数据中心行业模型提供按超大规模厂商、按季度的产能预测。

## **对 Google 的质疑与回应**

对我们“AWS 跑赢”论点最自然的质疑是：Google Cloud 的利润率也在提升，拥有与 AWS 相同（甚至更强）的垂直整合能力，而且表现更为抢眼——最新一个季度营收同比增速飙升至 >60%，GCP 利润率创历史新高。在指出 Google Cloud 加速这件事上，我们一直远领先于市场，最早一批报告于 2025 年 8 月发布在 Accelerator、Datacenter 和 Core Research 中。[我们的 TPU 深度解析极其详细地解释了 Google Cloud 为何跑赢](https://newsletter.semianalysis.com/p/tpuv7-google-takes-a-swing-at-the)。

但我们认为，这种利润率上升是一种幻觉，更接近“EBTIT”利润率——即“扣除训练、利息和税项之前”的利润（Earnings Before Training, Interest and Taxes）。Alphabet 因 DeepMind/Gemini 的训练开支而成本上升，但这些成本被记在“Alphabet 层级活动（Alphabet-Level Activities）”中，而不是 GCP。根据 Google 最新的 10-Q，Alphabet-Level Activities“主要反映与我们共享 AI 研发相关的费用”，1Q26 为 $5.4B，高于 1Q25 的 $3.0B。也就是说，所有 Gemini API 营收都以高于平均水平的利润率流入 Google Cloud，抬高了 GCP 的利润率画像，而 $10B+ 的年化成本却被记在别的桶里。

此外，Google Cloud 可能还受益于一次性的权利金收入——Google 作为 IP 供应商，通过 Broadcom 向 Anthropic 出售 TPU。

## **云 vs AI 实验室 vs 硬件：Google 如何满足所有需求？**

Google 是终极的供给受限型公司。这是单独一家公司，却试图同时在云上与 AWS 竞争、在硬件上与 Nvidia 竞争、在模型上与 Anthropic 和 OpenAI 竞争、在广告上与 Meta 竞争、在自动驾驶上与 Tesla 竞争，诸如此类。

在分析 Google 的产能增长时，我们实在看不到足以满足所有需求的建设量。内部产能足够打造一家成功的 AI 实验室，但留给云业务（不含硬件）增长到与 AWS 同等规模的空间很小。尤其是，Gemini Enterprise Agent Platform（前身 Vertex）作为 Claude（未来也许还有 OpenAI）的分发平台，**其新增产能显著低于 Bedrock**。

对 Google 而言，GCP 更像是一个用来向上销售更多服务的平台。Meta 是最好的例子：先是一笔大型 GPU 交易，随后带来大规模的 Gemini 采用，然后又是一笔庞大的 TPU 硬件交易。
