# 半导体世纪的劫案｜Arm 中国完全失控，以拥有自研 IP/研发的独立公司身份运营

> 原文：[The Semiconductor Heist Of The Century | Arm China Has Gone Completely Rogue, Operating As An Independent Company With Inhouse IP/R&D](https://newsletter.semianalysis.com/p/the-semiconductor-heist-of-the-century) · SemiAnalysis

Arm 被广泛视为最重要的半导体 IP 公司。每年有数十亿颗新芯片搭载其 IP 出货，覆盖手机、汽车、微控制器、亚马逊服务器，甚至[英特尔最新的 IPU](https://twitter.com/dylan522p/status/1428409698852683783?s=20)。它原本是一家英国控股、总部设在英国的公司，但软银（SoftBank）于 2016 年将其收购。此后软银持续向 Arm Limited 投入资金，深耕物联网、汽车和服务器市场。其战略的一部分还包括大举进军中国，力争成为所有细分市场的 CPU 供应主导者。

作为对中国市场重视的一环，软银在压力之下同意组建合资公司。在新合资公司中，软银子公司 Arm Limited 将该公司 51% 的股权出售给一个中国投资财团，对价仅为区区 [$775M](https://www.reuters.com/article/us-softbank-group-china-jointventure/softbanks-arm-cedes-control-of-china-ops-to-consortium-for-775-million-idUSKCN1J10RM)。这家合资公司拥有 Arm IP 在中国境内的独家分销权。不到两年，这家合资公司便脱离了掌控。从法律上说，它一直都是独立实体，但 Arm 此前仍维持着控制权。近期，Arm 中国向行业做了一场介绍，内容涉及将自有 IP 品牌化、通过进一步研发加以扩展，并强调其正在走一条自主运营的道路。

**这家公司名为「安谋科技」，但它并不隶属于 Arm Limited。**

**作者将之称为「本世纪的科技劫案」。**

![](https://bucketeer-e05bbc84-baa3-437e-9518-adb32be77984.s3.amazonaws.com/public/images/4856fea2-70a8-4adf-b49a-9fc8ae1da5d8_700x394.jpeg)

在介绍他们举办的活动及其意义之前，先回顾一下来龙去脉。2020 年，Arm 及部分投资方同意罢免 Arm 中国 CEO 吴雄昂（Allen Wu）。罢免的原因是他利用 Arm CEO 的职务身份，为自己名下的公司 Alphatecture 吸引投资。类似下述例子及更多内容可在[此处](https://www.ft.com/content/dc55d4c9-1065-4db0-98a4-f7f0c1de563b)查阅。

> 吴先生曾向 Arm 中国客户提供折扣，以换取他们对 Alphatecture 的投资。

事实证明，罢免吴雄昂异常艰难。尽管 Arm 中国董事会以 7 比 1 投票通过，公司公章仍掌握在吴雄昂手中。在中国，公章是一种印章，持有者有权以此使公司及其代表承担权利与义务。要收回公章和营业执照，将是一场旷日持久、历时数年的法律程序。而且，这意味着至少还需要 Arm 以外的部分投资方一同参与。目前其他投资方仍支持罢免吴雄昂。中国法院系统也需要认可罢免一名高管、代之以由西方影响力方钦点人选的做法。

尽管被正式解聘，吴雄昂依然大权在握。他清洗了忠于 Arm 的高管，甚至雇佣了由 Arm 中国出资、只向他本人汇报的安保力量。这支安保队伍使 Arm 方面无法进入 Arm 中国的办公室。吴雄昂已强势接管这家公司，并按自己的意愿运营。一个耐人寻味的细节是：吴雄昂为宣布自己的免职非法而起诉了 Arm 中国。在那起诉讼中，他实际上同时代表了原被告双方，等于自己告自己。

Arm 已停止向出口管制清单上的实体转让任何 IP。据 Arm 说法，没有 IP 被窃取。与此同时，Arm 也尝试向政府陈情，称这种局面对中国半导体产业不利。

![](https://bucketeer-e05bbc84-baa3-437e-9518-adb32be77984.s3.amazonaws.com/public/images/191d81a9-78bc-4733-bfbd-ca1b93b7a37a_1024x566.png)

这就引出了当下：Arm 中国举办了一场活动，公开宣告独立。他们宣称安谋科技是中国最大的 CPU IP 供应商；它脱胎于 Arm，但已是一家独立运营的中国公司。

活动内容以宣传安谋科技的业务为主。其中一些亮点强调：安谋科技自成立以来累计出货 20B 颗；拥有 90 多家合作伙伴，其中 29 家已实现基于该 IP 的芯片量产。出货覆盖移动、网络基础设施、5G 和物联网。这些成果由公司 400 多人的研发团队完成，且该团队全部驻扎在中国。

![](https://bucketeer-e05bbc84-baa3-437e-9518-adb32be77984.s3.amazonaws.com/public/images/bd962c7b-16e1-4a76-aa18-5175720e453a_1024x567.png)

除了公开自称独立实体之外，他们还发布并展示了独立研发、另行命名的 IP，产品线名为 Power Core，归于 XPU 之下。这些 IP 模块包括 NPU、SPU、ISP 和 VPU，且他们明确表示未来将超出此范围。

其中 NPU（神经网络处理器）尤其值得关注，因为 Arm 自身也已开发了一系列面向 AI 的 IP。安谋科技正锐意打造自有 IP 来源，降低对 Arm Limited 的依赖。这只是开始，安谋科技下一步走向何方无人知晓。或许他们终将着手研发自己的 CPU 核心、GPU 和服务器设计。

这些 IP 大多面向移动或物联网类用例。SPU（安全处理单元）专门用于构建安全飞地（secure enclave）并充当管理引擎。ISP（图像信号处理器）负责接收摄像头输入并将其处理为数字形式，通过各种技术和运算增强原始图像。ISP 与 NPU 配合，用于分析图像和视频，以识别人物、物体和事件。这些 IP 模块对新兴应用至关重要——未来十年中国将部署数以十亿计的摄像头。最后是视频处理单元（VPU），负责以 H264、VP9 等常见格式（以及即将支持的 AV1）编解码视频。

![](https://bucketeer-e05bbc84-baa3-437e-9518-adb32be77984.s3.amazonaws.com/public/images/0a53fb40-8469-4004-9be6-1ef7110da7d8_600x209.png)

Arm 中国（安谋科技）正在主张其独立性。这是中国合资公司脱离掌控案例中曝光度最高的一例，也是最危险的一例。Arm 中国董事会并不支持吴雄昂，但他在被正式免职后依然掌权。少数持股的合资企业被夺走控制权的先例并非没有，但本案可能是迄今最为明目张胆的一次。

**Arm 遭受了根本性冲击——第二大市场从其脚下被夺走。据 Arm 说法，没有 IP 被窃取，但 Arm 无法直接向中国任何公司发放 IP 授权，必须经由安谋科技。**

在中国境内，只有吴雄昂控制的这家「失控的」Arm 中国实体能够签订 Arm IP 授权协议。尽管 Arm 是这家公司的最大单一股东，他们对公司运营没有任何控制权或话语权。安谋科技已凭借自有 IP 走上了自己的道路。Arm 的 IP 授权基础并非其业务的终点。这一局面对于英伟达潜在收购或 Arm IPO 意味着什么，仍有诸多疑问悬而未决，但可以确定的是：软银短视的逐利行为酿成了一个巨大的困局。

2021 年 8 月 31 日更新：需要强调，据 Arm 方面说法，IP 未被窃取、授权也未停止；但 SemiAnalysis 维持其判断——针对 Arm 中国实体控制权的「劫案」确已发生。
