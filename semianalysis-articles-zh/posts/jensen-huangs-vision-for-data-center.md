# 黄仁勋的数据中心霸主愿景将摧毁 Arm 生态系统

> 原文：[Jensen Huang’s Vision For Data Center Dominance Will Destroy The Arm Ecosystem](https://newsletter.semianalysis.com/p/jensen-huangs-vision-for-data-center) · SemiAnalysis

随着时间一周周过去，传言不断发酵，英伟达（Nvidia）收购 Arm 的可能性在不断上升。乍看之下，这两家公司的业务完全不相容。一家毛利率极高、高度垂直整合的图形与 AI 公司，去收购一家低毛利的 IP 授权公司，说不通。作为 Arm 的被授权方，英伟达本来就能构建他们想要的任何产品。把整头牛买下来并不能挤出更多的牛奶，也无法与现有业务模式产生协同。更何况，以英伟达在合作伙伴中的名声，这笔交易甚至可能促使客户开始寻找备选方案，并加速 RISC-V 的普及。黄仁勋（Jensen Huang）在追求数据中心霸主地位的过程中，可能会为其他所有人毁掉 Arm 生态系统。

![](https://bucketeer-e05bbc84-baa3-437e-9518-adb32be77984.s3.amazonaws.com/public/images/04349c2c-5400-49ba-a57a-e82bb4304a15_1140x606.jpeg)

收购 Arm 的理由在很多人看来十分荒谬，但黄仁勋的愿景是：数据中心本身就是一台计算机，而英伟达要成为造出这台计算机的公司。他们需要完全垂直整合，控制这台计算机的每一个方面。目前，凭借出色的硬件以及过去十年间由数千名英伟达工程师构建的 CUDA/各类 SDK 所组成的庞大软件护城河，他们牢牢锁死了加速计算市场。随着对 Mellanox 的收购，他们又把数据中心的「数据处理器（DPU）」收入囊中。他们还通过收购 SwiftStack 和 Cumulus Networks，不断把垂直整合的软件栈扩张到网络领域。

![](https://bucketeer-e05bbc84-baa3-437e-9518-adb32be77984.s3.amazonaws.com/public/images/a2d8bc54-42e4-4ca4-95da-1c2ac01de759_1140x575.jpeg)

数据中心是一张三条腿的凳子，而剩下的缺口是 CPU。AMD、英特尔（Intel）以及多家超大规模云厂商也在打造自己的「三脚凳」。对英伟达最大的威胁，是英特尔/AMD 终于拿出够格的 GPU 和配套软件栈。随着美国能源部大举投入 SYCL，加上业内众多力量向其聚集，软件战线正在快速推进。此外，各家超大规模云厂商也在用 Arm Neoverse IP 快速自研 CPU，与其加速器配套，例如用于 AI 负载的 Google TPU 和 Amazon Inferentia。最后，这些超大规模云厂商早已拥有自己的定制网络栈。英伟达目前的地位非常强势，但也岌岌可危，因为他们的多条护城河可能被同时侵蚀。

在任何行业，要想长期维持高毛利，都必须筑起高到无人能够闯入并颠覆的进入壁垒。尽管英特尔在执行力上已经基本停滞了 5 年，他们仍然坐收 >55% 的毛利率。黄仁勋的愿景如果完全实现，英伟达将建起一道几乎无法穿透的护城河，坐拥高毛利并锁定客户。这听起来居心叵测，但英伟达的解决方案将是即插即用的。绝大多数公司根本没有资源构建完整的软件栈来匹配专用硬件。英伟达会提供最好的解决方案，而它最终会变成一桩昂贵的交易，把你囚禁在这个「魔鬼生态系统」里。

![](https://bucketeer-e05bbc84-baa3-437e-9518-adb32be77984.s3.amazonaws.com/public/images/3f6edcf9-a647-4664-820d-2daab9a1faa0_1140x587.png)

这正是收购 Arm（而非仅授权其技术）的意义所在。英伟达需要筑起护城河，而唯一的办法就是实质性地劫持整个开放的 Arm 生态系统。自研 CPU ISA 的投资过于庞大，而且不会有生态采用。就连 Power 和 MIPS 的开放化也未能阻止它们缓慢走向消亡。RISC-V 同样仍处于襁褓期，还需要很多年才能进入嵌入式以外的任何垂直领域。

黄仁勋只有成为唯一同时握有 CPU、GPU 和 DPU「三件套」的公司，才能实现数据中心霸主的愿景。而英伟达只有以一个不合理的价格收购 Arm 才能做到这一点。一家独立的 Arm 根本不值软银（SoftBank）想要的 $35B-$50B。即便 $20B 的估值，对 Arm 而言也已经偏高。

![](https://bucketeer-e05bbc84-baa3-437e-9518-adb32be77984.s3.amazonaws.com/public/images/745f35fd-539b-4485-8d50-15b7a7dae757_1140x641.jpeg)

如果英伟达愿意把半导体 IP 世界彻底颠覆，这个价格就能自圆其说。实现投资回报（ROI）的终极路径，意味着推翻 Arm 当前的商业模式。考虑到英伟达超过 $300B 的市值，这笔交易对现有股东的稀释不会太厉害。他们会先以现金/股票混合的方式完成收购，然后争取监管批准。监管批准乍看是道大坎，但我们认为并不会。只要英伟达承诺大额投资，英国会欣然放行。如果把当前 Arm 中国合资公司的闹剧遮掩过去，中国也愿意睁一只眼闭一只眼。欧盟可能需要一些让步，但由于英伟达在 Arm 的大多数垂直领域并不构成竞争，在这里获得批准也不应太难。一想到 Arm 将落入美国掌控，美国监管机构会兴奋得流口水。

下一步是让客户确信两家公司的业务将分开运营。据《金融时报》（Financial Times）报道，黄仁勋已经开始释放这一信号。

> 随着公司业务延伸至供应一整套完整的数据中心计算平台，公司将以相互独立的「层」的形式出售其中的部分技术，黄仁勋表示。他补充道，其他公司也将能够获得其知识产权授权、用于自己的芯片，而不必向英伟达购买芯片。

作为两家公司整合的一部分，英伟达会砍掉或出售 Arm 的 Mali GPU 和 Ethos NPU 业务。这些业务将与自有产品重复，并可用英伟达自身的技术能力来补足。这将相当令人震惊，因为英伟达此前对外授权其 GPU 架构的尝试全部以失败告终。如果英伟达此番重启授权并取得成功，我们可能会生活在这样一个世界里：他们的 CUDA 架构及配套软件栈（即锁定）扩散到手机、嵌入式以及即将到来的增强现实领域。届时会有一些流失，例如三星（Samsung）已转向授权 AMD 的 RDNA 图形架构。总体而言，这也会加速从 Arm 生态迁往 RISC-V 的进程，但对大多数公司而言，这将是一个漫长而痛苦的迁移。

![](https://bucketeer-e05bbc84-baa3-437e-9518-adb32be77984.s3.amazonaws.com/public/images/dccc88db-344f-429f-ae44-cb7bccacad0b_1024x395.png)

英伟达在此的关键，是通过搅动局面来制造被俘获、有依赖性的客户，但又不能搅得太过火。如果「英伟达 + Arm」（NvidiArm）的方案既方便又便宜，生态中的大多数玩家就不会急着出逃。英伟达大概率会在一段时间内不提价，好让被授权方产生现状安稳的错觉。涨价终究会来。流失最严重的将是嵌入式市场——RISC-V 在那里基本已经落地，而且像[阿里巴巴](https://twitter.com/dylan522p/status/1295500585123188737?s=20)（Alibaba）和 Si-Five 这样的玩家手里的 IP 几乎已经蓄势待发。

移动 SoC 市场未来多年都将被 Arm 路线图牢牢锁住，这是英伟达可以开始激进攫取 ROI 的领域之一。苹果（Apple）持有永久授权，因此不受影响，但高通（Qualcomm）、三星和联发科（MediaTek）将开始坐立不安：授权费飙升，而他们自研 CPU 团队早已解散、别无备选。联发科的依赖程度尤其高——不仅依赖 ARM CPU，其许多 SoC 还依赖 Arm 的 GPU 和互连。

![](https://bucketeer-e05bbc84-baa3-437e-9518-adb32be77984.s3.amazonaws.com/public/images/22a92854-feaa-4ef6-be8e-62a4f6d04e6f_1140x641.png)

英伟达最大的 ROI 途径来自数据中心。x86 早就该被颠覆了。即便 AMD 在快速创新，这个世界仍想要更多选择。多家超大规模云厂商和独立无厂设计公司都在推进 Arm 服务器开发。Arm 将凭借授权的 Neoverse 设计以及 Nuvia、Marvell 这类公司的自研设计，打破 x86 的垄断。一旦 x86 双寡头格局被打破，英伟达在这里同样可以快速提价。超大规模云厂商的自研 Arm Neoverse 设计在总拥有成本（TCO）上仍将优于任何商用芯片，但这一省钱优势会开始减弱。

![](https://bucketeer-e05bbc84-baa3-437e-9518-adb32be77984.s3.amazonaws.com/public/images/3821f24e-2843-4d64-bf82-37e7695303e7_1140x641.png)

英伟达可以开始向竞争对手施压的另一个相邻市场是汽车。英特尔的 Mobileye 目前使用 MIPS 并正在转向 x86，而特斯拉（Tesla）和高通使用 Arm 核心。如果授权费在这里大幅上调，英伟达就能从竞争对手的销售额中抽取利润。归根结底，CPU 在汽车领域并不是竞争优势，而只是最便宜、最方便的选项。

随着 Arm 生态系统走向成熟，它将不再是最便宜的选择，而只剩下「方便」这一个属性。嵌入式市场已经看到了 RISC-V 的曙光，其普及只会从这里加速。其他市场则早已迷上廉价授权 Arm IP 这剂「毒品」。在英伟达咄咄逼人的掌控之下，这些「瘾君子」短期内别无选择，只能乖乖掏钱、接受各种要求。他们会寻找替代供应，但这一转向将耗时长久。

![](https://bucketeer-e05bbc84-baa3-437e-9518-adb32be77984.s3.amazonaws.com/public/images/d57072a8-54a2-46b3-88d7-364ecf8b937f_1140x642.jpeg)

英伟达的终局并不是从授权费中赚取更多收入。他们的终局是成为一家完全垂直整合的数据中心提供商。他们会想要制造并控制这张三脚凳的每一个部分。这意味着他们会慢慢扼杀 Neoverse 的理念——无论是把这个 IP 弄得极其昂贵，还是让自家设计领先一代，英伟达都会在 Arm 服务器 CPU 周围筑起护城河。随着时间推移，黄仁勋会逐步排挤其他 Arm 供应商，用英伟达的自研设计取而代之。开放的 Arm 生态系统将被劫持，换成一个堪比甚至超越英特尔和 AMD 的封闭生态系统。

如果英伟达能迅速攫取世界上最重要的知识产权——使用最广泛的 CPU ISA 及其设计——他们将掌控移动与数据中心的命运。这就是黄仁勋为「马基雅维利式」接管计算未来而准备的「特洛伊木马」。
