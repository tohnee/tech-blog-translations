# Microsoft Ignite 2026：MAI 主题演讲全文

> 原文：[Microsoft Ignite 2026: MAI keynote transcript](https://microsoft.ai/news/microsoft-ignite-2026-mai-keynote/) · Microsoft AI

我们在 MAI 的使命，是为你们打造世界上最好的模型，并让每一位开发者和每一个组织都始终站在能力的最前沿。

但我从每一位 CIO 和 CFO 那里反复听到的是：眼下 *token 开销* 正在飙升。而按前沿模型的价格，这笔账根本算不过来。

所以我们的承诺是，给你市面上最好的性价比，让你能够*真正*扩展你的 Agent。

我们也知道，你希望模型真正属于自己——权重由你掌控。

我们不只在前沿质量上做爬坡。我们把质量*与价格*放在一起协同优化。

而且我们持续这样做，一次又一次。我们交付、学习、改进、重复。

以编码为例。

在四项针对我们在 GitHub Copilot 中看到的*日常企业编码*任务的常用基准上取平均，MAI Code 2 以仅 40% 的成本达到 GPT 6.1 Sol 98% 的性能；对比 Opus 5.5，成本更是低到令人难以置信的 5%。

Code 2 Flash 也是如此。在这些日常任务上，它与 6 Luna 和 Haiku 5.5 旗鼓相当，价格分别只有后两者的 65% 和 20%。

但 Agent 越来越需要做决策，尤其是在速度和成本至关重要的场景。

因此，Decision 1.1 把模型路由直接集成进你的应用。在 Artificial Analysis Decision Index 上，它胜过 Jev、Google 和 OpenAI。

需要强调的是，我们构建这些模型时优先考虑客户每天都要做的编码工作。因此它们明确尚未针对更难的问题进行调优，例如基础科学研究和超长周期的 Agent 任务。

我们不会以你的成本为代价去追逐那些更小众的能力。毕竟，当同一个模型还兼顾推动科学前沿时，你就要在每一个任务上为这项能力付费——哪怕只是修一个例行的 bug。

所以我们的承诺是：在对你最重要的事情上，持续推进性价比前沿。

一个很好的例子是 AT&T 定制版的 Code 2 Flash。它在标准 5G 网络分析上优于 6.1 Sol，而成本低了惊人的 50 倍。

网络安全领域也是同样的故事。过去几个月对我们所有人来说，都是一次示警和一记警钟。

我们正面对一个新的现实：攻击与漏洞利用比以往任何时候都更便宜、更容易，也更普遍。

这意味着，Agent 安全、对齐与围控将成为 2027 年及以后最需要做对的事情。

MAI Cyber 2 Flash 就是我们的回答。在 CyberGym-E2E 上，它以每任务不到 2% 的成本领先 GPT 6 Astra。确实了不起。

这就是微软数十年专有数据和世界级安全专业能力的力量——它让我们能够以惊人的价格，为你带来一个不仅能发现漏洞、还能给出正确修复建议的模型。

我们在多模态上同样进展迅速。我们现在是图像生成领域排名第二的实验室，而就在今天早上，MAI Image 2.7 成为世界第一的图像编辑模型，成本只有竞争对手的五分之一。

Adobe、Sports Illustrated 和 Manus 等客户表示，它带来了专业级质量，以及极其精准、响应迅速的编辑体验。

我们的转写模型则是世界上最快、最准确的。当然，医疗大概是所有 AI 应用中最重要的、最复杂的、也是风险最高的一个。

MAI Transcribe 2 现已应用于每月 1,000 万次患者的 Dragon Copilot 就诊，同时将错误率减半。

我们致力于为你提供前沿性能，价格则低到可以全天候运行。

正如 Judson 在开场时所说：在这场新的平台迁移中，你的核心资产是你的 IP 和工作流，是你多年积累的商业数据，本质上是一切让你的公司之所以成为这家公司的东西。你的 IQ。

我一次又一次从企业领导者那里听到：没有人愿意把自己的 IQ 灌进别人的模型里。

而如果你基于开放权重构建，你真的能信任它们的来源，或者信任它们在你将其作为最有价值的 IP 与数据的底座时的表现吗？

所以我们听到了你们的声音。我们从自定义模型起步——正如刚才看到的 Alaska 和 AT&T，还有 Docusign、Rakuten 和 Woven by Toyota：在满足你*特定*需求的任务上更快、更好。

今天，我们借助 MAI Licensed Weights 迈出一大步：由你掌控的模型。

你取一个前沿 MAI 模型，如果愿意，用专有数据对它进行定制。然后在你自己的 Azure 环境中安全运行。

谁能访问由你决定。你的数据和适配成果完全归你所有。我们还将通过 Frontier Company 与你合作，交付定制模型，并把它嵌入你自己的产品和 Agent。

这就是 MAI，一个兼具卓越性价比的世界级模型家族：世界上最好的图像编辑模型；最好的转写模型；成本仅 2% 的前沿网络防御；以及价格真正可规模化的世界级日常编码模型。

关键在于，这一切都承载着你的 IQ。你的 Agent。你的权重。全部由你掌控。

这就是你可以信任的前沿智能，来自你可以信任的公司。
