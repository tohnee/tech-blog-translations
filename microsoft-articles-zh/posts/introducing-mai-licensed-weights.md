# MAI Licensed Weights：由你掌控的前沿性能

> 原文：[MAI Licensed Weights: Frontier performance you control](https://microsoft.ai/news/introducing-mai-licensed-weights/) · Microsoft AI

让一家公司与众不同的东西，将越来越多地存在于它所运行的 AI 模型之中。企业越来越希望对模型拥有控制权：谁能访问、如何适配、运行成本多少，以及何时升级。

正因如此，我们推出 MAI Licensed Weights（授权权重），让组织能够在自己的 Azure 环境中部署并定制微软 AI 模型。

## 由你掌控的模型

MAI Licensed Weights 将微软的前沿 AI 模型带入你自己的 Azure 环境，你可以在其中针对自身业务进行适配，并安全地融入专有知识与专业经验。你的数据和适配成果始终归你所有，微软只有在获得你明确同意的情况下才会将其用于训练模型。

当这些模型嵌入到你最重要的产品和流程中，你仍掌控它们的部署方式、访问权限以及升级时点。这意味着你可以按自己的节奏创新，而不必牺牲业务所依赖的连续性。

## 为你的业务打造的前沿性能

对企业而言，最好的模型未必是最大或最强的通用模型，而是在真正重要的任务上表现最好、且成本能让 AI 规模化部署变得可行的那个模型。

通过让 MAI 模型适配自身专有知识和工作流，客户在专业任务上取得了前沿级甚至更好的性能，而成本仅为原来的一小部分。

**AT&T** 使用 MAI 模型分析 5G 网络。在标准任务上，MAI 以仅 1/50 的成本优于 GPT-6.1 Sol。[1](#fn-1) 在更复杂的任务上，它以显著更低的成本达到前沿级性能。

其他客户也展示了类似的结果：

* **Woven by Toyota** 使用 MAI 模型修复软件代码，在其现有前沿模型需要人工介入的案例中，有 44% 由 MAI 产出了可直接合并的修复，而成本不到十分之一。[2](#fn-2)
* **Alaska Airlines** 将飞机维修报告分类的准确率从 81% 提升到 91%，以极低的成本超越了领先的前沿模型。[3](#fn-3)

这些结果说明，当企业把微软的前沿 AI 研究与自身专业经验结合时，能够实现什么：在重要任务上更好的表现，成本却大幅降低。而随着越来越多的专业经验嵌入 AI 模型，掌控并持续演进这些模型的能力也将变得越来越有价值。

## 立即开始

MAI Licensed Weights 即将通过我们的 Frontier Company 合作计划推出。如需了解更多，请联系你的微软客户团队。

**关于这些结果**
*结果反映客户针对特定任务适配模型后的评估。性能与成本优势会因工作负载、模型配置与评估方法而异。*

1. **AT&T：**定制版 MAI Code 2 Flash 和 Code 2 在 5G 网络运营分析上评估，包含与 GPT-6.1 Sol 的对比。
2. **Woven by Toyota：**MAI Code 2 Flash 基于历史 MISRA 编码规范修复记录进行微调，并与生产中使用的前沿模型进行对比。
3. **Alaska Airlines：**MAI Code 2 Flash 在飞机维修报告分类任务上评估，调优后准确率从 81.2% 提升至 91.1%。最终决策仍由具备资质的员工负责。
