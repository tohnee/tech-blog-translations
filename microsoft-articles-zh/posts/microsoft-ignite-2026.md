# 七款全新的世界级模型，兼具可规模化的性价比

> 原文：[Seven new world-class models at scalable price-performance](https://microsoft.ai/news/microsoft-ignite-2026/) · Microsoft AI

在 MAI，我们的使命是为你们打造世界上最好的模型，并让每一位开发者和每一家企业始终站在能力的最前沿。

但随着 token 开销飞涨，我们知道你们还需要这样的模型：价格足以支撑 Agent 全天候运行、真正去做工程工作。

因此，今天我们发布一系列共七款全新的世界级模型，性价比真正出类拔萃。

**阵容如下：**

* **[MAI Cyber 2 Flash](/news/introducing-mai-cyber-2-flash/)** 在 CyberGym-E2E 基准上以每任务不到 2% 的成本超越 GPT-6 Astra 的质量。
* **[MAI Code 2](/news/introducing-mai-code-2-and-mai-code-2-flash/)** 以约 40% 的价格达到 GPT-6.1 Sol 98% 的编码质量。对比 Opus 5.5，它以仅 5% 的价格达到 96% 的性能。
* **[MAI Code 2 Flash](/news/introducing-mai-code-2-and-mai-code-2-flash/)** 以 65% 的价格达到与 GPT-6 Luna 相当的性能，以 20% 的价格达到与 Haiku 5.5 相当的性能。
* **[MAI Image 2.7](/news/introducing-mai-image-2-7/)** 在 Artificial Analysis 图像编辑榜单上排名第一，以仅五分之一的价格超越 GPT Image 2.6 Sunburst（max）。
* **[MAI Realtime 1](/news/introducing-mai-realtime-1/)** 优于 GPT-Realtime 2.1，起价仅为每分钟音频 0.01 美元。
* **Dragon Copilot Transcribe** 构建于 MAI Transcribe 2 之上——后者是全球最快、最准确的多语种转写模型——现已每月支撑 1,000 万次患者就诊，并将多语种错误率减半。
* **[Decision 1.1](http://aka.ms/decision-model-ga)** 是微软最新的决策模型，比 GPT-6.1 Sol 快 50 倍、便宜 79 倍。
* [**Maia 200**](https://blogs.microsoft.com/blog/2026/10/12/microsoft-to-expand-azure-maia-system-to-multi-gigawatt-deployments/)，微软第二代 AI 加速器，现已投产运行我们最大的模型，每瓦 token 数提升至 1.7 倍。

## 为全天候运行而构建的前沿网络防御

安全、对齐与围控（containment）是 2027 年及以后 Agent 开发中最重要的优先事项。这也是我们的首要任务。我们需要让监控与控制 Agent 全天候运行，防御并修补在线生产系统。正因如此，**[MAI Cyber 2 Flash](https://microsoft.ai/news/introducing-mai-cyber-2-flash/)** 的设计目标就是以零头的成本交付前沿智能。

我们的模型基于微软数十年积累的专有数据和世界级安全专业能力构建，帮助防御方在攻击者拥有廉价且充裕的进攻工具的新时代保持安全。

MAI Cyber 2 Flash 建立在防御方已经依赖的早期 MAI Cyber 模型之上。MAI Cyber 占 MDASH 全部扫描的近 40%，而在首次使用 MAI 的扫描中，有 90% 继续使用它。我们最新模型的输出 token 价格比 MAI Cyber 1.1 Flash 低 86%，让现有 MDASH 客户以更低价格获得更强的模型。

## 以零头成本获得惊人的编码性能

**[MAI Code 2](https://microsoft.ai/news/introducing-mai-code-2-and-mai-code-2-flash/)** 为日常企业编码任务的最佳性价比而构建。在四项针对我们在 GitHub Copilot 中看到的日常企业编码任务的常用基准（DeepSWE 1.1、Terminal Bench 2.1、SWE-Atlas 和 FrontierCode v1.1）上取平均，MAI Code 2 以 40% 的价格达到 GPT-6.1 Sol 98% 的性能，以仅 5% 的价格达到 Claude Opus 5.5 96% 的性能。

我们构建这些模型时，优先考虑客户每天都要做的编码工作。它们明确尚未针对更难的问题进行调优，例如基础科学研究和超长周期的 Agent 任务。

MAI Code 2 还经过调优，能够生成出色的仪表盘和可视化。在一项针对前端工作的盲测并排评估中，开发者有 64% 的情况更偏好 MAI Code 2，而非 GPT-6 Sol。今天就可以在 [GitHub Copilot](https://github.com/features/copilot) 中试用 MAI Code 2。[在此了解更多](/news/introducing-mai-code-2-and-mai-code-2-flash/)。

**[MAI Code 2 Flash](https://microsoft.ai/news/introducing-mai-code-2-and-mai-code-2-flash/)** 面向高并发量的日常任务，例如代码解释、定向修改、例行修复和快速迭代，同时以低得多的成本提供质量。在衡量日常、高频例行编码任务的三项编码基准（DeepSWE 1.1、Terminal Bench 2.1 和 SWE-Atlas）上，它的性能与 GPT-6 Luna 和 Claude Haiku 5.5 相当，价格分别为后两者的 65% 和 20%。它已在 [GitHub Copilot](https://github.com/features/copilot) 中可用，并在 [Microsoft Foundry](https://azure.microsoft.com/en-us/products/ai-foundry) 中开放限量访问预览。

## 世界上最好的图像与转写模型

[**MAI Image 2.7**](/news/introducing-mai-image-2-7/) 是世界上最好的图像编辑模型，在 Artificial Analysis 上排名第一，以仅五分之一的价格超越 GPT Image 2.6 Sunburst（max）。在文生图方面，我们的模型排名第四，使我们成为排名第二的实验室。而 **MAI Image 2.7 Flash** 以每 1,000 张图像约 10 美元的价格，为高并发场景带来世界级的图像生成能力。两者均可在 Microsoft Foundry [此处](https://azure.microsoft.com/en-us/products/ai-foundry)获取。

**[MAI Realtime 1](/news/introducing-mai-realtime-1/)** 是我们的首个实时语音到语音模型，专为自然、低延迟的对话设计。在我们的评估中，它在外部基准和 Dynamics 365 基准上均优于 GPT-Realtime 2.1。它的定价面向企业级规模使用，起价为每分钟音频 0.01 美元，可大幅节省预算。你可以在 [MAI Labs](https://labs.microsoft.ai/?model=mai-realtime-1) 中试用，并[在此登记意向](https://forms.cloud.microsoft/r/AQcVUgqpZZ)。

**Dragon Copilot Transcribe** 构建于 MAI Transcribe 2 之上，现已在 Dragon Copilot 中上线，承担 100% 的医患对话转写。它每月覆盖 1,000 万次就诊，将多语种工作流中的错误率减半，并已服务于全美三分之一的医生。

## 市场上领先的决策模型

**[Decision 1.1](http://aka.ms/decision-model-ga)** 将模型路由直接集成到你的应用中，让更大、更贵的模型只在你真正需要时被调用。在 Artificial Analysis Decision Index 上，微软领先于 Jev、Google 和 OpenAI，同时速度更快、成本更低。它已被 4,000 家客户使用，比 GPT-6.1 Sol 快 50 倍、便宜 79 倍。
