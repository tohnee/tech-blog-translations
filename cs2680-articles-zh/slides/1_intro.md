## 第 30 页

**AI 系统有何不同：计算**

异构计算

- CPU：tokenization、kernel 启动、数据移动、工具调用 —— GPU：矩阵乘法
- 混合 GPU 代际与 xPU

不同的计算阶段

- Prefill 是计算受限；decode 是内存带宽受限
- 同一部署会撞上不同瓶颈：计算、带宽、容量

执行时间不可预测

- 取决于输出长度，这使调度复杂化

## 第 31 页

**AI 系统有何不同：非确定性计算**

- 传递性：a == b、b == c 不蕴含 a == c
- 分配律也失效：a \* (b + c) != a \* b + a \* c，但未被广泛使用

**为什么发生**

- 浮点加法不满足结合律——每次运算都会舍入
- 蝴蝶效应：矩阵乘法中第 7 位小数的变化会翻转下一个 token

**来源**

- 运行时：warp/block 调度、内存序、异步流、批大小
- 软件：融合乘加 vs 两次运算、自动调优、次正规数
- 硬件：CUDA vs tensor core、Hopper FP8 vs Blackwell micro-scaling tiles

近似计算是可接受的。

## 第 32 页

巨大状态

- 模型权重：GB 到 TB
- KV 缓存：每 token 数十到数百 KB
- 前缀缓存：跨请求复用 KV

多 GPU 通信

- 流水线 / 张量 / 专家 / 上下文并行
- 集合通信：NCCL、UCCL
- 拓扑：NVLink、以太网/InfiniBand
- CPU 与内核旁路：RDMA

## 第 36 页

**什么是 AI 智能体？**

记忆　LLM　推理与规划　智能体　动作　观察　环境

AI 智能体是一种自主软件系统，它使用 AI 模型对目标进行推理、使用外部工具，并执行多步动作，直到任务完成。

1. 规划——把任务分解为子步骤
2. 行动——调用外部工具（API、数据库）
3. 观察——解释这些工具返回的结果
4. 适应——根据新信息修订计划
5. 交付——返回最终结果

## 第 39 页

**为什么智能体是一个系统问题？**

多轮：关键路径跨越 GPU、CPU、存储、网络与外部服务。

传统 LLM 服务：请求 → 推理 → 响应

智能体服务：推理 → 工具 → 推理 → 工具 → 检索 → 推理 → …

- 步骤之间存在依赖
- 步骤延迟高度可变
- 阻塞 / 等待工具
- 状态快速增长
- 并发与投机
- 轨迹中任何位置都可能失败

## 第 50 页

**关键区别：自主性、复杂度与学习**

- **自主性**：智能体独立运行并决策以达成目标。助手需要用户输入与指导。机器人遵循预编程规则。
- **复杂度**：智能体处理复杂任务与多步工作流。助手与机器人适合更简单的任务与交互。
- **学习**：智能体使用机器学习随时间适应。助手可能有一定程度的学习。机器人几乎不学习，或完全不学习。
