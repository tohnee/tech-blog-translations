# J.Crew 借助 Claude 将其标志性的造型理念变为现实

> 原文：[J. Crew brings its signature approach to styling to life with Claude](https://claude.com/resources/articles/j-crew-style-advisor-with-claude) · Claude 博客

J.Crew 全新的 Style Advisor 使用 Claude 提供更个性化的在线购物方式，以完整造型而非单件商品进行推荐。

在线上，购物通常是一件商品一件商品地发生，因此顾客找到一件毛衣后，还得再去找能与之搭配的裤子和鞋子。为了改变这一点，J.Crew 今天推出了 Style Advisor——一个在 [JCrew.com](https://www.jcrew.com/)（在新标签页中打开）上的 AI 造型师，帮助顾客按整套造型购物。J.Crew 团队用 [Claude Code](https://claude.com/product/claude-code)（在新标签页中打开）构建了它，并使用了从 Fable 到 Haiku 的多个 Claude 模型，每个模型都匹配其最擅长的工作。目前它已在美国的女士和男士款式上线。

40 多年来，J.Crew 自家的造型师通过平衡比例、色彩与层次，并用出人意料的方式搭配单品，打造出完整的造型。Style Advisor 把这份专业能力搬到了线上。顾客描述自己的需求，比如一套海滩婚礼的着装或第一次面试的穿搭，它就会用取自 J.Crew 自家拍摄的完整造型来回应。顾客可以在此基础上继续调整，让购物变成一场视觉对话。

## **如何构建**

J.Crew 的产品团队使用 [Claude Fable](https://www.anthropic.com/claude/fable)（在新标签页中打开）5.1——Anthropic 面向复杂、开放式工作的模型——来规划 Style Advisor 应如何像造型师一样推理，然后在 Claude Code 中用 [Claude Opus](https://www.anthropic.com/claude/opus)（在新标签页中打开）5.5 构建出一个可用的原型。J.Crew 的工程师将这个原型推向了生产环境。在每次对话中，[Claude Sonnet](https://www.anthropic.com/claude/sonnet)（在新标签页中打开）5.5 担任造型师，决定回应的每一步；[Claude Haiku](https://www.anthropic.com/claude/haiku)（在新标签页中打开）5.5 则处理快速、聚焦的任务，让 Style Advisor 能迅速作答。由于每个造型都来自 J.Crew 的造型师，其推荐始终与 J.Crew 的造型视角保持一致。

### **顾客如何使用 Style Advisor**

* **购买整套造型。**每一条推荐都源自 J.Crew 造型师为品牌产品目录拍摄所创作的造型，Style Advisor 以照片形式展示它们，让顾客看到完整的搭配。
* **从单件开始搭配。**顾客可以从一件单品入手，获得补全整体造型的建议。
* **按场合穿搭。**顾客可以说明自己要去的场合——度假、节日派对或婚礼——并获得相应的推荐。
* **获得 J.Crew 的视角。**Style Advisor 采用与 J.Crew 门店造型师相同的造型原则。

## **下一步**

发布之初，Style Advisor 帮助顾客发现新的造型灵感，更自信地购物。随着时间推移，J.Crew 计划根据每位顾客的偏好和过往购买记录来定制建议，让它更加个性化，并将它推广到更多市场和产品线。

“随着消费者期望的演变以及 AI 为零售带来新的可能性，J.Crew 正在挑战传统的线上购物模式，从单件商品搜索转向更连贯、更由灵感驱动的体验，”J.Crew Group 首席执行官 Libby Wadle 表示。“很长一段时间以来，我们一直在思考顾客未来希望如何购物，以及我们如何引领这一演变，而不是被动应对。我们看到了一个从根本上重新思考购物体验的机会。通过与 Anthropic 的合作，我们把 J.Crew 数十年的造型、商品企划和创意专长汇聚在一起，帮助塑造顾客行为的下一步。”

“J.Crew 拥有时尚界最具辨识度的视角之一，其团队用 Claude 以一种全新的方式把这份专业能力带给顾客，”Anthropic 首席商务官 Paul Smith 表示。“他们用前沿模型构建体验，用更快、更高效的模型来运行它，因此顾客能获得快速且忠于品牌造型理念的答案。”

***今天就开始用 [Claude Code](https://claude.com/product/claude-code)（在新标签页中打开）构建吧。***
