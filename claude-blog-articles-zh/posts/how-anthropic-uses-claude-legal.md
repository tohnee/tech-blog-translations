# Anthropic 法务团队如何用 Claude 把审核时间从数天缩短到数小时

> 原文：[How Anthropic's legal team cut review times from days to hours with Claude](https://claude.com/resources/articles/how-anthropic-uses-claude-legal) · Claude 博客

*副总法律顾问 Mark Pike 分享我们的法务团队如何用 Claude 构建工作流，把审核营销内容、红线修订合同等重复性任务自动化——无需写代码。*

在 Anthropic，Mark Pike 的桌上摆着一部复古投币电话，新旧错位得有点滑稽。拿一枚“法务挑战币”往上一敲——是的，真的——它就会响。一个 AI 机器人接起来，弄清你需要什么，然后把你转接给合适的律师。

这是 Mark 自己搭的。而他并不会写代码。

“我不会说自己是在学编程，”Anthropic 的产品律师 Mark 说。“我和 Claude 合作处理一些涉及编程的项目，但真正写代码的不是我。我只是非常擅长排查问题。”

## 问题：被事务性工作淹没

在用 Claude 之前，Mark 的一天和任何一位公司法务没什么两样。回复合规文件和客户问卷。起草并更新服务条款和隐私政策。在发布前的最后几小时里审阅博客文章和邮件文案。

“用 Claude 之前，我有一大堆事务性杂活，”Mark 说。“那些我会拖到一天结束才做的事，因为我知道它们很花时间，却没用到我大脑最好的部分。”

流程永远一样：Slack 上来个提醒或一封邮件，打开 Google 文档，读一遍，插入评论，再回去告诉客户他们需要改什么，然后来回两三次，把事情弄到合适的状态。

Anthropic 的法务团队决定做点什么。他们进了一间会议室，把痛点写在白板上：什么在消耗我们的精力？什么感觉在重复？什么阻碍了我们做有影响力的工作？

清单很长。拖上好几天的营销内容审核周期。吃掉数小时人工比对的合同红线修订。模式相似却每次都要从头重建格式的隐私影响评估。甚至连实体邮件的分拣也在其中。

“目标是让法务团队从‘说不部门’变成跨职能的思想伙伴，”Mark 解释道。“当法务团队对 AI 感到兴奋时，我们就不再是更广泛采用的阻碍者。其他团队看到我们在做什么，就会意识到他们也能做到。”

## 解决方案：四个实战工作流

经过几个月的时间和大量实验，法务团队一些最大的痛点已经演变成可重复的工作流。

### 营销内容审核工作流

![](https://assets.claude.com/b70130a1213d1f87da2a7530ec9a2c11760fea24.png)

法务团队的营销材料自审工具，让市场推广（go-to-market）员工在提交法务做最终审核之前先自查内容。

这个问题对任何支持营销的法务团队都不陌生：临近截止的博客文章审核，周转时间极紧。

Mark 和团队构建的方案是一个固定在 Slack 里的自助审核工具。营销人员粘贴内容，Claude 用一个“技能”（一个包含法务团队历史指导原则和审核框架的文件）来分析它。工具会识别宣传权问题、夸大表述、统计数据准确性问题等，并把它们标记为低、中或高风险。它会在营销人员还没提交工单之前就给出修改建议。

“它会指出类似‘嘿，你有这个 logo 的使用权吗？这个统计数据准确吗？这个商标需要加符号’之类的问题，”Mark 解释道。“做完这些，再去法务工单队列提交工单。”

当内容确实进入正式审核时，它会带着预先标记的问题被分派给合适的律师。自这套工具接入他们的队列以来，周转时间从两到三天降到 24 小时。

“我仍然会读那篇博客文章。我仍然在审这项工作，”Mark 指出。“但这帮助我们以更快的速度推进。”

### 合同红线修订工具

比对合同版本并提出备选条款语言，是件耗时的工作。

现在 Claude 会在 Google Docs 和 Office 365 等工具中比对文档版本、高亮变更，并从商务谈判手册中推荐条款措辞。团队成员摸索出了让 Claude 在 Google Docs 内工作、实时以建议修改的形式评论的方法。审阅合同的人可以直接在文档里问：“嘿 Claude，你觉得这个措辞能满足我们的需求吗？”并立刻得到反馈。

“合同红线修订是所有人对 AI 的期待场景，”Mark 说。“而 Claude 真的很擅长——它为我们省下了数小时的人工比对。”

Mark 和同事还编写了 [Skills](https://claude.com/resources/articles/skills)——存储在文件中、由 Claude 根据任务读取的专用指令和最佳实践——来进一步简化特定类型文件的审核，从 NDA 到第三方供应商协议。

### 外部商业活动审核

![](https://assets.claude.com/4a511f132bc9f11d2582225a6e1176f953ba483f.jpg)

法务团队的外部商业活动申请表，加速了 Anthropic 员工的利益冲突审核流程。

在 Anthropic，如果员工想对外提供咨询或加入非营利组织董事会，需要填一张表来排除利益冲突。雇佣法律师过去要在常规的利益冲突表格审核上花大量时间。

他们由 Claude 驱动的工作流让员工填写一张包含所在部门、直属经理和拟从事活动说明的表格。Claude 依据利益冲突政策框架分析提交内容，并通过 Slack 把建议发给律师审批。

“以前你得和员工面谈，来回几轮才能弄清细节和可能存在的冲突。有了这个工作流，Claude 读取表格，需要时追问更多信息，并给出结论建议，”Mark 解释道。“然后它带着建议进入我们的队列。”

### 隐私影响评估（PIA）

从头撰写隐私影响评估很繁琐，即便它们的模式相似。团队现在使用 [MCP（Model Context Protocol）](https://modelcontextprotocol.io/)服务器把 Claude 连接到存有以往 PIA 的 Google Drive 文件夹，并用一个 Skill 指导 Claude 掌握格式和关注点。

例如，律师可以让 Claude 基于一个装满以往 PIA 的文件夹撰写一份新的 PIA。

“Claude 非常擅长读取那部分上下文，并用那个技能生成新模板，帮我继续推进这一天的工作，”Mark 说。

## 用法务工作使用 Claude 的最佳实践

Mark 的经验为正在采用 AI 的律师和法务专业人士提供了实用指导。

**从痛点出发，而不是从技术出发**

问问自己：我们手上最忙的工作是什么？什么在消耗我们的精力？什么感觉在重复？“不要从‘AI 能做什么’开始，”Mark 建议。“从‘我们希望自己不必做什么’开始。”

**用自然语言描述你的需求**

“我第一次看到 Claude Code 时，它看起来像《黑客帝国》里的东西，”Mark 回忆道。“一行行代码滚过去，第一眼很吓人。但后来我只是打了一句普通的话，描述我想要什么。然后它就工作了。”

**内置人工监督**

AI 仍然可能产生幻觉。始终核验引用和输出。把 AI 用于第一轮审核、分诊和起草，而不是最终判断。Mark 的工作流会流转给律师审批，而不是绕过律师。“我们知道 AI 系统仍可能产生幻觉，我们要确保核验和检查引用，确认 AI 没有编造内容。”

**用 Skills 保持一致性和语气**

[Skills](https://www.anthropic.com/news/skills) 是包含指令、脚本和资源的文件，Claude 会在与任务相关时动态加载它们。它们把专业知识打包成可复用的工作流，让 Claude 在专门任务上表现更好。

Mark 以两种方式使用 Skills。第一是保证工作流一致性：他的营销审核技能包含法务团队的指导原则，帮助 Claude 识别问题，并在营销人员提交法务之前指导他们如何修改。

第二是语气和写作风格：Mark 让 Claude 分析他最近的十份备忘录，学习他的格式偏好以及他在产品法律简报中通常包含的内容。现在他可以把产品路线图上传到 Claude 项目，调用自己的技能，得到一份带有他本人语气风格的初稿。

不同的技能服务于不同的专业领域：雇佣、商务、隐私、公司。一个技能可以教 Claude 像雇佣法律师那样写作，或像产品律师那样格式化备忘录。

**借助 MCP 连接你的知识来源。**

MCP 让你可以把其他系统中的信息拉进 Claude。Anthropic 法务团队用 MCP 把 Claude 连接到 Google Drive、JIRA 工单、Slack 消息和 Google Calendar。把这些信息都拉进来，意味着能在正确的时机呈现正确的上下文。

## 更大的图景

Mark 设想这样一种未来：新入职的律师通过提示词库和技能，继承团队积累的知识。新人不必翻读旧备忘录来学习内部文风，而是可以调用一个技能，教 Claude 像团队的产品律师那样写作，或按公司法务组偏好的格式整理董事会纪要。

“我们不是在取代律师，”他说。“我们是在拓展可能性的边界。我们在用他们需要的能力和工具武装他们，让他们把最好的工作做出来。”
