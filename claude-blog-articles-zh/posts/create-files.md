# Claude 现在可以创建和编辑文件

> 原文：[Claude can now create and edit files](https://claude.com/resources/articles/create-files) · Claude 博客

描述你的需求，拿回可直接使用的电子表格、文档、演示文稿和 PDF，而不只是文字回复。

*编者注：本文中提及 Max 的内容写于 2026 年 10 月 30 日之前，其中的 Max 现包含 Max 和 Ultra 两个套餐。*

**更新：**现已在付费套餐中全面开放，并提供网络与出口（egress）控制（2025 年 10 月 21 日）。

Claude 现在可以直接在 [Claude.ai](https://claude.ai/) 和桌面应用中创建和编辑 Excel 电子表格、文档、PowerPoint 幻灯片和 PDF。这改变了你与 Claude 协作的方式——你不再只是收到文字回复或应用内的 artifacts，而是可以描述需求、上传相关数据，然后拿回可直接使用的文件。

文件创建功能现以预览形式向 Max、Team 和 Enterprise 套餐用户开放。Pro 用户将在未来几周内获得访问权限。

### 你可以做什么

Claude 会根据你的指令创建真实文件——无论是基于上传的数据、检索信息，还是从零构建。以下是几个例子：

* **把数据变成洞察**：把原始数据交给 Claude，拿回经过打磨的成果，包括清洗后的数据、统计分析、图表，以及解释关键所在的书面洞察。
* **构建电子表格**：描述你的需求——带情景分析的财务模型、带自动化仪表盘的项目跟踪表，或带差异计算的预算模板。Claude 会用可用的公式和多个工作表把它做出来。
* **跨格式工作**：上传一份 PDF 报告，得到 PowerPoint 幻灯片；分享会议记录，得到格式规范的文档；上传发票，得到整理好并带有计算的电子表格。Claude 承担繁琐的工作，并按你需要的方式呈现信息。

![三个提示词及生成的 Excel、文档和 PDF 文件。](https://assets.claude.com/dbd800f381e7b4449ed6a87bdfda7097fb94a289.jpg)

无论你需要客户细分分析、销售预测还是预算跟踪，Claude 都会处理技术工作并产出你需要的文件。文件创建把通常需要编程技能、统计知识和数小时努力的项目，变成几分钟的对话。

### **工作原理：Claude 的计算机**

过去一年，我们看到 Claude 从回答问题走向完成整个项目，现在我们正让这种能力更易获得。我们为 Claude 提供了一个私有计算机环境，它可以在其中编写代码、运行程序，产出你需要的文件和分析。

这使 Claude 从顾问变成主动的协作者。你带来上下文和战略；Claude 在幕后处理技术实现。这展示了我们的方向：让复杂的多步骤工作可以通过对话完成。随着这些能力扩展，想法与执行之间的差距将持续缩小。

### **开始使用**

要开始创建文件：

1. 在 [Settings > Features > Experimental](https://claude.ai/settings/features) 中启用“Upgraded file creation and analysis”
2. 上传相关文件，或描述你的需求
3. 通过聊天引导 Claude 完成工作
4. 下载完成的文件，或直接保存到 Google Drive

![开启该功能的开关。](https://assets.claude.com/f1451444c1da87b4e8990d280fc50ab7e8c5ebb1.png)

从数据清洗或简单报告等直接任务开始，等你熟悉 Claude 处理文件的方式后，再逐步尝试财务模型之类的复杂项目。

该功能让 Claude 可以联网创建和分析文件，这可能会让你的数据面临风险。使用该功能时请密切关注对话。[了解更多](https://support.anthropic.com/en/articles/12111783-create-and-edit-files-with-claude)。
