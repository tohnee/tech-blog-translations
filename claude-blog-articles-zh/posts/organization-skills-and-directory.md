# 面向组织、合作伙伴与生态的 Skills

> 原文：[Skills for organizations, partners, the ecosystem](https://claude.com/resources/articles/organization-skills-and-directory) · Claude 博客

今年 10 月，我们推出了 [Skills](https://claude.com/resources/articles/skills)——一种把你自己的工作方式教给 Claude、让它执行可重复工作流的方法。今天，我们让 Skills 更易于部署、发现和[构建](https://claude.com/resources/articles/how-to-create-skills-key-steps-limitations-and-examples)：面向管理员的组织级管理；一个收录 Notion、Canva、Figma、Atlassian 等合作伙伴所构建 Skills 的目录；以及一项让 Skills 能跨 AI 平台通用的开放标准。

## **在整个组织范围内管理 Skills**

Claude Team 和 Enterprise 套餐的管理员现在可以在管理设置中集中配置 Skills。管理员配置的 Skills 默认对所有用户启用。用户仍可根据自己的选择关闭个别 Skills。这让组织能在各团队之间保持一致、经过批准的工作流，同时让个人用户自定义自己的体验。

![](https://assets.claude.com/9c64e79724254d88623b70d69e969db6bfbf5a87.png)

## **发现、创建和编辑新的 Skills**

创建 Skills 现在更简单了。描述你想要什么，Claude 会帮你构建，或者直接编写指令。对于复杂的工作流，可以上传 skill 文件夹，或使用 skill-creator。Claude 也可以帮你编辑已有的 Skills；新增的预览会显示完整内容，让你在启用之前就能确切理解一个 Skill 做什么。

## **Skills 目录**

一个不断扩充的、由合作伙伴构建的 Skills 合集现已在 [claude.com/connectors](https://claude.com/connectors) 上线。

管理员可以在整个组织内配置这些合作伙伴 Skills，让团队无需任何定制开发，就能立即获得针对他们已在使用的工具的工作流。

## **一项开放标准**

我们还将 [Agent Skills](https://agentskills.io) 发布为一项开放标准。与 MCP 一样，我们相信 Skills 应当能在不同工具和平台之间移植——同一个 Skill，无论你用的是 Claude 还是其他 AI 平台，都应该能工作。我们一直在与生态中的成员协作，也很高兴看到这项标准已被早期采用。

## **快速开始**

* **Claude 应用：** 浏览 [Skills 目录](https://claude.com/connectors)，在设置 > 能力（Capabilities）> Skills 中启用。
* **Claude Code：** 从插件目录安装，或把 Skills 检入你的代码仓库。
* **Claude 开发者平台（API）：** 通过 /v1/skills 端点使用 Skills。参见[文档](https://platform.claude.com/docs/en/agents-and-tools/agent-skills/overview)。

管理员可以通过管理设置（Admin Settings）在组织范围内配置 Skills。使用 Skills 需要启用[代码执行与文件创建](https://claude.ai/settings/capabilities)。
