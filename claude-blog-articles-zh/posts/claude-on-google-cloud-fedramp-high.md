# Google Cloud Vertex AI 上的 Claude：获得 FedRAMP High 与 IL2 授权

> 原文：[Claude on Google Cloud’s Vertex AI: FedRAMP High and IL2 Authorized](https://claude.com/resources/articles/claude-on-google-cloud-fedramp-high) · Claude 博客

Claude 现已在 Google Cloud 的 Vertex AI 上获得 FedRAMP High 和 IL2 工作负载授权，使联邦机构和国防组织能够在满足严格合规要求的前提下使用我们的模型。

今天，我们宣布 Claude 模型已通过 Google Cloud Vertex AI 平台获得 FedRAMP High 和 IL-2 工作负载授权。

凭借这些授权，联邦文职机构和国防组织可以在满足其严格监管合规要求的同时使用 Claude，从而在创新与安全之间取得平衡。

### 扩大政府对 Claude 的使用渠道

联邦风险与授权管理计划（FedRAMP）为联邦云服务的安全评估提供了标准化方法。借助 Vertex AI，联邦机构可以在已获 FedRAMP High 授权的环境中使用 Claude，覆盖医疗、执法、金融和应急服务等领域，同时保持对敏感非密数据的合规要求。

同样，国防承包商和机构在处理非受控非密信息时，可以在已获 DoD 影响等级 2（IL2）授权的环境内使用 Claude，从而支持更广泛的国防用例。

有了 Claude，联邦机构现在可以：

- 构建 AI 应用和工作流，同时保持对严格安全标准的合规
- 访问完整的 Claude 模型家族，包括我们迄今最智能的模型 Claude 3.7 Sonnet
- 以前沿 AI 能力支撑数字化转型计划

### 为政府 AI 创新清障

Vertex AI 上的 Claude 以 API 形式提供全托管、无服务器的模型，机构无需自行配置或管理基础设施，即可落地满足其技术与安全需求的 AI 解决方案。

Claude 的 FedRAMP High 和 IL2 可用性对政府客户而言是重要进展，也为未来兼容 IL5 奠定基础——届时将可用于更敏感的国防部工作负载。

### 开始使用

联邦机构雇员和承包商可以通过 Google Cloud 的 Assured Workloads 访问 Vertex AI 上的 Claude 模型。Assured Workloads 提供专为政府工作负载设计的增强安全与合规控制。

要在 FedRAMP High 或 IL2 环境中开始使用 Claude：

1. 搭建一个配置了 FedRAMP High 或 IL2 的 Assured Workloads 的 Google Cloud 环境
2. 通过 Vertex AI Model Garden 访问 Claude 模型
3. 使用 Vertex AI API 端点开始构建
