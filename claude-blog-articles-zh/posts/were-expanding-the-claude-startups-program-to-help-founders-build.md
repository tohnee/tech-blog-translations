# 我们正在扩展 Claude Startups 计划，帮助创始人构建产品

> 原文：[We're expanding the Claude Startups program to help founders build](https://claude.com/resources/articles/were-expanding-the-claude-startups-program-to-help-founders-build) · Claude 博客

***更新（2026 年 10 月 13 日）：本期计划名额已满，我们目前暂不接受新的申请。请访问 [Claude Startups 页面](https://claude.com/programs/startups)了解详情与常见问题解答。***

今天，我们正在扩展 Claude Startups——这是我们面向在 Claude 之上创办公司的创始人的计划。会员权益包括一年的 Claude Team 套餐、API 额度、有助于运营 AI 原生公司的工具特别优惠、与 Anthropic 应用 AI（Applied AI）团队的开放咨询时间（office hours），以及更多内容。

## **我们为什么要扩展该计划**

把一个想法变成产品，从来没有像今天这样容易。一个小团队可以在创纪录的时间内做出原型，没有编程背景的人也能交付可用的软件。但想法只是第一步。当人人都能快速构建时，你反而更难知道是什么让你的产品与众不同，尤其是底层的模型还在不断变强。创始人也必须承担起步阶段的成本，而合适的工具既难找、也难以快速配置到位。这正是紧密合作能起作用的地方：与构建模型的人共处的时间，可以帮助你了解他们正走向何方、决定在哪里做出差异化，并尽早解决这些挑战。

这就是我们创建 Claude Startups 的原因。自今年早些时候启动该计划以来，会员们已获得 Claude 额度和工具、与构建者社区的连接，以及生态系统新闻和产品功能的访问权限。许多快速成长的 AI 原生公司已加入该计划，在下一阶段，我们将向更多公司开放。

## **今天就开始构建**

我们希望基于 Claude 构建的创始人取得成功，而在早期我们所能做的最有用的事，就是让你从一开始就能使用我们的模型和产品。Claude 每隔几个月就会显著变强，而一家为未来做好准备的公司，可以在我们的模型发布当天就把它用起来。

Claude Startups 会员可获得价值最高 7,000 美元的 Claude 产品与额度用于构建\*：

* **免费使用一年 Claude Team：**面向首次使用 Team 的公司，最多五个 Premium 席位。
* **一次性 1,000 美元 API 额度用于起步：**获批后即可使用，让你立刻开始——接入 API、测试几个想法，并跑早期的评估（evals）。

## **运营 AI 原生公司的工具**

全新的 Claude Startup Stack 是一组面向初创公司日常运营工具的权益，覆盖从销售到设计再到数据工程的各个环节。会员可获得来自同样基于 Claude 构建的公司的折扣与额度，价值最高 45,000 美元\*\*。

[](https://assets.claude.com/c7219aed2bc99e9ccc5c1bf9aaeac1427489fc37.mp4)

### **其他权益**

会员还能获得一套支持业务成长的体系：从触达新客户，到与我们的团队一起解决技术问题，再到与其他创始人共同学习。

* **与 Anthropic 保持紧密联系：**会员可以预约与 Anthropic 应用 AI 团队的线上开放咨询时间。
* **触达 Claude 用户：**Claude Marketplace 是 Claude 用户发现连接器和插件的地方，因此通过审核的上架条目会让你的产品出现在 Claude 各应用的用户面前。会员可获得实操帮助，来构建自己的条目并提交审核。
* **融入社区：**获得 Founder House、黑客松和聚会等活动（名额有限）的参与机会，以及订阅我们的 Startup Newsletter——其中包含产品与生态系统新闻，还有被专题报道的机会。

**立即申请**

过去五年内成立、或过去两年内获得融资的初创公司均可申请。我们创建这个计划，是因为我们相信 AI 的益处将通过那些在模型之上构建的公司惠及大多数人，而不仅仅是通过模型本身。这使得与创始人和开发者紧密合作成为我们使命的核心。AI 将赋能他们，为社会带来更快的科学发现、全新的产品品类，以及更有能力的公司。Claude Startups 正是我们帮助更多这类公司起步、并在它们成长过程中提供支持的方式。

访问 [Claude Startups 页面](https://claude.com/programs/startups)了解更多并提交申请。

关于初创公司日常如何使用 Claude Code，请参阅 [The Claude Code guide for startups](/resources/articles/claude-code-guide-for-startups)

\*按一年 Claude Team、五个 Premium 席位、每席位每月 100 美元、按年计费（6,000 美元）加上一次性额度（1,000 美元）计算。实际价值取决于你的席位数量与类型。额度受我们的[《补充额度条款》（Supplemental Credit Terms）](https://www.anthropic.com/legal/credit-terms)约束。

\*\*按截至 2026 年 9 月合作伙伴标价计算的所有 Claude Startup Stack 优惠合计最高价值。实际价值取决于你兑换哪些优惠、你的套餐以及团队规模。优惠由合作伙伴提供，并受其条款约束。你的公司可能无法获得或组合所有优惠。
