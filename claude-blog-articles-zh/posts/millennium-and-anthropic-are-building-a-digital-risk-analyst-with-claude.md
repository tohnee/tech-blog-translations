# Millennium 与 Anthropic 用 Claude 打造数字风险分析师

> 原文：[Millennium and Anthropic are building a digital risk analyst with Claude](https://claude.com/resources/articles/millennium-and-anthropic-are-building-a-digital-risk-analyst-with-claude) · Claude 博客

Anthropic 正与 Millennium 合作——后者是全球最大的另类投资管理公司之一——共同开发一名数字风险分析师：一位 AI 队友，与该公司的风险经理并肩工作并接受其监督，发掘新的风险洞察，并就跨资产类别的风险敞口形成观点。

Claude 和 [Claude Code](https://claude.com/product/claude-code) 如今已在 Millennium 广泛使用——从交易台、工程团队到核心业务职能。Millennium 的数字风险分析师扩展了他们对 Claude 的使用，帮助风险经理更快、更深入地分析风险头寸。

## 用 Claude 评估金融风险

几十年来，投资公司一直在用技术改进风险度量，从传统评估走向更复杂的实时情景分析。Millennium 的数字风险分析师旨在攻克关键工作流，由 Millennium 的专有数据和 Claude 的前沿智能驱动。

数字风险分析师会随时间保留并调用信息，运用新的推理能力帮助解释每日风险变化。这些发现随后由 Millennium 的人类风险经理验证和充实。

“在 Millennium，我们相信 AI 能帮助人们把成就提升到新的高度。”Millennium 首席信息官 Vlad Torgovnik 表示，“我们与 Anthropic 的合作就是一个很好的例子，它展示了 AI 如何在我们业务的核心环节推动创新，同时让人类判断始终处于决策的中心。我们很高兴能继续与这样一家行业领导者合作，探索 AI 为业务创造价值的新方式。”

## Millennium 员工如何使用 Claude

Millennium 是 Claude 和 Claude Code 的早期采用者。员工使用 Claude Code 编写软件、构建产品并改进工作流，包括在 Millennium 340 多个投资团队中的许多团队里。

数字风险分析师通过记录其推理过程、在沙箱环境中测试其行动，并要求人类专家评估和批准其决策，来提供安全、可审计的分析。Millennium 的风险专家正与 Anthropic 的研究和应用 AI 团队一起，在 Millennium 的 AI 实验室中构建它。

Millennium 正在利用其内部 AI 实验室继续推进前沿：用雄心勃勃的用例对 Anthropic 最新的 Claude 模型进行压力测试，并让 Claude 在快节奏的环境中发挥创新作用。

“金融服务需要人们能够在复杂、严苛的环境中信任的 AI。”Anthropic 金融服务董事总经理 Belinda Neal 表示，“Millennium 是 Claude 和 Claude Code 的早期采用者，我们与其风险团队的合作将展示 AI 如何为 Millennium 风险经理每天所做的分析提供支持。”

“Claude 能够推理风险头寸、解释每日变化，并把学到的内容带入下一个问题。”Anthropic 资产与财富管理负责人 Peter Nolan 表示，“Millennium 的风险经理将借助前沿智能获得自动化建议，目标是节省宝贵的时间。”
