# Claude 现已在 Microsoft 365 Copilot 中可用

> 原文：[Claude is now available in Microsoft 365 Copilot](https://claude.com/resources/articles/claude-now-available-in-microsoft-365-copilot) · Claude 博客

今天，Microsoft 宣布 Claude 模型现已在 Microsoft 365 Copilot 中可用，通过 Microsoft 的生产力平台把 Claude 带给数百万企业用户。

从 Microsoft 的 Researcher 智能体和 Copilot Studio 开始，企业客户现在可以在现有模型选项之外选择 Claude Sonnet 4 和 Opus 4.1，从而更灵活地为具体业务需求挑选合适的 AI。

Claude Sonnet 4 和 Claude Opus 4.1 的加入，帮助 Microsoft 把业界最优秀的 AI 创新引入 Microsoft 365 Copilot，并针对实际工作调校、贴合你的业务需求。

**Anthropic 模型在 Microsoft 365 Copilot 中的呈现方式：**

- **Researcher 智能体**：Microsoft 的推理智能体现在可以由 Claude Opus 4.1 驱动。无论你是在制定详尽的市场进入策略、分析新兴产品趋势，还是撰写一份全面的季度报告，都可以选择自己喜欢的模型来支撑深度工作。Researcher 帮助你处理复杂、多步骤的研究——不只对网页和可信的第三方数据进行推理，还会对分布在你邮件、聊天、会议、文件等处的全部工作内容进行推理，按需交付高水平的专业能力——而现在你还可以选择模型。
- **Copilot Studio**：Claude Sonnet 4 和 Claude Opus 4.1 模型现已作为模型选项在 Copilot Studio 中提供，让你能轻松创建并定制企业级智能体。通过此次发布，你可以构建、编排和管理由 Anthropic 模型驱动的智能体，用于深度推理、工作流自动化和灵活的智能体任务。借助 Copilot Studio 中的多智能体系统和提示工具，你可以按需为专门任务选用 Claude。

完成选择加入后，你就可以在 Researcher 中轻松选择 Claude。

![Claude in Researcher 让组织能够为具体业务需求选择合适的 AI。](https://assets.claude.com/edcc8828d4056f6bc21a1eeb206ede9e915bbd58.gif)

Claude Opus 4.1 现已在 Microsoft 的 Researcher 智能体中可用，让团队能够借助 Anthropic 业界领先的 AI 处理复杂、多步骤的研究。

**开始使用**

Claude in Researcher 今日起通过 Microsoft 的 Frontier Program，向已选择加入的 Microsoft 365 Copilot 授权客户推出。若要构建智能体，用户也可以通过 Frontier Program 选择加入，试用 Copilot Studio 中的 Claude。Anthropic 模型托管在 Microsoft 管理的环境之外，并受 Anthropic 条款与条件约束。开始使用时，组织管理员可以在 Microsoft 365 管理中心启用对 Anthropic 模型的访问。详见[此处](https://go.microsoft.com/fwlink/?linkid=2334803)。

敬请期待 Microsoft 365 生态内更多 Claude 体验，并在 [anthropic.com/enterprise](http://anthropic.com/enterprise) 了解更多 Claude 的企业能力，以及我们对安全、可信 AI 的承诺。更多细节见 [Microsoft 的发布博客](https://www.microsoft.com/en-us/microsoft-365/blog/2025/09/24/expanding-model-choice-in-microsoft-365-copilot/)。
