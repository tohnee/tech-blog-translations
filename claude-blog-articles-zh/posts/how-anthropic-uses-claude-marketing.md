# Anthropic 增长营销团队如何用 Claude Code 把广告制作时间从 30 分钟缩短到 30 秒

> 原文：[How Anthropic's Growth Marketing team cut ad creation time from 30 minutes to 30 seconds with Claude Code](https://claude.com/resources/articles/how-anthropic-uses-claude-marketing) · Claude 博客

*Anthropic 增长营销人员 Austin Lau 分享自己如何从一个从未打开过终端的人，变成能构建 Figma 插件和自动化广告生成工作流的人——而且没写过一行代码。*

在 Claude Code 之前，Austin Lau 这辈子没写过一行代码。这个产品刚发布时，他甚至得用 Google 搜怎么在电脑上打开终端。

“Claude Code 刚发布时，我的第一反应是：我完全不知道这产品是干嘛用的，”Anthropic 增长营销人员 Austin 说。“作为营销人，我当时真没 get 到——它的用途对我来说还不明显。”

但好奇心最终占了上风。

Anthropic 的一位同事曾在公司 Slack 工作区发布过一份指南，讲非技术员工如何安装 Claude Code。Austin 决定照着做。

一周后，Austin 构建了两个从根本上改变他工作方式的工作流：一个一键生成广告素材变体的 Figma 插件，以及一个 Google Ads 文案工作流——它帮他头脑风暴、打磨广告文案，再导出为可直接上传的 CSV 文件。过去每条广告要花 30 分钟，现在只需 30 秒。

下面是他做到的过程，以及其他营销人员可以从他用 Claude Code 的经历中学到什么。

## **问题：被文案与素材变体淹没**

规模化做效果营销，意味着要持续产出新鲜的创意素材。仅 Google 的自适应搜索广告一项，就要求 15 条各不相同的标题。每隔几周，这些文案就需要刷新——同时还要保持品牌语调、传达价值主张。

“难的地方在于，当你在这种量级上运营时，文案需要极其频繁地刷新，”Austin 解释道。“而 Google 对文案的要求因为严格的字符数限制，灵活性更低。”

旧流程是这样的：打开 Google Sheets，头脑风暴标题和描述，手动核对字符数，复制粘贴到 Google Ads，然后重复。

视觉广告的流程更繁琐。Austin 要打开 Figma，把现有画框复制多次，切到 Google Doc 取标题文案，再切回 Figma 粘贴，然后重复——十个以上变体、多种宽高比，全都如此。

“这些时间加起来非常、非常快，”Austin 说。

## **解法：两个消灭营销杂活的工作流**

借助 Claude，Austin 最终建起了两个改变日常工作的流程。但 Austin 的第一个项目，其实是做一个简单的计算器应用。

“我让 Claude 做的第一件事，就是给我做一个非常简单的计算器应用，纯粹想看看它会怎么回应，”他回忆道。“Claude 基本上帮我把后端、还有一个很简陋的前端都做出来了。然后它告诉我，‘你实际该怎么运行它。’”

这个小实验改变了他对自己在工作任务中能达成什么的看法。

### **用于生成创意变体的 Figma 插件**

制作广告变体意味着无休止的复制、粘贴，以及在 Figma 和 Google Docs 之间来回切换。

于是 Austin 用 Claude Code 构建了一个 Figma 插件。这个项目花了大约 45 分钟到 1 小时，但如今每次跨多个宽高比更新一大批素材时，能为他省下近 30 分钟。

开始时，他打开 Claude Code，用一句提示词描述自己的问题：“Claude，我在 Figma 里工作。我真的很想解决这种重复复制粘贴的难题。你能帮我构建一个 Figma 插件来解决这个问题吗？”

Claude 去做了调研，评估怎样构建插件最合适、有哪些限制，然后开始做原型。经过一些排错后，Austin 在 Figma 里装上了一个能用的插件。

![](https://assets.claude.com/8fcd4943e754755157c55f1a059597756373119a.png)

Austin 的插件让他可以从 Google Sheet 粘贴标题文案，并一键生成几十个广告变体。

“我只需要指定素材的画框，然后一次性把我想更新的所有变体和文案复制粘贴进去，点一下按钮，Figma 插件就会为这张图生成所有不同的排列组合，”Austin 解释道。

### **Google Ads 文案生成**

针对自适应搜索广告，Austin 构建了一个工作流：借助现有广告系列与广告效果数据，帮助头脑风暴并生成可直接上传的广告文案，从而了解哪类信息更能打动潜在客户。这个工作流每周在文案创作和字符校验上为他省下数小时。机械性任务省下的时间，让他如今能跑更多文案实验，更快地针对真正效果最好的方向迭代。

使用时，他在 Claude 里输入 `/rsa`——这是他为自适应搜索广告创建的自定义斜杠命令。Claude Code 会询问广告系列数据、现有文案和关键词，然后把他的输入与他为 Anthropic 品牌语调与文风、产品信息准确性、Google Ads RSA 最佳实践创建的 [Agent Skills](https://claude.com/resources/articles/skills) 交叉比对。

但输出只是一个起点。

“Claude 是很棒的头脑风暴伙伴，但有时它第一次并不能做对，”Austin 解释道。“我的很多工作就是来回打磨、反复推敲，帮助文案逐步精炼。”

这种打磨很重要，因为 Austin 要拿每一条标题去对照他所了解的、能打动 Anthropic 受众的东西。价值主张传达出去了吗？语气对吗？在竞品中够突出吗？文案感觉对了之后，Claude Code 会把所有内容汇总成一个可直接上传的 CSV 文件。

而这一切都建立在人的基础之上。“我们提供给 Claude 的所有文案和示例，都是与产品营销和文案团队共同撰写的，”Austin 说。这个扎实的起点意味着，在 Claude 开始头脑风暴之前，人的判断已经嵌入其中。

![](https://assets.claude.com/d18dbdc9038dfaa0e2f44d3edab18218729ff229.png)

该工作流会把相关的广告系列与广告组列，以及每条广告的 15 条标题和 4 条描述导出为 CSV 文件，经人工审核后可直接上传到 Google Ads。

## **构建自己的工作流的最佳实践**

Austin 的经历为营销人员——或者说任何没有技术背景、想用 Claude Code 构建定制工具的人——提供了实用指引。

**从小的、重复的步骤开始**

“我的建议是：如果你想试试 Claude Code 这类工具，就先想一想，你的工作里有哪些部分是你已经识别出来的重复性工作，或者你觉得可以自动化的，然后从一个非常、非常简单的小东西开始，”Austin 解释道。

比如，Austin 的第一个项目就是做一个计算器应用，先看看 Claude 是怎么工作的。

**让好奇心驱动你的工作**

Austin 形容自己是“那种一旦对某件事非常好奇，就会较真到近乎固执、非要找到答案的人”。正是这种坚持，把一个他不知如何操作的空白终端，变成了他每天都在用的可用工具。

**像向同事解释问题那样和 Claude 交流**

“你不需要会写代码。你只需要知道如何把面临的挑战、以及你想解决什么，用非常清晰简洁的方式说明白，”Austin 说。

非技术员工本来就是各自领域的主题专家。他们了解自己的工作流，能感受到摩擦点，也清楚自己需要什么样的输出。Claude Code 让他们有能力自行解决任何反复出现的技术问题。

**基于已有资源来构建**

做 Figma 插件时，Austin 把 Claude Code 指向现有的 Figma API 文档。Claude 借助这些文档自行调研，并构建了一个原型供 Austin 试验。一个勉强能跑的原型，已足以验证 Austin 心中的概念，最终演化成一个可用的产品。

**更大的图景**

在职业生涯的大部分时间里，Austin 都认为某些事情遥不可及。如果需要装一个跟踪像素，他得请工程师来装。如果需要构建一个定制工作流，他得向支持团队提交工单。

“几年前，如果你有个想法要构建这样的工作流，大概需要一队工程师来支持你，”Austin 说。“现在，有了 Claude Code 这样的工具，作为一个非技术营销人，我真的可以自己去把这些东西建出来。所以，‘我希望有这个东西’和‘我能自己把它建出来’之间的差距，其实比大家以为的小得多。”

他如今已向同事和客户演示过自己的工作流，大家的反应都一样：为什么*我们*还没做这个？

## **营销人员的下一步**

Austin 认为增长营销这一角色正在快速演变。“我觉得增长营销正在变得有点像产品经理，”Austin 说。“我们不仅能执行广告系列，还能真正构建产品来帮助我们达成目标。”

Austin 并不是 Anthropic 唯一用 Claude 做构建的营销人。在整个营销组织里，各团队都在取得类似成果：

* **达人营销**用 Claude 为达人和播客撰写脚本，每月释放 100 多个小时用于更高价值的工作
* **客户营销**用 30 分钟而非 2.5 小时起草客户案例，每周节省 10 小时
* **数字营销**构建了 Web 开发工作流，使团队生产力同比提升 5 倍
* **产品营销**用 Skills 和 Projects 制作发布简报，每次发布节省 5-10 小时
* **合作伙伴营销**为销售团队构建了自助式活动支持，把展会筹备时间减少 40%

“大多数营销人对待 AI 的方式可能都差不多：只把它看成帮助简化写文案、头脑风暴之类工作的工具，”Austin 说。“但他们还没有真正想清楚，哪些实际环节才是他们能真正把 Claude 这类工具嵌入工作流的地方。”

对于采用 Claude Code 这类工具的团队来说，一个机会正在形成：把更少时间花在重复性执行上，把更多时间花在对工作真正重要的事情上。
