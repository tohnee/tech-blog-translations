# Claude 与你的生产力平台

> 原文：[Claude and your productivity platforms](https://claude.com/resources/articles/productivity-platforms) · Claude 博客

Claude 现已与 Microsoft 365 集成，并在你已连接的工具中提供企业搜索。

Claude 与你每天使用的生产力工具协同工作，把来自文档、邮件和日历的上下文直接带入对话。少花时间搜集信息，把更多时间用在驱动影响力的决策和工作上。

## 面向 Claude 的 Microsoft 365 连接器

使用我们的 MCP 连接器把 Claude 与 Microsoft 365 连接起来。通过访问你的文档、沟通记录和日历，Claude 获得更有效协作所需的上下文——帮你梳理复杂问题、做出明智决策，并更快采取行动。

Claude 支持：

- **Microsoft SharePoint 和 OneDrive**：跨站点和文档库搜索并分析文档，从项目规格到战略规划，无需手动把文件上传到 Claude。
- **Microsoft Outlook**：访问邮件线程、分析沟通模式，并从往来邮件中提取洞察，以了解项目状态、客户反馈或团队共识。
- **Microsoft Teams：**在聊天会话、频道讨论和会议纪要中搜索，找出决策、跟踪项目进展，并了解团队一直在讨论什么。

## 企业搜索

![展示多种已连接应用图标的工作流示意图](https://assets.claude.com/1097542eb1cafd7ad79c95f302686bf5733a40c4.png)

我们也在让公司知识的获取更容易：通过一个以你公司名称做个性化的专用共享项目。该项目包含自定义提示词，帮助 Claude 在你公司的各类工具中高效搜索，并提供连接核心工作应用的简单设置步骤。管理员完成设置并连接你的核心工具后，组织内所有人都会自动获得该项目的访问权限。

当你向 Claude 提问时，它可以在一个地方搜索你公司已连接的所有数据源，因此你得到的答案来自组织的集体知识，而不只是你自己的文件。例如，向 Claude 询问公司的远程办公政策，它会从 SharePoint 中的人力资源文档、Outlook 中的邮件讨论以及各处的团队指南中汇集信息，给出一份详细的报告。

企业搜索在新成员入职、回答诸如分析客户反馈模式这类战略性问题，以及快速找到就任何主题应当咨询的内部专家方面，尤其有价值。

## 开始使用

Microsoft 365 连接器现已面向所有 Claude Team 和 Enterprise 套餐客户提供。管理员必须先为其组织启用该连接器，个人用户才能使用自己的账户完成认证。

企业搜索已向所有 Team 和 Enterprise 组织启用。在团队使用之前，管理员需要先定制该项目，并为其组织挑选数据源。
