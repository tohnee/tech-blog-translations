# JPMorganChase 将 Claude Code 推广至公司更多员工

> 原文：[JPMorganChase expands Claude Code to more employees across the firm](https://claude.com/resources/articles/jpmorganchase-expands-claude-code) · Claude 博客

JPMorganChase 正在全公司推广 Claude，覆盖工程师之外的更多员工。在商业与投资银行（Commercial and Investment Bank）部门，工作更快进入生产环境，公司则把这部分释放出的产能重新投入到业务优先事项上。

各团队正[对更多遗留系统进行现代化改造](https://claude.com/resources/articles/how-to-prepare-for-ai-driven-code-modernization-projects)，工程师们则在构建自己的智能体，包括拉取请求审查智能体和自愈智能体，并分享行之有效的做法。

基础设施与运营团队使用 [Claude Code](https://claude.com/product/claude-code)（在新标签页中打开）进行监控、告警和根因分析。公司的安全团队使用我们的前沿模型更快地发现并修复漏洞——这项工作我们最初在 [Project Glasswing](https://www.anthropic.com/glasswing)（在新标签页中打开）中介绍过。

## **触达产品团队与顾问**

离业务最近的人也在用 Claude 构建。产品团队把需求直接转化为工程待办清单，其他团队则用 Claude Code 做风险与控制评估以及项目规划。

知识类工作也已展开。产品开发生命周期中有很大一部分发生在代码之外：调研、需求、设计和规划。

在其资产与财富管理（Asset & Wealth Management）业务中，JPMorganChase 把拥有最深业务洞见和最大胆想法的人，与技术和产品专家一起编入小而自主的团队。这帮助他们更容易地大规模构建并交付定制化的客户投资解决方案。Claude Code 现已成为其工程工作流的一部分，团队推进得更快，同时每一项变更在交付到客户手中之前都要经过更严格的测试。

上个月，J.P. Morgan Asset Management 宣布推出一款连接器，将 55ip 的 ActiveTax Technology® 引入 [Claude for Financial Advisors](https://claude.com/resources/articles/claude-for-financial-advisors)（在新标签页中打开），把税务感知的投资组合迁移分析带入顾问的日常工作。

## **为受监管公司而构建**

Claude Code 在受控环境中运行，包括公司自建的容器化开发平台 Devspace，运行在自有基础设施上。其目的是防止智能体直接访问员工凭据或内部系统。访问权限分阶段放开，新的 Claude 模型在任何人可以使用之前，都要先通过公司自己的审批流程。

代码的发布遵循同样的纪律。数千项自动化测试和审批关卡检查每一项变更，自动化关卡给出硬性的通过或停止结论，并由流水线强制执行，因此 Claude 无法为自己的工作签字放行。每一次生产变更仍有明确的人类责任人。

过去一年，JPMorganChase 对 Claude 的使用已从软件工程扩展到网络防御，再到面向财务顾问的工具；而 JPMorganChase 对我们的要求，正在塑造我们为其他受监管机构构建的产品。让 Claude 在全球最大金融机构之一的管控之内运行，正是我们努力的方向。
