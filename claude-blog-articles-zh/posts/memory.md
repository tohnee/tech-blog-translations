# 为团队带来记忆功能

> 原文：[Bringing memory to teams](https://claude.com/blog/memory/) · Claude 博客

***更新：**扩展至 Pro 和 Max 套餐（2025 年 10 月 23 日）*

***记忆功能现正陆续向 Pro 和 Max 套餐用户推出***

无论你是在迭代一份战略提案、调试一个问题，还是同时管理多个项目，Claude 都能从你上次停下的地方继续。与 Team 和 Enterprise 用户一样，你将获得项目级记忆（每个项目都有各自独立的记忆）、查看和编辑 Claude 记住了什么的完全控制权，以及不会保存到记忆的隐身聊天。在此次推出之前，我们围绕敏感的身心健康相关话题和各种边界情况开展了大量安全测试——包括记忆是否会强化对话中的有害模式、导致过度迎合，以及是否可能被用来绕过我们的安全防护。通过这些测试，我们找出了 Claude 的回复需要打磨的地方，并对记忆功能的运作方式做了针对性调整。这些迭代帮助我们在构建和改进记忆功能的同时，确保 Claude 能为用户提供有益且安全的回复。要开始使用，请在「设置」中启用记忆功能。

今天，我们为 Claude 应用推出记忆功能：Claude 会记住你和团队的项目与偏好，让你不必反复解释背景，复杂的工作得以持续推进。

记忆功能是*完全可选的*，配有细粒度的用户控制，帮助你管理 Claude 记住的内容。我们同时推出隐身聊天（Incognito chats），这类对话不会出现在你的对话历史中，也不会保存到记忆。

记忆功能从今天起陆续向 Team 和 Enterprise 套餐用户推出。Enterprise 管理员可以随时选择为整个组织停用记忆功能。隐身聊天面向所有 Claude 用户开放。

### 为工作而生的记忆

借助记忆功能，Claude 专注于学习你的职业背景和工作模式，以最大化生产力。它记得团队的流程、客户需求、项目细节和优先级。销售团队在多个交易之间保持客户背景，产品团队在多个冲刺之间维护规格说明，高管追踪各项计划而无需反复重建背景。

如果你使用项目功能，**Claude 会为每个项目创建独立的记忆**。这确保你的产品发布规划与客户工作相互独立，机密讨论与日常运营互不混杂。这些项目边界帮助你与你的团队管理复杂的多线并进事务，避免无关细节互相掺杂，同时充当一道安全防护栏，把敏感对话隔离在各自的范围内。

Claude 使用一份记忆摘要把所有记忆集中在一处，供你查看和编辑。在设置中，你可以确切看到 Claude 从你的对话中记住了什么，并随时通过与 Claude 聊天来更新这份摘要。根据你告诉 Claude 要关注什么、忽略什么，Claude 会调整它所引用的记忆。

### 隐身聊天

有时你需要 Claude 的帮助，却不想使用记忆，也不想把内容写入记忆。隐身聊天为你提供一个干净的起点，适合那些你不想保存在记忆中的对话。它非常适合敏感的头脑风暴、机密的战略讨论，或者你只是想要一场不带此前对话背景的全新交流。你的常规记忆和对话历史保持原样、不受影响。如果你在 Team 或 Enterprise 套餐上使用记忆功能，你标准的数据保留设置同样适用于此。

### 从工作团队场景起步

记忆功能带来了新的安全考量，我们把这一功能设计得在工作场景中实用，同时避开敏感对话与话题。我们也在采取审慎的分阶段推进方式，确保这些强大的能力得到负责任的部署，并在扩大可用范围之前，继续评估和测试记忆功能在人们使用 Claude 的不同方式中的表现。

### 开始使用

要看看记忆功能的实际效果，请在「设置」中启用该功能，并在初始设置时让 Claude 根据你过往的对话生成记忆。你可以问 Claude「我们上周在做什么？」，看看 Claude 对你已有的聊天和已连接的工具记住了什么。如果你想从其他 AI 工具导入记忆细节，或者把你的记忆从 Claude 导出以备份或迁移，可以[按照这些说明操作](https://support.anthropic.com/en/articles/12123587-importing-and-exporting-your-memory-from-claude)。

伟大的工作随时间累积而成。有了记忆功能，与 Claude 的每一次对话都会让下一次变得更好。
