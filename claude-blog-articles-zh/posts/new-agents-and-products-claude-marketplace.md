# Claude Marketplace 上新：面向安全、生产力与创意工作的智能体与产品

> 原文：[New agents and products for security, productivity, and creative work on Claude Marketplace](https://claude.com/resources/articles/new-agents-and-products-claude-marketplace) · Claude 博客

我们为 [Claude Marketplace](https://claude.com/marketplace) 新增了一批智能体和产品。Claude Marketplace 是团队寻找合作伙伴工具与服务、从而更充分利用 Claude 的地方。此次新增覆盖安全、开发者基础设施、创意和生产力领域。

符合条件的企业客户可以[将其在 Anthropic 的承诺用量（committed spend）的一部分用于这些解决方案](https://claude.com/resources/articles/how-coderabbit-power-digital-and-thoughtspot-scale-with-snowflake-and-vercel-on-claude-marketplace)。这样他们就能用同一份承诺覆盖 Claude 和合作伙伴产品，无论是购买新东西，还是扩展现有平台。

目前市场上已有 25 个以上的合作伙伴智能体和产品。以下是最近的更新，以及团队可以用它们做什么。

## **用于保护代码与系统的产品与智能体**

**[Chainguard](https://claude.com/marketplace/agents-products/chainguard)：**Chainguard Harness 在隔离的 microVM 中从源码构建应用，并探测运行中的应用是否存在可被利用的漏洞。它帮助团队修复 Claude 发现的问题，并针对可复现的漏洞提供定制的修复建议。

**[Checkmarx](https://claude.com/marketplace/agents-products/checkmarx)：**Checkmarx One 将基于规则的分析与 AI 推理结合，发现代码中的漏洞，帮助团队对发现的问题排定优先级，并在代码交付前修复。

**[Cyera](https://claude.com/marketplace/agents-products/cyera)：**Cyera Agent Guardian 清点 Claude 部署资产，在 Claude 运行前治理权限，并对提示词、文件和工具调用执行策略。它帮助团队通过红队演练测试这些控制措施。

**[Rubrik](https://claude.com/marketplace/agents-products/rubrik)：**Rubrik Code Guardian 使用 Anthropic 的前沿 AI 模型，审查 GitHub 或 Azure DevOps 仓库的安全副本，查找多步攻击路径。它帮助安全和工程团队按严重程度对问题排序，并将确认的关键问题转化为可跟踪的工单。

**[Tanium](https://claude.com/marketplace/agents-products/tanium)：**Tanium Cloud 为团队提供对全部终端的实时可见性和控制。它帮助 IT 和安全团队发现并修复漏洞、错误配置和缺失的补丁。

## **面向工程团队的开发基础设施**

**[Datadog](https://claude.com/marketplace/agents-products/datadog-agent-observability)：**Datadog Agent Observability 追踪智能体经工具和服务的执行过程，通过呈现生产环境中的模式并建议修复方案，帮助团队提升智能体质量、性能和成本效率。

**[Netlify](https://claude.com/marketplace/agents-products/netlify)：**Netlify Enterprise 将应用、站点和智能体部署到全球边缘网络，每次变更都会生成预览 URL。它帮助团队把用 Claude 构建的东西从原型推进到生产，无需配置任何基础设施，并包含 SSO、基于角色的访问和审计日志。

## **营销与创意工作工具**

**[AirOps](https://claude.com/marketplace/agents-products/airops)：**AirOps 提供一个智能体平台，用于 AI 搜索策略、内容和多渠道执行，帮助营销团队分析品牌在 AI 搜索中的表现，并把结果与销售管线和收入挂钩。

**[Runway](https://claude.com/marketplace/agents-products/runway)：**Runway 可生成和编辑视频、图像和音频，帮助创意与营销团队把简报变成成品素材，并用自然语言剪辑素材。

**[Webflow](https://claude.com/marketplace/agents-products/webflow)：**Webflow 提供内建工具来构建、管理和优化网站，帮助营销人员、设计师、开发者和智能体进行改动，控制与治理能力内建其中。

## **面向各团队的生产力应用**

[**Asana**](https://claude.com/marketplace/agents-products/asana)：Asana AI Teammates 是预构建的智能体，利用 Asana Work Graph 中的上下文，每个都有自己的身份、作用域权限和审计追踪。它们帮助团队处理多步工作，并把需要判断的决策转交给负责人。

**[Glean](https://claude.com/marketplace/agents-products/glean)：**Glean 跨系统连接公司知识与工作流，帮助员工在已连接的应用中找到答案并完成多步任务。

**[monday](https://claude.com/marketplace/agents-products/monday)：**monday 的智能体在项目、看板、文档和会议中工作，以负责人和截止日期作为上下文。它们帮助 PMO、IT、市场、财务和运营团队控制 AI 可以访问、批准和花费什么。

[**Zoom：**](https://claude.com/marketplace/agents-products/zoom)Zoom Agentic Search 在 Claude 内利用最新的会议摘要、工作对话、文档以及已连接的第三方来源回答问题。团队无需分析原始转录文本或串联多个工具，就能获得符合权限的结果。
