# 在语音模式中想清楚难题

> 原文：[Think through hard problems in voice mode](https://claude.com/resources/articles/think-through-hard-problems-in-voice-mode) · Claude 博客

从今天起，语音模式运行在 Claude Opus、Claude Sonnet 和 Claude Haiku 之上，可以调用你已连接的 Gmail、Slack 等工具，并支持更多语言。

![](https://assets.claude.com/30378eeef4acaf8767584682acb830aceb120214.png)

有些问题是没法靠打字想清楚的。语音模式适合为一场重要的提案会议做演练、在多个 offer 之间做选择、大声复盘自己的流程，或者头脑风暴新想法。

## **跟得上你思路的讨论搭档**

今年早些时候我们加入免手操作对话后，人们开始把语音模式用于快速提问之外的事情。他们开始在更长的会话中、用语音而非文字来梳理真实的业务问题。但在此之前，语音模式只运行在我们的 Claude Haiku 模型上，选择它是为了速度。它让对话保持快捷，但不总能做到深入。

Claude Opus 和 Sonnet 这两个专为攻克难题而设计的模型，现在已可用于语音模式。你可以在对话中途通过模型选择器切换模型。语音模式会使用你所选模型中最快的版本，让对话流畅进行。它默认使用你上次在文字聊天中使用的模型，因此你可以在语音和文字之间切换，而无需从头开始。

![](https://assets.claude.com/865b630abe138d5d9e340d021d081ee2f07f7292.png)

有了更强的模型，你可以把一个尚未成形的想法说出来，并想清楚自己真正怎么想。Claude 会追问，并在你的思路上继续推进，而不是直接甩给你一个答案。语音模式是轮流进行的，也就是说 Claude 会先听、暂停思考，然后再回应。

可以试试这几件事：

* 为一场重要的对话做演练，让 Claude 就你的沟通风格给出反馈。
* 把面向客户的提案讲一遍，让 Claude 找出你逻辑中的漏洞。
* 为产品路线图头脑风暴想法，并让 Claude 用竞品调研来验证这些想法。
* 请 Claude 帮你评估关于上一条视频为何走红的几种不同假设。

## **从聊到做**

当你决定好要做什么之后，就让 Claude 去做。以下是你可以在自己的工具中完成的一些示例：

* 要迟到了？让 Claude 把 Google 日历上的一场会议推迟 30 分钟。
* 把一段关于客户提案的对话变成 Canva 里的一页纸方案。
* 让 Claude 总结你今天收到的邮件，并为最关键的那几封起草回复。

![](https://assets.claude.com/aa6f885466e845c2e438a48e8f4002558619ab67.png)

在使用你已连接的某个工具之前，Claude 会先请求许可。你可以在 Claude 移动端、桌面端或 Web 应用的 Settings > Connectors 中连接新工具。

## **用更多语言对话**

现在所有套餐的语音模式都支持更多语言，你可以用自己思考时所用的语言与 Claude 交谈，并可在对话中途切换。可选语言包括：

* 英语
* 法语
* 德语
* 印地语
* 印尼语
* 意大利语
* 日语
* 韩语
* 葡萄牙语（巴西）
* 西班牙语（拉丁美洲）
* 西班牙语（西班牙）

直接对 Claude 说出要把英语切换成你想要的语言，或者在语音设置的语言选择器中选择你的语言。

![](https://assets.claude.com/f8e24ddaa5683961cc283b79d5b0c33475cda524.png)

Claude 不会自动检测你的语言，所以你需要口头提出，或自行选择语言，才能从英语切换过去。你需要专门为语音模式设置语言，因为之前的语言设置不会沿用过来。

## **开始使用**

语音模式的最新更新以 beta 形式向移动端、桌面端和 Web 的所有聊天用户开放，但在手机上体验最佳。在 Free 套餐中，你可以使用 Claude Haiku、一个已连接的工具，以及所有可用语言。付费套餐可以使用更多模型和你连接的全部工具。语音对话会占用你常规的用量额度。

在 Claude 移动应用中点击声波图标即可试用语音模式，或[下载应用](https://claude.com/download)开始使用。
