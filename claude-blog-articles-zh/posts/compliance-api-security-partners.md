# Claude 现已接入更多安全与合规工具

> 原文：[Claude now works with more security and compliance tools](https://claude.com/resources/articles/compliance-api-security-partners) · Claude 博客

***更新**：我们已扩展到 100 多家安全与合规合作伙伴集成，完整列表见[帮助中心](https://support.claude.com/en/articles/15167101-get-started-with-claude-compliance-api-integrations)。*

今天我们推出与知名安全与合规工具的 28 项集成。现在，IT 与安全团队可以在我们的平台和整套产品中治理 Claude，就像他们治理技术栈中其他应用的方式一样。

## 工作原理

这些新集成全部由 Claude Compliance API 驱动，它为企业安全与合规团队提供对两类数据的程序化访问：

* **来自 Claude Enterprise 的对话内容**——包括聊天、上传的文件和项目——使管理团队能够把已用于其他办公应用的同一套安全、监控和 DLP 策略应用到 Claude 上。
* **跨 Claude Enterprise 和 Claude Platform 的活动事件**——用户登录、管理员操作和配置变更——让安全团队获得关于 Claude 在全组织内使用情况的统一视图。

## Claude Compliance API 集成

现已有 100 多家安全与合规提供商提供集成，覆盖企业所依赖的各类别——包括 DLP、SASE、数据安全、SIEM 与安全运营、身份、eDiscovery、AI 安全态势管理，以及 AI 可观测性与遥测基础设施。

**对于 Claude 客户：** 要将你的 Claude 实例连接到受支持的合作伙伴平台，请访问我们的[帮助中心](https://support.claude.com/en/articles/15167101-get-started-with-claude-compliance-api-integrations)，并查阅 [Claude Enterprise](https://support.claude.com/en/articles/13015708-access-the-compliance-api) 和 [Claude Platform](https://platform.claude.com/docs/en/manage-claude/compliance-api) 的 Compliance API 文档。

**对于安全合作伙伴：** 如果你是一家已构建 Compliance API 集成的安全、合规或 IT 平台，请[在此申请](https://forms.gle/1rkBcdwwR5bLLD82A)加入该网络。
