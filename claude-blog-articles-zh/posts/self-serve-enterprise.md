# Claude Enterprise 现已支持自助购买

> 原文：[Claude Enterprise, now available self-serve](https://claude.com/resources/articles/self-serve-enterprise) · Claude 博客

从今天起，任何组织都可以直接在我们的[网站](http://claude.ai/create/enterprise)上购买 Claude Enterprise，无需与销售团队沟通。几分钟内即可设置工作区、配置 SSO 并开始邀请团队成员。

## Claude Enterprise

Claude Enterprise 让整个组织都能使用 [Claude](https://claude.com/product/overview)、[Claude Code](https://claude.com/product/claude-code) 和 [Cowork](https://claude.com/product/cowork)，同时提供企业级安全能力，并支持处理大型代码库、大量文档以及广泛的组织上下文。

你的团队可以与 Claude 一起头脑风暴，从 web 和终端分派编码任务，或把复杂的多步骤项目交出去并收获完成的交付物。借助 Cowork [使用插件](https://claude.com/resources/articles/cowork-plugins)，你可以把 Claude 变成销售、财务、法务、营销等领域的专家。

Claude 还能与你团队已在使用的工具协作。通过[连接器](https://claude.com/connectors)连接 Microsoft 365、Slack 及其他平台，或通过内置的聊天侧边栏直接在 [Excel](https://claude.com/claude-in-excel) 和 [PowerPoint](https://claude.com/claude-in-powerpoint) 中与 Claude 协作。

Claude Enterprise 包含组织大规模部署 AI 所需的安全与管理控制：

* 通过单点登录（SSO）和域名捕获管理用户访问，并通过 SCIM 自动化账号开通。
* 审计日志和 Compliance API 让安全与合规团队了解 Claude 的使用情况，管理员可以管理整个组织的权限。
* 管理员可以设置自定义的数据保留策略，并通过用量分析跟踪团队活动、功能采用情况和支出。
* 默认情况下，Anthropic 不会使用 Claude Enterprise 的内容训练模型。

## 定价

Claude Enterprise 采用简单的“席位 + 用量”模式。用量按 API 价格计费，因此你的组织只需为实际使用的部分付费。管理员可以在组织和个人用户两个层级设置支出上限，从而可靠地控制成本。
