# Claude 网页搜索现已面向所有计划全球开放

> 原文：[Claude web search now available globally on all plans](https://claude.com/blog/web-search/) · Claude 博客

***更新：****网页搜索（web search）现已面向所有 Claude 计划全球开放。（2025 年 5 月 27 日）*

你现在可以使用 Claude 搜索互联网，从而获得更及时、更相关的回答。借助网页搜索，Claude 可以获取最新的事件和信息，提升其在受益于最新数据的任务上的准确性。

当 Claude 将来自网络的信息融入回答时，它会提供直接引用，方便你对来源进行事实核查。你不必自己翻找搜索结果，Claude 会以对话的形式处理并给出相关来源。这一增强用实时洞察拓展了 Claude 庞大的知识库，让回答建立在更新的信息之上。

结合网页搜索使用 Claude 的常见方式：

- **销售团队**可以通过分析行业趋势来了解关键举措和痛点，从而在与潜在客户的知情对话中转变客户规划方式，赢得更高的赢单率。
- **金融分析师**可以评估当前市场数据、财报和行业趋势，做出更好的投资决策，并为财务模型的假设提供依据。
- **研究人员**可以通过检索网络上的原始文献，撰写更有力的科研经费申请书和文献综述，发现新兴趋势并找出当前文献的空白。
- **购物者**可以跨多个来源比较产品特性、价格和评论，做出更有依据的购买决策。

## 开始使用

网页搜索目前以功能预览（feature preview）的形式，面向美国的所有 Claude 付费用户开放。对免费计划用户和更多国家的支持即将推出。要开始使用，请在你的[个人资料设置](https://claude.ai/redirect/website.v1.511b92f9-8255-4545-abf4-9817c96cb7d2/settings/profile#feature-preview)中开启网页搜索，然后与 Claude 3.7 Sonnet 开始对话。在适用的情况下，Claude 会搜索网络来辅助回答。
