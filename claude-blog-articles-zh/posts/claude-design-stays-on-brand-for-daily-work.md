# Claude Design 现在让日常工作也始终贴合品牌

> 原文：[Claude Design now stays on brand for daily work](https://claude.com/resources/articles/claude-design-stays-on-brand-for-daily-work) · Claude 博客

*2026 年 9 月更新：Claude Design 现在可以在任何与 Claude 的对话中使用，包括 Claude Code 和 Artifacts 标签页，付费方案用户可用 beta 版。幻灯片演示文稿在 Claude Slides 中有自己的起点。详情见[发布文章](https://claude.com/resources/articles/cowork-is-now-claude)。*

![](https://assets.claude.com/26fe4b872e9039c8736c215fcc8d33a8c933961f.webp)

[Claude Design](https://claude.com/product/design) 现在可以跨项目遵循你的设计系统，与 Claude Code 流畅协作，允许你直接在画布上编辑，并连接更多你已经在用的工具。它在 Claude 桌面应用的侧边栏中有了新位置；https://claude.com/product/design

我们的目标一如既往：让你探索比截止日期通常允许的更多方向，并让交接到打磨或构建环节的过程尽可能顺畅。这个目标现在服务于更多的人。上线第一周就有超过一百万人使用了 Claude Design，你们的反馈正在塑造我们接下来的产品方向。

## 用你的设计系统组件来构建

我们重建了设计系统导入功能，让它更灵活、更精确。你可以从 GitHub 仓库、设计文件或直接上传的方式导入一个或多个设计系统。Claude 会用你的组件进行构建，将输出与你的设计系统比对，并在呈现给你之前完成修正。对更大的团队，新增的管理员角色可以批准一套标准系统并锁定编辑，确保产出始终符合公司规范。

## 在设计稿与代码之间切换

现在，在 Claude Design 与 Claude Code 之间切换、同时保持工作同步变得更加容易。使用 /design-sync 拉取你的设计系统，这样你在 Claude Design 中构建的一切都从既有组件出发。当设计稿可以转化为软件时，你可以把它交给 Claude Code——它会从你已有的工作继续，而不是从一张截图重新开始。

更喜欢从 Claude Code 开始？在桌面端或终端会话里直接要一个设计，或用 /design 创建、编辑、同步设计项目。把设计稿导入代码库，把代码变成可交互的原型，或者让 Claude 把一个项目一路推进到底。

> “Claude Design 把前沿模型的智能，与久经验证的设计工具的功能和能力结合在了一起。无论是为 Tenex 的网站做设计方向、制作新的品牌素材还是准备演示文稿，我第一个去的地方都是 Claude Design。易用的 UX 加上出色的品味和设计直觉，正是它成为我技术栈核心部分的原因。而 Claude Design 与 Claude Code 之间的交接，让从原型到生产的过程变得无缝。”
> —— Alex Lieberman，Morning Brew 与 Tenex 联合创始人

## 日常使用更稳定

全新的编辑器让你可以直接、细粒度地控制设计中的每一个元素。新增的丰富布局控件让你可以拖拽、缩放和对齐元素。数百项稳定性修复让编辑器经得起真实使用的考验。

Claude Design 现在还与你在 Claude 上的其他工作（包括 Claude Code）共享用量上限，因此大多数人会获得更多的创作余量，触及上限的情况也会更少。

## 从画布到你使用的工具

可靠地导出为 PDF、PowerPoint 或 HTML，或者把作品发送到你已经在用的应用——连接器列表包括 Adobe、Base44、Canva、Gamma、Lovable、Miro、Replit、Vercel 和 Wix。

## 开始使用

Claude Design 在付费方案上以 beta 形式提供。它在 Pro、Max、Ultra 和 Team 方案中默认开启，在 Enterprise 中默认关闭——需要管理员在 Organization settings > Artifacts 中为整个组织或特定群组开启。在 Team 和 Enterprise 方案中，链接默认在组织内部共享。在任何与 Claude 的对话（包括 Claude Code）中要一个设计，从 Artifacts 标签页开始，或继续使用 [claude.ai/design](https://claude.ai/design)。导入你的设计系统，然后开始创作。没有灵感？为你的下一个落地页要三个方向，再挑出值得打磨的那个。
