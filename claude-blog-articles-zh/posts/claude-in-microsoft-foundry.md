# Microsoft Foundry 中的 Claude 现已正式可用

> 原文：[Claude in Microsoft Foundry is now generally available](https://claude.com/resources/articles/claude-in-microsoft-foundry) · Claude 博客

### **通过你的 Azure 账户使用 Claude 构建**

起步阶段，Claude Opus 4.8 与 Claude Haiku 4.5 已在 Messages API 中提供，并支持提示缓存（prompt caching）和扩展思考（extended thinking）等核心能力，覆盖从编码、智能体工作到复杂推理的各类用例。我们会持续扩展 Foundry 中可用的能力。

Microsoft Foundry 中的 Claude 是 Azure 原生的，可与现有的 Azure 身份、网络和治理控制配合使用。你会收到一张统一账单；对于符合条件、签订了 Microsoft 企业协议的客户，Claude 用量可抵扣 Microsoft Azure 承诺用量。

### **在 Azure 中运行 Claude，由 Anthropic 运营**

在 Microsoft Foundry 中运行 Claude 有两种方式。如果你看重在自有 Azure 环境中运行——具备 Azure 身份认证、计费、治理以及美国数据区——请选择*托管于 Azure*。如果你需要完整的 API 功能集，或需要尚未在 Azure 上提供的模型，请选择*托管于 Anthropic*（此前的 Foundry 预览版）。长期来看，我们的目标是让托管于 Azure 的方案与 Anthropic 托管的方案在功能和模型上保持一致。

### **开始使用**

Microsoft Foundry 中的 Claude 今日正式可用。要开始使用，请打开 [Microsoft Foundry 中的 Claude](https://learn.microsoft.com/en-us/azure/foundry/foundry-models/how-to/use-foundry-models-claude?tabs=python)，或查阅[文档](https://platform.claude.com/docs/en/build-with-claude/claude-in-microsoft-foundry)。
