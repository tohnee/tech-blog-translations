# Claude Cowork 与聊天现已合并为一个 Claude

> 原文：[Claude Cowork and chat are now one Claude](https://claude.com/resources/articles/cowork-is-now-claude) · Claude 博客

你不必再选择任务该放在哪里。Claude 承担更多工作。

从今天起，Claude Cowork 和聊天正在合并为一个 Claude。无论是随口一问，还是交出一份中午就要交的报告，Claude 都会接着做下去——即使你已经合上笔记本电脑。该功能将在未来几周向 Pro、Max 和 Ultra 套餐推出，后续还会有更多套餐跟进。

Claude 产出的内容也不需要各自占据一块地方。[Claude Docs 和 Claude Slides](https://claude.com/resources/articles/dashboards-and-motion)于今天推出，[Claude Design](https://claude.com/product/design)（在新标签页中打开）现在也能在你的对话中工作。要一份文档，你和 Claude 一起写；要一份演示文稿，Claude 起草幻灯片。你可以直接编辑、直接从 Claude 演示，或下载为 PowerPoint 或 PDF。这三项功能都在付费套餐上以 beta 形式提供，Enterprise 管理员可以选择何时开启。如果你单独使用 Claude Design，它仍像以前一样工作。

我们当初把 Cowork 打造成处理更大工作的独立空间，把 Design 打造成处理视觉工作的独立空间。人们两个都在用，并告诉我们，令人沮丧的是要判断一项任务到底属于哪里。而且在一个工具里开始的工作，也无法延续到另一个工具中。于是我们不再让你做选择。Claude 现在能判断一项任务需要什么，因此 Cowork 和 Design 能做的事，都可以在任何对话中使用，并带着你已有的上下文、技能和连接器。

> “我可以让 Claude 调出[我的法律研究数据库]，它会拉取所有案例、逐一阅读、判断我还可能需要哪些其他案例、下载它们，并存到一个文件夹里供我本人查阅。”

Andrew Keller，高级经济学家

## 实际体验

一份周报中午就要交。出门前，你问 Claude 上周销售管道里有哪些变化，然后补充：“照我们一贯的写法来写，标出任何延误的地方，并把要点做成五页幻灯片，供管理层会议使用。”如果有不清楚的地方，Claude 会问。你可以在去办公室的路上用手机查看进度。等你坐到工位时，报告已经以文档形式等着你，上面还有同事的批注；幻灯片也已就绪，可以打开、调整并下载为 PowerPoint。两者出自同一次对话，所以幻灯片已经与报告保持一致。你自己改了一行，在某一页幻灯片上给 Claude 留了条评论，然后分享出去。把它设为每周一执行，Claude 就会在无需提醒的情况下开始写报告。

你用 Claude Design、Slides 或 Docs 制作的任何内容，都存放在一个可分享的链接中，你可以在手机上打开它。你可以选中某个元素并移动它，或告诉 Claude 你想改什么。

你可以选择 Claude 与你同步的方式。默认情况下，Claude 在执行操作前会先询问。如果你更希望让 Claude 持续工作，只在某些事情需要细看时才找你确认，也可以开启该选项。最终决定权始终在你手上。

## 开始使用

如果你主要用聊天，不需要做任何改变。当你想交出更大块的工作时，不妨从下一份你本来要自己做的报告或演示文稿开始试试。如果你一直在 [Cowork 中工作](https://claude.com/resources/guides/claude-cowork-product-guide)，一切都在原来的位置：你的对话、项目、artifacts、连接器和技能。打开应用，就能接着上次的地方继续。

该功能将首先在 Pro、Max 和 Ultra 套餐推出，未来几周内在 Web、桌面端和移动端的 Claude 应用中向这些套餐的现有用户和新用户开放。无需开启任何设置。Team 和 Free 套餐很快跟进；对于 [Enterprise 管理员](https://claude.com/resources/webinars/unified-claude-what-it-means-for-admins)，在其组织发生任何变化之前，我们会至少提前 30 天通知。
