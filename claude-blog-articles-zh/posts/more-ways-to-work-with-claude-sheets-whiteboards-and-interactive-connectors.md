# 更多与 Claude 协作的方式：Sheets、Whiteboards 与交互式连接器

*以思维的速度工作*

我们亲眼见证 Claude Code 改变了开发者的工作方式。工程师从逐行手写代码，转变为描述想法、审阅 Claude 构建的产物，重新找回了创造的乐趣。我们的目标是把这份魔力带给每一个团队，今天我们正在拓展 Claude 所能创造的可能：推出新的产物（artifact）类型——**Claude Sheets**、**Claude Whiteboards** 和 **Claude Data**；通过**交互式连接器**的升级，让你在最常用的应用里工作得更顺手；**Claude Meetings** 也即将推出。

## 你所有的连接器与上下文

在 Claude Code 中，Claude 所需的上下文本就存在于代码库里。对其他团队而言，上下文则散落在邮件、各类应用和网盘之中。Claude 通过基于 [Model Context Protocol（在新标签页打开）](https://www.anthropic.com/news/model-context-protocol)（MCP）构建的连接器触达这些上下文——MCP 是我们为「把 AI 与你使用的工具连接起来」而推出的开放标准。[Claude Marketplace](https://claude.com/resources/articles/claude-marketplace) 收录了 9000 多个连接器与插件，其中也包括社区构建的。

[**交互式连接器（在新标签页打开）**](https://claude.com/resources/articles/interactive-connectors-full-tool) 更进一步。从今天起，合作伙伴可以把自家应用直接嵌入 Claude，让你无需切换标签页就能在 Adobe、Atlassian 等应用中工作。来自 [Salesforce](https://claude.com/resources/articles/salesforce-in-claude)（beta）、NetSuite 和 Workday（beta）的插件内置了技能（skills）：销售可以准备客户通话，会计可以分析财务数据，HR 团队可以处理休假与报销。

## 更快地共同把想法变为现实

从今天起，Claude 可以与你的团队一起构建电子表格、白板和仪表盘。它们与 Claude 现有的创建[文档、幻灯片和设计（在新标签页打开）](https://www.youtube.com/watch?v=To5nrYqvR44)的能力协同工作，也支持 [Claude Motion（在新标签页打开）](https://support.claude.com/en/articles/17454997-get-started-with-claude-motion)（beta）——它能把内容转化为短动画。在每一种场景里，Claude 都能迅速领会你的需求，让你的思路决定工作的节奏：

* [**新的产物类型（在新标签页打开）**](https://claude.com/resources/articles/sheets-whiteboards-data)：
  + 在 Claude Sheets 中，你的团队与 Claude 共同构建电子表格、协作整理数据、创建和编辑公式，并可跨多个工作表标签工作。
  + Claude Whiteboards 是一块数字白板，团队可以在会议中一起铺陈、梳理想法，随后让 Claude 总结讨论结果。
  + Claude Data（原 Dashboards）可连接 Snowflake、Salesforce 等工具，并能使用你数据团队认证的定义（beta）来创建仪表盘、可视化数据故事或带旁白的短视频。

你还可以让 Claude 按你团队的协作方式构建自定义产物，例如客户账户追踪表、每日简报、项目状态看板或合同审阅表。由于 Claude 在每一步都携带着同一份上下文，一个想法可以从白板延续到电子表格，再延续到仪表盘，无需反复重述细节。

即将推出的 **Claude Meetings** 让你能把 Claude 加入通话，由它记笔记，并在对话过程中更新团队正在处理的文档。

## 已经这样工作的团队

在 Anthropic 内部，非技术团队开始获得与工程师同等的 Claude 价值。我们的法务团队与 Claude 合作，构建了一个基于 Slack 的法律审阅工具，能依据团队自己的操作手册自动生成修订标记（redline）。这把市场物料的审阅从三天缩短到 24 小时，简单的修改在律师审阅草稿之前就已完成。我们的财务团队把一份冗长的高管业务更新文档变成了一张交互式页面，如今整个团队与 Claude 一起更新它。

这两个团队都不写代码，但都是各自领域的专家。他们用 Claude 把这份知识转化为节省时间、且他人也能使用的工具。我们的客户也在这样工作：

## 为企业而建，也与企业共建

随着 Claude 接入越来越多的工具，企业需要更好的方式来监管它的访问权限与行动。我们内建了安全与合规管控，帮助企业满足自身要求，同时也用同一个 Claude 处理我们自己最敏感的工作。在 Enterprise 套餐中，管理员可以决定谁能使用哪些产品和连接器，并能以细粒度方式为组织设定支出上限。

这种管控同样适用于 Claude 所连接的工具。借助 [**Claude auto-connect（在新标签页打开）**](https://support.claude.com/en/articles/15537633-auto-connect-your-organization-s-apps-to-claude)——目前已在符合条件的 Team 和 Enterprise 套餐中进入 beta——连接 Notion、Atlassian 或 Dropbox 这类应用只需一次性配置。此后员工第一次在 Claude 中使用该工具时即自动完成连接，而不必逐个连接。

无论工具以何种方式接入，Claude 都在你现有的权限范围内工作。管理员还可以限制每个连接器能做什么，例如 Claude 或许可以读取 Slack，但不能代表你发送消息。

保护敏感业务数据是我们构建产品的核心，随着 Claude 承担更长、更复杂的工作，我们也在持续加固这些保护：

* 来自企业组织的数据[在传输和静态存储时均加密（在新标签页打开）](https://claude.com/resources/articles/unified-claude-enterprise)。
* 在 Enterprise 套餐中，安全团队[可以查看 Claude 的使用情况（在新标签页打开）](https://support.claude.com/en/articles/15167101-get-started-with-claude-compliance-api-integrations)，途径包括审计日志，以及一个可与 100 多种安全与合规工具（含 Splunk 和 CrowdStrike）协作的 Compliance API。
* 在 Enterprise 版全新的 Claude 体验中，每个云端会话都运行在自己的[隔离虚拟机（在新标签页打开）](https://claude.com/resources/articles/unified-claude-enterprise)中，连接器凭据则保存在其外部。

## 与你的想法同步推进的工作

现代工作围绕软件来组织，而 Claude 围绕你运转。它通过你连接的工具了解团队的工作，帮你以所需的格式把想法变为现实，并在管理员设定的管控范围内运行。这样你就能腾出更多时间，专注推进那些大目标。
