# 将 Claude Code 和 Claude Cowork 带入政府领域

> 原文：[Bringing Claude Code and Claude Cowork to government](https://claude.com/resources/articles/bringing-claude-code-and-claude-cowork-to-government) · Claude 博客

[Claude Code](https://claude.com/product/claude-code) 和 [Claude Cowork](https://claude.com/product/cowork) 现已在 Claude for Government Desktop 中公开 beta，构建于我们商业客户使用的同一应用之上，并通过 FedRAMP High 授权环境交付。

借助 Claude Code，公共部门团队可以构建和现代化支撑公共服务的软件系统。Claude Cowork 直接处理桌面上的文件，让机构员工可以把备忘录撰写、RFP 审查、案件处理和演示文稿交给 Claude。

扩展后的体验还带来额外的治理能力。管理员可以设置配置默认值，并在各部门之间分配和控制支出。安全团队和授权官员可以获得防篡改的审计日志，以及支持机构 ATO 流程的文档。

今天的发布让各机构在履行使命时更容易采购、授权和分配 AI。

## 新增内容

**Claude Code 和 Claude Cowork。**各机构与我们商业用户以相同的节奏获得新能力。对话历史存储在机构管理的设备本地。推理在 FedRAMP High 授权环境中运行。

**契合拨款的计费方式。**项目办公室可以通过标准席位将 AI 支出与拨款资金挂钩，也可以定义带有支出和模型限制的自有席位层级；用量以固定增量购买，并设有硬性的不得超过上限。管理员可以在管理控制台按用户和按模型跟踪用量，自动消耗警报会在余额过低之前发出提醒。

**匹配部门组织方式的管理。**部门级管理员可以向子机构分配席位和预付用量，同时允许各子机构管理自己的用户。管理员可以使用 SCIM 组映射，为特定席位层级设置速率限制、美元上限和允许使用的模型。此外，分层配置为子机构设定默认值，包括 Claude 可以连接什么、哪些功能可用，以及指导 Claude 如何与用户交互的指令。

**内建于设计中的监督。**每一项管理操作都会记录在哈希链式审计日志中，组织管理员可以直接在产品内查看。Anthropic 一方的敏感操作需要双人批准。用量导出仅为计量数据，因此机构无需转移敏感材料即可回应 ATO 和 IG 的请求。

## 安全与监督

对于正在评估桌面部署的安全团队，我们公开发布《FedRAMP 安全配置指南》，客户可据此以安全方式配置其 Claude for Government 产品。

此外，FedRAMP 要求我们提供正式变更通知，其中包含与本次变更相关的详细信息。

最后，新版桌面客户端已有渗透测试摘要，后续的补充渗透测试摘要将在可用时提供。变更通知和渗透测试摘要可通过 Anthropic 信任中心在 NDA 下获取。该应用通过标准机构 MDM 平台部署。

## 开始使用

Claude for Government 从今天起以 beta 形式提供。Anthropic 仍是签约和计费主体——各机构无需单独建立云服务商关系即可开始使用。

新客户可在 [claude.com/solutions/government](https://claude.com/solutions/government) 申请访问权限。

安全团队可通过[以下链接](https://trust.anthropic.com/resources?s=gutlu13ft6nd7famxolbxg&name=[anthropic]-2025-annual-penetration-testing-reports)下载渗透测试工件。
