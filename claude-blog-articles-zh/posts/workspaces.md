# Anthropic API Console 中的 Workspaces

> 原文：[Workspaces in the Anthropic API Console](https://claude.com/resources/articles/workspaces) · Claude 博客

Workspaces 让开发者可以更轻松地同时管理多个 Claude 部署。

* 分类：[产品更新](/resources/product-updates)
* 产品：Claude Platform
* 日期：2024 年 9 月 10 日
* 阅读时长：3 分钟

我们在 Anthropic API Console 中推出 Workspaces（工作区），帮助开发者高效管理多个 Claude 部署。工作区是独立的环境，让你能够组织资源、简化访问控制，并在更细的粒度上设置自定义支出限额和速率限制。

## 管理多个部署

对于在不同环境（如开发、预发布和生产）以及不同用例中使用 Claude 的开发者，Workspaces 为整个组织与各个 API key 提供了一层抽象。

![展示不同工作区的产品界面截图](https://assets.claude.com/d07c04192b72f56c97ec51e9f5950d14549cbdc7.png)

**借助 Workspaces，你可以：**

* **设置细粒度支出限额**：按工作区实施月度支出限额，让你精细控制 API 使用成本。
* **对相关资源分组**：将 API key、用量数据和设置组织成与项目或环境对应的逻辑分组。
* **管理速率限制**：在组织整体速率限制之内，独立调整每个工作区的速率限制，从而更好地管理各部署的负载。
* **简化访问控制**：通过在工作区级别分配用户权限，提升账户安全性。
* **高效监控用量**：按工作区查看 API 用量和成本明细，更轻松地跟踪并优化资源分配。

## 开始使用

Workspaces 现已面向我们 Console 中的所有 Anthropic API 用户开放。要开始使用，你可以在[这里](https://console.anthropic.com/settings/workspaces)创建一个工作区，并生成工作区范围的 API key。了解更多，请查阅我们[帮助中心](https://support.anthropic.com/en/articles/9796807-creating-and-managing-workspaces)中的详细指南。
