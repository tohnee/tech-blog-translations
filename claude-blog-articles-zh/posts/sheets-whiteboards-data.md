# 推出 Claude Whiteboards、Claude Sheets 和 Claude Data

> 原文：[Introducing Claude Whiteboards, Claude Sheets, and Claude Data](https://claude.com/resources/articles/sheets-whiteboards-data) · Claude 博客

现在，你可以直接在 Claude 中在白板上头脑风暴、构建表格、共享数据。

今天，我们以 beta 版推出 Claude Whiteboards 和 Claude Sheets，而 [Claude Dashboards（在新标签页中打开）](https://claude.com/resources/articles/dashboards-and-motion)则以 Claude Data 之名正式可用（GA）。Whiteboards 是一块共享画板，团队可以在上面与 Claude 一起头脑风暴；Sheets 是一个 Claude 与你共同构建和编辑的电子表格；Claude Data 则新增了数据故事（data stories）、认证查询（certified queries）和实时共享。这些功能在所有付费套餐中均可使用。

过去在项目中使用 Claude，往往意味着要把产出搬到另一个工具或程序中，而 Claude 无法实时访问以跟进进展和变化。现在，你的文档、画板、表格和仪表盘都可以留在 Claude 中，你的团队也能继续在其中共同编辑。准备好之后，你可以把产出直接带入合作伙伴的工具中继续工作。

## Claude Whiteboards

很多人把 Claude 当作思考伙伴，但与其头脑风暴通常意味着要把结果复制粘贴到别处，才能与同事一起头脑风暴或协作。现在，你可以把一份杂乱的想法大声说给 Claude 听，Claude 能把它变成一块画板，附带包含负责人和日期的时间线，让你和团队实时协作。例如在复盘会（retro）上，每个人都可以添加自己的笔记，Claude 能按主题把它们归类，并为每个人起草行动项。你可以用框选圈出画板的任意部分，向 Claude 提问，把注意力集中在那里。头脑风暴结束后，Claude 可以把画板转成文档或演示文稿，或带入 Lucid、Miro、Vani by Zoho 等工具，与团队继续推进。

## Claude Sheets

Claude 现在可以生成带工作表标签、公式、格式和下拉菜单的电子表格，往往只需要一句提示，例如要一个营销活动跟踪表或招聘预算表。它可以在单元格中编辑，并把每一处新编辑标出轮廓，方便你追踪变更。你可以把表格分享给团队，让你和 Claude 一起在其上工作。

目前，Sheets 的电子表格功能还比较简单，但我们正在增加更多功能。当你需要 Excel 的完整功能时，可以把文件导出为 .xlsx 或 CSV，或使用 [Claude for Excel（在新标签页中打开）](https://claude.com/claude-for-microsoft-365)。你也可以在 Airtable、Asana、monday.com 和 Smartsheet 等合作伙伴工具中继续工作。

## Claude Data

[Claude Dashboards（在新标签页中打开）](https://claude.com/resources/articles/dashboards-and-motion)于 10 月以 beta 版发布，让团队可以在 Amazon Redshift、BigQuery、ClickHouse 等工具中快速查询公司的数据。从今天起，它以 Claude Data 之名正式可用。我们之所以改名，是因为公司使用数据的方式比仪表盘更广，而这一产品现在覆盖了他们更广泛的工作方式。认证查询和实时共享处于 beta 阶段。以下是团队使用 Claude Data 的一些方式：

* **创建指标的认证定义。**你的数据团队可以认证所有人都应使用的查询，这样就不会出现基于互相冲突的数据来搭建或处理仪表盘的情况。基于这些指标构建的图表会带有「已认证」（certified）徽章，表明它们已经过认证。
* **用数据创作故事。**你可以与 Claude 在 Claude Data 中协作，基于你的指标起草数据故事或有旁白的视频，供你在分享前审阅。
* **与所有人共享最新数字。**借助实时共享，你的同事打开共享仪表盘时就能看到最新数字，即使他们没有访问那些让数据保持最新的连接器的权限。查看者看到的是你已批准的查询结果，无法借用你的权限运行其他查询。
* **匹配你的品牌观感。**Claude Data 现已支持设计系统（design systems）。
* **通过缓存加快加载。**以前，每个仪表盘每次加载都会重新加载。现在，仪表盘支持缓存，并且可以按仪表盘分别设置刷新频率。
* **追踪随时间发生的变化。**Claude Data 现在具备变更追踪，你可以看到谁做了编辑，并在需要时回滚到指定版本。

Claude Data 的合作伙伴包括 Amplitude、Mixpanel、Omni、PostHog、Sigma 和 ThoughtSpot。

## 也可以在你的其他工具中工作

从今天起，[交互式连接器（在新标签页中打开）](https://claude.com/resources/articles/interactive-connectors-full-tool)可以以完整应用的形式在你的对话旁边打开，或全屏打开，因此你可以自己在 Adobe、Atlassian、Box 和 Notion 等工具中工作，也可以让 Claude 与你一起进行修改。

## 开始使用

Claude Whiteboards、Sheets 和 Data 可在网页、桌面和移动端使用。Claude Data 需要数据连接器，例如数据仓库或 CRM。

**致管理员：**在 Team 套餐中，这三项功能默认开启。在 Enterprise 套餐中，Claude Whiteboards 和 Sheets 默认关闭，Claude Data 将于 2026 年 11 月 20 日默认开启。你可以随时在「组织设置 > Artifacts」中更改这些设置。
