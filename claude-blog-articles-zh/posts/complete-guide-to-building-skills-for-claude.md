# 构建 Claude Skills 的完整指南

> 原文：[A complete guide to building skills for Claude](https://claude.com/blog/complete-guide-to-building-skills-for-claude/) · Claude 博客

自 10 月[发布 Skills](https://claude.com/blog/skills) 以来，我们看到了开发者的浓厚兴趣：他们希望 Claude 一以贯之地遵循特定的工作流；高级用户希望把文档创建、研究流程这类可重复的任务自动化；团队希望统一 Claude 在整个组织中的运作方式；MCP 连接器开发者则希望为自己的集成搭配可靠的工作流。

共同点在于：人们希望获得更详细的指导，来构建有效的技能（skill）——无论是独立的工作流，还是经 MCP 增强的集成——从规划与结构，到测试与分发。

我们整理了这份指南来填补这一空白。它涵盖了从技术要求、技能结构到测试方法与常见故障排查模式的一切。无论你是在构建配合 Claude 内置能力的独立技能，还是在增强一个 MCP 集成，都能找到与自己相关的指导——并为有需要的人准备了专门的 MCP + Skills 章节。

**你将学到：**

- 技能结构的技术要求与最佳实践
- 独立技能与 MCP 增强工作流的模式
- 在不同使用场景中被验证有效的模式
- 如何测试、迭代与分发你的技能

如果你已经明确了自己最想自动化的前 2-3 个工作流，预计用 skill-creator 构建并测试你的第一个可用技能大约需要 15-30 分钟。

**适合谁读：**

- 希望 Claude 一以贯之地遵循特定工作流的开发者
- 想为自己的集成补充工作流知识的 MCP 连接器开发者
- 把可重复任务自动化的高级用户
- 希望统一 Claude 在组织内运作方式的团队
