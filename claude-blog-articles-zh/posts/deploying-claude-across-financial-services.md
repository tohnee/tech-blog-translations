# 在金融服务行业部署 Claude

> 原文：[Deploying Claude across financial services](https://claude.com/resources/articles/deploying-claude-across-financial-services) · Claude 博客

在本指南中，我们分享金融服务公司如何用 Claude 压缩最耗时的工作，包括客户案例和一份实用的采用路线图。

* 分类：[最佳实践](/resources/best-practices)
* 产品：Claude Cowork、Claude Enterprise
* 日期：2026 年 5 月 5 日
* 阅读时长：3 分钟

在整个金融服务行业，公司正在把 Claude 用于研究、交易工作、承保、理赔、模型审查和月末结账。多数公司会同时使用不止一个 Claude 产品来完成任务：用 Claude 进行对话和研究，用 Claude Cowork 处理跨文件、跨应用的项目级工作，用 Claude Code 服务量化团队和工程团队，用 Claude for Microsoft 365 支撑花在 Excel、PowerPoint、Word 和 Outlook 上的时间，并用 Claude Platform 与 Claude Managed Agents 构建和部署定制应用与智能体。

为帮助领导者规划落地路径，我们编写了一份面向金融服务行业的实用部署指南。它覆盖每个产品、Anthropic 已发布的预置金融智能体参考架构，以及一套公司当下即可执行的三阶段采用手册。

在本指南中，我们分享：

* 一份产品矩阵，说明何时使用 Claude Chat、Cowork、Code、Microsoft 365 加载项、Claude Platform 和 Claude Managed Agents
* 10 个预置金融智能体模板，包括推介材料生成器、市场研究员、KYC 筛查器、总账对账器和月末结账助手
* 来自 AIG、Commonwealth Bank of Australia、IG Group 和 Moody's 的客户故事
* 一套三阶段采用手册——打基础、试点、规模化——并给出每个阶段行之有效的行动与专业建议
* 按行业组织的用例，覆盖投资银行与私募股权、财富与资产管理，以及零售与商业银行

本指南面向两类读者：决定 Claude 在公司中如何定位的 AI 负责人，以及负责落地实施的工程师。
