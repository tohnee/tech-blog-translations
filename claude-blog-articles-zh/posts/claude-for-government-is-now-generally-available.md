# Claude for Government 现已正式可用

> 原文：[Claude for Government is now generally available](https://claude.com/resources/articles/claude-for-government-is-now-generally-available) · Claude 博客

Claude Code CLI 和 Claude for Microsoft 365 现也已开启抢先体验。

今天，[Claude for Government](https://claude.com/solutions/government) 面向联邦和州级机构正式可用。该平台通过 FedRAMP High 授权环境提供 Claude 的编码和智能体工作能力，[自 7 月起一直处于公开 beta](https://claude.com/resources/articles/bringing-claude-code-and-claude-cowork-to-government)。

各机构可以获得与 Anthropic 商业客户相当的能力，同时不牺牲合规要求。新能力通常按商业版本的发布节奏提供。

[Claude](https://claude.com/product/overview) 可直接处理桌面上的文件，让机构员工使用[技能](https://claude.com/resources/articles/skills-explained)、插件和项目来完成备忘录撰写、RFP 审查、案件处理等任务。借助 [Claude Code](https://claude.com/product/claude-code)，公共部门团队可以[构建并现代化支撑公共服务的软件系统](https://claude.com/resources/webinars/claude-code-and-public-service-modernizing-how-state-and-local-governments-build-software)。

Claude for Government 的治理控制专为公共部门机构而构建。管理员可以设置配置默认值，并在各部门之间分配和控制支出。安全团队和授权官员可以获得审计日志，以及支持机构 ATO 流程的文档。采购官员可以直接与 Anthropic 签约，并按正式可用条款授予合同。

Claude Code 命令行界面和 [Claude for Microsoft 365](https://claude.com/claude-for-microsoft-365) 也正在通过同一环境、以同样的管理控制推出抢先体验。

## 计费、管理与监督

**无席位费。**机构以固定增量购买用量，并设有硬性的不得超过上限，因此支出不会超过机构已承诺的金额。管理员可以定义用户层级，为每个群组设置支出和模型限制，按用户和按模型跟踪用量，并在余额过低之前收到消耗警报。

![](https://assets.claude.com/b9c200e7ade0471476106a0d939dabfbfcc7a685.png)

管理控制台中的支出分析视图

**契合部门组织方式的管理。**部门级管理员向子机构分配预付用量，同时各子机构管理自己的用户。各机构可以连接自己的身份提供商实现单点登录，并在管理门户中自助完成设置。SCIM 组映射为每个席位层级设置速率限制、美元上限和允许使用的模型。分层配置为子机构设定默认值，包括 Claude 可以连接什么以及哪些功能可用。

**内建于设计中的监督。**管理操作会记录在审计日志中，组织管理员可以查阅。Anthropic 一方的敏感操作需要双人批准。用量导出仅为计量数据，因此机构无需转移敏感材料即可回应 ATO 和 IG 的请求。对话历史保留在机构管理的设备本地。

## 开始使用

Claude for Government 今天已面向联邦和州级机构正式可用。机构无需单独建立云服务商关系即可开始使用。现有客户可以迁移到桌面应用，并通过应用内导入将对话历史一并带来。

我们的 [FedRAMP 安全配置指南](https://trust.anthropic.com/resources#6ab2b125752bf0e0e8025505)可通过 Anthropic 的[信任中心](https://trust.anthropic.com/)获取。该应用通过标准的机构 MDM 平台部署。

新机构可以在 [claude.com/solutions/government](http://claude.com/solutions/government) 申请访问权限。要加入 Claude Code CLI 或 Claude for Microsoft 365 的抢先体验，请联系我们的公共部门团队。也可通过 [Claude for Government 文档](https://claude.com/docs/government/overview)了解更多。
