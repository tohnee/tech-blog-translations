# Claude Code 现已支持 artifacts

> 原文：[Claude Code now supports artifacts](https://claude.com/blog/artifacts-in-claude-code/) · Claude 博客

从今天起，Claude Code 可以把工作进度捕获为 artifact（工件），将 Claude Code 的工作变成可实时更新、可分享的可视化页面——包括 PR 演练、系统讲解、仪表盘和发布清单——并随着会话的推进自动更新。

一次 Claude Code 会话的内容可以千差万别：排查一起事故、重构一个服务，或者分析数月的数据。Artifacts 会把这些工作转化为任何人都能够打开和浏览的网页，比如一份 pull request 演练、一个可筛选可排序的仪表盘，甚至是一份随着工作完成而自动打勾的发布清单。Artifacts 让在共享工作上的协作变得更容易，团队因此可以把更多时间花在构建上，把更少的时间花在同步进度上。

## **基于你会话中的上下文构建**

Claude Code 使用你会话的完整上下文来构建 artifact，包括你的代码库、你的连接器（connectors）以及对话本身。一个单一的事故页面可以同时汇集：代码中失败的测试及其背后的函数、来自所连接监控工具的错误尖峰，以及你刚跑完的会话中的根因推理。有了 artifacts，你不需要接通数据源，也不需要搭建基础设施。你只要索要一个页面，Claude Code 就会用已有的一切把它构建出来。

## **原地更新的实时页面**

当 Claude Code 更新一个 artifact 时，已打开的页面会原地刷新，队友在发布的那一刻就能看到更新。每一次发布都是同一链接下的一个新版本，附带版本历史，你随时可以恢复；画廊（gallery）则让你浏览和管理自己创建的所有 artifact。

从我们的内部测试来看，最常见的用例之一是调试。它们通常是这样的：一位工程师在站会之前启动了一起事故调查。Claude Code 梳理日志并发布一个 artifact：一条时间线、可疑的提交，以及一张错误率图表。她从页面页眉把链接分享给团队。到站会开始时，随着调查的推进，Claude 已经重新发布了两次，纳入了最新的信息。有了 artifacts，团队成员和相关方不必再「给我们讲讲那个智能体发现了什么」，因为所有人看到的都是同一个视图、拥有同样的上下文。

## **仅对你所在的组织可见**

每个 artifact 默认仅对其作者可见。当你准备好之后，可以直接从页面上把它分享给队友和你的组织。Artifacts 只能由你所在组织中经过身份验证的成员查看，无法设为公开。管理员通过组织级开关和基于角色的范围控制来管理访问，设置保留策略，并通过合规 API 获得全组织范围的可见性。

## **开始使用**

直接向你的会话索要一个 artifact——或者只是要一个可视化的东西，以下是一些按角色划分的点子：

- **法务 / 开源**：直接从仓库出发，对每个依赖项做许可证审计，标记 copyleft 许可。*“构建一个 artifact，列出每个第三方依赖及其许可证，标记出任何 copyleft 的内容。”*
- **隐私**：一张数据流地图，标出个人数据在代码中被收集、存储和记录的位置。*“把我们在代码库中接触个人数据的位置梳理成一个 artifact，供隐私审查使用。”*
- **安全**：发现的问题链接到确切的代码行，让修复毫无歧义。*“把这次审查中的认证（auth）发现整理成一个 artifact，每一条都链接到代码。”*
- **FinOps / 平台财务**：从你的基础设施即代码（infrastructure-as-code）映射出云资源与成本驱动因素。*“把 Terraform 中的云资源映射成一个 artifact，按服务分组，标出主要的成本驱动因素。”*
- **软件工程师**：一份审查者真正能跟得上的 PR 或 bug 演练，取自 diff 及其周边代码。“为这个 PR 做一个 artifact——diff、推理过程，以及我测试了什么。”
- **设计师与前端工程师**：一个屏幕的若干 UX 方向，每个都由你的真实组件构建，因此你选中的那个可以直接交付。“给我一个 artifact，包含这个注册表单的 5 种 UX 变体，用我们的组件库构建。”
- **资深工程师与架构师**：一张展示服务实际如何组合的地图，取自真实的 import 关系图，而不是白板。“把支付服务的组合方式从代码映射成一个 artifact。”
- **SRE 与值班人员**：一个随着调查推进而生长的事故页面，最终成为事故复盘。“把这个事故变成一个 artifact——时间线、可疑提交、监控中的错误尖峰——并在我排查的过程中重新发布。”
- **工程经理**：一页真正交付了什么的内容，取自已合并的 PR。“从 PR 出发，把我团队这周合并的内容做成一个 artifact，按项目分组。”

Claude Code 会构建页面并给你一个链接。在浏览器或桌面应用中打开它，从页眉分享——更新会自动发布到同一个 URL。

## **可用性**

Artifacts 现已面向 Claude Team 和 Enterprise 组织开放 beta，可从 Claude Code CLI 和桌面应用使用，页面可在任何浏览器中查看。
