# 用 Claude 构建并分享 AI 驱动的应用

> 原文：[Build and share AI-powered apps with Claude](https://claude.com/resources/articles/claude-powered-artifacts) · Claude 博客

直接在 Claude 中构建并分享 AI 驱动的应用。

**更新：**现已面向 Team 和 Enterprise 套餐提供。（2025 年 7 月 31 日）

**更新：**可将 PDF、图片等文件上传到你的 artifact 中。（2025 年 7 月 17 日）

今天，我们推出直接在 Claude 应用中构建、托管和分享交互式 AI 驱动应用的能力。开发者现在可以更快地迭代他们的 AI 应用，而不必操心为不断增长的受众扩容所带来的复杂性和成本。

### 构建并托管由 Claude 驱动的应用

我们构建的东西是这样的：Claude 现在可以创建通过 API 与 Claude 交互的 [artifacts](https://claude.com/features/artifacts)——把这些 artifacts 变成 AI 驱动的应用，让分享在经济上真正可行。

当有人使用你的 Claude 驱动应用时：

- 他们用已有的 Claude 账户完成身份验证
- 他们的 API 用量计入**他们自己的**订阅，而不是你的
- 你无需为他们的用量支付任何费用
- 无需任何人管理 API 密钥

Claude 编写的是真正的代码，用于编排复杂的 AI 功能。你可以查看它、修改它，并自由分享它。

### 社区创意

早期用户已经用交互式 artifacts 构建了：

- **AI 驱动的游戏**，其中的 NPC 能记住对话并根据玩家的选择作出调整
- **学习工具**，可根据个人技能水平调整并提供个性化辅导
- **数据分析应用**，用户上传 CSV 并用自然语言追问问题
- **写作助手**，从剧本到技术文档都能帮上忙
- **智能体工作流**，为复杂任务编排多次 Claude 调用

### 开始使用

在 Claude 应用中启用这项新的交互能力即可开始构建。只需描述你想创建什么，Claude 就会为你编写代码。

在你们协作的过程中，Claude 可以根据你的反馈调试并改进自己的代码。应用准备好后，你可以通过一个链接即时分享——无需任何部署流程。Claude 会处理提示工程、错误处理、编排逻辑等技术细节，让你把全部精力放在把想法变成现实上。

**你可以做到：**

- 在你的 artifacts 中使用 Claude API
- 处理文件，并用 React 构建丰富的 UI
- 查看、fork 并定制任何 artifact

**当前限制：**

- 尚不支持外部 API 调用
- 不支持持久化存储
- 仅限基于文本的补全 API

该能力目前以 beta 形式向 Free、Pro、Max 和 Ultra 套餐用户提供。
