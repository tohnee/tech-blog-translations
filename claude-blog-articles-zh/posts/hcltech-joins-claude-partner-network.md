# HCLTech 以全球顶级合作伙伴身份加入 Claude 合作伙伴网络

> 原文：[HCLTech joins the Claude Partner Network as a Global Premier partner](https://claude.com/resources/articles/hcltech-joins-claude-partner-network) · Claude 博客

*HCLTech 将把 Claude 融入其为银行、医院、电信公司和制造商提供的解决方案。*

Anthropic 正与 [HCLTech](https://www.hcltech.com/) 合作——这是一家全球性科技公司，在 60 个国家拥有 23 万多名员工。HCLTech 将通过专门的 Anthropic 业务单元和卓越中心，为其客户在 Claude 上构建智能体解决方案；把 Claude 嵌入 HCLSoftware 产品；并将 Claude 和 Claude Code 集成到 AI Force——它用来为客户运行 IT 服务的平台。HCLTech 由此成为 [Claude 合作伙伴网络](https://claude.com/partners)中的全球顶级合作伙伴（Global Premier Partner）——这是最高层级，要求拥有 1,000 名[认证从业者](https://claude.com/resources/articles/four-role-based-claude-certifications)。

HCLTech 为金融服务、制造业、生命科学与医疗保健、科技、半导体、电信与媒体、零售与消费品，以及出行与公共服务提供解决方案。在这些环境中，一个错误代价高昂，每一项变更都需要经过审查、记录和批准。这一合作正是为了把 Claude 带入这类工作，并配备为这些环境设计的控制措施。

## **HCLTech 如何让 Claude 投入工作**

HCLTech 在三个地方把 Claude 引入其业务，并为每一处设计了护栏和人工审核。

* **专门的 Anthropic 业务单元与卓越中心。** HCLTech 的前置部署工程师将搭建安全的沙箱环境，让客户在部署前用自身的系统和数据测试 Claude。该中心将培训客户员工队伍，帮助工程团队采用 AI 原生实践，并建立组织级控制，以便安全地大规模运行智能体。
* **HCLSoftware 产品中的 Claude。** HCLSoftware 成为 Anthropic 的独立软件供应商（ISV）合作伙伴，并将在网络安全、自动化、业务流程应用和应用开发等领域的部分产品中嵌入 Claude。首批产品是用于端点管理的 HCL BigFix、用于应用安全测试的 HCL AppScan，以及用于数据分析的 Actian AI analyst。
* **AI Force 中的 Claude 和 Claude Code。** AI Force 是 HCLTech 为其服务的企业提供 IT 支持、代码修复和数字员工服务的方式。Claude 和 Claude Code 在策略护栏和异常处理机制的配合下进入该平台。智能体处理常规工作，HCLTech 工程师负责监督高影响力的变更。

“很少有科技公司能同时具备全球系统集成商的规模和 ISV 的产品深度。”HCLTech 首席执行官兼董事总经理 C Vijayakumar 表示，“这让我们拥有罕见优势，能够安全地大规模工程化和部署智能体式 AI，并交付对客户最重要的业务成果。与 Anthropic 的合作进一步增强了我们实现这一目标的能力。”

“AI 的有用程度取决于它是否值得信任。我们打造 Claude，是为了让企业有信心将它带入最敏感、最有价值的工作。”Anthropic 联合创始人兼总裁 Daniela Amodei 表示，“HCLTech 为银行、医院、电信公司和制造商管理这类系统，我们很高兴能与他们合作，将 Claude 和 Claude Code 集成进去。这次合作——以及我们共同推进能力与安全的更广泛承诺——正是 AI 让整个行业的运行方式变得更好的途径。”
