# 你常用的工作工具现在是 Claude 中的交互式连接器

> 原文：[Your favorite work tools are now interactive connectors inside Claude](https://claude.com/resources/articles/interactive-tools-in-claude) · Claude 博客

借助 MCP Apps，在对话中打开 Asana、Slack、Figma 等工具

从今天开始，我们通过 MCP Apps 把交互式连接器带到 Claude。你可以在 Claude 中打开工具并与之交互。在 Asana 中构建和更新项目时间线。在格式化预览中起草、编辑并发送 Slack 消息。在 Figma 中把想法可视化为图表——全程无需切换标签页。

Claude 本就能连接到你的工具并代表你采取行动。现在，借助 MCP Apps，这些工具会以交互式连接器的形式直接出现在对话中，让你能看到正在发生什么，并实时协作。

以下是你现在可以直接在 Claude 中做的事情：

* [Amplitude](https://claude.com/connectors/amplitude) – 构建分析图表，然后交互式地探索趋势、调整参数，发掘隐藏的洞察。
* [Asana](https://claude.com/connectors/asana) – 把对话转化为团队可以在 Asana 中查看和执行的项目、任务和时间线。
* [Box](https://claude.com/connectors/box) - 搜索文件、内联预览文档，然后提取洞察并针对你的内容提问。
* [Canva](https://claude.com/connectors/canva) - 创建演示大纲，然后实时定制品牌和设计，产出可直接交付客户的演示文稿。
* [Clay](https://claude.com/connectors/clay) - 调研公司，查找带有邮箱和电话信息的联系人，拉取公司规模、融资等数据，然后直接在对话中起草个性化外联内容。
* [Figma](https://claude.com/connectors/figma) – 通过提示把文本和图像转化为 FigJam 中的流程图、甘特图或其他可视化图表。
* [Hex](https://claude.com/connectors/hex) - 提出数据问题，获得包含交互式图表、表格和引用的答案。

![](https://assets.claude.com/577251f8c98cfeb6a67ffe98b4e1be7d29503e64.png)

* [monday.com](https://claude.com/connectors/monday) - 管理你的工作、运行项目、更新看板、智能分配任务，并用洞察将进展可视化。
* [Slack](https://claude.com/connectors/slack)（来自 Salesforce）– 搜索并检索 Slack 对话以获取上下文，生成消息草稿，按你的方式排版，并在发布前审阅。

即将推出：**Salesforce** - 借助 Agentforce 360 将企业上下文带入 Claude，让团队可以在一个互联的界面中进行推理、协作和行动。

## **MCP Apps：构建于开放标准之上**

底层技术构建于[模型上下文协议（MCP）](https://modelcontextprotocol.io/docs/getting-started/intro)——连接工具与 AI 应用的开放标准。MCP Apps 是 MCP 的一项新扩展，让任何 MCP 服务器都能在任意支持的 AI 产品中——不仅是 Claude——提供带有丰富用户界面的交互式连接器。

我们将 MCP 开源，是为了给生态提供一个连接工具与 AI 的通用方式。现在我们进一步扩展 MCP，让开发者无论用户身在何处，都能在其上构建交互式 UI。

如需了解更多，请参阅 [MCP Apps——首个官方 MCP 扩展](https://blog.modelcontextprotocol.io/posts/2026-01-26-mcp-apps)的发布公告。

## **开始使用**

现在就可以在 Claude 中开始使用交互式连接器（MCP Apps）。前往 [claude.ai/directory](http://claude.ai/directory)，在“featured”分类下连接应用即可开始。该功能在移动端、Web 和桌面端的 Claude 中面向 Free、Pro、Max、Ultra、Team 和 Enterprise 套餐提供。它现在也可在 [Claude Cowork](http://claude.com/product/cowork) 中使用。
