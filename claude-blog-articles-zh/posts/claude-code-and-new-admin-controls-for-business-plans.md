# Claude Code 与面向企业套餐的新管理控制

> 原文：[Claude Code and new admin controls for business plans](https://claude.com/resources/articles/claude-code-and-new-admin-controls-for-business-plans) · Claude 博客

Claude 将其对话式 AI 与强大的编码智能体整合到同一个企业订阅中。

Enterprise 和 Team 客户现在可以升级到包含更多用量和 Claude Code 的高级席位，把我们的应用与强大的编码智能体整合到同一份订阅之下。用户可以在构思与实现之间无缝切换，管理员则获得在全组织推广 Claude 所需的可见性和控制能力。

我们还推出全新的 Compliance API，让组织能够以编程方式访问使用数据和客户内容，从而实现更好的可观测性、审计和治理。

## 将 Claude Code 加入你的套餐

管理员可以完全灵活地根据个人用户需求和岗位职责分配标准席位或高级席位。高级席位让用户同时访问 Claude 和 Claude Code，从而在整个开发生命周期中与 Claude 协作。

例如，开发者可以通过与 Claude 的交互式对话研究不熟悉的框架，然后在终端中使用 Claude Code 实现可用于生产的代码。他们可以在 Claude 对话中探索架构方案、评估权衡，然后切换到 Claude Code 构建选定的架构。

Behavox 等早期客户已经立即看到了成效。Behavox 是一家合规与安全公司。“自从把 Claude for Enterprise 与 Claude Code 打包后，我们已将其推广到数百名开发者，它很快成为我们的首选结对编程伙伴，”机器学习运营高级经理 Artem Pikulin 分享道。“它的编码辅助始终优于其他智能体，每天都在带来更出色的结果和价值。”

Altana 是连接全球供应链的 AI 驱动的产品网络，也经历了类似的变革性成果。“Claude Code 和 Claude 将 Altana 的开发速度提升了 2 到 10 倍，改变了我们构建复杂 AI/ML 系统的方式——这些系统支撑着围绕全球供应链大规模知识图谱的多方协作，”联合创始人兼首席科学官 Peter Swartz 表示。“因此我们正在承接雄心大得多的项目。”

## 灵活定价，成本可预测

Claude 席位包含足够一个典型工作日使用的用量，但当你的团队需要获取更多智能、与 Claude 进行更多对话时，管理员可以按标准 API 价格为用户开启额外用量。管理员可以控制单个用户的额外用量支出上限，从而既让用户保持灵活性，又让管理员获得可预测的账单。

这种方式提供了一种简单的 Claude 扩展路径，同时在每一步都提供集中计费、管理和企业级管理控制。

## 管理员的控制与管理

我们构建了新的全面控制能力，让组织获得使员工高效使用 Claude 所需的可见性和管理能力。

* **自助席位管理**：购买新席位、直接管理席位分配，并通过管理面板开通用户。
* **精细的支出控制：** 在组织和个人用户层级设置支出上限，在保持在预算内的同时为关键项目保留灵活性。
* **用量分析**：在 Claude 中查看 Claude Code 分析数据，包括代码被接受的代码行数、建议接受率和使用模式等指标。
* **受管策略设置**：为所有 Claude Code 用户部署并强制执行设置以匹配内部政策，包括工具权限、文件访问限制和 MCP 服务器配置。

## Compliance API

企业组织现在可以通过新的 Compliance API 更好地满足监管要求。合规团队无需再手动导出和定期审查，而是可以实时、以编程方式访问 Claude 的使用数据和客户内容，从而构建持续监控和自动化政策执行系统。

管理员可以将 Claude 数据集成到现有的合规仪表盘中，自动标记潜在问题，并通过选择性删除能力管理数据保留。这为组织提供了扩大 AI 采用规模、同时满足监管义务所需的可见性和控制力。
