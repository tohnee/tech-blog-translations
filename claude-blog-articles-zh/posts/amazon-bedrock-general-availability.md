# Amazon Bedrock 上的 Claude 现已面向所有 AWS 客户开放

> 原文：[Claude on Amazon Bedrock now available to every AWS customer](https://claude.com/resources/articles/amazon-bedrock-general-availability) · Claude 博客

Claude 现已在 Amazon Bedrock 上正式可用。

Claude 现已在 [Amazon Bedrock](https://aws.amazon.com/bedrock/claude/) 上正式可用。Amazon Bedrock 是一项全托管服务，为 Amazon Web Services（AWS）客户提供安全的基础模型云端访问，以及用于构建生成式 AI 应用的工具。

这意味着，如今每一位 AWS 客户都可以用 Claude 进行构建，并很快将获得一系列令人期待的新体验，其中包括 [Agents for Amazon Bedrock](https://aws.amazon.com/blogs/aws/preview-enable-foundation-models-to-complete-tasks-with-agents-for-amazon-bedrock/)——我们的团队在该功能的开发中发挥了关键作用。

Agents for Amazon Bedrock 目前处于预览阶段，它可以借助广泛使用的 [AWS Lambda](https://aws.amazon.com/lambda/) 函数来编排并执行 API 调用。通过这项功能，Claude 可以扮演更扩展的智能体角色：理解用户请求、把复杂任务拆解为多个步骤、通过对话收集更多细节、查询信息，并采取行动来满足请求。例如，一个用 Claude 构建了聊天助手的电商应用，不再只能查询商品库存——它实际上可以帮助客户更新订单、办理换货，以及查找相关的用户手册。

我们最近还透露，将通过该服务提供 Claude 模型的安全定制与微调能力。这项技术利用 AWS 客户的专业知识和专有数据来优化 Claude 的表现，从而给出更相关的结果，同时降低有害输出的可能性。

Claude 在 Amazon Bedrock 上的正式可用，推进了我们帮助企业以负责任的方式整合变革性 AI 的工作。未来几个月，我们还将宣布更多应用层解决方案，帮助各类组织从 Claude 中获得最大价值。

自 4 月宣布与 Amazon Bedrock 集成以来，Claude 已获得众多领先企业的自然采用，包括 **LexisNexis**、**Lonely Planet** 和 **Ricoh USA**。

顶级资产管理公司 **Bridgewater Associates** 也在利用我们最先进的模型 Claude 打造一款新颖的、由 AI 驱动的 Investment Analyst Assistant（投资分析师助手），为其团队的初级成员提供支持。

Bridgewater 致力于从根本上理解经济，揭示驱动全球市场的那些恒久且普适的因果关系。为了揭示这些关系，Bridgewater 的分析师会花大量时间理解并系统性地压力测试各种假设，且常常以代码的形式进行。

例如，分析师可能会研究美联储收紧政策对大宗商品价格的影响，为此创建关键的数据可视化（包括图表和表格），以检验假设、综合发现并分享研究成果。Bridgewater 的团队正与 Amazon Bedrock 上的 Claude 合作，让这一流程更高效、更具可扩展性。

“Claude 是我们即将推出的、运行在 Amazon Bedrock 上的 Investment Analyst Assistant 背后能力强大的模型。它能够接收基本指令、生成 Python 代码、处理报错，并输出图表和表格，表现很像一位一两年经验的分析师。”Bridgewater Associates 的 AI/ML 首席技术官 Aaron Linsky 表示，“当 Investment Analyst Assistant 不确定该走哪条路径时，它还会在尝试执行前提出澄清性问题。”

Linsky 补充道：“我们的 Investment Analyst Assistant 还支持就地编辑代码，这让分析师可以自行决定何时借助 Claude，何时自己动手做简单的修改。这带来了更快的反馈循环，也让 Investment Analyst Assistant 能基于更新后的代码库继续迭代——这是许多其他聊天式助手根本不具备的。”
