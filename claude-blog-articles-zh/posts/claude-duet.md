**Claude Duet 的安全性、隐私与安全保障**

2026 年 10 月 23 日——我们正在持续开发并加强这些保护措施。你可以[在此](https://claude.com/resources/articles/claude-duet-safety-privacy-and-security)进一步了解 Claude Duet 如何在设计上保障安全、隐私与安保。

今天，我们开放 Claude Duet 的研究预览。这是一款新应用，Claude 在其中以主动型智能体（proactive agent）的身份工作。它会带着需要你关注的事项主动来找你，完成你交代的任务，在你离开时继续工作，并在代表你行动之前先与你确认。我们打造 Claude Duet，是为了那些手头事情多到难以追踪的专业人士和小企业主。

它以独立应用的形式在 iOS、Android 和 claude.ai 上提供。在本次研究预览中，Claude Duet 包含在 Pro、Max 和 Ultra 套餐内，并使用与 Claude 其他功能相同的用量限额。如需获取访问权限，[加入候补名单（在新标签页打开）](https://claude.com/product/claude-duet)。

## 把注意力放在最重要的地方

我们把 Claude Duet 设计成一个你可以信赖的伙伴。各类专业人士每天都要在众多决策之间周旋，我们认为他们会发现 Claude Duet 特别有用。它帮助你决定把时间和精力优先投向哪里，并为那些过去觉得不可能或令人望而生畏的雄心项目腾出空间。

Claude Duet 之所以如此有用，在于它的判断力。我们围绕 [Claude Opus 5.5（在新标签页打开）](https://www.anthropic.com/claude-opus-5-5) 设计它，并把它打造得足智多谋：能判断什么需要你、什么可以等、什么时候应先与你确认。

每天早上，它会就你所连接应用中最重要的事项发给你一份简短简报。一天之中，它持续关注这些应用，只在有事情需要你注意时才给你发消息。你也可以交给它各种形态的任务——从安排会议这类简单的行政事务，到更复杂的工作，比如用几十种工具构建仪表盘、制作财务或销售预测、做原型以及构建网页应用。

## 安全与谨慎内建于设计之中

Claude Duet 汲取了我们多年来在智能体的安全、保障与隐私方面的工作成果，既包括我们自己构建的智能体，也包括企业运行自身智能体所用的基础设施：

* Claude Duet 基于我们的[可信智能体框架（在新标签页打开）](https://www.anthropic.com/research/trustworthy-agents)，该框架同样指导着 Claude Code 和 Claude in Chrome 等智能体。
* Claude Duet 对凭据的处理遵循我们为 [Claude Managed Agents（在新标签页打开）](https://www.anthropic.com/engineering/managed-agents) 采用的设计，因此它从不会直接看到你的密码或登录 token。
* 操作由我们的[自动模式分类器（在新标签页打开）](https://www.anthropic.com/engineering/claude-code-auto-mode)批准，这一防护措施同样保护 Claude 和 Claude Code，避免它们采取你未要求的步骤。
* Claude Duet 对隐藏指令和提示注入的防御来自我们的[浏览器使用研究（在新标签页打开）](https://www.anthropic.com/research/prompt-injection-defenses)，我们的模型和防护措施也在更广范围内覆盖这一问题。
* 我们对 Claude Duet 的安全基础设施进行了对抗性测试。红队和一家外部公司对 Claude Duet 做了渗透测试，它也被纳入我们公开的[漏洞赏金计划（在新标签页打开）](https://hackerone.com/anthropic)。

**Claude Duet 如何处理敏感信息。** 我们还在发布 Claude Duet 时配套推出了一套新的专用分类器和安全系统提示词，用于检查每条消息并防止敏感信息泄露。一个替你读邮件、发消息的智能体，时刻都在决定信息该流向何处。这套新的分类器和提示词旨在拒绝分享最严格层级信息的请求，包括信用卡号和政府身份证件。其他敏感信息，例如健康或个人财务状况，只有在你明确指示 Claude Duet 发送时才会放行。

我们正在持续开发并加强这些保护措施，并将在未来几天分享更多关于 Claude Duet 安全设计的细节。

## Claude Duet 如何运作

**你在 Claude 中的上下文是基础。** Claude Duet 会沿用你 Claude 账户中的记忆、技能和已连接应用，因此初始设置几乎不需要做什么。改变的是你们协作的方式：Claude Duet 会主动来找你，你可以通过打字或语音在同一个持续对话线程中给它发消息，所以一句快速回复和一个为期一周的项目都从同一个地方开始。

**你离开时，工作仍在继续。** Claude Duet 拥有一台带独立浏览器的虚拟机，因此不需要你的笔记本电脑或手机处于开机状态。用一条简短消息描述任务，它就会自行判断该用哪些应用、在后台该执行哪些步骤。任务完成或需要你审阅时，你会收到通知。

**有事需要你时才会收到消息。** Claude Duet 每隔几小时检查一次你连接的账户，因为不间断检查会更快耗尽你套餐的限额。我们正在持续测试它对「何时该给你发消息」的判断，并将根据测试者的反馈不断调优。你也可以告诉它你希望了解哪些信息、以及多频繁地收到消息。

**重要决策仍由你掌控。** Claude Duet 会自行阅读、起草和准备工作。但在发送消息、付款、签署文件或删除任何东西之前，它会准确告诉你它即将做什么，并等待你的批准。即使你批准，也有少数事情是不被允许的，比如交易证券或在账户之间转移资金。你也可以随时断开 Claude Duet 可访问的任何应用。

**连接你业务所依赖的工具。** Claude Duet 可以使用 [Claude Marketplace（在新标签页打开）](https://claude.com/marketplace/connectors-plugins)中超过 6,000 个连接器和插件来：

* 找出你错过的 Gmail 和 Slack 消息，并帮你回复。
* 检查 Intuit QuickBooks 或 Stripe 中的未付发票，并起草提醒。
* 在 Gusto 中准备并发起工资单，填好工时、奖金和报销。
* 起草职位发布，在你编辑并批准后发布到 LinkedIn。
* 协助准备协议，并通过 Docusign 发送以进行审阅和签署。
* 利用 HubSpot 中的联系人和商机历史起草跟进邮件。
* 在 Canva 中把你的产品发布变成一场社交媒体营销活动。
* 设置、设计并管理你的 Shopify 店铺。即将推出更丰富的可视化编辑器，让你在设计店面后、任何内容上线前进行预览。

你还可以使用 Stripe 的数字钱包 Link，让 Claude Duet 为你的业务采购物品。Claude Duet 会与你确认商品，Link 会请你批准这笔支出。随后它用虚拟卡付款，因此你的真实卡号不会被共享。它也可以使用 Shopify 的 Shop Pay 在网店结账。即将推出：在获得你许可后，它将能够用你保存在 1Password 中的登录信息登录网站。

## 加入研究预览

这是 Claude Duet 的早期版本，它仍可能误读某个对话线程，或对紧急程度的判断失准。我们围绕「工作」构建其核心功能，因此像订票这类个人事务还不太擅长，它也还不能向你展示它的浏览器。目前，Claude Duet 存在于独立应用中，与主 Claude 应用分开。我们从早期用户那里学到的东西，将决定两者如何协同工作。

在研究预览期间，Claude Duet 与 Claude 其他功能共享你套餐的用量限额，但它消耗限额的方式与典型对话不同。它的后台检查会计入这些限额，而更大的任务——比如构建财务模型或一份演示文稿——需要更多模型轮次和后台工作。
