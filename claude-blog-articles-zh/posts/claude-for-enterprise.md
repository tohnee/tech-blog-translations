# Claude 企业版

> 原文：[Claude for Enterprise](https://claude.com/resources/articles/claude-for-enterprise) · Claude 博客

Claude 企业版方案（Claude for Enterprise）帮助企业在 AI 的加持下大规模推动跨职能协作。

今天，我们发布 [Claude 企业版方案](https://claude.com/solutions/enterprise)，帮助企业在使用内部知识的前提下与 Claude 安全协作。

掌握更多上下文的团队能做出更好的工作。Claude 企业版方案提供扩展至 500K 的上下文窗口、更高的用量额度，以及原生 GitHub 集成，让你可以和 Claude 一起处理整个代码库。它还包含企业级安全功能——例如 SSO、基于角色的权限和管理工具——帮助保护你的数据与团队。

借助 Claude，组织内部的知识更容易共享和复用，团队中的每个人都能快速、稳定地产出最佳成果；与此同时，你的数据也受到保护。我们不会用你的对话和内容训练 Claude。如需开始使用企业版方案，[请联系我们的销售团队](https://www.anthropic.com/contact-sales)。

## 企业级管控

企业版方案引入了关键的安全与管理控制，将管理和保护公司敏感数据放在首位，包括：

* **单点登录（SSO）与域名捕获（domain capture）**：安全管理用户访问，并集中化配置（provisioning）控制。
* **基于角色的访问与细粒度权限控制**：为工作区指定主要所有者，以增强安全性和信息管理。
* **审计日志**：追踪系统活动，用于安全和合规监控。审计日志将在未来几周内提供。
* **跨域身份管理系统（SCIM）**：自动化用户配置与访问控制。SCIM 也将在未来几周内提供。

## 企业级功能

通过将 Claude 与组织的知识相连接，你可以在比以往更多的项目、决策和团队中扩展专业能力。

通过企业版方案，你可以借助扩展至 **500K 的上下文窗口**与 Claude 协作——这相当于数百份销售记录、数十份 100 页以上的文档，或中等规模的代码库。将知识输入其中，Claude 就能提供深入的、针对具体职能的指导。

![Claude 界面：用户正在上传多个文档、CSV 和 PDF 文件](https://assets.claude.com/9f2de17959c48904961eb98fa7aa7fd085b30f4e.png)

我们还为工程团队推出了**原生 GitHub 集成**，可将 GitHub 仓库与 Claude 同步。现在，你可以与代码库并肩工作，迭代新功能、调试问题，或帮助新工程师上手。GitHub 是我们正在构建的一系列原生集成中的第一个，目的是把 Claude 连接到最重要的数据源，让 Claude 提供更相关、更有洞见的协助。该功能目前面向早期企业版用户提供 beta 版，我们计划在今年晚些时候更广泛地开放。

![Claude 界面：用户正在选择 GitHub 连接器，为项目添加知识](https://assets.claude.com/fb4ba0ca10323c6fc7c16aca1072d4b6749ab590.png)

当扩展的上下文窗口与 **Projects** 和 **Artifacts** 结合使用时，Claude 就成为端到端的解决方案，帮助你的团队把任何想法从构思推进到高质量的工作产出。例如，市场人员可以把市场趋势转化为有吸引力的营销活动；产品经理可以上传产品规格，让 Claude 构建交互式原型；工程师可以连接代码库，借助 Claude 排查错误并找出优化点。

![Claude 界面：一个散点图 Artifact](https://assets.claude.com/7ccbee6da85787009663ec5ead8e123f778a2ae6.png)
