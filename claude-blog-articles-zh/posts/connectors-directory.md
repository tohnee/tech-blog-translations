# 发现可与 Claude 配合使用的工具

> 原文：[Discover tools that work with Claude](https://claude.com/resources/articles/connectors-directory) · Claude 博客

浏览并一键将 Claude 连接到你常用的应用和工具。

* 分类：[产品更新](/resources/product-updates)
* 产品：Claude apps
* 日期：2025 年 7 月 14 日
* 阅读时长：3 分钟

今天，我们推出一个新的工具目录，收录可连接到 Claude 的工具，你可以浏览并一键试用。我们还重点展示了由合作伙伴构建的新连接器，既包括 Notion、Canva、Stripe 等远程服务，也包括 Figma、Socket、Prisma 等本地桌面应用。

现在，Claude 可以访问与你相同的工具、数据和上下文——这使它从一个有用的助手转变为一个知情的 AI 协作者，能给出更相关的回答，并直接在你的工具中与你协作。

### 上下文改变一切

大多数 AI 交互都始于你从头解释一切：项目细节、截止日期、你用的工具——一遍又一遍。就像每次都要从零开始。

你可能会让 Claude *“为我们最新的功能写发布说明”*，然后得到一个有用的模板。如果把 Claude 连接到 Linear 这类工具，你就可以改为让 Claude *“根据 Linear 中我们最新一个冲刺的内容写发布说明”*，它会拉取你真实的 Linear 工单，生成专业的发布说明——可以直接发布。

以下是使用 Claude 与已连接工具的一些方式：

* **更快交付：** 把与 Claude 的讨论变成条理清晰的 Notion 路线图
* **创建设计：** 把创意简报转化为 Canva 社交媒体帖子
* **改进从设计到代码：** 把 Figma 文件转化为可上生产的代码
* **管理支付：** 访问 Stripe 客户数据和支付信息

### 开始使用

你可以在 [claude.ai/directory](http://claude.ai/directory) 浏览我们推荐的工具目录。点击“Connect”进行身份验证（桌面扩展则点击“Install”），Claude 就能访问你的工作上下文。你也可以在 [anthropic.com/partners/mcp](https://www.anthropic.com/partners/mcp) 浏览精选工具。

![Claude 应用中连接器对话框的截图，展示用户可以浏览并连接到 Claude 的各种工具和服务。](https://assets.claude.com/78b167a1a7db601cd0ff39356d03e9925e59baba.png)

该目录现已面向 web 和桌面端的所有 Claude 用户开放。本地桌面扩展可通过 Claude 桌面应用使用。连接远程应用和服务的连接器仅对付费套餐用户开放。
