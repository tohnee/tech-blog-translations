# GPT-Rosalind 新能力介绍

> 原文：[Introducing new capabilities to GPT‑Rosalind](https://openai.com/index/introducing-new-capabilities-to-gpt-rosalind/) · OpenAI 博客

我们为专为大规模企业级生命科学研究打造的 [GPT‑Rosalind](https://openai.com/rosalind/) 系列推出一次新的模型更新。它将 GPT‑5.5 的智能体编程与工具使用能力，与药物化学和基因组学等核心药物发现领域更强的模型智能结合在一起，同时在更广泛的生命科学分析、设计与实验工作流中提升性能。

生命科学的进步依赖于跨尺度、跨模态地综合数据与证据：分子、基因、通路和生命系统。在我们的评测中，更新后的 GPT‑Rosalind 在来自生物学专家的研究任务、复杂的药物化学查询、定量生物学以及湿实验室故障排查等任务上表现出广泛的性能提升。

GPT‑Rosalind 现已通过我们的可信访问部署结构，以研究预览形式面向全球符合条件的组织开放。

## 提升在具有科学价值的任务上的表现

为了衡量并持续改进 GPT‑Rosalind 的真实世界影响，我们设计了 LifeSciBench——一个由外部专家评审、聚焦生命科学研究基础层面的基准测试。现有的基准测试往往孤立地评估模型性能的单一组成部分或单一生物学领域，与之不同，LifeSciBench 从生命科学研究的六个核心工作流领域取材——证据处理、分析、设计与优化、科学推理、验证与运营、转化与沟通——以端到端的视角审视具有科学价值的工作。我们使用这个基准让模型进展与生命科学研究的需求和现实保持一致。

在由产业界与学术界专家识别出的、具有科学价值的任务上，GPT‑Rosalind 的表现领先。

从论文、图表、表格和实验记录中提取、核对并审计科学证据。

## 评测示例

我们正在为 AAV9-microDys-X 准备一次 FDA Type B 会议。AAV9-microDys-X 是一种基于 AAV9 的微肌营养不良蛋白（micro-dystrophin）基因疗法，用于治疗杜氏肌营养不良（Duchenne muscular dystrophy），由 MCK 启动子表达一个 138 kDa 的构建体。我们希望得到一份不留情面的批判性分析：我们目前的申报材料是否真的足以支持以微肌营养不良蛋白表达作为「合理可能预测临床获益」的替代终点来申请加速批准。

研究背景：开放标签的 1b/2 期试验，纳入 12 名 4–7 岁、确诊 DMD 且存在框外棒状结构域缺失、尚可行走的男孩。申报材料包括：

- 治疗前股外侧肌活检：采用针对 N 端肌动蛋白结合结构域的 MANEX1A 抗体进行定量 Western blot，微肌营养不良蛋白为健康对照的 0–3%。
- 治疗 12 周后对侧股外侧肌活检：使用同一 Western blot 方法（以考马斯亮蓝染色按总蛋白归一化），微肌营养不良蛋白平均为健康对照的 38%（范围 18–61%）。
- 治疗后免疫荧光：使用抗肌营养不良蛋白 C 端多克隆抗体，75–95% 的肌纤维出现肌膜信号。
- 48 周功能：NSAA 平均较基线变化 +1.4 分，而外部已发表的自然病程登记队列中为 −0.6（非配对 t 检验 p = 0.03）。
- 安全性：8/12 名患者出现一过性转氨酶升高，经类固醇减量方案处理；1 例心肌炎已痊愈；无死亡病例。
- 生物分布/持续性：12 周时肌肉中可检测到 AAV9 载体基因组，平均每个细胞核 2.3 个载体基因组。
- 入组标准：基线无抗 AAV9 中和抗体（滴度 <1:400），且无外显子 44 缺失。

请逐项对这份材料进行压力测试：FDA 或一位持怀疑态度的审评者会认为，就现有呈现方式而言，哪些证据不足以支持我们的结论？如有可能弥合这些缺口，还需要哪些额外的数据、分析或设计变更？对于任何未明确说明的内容，请假设截至 2025 年 12 月 31 日，来自其他临床级 138 kDa 微肌营养不良蛋白项目和相关临床试验的已知信息同样适用。

## 候选回答

**结论：** 就现有呈现方式而言，这份材料不足以支持以微肌营养不良蛋白表达作为「合理可能预测临床获益」的替代终点来获得加速批准。一位持怀疑态度的 FDA 审评者很可能会认为，生物标志物、功能、持久性、安全性和普遍适用性方面的证据都存在实质性支撑不足。

| 申报材料条目 | 关键失效模式 | 需要什么 |
|---|---|---|
| Western blot 定量 | MANEX1A 结合的 N 端表位为内源性全长肌营养不良蛋白与微肌营养不良蛋白转基因所共有，因此该检测无法干净地区分转基因产物与残留/回复突变（revertant）肌营养不良蛋白。以健康的全长肌营养不良蛋白作为标准品来定量 138 kDa 微肌营养不良蛋白同样不成立。 | 使用重组微肌营养不良蛋白标准品，并采用能区分转基因产物与内源性肌营养不良蛋白的正交方法，例如靶向质谱或转基因特异性/表位特异性检测。 |
| 免疫荧光 | C 端多克隆抗体并不适用，因为 138 kDa 构建体缺少 C 端结构域。许多 DMD 患者存在回复突变肌纤维，回复突变肌营养不良蛋白可能保留 C 端表位。回复突变肌纤维可能随年龄克隆性扩增，从而使免疫荧光信号产生偏倚，在年龄较大的男孩中尤其如此。 | 使用针对转基因中存在、而回复突变肌营养不良蛋白中不存在的表位的抗体重复免疫荧光实验。将转基因阳性纤维与回复突变纤维分开定量。 |
| 替代终点有效性 | 申报材料把蛋白量与临床功能混为一谈。「健康对照蛋白质量的 38%」并不意味着正常肌营养不良蛋白功能的 38%，因为微肌营养不良蛋白在结构上是截短的。 | 在把表达量当作替代终点之前，先以实证方式验证微肌营养不良蛋白质量百分比、肌膜定位、下游功能恢复与临床获益之间的关系。 |
| 活检设计 | 治疗前后的对侧股外侧肌活检引入了左右差异和肌肉内空间变异性。疾病进展和纤维脂肪替代也会改变经总蛋白归一化的信号。 | 使用一致的解剖学标志统一活检部位，改用肌肉特异蛋白进行归一化，并平行测量纤维脂肪组成。 |
| NSAA 对照组/统计 | 外部自然病程队列不是随机同期对照。试验入组标准、支持治疗、参与效应、基线 NSAA、类固醇方案、年龄和外显子类别都可能使该比较产生偏倚。非配对 t 检验并不充分。此外，+1.4 的 NSAA 变化在该年龄组的重测变异范围之内。 | 开展随机同期安慰剂对照研究，或至少采用对基线 NSAA、年龄、类固醇方案、外显子类别及其他混杂因素进行调整的分析。 |
| 年龄窗口混杂 | 4–7 岁的男孩正处于一个发育窗口期：未经治疗的可行走 DMD 患者在衰退占主导之前，运动功能可能仍在增强。48 周的 NSAA 变化混合了发育增益、疾病进展和可能的治疗效应。 | 采用带年龄分层的随机同期对照，把发育轨迹与治疗效应区分开来。 |
| 既往临床先例 | 开放标签的微肌营养不良蛋白功能信号并不能可靠地预示确证性获益；已发表的先例包括微肌营养不良蛋白基因疗法的确证性试验未能重现开放标签的 NSAA 改善。 | 不要把开放标签的 NSAA 变化当作决定性支持依据。要求提供受控的功能性证据。 |
| 构建体的结构性局限 | 138 kDa 构建体缺失了含有 nNOS 结合位点的血影蛋白重复序列 R16/17。nNOS 招募的缺失可能损害运动过程中的功能性交感舒张（functional sympatholysis）和缺血保护，从而形成与表达水平无关的机制性救治上限。 | 补充机制研究，说明这一特定构建体是否能恢复相关的肌营养不良蛋白关联复合物功能、nNOS 定位、运动生理与肌肉保护。 |
| AAV 持久性 | 12 周时的载体基因组并不能证明表达具有持久性。AAV9 基因组大多为非整合型游离体，可能随时间减少。载体基因组的存在不等于持续的蛋白表达。 | 测量 12 周以后的纵向转基因蛋白表达及功能性生物标志物的持久性。 |
| 免疫/安全性特征 | 8/12 患者出现转氨酶升高，与对 AAV 转导细胞的免疫应答一致，但机制尚未确立。鉴于 AAV9 对心脏的嗜性，1 例心肌炎值得警惕。 | 提供更深入的免疫监测、肝脏/心脏安全性表征，以及强化的心脏随访。 |
| 患者选择/普遍适用性 | 排除抗 AAV9 中和抗体阳性患者限制了普遍适用性；排除外显子 44 缺失限制了对该 DMD 亚组的适用性。n=12 的样本量过小，无法刻画更广泛 DMD 人群的安全性和有效性。 | 尽可能放宽入组标准，或在使用结果支持广泛批准之前，预先规定按抗体状态、基因型/外显子类别、年龄和基线功能进行的分层分析。 |

**监管结论：** 这份材料或许能显示生物活性，但尚未确立所测得的微肌营养不良蛋白表达是一个「合理可能预测临床获益」的可靠替代终点。主要缺口包括：检测特异性、无效的定量标准品、可能存在的回复突变纤维混杂、缺乏随机对照、年龄相关的 NSAA 混杂、持久性不确定，以及尚未解决的安全性与普遍适用性问题。

要弥合这些缺口，该项目需要一套受控的、经年龄分层的临床设计，并辅以转基因特异性表达检测、正交蛋白定量、组织组成控制、纵向持久性数据、针对截短构建体的机制性功能实验，以及更强的安全性监测——尤其是肝脏和心脏方面。

## 评分细则与评分

## 更强的科学推理

### 药物化学

GPT‑Rosalind 在药物化学领域取得业界领先的表现——药物化学是一门专注于把分子变成有用药物的学科。我们设计 MedChemBench 以反映真实的药物化学工作流，评估多模态化学结构理解、构效关系（SAR）、药物效价/毒性以及吸收、分布、代谢、排泄（ADME）预测、多参数先导化合物优化决策和逆合成分析。在 MedChemBench 上，GPT‑Rosalind 以 27.5% 对 25.1% 的成绩优于 GPT‑5.5，同时少用 7.2% 的 token。

GPT‑Rosalind 在药物化学中展现出更强的多模态合成与机理论证能力。

### 基因组学与定量生物学

在 GeneBench——我们针对基因组学与定量生物学长程端到端分析的智能体评测——上，GPT‑Rosalind 比 GPT‑5.5 少用 31% 的 token，同时取得更高的准确率：21.6% 对 20.4%。GeneBench 评估智能体在长程定量任务上的表现：基于真实的科学数据，智能体能否规划出有效的分析、质量控制（QC）、建模和校正，从而得到与决策相关的答案？收录的题目覆盖多个领域，包括功能基因组学、空间转录组学、蛋白质组学、表观基因组学和应用遗传学。

GPT‑Rosalind 比 GPT‑5.5 少用 31% 的 token，同时提升了准确率。

### 辅助真实世界的实验室工作

我们引入一个新的评测来检验 GPT‑Rosalind 帮助科学家开展真实世界实验室工作的能力。LabWorkBench 测试模型在科学家实际使用的湿实验室实验方案中，把扰动与实验结果关联起来的能力，用途涵盖从故障排查到方案优化。LabWorkBench 使用的数据为专有数据，因此不存在污染。GPT‑Rosalind 得分 63.2%，GPT‑5.5 为 55.8%，同时少用 5.3% 的 token。

在真实湿实验室实验方案辅助方面，GPT‑Rosalind 相较 GPT‑5.5 取得显著提升，同时改善了 token 效率。

## 从推理到可执行的工作流

我们构建了 [Life Sciences Research](https://github.com/openai/plugins/tree/main/plugins/life-science-research) 和 [Life Sciences NGS Analysis](https://github.com/openai/plugins/tree/main/plugins/ngs-analysis) 插件，为 [GPT‑Rosalind](https://openai.com/rosalind/) 增强的智能补上了一个面向可复用科学工作流的实用执行层。这两个插件共同把有据可查的证据检索、生物学解读和生物信息学执行带入同一个工作区，帮助研究者把外部证据与内部组学分析连接起来，同时保留产物与来源信息。现在所有用户都可以通过 Codex 访问这两个插件。符合条件的 GPT‑Rosalind 企业用户还可以使用 GPT‑Rosalind 来驱动这些插件。

为了更好地把 Codex 打造成科学家的动态工作台，我们为生物学原生文件类型添加了交互式查看器。首批序列、比对和结构查看器的设计目标，是让科学家在 GPT‑Rosalind 跨工作流推理的过程中始终贴近证据，并能利用当前活跃的查看器在上下文中直接回答后续问题。

上面的演示展示了这些能力在 GPT‑Rosalind 编排下的实际运作。我们跟随一位科学家研究一份液体肿瘤活检样本，以识别可能指导治疗的突变和其他分子变化。Life Sciences NGS Analysis 插件把处理过的 ctDNA 记录审查变成一个交互式笔记本，呈现出反复出现的变异、低频检出和样本演化轨迹，从而把调查聚焦到 KRAS G12C。在此基础上，Life Sciences Research 插件补充了有据可查的靶点、抑制剂和耐药性背景，而原生的序列、比对和结构查看器则让科学家能够直接查看突变位点第 12 位残基、它在 RAS 家族中的保守性，以及抑制剂结合口袋。工作流的最后一步是把证据转化为具体的后续选项，每一步及其产物都可供专家审阅。

Life Sciences NGS Analysis 插件

**scRNA-seq QC 与细胞注释**

把 10x 风格的矩阵文件包转化为经过 QC 过滤的单细胞产物、注释和 UMAP 图，你可以在 Codex 中查看和修改。Life Sciences NGS Analysis 插件会把请求路由到 scrna-seq-qc，根据数据选择 QC 阈值，保留过滤与注释相关的来源信息，并会提示诸如缺少双联体检测（doublet detection）依赖之类的阻塞项。

**Bulk RNA-seq FASTQ QC**

把 bulk RNA-seq 样本表、FASTQ 文件包和参考文件转化为经过 QC 审查的定量计数文件包，你可以在 Codex 中查看和复用。Life Sciences NGS Analysis 插件会路由请求、校验输入，并返回一个可审计的运行封装（run envelope），其中包含 MultiQC、Salmon 矩阵、来源信息和明确的注意事项。

我们将继续打造 [GPT‑Rosalind](https://openai.com/rosalind/)，使其成为覆盖科学研究全生命周期的更有能力的伙伴，帮助科学家更快地从正确的问题走向更清晰的证据、更好的实验，并最终走向患者的新疗法。
