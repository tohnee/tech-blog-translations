# Perplexity 放心地把端到端系统交给 GPT‑6 Astra

> 原文：[Perplexity trusts GPT‑6 Astra with end-to-end systems](https://openai.com/index/perplexity-improving-accuracy-with-astra/) · OpenAI 博客

作为一款 AI 驱动的答案引擎，Perplexity 高度专注于搜索和准确性。它处理海量信息的能力至关重要。联合创始人兼首席战略官 Johnny Ho 观察到，每当模型在编写代码方面变得更强，Perplexity 的搜索引擎也会随之进步。模型变得能够编写出更好的程序，去搜索网络和内部信息，并把内容总结得非常精炼。

但 Johnny 认为，真正的挑战在于把这些信息层面的能力应用到真实世界的系统上。而 GPT‑6 Astra 让这件事变得更容易了。

> 「我们可以让模型撰写通信内容、编辑真实世界的系统，并以前几代模型无法做到的方式监控我们的生产软件。」

## 让模型来做测试

对 Johnny 来说，AI 最有用的应用之一就是测试代码。由于手动测试的时间有限，他会让 GPT‑6 Astra 围绕一个应用程序构建一个小型测试程序。

模型会生成逼真的响应，就像另一个服务（例如语言模型 API 或连接器）会发来的那样。通过代替这些服务，模型可以检查应用程序如何响应，并对工作流进行从头到尾的测试。

> 「我们如今确实能把完整的端到端系统托付给它，而且与前几代模型相比，需要照看它的频率低得多。」
