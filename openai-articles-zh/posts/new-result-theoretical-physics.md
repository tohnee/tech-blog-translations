# GPT‑5.2 推导出理论物理中的一个新结果

> 原文：[GPT‑5.2 derives a new result in theoretical physics](https://openai.com/index/new-result-theoretical-physics/) · OpenAI 博客

我们发布了一篇新的预印本（preprint），表明一类许多物理学家原以为不会出现的粒子相互作用，实际上可以在特定条件下产生。这项工作聚焦于胶子（gluon）——传递强核力的粒子。该[预印本](https://arxiv.org/abs/2602.12176)已在 arXiv 上发布，并正在提交发表。在此期间，我们欢迎来自社区的反馈。

这篇题为「*Single-minus gluon tree amplitudes are nonzero*」的预印本由 Alfredo Guevara（Institute for Advanced Study）、Alex Lupsasca（Vanderbilt University 与 OpenAI）、David Skinner（University of Cambridge）与 Andrew Strominger（Harvard University）撰写，并由 Kevin Weil（OpenAI）代表 OpenAI 署名。

这篇预印本研究的是粒子物理学中一个核心概念：散射振幅（scattering amplitude）。散射振幅是物理学家用来计算粒子以特定方式相互作用之概率的量。对于胶子——传递强核力的粒子——许多振幅「在树图级」（tree level，即只保留没有量子圈的最简单图的计算）呈现出意想不到的简单形式。这些简化一再揭示出量子场论中更深层的结构；量子场论是提供一个把狭义相对论与量子力学统一起来的物理描述的框架。

然而，有一个情形通常被认为不存在（振幅为零）。当一个胶子具有负螺旋度（helicity，即无质量粒子可能具有的两种自旋取向之一），而其余 n−1 n-1 n−1 个胶子具有正螺旋度时，标准教科书论证表明相应的树图级振幅必为零。因此，这种构型大多被搁置一旁。

预印本表明这一结论过强。标准论证假定粒子动量是一般的（generic），即方向与能量不处于任何特殊的对齐状态。我们识别出动量空间中一个特定且精确定义的切片，在那里这一推理不再适用，即所谓半共线（half-collinear）区域。这里的半共线指胶子动量满足一个不典型、但在数学上有明确界定且自洽的对齐条件。在这个切片上，振幅并不为零，并且我们在一个特殊运动学区域中把它计算了出来。这一结果为许多新问题打开了大门，这些问题将成为后续研究的主题。重要的扩展包括计算引力子（graviton，传递引力的粒子）的类似振幅。

这项工作的一个核心方面关乎方法论。预印本中的最终公式——式 (39)——最初由 GPT‑5.2 Pro 猜想出来。人类作者用手工算出了整数 n n n 直到 n=6 n=6 n=6 的振幅，得到了非常复杂的表达式，展示于式 (29)--(32)，它们对应于一个「费曼图展开」，其复杂度随 n 呈超指数增长。GPT‑5.2 Pro 能够大幅降低这些表达式的复杂度，给出式 (35)--(38) 中简单得多的形式。从这些基础情形出发，它随后得以发现一个模式，并提出一个对所有 n n n 都成立的公式。

随后，一个经过脚手架（scaffold）搭建的 GPT‑5.2 内部版本花了约 12 个小时对该问题进行推理，得出了相同的公式，并给出了其有效性的正式证明。该方程随后被解析验证满足 Berends-Giele 递推关系——一种从更小的构件逐步构造多粒子树图振幅的标准方法。它还对照软定理（soft theorem）进行了检验，该定理约束振幅在某个粒子变软时的行为。

在 GPT‑5.2 的帮助下，这些振幅已经从胶子扩展到了引力子，其他推广也在路上。这些 AI 辅助取得的成果以及其他许多成果将在别处报道。
