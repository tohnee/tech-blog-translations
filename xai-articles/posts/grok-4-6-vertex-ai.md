# Grok 4.6 on Gemini Enterprise Agent Platform

Grok 4.6 is now available via Gemini Enterprise Agent Platform.

---

Today, we’re excited to announce that Grok 4.6 is now available on Gemini Enterprise Agent Platform.

Grok 4.6 is our latest flagship model, built for long-running agents and ambitious interactive and visual work. It offers a 500k context window and configurable reasoning efforts (low, medium, high, xhigh). Now, Gemini Enterprise Agent Platform users can use the model through [Model Garden](https://console.cloud.google.com/agent-platform/publishers/xai/model-garden/grok-4.6).

## [Capabilities & Pricing](#capabilities--pricing)

Grok 4.6 is available for:

- **Input**: $2 per 1 million tokens
- **Cached input**: $0.50 per 1 million tokens
- **Output**: $6 per 1 million tokens

For more on the model, read the [Grok 4.6 announcement](/news/grok-4-6).

## [Build with Grok 4.6 on Gemini Enterprise Agent Platform](#build-with-grok-46-on-gemini-enterprise-agent-platform)

Grok 4.6 is now available to developers in Model Garden. To get started, visit the [Grok 4.6 model card](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/partner-models/grok/grok-4-6). We're excited to see what you build!
