### [Getting started](#getting-started)

GitHub Copilot spans multiple products, including cloud agents, the Copilot CLI, and the VSCode IDE. From the model picker, simply pick "Grok 4.5" to start using our latest coding model. For some businesses and enterprises, you will need to enable the model from Copilot settings.
