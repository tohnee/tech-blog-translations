# Connect Grok to Hermes Agent

Use your Grok account and subscription inside Nous Research’s open-source, self-improving Hermes agent.

---

Starting today, you can use your Grok subscription directly inside Hermes Agent.

Hermes Agent is Nous Research’s open-source, self-improving agent. It runs persistently on any computer, sandbox, or VPS and creates long-term memory across sessions, learning as you use it. Like other open-source personal agents, Hermes can connect to WhatsApp, Discord, Telegram, Signal, or other messaging providers.

With your Grok subscription in Hermes, you can use:

- Grok 4.3 for text conversations and advanced reasoning
- Grok Text-to-Speech for spoken responses
- Grok Imagine for your agent to create images and videos

Connecting Grok to your Hermes agent is available on every tier.

### [Setup](#setup)

Install Hermes Agent:

bash

```
# Linux / macOS / WSL2 / Android (Termux)
curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh | bash
```

Pick the Grok provider:

bash

```
hermes model
```

Select **xAI Grok OAuth (SuperGrok Subscription)**, sign in through the browser, and start chatting:

bash

```
hermes --tui
```

For more, see the [Hermes Agent xAI Grok OAuth docs](https://hermes-agent.nousresearch.com/docs/guides/xai-grok-oauth).
