# Use Grok in OpenCode

Use your SuperGrok or X Premium subscription inside OpenCode.

---

You can now use your SuperGrok or X Premium subscription inside OpenCode. OpenCode is an open-source coding agent available in your terminal or as a standalone desktop app.

After connecting your Grok account, start coding with Grok Build, the same model that powers xAI's [terminal-based coding agent](https://x.ai/cli).

### [Setup](#setup)

Install OpenCode:

bash

```
curl -fsSL https://opencode.ai/install | bash
```

Run the guided onboarding:

bash

```
opencode
```

When prompted for a model provider, select xAI Grok OAuth, sign in, and start coding. For more, see the OpenCode docs.

More open-source agents and integrations are coming soon.
