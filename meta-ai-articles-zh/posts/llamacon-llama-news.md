# 首届 LlamaCon 发布的全部内容

> 原文：[Everything we announced at our first-ever LlamaCon](https://ai.meta.com/blog/llamacon-llama-news) · Meta AI（Wayback 存档）

要点：

- 我们在庆祝首届 LlamaCon 之际，分享一批激动人心的新工具，让基于 Llama 构建、创建贴合自身用例的定制模型变得更加容易。
- 以限量预览形式推出的 Llama API，结合了闭源模型的最佳特性与开源的灵活性，提供一键创建 API 密钥和交互式试验场，方便探索不同的 Llama 模型。
- 我们还分享新的 Llama 防护工具，并宣布 Llama 守卫者计划（Llama Defenders Program）——精选的受信任合作伙伴可以访问 AI 驱动的工具，帮助评估其系统的安全性，防范潜在威胁。

LlamaCon 正式开幕。我们的首届活动汇聚了来自世界各地的开发者，他们有一个共同点：热爱用 Llama 构建。自我们推出 Llama 已过去两年多。在此期间，我们的下载量突破十亿次，最重要的是，Llama 已确立其在开源 AI 生态中的领导地位。开发者、初创企业、政府和企业正借助 Llama 的能力驱动创新、提升效率、解决复杂问题并取得成功。当然，把一群开发者聚在一起，我们少不了要分享一些开源工具，让他们更轻松地探索 Llama 模型、更快地构建，并用上最新的防御与保护工具。以下是我们今天发布的内容以及如何上手我们的最新版本。

## 预览版 Llama API 登场：闭源模型 API 的最佳特性，加上开源的灵活性

我们希望让你更轻松地快速开始用 Llama 构建，同时让你完全掌控自己的模型和权重，不被 API 锁定。今天，我们宣布 Llama API——我们即将推出的 Llama 应用开发平台，现以限量免费预览形式提供。Llama API 提供一键创建 API 密钥和交互式试验场，可探索不同的 Llama 模型，包括我们本月早些时候发布的 Llama 4 Scout 和 Llama 4 Maverick。准备好构建应用时，我们提供 Python 和 Typescript 的轻量 SDK。Llama API 还与 OpenAI SDK 兼容，让现有应用的迁移轻而易举。

我们知道，能用到帮助你定制和更高效运行模型的工具同样重要。作为本次发布的一部分，我们在新 API 中提供微调与评估工具，你可以调校自己的 Llama 3.3 8B 定制版本。我们分享这一能力，是为了帮你降低成本，同时朝着更高速度与准确率努力。你可以生成数据、在其上训练，然后用我们的评估套件轻松测试新模型的质量。让评估更易得、更易运行，将帮助人们从直觉走向数据，确保拥有表现良好、满足需求的模型。

内容与数据的安全与隐私是我们的首要任务。我们不会用你的提示或模型响应来训练我们的 AI 模型。准备就绪后，你在 Llama API 上构建的模型归你所有，可以带到任何你想托管的地方——我们不会把它们锁在我们的服务器上。我们正在向精选客户开放这些功能，并计划在未来数周与数月更广泛地推出。这将为开发者构建面向各种用例的定制模型打开新的可能。此次预览只是 Llama API 的第一步。我们很高兴有更多人用我们的 API 构建，并将利用他们的反馈迭代未来版本。如果你有兴趣申请免费预览的早期限量名额，请填写此表单。

## Llama API 快速推理

我们高兴地宣布与 Cerebras 和 Groq 的合作，帮助更多 Llama 开发者通过 Llama API 获得更快的推理速度。由 Cerebras 和 Groq 驱动的 Llama 4 模型的早期实验性访问现已开放申请，为开发者提供了便捷的方式，在向所选供应商扩展之前先实验和原型化用例。只需在 API 中选择 Cerebras 或 Groq 的模型名称，开发者即可利用这一能力，享受所有用量统一记录的顺畅体验。这一合作强化了我们对培育多元生态、提供灵活性与选择权的承诺，我们期待与更多供应商扩展合作，为基于 Llama 的构建带来更多选项。

## 新的 Llama Stack 集成

我们从开发者那里听说，需要让使用不同服务商部署应用变得更简单。去年，我们与合作伙伴协作，为他们的下游企业客户构建 Llama Stack 发行版。今年，我们正在扩展这些合作，包括最近宣布的 Llama Stack 与 NVIDIA NeMo 微服务的集成，并与 IBM、Red Hat、Dell Technologies 等伙伴紧密合作，即将宣布新的集成。我们与合作伙伴一道，期望 Llama Stack 成为希望无缝部署生产级交钥匙 AI 解决方案的企业的行业标准。

## 面向开源社区的新 Llama 防护与安全

我们致力于为开发者提供构建安全 AI 应用的最佳工具与资源。今天，我们为开源社区发布新的 Llama 防护工具，包括 Llama Guard 4、LlamaFirewall 和 Llama Prompt Guard 2。我们还分享了帮助组织用 CyberSecEval 4 评估 AI 系统在安全运营中效用的更新，并宣布面向精选合作伙伴的 Llama 守卫者计划。随着更强大的 AI 模型不断涌现，我们相信这是提升软件系统鲁棒性的重要努力。阅读更多关于我们最新开源防护工具与 AI 安全进展的消息。

## 认识 Llama 影响力资助获得者

Llama 影响力资助旨在通过开源 AI 促进创新、创造经济机会。今天，我们高兴地宣布第二届 Llama 影响力资助的 10 个国际获得者。超过 150 万美元的资助将支持使用 Llama 推动变革性变革的公司、初创企业和大学。今年的获得者展示了多样的解决方案，包括来自美国的 E.E.R.S.——它用 Llama 驱动的聊天机器人增强公众对公共服务的获取；以及英国的 Doses AI——以实时错误检测变革药房运营。其他值得关注的获奖者包括为美国农村社区提供离线 AI 支持的 Solo Tech，以及帮助非洲等地数百万学生的多语言学习工具 FoondaMate。阅读更多关于 Llama 影响力资助获得者的信息。

## 未来属于开源

我们自豪地成为开源 AI 的领导者，并让 Llama 生态走在这一革命的前沿。有了 Llama，开发者与企业可以自由构建任何想要的东西，不受专有系统或锁定合同的束缚。这种灵活性，加上其可移植性与可及性，使 Llama 成为希望驾驭 AI 之力的人的首选。我们致力于成为企业与开发者的长期伙伴，提供从闭源模型的平滑迁移路径。Llama 价格实惠、易于使用，让更多人无论技术水平或硬件资源如何，都能获得 AI 的益处。我们相信 AI 有变革行业、改善生活的潜力，正因如此，我们满怀热情地继续支持 Llama 生态的成长与发展，造福所有人。我们迫不及待想看你接下来构建什么。
