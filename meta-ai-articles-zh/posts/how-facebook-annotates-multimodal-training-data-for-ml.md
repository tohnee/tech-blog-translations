# Facebook 如何为机器学习标注多模态训练数据

> 原文：[How Facebook annotates multimodal training data for ML](https://ai.facebook.com/blog/how-facebook-annotates-multimodal-training-data-for-ml) · Meta AI（Wayback 存档）

2019 年 5 月 31 日

我们构建了一个名为 Halo 的标注平台，让 Facebook 研究者能够更轻松、更高效地创建高质量训练数据。Halo 创建标注任务，然后在图像、音频、视频和 3D 等多种媒体类型上可视化相应数据。该平台新颖的可插拔架构通过配置表达端到端的标注流程，支持可在不同标注任务间复用的可替换组件。Halo 的目标是让 Facebook 研究者专注于训练 ML 模型——而不是构建标注工具。

许多机器学习（ML）应用的性能取决于底层模型可用训练数据的质量和数量。在 ML 中，创建并搭建标注训练数据的流水线是研究者工作流中不可或缺的一环。为了扩展这一流程，我们用 React 构建了一个新的基于配置的标注 UI 框架。它利用 SVG 分层把各种标注组件堆叠到单一平台中，让研究者可以快速即插即用地组合不同部件。我们把这一框架称为 Human-AI loop（Halo，人机回路）。研究者可以精简标注任务、可视化标注结果与精度指标，并导出标注以开始训练模型。

在 Facebook ML 发展的早期，研究者从零开始创建定制标注工具来完成临时任务。随着 ML 在各团队普及，我们需要一种可扩展的方式，为广泛的场景创建并标注训练数据。我们还希望找到一种方式，就任务创建和标注员管理与全组织的研究者分享最佳实践。所有这些考量促使我们构建一个统一平台来支持研究者，同时改进标注流程的每一步。用 Halo 标注的数据集训练的模型，正在为我们全家桶产品中的 AI 体验提供动力。

## 幕后：一个灵活的、基于配置的系统

我们最大的挑战是创建一个既支持种类繁多的任务、又可维护可扩展的平台。这些任务可以是以下要素的任意组合：

- **媒体类型**：音频、视频、图像和 3D，包括每个任务中多种媒体类型的组合；
- **标注类型**：边界框、像素级分割、转写文本等及其组合；
- **队列管理**：通过为任务到标注员提供不同的分配算法来执行，包括把同一任务发给多名标注员并测量标注者间一致性的能力；
- **自定义指标框架**：可以接受金标准（gold standard）标注并计算特定任务的质量指标。

这种对可配置性的需求，促使我们创建了一种通过单一基于 JSON 的标注配置来表达整个标注流程的架构——从创建新任务到生成最终分析报告。我们还通过设置经过充分测试和研究的默认值，把最佳实践集成到平台中。例如，我们以不同比率自动注入金标准数据，并在分析报告中实现一套标准化的任务特定精度指标。

要使用 Halo，研究者先提交一份提案，阐明项目细节、数据用途以及在 Facebook 内的更广泛背景。需要人工标注环节的项目，首先要接受跨职能隐私团队的风险评估。他们会向人工标注员提供一套标准化的准则或说明，这些准则经过精心设计以减轻偏见、保护隐私并确保客观性。这些准则用于创建标注流程每一步所需的数据。

研究者按以下步骤走完 Halo 流程。研究者通过内部数据库查询或我们的 API 把数据上传到系统中。给定一个查询，Halo 可以并行分块处理数据，并把每一行排入一个独立的标注任务。数据加载到中间存储后，研究者使用 UI 构建器定义标注工具的行为。这个基于 React 的 UI 平台读取配置，然后利用 SVG 的元素渲染顺序对各组件分层。这一概念类似于广泛使用的照片编辑或演示软件的做法——每一层代表图像的一部分。不过在 Halo 的 UI 平台中，每一层都有自己的功能。例如，在下面的示例动图中，图像层负责渲染原始图像，另一个独立的层负责渲染边界框。UI 平台把其他核心工具功能分离到不同层中——例如，单独一层可以渲染鼠标十字线或在悬停时显示工具提示。这些层中的每一层都可以处理多种媒体类型。有了这种设计，添加新功能就像添加一个新层一样简单。事实上，多个研究团队已经向我们 的组件库贡献了自己的层，扩大了 Halo 支持的用例范围，也放大了平台的价值。

与任何支持组件生态贡献的平台一样，我们需要一套通信协议，让每个组件既能独立存在，又能组合到同一个工具中。UI 平台使用 Undux 做状态管理，用 React Hooks 封装，并通过 Flow 做静态类型检查。由于渲染和数据管理由 UI 平台处理，每个组件自动享有核心功能，包括撤销和重做、本地存储缓存，以及各种渲染性能优化。

下一步是设置指标，用于理解数据标注完成后的输出质量。鉴于 Facebook 需要的标注类型和方法范围极广，我们创建了一个指标框架，允许研究者用 Hack 编写自己的自定义函数。它读取同一份 JSON 配置来参数化指标计算的某些阈值。Halo 在提供的金标准数据集上支持多种标准指标——从图像分割的 IoU，到音频转写的 WER，再到文本翻译的 BLEU 分数。

由于 Halo 完全由配置驱动，任务可以直接在平台 UI 中实时更改和测试，无需改动代码。所有更改都有版本记录，参数在标注过程中易于修改。例如，研究者可以在标注中途更新质量指标，重新配置后，指标会自动回填到一个新版本。

至此任务就绪，底层任务被设置并分发给标注员。在标注过程中的任何时候，研究者都可以访问单独的管理员 UI，以只读模式可视化结果。对于有金标准数据集的任务，我们会叠加这些任务以便于审计，并为指标提供相应的可视化。研究者还可以通过把输出串联到另一个任务来进一步迭代，从而创建出精密的标注任务 DAG（有向无环图）。例如，边界框标注的结果可以被裁剪，然后通过程序送去做关键点标注。

## Halo 实战

**视频音频转写。**在一个案例中，Facebook 的研究者使用标准视频播放器和单一文本框，转写一组公开视频中所有可听懂的音频，目标是训练和评估用于实时字幕及其他下游应用的自动语音识别（ASR）模型。标注员观看完整视频，转写有人说话的部分。借助 Halo，团队通过 Halo API 以程序化方式创建标注员任务，每个任务包含用语音活动检测（VAD）模型生成的视频片段。这个可直接投入生产的工具在三天内完成，把每个视频的平均标注时间减少了 32%。因此，转写过程对标注员而言轻松了许多，因为他们可以直接跳到视频中有人说话的片段。

**检测图像中的有害文字。**使用 Halo 的核心团队之一专注于 Rosetta——一个检测并识别图像和视频等视觉媒体中文字的 Facebook 工具。该团队标注了数十万张图像，为十几种语言的文本生成了数百万个边界框。相应训练模型的输出随后作为一个信号，服务于一个主动保护人们免受有害内容（如包含仇恨言论的帖子）侵害的元分类器。

**自动生成图像描述。**可扩展的标注还帮助我们构建了 Facebook 核心应用中的自动替代文本（Automatic Alt Text，AAT）。该技术为照片生成文本描述，帮助视障人士。有了 AAT，人们可以用屏幕阅读器听到图像内容的描述。我们用 Halo 对分类模型生成的类别做后处理。为 AAT 模型创建这些标注数据，有助于让 Facebook 更具可访问性。

## 接下来是什么

研究者在开始训练模型之前，要把大量时间花在处理数据上。标注始终是驱动 ML 应用的关键一环，我们将继续为 Halo 增加基础标注组件。其中一个开发方向是利用我们在训练深度学习模型方面的专长，构建交互式标注工具。例如，GrabCut 式引导分割的新进展可以帮助提升端到端标注效率。构建这个平台也让我们有机会学习和自动化研究者在部署模型之前要经历的其他常见步骤。例如，我们注意到研究者在 Halo 之上构建主动学习回路，以帮助选择合适的标注数据点来改进模型，于是我们构建了标准化工作流，把这类常规流程打包进平台。所有这些改进都是为了精简数据准备，并最终把我们的创新从研究快速带到生产。
