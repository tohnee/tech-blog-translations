# 埃森哲基于 Llama 构建

> 原文：[accenture-built-with-llama](https://ai.meta.com/blog/accenture-built-with-llama) · Meta AI（Wayback 存档）

## 构建基于 Llama 的聊天机器人，吸引某政府间组织的利益相关方

当一家全球领先的政府间组织寻求一个聊天机器人，以加深利益相关方对其可持续发展目标（SDG）的参与时，合作伙伴埃森哲（Accenture）选择了 Llama，用于该组织首个大规模、面向公众的生成式 AI 应用。这个聊天机器人最初是一个概念验证（POC），旨在服务从政策专家到普通公众的各类群体，在该计划卷帙浩繁的资料中提供易于获取的信息和参与机会。投入生产后，它将让企业与政府领导者、政策制定者、教育工作者、学生、媒体和普通市民得以了解 SDG、其实施进展，以及参与和更深入介入的方式。

该组织发布的内容范围很广——从报告和工作论文到政策简报等。这些材料目前分布在其各个渠道和网站上。许多报告长达数百页，包含一般受众难以理解的内容。聊天机器人可以快速高效地提供与查询相关的出版物的摘要和要点，让更广泛的受众更容易理解。

「要在 2030 年时间表内实现该计划的目标，需要全世界共同努力和创新思维，」埃森哲首席 AI 官（Chief AI Officer）Lan Guan 说，「利用有前景的技术来吸引跨部门利益相关方、支持大规模协作，对这项工作至关重要。」

该聊天机器人基于 Llama 3.1 构建，在 AWS 上运行，并在定制和推理阶段使用多种工具和服务以确保可扩展性和稳健性。训练中使用了该组织出版物的特定内容，以提升政策建议和摘要的相关性。团队集成了 Llama Guard 来识别和处理超范围问题。聊天机器人采用检索增强生成（RAG）工作流，使回答立足于该计划的内容之上，从而支持内容摘要和查询。该大语言模型可以通过整合从该组织数据源摄取的信息来生成内容，在回答中呈现相关报告链接，并引导用户访问该组织网站以深入学习。

该组织「在支持这一计划的目标方面发挥着多方面作用，包括提升意识、报告进展以及促成伙伴关系与协作」，Guan 说，「聊天机器人使其能够围绕相关的最新内容有效吸引广泛的利益相关方，并突出协作机会，从而支撑其在推广这项工作中的整体战略角色。」

## 选择 Llama 与开源

她表示，除了性能与安全性之外，埃森哲选择 Llama 还因为团队在 POC 中使用的云平台可以直接使用它，以及它的多语言能力。采用开源 LLM 也与客户的目标契合，即推动机会、创新和技术的公平可及，支持所有国家的发展。

为了解决基础设施成本以及使用最大的 Llama 模型——Llama 3.1 405B——带来的一些不稳定性，团队对架构做了调整，以在将成本保持在可控范围内的同时容纳这个大模型，作为临时方案。下一阶段将评估更小的 Llama 模型的输出，并探索对较小版本进行微调，在保持聊天机器人高可用性的同时获得可比的质量和安全性输出。

团队还计划扩展该用例，纳入与该计划相关的活动信息。计划还要求从英语扩展到支持六种语言（英语、法语、西班牙语、中文、阿拉伯语和俄语）。展望更远，随着 Llama 的发展与壮大，Guan 表示团队期待构建一个多模态聊天机器人，让客户的利益相关方能够有效互动各种非文本内容，包括视频、图形和结构化数据。
