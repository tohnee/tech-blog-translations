# 介绍 Llama 3.1：我们迄今最强大的模型

> 原文：[Introducing Llama 3.1: Our most capable models to date](https://ai.meta.com/blog/meta-llama-3-1) · Meta AI（Wayback 存档）

**要点**

- Meta 致力于开放可及的 AI。请阅读 Mark Zuckerberg 的公开信，详述为什么开源对开发者有利、对 Meta 有利、对世界有利。
- 为了把开放智能带给所有人，我们的最新模型将上下文长度扩展到 128K，新增八种语言的支持，并包含 Llama 3.1 405B——首个前沿水平的开源 AI 模型。
- Llama 3.1 405B 独树一帜，拥有无与伦比的灵活性、控制力和媲美最佳闭源模型的最先进能力。
- 我们的新模型将使社区能够解锁新的工作流，例如合成数据生成和模型蒸馏。
- 我们正在持续把 Llama 打造为一个系统，提供更多可与模型配合使用的组件，包括一个参考系统。我们希望用工具赋能开发者，创造他们自己的定制智能体和新型智能体（agentic）行为。
- 我们正在用新的安全工具（包括 Llama Guard 3 和 Prompt Guard）予以强化，帮助负责任地构建。
- 我们还就 Llama Stack API 发布了征求意见稿，这是我们希望让第三方项目更便捷地利用 Llama 模型的标准接口。
- 生态系统已准备就绪，超过 25 家合作伙伴——包括 AWS、NVIDIA、Databricks、Groq、Dell、Azure 和 Google Cloud——在发布首日即提供服务。
- 在美国，你可以在 WhatsApp 和 meta.ai 上试用 Llama 3.1 405B，问它一个有挑战的数学或编程问题。

在今天之前，开源大语言模型在能力和性能上大多落后于闭源模型。现在，我们正开启一个由开源引领的新时代。我们公开发布 Meta Llama 3.1 405B，我们相信这是世界上最大、最强大的公开可用基础模型。迄今为止所有版本的 Llama 累计下载量已超过 3 亿次，而这仅仅是开始。

## 认识 Llama 3.1

Llama 3.1 405B 是首个在通用知识、可控性、数学、工具使用和多语言翻译等最先进能力上媲美顶级 AI 模型的公开可用模型。随着 405B 模型的发布，我们将为创新按下加速键——带来前所未有的成长与探索机遇。我们相信，最新一代 Llama 将点燃新的应用和建模范式，包括用于改进和训练更小模型的合成数据生成，以及模型蒸馏——这一能力在开源领域从未在此规模上实现过。作为本次最新发布的一部分，我们推出了升级版的 8B 和 70B 模型。它们支持多语言，上下文长度大幅延长至 128K，具备最先进的工具使用能力和整体更强的推理能力。这使我们的最新模型能够支持高级用例，例如长文本摘要、多语言对话智能体和编程助手。我们还修改了许可证，允许开发者使用 Llama 模型（包括 405B）的输出来改进其他模型。

秉承我们对开源的承诺，从今天起，这些模型可在 llama.meta.com 和 Hugging Face 供社区下载，并可在我们广泛的合作伙伴平台生态中立即开始开发。

## 模型评测

在本次发布中，我们在超过 150 个基准数据集上评估了性能，覆盖广泛的语言范围。此外，我们还进行了大量人工评估，在真实场景中将 Llama 3.1 与竞争模型进行比较。我们的实验评估表明，我们的旗舰模型在一系列任务上与领先的基础模型——包括 GPT-4、GPT-4o 和 Claude 3.5 Sonnet——具有竞争力。此外，我们的小模型与参数量相近的闭源和开源模型相比也具有竞争力。

## 模型架构

作为我们迄今最大的模型，在超过 15 万亿 token 上训练 Llama 3.1 405B 是一项重大挑战。为了在这样的规模上进行训练并在合理时间内取得现有成果，我们大幅优化了整个训练栈，将模型训练扩展到超过 1.6 万块 H100 GPU，使 405B 成为首个在此规模上训练的 Llama 模型。为此，我们做出的设计选择聚焦于让模型开发过程可扩展且直接了当。我们选择了经过少量调整的标准 decoder-only transformer 架构，而非专家混合（MoE）模型，以最大化训练稳定性。我们采用迭代式后训练流程，每轮都使用监督微调和直接偏好优化（DPO）。这使我们能够为每一轮创建最高质量的合成数据，并提升每项能力的性能。

与之前版本的 Llama 相比，我们改进了用于预训练和后训练的数据的数量与质量。这些改进包括为预训练数据开发更细致的预处理与整理流水线，为后训练数据开发更严格的质量保证和过滤方法。正如语言模型扩展定律所预期，我们的新旗舰模型超越了用同一流程训练的较小模型。我们还用 405B 参数模型改进了较小模型的后训练质量。为了支持 405B 这一规模模型的大规模生产推理，我们将模型从 16 位（BF16）量化到 8 位（FP8）数值，有效降低了所需算力，使模型能在单个服务器节点内运行。

## 指令与对话微调

对于 Llama 3.1 405B，我们致力于提升模型回应用户指令时的有用性、质量和细致的指令遵循能力，同时确保高水准的安全性。我们最大的挑战在于支持更多能力、128K 上下文窗口以及增大的模型尺寸。在后训练中，我们在预训练模型之上进行若干轮对齐，产出最终的对话模型。每轮包括监督微调（SFT）、拒绝采样（RS）和直接偏好优化（DPO）。我们使用合成数据生成来产出绝大多数 SFT 示例，并多轮迭代，在所有能力上产出质量越来越高的合成数据。此外，我们投入多种数据处理技术，将合成数据过滤到最高质量。这使我们能够扩展各能力上的微调数据量。我们谨慎地平衡数据，以产出一款在所有能力上都高质量、均衡的模型。例如，即便扩展到 128K 上下文，我们也保持在短上下文基准上的模型质量；同样，即便加入安全缓解措施，我们的模型仍持续提供尽可能有用的回答。

## Llama 系统

Llama 模型从设计之初就作为整体系统的一部分工作，该系统可以编排多个组件，包括调用外部工具。我们的愿景是超越基础模型本身，让开发者获得一个更完整的系统，赋予他们设计和创建符合自身愿景的定制产品的灵活性。这一思路始于去年我们首次引入核心 LLM 之外的组件。作为我们在模型层之外负责任地开发 AI 并帮助他人同样行事的持续努力的一部分，我们发布了一个完整的参考系统，包含多个示例应用，并纳入了新组件，如多语言安全模型 Llama Guard 3 和提示注入过滤器 Prompt Guard。这些示例应用是开源的，社区可以在此基础上构建。

Llama 系统愿景中各组件的实现目前仍是碎片化的。因此，我们已开始与业界、初创公司和更广泛的社区合作，帮助更好地定义这些组件的接口。为此，我们在 GitHub 上就我们所说的「Llama Stack」发布了征求意见稿。Llama Stack 是一套标准化且带有明确倾向的接口，用于构建规范化工具链组件（微调、合成数据生成）和智能体应用。我们希望它们能在整个生态中被采用，从而帮助实现更轻松的互操作性。我们欢迎对提案的反馈与改进建议。我们很高兴能发展围绕 Llama 的生态系统，为开发者和平台提供商降低门槛。

## 开放驱动创新

与闭源模型不同，Llama 模型权重可供下载。开发者可以完全按自己的需求和应用定制模型，在新数据集上训练，并进行额外微调。这使更广泛的开发者社区和全世界能更充分地释放生成式 AI 的力量。开发者可以完全针对自己的应用进行定制，并在任何环境中运行——包括本地部署、云端，甚至在笔记本电脑上本地运行——全程无需与 Meta 共享数据。虽然很多人可能会说闭源模型更具成本效益，但根据 Artificial Analysis 的测试，Llama 模型提供了业界最低的每 token 成本之一。而且正如 Mark Zuckerberg 所指出的，开源将确保全世界更多人能获得 AI 的益处与机遇，确保权力不会集中在少数人手中，确保这项技术能在全社会更均衡、更安全地部署。这就是我们继续沿着让开放获取 AI 成为行业标准这条路迈进的原因。

我们已经看到社区用过去的 Llama 模型构建了惊人的东西：一个用 Llama 构建并部署在 WhatsApp 和 Messenger 中的 AI 学习伙伴；一个专为医疗领域定制、帮助指导临床决策的 LLM；还有一家巴西的医疗健康非营利初创公司，让医疗系统更容易以数据安全的方式组织和沟通患者的住院信息。我们迫不及待想看到他们借助开源的力量用我们的最新模型构建出什么。

## 用 Llama 3.1 405B 构建

对普通开发者而言，使用 405B 这一规模的模型颇有挑战。虽然它是一款极其强大的模型，我们认识到使用它需要可观的算力资源和专业能力。我们与社区交流过，也深知生成式 AI 开发远不止给模型写提示词。我们希望每个人都能充分发挥 405B 的价值，包括：

- 实时和批量推理
- 监督微调
- 针对特定应用评估你的模型
- 持续预训练
- 检索增强生成（RAG）
- 函数调用
- 合成数据生成

这正是 Llama 生态系统可以帮上忙的地方。从第一天起，开发者就能利用 405B 模型的全部高级能力并立即开始构建。开发者还可以探索高级工作流，比如易于使用的合成数据生成、按照开箱即用的指引进行模型蒸馏，以及通过 AWS、NVIDIA 和 Databricks 等合作伙伴的方案实现无缝 RAG。此外，Groq 已为云端部署优化了低延迟推理，Dell 也为本地系统实现了类似优化。我们与 vLLM、TensorRT 和 PyTorch 等关键社区项目合作，从第一天起就内置了支持，确保社区为生产部署做好准备。我们希望 405B 的发布还能激励更广泛社区的创新，让这一规模模型的推理和微调变得更容易，并开启模型蒸馏的下一波研究。
