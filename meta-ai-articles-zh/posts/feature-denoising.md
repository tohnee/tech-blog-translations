# 新的特征级去噪模型提升对抗鲁棒性

> 原文：[New feature-level denoising model improves adversarial robustness](https://ai.facebook.com/blog/feature-denoising) · Meta AI（Wayback 存档）

**研究内容：**一种在特征层使用图像去噪来推进对抗鲁棒性技术水平的新网络架构。虽然对抗扰动在像素空间中很小，我们发现它们也会在网络的特征图中造成显著「噪声」。因此，我们提出一种新方法，其中包含用非局部均值或类似双边滤波器的其他滤波器为特征去噪的块。与大规模对抗训练相结合时，我们的特征去噪网络改进了对抗鲁棒性的最先进水平。为让你对性能提升有个概念：我们的方法在 ImageNet 白盒攻击下达到 55.7% 的精度，而此前最先进水平为 27.9%。此外，我们提交到 2018 年对抗攻击与防御竞赛（CAAD）的作品令人信服地赢得了该竞赛，取得 50.6% 的精度，超过第二名约 10%。

**工作原理：**我们在卷积网络的中间层加入去噪块。去噪块旨在减少特征噪声——这种噪声只在分类对抗图像时出现。我们在去噪块中试验了四种不同的操作：非局部均值、双边滤波器、均值滤波器与中值滤波器，从视觉上看它们都能减少特征图中的噪声。去噪块与网络所有层使用对抗训练端到端联合训练。由于对抗训练的计算成本很高，大规模对抗训练系统对成功同样重要。我们在 ImageNet 分类数据集（约 128 万张图像、1000 个类别）上训练并评估了方法。

**为什么重要：**针对图像分类系统的对抗攻击是对图像的微小扰动，可能导致这些系统做出错误预测。这些扰动或者无法察觉，或者被人视为不可辨识的噪声。在训练中提升对抗鲁棒性，是防御卷积网络现实应用中漏洞的重要一步。一个例子是人们篡改违反我们政策的图像，使其躲过我们的检测工具。我们的特征级去噪模型在白盒与黑盒两种设置下都提升了图像分类的精度。我们已在 GitHub 发布训练系统与鲁棒模型，以促进未来研究。
