# 初窥 Meta Llama 3 的早期影响

> 原文：[A look at the early impact of Meta Llama 3](https://ai.meta.com/blog/meta-llama-3-update) · Meta AI（Wayback 存档）

我们把 Meta Llama 3 交到开发者社区手中才一周，反响已经非常热烈。随着最初几款 Llama 3 模型的发布，我们希望在整个技术栈上掀起 AI 创新的下一波浪潮——从应用、开发者工具、评测到推理优化等等，而我们已经看到了了不起的成果。从把 Llama 3 上下文窗口翻倍的项目，到量化、网页导航、工具使用、低精度微调、本地部署等各方面工作，社区的反馈极为热烈。

自上周四发布以来，模型的下载量已超过 120 万次，开发者在 Hugging Face 上分享了超过 600 个衍生模型。Llama 3 的 GitHub 仓库已突破 17000 颗星，Llama 3 70B Instruct 在 LMSYS Chatbot Arena 排行榜的纯英语评测中并列第一，总榜排名第六，是排名最高的公开可用模型，仅次于闭源专有模型。

我们在芯片、硬件和云服务方面的合作伙伴已开始向其用户部署 Llama 3，我们也看到社区迅速针对各自需求微调 Llama 3。例如，在耶鲁医学院，团队与洛桑联邦理工学院计算机与通信科学学院合作，在发布后 24 小时内就完成了 Meta Llama 3 的微调，推出 Llama-3[8B]-MeditronV1.0——首个面向医学微调的 Llama 3 8B。这个新模型在 MedQA、MedMCQA 等标准基准上超越了其参数量级内所有最先进的开放模型。关于耶鲁和 EPFL 如何在 Llama 2 之上构建第一版 Meditron，可在此阅读更多。

正如我们在发布时所说，这只是 Llama 3 的开始。未来几个月，我们将发布具备新能力的模型，包括多模态、多语言对话能力、更长的上下文窗口以及更强的整体能力。我们很高兴很快分享更多，并见证社区驱动的下一波创新。
