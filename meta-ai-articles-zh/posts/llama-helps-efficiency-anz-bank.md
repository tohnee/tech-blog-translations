# Llama 如何助力澳大利亚大型银行提升工程效率

> 原文：[How Llama helps drive engineering efficiency at a major Australian bank](https://ai.meta.com/blog/llama-helps-efficiency-anz-bank) · Meta AI（Wayback 存档）

金融机构要采用快速发展的数字化解决方案并非易事。基于 Llama 构建为澳大利亚四大银行之一的 ANZ 带来了提升效率的契机。ANZ 希望为其 Ensayo AI 平台精简工程工作流——该平台旨在加速软件交付、促进技术部门的知识共享。银行需要能改善业务与技术团队协作、并自动化重复性软件开发任务的技术。「Llama 以其灵活的部署选项脱颖而出，让 ANZ 可以在本地与云平台之间选择，以契合政策要求，」ANZ 的 Rico Zhang 说，「这种灵活性在金融服务业至关重要——数据安全与合规没有商量余地。」使用 Llama 这样的开源模型以及配套开发与调试工具，使银行在保持运营效率的同时守住合规。

## 基于每个新版 Llama 构建

自 ANZ 采用最早版本的 Llama 处理基础的提示-响应任务以来，其对 Llama 的使用已显著演进——那些早期任务让团队得以在 Ensayo AI 软件交付加速平台的语境下理解模型的优势与局限。随着时间推移，Llama 已深度集成进 Ensayo AI 框架，从通用助手进化为专用的知识驱动系统。随着 Llama 3 的发布，团队集成了检索增强生成（RAG）与智能体等高级特性。这一演进使 ANZ 得以建立更结构化的知识库，让 Ensayo AI 动态检索并呈现最相关的信息。

## 不打折扣地有效集成

在银行业，确保数据隐私与安全合规是头等大事。即便 Ensayo AI 不处理客户或生产数据，它仍必须满足严格的安全标准。ANZ 成立了专门的 AI 工作组、AI 用例指导委员会以及伦理与隐私审查职能，共同定义并执行安全协议、合规指南与伦理标准，以治理生成式 AI 的使用。团队实施了安全沙箱环境，并利用数据匿名化技术保护敏感信息。ANZ 与内外部利益相关者跨职能协作，使实施与相关政策对齐。

为针对 Ensayo AI 的特定需求微调 Llama，他们策展并准备了三个关键数据集：ANZ 系统 API 规范（Swagger）、ANZ 测试脚本数据集，以及 ANZ 业务服务与生产事件历史。微调目标是让 Llama 能够理解并推断 API 之间潜在的交互、预判对象与数据如何在 API 之间传递（即便上下文极少），并生成准确输出，如 API 测试用例、测试数据、时序图和全面的 API 知识。微调过程包括数据标注、监督微调和提示工程，以及迭代测试与改进。最终，微调后的 Llama 模型展现出更强的 API 理解力，生成准确率显著提升。它能在有限上下文下有效处理复杂工作流，使 Ensayo AI 交付精确、可执行的产出。

## 未来展望

「开源方式促进了创新、透明与协作，对我们组织产生了积极影响，」Zhang 说，「通过采用 Llama 这样的开源模型，我们获得了更好的版本控制和对 AI 解决方案的洞察。」虽然 Llama 3 8B 为满足眼前需求提供了微调方案，ANZ 计划在未来数月适配更大的 405B 模型——这需要与安全、风险和政策团队协作。展望未来，银行旨在利用多个 Llama 模型，包括为特定领域专家任务微调较小模型——这一策略让 ANZ 团队在交付专业能力的同时优化资源。「『越大越好』的信念在银行业并不总是成立，」Zhang 说，「随着我们迈向『AI 智能体驱动』的未来，专注特定领域的较小微调模型将扮演重要角色。Llama 的适应性使其非常适合开发具备领域专业知识的聚焦模型，高效满足关键需求。」
