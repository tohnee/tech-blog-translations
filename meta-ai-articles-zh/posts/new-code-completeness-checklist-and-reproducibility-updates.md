# 新的代码完整性清单与可复现性更新

> 原文：[New code completeness checklist and reproducibility updates](http://ai.facebook.com/blog/new-code-completeness-checklist-and-reproducibility-updates) · Meta AI（Wayback 存档）

科学是累积性的：进步取决于我们能否在他人的工作之上继续构建。这就是为什么可复现性对加速 AI 这类领域的进步至关重要。Papers with Code 是一个面向机器学习（ML）论文和代码的免费社区驱动资源，于去年 12 月加入 Facebook AI。今天，Papers with Code 推出「ML 代码完整性清单」（ML Code Completeness Checklist）。该清单的目标是增强可复现性，并提供一套急需的最佳实践与代码仓库评估标准，让用户可以在已发表工作的基础上继续构建。ML 代码完整性清单现已提供，并且是 NeurIPS 2020 官方代码提交流程的一部分。

Papers with Code 的这项工作建立在 Facebook AI 研究（FAIR）常务董事 Joelle Pineau 去年推出的「机器学习可复现性清单」之上。该清单是 NeurIPS 2019 论文提交流程的必备部分，也是该会议首届「可复现性挑战」的核心。NeurIPS 2019 录用的最终版论文中约 75% 附带代码，而前一年为 50%。作为挑战的一部分提交的论文有 173 篇，比 ICLR 2019 类似挑战的提交量增长 92%。

阅读 Papers With Code 博客文章了解新清单的更多信息，并了解 NeurIPS 2020 可复现性计划。
