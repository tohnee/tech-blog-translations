# 用多任务学习改进组织病理学图像分类

> 原文：[Using multitask learning to improve image classification for histopathology](https://ai.meta.com/blog/using-multitask-learning-to-improve-image-classification-for-histopathology) · Meta AI（Wayback 存档）

5 月 4 日

**研究内容：** 一条基于卷积神经网络（CNN）的十亿像素级（gigapixel）组织病理学图像分类流水线。与当前大多数方法不同——它们通常需要专家为每个组织病理学分类任务做像素级标注——我们提出使用一个在多个组织病理学数据集和分类任务上以监督方式训练的编码器网络。我们的方法受病理学家工作流程的启发：在分析一个新的图像分类任务或数据集时，他们会把以往研究过的疾病中与分类相关的知识迁移过来。我们证明，通过利用四个组织病理学数据集，CNN 编码器学到的特征可以泛化到新数据集和新任务。我们在肿瘤增殖评估挑战赛（Tumor Proliferation Assessment Challenge）上取得了最先进的结果，在结直肠肝转移分类上取得了有竞争力的表现，并展示了辅助预测患者预后的潜力。

来自 Camelyon16 数据集的图像，展示带有小面积乳腺癌转移的淋巴结组织切片。图片由荷兰奈梅亨拉德堡德大学医学中心提供。

**工作原理：** 我们与拉德堡德大学医学中心（荷兰）和伊拉斯姆斯医学中心（荷兰）的合作者一起，提出利用多任务学习和迁移学习方法来缓解组织病理学图像中信噪比低的问题。在我们的方法中，我们利用为识别不同病理构建的四个组织病理学数据集，学习一个压缩的图像表示（编码器），它抑制低级像素噪声和虚假相关，同时识别并提取在多种下游任务中表现良好的可迁移特征。编码器一旦学成，任何组织病理学数据集都可以被编码，再用图像级标签训练一个分类器。

首先，我们使用多个组织病理学分类任务和多任务学习训练目标训练一个编码器（步骤 1）。嵌入函数学成后，我们可以编码任何组织病理学数据集，并为新的分类任务学习一个分类器（步骤 2）。

**为什么重要：** 组织病理学图像分类尤其困难，因为图像尺寸在百亿像素量级，而分类信号可能非常微弱（低信噪比图像分类场景）。例如，组织病理学图像呈现的样本可能包含数十万个细胞，而标签可能取决于单个肿瘤细胞的有无。对于每张图只有一个标签的十亿像素级组织病理学图像分类场景，理解并改进 CNN 的泛化能力十分重要。我们此前与拉德堡德大学医学中心和伦敦帝国理工学院（英国）合作开发了一个图像分类工具箱，可以在两个模拟数据集上以宽泛的信噪比谱系对 CNN 架构进行受控的压强测试。低信噪比图像分类是医学成像中非常普遍且重要的问题，其中常见的问题包括：图像中是否存在病变、疾病的分级如何、图像显示的是健康还是异常组织。收集大量像素级标注耗时费力，且需要大量领域专业知识。这常常造成医学成像数据集的瓶颈，限制数据集规模。一个成功且数据高效的低信噪比分类解决方案，有望通过减少标注所需的时间和资源来扩大数据集规模。这样的解决方案可以让那些没有像素级标注的应用实现图像自动分析，例如患者预后、癌症复发和治疗响应的预测。
