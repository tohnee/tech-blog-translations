# 推出 N-Bref：基于神经网络的反编译框架

> 原文：[Introducing N-Bref: a neural-based decompiler framework](https://ai.facebook.com/blog/introducing-n-bref-a-neural-based-decompiler-framework) · Meta AI（Wayback 存档）

**这项研究是什么：**反编译器把汇编指令这类低层可执行代码转换回 C++ 等更容易被人阅读的高级编程语言。它们可用于检测计算机安全漏洞与异常，也可用于取证。反编译器还能用来查找潜在病毒、调试程序、翻译过时代码、找回丢失的源代码等。传统上，反编译程序由人类专家凭启发式规则手工设计。也就是说，对每一对编程语言（如 C++ 与汇编），领域专家都要写下大量规则——这个过程可能耗时数年，在棘手情形下还需要格外小心地处理与调整。源语言的升级（例如从 C++03 升到 C++11）也会带来不小的维护工作。在这篇文章中，我们提出 N-Bref——一个基于神经网络的反编译框架，在传统反编译的既有系统之上提升了性能准确率。这是 FAIR（Meta 基础人工智能研究院）与 UCSD STABLE 实验室（由 Jishen Zhao 领导）的合作成果。N-Bref 将从数据集生成、神经网络训练到评估的整套设计流程完全自动化，无需人类工程师参与。它率先将最先进的神经网络（如神经机器翻译中使用的 Transformer）改造用于处理真实代码反编译任务中高度结构化的输入输出数据。N-Bref 可处理由生成的 C++ 程序编译得到的汇编代码——这些程序会常规性地调用标准库（如 `<string.h>`、`<math.h>`）——以及简单的、类似真实代码库的解决方案。

下表用两项指标比较了 N-Bref 与既有方法的准确率：(a) 类型恢复与 (b) AST 生成。Ins2AST 是我们此前不使用 Transformer 的神经程序反编译器；REWARD 是专家设计的类型恢复工具；Lang2logic 是一个序列到树的翻译器；我们还提供了 vanilla Transformer 基线。N-Bref 优于传统反编译器（如 REWARD [2]），在输入程序较长且控制流复杂时尤为明显；它也优于我们此前未使用 Transformer 的工作。值得注意的是，我们的系统能够反编译来自 C 标准库（如 `<math.h>`、`<string.h>`）的真实 C 代码，以及人类为解决真实问题而编写的基础代码库。我们的研究全面分析了神经反编译器设计中各个组件如何在不同数据集配置下影响程序恢复的总体准确率。

**工作原理：**我们首先把输入的汇编代码编码为图结构，以更好地表示不同指令之间的关系。然后使用现有的图嵌入工具（GraphSage [1]）编码该图结构，得到汇编代码的表示。为构建并迭代精炼编码代码高层语义的抽象语法树（AST），我们使用能处理高度结构化汇编代码的记忆增强 Transformer。最后，我们把 AST 转换为真正的高级语义语言（如 C）。为收集训练数据，我们还提供了一个工具，用于为神经反编译研究生成并统一高级编程语言的表示。

**为什么重要：**据我们所知，这是端到端可训练的代码反编译系统首次在 C++ 等被广泛使用的编程语言上表现相当出色。这一进展让该领域向能够在大规模代码库上运行的反编译系统又迈进了一步。我们的团队还开发了首个面向神经反编译器开发与测试的数据集生成工具，能生成接近人类程序员手写风格的代码。该工具同样适合开发基于学习的方法。代码与数据生成工具均已在 GitHub 开源。
