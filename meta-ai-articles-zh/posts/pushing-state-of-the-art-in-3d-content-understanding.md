# 推进 3D 内容理解的最先进水平

> 原文：[Pushing state-of-the-art in 3D content understanding](https://ai.meta.com/blog/pushing-state-of-the-art-in-3d-content-understanding) · Meta AI（Wayback 存档）

为了解读我们周围的世界，AI 系统必须理解三维视觉场景。这一需求超出了机器人、导航乃至增强现实应用的范围。即便是 2D 照片和视频，其中描绘的场景和物体本身就是三维的；真正智能的内容理解系统必须能够识别视频中旋转杯子的把手几何，或辨认照片中哪些物体在前景、哪些在背景。今天，我们分享 Facebook AI 若干新研究项目的细节，它们以不同而互补的方式推进 3D 图像理解的最先进水平。这些将在首尔举行的国际计算机视觉大会（ICCV）上展示的工作，应对了多种用例和情形，训练数据的类型、数量和输入各不相同。

- Mesh R-CNN 是一种新颖的最先进方法，可在广泛的真实世界 2D 图像中预测最精确的 3D 形状。该方法利用我们通用的物体实例分割框架 Mask R-CNN，甚至能检测复杂物体，如椅子腿或相互重叠的家具。
- 采用与 Mesh R-CNN 互补的另一路径（称为 C3DPO），我们通过解读 3D 几何，首次在三个基准上对超过 14 个物体类别成功实现了大规模非刚性形状 3D 重建，而且仅使用 2D 关键点、零 3D 标注。
- 我们提出了一种学习图像与 3D 形状关联的新方法，同时显著降低对标注训练样本的需求。这让我们更接近能为更多种类物体创建 3D 表示的自监督系统。
- 我们开发了一项名为 VoteNet 的新技术，在可从激光雷达（LIDAR）或其他传感器获得 3D 输入的情形下执行物体检测。该任务的大多数传统系统依赖 2D 图像信号，而我们的系统纯基于 3D 点云，取得了高于以往工作的精度。

这项研究建立在近期「用深度学习预测和定位图像中物体」的进展，以及体素、点云、网格等 3D 形状理解新工具和架构的基础上。计算机视觉领域覆盖广泛任务，而 3D 理解将在提升 AI 系统更贴近地理解、解读并运作于现实世界的能力方面扮演核心角色。

## 在预测无约束、被遮挡物体的 3D 形状上达到最先进水平

Mask R-CNN 这类感知系统是理解图像的强大通用工具。但由于它们在 2D 中做预测，忽略了世界的 3D 结构。利用 2D 感知的进展，我们设计了一个 3D 物体重建模型，可从具有各种光学挑战（包括遮挡、杂乱和多样拓扑结构物体）的无约束真实图像中预测 3D 物体形状。要在对此类复杂性鲁棒的物体检测系统中加入第三个维度，需要更强的工程能力，而现有工程框架阻碍了这一领域的进展。

（原文此处嵌入视频。Mesh R-CNN 接收输入图像，预测图像中的物体实例，并推断其 3D 形状。为捕捉几何和拓扑的多样性，它先预测粗糙体素，再细化为精确的网格预测。）

为应对这些挑战，我们为 Mask R-CNN 的 2D 物体分割系统增加了一个网格预测分支，并构建了 Torch3d——一个包含高度优化 3D 算子的 PyTorch 库来实现该系统。Mesh R-CNN 用 Mask R-CNN 检测并分类图像中的各种物体，然后用新颖的网格预测器推断 3D 形状——它采用「体素预测 + 网格细化」的混合方法。这一两步流程使我们在预测细粒度 3D 结构上取得了超越以往工作的结果。Torch3d 通过高效、灵活、模块化地实现复杂运算（如倒角距离、可微网格采样和可微渲染器）使这一切成为可能。我们用 Detectron2 实现了最终系统，以 RGB 图像为输入，既检测物体又预测 3D 形状。与 Mask R-CNN 用监督学习实现强 2D 感知类似，我们的新方法用图像-网格对的完全监督学习来学习 3D 预测。训练时我们使用 Pix3D 数据集——由 10,000 对图像和网格组成——明显小于通常包含数十万张图像和物体标注的 2D 基准。

我们在两个数据集上评估了 Mesh R-CNN，均取得强劲结果。在 Pix3D 数据集上，Mesh R-CNN 是首个能够联合检测所有类别物体、并在多样、杂乱、遮挡的家具场景中估计其完整 3D 形状的系统——以往工作聚焦于评估在完美裁剪、无遮挡图像片段上训练的模型。在 ShapeNet 数据集上，我们「体素预测+网格细化」的混合方法以 7% 的相对优势超越以往工作。

（原文此处嵌入视频。Mesh R-CNN 系统概览。我们在 Mask R-CNN 之上增加 3D 形状推断。）

准确预测和重建真实世界无约束场景的形状，是增强虚拟现实和其他形式的远程呈现等新体验的重要一步。不过，为 3D 图像收集标注数据比 2D 图像复杂耗时得多，这也是 3D 形状预测数据集落后于 2D 的原因。因此，我们正在探索结合监督与自监督学习来重建 3D 物体的不同方法。在此阅读 Mesh R-CNN 完整论文。

## 用 2D 关键点重建 3D 物体类别

对于没有网格及对应图像可供训练、也无需对静态物体或场景做完整重建的场景，我们开发了一种替代方法。我们的新系统 C3DPO（Canonical 3D Pose Networks）构建 3D 关键点模型的重建，并使用更广泛可得、更丰富的 2D 关键点监督取得了最先进的重建结果。C3DPO 帮助我们以适合大规模部署的弱监督方式理解物体的 3D 几何。

C3DPO 从检测到的 2D 关键点为一系列物体类别生成 3D 关键点，准确区分视角变化与形状形变。2D 关键点追踪物体类别的特定部位（如人体关节或鸟翼），提供了关于物体几何及其形变或视角变化的完整线索。所得 3D 关键点用途广泛，例如为 VR 中更逼真的虚拟形象图形建模 3D 面部和全身网格。与 Mesh R-CNN 类似，C3DPO 使用带遮挡和缺失值的无约束图像重建 3D 物体。C3DPO 是首个能够重建由数十万张图像、数千个 2D 关键点组成的数据集的方法。我们在三个不同数据集、超过 14 个多样非刚性物体类别上取得了最先进的重建精度。我们已在 此处 公开这项工作的代码。

我们的模型有两项重要创新。第一，给定一组单目 2D 关键点，我们的新 3D 重建网络预测相应相机视角的参数以及规范朝向下的 3D 关键点位置。第二，我们引入了一种称为规范化（canonicalization）的新正则化技术，由一个与 3D 重建网络共同学习的辅助深度网络构成。该技术解决了分解 3D 视角与形状带来的歧义。这两项创新使我们能够比传统方法更好地捕捉数据的统计模型。此类重建此前无法实现，主要因为以往基于矩阵分解的方法受内存限制——与我们的深度网络不同，它们无法在「小批量」模式下运行。以往方法通过利用多张同时拍摄的图像并在瞬时 3D 重建之间建立对应来建模形变，这需要大多只有专门实验室才有的硬件。C3DPO 带来的效率提升，使得在无法使用 3D 捕获硬件的场合（如飞机等大型物体）也能进行 3D 重建。在此阅读 C3DPO 完整论文。

## 从图像集合学习像素到表面的映射

（原文此处嵌入视频。我们的系统学习一个参数化卷积神经网络（CNN），以图像为输入，预测逐像素的规范表面映射，指示模板形状上对应的位置点。2D 图像与 3D 形状之间预测的规范表面映射颜色相似，暗示了对应关系。）

我们在降低为通用物体类别开发 3D 理解所需的监督方面又迈进一步。我们提出的方法可以利用带有近似自动实例分割的无标注图像集合。我们不显式预测图像背后的 3D 结构，而是 tackle 一个互补任务：把图像中的像素映射到 3D 形状的类别级模板表面。这一映射不仅让我们能在类别级 3D 形状的语境下理解图像，还赋予我们泛化同类或同类别物体之间对应关系的能力。例如，当人们看到左图中高亮的鸟喙时，可以轻松在右图图像中定位对应的点——这是因为我们直觉上理解这些实例共享的 3D 结构。我们「把图像像素映射到规范 3D 表面」的新方法让学习到的系统也具备这一能力。在通过衡量跨实例传递对应关系的准确率来评估我们的方法时，我们取得的结果大约是未利用任务底层 3D 结构的以往自监督方法的两倍。

我们的关键洞见——使学习所需的监督大幅减少——是：像素到 3D 表面的映射可以与其逆操作（从 3D 到像素）配对以构成一个循环。我们的新方法将其付诸实施，可以只用无标注的、免费的、公开可得的图像集合以及来自检测方法的近似分割进行学习。我们得到的系统可以开箱即用，与自顶向下的 3D 预测方法普遍配合，提供互补的逐像素 3D 理解，代码已在此发布。如上图中移动汽车颜色的一致性所示，我们的系统为运动和旋转中的物体产生不变的逐像素嵌入。这种一致性超越单个实例，在需要理解物体间共性的场景中很有用。我们不直接学习两张图像之间的 2D 到 2D 对应，而是学习 2D 到 3D 的对应，并用 3D 到 2D 的重投影确保一致性——这个一致的循环充当了学习 2D 到 3D 对应的监督信号。例如，如果我们训练系统学习椅子上该坐的位置或杯子的抓握处，我们的表示在系统下次需要理解坐在另一把椅子的哪里、或如何抓握另一个杯子时依然有用。这类任务不仅能加深我们对传统 2D 图像和视频内容的理解，还能通过迁移物体表示增强 AR/VR 体验。在此阅读关于规范表面映射的更多信息。

## 改进当前 3D 系统中物体检测的基本功

随着自主智能体和 3D 空间扫描系统等前沿技术持续进步，我们需要在 3D 数据 readily 可得时推进物体检测机制。在这些情形下，3D 场景理解系统需要知道场景中有什么物体、它们在哪里，以支撑导航等高层任务。我们改进了现有系统，构建了 VoteNet——一个为点云量身定制的高精度端到端 3D 物体检测网络，它被 ICCV 2019 提名为最佳论文奖。与依赖 2D 图像信号的该任务传统系统不同，我们的系统是最早纯基于 3D 点云的系统之一。这一方法更高效，识别精度远超以往工作。我们已在此开源的模型取得了最先进的 3D 检测结果：在 SUN RGB-D 和 ScanNet 上分别以至少 3.7 和 18.4 mAP（平均精度均值）的提升超越以往所有 3D 物体检测方法。VoteNet 仅使用几何信息就胜过以往方法，不依赖标准彩色图像。VoteNet 设计简单、模型紧凑、效率高——完整场景耗时约 100 毫秒，内存占用小于以往为研究设计的方法。

（我们的算法接收来自深度相机的 3D 点云，返回带语义类别的物体 3D 边界框。）

（点云 3D 物体检测 VoteNet 架构示意图。我们引入了受经典霍夫投票算法启发的投票机制。用这种方法，我们实质上生成靠近物体中心的新点，然后把这些点分组聚合以生成框提议。借助通过深度神经网络学习的投票基本思想，一组 3D 种子点向物体中心投票，以恢复它们在哪里、是什么。）

随着 3D 扫描仪在真实世界的使用增长——从自动驾驶汽车到生物医学应用已很常见——我们能够通过定位和分类 3D 场景中的物体来实现 3D 内容的语义理解变得很重要。用更先进的深度相机传感器补充 2D 相机进行 3D 识别，让我们能对任意给定场景捕捉更鲁棒的视角。有了 VoteNet，系统可以更好地识别场景中的主要物体，支撑放置虚拟物体、导航和 LiveMap 构建等任务。

## 开发对现实世界有更丰富理解的系统

3D 计算机视觉有许多开放的研究问题，我们正在试验多种问题表述、技术和监督方法，探索推进该领域的最佳方式——正如我们曾在 2D 理解上所做的那样。随着数字世界适应并转向 3D 照片和沉浸式 AR/VR 体验等产品，我们需要持续推动复杂系统更准确地理解视觉场景中的物体并与之交互。这也是 Facebook AI 长期目标的一部分：开发像人类一样理解和与现实世界交互的 AI 系统。我们一直在广泛的能力范围内创造科学突破，专注于缩小物理空间与虚拟空间的差距。我们最新的 3D 研究还可以帮助改进并充实 Facebook AI 仿真平台中的 3D 物体——这对训练虚拟智能体在现实世界运行很重要。正如机器人学促使我们应对在条件更不可预测的物理世界做实验带来的复杂挑战，3D 研究对于教会系统理解物体的所有视角很重要——即便它们被遮挡、隐藏或存在其他光学挑战。当与触觉感知和自然语言理解等其他感官结合时，虚拟助理等 AI 系统可以以更无缝、更有用的方式运作。总体而言，这些前沿研究帮助我们更进一步接近构建能像人类一样直觉理解三个维度的 AI 系统。

本博文所述研究论文将在 ICCV 2019 上展示，同期展示的还有计算机视觉其他新工作，包括：SlowFast——一种用两种不同帧率的输入从视频中提取信息的方法；TensorMask——一种使用稠密滑动窗口技术的物体分割替代方法。
