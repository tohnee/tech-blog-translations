# PyTorch3D：面向 3D 深度学习的开源库

> 原文：[Introducing PyTorch3D, an open-source library for 3D deep learning](https://ai.meta.com/blog/-introducing-pytorch3d-an-open-source-library-for-3d-deep-learning/) · Meta AI（Wayback 存档）

3D 理解在提升 AI 系统更好地理解现实世界并在其中运作的能力方面扮演着重要角色——包括机器人在物理空间中的导航、改进虚拟现实体验，甚至在 2D 内容中识别被遮挡的物体。但 3D 深度学习研究一直受限，原因在于缺乏足够的工具和资源来支撑神经网络处理 3D 数据的复杂性，而且许多传统图形算子是不可微分的。Facebook AI 构建并即将发布 PyTorch3D——一个高度模块化、经过优化的库，具备独特能力，旨在让用 PyTorch 做 3D 深度学习变得更加容易。PyTorch3D 提供了一组常用、快速且可微分的 3D 数据算子和损失函数，以及一个模块化的可微分渲染 API——让研究者能够立刻把这些函数导入当前最先进的深度学习系统。PyTorch3D 近期在 Facebook AI 构建 Mesh R-CNN 的工作中发挥了催化剂作用，该工作从复杂室内空间的图像中实现了完整的 3D 物体重建。我们将 PyTorch3D 与我们高度优化的 2D 识别库 Detectron2 融合，成功地把物体理解推向了第三维度。PyTorch3D 中处理旋转和 3D 变换的函数也是创建 C3DPO 的核心，这是一种用更少标注训练数据学习图像与 3D 形状之间关联的新方法。研究者和工程师同样可以把 PyTorch3D 用于各种各样的 3D 深度学习研究——无论是 3D 重建、捆集调整（bundle adjustment），还是 3D 推理——来改进 2D 识别任务。今天，我们在此分享 PyTorch3D 库，并在此开源我们的 Mesh R-CNN 代码库。

## PyTorch3D：更快、更灵活的 3D 深度学习研究

3D 理解的深度学习研究相较 2D 理解探索较少，原因之一是 3D 数据输入更复杂，对内存和计算的要求更高，而 2D 图像可以用简单的张量表示。3D 运算还必须是可微分的，这样梯度才能从模型输出向后传播回输入数据。考虑到计算机图形领域的许多传统算子（例如渲染）都包含阻断梯度的步骤，这一点尤其具有挑战性。

正如 PyTorch 为 2D 识别任务提供高度优化的库一样，PyTorch3D 通过提供批处理能力以及对 3D 算子和损失函数的支持来优化训练和推理。

**用于存储和操作批次三角形网格的数据结构**

（原文此处嵌入视频。）

由于 3D 网格由一组顶点坐标和面片索引构成，对不同尺寸的 3D 网格进行批处理带来了若干挑战。为应对这一挑战，我们创建了 Meshes——一种在深度学习应用中对异构网格进行批处理的数据结构。这种数据结构让研究者能够轻松地把底层网格数据变换为不同视图，以便让算子与数据的最优表示相匹配。PyTorch3D 让研究者和工程师能够高效地在不同表示视图之间切换并访问网格的不同属性。

**三角形网格上的高效运算**

（原文此处嵌入视频。）

我们已经完成了优化若干常用 3D 数据算子和损失函数实现的底层工作，支持异构的输入批次。这意味着研究者和工程师可以直接导入 PyTorch3D 中的算子以加快实验速度，而不必在每个新项目开始时从头重建或重新实现这些算子。这些算子包括 chamfer 损失——一种比较两组点云并用作 3D 网格损失函数的方法。我们使用 CUDA 内核为该损失函数中高度消耗资源的最近邻计算创建了一种优化方式。随着时间推移，我们会继续增加常用算子的数量。

**可微分网格渲染器**

（原文此处嵌入视频。）

渲染是计算机图形学的核心部分，它把 3D 模型转换为 2D 图像，是连接 3D 场景属性与 2D 图像像素的天然桥梁。然而，传统渲染引擎不可微分，因此无法纳入深度学习流水线。近来，若干学术研究项目（如 OpenDR、Neural Mesh Renderer、Soft Rasterizer 和 redner）展示了如何构建能与深度学习干净集成的可微分渲染器。可微分渲染是一个新兴领域，我们希望调整核心算法以聚焦灵活性。我们需要一个能够访问各种中间值的渲染引擎，以满足不同下游应用的消费需求。在 PyTorch3D 中，我们编写了一个高效、模块化的可微分渲染器。我们的实现由可组合的单元构成，允许用户轻松扩展渲染器以支持自定义光照或着色效果。计算繁重的光栅化步骤在 PyTorch、C++ 和 CUDA 中都有并行实现，并配有全面的测试来验证正确性。与 PyTorch3D 中的所有其他算子一样，我们的渲染器依托 Mesh 数据结构支持异构批次数据。关于渲染器实现和 PyTorch3D 中可用模块的深入介绍，可以在 PyTorch3D 文档中找到。

## 推动 3D 理解向前发展

我们对 PyTorch3D 的目标是推动深度学习与 3D 交叉领域的进展。我们设计了高效且优化的算子、异构批处理能力和模块化的可微分渲染 API，为研究者和工程师配备一套工具包，以便用复杂的 3D 输入实现前沿研究。凭借独特的可微分渲染能力，我们对构建无需依赖耗时的人工 3D 标注即可做出高质量 3D 预测的系统、并开辟 3D 研究新方向的潜力感到兴奋。在 Facebook AI，我们将持续改进和扩充 PyTorch3D 中提供的算子，也欢迎社区贡献，共同建设这一资源。PyTorch3D 代码可在此获取，Mesh R-CNN 代码在此。
