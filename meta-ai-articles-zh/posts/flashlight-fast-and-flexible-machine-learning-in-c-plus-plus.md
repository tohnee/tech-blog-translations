# Flashlight：用 C++ 实现快速而灵活的机器学习

> 原文：[Flashlight: Fast and flexible machine learning in C++](https://ai.facebook.com/blog/flashlight-fast-and-flexible-machine-learning-in-c-plus-plus) · Meta AI（Wayback 存档）

2021 年 4 月 16 日

**这是什么：**Flashlight 是一个完全用 C++ 编写的新开源机器学习（ML）库，由 FAIR 构建，旨在让团队能够快速、轻松地修改深度学习与机器学习框架以更好地满足自身需求，从而为突破性研究提供动力。深度学习与机器学习框架擅长它们所做的事——但修改这些框架的内部机制历来困难。找到要改的正确代码既耗时又易错，因为底层内部可能被无意混淆、闭源，或为特定目的手工调优过。而且一旦做了修改，之后重新编译框架既费时又耗算力。

我们把 Flashlight 设计为可从核心定制。它只包含研究所需的最基本构建块，使其导航简单直观。得益于极简设计与免受语言绑定之累，当你修改 Flashlight 的核心组件后，重建整个库及其训练流水线只需几秒钟。我们用现代 C++ 从零编写 Flashlight，因为这门语言是在高性能计算环境中做研究的强大工具。Flashlight 的框架开销极低，因为现代 C++ 提供一流的并行性与开箱即用的速度。Flashlight 还提供简单的桥接，以集成来自底层领域特定语言与库的代码。我们开源 Flashlight，是为了让 AI 社区更容易摆弄支撑深度学习与机器学习框架的底层代码，更好地利用手头硬件并突破性能极限。

**它做什么：**Flashlight 构建在一小层模块化、易用的基础抽象之上。我们从 ArrayFire 张量库起步，它支持动态张量形状与类型，免去僵硬的编译期规范与 C++ 模板的需要。ArrayFire 还用高效的即时编译器动态优化运算。在这些基础组件之上，Flashlight 包含可定制的内存管理器，以及面向分布式与混合精度训练的 API。再结合快速、轻量的 autograd（深度学习的基本组件，自动计算深度神经网络中常见的链式运算的导数），Flashlight 还具备面向大规模数据处理与训练的模块化抽象。这些组件为支持一般研究方向而构建，无论在深度学习还是其他领域。

Flashlight 的轻量领域应用（见上图）支持跨多种模态的研究，包括语音识别、语言建模与图像分类及分割——全部在单一代码库中。这一设计免去了组合多个独立领域特定库的需要，使 Flashlight 能支持在多种设置上验证新想法，让多模态研究更简单。这只需要一次增量重建，而不是为各个上游领域特定框架分别修改与重建。虽然深度学习的常见原语通过硬件专用厂商库中优化良好的内核实现，但编写自定义高性能代码往往难以快速集成与迭代。Flashlight 让构建新的底层计算抽象变得轻而易举：你可以干净地集成 CUDA 或 OpenCL 内核、Halide AOT 流水线或其他自定义 C/C++ 代码，费力极少。现代 C++ 还免去了内存管理等任务，同时为函数式编程提供强大工具。Flashlight 支持直接用 C++ 做研究，无需调整外部装置或绑定，也无需适配器来处理线程、内存映射或与底层硬件互操作。因此，集成快速、并行的代码变得简单直接。

**为什么重要：**随着深度学习与机器学习模型日益复杂，进步依赖于优化。先进的 AI 模型与研究需要高效利用可用硬件的高性能代码。Flashlight 的模块化内部使其成为「面向研究框架的强大研究框架」。Flashlight 的快速重建便于在库本身之上做研究，再把成果下游应用到其他框架。通过让快速迭代自定义底层代码变得更容易，Flashlight 为突破性能极限的研究打开了大门。我们已经在 Facebook 把 Flashlight 用于以下研究：开发快速语音识别流水线、用于迭代伪标注的线程化可定制训练时重标注流水线，以及可微束搜索解码器。借助集成外部平台 API 以支持新硬件或编译工具链、并与 Flashlight 其余部分即时互操作的能力，我们的持续研究进一步加速。我们希望开源 Flashlight 能让修改支撑 AI 模型的代码、集成新的底层语言与库变得更容易——最终帮助 AI 社区更快地迭代他们的想法。
