# 用「放射性数据」检测数据集是否被用于训练

> 原文：[Using ‘radioactive data’ to detect if a dataset was used for training](http://ai.facebook.com/blog/using-radioactive-data-to-detect-if-a-data-set-was-used-for-training) · Meta AI（Wayback 存档）

**研究内容：** 我们开发了一种标记数据集中图像的新技术，让研究者能够判定某个机器学习模型是否使用这些图像训练过。这可以帮助研究者和工程师追踪哪个数据集被用来训练模型，从而更好地理解各种数据集如何影响不同神经网络的性能。我们把这种新的验证方法称为「放射性」（radioactive）数据，因为它类似医学中放射性标记物的使用：硫酸钡等药物让医生能在计算机断层扫描（CT）或其他 X 光检查中更清晰地看到某些病症。我们引入的独有标记无害、不影响模型的分类准确率，却能在学习过程中保留下来，并可在神经网络中以高置信度检出。我们的方法提供一个置信水平（p 值），判断某放射性数据集是否被用于训练某个特定模型。放射性数据不同于以往那些以不可察觉方式「投毒」训练集、使训练出的模型泛化变差的方法。

**工作原理：** 为执行图像分类，卷积神经网络（CNN）从图像计算出一个特征表示，再从特征预测特定标签。为标记具有给定标签的图像，我们的方法把它们的特征沿一个特定方向（载波，carrier）移动，该方向随机采样、与数据无关。在用这类数据训练模型后，其分类器会与载波方向对齐。我们通过计算每个类别的分类器与载波方向的余弦相似度来验证这种对齐。这给出了模型用放射性数据训练的置信水平。我们在大规模基准（ImageNet）、标准架构（ResNet-18、VGG-16、DenseNet-121）和标准训练流程上的实验表明：即使训练模型所用的数据中只有 1% 是放射性的，我们也能以高置信度（p 小于 10^-4）检出放射性数据的使用。我们还专门设计了放射性数据方法，使得检测一个数据集是否具有放射性、以及从训练好的模型中去除标记都极其困难。

第一行为 Holidays 数据集的原始图像，第二行为带有放射性标记的图像（PSNR=42dB）。第三行仅为放射性标记，放大 5 倍。最底一行把这个夸张化的标记加到原始图像上用于可视化，相当于加性噪声的 14dB 放大。

在不显著影响基于数据集训练的模型的前提下改变数据集，颇具挑战。典型方法要么改变训练集中样本的标签，要么在图像上添加可见线索，这会降低准确率和/或被肉眼察觉。我们的方法通过在特征空间中加入同类图像内一致的微小扰动规避了这一问题。此外，我们的对齐技术使我们即使在训练模型的架构与标记网络不同的情况下，也能检测特征空间中的这种扰动。

**为什么重要：** 放射性数据可以用来标记数据并验证其在下游模型中的后续使用。这在大型系统中很有用——复杂的流水线让人难以追踪每个数据点的使用情况。数据可以在进入流水线前被标记，对流水线输出的模型可以进行检测。放射性数据等技术还可以帮助研究者和工程师更好地理解领域内其他人如何训练模型，例如有助于发现这些模型中潜在的偏见。放射性数据还有助于防止特定数据集在机器学习中被滥用。
