# Qwen2.5 技术报告

> 原文：[Qwen2.5 Technical Report](https://arxiv.org/abs/2412.15115) · Qwen 团队 arXiv

Qwen 团队

###### 摘要

在本报告中，我们介绍 Qwen2.5——一个为满足多样化需求而设计的全面的大语言模型（LLM）系列。与之前的版本相比，Qwen2.5 在预训练与后训练两个阶段都得到了显著改进。在预训练方面，我们将高质量预训练数据集从之前的 7 万亿 token 扩充到 18 万亿 token，为常识、专业知识与推理能力奠定了坚实基础。在后训练方面，我们实施了包含超过 100 万个样本的精细监督微调，以及多阶段强化学习，包括离线学习 DPO 与在线学习 GRPO。后训练技术显著增强了人类偏好对齐，并在长文本生成、结构化数据分析与指令遵循方面带来了显著提升。

为了有效应对多样多变的使用场景，我们提供了配置丰富的 Qwen2.5 大语言模型系列。开放权重产品包括参数规模为 0.5B、1.5B、3B、7B、14B、32B 与 72B 的基础模型和指令微调模型，同时还提供指令微调模型的量化版本。超过 100 个模型可以通过 Hugging Face Hub、ModelScope 与 Kaggle 获取。此外，对于托管方案，专有模型目前包括两个专家混合（MoE）变体：Qwen2.5-Turbo 与 Qwen2.5-Plus，二者均可从 [Alibaba Cloud Model Studio](https://www.alibabacloud.com/en/product/modelstudio) 获取。

Qwen2.5 在评估语言理解、推理、数学、编程、人类偏好对齐等能力的广泛基准上展示了顶级性能。具体而言，开放权重旗舰模型 Qwen2.5-72B-Instruct 胜过了众多开源与专有模型，并与最先进的开放权重模型 Llama-3-405B-Instruct（规模约为其 5 倍）表现出相当的竞争力。Qwen2.5-Turbo 与 Qwen2.5-Plus 在分别与 GPT-4o-mini 和 GPT-4o 竞争的同时，提供了更优的性价比。此外，作为基础，Qwen2.5 模型已被用于训练专用模型，例如 Qwen2.5-Math（[Yang et al., 2024b](#bib.bib90)）、Qwen2.5-Coder（[Hui et al., 2024](#bib.bib40)）、QwQ（[Qwen Team, 2024d](#bib.bib68)）以及多模态模型。

## 1 引言

通用人工智能（AGI）的火花正随着大型基础模型（尤其是大语言模型，LLM）的快速发展而日益显现（[Brown et al., 2020](#bib.bib13)；[OpenAI, 2023](#bib.bib58)；[OpenAI, 2024a](#bib.bib59)；[Gemini Team, 2024](#bib.bib31)；[Anthropic, 2023a](#bib.bib6)；[Anthropic, 2023b](#bib.bib7)；[Anthropic, 2024](#bib.bib8)；[Bai et al., 2023](#bib.bib10)；[Yang et al., 2024a](#bib.bib89)；[Touvron et al., 2023a](#bib.bib79)；[Touvron et al., 2023b](#bib.bib80)；[Dubey et al., 2024](#bib.bib25)）。模型与数据规模化的持续进步，加之「大规模预训练 + 高质量监督微调（SFT）与基于人类反馈的强化学习（RLHF）（[Ouyang et al., 2022](#bib.bib61)）」的范式，使大语言模型在语言理解、生成与推理方面发展出涌现能力。在此基础上，推理时扩展（inference time scaling）的最新突破——特别是 o1（[OpenAI, 2024b](#bib.bib60)）所展示的——通过逐步推理与反思增强了 LLM 深度思考的能力。这些进展提升了语言模型的潜力，表明随着它们持续展现出指向更通用人工智能的涌现能力，它们可能在科学探索中取得重大突破。

除了模型能力的快速发展之外，近两年间 LLM 社区还涌现出大量开放（开放权重）大语言模型，例如 Llama 系列（[Touvron et al., 2023a](#bib.bib79)；[Touvron et al., 2023b](#bib.bib80)；[Dubey et al., 2024](#bib.bib25)）、Mistral 系列（[Jiang et al., 2023a](#bib.bib42)；[Jiang et al., 2024a](#bib.bib43)）以及我们的 Qwen 系列（[Bai et al., 2023](#bib.bib10)；[Yang et al., 2024a](#bib.bib89)；[Qwen Team, 2024a](#bib.bib65)；[Hui et al., 2024](#bib.bib40)；[Qwen Team, 2024c](#bib.bib67)；[Yang et al., 2024b](#bib.bib90)）。开放权重模型使普通用户和开发者都能使用大语言模型，促成更广泛的研究参与、通过社区协作培育创新，并加速了人工智能应用在多样领域的发展。

最近，我们发布了 Qwen 系列最新版本 Qwen2.5 的细节。在开放权重方面，我们发布了 7 种规模的预训练与指令微调模型，包括 0.5B、1.5B、3B、7B、14B、32B 和 72B，并且不仅提供 bfloat16 精度的原始模型，还提供不同精度的量化模型。具体而言，旗舰模型 Qwen2.5-72B-Instruct 与最先进的开放权重模型 Llama-3-405B-Instruct（规模约为其 5 倍）相比表现出相当的竞争力。此外，我们还发布了专有的专家混合（MoE，[Lepikhin et al., 2020](#bib.bib49)；[Fedus et al., 2022](#bib.bib26)；[Zoph et al., 2022](#bib.bib101)）模型，即 Qwen2.5-Turbo 与 Qwen2.5-Plus¹，它们分别与 GPT-4o-mini 和 GPT-4o 相比表现出相当的竞争力。

¹ 在 API 中，Qwen2.5-Turbo 的标识为 qwen-turbo-2024-11-01，Qwen2.5-Plus 的标识为 qwen-plus-2024-xx-xx（即将发布）。

在本技术报告中，我们介绍 Qwen2.5——我们持续努力打造更好 LLM 的成果。下面，我们列出 Qwen 最新版本的关键特性：

- •

  规模更优（Better in Size）：与 Qwen2 相比，Qwen2.5 除了 0.5B、1.5B、7B 和 72B 模型之外，还恢复了 3B、14B 和 32B 模型，这些模型对资源受限的场景更具成本效益，而在当前开放基础模型领域中这类规模仍相对缺乏。Qwen2.5-Turbo 与 Qwen2.5-Plus 在准确性、延迟与成本之间取得了出色平衡。
- •

  数据更优（Better in Data）：预训练与后训练数据均得到显著改进。预训练数据从 7 万亿 token 增加到 18 万亿 token，重点聚焦知识、编程与数学。预训练分阶段进行，以允许在不同数据混合（mixture）之间过渡。后训练数据达 100 万个样本，覆盖监督微调（SFT，[Ouyang et al., 2022](#bib.bib61)）、直接偏好优化（DPO，[Rafailov et al., 2023](#bib.bib70)）与组相对策略优化（GRPO，[Shao et al., 2024](#bib.bib75)）各阶段。
- •

  使用更优（Better in Use）：Qwen2 在使用中的若干关键局限已被消除，包括更大的生成长度（从 2K token 到 8K token）、对结构化输入与输出的更好支持（例如表格和 JSON），以及更简便的工具使用。此外，Qwen2.5-Turbo 支持长达 100 万 token 的上下文长度。

## 2 架构与分词器

总体而言，Qwen2.5 系列包括用于开源的稠密（dense）模型，即 Qwen2.5-0.5B / 1.5B / 3B / 7B / 14B / 32B / 72B，以及用于 API 服务的 MoE 模型，即 Qwen2.5-Turbo 和 Qwen2.5-Plus。下面，我们提供模型架构的细节。

对于稠密模型，我们沿用与 Qwen2（[Yang et al., 2024a](#bib.bib89)）相同的基于 Transformer 的解码器架构（[Vaswani et al., 2017](#bib.bib81)；[Radford et al., 2018](#bib.bib69)）。该架构包含若干关键组件：用于高效利用 KV 缓存的分组查询注意力（GQA，[Ainslie et al., 2023](#bib.bib3)）、用于非线性激活的 SwiGLU 激活函数（[Dauphin et al., 2017](#bib.bib22)）、用于编码位置信息的旋转位置编码（RoPE，[Su et al., 2024](#bib.bib77)）、注意力机制中的 QKV 偏置（[Su, 2023](#bib.bib76)），以及带预归一化的 RMSNorm（[Jiang et al., 2023b](#bib.bib45)）以确保训练稳定。

在稠密模型架构的基础上，我们将其扩展为 MoE 模型架构。具体做法是将标准前馈网络（FFN）层替换为专用的 MoE 层，其中每层包含多个 FFN 专家以及一个将 token 路由到 top-K 专家的机制。沿袭 Qwen1.5-MoE（[Yang et al., 2024a](#bib.bib89)）中的方法，我们实现了细粒度专家切分（[Dai et al., 2024](#bib.bib21)）与共享专家路由（[Rajbhandari et al., 2022](#bib.bib71)；[Dai et al., 2024](#bib.bib21)）。这些架构创新为模型在下游任务上的性能带来了实质提升。

在分词方面，我们使用 Qwen 的分词器（[Bai et al., 2023](#bib.bib10)），它实现了字节级字节对编码（BBPE，[Brown et al., 2020](#bib.bib13)；[Wang et al., 2020](#bib.bib83)；[Sennrich et al., 2016](#bib.bib74)），拥有 151,643 个常规 token 的词表。与前代 Qwen 版本相比，我们将控制 token 集合从 3 个扩展到 22 个，新增两个用于工具功能的 token，其余分配给其他模型能力。这一扩展在所有 Qwen2.5 模型间建立了统一的词表，增强了一致性并减少了潜在的兼容性问题。

## 3 预训练

我们的语言模型预训练流程由若干关键部分组成。首先，我们通过精细的过滤与评分机制，结合策略性的数据混合（data mixture），精心构建高质量训练数据。其次，我们对超参数优化开展广泛研究，以在各种规模上有效训练模型。最后，我们纳入专门的长上下文预训练，以增强模型处理和理解长序列的能力。下面，我们详述数据准备、超参数选择与长上下文训练的方法。

### 3.1 预训练数据

与前代 Qwen2 相比，Qwen2.5 在预训练数据质量上展现出显著增强。这些改进源于以下几个关键方面：

1. (1)

   更好的数据过滤。高质量预训练数据对模型性能至关重要，因此数据质量评估与过滤是我们流程中的关键环节。我们利用 Qwen2-Instruct 模型作为数据质量过滤器，执行全面的多维度分析来评估和打分训练样本。该过滤方法相较于此前用于 Qwen2 的方法是一大进步，因为它得益于 Qwen2 在更大规模多语言语料上的扩展预训练。增强的能力带来了更细致的质量评估，既改善了对高质量训练数据的保留，也在多种语言上更有效地过滤了低质量样本。
2. (2)

   更好的数学与代码数据。在 Qwen2.5 的预训练阶段，我们纳入了来自 Qwen2.5-Math（[Yang et al., 2024b](#bib.bib90)）与 Qwen2.5-Coder（[Hui et al., 2024](#bib.bib40)）的训练数据。这种数据整合策略被证明极为有效，因为这些专用数据集对于在数学与编程任务上取得最先进性能功不可没。通过在预训练中利用这些高质量的领域专用数据集，Qwen2.5 继承了数学推理与代码生成两方面的强大能力。
3. (3)

   更好的合成数据。为生成高质量合成数据（尤其在数学、代码与知识领域），我们同时利用了 Qwen2-72B-Instruct（[Yang et al., 2024a](#bib.bib89)）与 Qwen2-Math-72B-Instruct（[Qwen Team, 2024c](#bib.bib67)）。这些合成数据的质量通过我们专有的通用奖励模型以及专用 Qwen2-Math-RM-72B（[Qwen Team, 2024c](#bib.bib67)）模型的严格过滤得到进一步提升。
4. (4)

   更好的数据混合。为优化预训练数据分布，我们使用 Qwen2-Instruct 模型对不同领域的内容进行分类与平衡。我们的分析表明，电子商务、社交媒体与娱乐等领域在网络规模数据中显著过量呈现，常包含重复、基于模板或机器生成的内容。相反，技术、科学与学术研究等领域虽然包含更高质量的信息，但传统上呈现不足。通过对过量呈现领域进行策略性下采样、对高价值领域进行上采样，我们确保了训练数据集更加均衡且信息丰富，更好地服务于模型的学习目标。

在这些技术的基础上，我们构建了一个更大、质量更高的预训练数据集，从 Qwen2（[Yang et al., 2024a](#bib.bib89)）使用的 7 万亿 token 扩展到 18 万亿 token。

### 3.2 超参数缩放定律

我们基于 Qwen2.5 的预训练数据构建了超参数缩放定律（[Hoffmann et al., 2022](#bib.bib36)；[Kaplan et al., 2020](#bib.bib46)）。以往研究（[Dubey et al., 2024](#bib.bib25)；[Almazrouei et al., 2023](#bib.bib4)；[Hoffmann et al., 2022](#bib.bib36)）主要用缩放定律在给定算力预算下确定最优模型规模，而我们利用它们来跨模型架构识别最优超参数。具体而言，我们的缩放定律帮助确定各种规模稠密模型与 MoE 模型的关键训练参数，如批大小 $B$ 与学习率 $\mu$。

通过大量实验，我们系统研究了模型架构与最优训练超参数之间的关系。具体而言，我们分析了最优学习率 $\mu_{\textrm{opt}}$ 与批大小 $B_{\textrm{opt}}$ 如何随模型规模 $N$ 与预训练数据规模 $D$ 变化。我们的实验覆盖了全面的架构范围，包括 44M 到 14B 参数的稠密模型与 44M 到 1B 激活参数的 MoE 模型，训练数据集规模从 0.8B 到 600B token。利用这些最优超参数预测，我们进而将最终损失建模为模型架构与训练数据规模的函数。

此外，我们利用缩放定律来预测并比较不同参数量的 MoE 模型与对应稠密模型的性能。这一分析指导了我们 MoE 模型的超参数配置，使我们能够通过仔细调整激活参数与总参数，实现与特定稠密模型变体（如 Qwen2.5-72B 和 Qwen2.5-14B）相当的性能。

### 3.3 长上下文预训练

为了获得最优的训练效率，Qwen2.5 采用两阶段预训练方法：初始阶段使用 4,096 token 的上下文长度，随后是面向更长序列的扩展阶段。沿袭 Qwen2 的策略，我们在最终预训练阶段将除 Qwen2.5-Turbo 之外的所有模型变体的上下文长度从 4,096 扩展到 32,768 token。同时，我们使用 ABF 技术（[Xiong et al., 2023](#bib.bib88)）将 RoPE 的基础频率从 10,000 提升到 1,000,000。

对于 Qwen2.5-Turbo，我们在训练期间实施渐进式上下文长度扩展策略，经历四个阶段推进：32,768 token、65,536 token、131,072 token，最终达到 262,144 token，RoPE 基础频率为 10,000,000。在每个阶段，我们精心整理训练数据，使其包含 40% 处于当前最大长度的序列与 60% 较短的序列。这种渐进式训练方法使模型能够平滑适应不断增长的上下文长度，同时保持其有效处理和泛化到不同长度序列的能力。

为增强模型在推理时处理更长序列的能力，我们实施了两个关键策略：YARN（[Peng et al., 2023](#bib.bib62)）与双块注意力（DCA，[An et al., 2024](#bib.bib5)）。通过这些创新，我们实现了四倍的序列长度容量提升，使 Qwen2.5-Turbo 能够处理多达 100 万 token，其他模型能够处理多达 131,072 token。值得注意的是，这些方法不仅通过降低困惑度改善了长序列建模，还保持了模型在较短序列上的强劲表现，确保在不同输入长度下质量的一致性。

## 4 后训练

与 Qwen 2 相比，Qwen 2.5 在后训练设计上引入了两项重大改进：

1. (1)

   扩展的监督微调数据覆盖：监督微调流程利用了包含数百万高质量样本的大规模数据集。这一扩展专门针对此前模型表现受限的关键领域，如长序列生成、数学问题求解、编程、指令遵循、结构化数据理解、逻辑推理、跨语言迁移以及稳健的系统指令。
2. (2)

   两阶段强化学习：Qwen 2.5 的强化学习（RL）过程分为两个不同阶段：离线 RL 与在线 RL。

   - •

     离线 RL：该阶段聚焦于发展奖励模型难以评估的能力，如推理、事实性与指令遵循。通过对训练数据的精细构建与验证，我们确保离线 RL 信号既可学习又可靠（[Xiang et al., 2024](#bib.bib87)），使模型能够有效习得这些复杂技能。
   - •

     在线 RL：在线 RL 阶段利用奖励模型检测输出质量细微差别的能力，包括真实性、有用性、简洁性、相关性、无害性与去偏见。它使模型能够生成精确、连贯且结构良好的回复，同时保持安全性与可读性。因此，模型的输出能够持续满足人类的质量标准与期望。

### 4.1 监督微调

在本节中，我们详述 Qwen2.5 在 SFT 阶段取得的关键增强，聚焦于若干关键领域：

1. (1)

   长序列生成：
   Qwen2.5 能够以最高 8,192 token 的输出上下文长度生成高质量内容，相比通常保持在 2,000 token 以下的典型后训练响应长度有显著进步。为弥补这一差距，我们开发了长回复数据集（[Quan et al., 2024](#bib.bib64)）。我们采用回译（back-translation）技术从预训练语料中为长文本数据生成查询，施加输出长度约束，并使用 Qwen2 过滤低质量的成对数据。
2. (2)

   数学：
   我们引入了 Qwen2.5-Math（[Yang et al., 2024b](#bib.bib90)）的思维链（chain-of-thought）数据，其涵盖多种查询来源，包括公开数据集、K-12 题目集合与合成题目。为确保高质量推理，我们采用拒绝采样（[Yuan et al., 2023](#bib.bib95)）并结合奖励模型与标注答案进行引导，生成逐步的推理过程。
3. (3)

   编程：
   为增强编程能力，我们纳入了 Qwen2.5-Coder（[Hui et al., 2024](#bib.bib40)）的指令微调数据。我们将多个语言专用智能体（agent）纳入协作框架，生成覆盖近 40 种编程语言的多样且高质量的指令对。我们通过从代码相关问答网站合成新样本、从 GitHub 收集算法代码片段来扩展指令数据集。我们使用全面的多语言沙箱执行静态代码检查，并通过自动化单元测试验证代码片段，确保代码质量与正确性（[Dou et al., 2024](#bib.bib24)；[Yang et al., 2024c](#bib.bib91)）。
4. (4)

   指令遵循：
   为确保高质量的指令遵循数据，我们实施了严格的基于代码的验证框架。在这一方法中，LLM 同时生成指令与相应的验证代码，以及用于交叉验证的全面单元测试。通过基于执行反馈的拒绝采样，我们精心挑选用于监督微调的训练数据，从而保证模型忠实遵守预期指令（[Dong et al., 2024](#bib.bib23)）。
5. (5)

   结构化数据理解：
   我们开发了全面的结构化理解数据集，既涵盖传统任务，如表格问答、事实核查、纠错与结构理解，也涉及包含结构化与半结构化数据的复杂任务。通过在模型回复中引入推理链，我们显著增强了其从结构化数据中推断信息的能力，从而提升了其在这些多样任务上的表现。这一方法不仅拓宽了数据集的范围，也深化了模型对复杂数据结构进行推理并得出有意义洞察的能力。
6. (6)

   逻辑推理：为增强模型的逻辑推理能力，我们引入了涵盖多个领域的 70,000 个新查询的多样集合。这些查询包括多项选择题、判断题与开放性问题。模型被训练以系统化地解决问题，运用演绎推理、归纳概括、类比推理、因果推理与统计推理等多种推理方法。通过迭代精修，我们系统性地过滤掉包含错误答案或推理过程有缺陷的数据。这一过程逐步强化了模型进行逻辑而准确推理的能力，确保其在不同类型推理任务上的稳健表现。
7. (7)

   跨语言迁移：为促进模型通用能力跨语言迁移，我们使用翻译模型将高资源语言的指令转换为多种低资源语言，从而生成相应的回复候选。为确保这些回复的准确性与一致性，我们评估每个多语言回复与其原始版本之间的语义对齐程度。该过程保留了原始回复的逻辑结构与风格细节，从而在不同语言之间维持其完整性与连贯性。
8. (8)

   稳健的系统指令：我们构建了数百个通用系统提示（system prompt），以提升后训练中系统提示的多样性，并确保系统提示与对话之间的一致性。使用不同系统提示的评测表明，模型保持了良好性能（[Lu et al., 2024b](#bib.bib55)）且方差降低，表明稳健性有所改善。
9. (9)

   回复过滤：为评估回复质量，我们采用多种自动标注方法，包括专用的批评（critic）模型与多智能体协作评分系统。回复需经过严格评估，只有被所有评分系统判定为无瑕的回复才予以保留。这种全面的方法确保我们的输出保持最高的质量标准。

最终，我们构建了超过 100 万个 SFT 样本的数据集。模型以 32,768 token 的序列长度微调两个 epoch。为优化学习，学习率从 $7\times 10^{-6}$ 逐步降至 $7\times 10^{-7}$。为应对过拟合，我们施加 0.1 的权重衰减，并将梯度范数裁剪的最大值设为 1.0。

### 4.2 离线强化学习

与在线强化学习（RL）相比，离线 RL 支持预先准备训练信号，这对于存在标准答案但难以用奖励模型评估的任务尤为有利。在本研究中，我们聚焦于客观查询领域，如数学、编程、指令遵循与逻辑推理，在这些领域获得准确评估可能颇为复杂。在上一阶段，我们大量采用了执行反馈与答案匹配等策略来确保回复质量。在本阶段，我们复用该流程，使用 SFT 模型为一组新查询重采样回复。通过质量检查的回复用作正例，未通过的则作为直接偏好优化（DPO）训练的负例（[Rafailov et al., 2023](#bib.bib70)）。为进一步增强训练信号的可靠性与准确性，我们同时使用人工与自动化审查流程（[Cao et al., 2024](#bib.bib14)）。这种双重方法确保训练数据不仅可学习，而且符合人类期望。最终，我们构建了约 150,000 对训练对组成的数据集。随后，模型使用 Online Merging Optimizer（[Lu et al., 2024a](#bib.bib54)）训练一个 epoch，学习率为 $7\times 10^{-7}$。

### 4.3 在线强化学习

为开发用于在线 RL 的稳健奖励模型，我们遵循一套精心定义的标注标准。这些标准确保模型生成的回复不仅高质量，而且符合伦理标准与以用户为中心的标准（[Wang et al., 2024a](#bib.bib82)）。数据标注的具体准则如下：

- •

  真实性（Truthfulness）：回复必须以事实准确性为基础，忠实反映所提供的上下文与指令。模型应避免生成虚假信息或给定数据不支持的信息。
- •

  有用性（Helpfulness）：模型输出应真正有用，有效解决用户的查询，同时提供积极、有吸引力、有教育意义且相关的内容。它应精确遵循给定指令并为用户带来价值。
- •

  简洁性（Conciseness）：回复应简明扼要、切中要点，避免不必要的冗长。目标是在不让过多细节压垮用户的情况下清晰高效地传达信息。
- •

  相关性（Relevance）：回复的所有部分都应与用户的查询、对话历史及助手上下文直接相关。模型应调整其输出，以确保与用户的需求和期望完美契合。
- •

  无害性（Harmlessness）：模型必须优先考虑用户安全，避免任何可能导致违法、不道德或有害行为的内容。它应始终促进伦理行为与负责任的交流。
- •

  去偏见（Debiasing）：模型应生成不带偏见的回复，包括但不限于性别、种族、国籍与政治方面的偏见。它应平等且公正地对待所有话题，遵循广泛接受的道德与伦理标准。

用于训练奖励模型的查询来自两个不同的数据集：公开可用的开源数据，以及以更高复杂性为特征的专有查询集。回复由 Qwen 模型的多个检查点生成，这些检查点在训练的不同阶段分别经 SFT、DPO 与 RL 等不同方法微调。为引入多样性，这些回复在不同的 temperature 设置下采样。偏好对通过人工与自动化标注流程共同构建，DPO 的训练数据也被整合进该数据集。

在我们的在线强化学习（RL）框架中，我们采用组相对策略优化（GRPO，[Shao et al., 2024](#bib.bib75)）。用于训练奖励模型的查询集与 RL 训练阶段所用的相同。训练期间查询的处理顺序由奖励模型评估的响应得分方差决定。具体而言，响应得分方差较高的查询会被优先处理，以确保更有效的学习。我们对每个查询采样 8 个回复。所有模型均以 2048 的全局批大小训练，每个 episode 包含 2048 个样本，其中一对查询与回复视为一个样本。

### 4.4 长上下文微调

为进一步扩展 Qwen2.5-Turbo 的上下文长度，我们在后训练中引入更长的 SFT 样本，使其在长查询上更好地对齐人类偏好。

在 SFT 阶段，我们采用两阶段方法。第一阶段，模型仅使用短指令微调，每条指令最多包含 32,768 token。该阶段使用与其他 Qwen2.5 模型相同的数据和训练步数，以确保在短任务上的强劲表现。第二阶段，微调过程同时结合短指令（最多 32,768 token）与长指令（最多 262,144 token）。这种混合方法有效增强了模型在长上下文任务中的指令遵循能力，同时保持了其在短任务上的表现。

在 RL 阶段，我们使用与其他 Qwen2.5 模型类似的训练策略，仅聚焦于短指令。这一设计选择出于两个主要考虑：其一，RL 训练对长上下文任务而言计算成本高昂；其二，目前能够为长上下文任务提供合适奖励信号的奖励模型仍然稀缺。此外，我们发现仅在短指令上进行 RL 仍能显著增强模型在长上下文任务上与人类偏好的对齐。

## 5 评测

预训练产生的基础模型与后训练产生的指令微调模型均通过一套全面的评测套件进行评估，该套件包括常用的开放基准与面向技能的内部数据集。该评测套件设计为以自动为主、人工参与最少。

为防止测试数据泄露，我们在构建预训练与后训练数据集时使用 n-gram 匹配排除可能被污染的数据。沿袭 Qwen2 使用的标准，对于训练序列 $\mathbf{s}_{t}$，若存在测试序列 $\mathbf{s}_{e}$ 使得二者分词后的最长公共子序列（LCS）长度同时满足 $|\text{LCS}(\mathbf{s}_{t},\mathbf{s}_{e})|\geq 13$ 与 $|\text{LCS}(\mathbf{s}_{t},\mathbf{s}_{e})|\geq 0.6\times\min(|\mathbf{s}_{t}|,|\mathbf{s}_{e}|)$，则将其从训练数据中移除。

### 5.2 指令微调模型

为了审慎评估指令微调模型，我们采用多层面的方法。基础技能与人类偏好通过开放数据集与基准进行评估。此外，我们详细的内部评测深入考察模型在关键领域与多语言方面的能力。其中特别关注长上下文能力的评估。后续各节概述评测方法并给出结果。

#### 5.2.1 开放基准评测

为全面评估指令微调模型的质量，我们结合自动评测与人工评测来评估能力与人类偏好。对于基础能力的评测，我们采用与预训练模型评测相似的数据集，聚焦自然语言理解、编程、数学与推理。具体而言，通用评测采用 MMLU-Pro、MMLU-redux 与 LiveBench 0831（[White et al., 2024](#bib.bib86)）；科学与数学采用 GPQA、GSM8K 与 MATH；编程采用 HumanEval、MBPP、MultiPL-E 与 LiveCodeBench 2305-2409（[Jain et al., 2024](#bib.bib41)）；指令遵循采用 IFEval（[Zhou et al., 2023](#bib.bib100)）²。此外，我们还通过在 MT-Bench（[Zheng et al., 2023](#bib.bib98)）与 Arena-Hard（[Li et al., 2024](#bib.bib50)）等基准上进行评测，评估人类偏好对齐与指令遵循的表现。

我们在中英两种语言上将 Qwen2.5-Instruct 模型与若干领先语言模型进行比较，包括 GPT-4、Claude3.5-sonnet、Qwen2 与 Llama-3.1。我们的分析聚焦于模型规模及其对性能的影响，以及最新的 Qwen2.5 系列与前代及竞争模型的比较。对于较小的模型，我们观察到 Qwen2.5-0.5B 模型达到了与 Qwen2-1.5B 模型相当甚至超越的水平。这表明 Qwen2.5 系列优化了参数使用，使中等规模模型能够达到上一代更大模型的类似性能水平。Qwen2.5-3B 模型表现出与 Qwen2-7B 模型相当的性能。值得注意的是，Qwen2.5-32B 模型相较 Qwen2-72B 模型有显著提升。我们的旗舰模型 Qwen2.5-72B 进一步缩小了 Qwen 与 GPT-4、Claude3.5-sonnet 等最先进模型之间的差距。尤其地，Qwen2.5-72B 在除指令遵循外的所有指标上匹敌或超越 Llama-3.1-405B 的性能。这一成就凸显了 Qwen2.5-72B 在广泛语言处理任务上的竞争力，同时也指出了未来改进的方向。Qwen2.5-Plus 弥补了此前在中文指令遵循方面的短板，并进一步增强其在其他方面的优势。

#### 5.2.3 奖励模型

奖励模型是指导 RL 流程的基石，因此我们对 Qwen2.5 系列所用的奖励模型进行了单独评测。我们的评测基准涵盖 Reward Bench（[Lambert et al., 2024](#bib.bib48)）、RMB（[Zhou et al., 2024](#bib.bib99)）、PPE（[Frick et al., 2024b](#bib.bib29)），以及一个内部收集的域外中文人类偏好基准（Human-Preference-Chinese），以提供全面分析。作为比较，我们纳入了基线模型，如 Nemotron-4-340B-Reward（[Adler et al., 2024](#bib.bib2)）、Llama-3.1-Nemotron-70B-Reward（[Wang et al., 2024c](#bib.bib85)）与 Athene-RM-70B（[Frick et al., 2024a](#bib.bib28)）。结果见表 15。总体而言，我们的发现表明：Llama-3.1-Nemotron-70B-Reward 在 Reward Bench 上表现最佳，而 Athene-RM-70B 在 RMB 基准上表现最好。Qwen2.5-RM-72B 在 PPE 与 Human-Preference-Chinese 评测中均处领先，在 RMB 上仅次于 Athene-RM-70B 位列第二，并在 Reward Bench 上取得与 Nemotron-4-340B-Reward 相当的性能水平，尽管略逊于 Llama-3.1-Nemotron-70B-Reward。

由于奖励模型评测方法的缺乏，当前奖励模型通常使用 Reward Bench 进行评测。然而，我们来自多个 RM 基准的评测结果表明，对特定基准的过度优化可能触发古德哈特定律（Goodhart's law，[Hoskin, 1996](#bib.bib37)），导致在其他基准上的性能退化，并可能影响下游对齐性能。这凸显了在多样基准上全面评测奖励模型的必要性，而非仅依赖单一基准。

更重要的是，通过迭代实验，我们还认识到一个关键局限：当前奖励模型评测基准并不能准确预测在其指导下训练出的 RL 模型的性能。换言之，RM 基准上的更高分数并不必然对应所得 RL 模型更优的表现。这一洞察凸显了对奖励模型更具预测性的评测方法开展进一步研究的需要。

## 6 结论

Qwen2.5 代表了大语言模型（LLM）的重大进步，其在 18 万亿 token 上增强的预训练与精巧的后训练技术（包括监督微调与多阶段强化学习）相得益彰。这些改进提升了人类偏好对齐、长文本生成与结构化数据分析，使 Qwen2.5 在指令遵循任务上高度有效。Qwen2.5 提供多种配置，既有从 0.5B 到 72B 参数的开放权重模型，也有包括 Qwen2.5-Turbo 与 Qwen2.5-Plus 等高性价比 MoE 变体在内的专有模型。实证评测表明，Qwen2.5-72B-Instruct 尽管规模小六倍，仍取得了与最先进 Llama-3-405B-Instruct 相当的性能。Qwen2.5 还作为专用模型的基础，展示了其在领域特定应用中的多功能性。我们相信，Qwen2.5 的强劲性能、灵活架构与广泛可得性，使其成为学术研究与工业应用的宝贵资源，并确立其作为未来创新关键参与者的地位。

未来，我们将聚焦于推进稳健的基础模型。首先，我们将通过纳入更广泛、更多样、更高质量的数据，迭代改进基础与指令微调大语言模型（LLM）。其次，我们将继续开发多模态模型，目标是将各种模态整合进统一框架，以促进跨文本、视觉与听觉领域的无缝端到端信息处理。第三，我们致力于增强模型的推理能力，这将通过推理算力资源的策略性扩展来实现。这些努力旨在突破当前技术的边界，并为更广泛的人工智能领域做出贡献。
